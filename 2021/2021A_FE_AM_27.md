# 2021A_FE_AM_27
Which of the following is an appropriate explanation of an E-R diagram?
a) A relationship is expressed by describing the related entity name in the entity type.
b) The relationship between entity types is expressed by an arrow from the referencing side in the direction of the referenced side.
c) There are no attributes in the entity type, but the relationship type has attributes.
d) There are several kinds of relationships between entity types such as one-to-many or many-to-many.
?
d) There are several kinds of relationships between entity types such as one-to-many or many-to-many.
### Explanation
An Entity-Relationship (E-R) diagram is used to represent data models, showing entities and the relationships between them. These relationships can have different cardinalities, such as one-to-one, one-to-many, or many-to-many, making (d) the correct choice. Entities can indeed have attributes (making c incorrect).

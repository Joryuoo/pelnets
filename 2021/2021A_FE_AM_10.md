# 2021A_FE_AM_10
Which of the following is an appropriate description of XML?

a) An exclusive editor is required to produce XML documents.
b) It is an integration of the logical structure and document style.
c) It is based on HTML and offers more extended functions.
d) The attributes and logical structure of a document can be defined with user-defined tags.
?
d) The attributes and logical structure of a document can be defined with user-defined tags.
### Explanation
XML (eXtensible Markup Language) is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. Its key feature is that it allows users to define their own custom tags to specify the logical structure and attributes of the data it contains.

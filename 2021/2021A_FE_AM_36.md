# 2021A_FE_AM_36
Which of the following properties for information security defined in ISO/IEC 27000:2018 refers to a guarantee that the message data received is the same as the message data sent?

a) Availability
b) Confidentiality
c) Integrity
d) Non-repudiation
?
c) Integrity
### Explanation
In information security, integrity ensures that data has not been altered, modified, or destroyed in an unauthorized manner during transmission or storage. It guarantees that the data received is exactly what was sent.

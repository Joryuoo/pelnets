# 2021A_FE_AM_11
Which of the following is an appropriate term for a special register that contains the address of the next instruction to be fetched?

a) Accumulator
b) Instruction register
c) Program counter
d) Status register
?
c) Program counter
### Explanation
The Program counter (also known as the Instruction pointer) is a special-purpose register in a computer processor that holds the memory address of the next instruction to be fetched and executed.
- Accumulator: Stores the results of arithmetic and logic operations.
- Instruction register: Holds the current instruction that is being decoded or executed.
- Status register: Holds condition codes or flags (like zero, carry, overflow) that indicate the results of the last operation.

# 2021A_FE_AM_35
Which of the following is an appropriate description of a Trojan horse?

a) A brute force attack software tool
b) A malicious computer program that presents itself as a legitimate one
c) A malicious user that steals private information from a system
d) A software tool to decrypt an encrypted password
?
b) A malicious computer program that presents itself as a legitimate one
### Explanation
A Trojan horse is a type of malware that disguises itself as legitimate or desirable software to trick users into executing it. Once activated, it can steal data, compromise security, or cause other harm to the computer system.

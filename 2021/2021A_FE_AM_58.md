# 2021A_FE_AM_58
In the event of a disk failure, which of the following is a method for recovering a database by restoring a full backup data onto a disk from a tape, and then reflecting, from logs, post-update copies after the full backup was taken?

a) Checkpoint restart
b) Reboot
c) Roll forward
d) Rollback
?
c) Roll forward
### Explanation
**Roll forward** is a recovery technique used after a physical failure (like a disk crash). It involves restoring the latest full backup from a storage medium and then applying the transactions recorded in the transaction log file (post-update copies/after-images) sequentially to bring the database back to its state right before the failure. Rollback (or Roll backward) is used to undo uncommitted transactions (using before-images).

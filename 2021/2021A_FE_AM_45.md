# 2021A_FE_AM_45
Which of the following UML diagrams is used to represent the user interactions with the system and the functions of the system?

a) Activity diagram
b) Class diagram
c) Sequence diagram
d) Use case diagram
?
d) Use case diagram
### Explanation
A Use Case diagram in UML (Unified Modeling Language) is specifically designed to represent the interactions between users (actors) and the system, illustrating the functional requirements and the different ways users can interact with the system.
- Activity diagram shows the flow of control or object flow with emphasis on the sequence and conditions of the flow.
- Class diagram shows the static structure of the system (classes, attributes, operations, and relationships).
- Sequence diagram shows object interactions arranged in a time sequence.

# 2021A_FE_AM_65
Which of the following is an activity that is performed when non-functional requirements are defined?

a) Clarifying the flows of information (i.e., data) between the functions that constitute business operations
b) Creating technical requirements of development standard according to the programming language used in system development
c) Defining the scope to be implemented as system functions
d) Specifying the interface for exchanging information with other systems
?
b) Creating technical requirements of development standard according to the programming language used in system development
### Explanation
Non-functional requirements dictate how a system should perform rather than what it should do. This includes technical requirements, performance, security, reliability, and development standards, whereas functional requirements (like defining system functions or interfaces) describe specific behaviors or functions.

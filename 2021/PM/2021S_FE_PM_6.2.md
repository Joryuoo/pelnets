### Explanation
- **Blank C**: The BFS (Breadth-First Search) algorithm initializes by setting the distance of the starting node `s` to 0. Since the array `d` stores these shortest path distances, the correct code initialization is `d[s] <- 0`. This corresponds to answer **d**.
- **Blank D**: When an unvisited neighbor node `w` is discovered from the currently evaluated node `v`, its shortest path distance from the start node is the distance of `v` plus 1. Therefore, the distance of `w` should be updated as `d[w] <- d[v] + 1`, which corresponds to answer **h**.

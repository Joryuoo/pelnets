### Explanation
**Subquestion 1**

The `display_poly` function outputs a polynomial based on an integer array of its coefficients. Let's analyze the requirements and how they are implemented in the C code:

**Blank A:**
When `deg == 0`, the polynomial has only a single constant term. According to rule (i), the program should print `0` for the zero polynomial `{0}`, and according to rule (vi), if the degree is 0, it shouldn't print `*`, `x`, or `^`. Therefore, it simply prints the constant value, which is `pol[0]`. Thus, `____A____` should be `"%d", pol[0]`, which corresponds to option **b**.

**Blank B:**
The `for` loop iterates from `i = deg` down to `0`. Inside the loop, it calls `print_coef` and `print_star` for each term. `print_coef` takes `(int coef, int pow, int deg)`, and `print_star` takes `(int coef, int pow)`. The coefficient for the term with power `i` is `pol[i]`. So, both function calls should receive `pol[i], i` as arguments for their `coef` and `pow` parameters. This corresponds to option **d**.

**Blank C:**
In `print_coef`, if `coef == 1`, rule (iii) states that a positive coefficient (except for the highest degree) needs a `+` sign. The highest degree is handled differently (where `deg == 0` isn't processed in this loop because `display_poly` catches it first). Here, if `pow == 0`, the loop is handling a constant term, which must always be a lower degree term. Since `coef` is 1, it should just print `+1`. Therefore, `____C____` is `"+1"`, which corresponds to option **c**.

**Blank D:**
When `coef == -1`, rule (iv) states that for a degree that is not 0, it should omit `1`, so it only needs to print `-`. In `print_coef`, there is a check immediately after printing `____D____`: if `pow == 0`, it prints `"1"`. This means `____D____` should simply print the negative sign `"-"` so that the `-1` logic successfully yields `"-1"` when `pow == 0` and `"-"` otherwise. Thus, `____D____` is `"-"`, corresponding to option **e**.

**Blank E:**
The `print_star` function determines whether to print the multiplication sign `*`. According to the rules, `*` is printed between the coefficient and the variable `x`. Rule (vi) specifies that if the degree is 0, we do not print `*`. Moreover, rule (iv) specifies that if the coefficient is 1 or -1 and the degree is not 0, we omit `*`. The code `if (____E____ && coef != 1 && coef != -1)` already handles the `coef` conditions. To ensure `*` is not printed when the degree is 0, `____E____` must be `pow > 0`. This corresponds to option **b**.

### Explanation
**Subquestion 2**
The SQL query (SQL2) calculates the total ordered quantity and total arrived quantity for each order number, then computes the amount that still needs to arrive.

1. **Blank B:** The query needs the total ordered quantity per order. In the subquery `d`, the `OrderDetail` table is grouped by `OrderNo`, so the select clause should aggregate the quantity: `SUM(Quantity) AS TotalQuantity`. This corresponds to **f**.
2. **Blank C:** The query needs the total arrived quantity per order. In the subquery `a`, the `Arrival` table is grouped by `OrderNo`, so the select clause should aggregate the arrival quantity: `SUM(ArrivalQuantity) AS ArrivalQuantity`. This corresponds to **e**.
3. **Blank A:** The query performs a `LEFT JOIN` from the `d` subquery to the `a` subquery. If an order has no corresponding records in the `Arrival` table, `a.ArrivalQuantity` will be `NULL`. The `ISNULL` function should replace this `NULL` with `0` so the math works. The correct syntax is `a.ArrivalQuantity, 0`. This corresponds to **a**.
4. **Blank D:** Looking at the sample data, Order 3 is present in the `OrderDetail` table but has no corresponding records in the `Arrival` table. Since it's a `LEFT JOIN` from `d`, the row for Order 3 will be preserved, but all its columns from the `a` table will be `NULL`. Thus, the `d.OrderNo` of the row containing `NULL` fields is `3`. This corresponds to **c**.

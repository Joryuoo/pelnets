According to Table 1, CR's interface `e0` has the IP address `172.16.100.1` with a `/30` subnet mask (`255.255.255.252`). This means the network `172.16.100.0/30` is physically attached to CR's `e0` interface. Therefore, the Next hop/GW should be **directly connected** (i).
- **Blank B:** In Table 3 (Routing Information of Router 1), to reach the destination network `172.16.100.128/25` (which is connected to R2's `e2` interface), R1 must forward packets to Router 2. R1 and R2 share the network `172.16.100.4/30` (R1's `e0` is `172.16.100.5` and R2's `e1` is `172.16.100.6`). Thus, the Next hop/GW for R1 to reach R2's LAN is R2's interface IP on this shared link, which is **172.16.100.6** (h).
- **Blank C:** In Table 4 (Routing Information of Router 2), the Next hop/GW is `172.16.100.1` (the Core Router CR) and it uses interface `e0`. Since CR connects the internal network to the Internet, R2 must send all unknown Internet-bound traffic to CR. This is represented by a default route, which is specified as **any/any** (g) in the Destination Network column.

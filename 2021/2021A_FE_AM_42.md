# 2021A_FE_AM_42
Which of the following technologies is the most suitable to divide the whole company network into networks by department?

a) DMZ (DeMilitarized Zone)
b) NAT (Network Address Translation)
c) VLAN (Virtual Local Area Network)
d) VPN (Virtual Private Network)
?
c) VLAN (Virtual Local Area Network)
### Explanation
A Virtual Local Area Network (VLAN) is a logical grouping of devices in the same broadcast domain, which allows a physical network to be partitioned into multiple logical networks. This is highly suitable for dividing a company's network into smaller networks by department to improve security and performance.
- DMZ is used to expose external-facing services to an untrusted network.
- NAT is used to translate private IP addresses to a public IP address.
- VPN is used to securely connect remote users or sites over a public network.

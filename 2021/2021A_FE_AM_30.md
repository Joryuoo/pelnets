# 2021A_FE_AM_30
In the OSI basic reference model, which of the following is a network device that operates at the network layer?
a) Access point
b) Bridge
c) Repeater
d) Router
?
d) Router
### Explanation
In the OSI (Open Systems Interconnection) basic reference model, a router is the standard network device that operates at Layer 3, the Network layer. It is responsible for routing data packets between different IP networks. For context, a repeater operates at Layer 1 (Physical layer), and a bridge operates at Layer 2 (Data Link layer).

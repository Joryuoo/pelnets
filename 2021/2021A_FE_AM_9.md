c) 91
### Explanation
This is McCarthy's 91 function, defined as:
M(n) = n - 10 if n > 100
M(n) = M(M(n + 11)) if n <= 100
For any input n <= 100, McCarthy's 91 function evaluates to exactly 91. Since 97 <= 100, M(97) = 91.

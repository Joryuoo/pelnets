# 2021A_FE_AM_3

?
d) (A ∩ C) ∪ (B ∩ C) = (A ∪ B) ∩ C
### Explanation
By the distributive property of sets, the intersection of a set C with the union of sets A and B is equal to the union of the intersections of C with A and C with B. Therefore, (A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C), which matches option d.

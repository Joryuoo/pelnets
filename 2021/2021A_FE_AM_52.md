# 2021A_FE_AM_52
A project is planned to complete in 12 months and the budget for the completion of the project is $100,000. After six months, it is found that $60,000 was spent, but only 40% of the work has been completed. If the Cost Performance Index (CPI) is not changed, what is the estimated amount (in dollars) required to complete the remaining tasks of the project?

a) 40,000
b) 60,000
c) 90,000
d) 150,000
?
c) 90,000
### Explanation
*   **Budget at Completion (BAC)** = $100,000
*   **Actual Cost (AC)** = $60,000
*   **Earned Value (EV)** = 40% of BAC = $100,000 * 0.40 = $40,000
*   **Cost Performance Index (CPI)** = EV / AC = $40,000 / $60,000 = 2/3

The remaining work is 60% of the project, which has a planned value of $60,000.
**Estimate to Complete (ETC)** = (Remaining Planned Value) / CPI = $60,000 / (2/3) = $60,000 * (3/2) = $90,000.
Thus, $90,000 is required to complete the remaining tasks.

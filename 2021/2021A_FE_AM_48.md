# 2021A_FE_AM_48
Which of the following is an appropriate description concerning test data for black box testing?

a) Test data is created based on branch coverage.
b) Test data is created based on condition coverage.
c) Test data is created based on external specifications.
d) Test data is created based on program structures.
?
c) Test data is created based on external specifications.
### Explanation
Black box testing (also known as specification-based testing) focuses on the inputs and expected outputs of the software system without knowing the internal implementation or code structure. Therefore, test data is designed based on external requirements and specifications.
- Options A, B, and D all describe techniques used in white box testing, which relies on the internal structure and logic of the code (branch coverage, condition coverage, program structures).

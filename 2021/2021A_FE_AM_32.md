# 2021A_FE_AM_32
Which of the following is a data link layer function that enables a receiver to control the amount of data a sender transmits?

a) Congestion control
b) Error control
c) Flow control
d) Media access control
?
c) Flow control
### Explanation
Flow control is a technique used in data communications to manage the rate of data transmission between two nodes to prevent a fast sender from overwhelming a slow receiver. It helps the receiver control the amount of data it is willing to accept.

# 2021A_FE_AM_39
Which of the following is a type of malware that embeds itself within a program and inserts its copy into other programs?

a) Backdoor
b) Trojan horse
c) Virus
d) Worm
?
c) Virus
### Explanation
A computer virus is a type of malicious software that requires a host program to operate. It embeds itself within an executable file and, when executed, replicates by inserting copies of itself into other programs or files.

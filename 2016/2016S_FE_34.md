# 2016S_FE_34
Which of the following is a data link layer function that enables receivers to control the amount of data to be received from the senders?

a) Congestion control
b) Error control
c) Flow control
d) Media access control
?
c) Flow control

### Explanation
**Flow control** is a mechanism used in data communication (both at the Data Link layer and the Transport layer) to regulate the rate of data transmission between two communicating nodes. It ensures that a fast sender does not overwhelm a slow receiver with more frames or packets than the receiver can buffer and process.

Common data link layer flow control mechanisms include:
- **Stop-and-Wait**: The sender transmits one frame and waits for an acknowledgment (ACK) before sending the next.
- **Sliding Window**: Allows the sender to transmit multiple frames up to a negotiated window size before requiring an acknowledgment.
- **Pause Frames (IEEE 802.3x)**: In Ethernet, a receiver sends a pause frame to temporarily halt transmissions when its buffers near saturation.

**Analysis of incorrect options:**
- **a) Congestion control**: Prevents network bottlenecks and overload in intermediate routers and links across the network (typically managed at the network and transport layers, e.g., TCP congestion control).
- **b) Error control**: Detects and corrects transmission errors (e.g., CRC checksums, ARQ retransmissions) to ensure frame integrity.
- **d) Media access control (MAC)**: Sublayer of the data link layer responsible for controlling how devices share and access a shared physical medium without collisions (e.g., CSMA/CD, CSMA/CA).

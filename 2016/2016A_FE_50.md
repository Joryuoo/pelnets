# 2016A_FE_50
Which of the following is an appropriate order of six phases used in every SDLC (Software Development Life Cycle) model?

a) Requirements Analysis → Design → Programming → Deployment → Testing → Maintenance
b) Requirements Analysis → Design → Programming → Testing → Deployment → Maintenance
c) Requirements Analysis → Design → Programming → Testing → Maintenance → Deployment
d) Requirements Analysis → Programming → Testing → Design → Maintenance → Deployment
?
b) Requirements Analysis → Design → Programming → Testing → Deployment → Maintenance
### Explanation
The Software Development Life Cycle (SDLC) defines the standard sequence of phases through which a software product is created, deployed, and supported:

1. **Requirements Analysis:** Gathering business needs, defining user requirements, and analyzing system specifications.
2. **Design:** Creating architectural blueprints, system workflows, database schemas, and interface specifications based on the requirements.
3. **Programming (Implementation / Coding):** Writing executable source code according to the design specifications.
4. **Testing:** Verifying and validating that the developed software meets requirements, functions properly, and is free of defects.
5. **Deployment:** Releasing and installing the tested software into the target production environment for users.
6. **Maintenance:** Ongoing operational support, bug fixing, performance optimization, and adapting the system over time.

Therefore, the correct chronological order is:
**Requirements Analysis → Design → Programming → Testing → Deployment → Maintenance** (Option **b**).

Why the other options are incorrect:
* **a)** Inverts testing and deployment (testing must always occur before software is deployed to production).
* **c)** Places maintenance before deployment (a system cannot undergo operational maintenance before being released to production).
* **d)** Places programming before design and places maintenance before deployment.

# 2016A_FE_46
Which of the following is the most appropriate explanation of the deployment diagram defined in UML 2.x (including 2.0 and later versions)?

a) It addresses the dynamic view of the system. In other words, it is drawn for a single class to show the lifetime behavior of a single object.
b) It describes the types of objects in the system and the various kinds of static relationships that exist among them.
c) It shows a static view of the run-time configuration of processing nodes, such as servers and clients, as well as the components that run on these nodes.
d) It shows the organizations and dependencies among a set of pieces that are independently purchasable and upgradeable, and addresses the static implementation view of the system.
?
c) It shows a static view of the run-time configuration of processing nodes, such as servers and clients, as well as the components that run on these nodes.
### Explanation
In the Unified Modeling Language (UML 2.x):

* A **Deployment Diagram** models the physical architecture of an IT system. It illustrates the physical hardware devices and execution environments (**processing nodes**, such as web servers, database servers, and clients), communication paths connecting them, and the software artifacts and components deployed onto those nodes. It represents the **static deployment view** of the system.

Breakdown of the other options:
* **a)** Describes a **State Machine Diagram** (Statechart Diagram), which specifies the dynamic lifecycle behavior of an object in response to events and transitions.
* **b)** Describes a **Class Diagram**, which models the static structural view of classes, attributes, operations, and relationships (inheritance, association, aggregation).
* **d)** Describes a **Component Diagram**, which shows the modular software components, their interfaces, and dependencies representing the static implementation view.

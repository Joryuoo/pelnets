# 2016S_FE_39
Which of the following is an appropriate method of authenticating users by using a password?

a) The hash value of the user ID corresponding to the password is registered, and the password entered during authentication is converted by the hash function and compared.
b) The hash value of the user ID corresponding to the password is registered, and the user ID entered during authentication is converted by the hash function and compared.
c) The password is converted to a hash value and registered, and the password entered during authentication is converted by the hash function and compared.
d) The password is converted to a hash value and registered, and the user ID entered during authentication is converted by the hash function and compared.
?
c) The password is converted to a hash value and registered, and the password entered during authentication is converted by the hash function and compared.

### Explanation
To prevent unauthorized exposure of user credentials in the event of a database compromise, passwords must never be stored in plain text. Secure password-based authentication follows a two-stage cryptographic hashing procedure:

1. **User Registration**:
   - The user inputs their desired password.
   - The system computes the **hash value** of the password using a cryptographic one-way hash function (typically combined with a unique salt to defeat precomputed rainbow tables).
   - Only the resulting hash value (and salt) is stored in the database alongside the user ID.

2. **User Authentication (Login)**:
   - When the user logs in, they supply their user ID and plain text password.
   - The system hashes the entered password using the identical hash function (and stored salt).
   - The computed hash is compared against the stored registered hash value. If the two match, the user is authenticated.

**Analysis of incorrect options:**
- **a)** Compares a hash of the user ID with a hash of the password, which are unrelated values.
- **b)** Only compares user ID hashes; user ID is public/identifier information, not secret authentication knowledge.
- **d)** Compares the stored password hash with the hash of the user ID, which will never match.

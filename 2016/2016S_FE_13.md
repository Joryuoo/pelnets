# 2016S_FE_13
Which of the following is an addressing mode that provides an offset to the program counter (PC) content to determine the address of the operand?

a) Immediate addressing mode
b) Indirect addressing mode
c) Register indirect addressing mode
d) Relative addressing mode
?
d) Relative addressing mode
### Explanation
Addressing modes dictate how an operand's effective address (EA) is determined:
- **Relative addressing mode (Program Counter Relative Addressing):** The effective address is obtained by adding a signed offset (displacement) provided in the instruction to the current contents of the Program Counter (PC):
  $$\text{EA} = \text{PC} + \text{Offset}$$
  This is commonly utilized for conditional branches and position-independent code.
- **Immediate addressing mode:** The instruction directly contains the data operand itself in the address/immediate field.
- **Indirect addressing mode:** The address field of the instruction references a memory location that contains the effective address of the operand.
- **Register indirect addressing mode:** A CPU register holds the memory address of the operand.

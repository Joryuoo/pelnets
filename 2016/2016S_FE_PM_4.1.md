### Explanation

**Subquestion 1:**
*   **Blank A (b):** The text in step (2) explicitly states that "The server creates a **client-file table** in the cache to keep track of what files the client has." Therefore, the server uses the client-file table to know the files each device has.
*   **Blank B (f):** According to the problem description for an updated file, step (8u) indicates that an "update tag is placed in the client-file table," and step (9u) says "A broadcast of the file update is sent." This implies that the **update tag on the client-file table** is used to determine if a broadcast that a file update has occurred is needed.
*   **Blanks C and D (b, c):** When multiple workstations with empty Disk Ws request the exact same files from the server, the server will retrieve these files from its cache instead of Disk S (since the first request placed them in the cache). This increases the **hit ratio of cache**. Additionally, downloading all these files to multiple workstations simultaneously will significantly increase the **network traffic**. (Answers can be in either order).
*   **Blank E (b):** This behavior occurs during the process where the server sends the files to the workstations, which corresponds to step **(3)** ("Send files & directory structure") in Figure 1.

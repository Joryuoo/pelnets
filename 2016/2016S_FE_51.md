# 2016S_FE_51
Which of the following is a mechanism that allows several subclasses of a common parent class to override the same method with different behaviors?

a) Aggregation
b) Composition
c) Inheritance
d) Polymorphism
?
d) Polymorphism
### Explanation
**Polymorphism** (specifically *subtype polymorphism* or *dynamic method dispatch*) is an object-oriented programming concept where different subclasses derived from a common superclass can provide their own specific implementations of a method (method overriding). When a call is made to the method via a reference to the superclass, the specific behavior executed depends dynamically on the actual runtime object.

- **Polymorphism (d)**: Allows multiple derived classes to implement a method with the same name and signature in different ways, exhibiting polymorphic behavior at runtime.
- **Aggregation (a)**: A weak "has-a" relationship between classes where child objects can exist independently of the parent object.
- **Composition (b)**: A strong "has-a" relationship where child objects are bound to the parent's lifecycle and cannot exist without it.
- **Inheritance (c)**: The mechanism allowing a class to inherit fields and methods from another class ("is-a" relationship). While inheritance provides the hierarchy necessary for overriding, the ability of multiple subclasses to execute distinct behaviors through that overridden method is polymorphism.

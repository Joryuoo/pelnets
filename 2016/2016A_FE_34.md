# 2016A_FE_34
Concerning email protocols, which of the following descriptions is correct?

a) IMAP allows the message to remain on the server even after it is downloaded to a local PC.
b) IMAP uses UDP for faster downloading of emails, whereas POP3 uses TCP.
c) POP3 and IMAP uses the same port number for interoperability in email communication.
d) POP3 is used for sending email messages from the sender’s mail server to the receiver’s mail server.
?
a) IMAP allows the message to remain on the server even after it is downloaded to a local PC.
### Explanation
* **IMAP (Internet Message Access Protocol):** Designed to manage email messages directly on the remote mail server. When a client reads or downloads a message, the email remains stored on the mail server unless explicitly marked for deletion. This enables synchronized email management across multiple devices (e.g., PC, smartphone, webmail). Thus, **a** is correct.

**Why the other options are incorrect:**
* **b)** Both IMAP and POP3 operate over **TCP** to guarantee reliable, error-free transmission of email messages. Neither protocol uses UDP.
* **c)** POP3 and IMAP use different default port numbers:
  * **POP3:** TCP Port 110 (unencrypted) / Port 995 (POP3S over SSL/TLS).
  * **IMAP:** TCP Port 143 (unencrypted) / Port 993 (IMAPS over SSL/TLS).
* **d)** Sending email messages from a client to a mail server, or between mail servers, is performed by **SMTP (Simple Mail Transfer Protocol)**. POP3 is exclusively a mail retrieval protocol used by an end-user client to fetch mail from a server.

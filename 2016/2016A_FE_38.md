# 2016A_FE_38
Which of the following is an appropriate description of a Trojan horse used for security attacks in computing?

a) It is a brute force attack algorithm.
b) It is an effective way to detect an intruder.
c) It is a rogue program that tricks users.
d) It is a user who steals valuable information.
?
c) It is a rogue program that tricks users.
### Explanation
* **Trojan Horse (Trojan):** A class of malicious software (malware) disguised as legitimate, benign, or useful software (such as a utility, system tool, or game) to mislead and trick users into installing and running it. Once executed, it carries out concealed malicious activities, such as granting backdoor access, stealing credentials, or installing spyware.
* Unlike viruses or worms, a Trojan horse does not self-replicate or spread on its own by infecting other files; its propagation depends entirely on social engineering and deceptive appearance. Therefore, **c** is the correct description.

**Analysis of other options:**
* **a)** Describes a cryptographic key or password recovery technique, not a Trojan horse.
* **b)** Describes an Intrusion Detection System (IDS) or honeypot mechanism.
* **d)** Describes a human threat actor or malicious insider, not a software program.

# 2016S_FE_17
Which of the following is an appropriate description of throughput?

a) Even if some idle time resulting from operator intervention between the end of a job and the start of the next job occurs in a system, throughput is not affected.
b) Multi-programming contributes to reducing turnaround time, but is not useful in improving throughput.
c) Spooling, which involves temporarily saving the output to a printer in a hard disk, is useful in improving throughput.
d) Throughput is an index of CPU performance and is not affected by the I/O speed, overhead time, and other such factors.
?
c) Spooling, which involves temporarily saving the output to a printer in a hard disk, is useful in improving throughput.
### Explanation
**Throughput** represents the total amount of useful work or number of jobs processed by a computer system per unit of time (e.g., transactions per second, jobs per hour).
- **c) is correct:** **Spooling** (Simultaneous Peripheral Operations On-Line) buffers data destined for slow I/O devices (such as printers) onto high-speed secondary storage (hard disk). This decouples the CPU from the device's slow transfer rate, freeing the CPU to immediately proceed to execute other pending tasks, thereby substantially boosting overall system throughput.
- **a) is incorrect:** Idle time directly reduces the number of completed jobs per unit of time, which inevitably lowers system throughput.
- **b) is incorrect:** Multi-programming keeps the CPU active by switching to other runnable tasks whenever a task is waiting for an I/O operation, which directly enhances CPU utilization and increases throughput.
- **d) is incorrect:** Throughput is a holistic measure of whole-system performance and is significantly constrained by I/O latency, memory bandwidth, operating system context-switching overhead, and peripheral bottlenecks.

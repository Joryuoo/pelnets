# 2016S_FE_31
Which of the following is an appropriate method used to remove data redundancy in relational database systems?

a) Entity-relationship
b) Functional dependency
c) Hierarchical
d) Normalization
?
d) Normalization

### Explanation
**Normalization** is the systematic design process used in relational databases to organize tables and attributes to minimize or eliminate data redundancy and prevent update, insertion, and deletion anomalies. It involves decomposing tables into smaller, well-structured relations following a series of normal forms (such as 1NF, 2NF, 3NF, and BCNF).

- **a) Entity-relationship**: ER modeling is a high-level conceptual modeling technique used during the initial database design phase to represent entities and their relationships. It is not an algorithm or method for eliminating data redundancy in relational schemas.
- **b) Functional dependency**: A functional dependency ($X \rightarrow Y$) describes a relationship and constraint between attributes where one attribute uniquely determines another. While functional dependencies are analyzed *to perform* normalization, the dependency itself is not the method used to remove redundancy.
- **c) Hierarchical**: Refers to the hierarchical database model, an older database paradigm where records are organized in a tree-like hierarchy (parent-child segments), rather than a method for removing redundancy in relational systems.

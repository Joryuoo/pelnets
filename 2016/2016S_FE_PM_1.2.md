### Explanation

**Subquestion 2:**
* **Blank E:** To prevent SQL injection attacks, developers should verify and sanitize characters entered into a Web form, ensuring illegal characters (such as single quotes `'` or double hyphens `--`) are safely handled, escaped, or rejected. This stops the attacker from altering the SQL statement's structural logic. Thus, **E = d**.
  * Desktop applications (a) are still vulnerable if they construct unsanitized database queries.
  * Hashing passwords (b) secures stored passwords from database breaches but does not prevent the application from executing injected SQL commands.
  * A packet-filtering firewall (c) blocks unauthorized network traffic to the database, but since SQL injections are transmitted through the legitimate Web server connection, a firewall cannot stop them.

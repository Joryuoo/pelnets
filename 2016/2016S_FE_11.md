# 2016S_FE_11
In a CPU with a four (4)-stage pipeline composed of fetch, decode, execute, and write back, each stage takes 10, 6, 8, and 8 ns, respectively. Which of the following is an approximate average instruction execution time in nanoseconds (ns) in the CPU? Here, the number of instructions to be executed is sufficiently large. In addition, the overhead for the pipelining process is negligible, and the latency impact from all hazards is ignored.

a) 6
b) 8
c) 10
d) 32
?
c) 10
### Explanation
In an instruction pipeline, multiple instructions are processed concurrently across sequential stages.
- The execution times for each stage are:
  - **Fetch:** 10 ns
  - **Decode:** 6 ns
  - **Execute:** 8 ns
  - **Write Back:** 8 ns
- The pipeline clock cycle time is governed by the longest (bottleneck) stage because all stages must synchronize to the same clock.
  $$\text{Clock Cycle Time} = \max(10, 6, 8, 8) = 10\text{ ns}$$
- Once the pipeline is fully loaded, one instruction completes every clock cycle (every 10 ns).
- For a sufficiently large number of instructions $N$, the initial latency required to fill the pipeline becomes negligible, resulting in an average execution time of approximately **10 ns** per instruction.

# 2016A_FE_18
In a paged virtual memory system, the LRU method is used in the page replacement algorithm. When the page frame assigned to the main memory is 4, and pages are accessed in the order of 1, 2, 3, 4, 5, 2, 1, 3, 2, 6, which of the following page is replaced at the time of accessing page 6? Here, no page exists in the main memory in the initial state.

a) 1
b) 2
c) 4
d) 5
?
d) 5
### Explanation
The **LRU (Least Recently Used)** page replacement algorithm replaces the page that has not been accessed for the longest period of time when a page fault occurs and all memory frames are occupied.

- Number of page frames = **4**
- Sequence of page accesses: `1, 2, 3, 4, 5, 2, 1, 3, 2, 6`

---

#### Step-by-Step Trace:
We maintain the set of 4 frames ordered from **[Least Recently Used $\rightarrow$ Most Recently Used]**:

| Step | Page Accessed | Status | Frames Content [LRU $\rightarrow$ MRU] | Action / Evicted Page |
| :---: | :---: | :---: | :---: | :--- |
| 1 | **1** | Page Fault | `[1]` | Loaded into empty frame |
| 2 | **2** | Page Fault | `[1, 2]` | Loaded into empty frame |
| 3 | **3** | Page Fault | `[1, 2, 3]` | Loaded into empty frame |
| 4 | **4** | Page Fault | `[1, 2, 3, 4]` | Loaded into empty frame (All 4 frames full) |
| 5 | **5** | Page Fault | `[2, 3, 4, 5]` | Page **1** is LRU $\rightarrow$ replaced by **5** |
| 6 | **2** | Hit | `[3, 4, 5, 2]` | Page **2** accessed $\rightarrow$ moved to MRU |
| 7 | **1** | Page Fault | `[4, 5, 2, 1]` | Page **3** is LRU $\rightarrow$ replaced by **1** |
| 8 | **3** | Page Fault | `[5, 2, 1, 3]` | Page **4** is LRU $\rightarrow$ replaced by **3** |
| 9 | **2** | Hit | `[5, 1, 3, 2]` | Page **2** accessed $\rightarrow$ moved to MRU |
| 10 | **6** | Page Fault | `[1, 3, 2, 6]` | Page **5** is LRU $\rightarrow$ replaced by **6** |

---

#### Detailed Inspection at Step 10 (Accessing Page 6):
Just before page 6 is accessed, the state of the 4 frames and their most recent access steps are:
- Page **5**: last accessed at Step 5 (Least recently used)
- Page **1**: last accessed at Step 7
- Page **3**: last accessed at Step 8
- Page **2**: last accessed at Step 9 (Most recently used)

Because page **5** has the oldest access time (Step 5), it is the least recently used page and will be replaced to accommodate page 6.

Therefore, the correct choice is **d) 5**.

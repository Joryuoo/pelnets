# 2016A_FE_36
Which of the following is a secure communication protocol that provides a hybrid cryptosystem where public key cryptography is used to transfer a shared private key securely to the other side, and private key cryptography is used to encrypt subsequent communications for the remaining session?

a) AES (Advanced Encryption Standard)
b) RSA
c) SSL/TLS (Secure Socket Layer/Transport Layer Security)
d) WAF (Web Application Firewall)
?
c) SSL/TLS (Secure Socket Layer/Transport Layer Security)
### Explanation
* **SSL/TLS (Secure Sockets Layer / Transport Layer Security):** A cryptographic protocol operating between the transport layer and application layer that secures network communications (such as HTTPS). It utilizes a **hybrid cryptosystem** to balance performance and security:
  1. **Public-Key (Asymmetric) Cryptography** (such as RSA or Diffie-Hellman / ECDHE) is used during the handshake to authenticate the server (and optionally the client) and securely exchange/establish a shared secret key.
  2. **Private-Key / Symmetric-Key Cryptography** (such as AES or ChaCha20) uses that shared secret key to encrypt bulk data transmission for the remainder of the session, providing high speed and low computational overhead.

**Analysis of other options:**
* **a) AES:** A symmetric block cipher algorithm, not a communication protocol.
* **b) RSA:** An asymmetric (public key) encryption and signature algorithm, not a full network protocol.
* **d) WAF:** An application firewall that monitors and blocks malicious HTTP traffic (such as SQL injection and XSS), not an encryption protocol.

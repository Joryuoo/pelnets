# 2016A_FE_20
Which of the following is an open source integrated development environment that includes software and support tools for application development?

a) Eclipse
b) Perl
c) PHP
d) Ruby
?
a) Eclipse
### Explanation
An **Integrated Development Environment (IDE)** is a comprehensive software application providing programmers with combined tools for software development, typically comprising a source code editor, build automation tools, a compiler/interpreter, and a debugger.

- **a) Eclipse:** An open-source, extensible **Integrated Development Environment (IDE)** managed by the Eclipse Foundation. Although initially famous as a Java development environment, its modular plugin architecture supports numerous languages (such as C/C++, PHP, Python, and JavaScript) along with integrated testing, profiling, version control, and GUI building tools.
- **b) Perl:** A high-level, interpreted scripting **programming language** renowned for text manipulation and regular expression capabilities.
- **c) PHP (Hypertext Preprocessor):** A widely-used open-source server-side **scripting language** primarily designed for web development.
- **d) Ruby:** An open-source, object-oriented dynamic **programming language** focusing on simplicity and developer productivity.

Therefore, **a) Eclipse** is the only IDE among the choices.

# 2016A_FE_58
When a version management system for source code is installed, which of the following is an appropriate check point to be added for the confidentiality of the source code during the system audit?

a) The access control settings of the version management system are appropriate.
b) The installation cost of the version management system is at a proper level.
c) The results of the change registered in the version management system are approved by the person in charge.
d) The version management system is selected by the development department.
?
a) The access control settings of the version management system are appropriate.
### Explanation
In information security and system auditing, controls are evaluated against the three core tenets of the **CIA Triad** (Confidentiality, Integrity, and Availability):

* **Confidentiality (Option a):**
  Ensures that sensitive information (such as proprietary software source code) is shielded from unauthorized access, viewing, or disclosure. Verifying that **access control settings** (e.g., repository permissions, user authentication, role-based access privileges, and branch restrictions) are appropriately configured is the direct check point for **confidentiality**.

Analysis of other options:
* **b) Installation cost:** Evaluates economic efficiency, budget compliance, and procurement cost-benefit, not security or confidentiality.
* **c) Approval of registered changes:** Ensures that changes are properly vetted and authorized to maintain code quality, security, and correctness. This evaluates **integrity**, not confidentiality.
* **d) Tool selection by the development department:** Relates to IT governance and tool selection procedures, not confidentiality control.

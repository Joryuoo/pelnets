# 2016A_FE_24
Which of the following shows the path information from the front page of a web site to the current page, a user is currently viewing?

a) Breadcrumbs
b) Navigation bar
c) Scroll bar
d) Site map
?
a) Breadcrumbs
### Explanation
**Breadcrumbs** (or **breadcrumb navigation**) is a secondary navigational aid used in web design and user interfaces:

- **Function:** It typically appears horizontally near the top of a webpage below the main header, showing the hierarchical path from the root / home page to the page the user is currently viewing (e.g., `Home > Products > Electronics > Laptops`).
- **Benefits:**
  1. It provides immediate contextual awareness of the user's location within the website's structure.
  2. It allows users to quickly jump back to higher-level parent categories or the home page with a single click.
  3. It reduces the number of actions a user needs to take to navigate to higher-level pages.
- **Origin:** The term comes from the classic fairy tale *Hansel and Gretel*, where breadcrumbs were dropped along the trail so they could find their way back home.

**Analysis of incorrect options:**
- **b) Navigation bar:** A primary UI component (header or sidebar menu) displaying top-level navigational links across the website (e.g., Home, About, Services, Contact), rather than the specific hierarchical trail to the current page.
- **c) Scroll bar:** A GUI control element that allows users to scroll through content vertically or horizontally when the page content exceeds the display viewport.
- **d) Site map:** A comprehensive list or hierarchical diagram of all pages available across an entire website, designed either as a directory page for users or as an XML file for search engine web crawlers.

# 2016A_FE_40
Which of the following is an example of improper use of a key logger?

a) It interrupts the communication between two parties, and then collects and falsifies the information being exchanged.
b) When Internet banking is used, it collects the password entered by the user.
c) When the browser is initiated, it arbitrarily displays a tool bar that the user has not installed.
d) When the user browses movies on a browser, it arbitrarily displays unintended advertisements for the user.
?
b) When Internet banking is used, it collects the password entered by the user.
### Explanation
* **Keylogger (Keystroke Logger):** A surveillance tool (either a software utility or a hardware dongle plugged into the keyboard port) designed to record every key pressed on a keyboard.
* In malicious or improper applications, an unauthorized keylogger runs covertly in the background to capture sensitive confidential inputs—such as user credentials, credit card details, and Internet banking passwords—without the user's consent. Thus, **b** is an example of improper use.

**Analysis of other options:**
* **a)** Describes a **Man-in-the-Middle (MitM) attack**, where an adversary intercepts, monitors, or alters communications between two endpoints.
* **c)** Describes a **browser hijacker** or potentially unwanted program (PUP) modifying browser settings.
* **d)** Describes **adware**, which displays unwanted promotional advertisements.

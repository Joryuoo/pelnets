# 2016S_FE_54
Which of the following is a term for the process of generating a Unified Modeling Language (UML) class diagram from a program?

a) Backtracking
b) Forward engineering
c) Re-engineering
d) Reverse engineering
?
d) Reverse engineering
### Explanation
- **Reverse engineering (d)**: The process of analyzing an existing software system (such as source code or compiled binaries) to extract high-level design specifications, software architecture, or models like UML class diagrams. It moves backward from implementation to abstraction.
- **Forward engineering (b)**: The traditional software engineering process of moving from high-level abstract models and specifications to concrete implementation (e.g., generating code from a UML class diagram).
- **Re-engineering (c)**: The examination and alteration of an existing subject system to reconstitute it in a new form and the subsequent implementation of the new form (often combining reverse engineering followed by redesign and forward engineering).
- **Backtracking (a)**: An algorithmic problem-solving approach that explores solution candidates incrementally and abandons ("backtracks") paths that cannot lead to a valid solution.

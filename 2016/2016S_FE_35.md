# 2016S_FE_35
TCP/IP is a layered set of communication protocols consisting of the Network Interface layer, the Internet layer, the Transport layer, and the Application layer. Which of the following is a combination of the Transport layer protocols?

a) DHCP, TCP
b) HTTP, UDP
c) IP, TCP
d) TCP, UDP
?
d) TCP, UDP

### Explanation
The TCP/IP four-layer architecture organizes communication protocols into distinct functional layers:

1. **Application Layer**: Provides network services directly to applications and end users.
   - Examples: **HTTP**, HTTPS, FTP, SMTP, DNS, **DHCP**, SSH.
2. **Transport Layer**: Manages host-to-host end-to-end communication, flow control, and multiplexing via port numbers.
   - **TCP (Transmission Control Protocol)**: Connection-oriented, reliable protocol providing packet sequencing, acknowledgments, and retransmission.
   - **UDP (User Datagram Protocol)**: Connectionless, lightweight protocol without delivery guarantees, used for low-latency traffic (e.g., DNS queries, streaming, VoIP).
3. **Internet Layer**: Handles logical addressing and packet routing across networks.
   - Examples: **IP** (IPv4, IPv6), ICMP, ARP, IGMP.
4. **Network Interface Layer**: Defines physical transmission and hardware-level framing over physical media.
   - Examples: Ethernet, Wi-Fi, PPP.

**Evaluation of choices:**
- **a) DHCP, TCP**: DHCP is Application layer; TCP is Transport layer.
- **b) HTTP, UDP**: HTTP is Application layer; UDP is Transport layer.
- **c) IP, TCP**: IP is Internet layer; TCP is Transport layer.
- **d) TCP, UDP**: Both protocols operate at the Transport layer.

# 2016A_FE_28
In the process of table implementation, which of the following is an appropriate SQL statement that removes a column in an existing table?

a)
ALTER TABLE table_name
DELETE COLUMN column_name

b)
ALTER TABLE table_name
DROP COLUMN column_name

c)
UPDATE TABLE table_name
DELETE COLUMN column_name

d)
UPDATE TABLE table_name
DROP COLUMN column_name
?
b) ALTER TABLE table_name DROP COLUMN column_name
### Explanation
In SQL, commands are divided into functional categories including **DDL** (Data Definition Language) and **DML** (Data Manipulation Language):

- **Modifying Table Structure (DDL):**
  - To alter the structural schema or definition of an existing database table (such as adding, altering, or removing columns and constraints), the standard DDL command is **`ALTER TABLE`**.
  - To remove an existing column, standard SQL specifies the **`DROP COLUMN`** clause:
    ```sql
    ALTER TABLE table_name DROP COLUMN column_name;
    ```
  - Therefore, **b)** is the correct and valid SQL statement.

**Analysis of incorrect options:**
- **a)** Incorrect. SQL does not use `DELETE COLUMN` within an `ALTER TABLE` statement. `DELETE` is a DML operation for records, not schema elements.
- **c)** Incorrect. `UPDATE` is a DML command used to modify data in existing rows (`UPDATE table_name SET ...`), not to modify table structures. Furthermore, `UPDATE TABLE` and `DELETE COLUMN` are invalid SQL syntax.
- **d)** Incorrect. As noted above, `UPDATE` operates on table data, not table definitions. The `DROP COLUMN` clause cannot be used with `UPDATE`.

# 2016A_FE_33
In a TCP/IP environment, which of the following is a standard for attaching image data to an email?

a) JPEG
b) MIME
c) MPEG
d) SMTP
?
b) MIME
### Explanation
* **MIME (Multipurpose Internet Mail Extensions):** An internet standard (RFC 2045–2049) that extends the original email format (RFC 822) to support non-ASCII text, character sets other than US-ASCII, and attachments such as audio, video, images (e.g., JPEG, PNG), and application binary files. It encodes binary content into 7-bit ASCII representations (such as Base64) so it can travel safely over standard SMTP mail systems.
* **JPEG (Joint Photographic Experts Group):** A compression format for photographic still images. It is an image file format, not an email protocol or email attachment standard.
* **MPEG (Moving Picture Experts Group):** A family of standards for lossy compression of video and audio, not an email attachment standard.
* **SMTP (Simple Mail Transfer Protocol):** The standard TCP/IP protocol used for sending and relaying email between mail servers. By default, legacy SMTP only handles plain 7-bit ASCII text and requires MIME to attach binary and image data.

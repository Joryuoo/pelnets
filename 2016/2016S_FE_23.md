# 2016S_FE_23

According to the Open Source Definition by OSI (Open Source Initiative), which of the following is the appropriate description concerning open source licensing?

a) The license allows any party to freely use, modify, and distribute a program. A royalty fee is required only if the program is redistributed commercially.
b) The license allows authors to put usage restrictions on a program to prevent such program from being used in business activities.
c) The license requires that all derivative works must be kept secret if the derivative works are based on an original program.
d) The license requires that the source code of a program must be made available either for free or at a reasonable reproduction cost.
?
d) The license requires that the source code of a program must be made available either for free or at a reasonable reproduction cost.

### Explanation

The **Open Source Definition (OSD)** maintained by the **Open Source Initiative (OSI)** specifies ten key criteria that software licenses must satisfy to be certified as open source:

1. **Free Redistribution:** The license shall not restrict any party from selling or giving away the software. The license shall not require a royalty or fee.
2. **Source Code:** The program must include source code, and must allow distribution in source code as well as compiled form. If not distributed with source code, there must be a well-publicized means of obtaining the source code for no more than a reasonable reproduction cost, preferably downloading via the Internet without charge.
3. **Derived Works:** The license must allow modifications and derived works, and must allow them to be distributed under the same terms as the license of the original software.
4. **Integrity of The Author's Source Code**
5. **No Discrimination Against Persons or Groups**
6. **No Discrimination Against Fields of Endeavor:** The license must not restrict anyone from making use of the program in a specific field of endeavor (e.g., in a business or for commercial research).
7. **Distribution of License**
8. **License Must Not Be Specific to a Product**
9. **License Must Not Restrict Other Software**
10. **License Must Be Technology-Neutral**

---

#### Evaluation of Options:
- **a) is incorrect:** Criterion 1 prohibits requiring any royalty or other fee for redistribution, even commercial redistribution.
- **b) is incorrect:** Criterion 6 forbids restricting software from being used in commercial/business activities.
- **c) is incorrect:** Criterion 3 requires allowing modified and derivative works to be distributed, typically openly (especially in copyleft licenses), not kept secret.
- **d) is correct:** Directly reflects Criterion 2 (Source Code), which requires source code to be made available for free or at a reasonable reproduction cost.

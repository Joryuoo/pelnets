# 2016A_FE_35
In IPv6 networks, what is the length of an IP address in bits?

a) 32
b) 64
c) 128
d) 256
?
c) 128
### Explanation
* **IPv6 (Internet Protocol version 6):** Uses an address length of **128 bits** (16 bytes). This provides an immense address space of $2^{128} \approx 3.4 \times 10^{38}$ unique addresses, effectively solving the address exhaustion limitation of IPv4. An IPv6 address is typically formatted as eight groups of four hexadecimal digits separated by colons (e.g., `2001:0db8:85a3:0000:0000:8a2e:0370:7334`).
* **IPv4 (Internet Protocol version 4):** Uses an address length of **32 bits** (4 bytes), providing $2^{32} \approx 4.3 \times 10^9$ addresses, written in dotted-decimal format (e.g., `192.168.1.1`).

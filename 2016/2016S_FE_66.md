# 2016S_FE_66

Which of the following is an appropriate description of cloud computing?

a) It is a collection of computer resources from multiple locations designed to reach a common goal.
b) It is a field of computer science that studies distributed systems in which components located on networked computers communicate and coordinate their actions by passing messages.
c) It is a model for enabling ubiquitous, convenient, on-demand access to a shared pool of configurable computing resources.
d) It is a service provisioning model in which a service provider makes computing resources and infrastructure management available to the customers as needed and charges them for a specific usage rather than a flat rate.
?
c) It is a model for enabling ubiquitous, convenient, on-demand access to a shared pool of configurable computing resources.

### Explanation

According to the official **NIST (National Institute of Standards and Technology) SP 800-145** definition, **Cloud Computing** is defined as:
> *"A model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction."*

Thus, **Option c** is the exact definition of cloud computing.

### Analysis of Other Options:
- **a) Grid Computing**: Refers to pooling geographically dispersed, heterogeneous computing resources together to work collaboratively on a massive, singular computational problem or common goal.
- **b) Distributed Systems / Distributed Computing**: The broader field of computer science studying software systems whose components reside on networked computers and coordinate via message passing.
- **d) Utility Computing**: The business/billing model where computing resources (processing, storage) are packaged, provided, and billed like traditional public utilities (electricity, water) based on metered consumption rather than a flat rate. While cloud computing utilizes utility pricing, option c provides the comprehensive definition of the computing model itself.

# 2016S_FE_18
Which of the following is the mean time between failures (MTBF) value of the entire system where unit A and unit B are connected in series and both units operate as one system? The MTBF value of unit A and unit B is 200 and 300 hours, respectively.

a) 200
b) 250
c) 300
d) 500
?
b) 250
### Explanation
- **Official Exam Answer:**
  The official PhilNITS answer key marks **b) 250**. The exam author simply took the arithmetic average of the MTBF of unit A and unit B:
  $$\text{Average MTBF} = \frac{\text{MTBF}_A + \text{MTBF}_B}{2} = \frac{200 + 300}{2} = 250\text{ hours}$$

- **Reliability Engineering Note (Exam Typo / Flaw):**
  In formal reliability theory, when two units are configured in series (meaning both must operate for the system to function), the failure rate of the system is the sum of the individual failure rates:
  $$\lambda_{\text{sys}} = \lambda_A + \lambda_B = \frac{1}{200} + \frac{1}{300} = \frac{3 + 2}{600} = \frac{5}{600} = \frac{1}{120}\text{ failures/hour}$$
  Therefore, the theoretical system MTBF should be:
  $$\text{MTBF}_{\text{sys}} = \frac{1}{\lambda_{\text{sys}}} = 120\text{ hours}$$
  Because 120 hours is not an option among the choices provided, the question intended candidates to compute the arithmetic mean $(200 + 300) / 2 = 250$ hours.

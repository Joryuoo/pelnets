# 2016A_FE_6
Binary search is used to search for an element from a sorted data of n elements. Which of the following is an expression that represents the order of computational complexity for this process?

a) log n
b) n
c) n²
d) n log n
?
a) log n
### Explanation
**Binary Search** works on a sorted array by repeatedly dividing the search interval in half.
Because the number of elements left to search is halved at each step ($n, n/2, n/4, \dots, 1$), the maximum number of steps required to find an element is proportional to the base-2 logarithm of $n$. Therefore, its time complexity is $O(\log n)$.

*   $O(n)$ is the complexity of a linear search.
*   $O(n \log n)$ is typical for efficient sorting algorithms like Merge Sort or Quick Sort.
*   $O(n^2)$ is typical for simple nested-loop sorting algorithms like Bubble Sort.

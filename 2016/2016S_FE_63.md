# 2016S_FE_63

When software asset management is audited, which of the following is the most appropriate point to be checked?

a) Checking to see whether compatibility with existing systems is evaluated at the time of installation
b) Checking to see whether evidence, such as a software license certificate, is properly retained
c) Checking to see whether failures are localized through database partitioning or other methods
d) Checking to see whether the organizational and functional structure of the software provider is taken into consideration
?
b) Checking to see whether evidence, such as a software license certificate, is properly retained

### Explanation

**Software Asset Management (SAM)** is a business practice that involves managing and optimizing the purchase, deployment, maintenance, utilization, and disposal of software applications within an organization.

A critical objective of SAM auditing is ensuring **legal compliance** and avoiding intellectual property violations (such as unlicensed software usage, under-licensing penalties, or copyright infringement):
- An auditor checks whether **evidence of ownership and entitlement** (such as software license certificates, purchase receipts, invoices, and license agreements) is properly retained and reconciled with the actual inventory of installed software instances.
- Therefore, **Option b** is the most appropriate checkpoint for auditing software asset management.

### Analysis of Other Options:
- **a) Checking compatibility with existing systems**: This is a technical checkpoint evaluated during the software acquisition/testing/deployment phase, not the ongoing management and auditing of software assets.
- **c) Checking localization of failures through database partitioning**: This is an architectural/fault-tolerance design concern in systems engineering and database administration.
- **d) Checking the organizational and functional structure of the software provider**: This relates to vendor risk assessment during supplier selection, not internal software asset management controls.

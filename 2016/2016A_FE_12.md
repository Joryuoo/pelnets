# 2016A_FE_12
![[2016A_FE_AM_Q12_full.png]]

a) A, B, C, D
b) A, D, B, C
c) C, D, A, B
d) D, C, A, B
?
b) A, D, B, C
### Explanation
The effective memory access time represents the average time required to access data.

- When a cache is **not present**, the effective access time is simply the access time of the main memory:
  $$T_{\text{eff}} = T_{\text{main}}$$

- When a cache is **present**, the effective access time is calculated using the cache hit rate ($h$):
  $$T_{\text{eff}} = (h \times T_{\text{cache}}) + ((1 - h) \times T_{\text{main}})$$
  where:
  - $h$ is the cache hit rate
  - $T_{\text{cache}}$ is the cache access time
  - $1 - h$ is the cache miss rate
  - $T_{\text{main}}$ is the main memory access time

---

#### Calculating Effective Access Time for Each Configuration:

- **A**: No cache
  $$T_{\text{eff}}(A) = 15\text{ ns}$$

- **B**: No cache
  $$T_{\text{eff}}(B) = 30\text{ ns}$$

- **C**: Cache present ($h = 60\% = 0.6$, $T_{\text{cache}} = 20\text{ ns}$, $T_{\text{main}} = 70\text{ ns}$)
  $$T_{\text{eff}}(C) = (0.6 \times 20) + ((1 - 0.6) \times 70)$$
  $$T_{\text{eff}}(C) = 12 + (0.4 \times 70) = 12 + 28 = 40\text{ ns}$$

- **D**: Cache present ($h = 90\% = 0.9$, $T_{\text{cache}} = 10\text{ ns}$, $T_{\text{main}} = 80\text{ ns}$)
  $$T_{\text{eff}}(D) = (0.9 \times 10) + ((1 - 0.9) \times 80)$$
  $$T_{\text{eff}}(D) = 9 + (0.1 \times 80) = 9 + 8 = 17\text{ ns}$$

---

#### Arranging in Order of Shorter Effective Access Time:
$$15\text{ ns (A)} < 17\text{ ns (D)} < 30\text{ ns (B)} < 40\text{ ns (C)}$$

The correct order from shortest to longest access time is **A, D, B, C**.
Therefore, the correct choice is **b) A, D, B, C**.

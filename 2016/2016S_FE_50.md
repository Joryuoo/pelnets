# 2016S_FE_50

In unit testing, which of the following activities is part of “white box testing”?

a) Boundary value analysis
b) Condition testing
c) Equivalence partitioning
d) Orthogonal array testing
?
b) Condition testing

### Explanation

Software testing techniques at the unit testing level are fundamentally categorized into **White-Box Testing** and **Black-Box Testing**:

#### White-Box Testing (Structural Testing)
Tests derive test cases based on an analysis of the internal structure, source code, and control flow of the software component.
- **Statement Coverage / Testing**: Ensuring every line of code/statement is executed at least once.
- **Decision / Branch Coverage**: Ensuring every decision branch (true/false) is traversed.
- **Condition Testing**: Tests each individual logical condition (Boolean sub-expression) within a decision to ensure both true and false outcomes are evaluated. Variations include condition coverage, decision/condition coverage, and Modified Condition/Decision Coverage (MC/DC).
- **Multiple Condition Coverage**: Tests all possible combinations of condition outcomes within each decision.
- **Path Testing**: Testing every independent execution path through the source code.

Therefore, **Condition testing** is a core white-box testing technique (**choice b**).

#### Black-Box Testing (Specification-based Testing)
Tests derive test cases from functional specifications, requirements, or interfaces without looking into internal source code.
- **a) Boundary Value Analysis (BVA)**: Focuses on values at the edges/boundaries of input equivalence classes (e.g., minimum, just above minimum, nominal, just below maximum, maximum).
- **c) Equivalence Partitioning (EP)**: Divides input domain data into partitions of valid and invalid values that are expected to be treated similarly by the program.
- **d) Orthogonal Array Testing (OAT)**: A systematic, statistical technique using orthogonal arrays to design test cases covering pair-wise combinations of multiple input parameters with minimal test cases.

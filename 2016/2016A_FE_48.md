# 2016A_FE_48
![[2016A_FE_AM_Q48_full.png]]

a) 24, 25, 49, 50
b) 24, 25, 50, 51
c) 25, 26, 49, 50
d) 25, 26, 50, 51
?
a) 24, 25, 49, 50
### Explanation
The module executes only when the integer $x$ satisfies the inequality:
$$25 \le x < 50$$

Since $x$ is an integer:
* The set of valid values that satisfy the condition is:
  $$\{25, 26, \dots, 48, 49\}$$

In **Boundary Value Analysis (BVA)**, test values are chosen at the boundaries between valid and invalid partitions:
1. **Lower Boundary:**
   * At the boundary (valid input): $x = 25$
   * Immediately outside the boundary (invalid input): $x = 24$
2. **Upper Boundary:**
   * Since $x < 50$, the maximum valid integer is $x = 49$.
   * At the boundary (valid input): $x = 49$
   * Immediately outside the boundary (invalid input): $x = 50$

Combining the two test values at each boundary gives:
$$\{24, 25, 49, 50\}$$

Therefore, option **a** is the correct combination of boundary values to test.

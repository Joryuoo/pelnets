# 2016A_FE_43
When a digital certificate has been installed in an in-house system accessed from a smartphone by an employee, which of the following can be checked using the in-house system?

a) Ensuring that the applications on the smartphone are the latest versions of the applications
b) Ensuring that the most recent security patch has been applied to the OS of the smartphone
c) Ensuring that the smartphone has been allowed to access the in-house system
d) Ensuring that the smartphone is not infected by a virus
?
c) Ensuring that the smartphone has been allowed to access the in-house system
### Explanation
In client-certificate authentication (e.g., mutual TLS / PKI-based access control), digital certificates are used to verify device or user identity and authorize access:

* When a client digital certificate issued by an organization's internal Certificate Authority (CA) is verified by the in-house server, the server confirms that the device possesses valid, trusted credentials issued to an authorized entity.
* This allows the in-house system to verify and enforce that only **authorized smartphones are permitted to access the in-house system**.

Why the other options are incorrect:
* Digital certificates are strictly cryptographic credentials used for authentication, digital signatures, and encryption. They do not inspect endpoint device health or state.
* Verifying application versions (**a**), operating system patch status (**b**), or virus/malware infection status (**d**) requires Mobile Device Management (MDM), Mobile Application Management (MAM), or Endpoint Detection and Response (EDR) software, not digital certificates.

# 2016A_FE_21
Which of the following is a characteristic of DRAM and not of SRAM?

a) It does not require refresh nor access operations in order to retain data.
b) It has a simple memory cell structure, and thus the price per bit is low.
c) It is mainly used for cache memory
d) It uses flip-flops for the memory cells to save data.
?
b) It has a simple memory cell structure, and thus the price per bit is low.
### Explanation
DRAM (Dynamic Random-Access Memory) and SRAM (Static Random-Access Memory) are two primary semiconductor RAM technologies with distinct characteristics:

- **DRAM (Dynamic RAM):**
  - **Memory Cell Structure:** Each memory cell consists of just one transistor and one capacitor (1T-1C). Because of this minimalistic and simple cell structure, DRAM achieves very high integration density and has a significantly **lower cost/price per bit**.
  - **Data Retention:** The capacitor stores data as an electrical charge, but this charge gradually leaks over time. Therefore, DRAM requires periodic **refresh operations** to rewrite and retain stored data.
  - **Primary Application:** Used as computer **main memory** (system RAM) where high storage capacity at a low cost is essential.

- **SRAM (Static RAM):**
  - **Memory Cell Structure:** Uses a flip-flop circuit consisting of 4 to 6 transistors per memory cell.
  - **Data Retention:** Retains its data statically without any refresh operations as long as electric power is supplied.
  - **Primary Application:** Much faster access times than DRAM, but bulkier cell size and higher cost per bit. It is primarily used for CPU **cache memory** (L1, L2, L3).

**Analysis of the choices:**
- **a)** Incorrect. Retaining data without refresh is a characteristic of **SRAM**, whereas DRAM requires periodic refresh.
- **b)** **Correct.** DRAM has a simple 1T-1C memory cell structure, resulting in higher density and lower price per bit.
- **c)** Incorrect. Being used mainly for cache memory describes **SRAM**; DRAM is used for main memory.
- **d)** Incorrect. Using flip-flops for memory cells describes **SRAM**; DRAM uses a transistor and capacitor.

# 2016S_FE_32
In a relation schema $R = (A, B, C, D, E)$, the following functional dependencies are held:  
$A \rightarrow BC$  
$CD \rightarrow E$  
$B \rightarrow D$  
$E \rightarrow A$  

Which of the following is a combination of two candidate keys for $R$?

a) A and E
b) B and C
c) B and D
d) C and D
?
a) A and E

### Explanation
A **candidate key** is a minimal superkey—a minimal set of attributes whose attribute closure determines all attributes in the relation schema $R = (A, B, C, D, E)$.

Let us compute the attribute closure for the given attributes:

1. **Closure of $A$ ($A^+$):**
   - Initial set: $\{A\}$
   - From $A \rightarrow BC$, add $B$ and $C$: $\{A, B, C\}$
   - From $B \rightarrow D$, add $D$: $\{A, B, C, D\}$
   - From $CD \rightarrow E$, add $E$: $\{A, B, C, D, E\}$
   - Since $A^+ = \{A, B, C, D, E\}$, **$A$ is a candidate key**.

2. **Closure of $E$ ($E^+$):**
   - Initial set: $\{E\}$
   - From $E \rightarrow A$, add $A$: $\{A, E\}$
   - From $A \rightarrow BC$, add $B$ and $C$: $\{A, B, C, E\}$
   - From $B \rightarrow D$, add $D$: $\{A, B, C, D, E\}$
   - Since $E^+ = \{A, B, C, D, E\}$, **$E$ is a candidate key**.

3. **Checking the other attributes:**
   - $B^+ = \{B, D\}$ (cannot determine $A, C, E$)
   - $C^+ = \{C\}$ (cannot determine $A, B, D, E$)
   - $D^+ = \{D\}$ (cannot determine $A, B, C, E$)

None of $B$, $C$, or $D$ individually is a candidate key. Therefore, **$A$ and $E$** are both valid candidate keys for $R$.

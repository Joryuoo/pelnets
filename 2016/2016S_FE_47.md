# 2016S_FE_47

Which of the following is an explanation of the pattern-matching method used by antivirus software?

a) A virus is detected by collating information with the checksum of a file.
b) A virus is detected by comparing a file before and after infection, and examining whether any change has been made to the file.
c) A virus is detected by monitoring an abnormal phenomenon that is caused by a virus in a system.
d) A virus is detected through comparison with the signature of an already-known virus.
?
d) A virus is detected through comparison with the signature of an already-known virus.

### Explanation

Antivirus software employs several distinct detection methods:

1. **Pattern-Matching Method (Signature-based Detection)**:
   - Antivirus vendors extract a unique sequence of bytes or instructions characteristic of a known virus, called a **signature** or **definition pattern**.
   - During a scan, the antivirus inspects files and compares their binary content against a database of known signatures. If a match is found, the file is identified as infected.
   - This method is highly accurate with extremely low false positives for known threats, but cannot detect zero-day or heavily obfuscated/polymorphic malware until a signature is created.

2. **Integrity Checking (Checksum Method)**:
   - Computes and records cryptographic hashes or checksums of clean system files. Later scans recalculate the checksum to detect unauthorized modifications.

3. **Heuristic / Behavioral Monitoring**:
   - Analyzes code logic for suspicious characteristics (heuristic) or monitors system behavior in real time (e.g., unexpected modification of system registry, attempt to inject code into other processes) to detect unknown viruses.

### Option Analysis
- **a)** Detecting viruses by comparing file checksums is known as **integrity checking**.
- **b)** Comparing files before and after modifications is also part of **file integrity monitoring (FIM)** or change detection.
- **c)** Monitoring system phenomena and abnormal behavior at runtime is **behavioral monitoring** or **heuristic analysis**.
- **d)** **Correct**. Pattern-matching works by comparing files with a database of known virus signatures.

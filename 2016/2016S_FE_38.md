# 2016S_FE_38
On the Internet, sometimes when one tries to load a Web page by specifying a URL like http://www.jitec.ipa.go.jp/, the page does not show up and an error page is shown instead. However, one can browse this page correctly by specifying its IP address like this: http://118.151.146.137/. Which of the following TCP/IP layer is responsible for this problem?

a) Application layer
b) Internet layer
c) Network Interface layer
d) Transport layer
?
a) Application layer

### Explanation
When browsing via direct IP address (`http://118.151.146.137/`) succeeds, it confirms that:
- Physical and frame delivery (**Network Interface layer**) is functional.
- IP routing and packet forwarding (**Internet layer**) is functional.
- Port-level connection and TCP session establishment (**Transport layer**) is functional.

The failure only occurs when resolving the host name (`www.jitec.ipa.go.jp`) into its corresponding IP address. Name resolution is performed by **DNS (Domain Name System)**. 

In the TCP/IP model, **DNS** operates as an **Application layer** protocol (running over UDP/TCP port 53). Therefore, the failure to resolve the URL is an issue occurring at the **Application layer** (such as misconfigured DNS server settings, unreachable DNS server, or DNS cache corruption).

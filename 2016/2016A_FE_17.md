# 2016A_FE_17
Which of the following is an appropriate explanation of spooling?

a) It determines the execution order for jobs that are loaded into a system according to characteristics and priority.
b) It sends communication data to a pre-registered agent instead of sending it directly to a counterpart.
c) It temporarily saves input data from a keyboard to the queue in the main memory.
d) It temporarily saves output data for a low-speed device, such as a printer, to a high-speed hard disk, and then sends it to the intended device.
?
d) It temporarily saves output data for a low-speed device, such as a printer, to a high-speed hard disk, and then sends it to the intended device.
### Explanation
**Spooling** stands for **Simultaneous Peripheral Operations On-Line**.

- In early computer architectures, high-speed CPUs were often severely bottlenecked if they had to write data directly to slow peripheral devices (such as line printers or card punches).
- To prevent programs and the CPU from idling while waiting for slow mechanical devices:
  1. The operating system intercepts output requests and rapidly writes the data to an intermediate high-speed auxiliary storage device (such as a hard disk drive or SSD), known as the **spool file** or **print queue**.
  2. The application is freed immediately to continue processing other tasks.
  3. A separate background process or print daemon feeds the spooled data to the printer at the printer's own operating speed.

---

#### Evaluation of Choices:
- **a) It determines the execution order for jobs that are loaded into a system according to characteristics and priority.**
  - *Incorrect.* This describes **job scheduling** (or CPU scheduling algorithms like priority scheduling).
- **b) It sends communication data to a pre-registered agent instead of sending it directly to a counterpart.**
  - *Incorrect.* This describes a **proxy server**, **message broker**, or **store-and-forward routing agent**.
- **c) It temporarily saves input data from a keyboard to the queue in the main memory.**
  - *Incorrect.* This describes **input buffering** or an OS **keyboard buffer** (usually held in RAM queues).
- **d) It temporarily saves output data for a low-speed device, such as a printer, to a high-speed hard disk, and then sends it to the intended device.**
  - *Correct.* This is the exact definition and function of spooling.

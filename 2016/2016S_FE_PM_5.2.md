### Explanation

**Subquestion 2:**
* **C (a):** The planned network configures global IP addresses `203.0.113.240/29`. A `/29` subnet provides $2^3 = 8$ total addresses. Subtracting the network address and broadcast address leaves 6 usable host addresses. The ADSL modem and the Layer-3 switch will use one global IP address each, taking up 2 addresses. The remaining addresses available for the external-use servers is $6 - 2 = 4$.
* **D (c):** WPA2-Personal (WPA2-PSK) relies on a shared pass-phrase for authentication. Because the same pass-phrase is given to all authorized users, the primary security risk is the leakage of this pass-phrase.
* **E (d):** WPA2-Enterprise provides enterprise-grade authentication and requires a dedicated backend authentication server. RADIUS (Remote Authentication Dial-In User Service) is the standard protocol used for this purpose.

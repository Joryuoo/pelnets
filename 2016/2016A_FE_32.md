# 2016A_FE_32
Which of the following is an appropriate description of network devices?

a) A bridge relays frames based on IP addresses.
b) A gateway converts protocols of the first through the third layers of the OSI basic reference model.
c) A repeater extends transmission distances by amplifying signals between the segments of the same type.
d) A router relays frames based on MAC addresses.
?
c) A repeater extends transmission distances by amplifying signals between the segments of the same type.
### Explanation
Network devices operate at different layers of the OSI reference model:

* **Repeater (Layer 1 - Physical Layer):** Receives weak or degraded electrical or optical signals from one network segment, regenerates and amplifies them, and retransmits them to another segment of the same type. This allows network cabling distances to be extended beyond physical limitations. Thus, **c** is correct.
* **Bridge (Layer 2 - Data Link Layer):** Connects network segments and filters/relays data frames based on **MAC addresses**, not IP addresses. (Option a is incorrect).
* **Router (Layer 3 - Network Layer):** Determines the best path and forwards packets across interconnected networks based on logical **IP addresses**, not MAC addresses. (Option d is incorrect).
* **Gateway (Layer 4 to Layer 7 - Transport to Application Layers):** Acts as a protocol converter between networks using completely different protocols (e.g., converting between different network architectures or application protocols), typically operating above Layer 3. (Option b is incorrect).

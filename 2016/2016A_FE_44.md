# 2016A_FE_44
Which of the following is a technique where a system is actually attacked and an intrusion attempt is made in order to detect security-related vulnerabilities of a computer or network?

a) Penetration test
b) Regression test
c) Software inspection
d) Walk-through
?
a) Penetration test
### Explanation
* **Penetration test (pen testing)** is an authorized simulated cyberattack against a computer system, application, or network infrastructure. Security professionals (ethical hackers) mimic the techniques of real-world adversaries to actively identify and exploit vulnerabilities, assessing the actual risk of unauthorized access or breach.

Why the other options are incorrect:
* **b) Regression test:** Software testing conducted after modifications, bug fixes, or enhancements to confirm that existing functionality continues to operate correctly without introducing new defects.
* **c) Software inspection:** A formal peer-review process where software artifacts (source code, requirements, or architecture documents) are systematically examined by a review team using predefined checklists to uncover defects.
* **d) Walk-through:** An informal static analysis review led by the author of the work product, stepping through documents or code with team members to gather feedback and achieve consensus.

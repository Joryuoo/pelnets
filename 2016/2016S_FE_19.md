# 2016S_FE_19
When the multiplicity of processing is increased in the virtual memory of a computer system, page-in and page-out operations occur very frequently, and the response speed of the system decreases suddenly. What is this phenomenon called?

a) Memory compaction
b) Overlay
c) Roll-out
d) Thrashing
?
d) Thrashing
### Explanation
- **Thrashing:** In a virtual memory system, thrashing occurs when the multiprogramming degree (multiplicity of processing) is increased to the point where the sum of the working sets of all active processes exceeds available physical memory frames. As processes continuously fault on missing pages, the system spends the vast majority of its operational time performing page-in and page-out swaps between main memory and secondary storage rather than executing application code. This causes CPU utilization and system responsiveness to drop sharply.
- **Memory compaction:** Reallocating loaded memory segments to consolidate non-contiguous free spaces into a single larger block, thereby reducing external fragmentation.
- **Overlay:** A memory management technique used when a program is larger than physical memory, allowing independent code segments to share the same physical memory space by replacing each other sequentially.
- **Roll-out (Swapping):** Moving an entire inactive process or large memory segments from RAM to secondary storage to free resources for active processes.

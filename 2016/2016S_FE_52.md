# 2016S_FE_52
The integration test for a software that is composed of a set of modules arranged in a hierarchical structure is performed from a low-level module. In such a case, which of the following is a test module used as a substitute for a higher level module?

a) Driver
b) Emulator
c) Simulator
d) Stub
?
a) Driver
### Explanation
In hierarchical integration testing:
- **Bottom-up integration testing**: Testing begins with the lowest-level modules. Since the higher-level calling modules have not yet been developed or integrated, a dummy calling module known as a **Driver** (or test driver) is required to invoke the lower-level module, pass test parameters, and receive/verify test outputs.
- **Top-down integration testing**: Testing begins with the top-level module. Dummy called modules known as **Stubs** are required to simulate lower-level modules that are called by the upper modules.

Other choices:
- **Emulator (b)**: Hardware or software that enables one computer system to behave exactly like another computer system (replicating both internal architecture and external behavior).
- **Simulator (c)**: A program that models and mimics real-world behavior or system responses, typically without replicating internal hardware states.
- **Stub (d)**: Used in top-down integration testing as a substitute for lower-level modules.

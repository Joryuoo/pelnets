# 2016A_FE_31
In a CSMA/CD based LAN, which of the following is an appropriate description of the transmission operation performed by a network node?

a) All nodes are connected in a ring topology, and a special frame is sent around to control the transmission right. Only the node that receives the special frame can transmit data.
b) Each node checks if the transmission medium is in use, and can transmit data if the medium is not in use. If a conflict is detected, a retransmission occurs after a random interval of time.
c) Each node is assigned a logical priority, and a transmission right is passed along in the order of priority. Only the node with the right can transmit data.
d) Only the node that has been assigned a time slot for transmission can transmit data.
?
b) Each node checks if the transmission medium is in use, and can transmit data if the medium is not in use. If a conflict is detected, a retransmission occurs after a random interval of time.
### Explanation
**CSMA/CD (Carrier Sense Multiple Access with Collision Detection)** is a media access control method historically used in Ethernet networks (IEEE 802.3):

* **Carrier Sense (CS):** A node listens to the shared transmission medium to check if any other node is currently transmitting. If the line is idle, it begins transmitting.
* **Multiple Access (MA):** Multiple nodes share the same physical channel.
* **Collision Detection (CD):** If two nodes transmit simultaneously, their signals collide on the wire. Both nodes detect this collision, abort their transmissions immediately, send a jam signal to ensure all nodes detect the collision, and wait for a pseudo-random backoff period (calculated via the truncated binary exponential backoff algorithm) before re-attempting transmission.

**Analysis of other options:**
* **a)** Describes **Token Ring** (IEEE 802.5), where a special frame called a token circulates in a ring topology.
* **c)** Describes a priority-driven or token-passing bus scheme (e.g., IEEE 802.4 Token Bus).
* **d)** Describes **TDMA (Time Division Multiple Access)**, where bandwidth is divided into pre-assigned time slots.

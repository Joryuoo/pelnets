# 2016S_FE_46

Which of the following is a purpose of using a WAF (Web Application Firewall)?

a) An attack on a vulnerability attributed to a Web server and a Web application is blocked.
b) The entry of a worm into a Web server is detected, and the worm is automatically exterminated.
c) The security hole of a Web server is identified, and an OS security patch is applied.
d) The vulnerabilities and inconsistencies of a Web application are detected during the integration test of content development of the Web server.
?
a) An attack on a vulnerability attributed to a Web server and a Web application is blocked.

### Explanation

A **Web Application Firewall (WAF)** is a specialized security device or software filter that operates at **Layer 7 (Application Layer)** of the OSI model.

Unlike traditional network firewalls (which inspect IP addresses and port numbers at Layers 3 and 4), a WAF inspects the actual payload and parameters of HTTP and HTTPS requests and responses. Its primary purpose is to detect and block attacks targeting vulnerabilities in Web servers and Web applications.

Common threats mitigated by a WAF include:
- **SQL Injection (SQLi)**
- **Cross-Site Scripting (XSS)**
- **Cross-Site Request Forgery (CSRF)**
- **Remote / Local File Inclusion (RFI / LFI)**
- **OS Command Injection**
- **Path / Directory Traversal**

### Option Analysis
- **a)** **Correct**. A WAF analyzes incoming web traffic in real time to block malicious requests exploiting web application and web server vulnerabilities.
- **b)** Detecting and exterminating worms/malware residing on the server is the function of an **antivirus / anti-malware** or endpoint detection and response (EDR) system.
- **c)** Identifying security holes and applying OS patches is handled by **vulnerability scanners** and **patch management systems** (e.g., WSUS, apt/yum update tools).
- **d)** Detecting bugs and vulnerabilities during testing and development is the role of **SAST (Static Application Security Testing)**, **DAST (Dynamic Application Security Testing)**, and software testing tools, not a runtime operational firewall like a WAF.

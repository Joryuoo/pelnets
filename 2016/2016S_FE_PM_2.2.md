### Explanation

**Subquestion 2:**
*   **Blank C (b):** We need to identify the missing output values in the Karnaugh map (Table 5) for the condition `IB = 0` and the corresponding `II, IT` combinations of `1, 1` and `1, 0`.
    *   The truth table (Table 4) determines that the output is 1 when the simultaneous power consumption exceeds 2,000W.
    *   For `IB = 0` (Boiler off), `II = 1` (Iron on, 1500W), and `IT = 1` (TV on, 600W), the total power is `1500W + 600W = 2100W`. Since 2100W > 2000W, the output is `1`.
    *   For `IB = 0` (Boiler off), `II = 1` (Iron on, 1500W), and `IT = 0` (TV off, 0W), the total power is 1500W. Since 1500W < 2000W, the output is `0`.
    *   Therefore, the missing values for `1, 1` and `1, 0` are `1` and `0` respectively. This corresponds to option **b**.

*   **Blank D (c):** We need to derive the logic expression for the remaining group in the Karnaugh map.
    *   The Karnaugh map has three cells with an output of 1: `(IB=0, II=1, IT=1)`, `(IB=1, II=1, IT=1)`, and `(IB=1, II=1, IT=0)`.
    *   The problem states these are grouped into a set of two adjacent cells and a single cell.
    *   The single cell is `(IB=1, II=1, IT=0)`, which correctly translates to the provided term `( IB • II • ¬IT )`.
    *   The set of two adjacent cells contains `(IB=0, II=1, IT=1)` and `(IB=1, II=1, IT=1)`. Since `IB` transitions between 0 and 1 while `II` and `IT` remain constant at 1, `IB` is eliminated.
    *   This leaves the logic expression for this set as `( II • IT )`.
    *   This matches option **c**.

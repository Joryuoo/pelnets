# 2016A_FE_37
In a meeting session, the security administrator provides a presentation regarding risks on social media and recommends that the attendees not give unnecessary personal information on social media websites. From which of the following attacks do the social media users effectively reduce the security risk most by following this recommendation?

a) Brute-force attack
b) Cognitive password attack
c) DoS (Denial of Service) attack
d) Phishing attack
?
b) Cognitive password attack
### Explanation
* **Cognitive password attack (Knowledge-based authentication attack):** An attack technique where an unauthorized party attempts to bypass password authentication or reset a user's password by guessing the answers to "security questions" (e.g., "What is the name of your first pet?", "Where were you born?", "What was your high school?", "What is your mother's maiden name?").
* Attackers often obtain this personal information from public posts, profiles, and quizzes on social media websites. By refraining from posting unnecessary personal information on social media, users directly starve attackers of the answers needed to compromise these security questions, thereby reducing the risk of a cognitive password attack most effectively.

**Analysis of other options:**
* **a) Brute-force attack:** Involves systematically guessing password combinations using automated tools. It relies on computational speed rather than biographical clues posted online.
* **c) DoS (Denial of Service) attack:** An attack designed to render a server or network unavailable by overwhelming it with illegitimate traffic.
* **d) Phishing attack:** An attack where deceptive communications trick individuals into clicking malicious links or giving up credentials. While personal information can help craft targeted phishing (spear phishing) emails, the primary defense against phishing is email filtering and vigilant inspection of links and senders, whereas withholding personal information directly neutralizes cognitive password guessing.

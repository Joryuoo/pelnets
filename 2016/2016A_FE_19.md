# 2016A_FE_19
There is a system in which the print requests waiting for output are assigned to an available printer in an order of A, B, and C, and then the printer available first among the three (3) printers A through C of the same model. If the print time of each print request is 5, 12, 4, 3, 10, and 4 (minutes) in the order of the requests waiting for output, which of the following lists of printers is arranged in an order starting from the longest time assigned for printing? Here, all printers are available in the initial state.

a) A, B, C
b) B, A, C
c) B, C, A
d) C, B, A
?
a) A, B, C
### Explanation
Three identical printers ($A, B, C$) process print jobs.
- **Assignment rule:** An available printer is selected in the order of preference $A \rightarrow B \rightarrow C$. After the initial assignments, a waiting job is dispatched to whichever printer becomes available first.
- **Initial state:** All printers are free at time $t = 0$.
- **Job queue:** $J_1 = 5\text{ min}$, $J_2 = 12\text{ min}$, $J_3 = 4\text{ min}$, $J_4 = 3\text{ min}$, $J_5 = 10\text{ min}$, $J_6 = 4\text{ min}$.

---

#### Step-by-Step Assignment Simulation:

1. **At $t = 0$:** All three printers are available.
   - Assign $J_1$ ($5\text{ min}$) to **Printer A** $\rightarrow$ busy until $t = 5$.
   - Assign $J_2$ ($12\text{ min}$) to **Printer B** $\rightarrow$ busy until $t = 12$.
   - Assign $J_3$ ($4\text{ min}$) to **Printer C** $\rightarrow$ busy until $t = 4$.

2. **At $t = 4$:** **Printer C** finishes $J_3$ and becomes available first.
   - Assign $J_4$ ($3\text{ min}$) to **Printer C** $\rightarrow$ busy until $t = 4 + 3 = 7$.

3. **At $t = 5$:** **Printer A** finishes $J_1$ and becomes available next.
   - Assign $J_5$ ($10\text{ min}$) to **Printer A** $\rightarrow$ busy until $t = 5 + 10 = 15$.

4. **At $t = 7$:** **Printer C** finishes $J_4$ and becomes available next.
   - Assign $J_6$ ($4\text{ min}$) to **Printer C** $\rightarrow$ busy until $t = 7 + 4 = 11$.

All 6 print requests have been assigned.

---

#### Total Assigned Printing Time per Printer:

- **Printer A:**
  $$5\text{ min } (J_1) + 10\text{ min } (J_5) = 15\text{ minutes}$$

- **Printer B:**
  $$12\text{ min } (J_2) = 12\text{ minutes}$$

- **Printer C:**
  $$4\text{ min } (J_3) + 3\text{ min } (J_4) + 4\text{ min } (J_6) = 11\text{ minutes}$$

*(Verification: $15 + 12 + 11 = 38\text{ minutes}$, which equals the sum of all print times: $5 + 12 + 4 + 3 + 10 + 4 = 38\text{ minutes}$.)*

---

#### Ordering from Longest to Shortest Time:
$$\text{Printer A } (15\text{ min}) > \text{Printer B } (12\text{ min}) > \text{Printer C } (11\text{ min})$$

The correct order is **A, B, C**.
Therefore, the correct choice is **a) A, B, C**.

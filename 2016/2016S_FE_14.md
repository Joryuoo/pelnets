# 2016S_FE_14
Which of the following is used to translate a logical address generated by a CPU into a physical address?

a) Direct Memory Access Controller (DMAC)
b) Memory Address Register (MAR)
c) Memory Management Unit (MMU)
d) Translation Lookaside Buffer (TLB)
?
c) Memory Management Unit (MMU)
### Explanation
- **Memory Management Unit (MMU):** The hardware component responsible for translating virtual (logical) memory addresses generated by the CPU into physical addresses in system RAM. The MMU also enforces memory protection and access rights across processes.
- **Direct Memory Access Controller (DMAC):** Manages direct data transfer between input/output peripherals and main memory without continuous CPU intervention.
- **Memory Address Register (MAR):** A CPU internal register that holds the physical address on the memory bus during read or write operations.
- **Translation Lookaside Buffer (TLB):** A fast hardware cache *inside* the MMU used to store recently resolved page translations to accelerate address translation. However, the comprehensive hardware functional unit that performs the address translation is the MMU.

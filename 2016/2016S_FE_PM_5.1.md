### Explanation

**Subquestion 1:**
* **A (a):** The internal network uses the IP address block `192.168.1.0/24`. In a `/24` subnet, the first address is reserved for the network address, which is `192.168.1.0`.
* **B (b):** A `/24` subnet provides $2^8 = 256$ total addresses. Subtracting the network address and the broadcast address (`.255`) leaves 254 usable host addresses. The ADSL modem uses `192.168.1.1` and the wireless access point uses `192.168.1.2`, taking up 2 addresses. The remaining maximum local IP addresses for PCs and laptops is $254 - 2 = 252$.

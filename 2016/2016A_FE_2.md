# 2016A_FE_2
When 4-bit signed numbers in 2's complement are used, which of the following operations will cause either an overflow or an underflow?

a) Add B to A when A is 0110 and B is 1111.
b) Add B to A when A is 1110 and B is 0110.
c) Subtract B from A when A is 0111 and B is 1010.
d) Subtract B from A when A is 1111 and B is 1111.
?
c) Subtract B from A when A is 0111 and B is 1010.
### Explanation
In 4-bit 2's complement, the range of representable decimal values is from -8 (`1000`) to +7 (`0111`).
Let's evaluate each option by converting the 4-bit numbers to decimal:

*   **a)** A = `0110` (+6), B = `1111` (-1). 6 + (-1) = +5 (`0101`). Within range. No overflow.
*   **b)** A = `1110` (-2), B = `0110` (+6). -2 + 6 = +4 (`0100`). Within range. No overflow.
*   **c)** A = `0111` (+7), B = `1010` (-6). 7 - (-6) = +13. The value +13 exceeds the maximum positive value (+7), causing an **overflow**.
*   **d)** A = `1111` (-1), B = `1111` (-1). -1 - (-1) = 0 (`0000`). Within range. No overflow.

# 2016S_FE_20
A company performs a full backup every Sunday night and differential backups every night other than Sunday night. If the failure occurs on Wednesday morning, which of the following backups is least needed to restore the system?

a) The latest differential backups from Tuesday.
b) The latest full and the latest differential backups from both Monday and Tuesday.
c) The latest full and the latest differential backups from Tuesday.
d) The latest full backups from Sunday.
?
c) The latest full and the latest differential backups from Tuesday.
### Explanation
- **Understanding Backup Types:**
  - **Full backup:** Copies the entire dataset (executed on Sunday night).
  - **Differential backup:** Copies all files and blocks that have changed *since the last full backup*.
  - Monday night's differential backup contains changes made during Monday.
  - Tuesday night's differential backup contains all changes made on both Monday and Tuesday.

- **System Restoration on Wednesday Morning:**
  To completely restore the system up to the point of the Tuesday night backup:
  1. Restore the **full backup from Sunday night**.
  2. Restore the **latest differential backup from Tuesday night**.
  Monday night's differential backup is completely redundant because all changes made on Monday are already encompassed within Tuesday's differential backup.

- **Exam Phrasing and Translation Context:**
  The phrase *"least needed to restore the system"* is a direct Japanese-to-English translation artifact of *"最低限必要なバックアップ"* (literally: *"the minimum backups necessary"* / *"at least needed"* to restore the system). 
  The minimal set of backups required to successfully restore the system is **the latest full backup (Sunday) and the latest differential backup (Tuesday)**, which corresponds exactly to choice **c**.

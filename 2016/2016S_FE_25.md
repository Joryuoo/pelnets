# 2016S_FE_25

Which of the following is a sequential circuit that has two (2) stable states?

a) Adder circuit
b) Flip-flop
c) NAND gate
d) NOR gate
?
b) Flip-flop

### Explanation

Logic circuits in digital electronics are broadly divided into two major classes:

1. **Combinational Circuits:**
   - The output depends **only on the current inputs** at any given moment.
   - They contain no memory elements and have no internal feedback loops to store state.
   - Examples include logic gates (AND, OR, NAND, NOR, XOR), multiplexers, decoders, encoders, and **adder circuits** (half-adder, full-adder).

2. **Sequential Circuits:**
   - The output depends **both on the current inputs and on the previous state** (history of inputs).
   - They contain memory elements to store binary information.
   - A **flip-flop** (also called a **bistable multivibrator**) is a fundamental sequential circuit that possesses exactly **two stable states** (logic 0 and logic 1). It remains in one of these states indefinitely until an external trigger (clock pulse or control signal) changes it. Flip-flops form the basic building block of registers, SRAM, and counters.

---

#### Option Breakdown:
- **a) Adder circuit:** A combinational circuit used to perform binary addition; it has no memory or stable states.
- **b) Flip-flop:** A sequential circuit with two stable states (bistable) used to store one bit of information. (**Correct**)
- **c) NAND gate:** A basic combinational logic gate.
- **d) NOR gate:** A basic combinational logic gate.

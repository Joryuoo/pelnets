# 2016A_FE_8
Which of the following best describes the characteristics of XML?

a) The style languages such as XSL and CSS used in HTML can also be used in XML.
b) XML allows a tag to be defined in order for an easier data exchange between information systems over the network.
c) XML is developed on its own specification, whereas HTML is on the SGML basis.
d) XML is HTML based and has some features added primarily for a performance improvement of displaying a web page.
?
b) XML allows a tag to be defined in order for an easier data exchange between information systems over the network.
### Explanation
**XML (eXtensible Markup Language)** is a meta-language that allows users to define their own custom tags to structure data. Its primary purpose is not displaying data, but rather storing and transporting data, making it highly suitable for data exchange between heterogeneous information systems over networks.

*   **a is incorrect:** XSL (eXtensible Stylesheet Language) is designed specifically for XML, but CSS is natively HTML-centric (though it can theoretically style XML, XSL is the standard for XML transformation).
*   **c is incorrect:** XML is actually a simplified subset of SGML, just like HTML was originally based on SGML.
*   **d is incorrect:** XML is not based on HTML and is not intended for performance improvements in web display; it is intended for structuring data.

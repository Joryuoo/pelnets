# 2016S_FE_12
Which of the following is the computer architecture where a processor executes the same instruction on multiple data?

a) MIMD
b) MISD
c) SIMD
d) SISD
?
c) SIMD
### Explanation
According to Flynn's taxonomy of computer architectures:
- **SIMD (Single Instruction, Multiple Data):** A single instruction stream is broadcast to multiple execution units, which execute the identical operation synchronously on distinct data elements. Common examples include vector processors and GPUs.
- **SISD (Single Instruction, Single Data):** A sequential uniprocessor architecture where a single instruction stream operates on one data stream at a time.
- **MISD (Multiple Instruction, Single Data):** Multiple instruction streams operate simultaneously on a single shared data stream. This architecture is rare and primarily used in specialized fault-tolerant systems with redundant processing.
- **MIMD (Multiple Instruction, Multiple Data):** Multiple independent processors execute different instruction streams concurrently on different data streams (e.g., modern multi-core processors, symmetric multiprocessing systems, and distributed clusters).

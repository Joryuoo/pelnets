# 2016S_FE_36
Which of the following is responsible for converting a domain name to a corresponding IP address?

a) DHCP server
b) DNS server
c) IMAP server
d) SMTP server
?
b) DNS server

### Explanation
The **DNS (Domain Name System) server** is responsible for **name resolution**—translating human-readable domain names (such as `www.jitec.ipa.go.jp`) into computer-routable numerical IP addresses (such as `118.151.146.137`) that routers and computers use to identify and route packets over the Internet.

**Analysis of incorrect options:**
- **a) DHCP (Dynamic Host Configuration Protocol) server**: Automatically assigns IP addresses, default gateways, subnet masks, and DNS server settings to client hosts joining a local network.
- **c) IMAP (Internet Message Access Protocol) server**: An email server protocol that allows client software to access and manage email messages stored on a remote server.
- **d) SMTP (Simple Mail Transfer Protocol) server**: A mail server protocol used for sending and forwarding outbound emails between email clients and mail servers.

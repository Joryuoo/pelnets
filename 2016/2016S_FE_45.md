# 2016S_FE_45

There is a network that is divided into three (3) segments, namely, an external segment, a demilitarized zone (DMZ), and an internal network by one (1) firewall. In the network, when a service for users is published on the Internet by using a system consisting of a Web server and a database (DB) server containing critical data, which of the following is the most appropriate method of server installation for protecting important data from unauthorized access from the Internet? Here, only a specific protocol is allowed for communication between the external segment and the DMZ, and between the DMZ and the internal network by the firewall, and communication between the external segment and the internal network is not allowed.

a) The Web server and the DB server are installed in an internal network.
b) The Web server and the DB server are installed in the DMZ.
c) The Web server is installed in an external segment, and the DB server is installed in the DMZ.
d) The Web server is installed in the DMZ, and the DB server is installed in an internal network.
?
d) The Web server is installed in the DMZ, and the DB server is installed in an internal network.

### Explanation

In multi-tier network security architectures:
- **External Segment (Internet)**: Completely untrusted public zone.
- **Demilitarized Zone (DMZ)**: A perimeter buffer zone containing public-facing servers (such as Web, Mail, or DNS servers) that must accept incoming connections from the Internet.
- **Internal Network (LAN)**: The trusted internal zone containing company workstations, private application backends, and critical database (DB) servers.

#### Best Security Practice for Server Placement
1. **Web Server**: Must be accessible by general users across the Internet via HTTP/HTTPS (ports 80/443), so it must be placed in the **DMZ**.
2. **Database (DB) Server**: Contains critical, proprietary data and must **never** be directly exposed or accessible from the outside. Placing the DB server in the **internal network** ensures that only authorized requests originating from the Web server in the DMZ (via dedicated database protocols/ports like SQL over port 3306 or 5432) can communicate with it. Direct communication between the Internet and the internal network remains strictly blocked by the firewall.

Even if the Web server is compromised, the attacker does not have direct access to the DB server, and network access controls restrict further lateral movement into the internal network.

### Option Analysis
- **a)** Installing the Web server in the internal network would require opening firewall holes from the Internet directly into the internal network, compromising the security of all internal systems.
- **b)** Installing both servers in the DMZ exposes the DB server directly to the DMZ perimeter, creating a severe risk of database breach if any service in the DMZ is compromised.
- **c)** Placing the Web server in the external segment leaves it completely exposed without firewall protection.
- **d)** **Correct**. Web server in the DMZ, DB server in the internal network is the industry-standard secure multi-tier deployment.

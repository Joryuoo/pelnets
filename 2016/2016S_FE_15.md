# 2016S_FE_15
Which of the following is an appropriate description concerning cache memory?

a) In a multi-tasking environment, a cache memory maintains data from each task to improve performance.
b) Multiprocessors where each has a cache memory need to synchronize values within the cache to maintain coherency.
c) The operating system manages the data transfer between registers and a cache memory.
d) The speed and size of a cache memory are the only consideration when improving performance.
?
b) Multiprocessors where each has a cache memory need to synchronize values within the cache to maintain coherency.
### Explanation
- **b) is correct:** In multiprocessor and multi-core systems where individual processors maintain their own private caches (such as L1 or L2 caches), duplicate copies of identical memory blocks can exist across caches. When a processor modifies data in its local cache, cache coherency protocols (e.g., MESI, MOESI) or hardware bus-snooping mechanisms must synchronize or invalidate the other caches to ensure data consistency across the entire system.
- **a) is incorrect:** Cache memory does not segregate data dedicated per task; cache entries are loaded dynamically based on spatial and temporal locality of memory addresses, and data from any task can be evicted by cache replacement logic.
- **c) is incorrect:** Data movement between registers and cache memory is entirely handled by hardware control logic (CPU instruction execution pipeline and cache controllers), not by operating system software.
- **d) is incorrect:** Cache design involves several critical architectural factors beyond speed and capacity, including cache associativity (direct-mapped vs. set-associative vs. fully associative), cache line/block size, replacement policies (e.g., LRU, FIFO), and write policies (write-through vs. write-back).

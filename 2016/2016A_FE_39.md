# 2016A_FE_39
Which of the following is an appropriate combination of the usage method of a signature key in a digital signature, and the purpose of a digital signature?

a) By the sender creating a digital signature with the signature key and attaching it to a message, the recipient can confirm the identity of the sender.
b) By the sender encrypting a message to which a fixed string is added with the signature key, the recipient can identify sections that have been falsified.
c) By the sender encrypting a message with the signature key, the content of the message cannot be understood by unrelated parties.
d) The recipient can use the signature key to decrypt an encrypted message to the plain text message.
?
a) By the sender creating a digital signature with the signature key and attaching it to a message, the recipient can confirm the identity of the sender.
### Explanation
In asymmetric public-key cryptography:
* **Signature Key (Sender's Private Key):** Exclusively held by the sender. The sender computes a cryptographic hash (digest) of the message, encrypts this digest using their private signature key to generate the **digital signature**, and attaches the signature to the message.
* **Verification Key (Sender's Public Key):** Made publicly available. The recipient decrypts the signature using the sender's public key and compares the result with the independently calculated hash of the received message.
* **Key Purposes of a Digital Signature:**
  1. **Authentication (Identity Confirmation):** Because only the sender possesses the private signature key, a valid signature confirms the authentic identity of the sender. Thus, **a** is correct.
  2. **Integrity:** Confirms that the message has not been altered or tampered with in transit.
  3. **Non-repudiation:** The sender cannot deny having sent the message.

**Analysis of other options:**
* **b)** A digital signature detects whether any falsification occurred, but it does not specify or isolate which specific sections were altered.
* **c)** Digital signatures provide authentication and integrity, not confidentiality. The message content remains readable unless separately encrypted with the recipient's public key.
* **d)** The recipient uses the sender's **public key** (verification key) to verify the signature, not the signature key (which is kept private by the sender).

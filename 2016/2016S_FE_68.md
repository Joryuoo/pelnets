# 2016S_FE_68

Which of the following is a work that is performed when nonfunctional requirements are defined?

a) Clarifying flows of information (i.e., data) between functions constituting business operations
b) Creating development criteria and standards based on programming language used in system development
c) Defining the scope to be implemented as system functions
d) Specifying the interface for exchanging information with other systems
?
b) Creating development criteria and standards based on programming language used in system development

### Explanation

System requirements definition is categorized into **functional requirements** and **nonfunctional requirements**:

1. **Functional Requirements**: Define *what* the system must do—the capabilities, business functions, services, and data flows provided to users.
   - **a) Clarifying information flows between business functions**: Functional requirement (data flow and process modeling).
   - **c) Defining the scope to be implemented as system functions**: Functional requirement (feature and operational scope).
   - **d) Specifying the interface for exchanging information with other systems**: Functional requirement (external interface specification for data exchange).

2. **Nonfunctional Requirements**: Define the quality attributes, architectural constraints, and technical standards governing the system's development and operation:
   - Performance (response time, throughput)
   - Availability and reliability (uptime, recovery time)
   - Security and compliance
   - Maintainability, portability, and scalability
   - **Development standards and technical criteria**: Includes defining coding conventions, language constraints, architectural guidelines, and development standards.

Therefore, **Option b** represents work performed during nonfunctional requirements definition.

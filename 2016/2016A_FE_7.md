# 2016A_FE_7
In Java technologies, which of the following is the specification of creating reusable software components that have frequently used functionalities?

a) Java applet
b) Java application
c) JavaBeans
d) JavaScript
?
c) JavaBeans
### Explanation
**JavaBeans** is a Java-based software component architecture. It provides a specification for creating reusable software components (known as "beans"). These beans are classes that encapsulate many objects into a single object (the bean), so they can be passed around as a single bean object instead of multiple individual objects.

*   **Java applet:** A small Java application that runs inside a web browser (now largely obsolete).
*   **Java application:** A standalone program written in Java.
*   **JavaScript:** A completely different scripting language primarily used for client-side web behavior, not related to Java's reusable component specifications.

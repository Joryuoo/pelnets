# 2016S_FE_41

Which of the following is a technique that is classified as social engineering?

a) Acquiring a password by calling a user and pretending to be a system administrator
b) Analyzing a password by using a round-robin attack tool
c) Entering a system by using software vulnerabilities, such as a buffer overflow
d) Entering a system from a back door created automatically by a virus infection
?
a) Acquiring a password by calling a user and pretending to be a system administrator

### Explanation

**Social engineering** refers to psychological manipulation and deception techniques used to trick individuals into divulging confidential or sensitive information (such as passwords, credit card numbers, or PINs) or performing actions that compromise security, rather than attacking hardware or software vulnerabilities directly.

Common examples of social engineering include:
- **Pretexting / Impersonation (Vishing / Phone Scams)**: Posing as a system administrator, tech support, or executive to extract credentials from employees.
- **Phishing**: Sending deceptive emails purporting to be from legitimate organizations to steal user credentials.
- **Shoulder Surfing**: Watching someone enter passwords or PINs over their shoulder.
- **Dumpster Diving**: Searching through trash bins for discarded papers containing passwords, server names, or sensitive data.
- **Tailgating / Piggybacking**: Following an authorized employee into a restricted physical area without authenticating.

### Option Analysis
- **a) Acquiring a password by calling a user and pretending to be a system administrator** (Correct): This is an act of pretexting/vishing that exploits human trust and perceived authority, which is a classic form of social engineering.
- **b) Analyzing a password by using a round-robin attack tool**: This is a brute-force / exhaustive search attack, which is a technical computational attack against password hashes or login mechanisms.
- **c) Entering a system by using software vulnerabilities, such as a buffer overflow**: This is a technical software exploit targeting memory safety defects in software.
- **d) Entering a system from a back door created automatically by a virus infection**: This is a malware-based technical intrusion.

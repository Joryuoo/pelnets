# 2016A_FE_42
Which of the following is the most effective method of detecting falsification of the contents of a web server?

a) Communications to the web server are monitored to ensure that there is no communication other than HTTP and HTTPS.
b) The hash value of each file of the contents of the web server is stored and periodically compared with the hash value generated from each file.
c) The memory usage of the web server is checked periodically to ensure that a buffer overflow has not occurred.
d) The updated date of each file of the contents of the web server is stored and compared periodically with the updated date of each file.
?
b) The hash value of each file of the contents of the web server is stored and periodically compared with the hash value generated from each file.
### Explanation
To detect falsification (unauthorized alteration or defacement) of web server contents, **File Integrity Monitoring (FIM)** using cryptographic hashes is the most effective approach:

* **Cryptographic Hash Functions** (e.g., SHA-256): Compute a fixed-length mathematical digest from file contents. Due to the **avalanche effect**, even a 1-bit change to a file will produce a completely different hash digest.
* By storing baseline hash values of legitimate files in a secure database and periodically recalculating and comparing the current hashes against the baseline, administrators can immediately and reliably detect any unauthorized modifications, injections, or additions.

Why the other options are incorrect:
* **a)** Monitoring communications to allow only HTTP/HTTPS traffic does not prevent or detect file changes. Attacks like web application exploits (e.g., file upload flaws, SQL injection) or administrative credential theft occur entirely over standard HTTP/HTTPS channels.
* **c)** Checking memory usage can help identify memory leaks or denial-of-service issues, but it does not detect alterations to static or dynamic web files stored on the server's filesystem.
* **d)** File update timestamps (modification dates) are easily manipulated or forged by attackers using commands such as `touch` to match original dates, making timestamps an unreliable defense against falsification.

# 2016A_FE_9
![[2016A_FE_AM_Q9_full.png]]

a) Direct addressing
b) Indexed addressing
c) Indirect addressing
d) Relative addressing
?
c) Indirect addressing
### Explanation
The diagram illustrates a two-step memory lookup:
1. The instruction's address part points to a location in main memory (address 20).
2. The value stored at address 20 is itself an address (25).
3. The CPU then goes to address 25 to fetch the actual **Data**.

This pointer-like behavior where the address field specifies a memory location that contains the effective address of the operand is known as **indirect addressing**.

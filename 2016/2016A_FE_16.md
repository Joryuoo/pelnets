# 2016A_FE_16
Which of the following occurs when a program attempts to access a page that is mapped in the virtual address space, but is not located in the main memory? Here, the OS supports paging.

a) Fatal error
b) Page fault
c) Scheduling error
d) Segmentation fault
?
b) Page fault
### Explanation
In a virtual memory system using paging, the virtual address space of a process is divided into fixed-size blocks called **pages**, while physical main memory (RAM) is divided into equal-sized blocks called **page frames**.

- The mapping between virtual pages and physical page frames is tracked by the **Page Table**.
- Each page table entry includes a **present/valid bit** indicating whether the page currently resides in physical RAM ($1$) or remains on secondary storage/swap space ($0$).

---

#### What happens during a Page Fault:
1. When the CPU executes an instruction referencing an address whose page table entry has the present bit set to $0$ (i.e., mapped in virtual address space but not currently in main memory), the Memory Management Unit (MMU) raises a hardware interrupt known as a **page fault**.
2. The operating system's page fault handler traps the execution, selects an available page frame (or evicts an existing page using a page replacement algorithm like LRU), loads the requested page from disk into main memory, updates the page table, and resumes the program.

---

#### Evaluation of Choices:
- **a) Fatal error:** A page fault is an expected, routinely handled event in demand-paging architectures; it is not a fatal error and does not terminate the program.
- **b) Page fault:** Correct. This is the exact terminology for accessing a virtual page currently absent from physical RAM.
- **c) Scheduling error:** Relates to the CPU dispatcher or process scheduler, completely unrelated to memory address translation.
- **d) Segmentation fault:** Occurs when a program attempts to access an invalid memory address (e.g., outside allocated segments or violating memory protection permissions such as writing to a read-only page).

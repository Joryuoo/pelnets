# 2016A_FE_49
Which of the following is an appropriate category of system maintenance preformed for the purpose of modifying the system to cope with changes in the software environment (e.g. DBMS, Operating system)?

a) Adaptive maintenance
b) Corrective maintenance
c) Perfective maintenance
d) Preventive maintenance
?
a) Adaptive maintenance
### Explanation
According to international standards for software maintenance (ISO/IEC 14764), software maintenance is categorized into four types:

1. **Adaptive Maintenance (Option a):** Modification of a software product performed after delivery to keep a software product usable in a changed or changing environment. Examples include adapting the software to upgraded operating systems, changes in DBMS versions, hardware changes, or new legal/regulatory requirements.
2. **Corrective Maintenance (Option b):** Reactive modification of a software product performed after delivery to correct discovered faults, bugs, or processing defects.
3. **Perfective Maintenance (Option c):** Modification of a software product after delivery to improve performance, maintainability, or add newly requested features/enhancements from users.
4. **Preventive Maintenance (Option d):** Modification of a software product after delivery to detect and correct latent faults before they become operational problems (e.g., code refactoring, structural improvements).

Because this maintenance is performed to adapt to software environment changes (DBMS, OS), it is classified as **adaptive maintenance**.

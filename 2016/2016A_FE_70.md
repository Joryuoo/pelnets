# 2016A_FE_70
Which of the following is a characteristic of an IC tag (RFID)?

a) An IC tag handles a significant amount of information, and thus it uses an external storage device for storing information.
b) An IC tag is resistant to dirt, and the recorded information can be read even from outside the container.
c) An IC tag needs to be inserted into a dedicated magnetic reader to read the recorded information.
d) An IC tag uses GPS to display the positional and attribute information of the current location.
?
b) An IC tag is resistant to dirt, and the recorded information can be read even from outside the container.
### Explanation
An **IC tag** (or **RFID tag** - Radio Frequency Identification) consists of an integrated circuit (microchip) that stores and processes data, connected to an antenna that transmits and receives radio waves.

Key characteristics of RFID tags include:
* **Contactless & Non-line-of-sight Communication:** Because communication is conducted via radio waves (RF), tags do not require direct physical contact or optical line-of-sight (unlike barcodes or QR codes).
* **Environmental Durability:** The IC and antenna are encapsulated, making them highly resistant to dirt, dust, grease, and moisture. They can be read through packaging, cardboard boxes, and containers without unboxing.
* **Bulk Scanning & Rewritability:** Multiple RFID tags can be scanned simultaneously in bulk, and read-write tags allow stored data to be updated dynamically.

Analysis of incorrect choices:
* **a)** An IC tag stores its data internally in non-volatile semiconductor memory (such as EEPROM); it does not require an external storage device.
* **c)** RFID is a wireless radio-frequency technology; magnetic readers are used for magnetic stripe cards.
* **d)** Standard RFID tags do not contain satellite GPS receivers; tracking is performed when tags pass within range of fixed RFID readers.

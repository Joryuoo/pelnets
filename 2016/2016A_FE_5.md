# 2016A_FE_5
Which of the following is the most appropriate description of a queue?

a) Data that is stored first is retrieved first.
b) Data that is stored last is retrieved first.
c) It references specific data by using an index.
d) It represents the hierarchical relationship of data by using at least two (2) pointers.
?
a) Data that is stored first is retrieved first.
### Explanation
A **queue** is a linear data structure that follows the **FIFO (First In, First Out)** principle.
*   **a) Data that is stored first is retrieved first:** This correctly describes FIFO (Queue).
*   **b) Data that is stored last is retrieved first:** This describes LIFO (Stack).
*   **c) It references specific data by using an index:** This describes an Array.
*   **d) It represents the hierarchical relationship of data by using at least two pointers:** This describes a Tree (e.g., binary tree using left/right child pointers).

# 2016A_FE_55
In order to check whether a system works normally, users in the system user department and operators in the system operations department jointly conduct operational testing prior to full operation. Which of the following is an appropriate description of what the users should prioritize during testing?

a) Testing whether all application programs work according to the specifications
b) Testing whether online, batch, and other processing is performed according to the operational procedures
c) Testing whether the performance objective is achieved
d) Testing whether the system operates according to predetermined business procedures
?
d) Testing whether the system operates according to predetermined business procedures
### Explanation
**Operational testing** (or User Acceptance Testing / UAT) is performed in an environment similar or identical to production to verify that the system is ready for live operational deployment. Both the user department and operations department participate, each focusing on their respective domains:

* **Users in the System User Department (Option d):**
  Their primary role is to verify that the system supports and complies with actual daily business operations according to **predetermined business rules, workflows, and procedures**. They test business logic, data entry flows, report outputs, and operational edge cases.

* **Operators in the System Operations Department (Option b):**
  Their priority is operational feasibility—verifying scheduled batch runs, online service execution, backup and recovery procedures, job scheduling, and operational handbooks.

* **Developers / System Testing Phase (Options a & c):**
  * Verifying that application code meets internal technical specifications (**a**) is conducted primarily during unit, integration, and system testing by developers and software testers.
  * Verifying non-functional performance objectives like throughput and response times (**c**) is conducted during performance and load testing prior to operational acceptance testing.

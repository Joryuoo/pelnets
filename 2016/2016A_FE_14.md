# 2016A_FE_14
A system is operated as a virtual machine environment with 20 physical machines. When the operating conditions are shown below, what is the minimum number of physical machine failures that causes the system to enter fall back operation?

[Operating conditions]
(1) If a physical machine fails, the virtual machines that were running on it are made to run evenly on all the other physical machines, and the resources that were used are distributed in the same way.
(2) When there are 20 physical machines, 70% of the resources of all physical machines are used.
(3) If the resources used on a single physical machine exceed 90%, the whole system enters fall back operation.
(4) Conditions other than (1) through (3) above do not need to be considered.

a) 2
b) 3
c) 4
d) 5
?
d) 5
### Explanation
Let us define:
- Resource capacity of 1 physical machine = $1$ unit (or $100\%$).
- Total physical machines = $20$.
- Total resource capacity = $20 \times 1 = 20$ units.

#### Step 1: Determine Total Active Resource Workload
When all 20 physical machines are operating, 70% of the total capacity is used:
$$\text{Total workload} = 20 \times 0.70 = 14\text{ units}$$

#### Step 2: Formulate the Condition for Fall Back Operation
Let $k$ be the number of failed physical machines.
- The number of remaining surviving physical machines is $20 - k$.
- Since the virtual machines and their resource usages are distributed evenly across the surviving machines, each surviving physical machine will bear:
  $$\text{Resource utilization per machine} = \frac{14}{20 - k}$$

The system enters fall back operation when the resource utilization on a single physical machine **exceeds 90%** ($> 0.90$):
$$\frac{14}{20 - k} > 0.90$$

#### Step 3: Solve for $k$
$$14 > 0.90 \times (20 - k)$$
$$14 > 18 - 0.90k$$
$$0.90k > 18 - 14$$
$$0.90k > 4$$
$$k > \frac{4}{0.90} \approx 4.44$$

Since $k$ must be a whole integer number of physical machines:
- For $k = 4$ failures: Remaining machines $= 16$.
  $$\text{Utilization} = \frac{14}{16} = 0.875 = 87.5\% \le 90\% \quad (\text{Normal operation})$$
- For $k = 5$ failures: Remaining machines $= 15$.
  $$\text{Utilization} = \frac{14}{15} \approx 0.9333 = 93.33\% > 90\% \quad (\text{Enters fall back operation})$$

Therefore, the minimum number of failures required to trigger fall back operation is **5**.
The correct choice is **d) 5**.

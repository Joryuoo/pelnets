# 2016A_FE_78
![[2016A_FE_AM_Q78_full.png]]

a) A → C → B
b) B → A → C
c) B → C → A
d) C → B → A
?
b) B → A → C
### Explanation
This is a classic **two-machine flow shop scheduling problem** ($M1 \to M2$), which can be solved optimally using **Johnson's Rule**:

### Johnson's Rule Procedure:
1. List the processing times for each job on both machines:
   * **Job A:** $M1 = 7$, $M2 = 3$
   * **Job B:** $M1 = 5$, $M2 = 6$
   * **Job C:** $M1 = 4$, $M2 = 2$
2. Identify the smallest processing time among all unscheduled jobs:
   * The minimum time is **$2$** (Job C on $M2$).
   * Since this minimum occurs on the second machine ($M2$), place Job C **as late as possible**:
     $$\text{Sequence: } [\_, \_, C]$$
3. Find the smallest processing time among the remaining jobs (A and B):
   * Minimum time is **$3$** (Job A on $M2$).
   * Since it is on $M2$, place Job A **as late as possible** among the remaining slots:
     $$\text{Sequence: } [\_, A, C]$$
4. Place the remaining job (B) in the first available slot:
   $$\text{Optimal Sequence: } B \to A \to C$$

---

### Verification (Makespan Timeline):

| Order | Job | $M1$ Start–End | $M2$ Start–End | Notes |
| :--- | :---: | :---: | :---: | :--- |
| 1st | **B** | $0 \to 5$ | $5 \to 11$ | $M2$ waits until $M1$ finishes B |
| 2nd | **A** | $5 \to 12$ | $12 \to 15$ | $M2$ starts at $\max(12, 11) = 12$ |
| 3rd | **C** | $12 \to 16$ | $16 \to 18$ | $M2$ starts at $\max(16, 15) = 16$ |

* Total completion time (Makespan) for **$B \to A \to C$** = **18** units of time.

Comparing with the other options:
* **$A \to C \to B$:**
  * $M1$: A($0\to 7$), C($7\to 11$), B($11\to 16$)
  * $M2$: A($7\to 10$), C($11\to 13$), B($16\to 22$) $\to$ Total time = **22**
* **$B \to C \to A$:**
  * $M1$: B($0\to 5$), C($5\to 9$), A($9\to 16$)
  * $M2$: B($5\to 11$), C($11\to 13$), A($16\to 19$) $\to$ Total time = **19**
* **$C \to B \to A$:**
  * $M1$: C($0\to 4$), B($4\to 9$), A($9\to 16$)
  * $M2$: C($4\to 6$), B($9\to 15$), A($16\to 19$) $\to$ Total time = **19**

The minimum total processing time of **18** is achieved with **$B \to A \to C$**.

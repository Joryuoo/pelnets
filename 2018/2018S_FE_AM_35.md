# 2018S_FE_AM_35
![[2018S_FE_AM_Q35_full.png]]
?
a) Source (web server) port number: 80, Destination (PC) port number: 50001
### Explanation
When a PC sends an HTTP request to a web server, the request packet uses an ephemeral port (e.g., 50001) as its source and port 80 (standard HTTP port) as its destination. 
When the web server replies with a response packet, the port numbers are swapped: the source port is the web server's listening port (80), and the destination port is the PC's ephemeral port (50001).

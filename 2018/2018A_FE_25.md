# 2018A_FE_25
Currently, the number of customers is 8,000 with annual increase rate of 20%. By assigning a fixed length code using 26 uppercase alphabet A- Z to each customer, what is the minimum code length required to accommodate all the customers for next three years?

a) 3
b) 4
c) 5
d) 6
?
a) 3
### Explanation
1. Calculate the customer count after three years with an annual increase of 20%:
   $$\text{Future Customers} = 8{,}000 \times (1 + 0.20)^3 = 8{,}000 \times 1.728 = 13{,}824$$

2. Calculate the capacity for fixed-length codes using 26 uppercase letters ($A\text{–}Z$):
   - Length 1: $26^1 = 26$
   - Length 2: $26^2 = 676$
   - Length 3: $26^3 = 17{,}576$

Since $17{,}576 \ge 13{,}824$, a code length of 3 is sufficient to uniquely identify all customers over the next three years. Therefore, the minimum code length is 3.

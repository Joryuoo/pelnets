# 2018A_FE_AM_21
Which of the following is a criterion for a page to be replaced in a Least Recently Used (LRU) algorithm?

a) The cumulative total number of references
b) The first referenced time
c) The frequency of references per unit of time
d) The last referenced time
?
d) The last referenced time
### Explanation
In the Least Recently Used (LRU) page replacement algorithm, the operating system replaces the page that has not been accessed for the longest period of time. Therefore, the decision criterion is based on the **last referenced time** of each page.

- **a) Cumulative total number of references:** Used in Least Frequently Used (LFU).
- **b) First referenced time:** Used in First-In, First-Out (FIFO).
- **c) Frequency of references per unit of time:** Used in frequency-based or aging replacement algorithms.
- **d) Last referenced time:** Used in LRU.

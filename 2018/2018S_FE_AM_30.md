# 2018S_FE_AM_30
In a distributed database system, which of the following is a method for the finalization of update processing when an inquiry is made to multiple sites that perform a series of transaction processes as to whether finalization is possible or not and whether finalization is possible at all sites?

a) Exclusive control
b) Roll back
c) Roll forward
d) Two-phase commitment
?
d) Two-phase commitment
### Explanation
In a distributed database system, a **two-phase commitment (2PC)** protocol ensures that all participating sites either commit or roll back a transaction together, maintaining data consistency across the network.
The two phases are:
1. **Prepare phase (Inquiry):** The coordinator node asks all participating sites if they can commit the transaction. Each site responds with a "ready" or "abort" message.
2. **Commit phase (Finalization):** If all sites responded with "ready", the coordinator issues a global commit command. If any site responded with "abort", the coordinator issues a rollback command to all sites.

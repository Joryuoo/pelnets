# 2018A_FE_66
Which of the following is the activity that translates the information gathered during analysis activities into a document as a set of requirements?

a) Feasibility study
b) Requirement analysis
c) Requirement definition
d) Requirement specification
?
c) Requirement definition
### Explanation
In systems development, **requirement definition** is the activity that synthesizes user needs and analytical findings into a formal baseline document defining system requirements.

- **Feasibility study**: Evaluates economic, technical, and operational viability before development begins.
- **Requirement analysis**: Explores, categorizes, models, and resolves conflicts within user and business requirements.
- **Requirement specification**: Produces a formal, developer-oriented software requirements specification (SRS) detailing functional and non-functional constraints.

# 2018S_FE_AM_6
There is a two-dimensional integer array A whose (i, j)-th element A[i, j] is $2 \times i + j$. What is the value of the element A[A[1, 1] $\times$ 2, A[2, 2] + 1]?

a) 12
b) 13
c) 18
d) 19
?
d) 19
### Explanation
First, we find the values of $A[1, 1]$ and $A[2, 2]$:
- $A[1, 1] = 2 \times 1 + 1 = 3$
- $A[2, 2] = 2 \times 2 + 2 = 6$

Next, we evaluate the indices for the target element:
- Row index $i = A[1, 1] \times 2 = 3 \times 2 = 6$
- Column index $j = A[2, 2] + 1 = 6 + 1 = 7$

Finally, we find the value of $A[6, 7]$:
- $A[6, 7] = 2 \times 6 + 7 = 12 + 7 = 19$.

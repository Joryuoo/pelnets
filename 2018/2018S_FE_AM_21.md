# 2018S_FE_AM_21
A D/A converter with a resolution of 8 bits generates an output voltage of 0 volts for a digital input value of 0, and an output voltage of 2.5 volts for a digital input value of 128. When the lowest 1 bit of the digital input value is changed, which of the following is the change (in volts) of the output voltage that is generated by the D/A converter?

a) 2.5/128
b) 2.5/255
c) 2.5/256
d) 2.5/512
?
a) 2.5/128
### Explanation
A D/A (Digital-to-Analog) converter transforms digital data into analog signals.
Given:
- Resolution = 8 bits
- Digital input 0 generates 0 V
- Digital input 128 generates 2.5 V

Assuming the output voltage is linear with respect to the input:
- The change in output voltage for a difference of 128 in the digital input (from 0 to 128) is 2.5 V.
- A change in the lowest 1 bit (the Least Significant Bit, or LSB) corresponds to a change of 1 in the digital input value.
- The corresponding change in output voltage is 2.5 V / 128.

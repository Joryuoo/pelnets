# 2018A_FE_20
In the virtual memory of a paging system, which of the following is a cause that increases the number of page fault occurrences?

a) An access to a page that has not been accessed for a long time in main memory
b) An increase in access to a page that does not exist in main memory
c) An increase in access to a page that exists in main memory
d) An increase in the ratio of pages that are updated among the pages in main memory
?
b) An increase in access to a page that does not exist in main memory
### Explanation
In a virtual memory paging system, a **page fault** occurs when an instruction attempts to access a memory page that is mapped in the virtual address space but is not currently loaded in physical main memory (RAM). When this happens, the Memory Management Unit (MMU) triggers a page fault exception, prompting the OS to retrieve the page from secondary storage.

- **b) (Correct):** Accessing non-resident pages directly causes page faults. An increase in such accesses increases page fault occurrences.
- **a) & c):** Pages present in main memory result in memory hits, causing zero page faults regardless of how long ago they were referenced.
- **d):** Modifying resident pages marks them as dirty, which affects page replacement write-back overhead but does not trigger page faults.

# 2018S_FE_AM_34
Which of the following delivery models does an ARP response use?

a) Anycast
b) Broadcast
c) Multicast
d) Unicast
?
d) Unicast
### Explanation
ARP (Address Resolution Protocol) maps an IP address to a MAC address. When a device sends an ARP request, it uses a **broadcast** delivery model so that all devices on the local network receive it. However, when the target device replies with an ARP response containing its MAC address, it sends the message directly back to the requester using a **unicast** delivery model.

# 2018A_FE_AM_80
Which of the following is an appropriate order of the workflow from transaction records to closing accounts?

a) General Ledger → Journal Book → Trial Balance Sheet → Work Sheet → Financial Statements
b) General Ledger → Journal Book → Work Sheet → Trial Balance Sheet → Financial Statements
c) Journal Book → General Ledger → Trial Balance Sheet → Work Sheet → Financial Statements
d) Journal Book → General Ledger → Work Sheet → Trial Balance Sheet → Financial Statements
?
c) Journal Book → General Ledger → Trial Balance Sheet → Work Sheet → Financial Statements
### Explanation
The standard accounting cycle from transaction recording to closing accounts follows this chronological sequence:

1. **Journal Book:** Daily transactions are first recorded chronologically into journal entries (debits and credits).
2. **General Ledger:** Transactions from the journal book are posted to their corresponding individual ledger accounts.
3. **Trial Balance Sheet:** Unadjusted debit and credit balances are listed to check mathematical equality (total debits = total credits).
4. **Work Sheet:** An accounting tool used to organize adjusting entries, determine adjusted trial balances, and sort items before financial statement preparation.
5. **Financial Statements:** Formal reports (Balance Sheet, Income Statement) prepared for internal management and external reporting.

Therefore, the correct workflow order is choice **c)**.

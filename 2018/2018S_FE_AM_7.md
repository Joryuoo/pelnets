# 2018S_FE_AM_7
![[2018S_FE_AM_Q7_p1.png]]

a) n + F(n - 1)
b) n - 1 + F(n)
c) n × F(n - 1)
d) (n - 1) × F(n)
?
c) n × F(n - 1)
### Explanation
The factorial function for a non-negative integer $n$, denoted as $n!$, is defined mathematically as:
- $0! = 1$
- $n! = n \times (n - 1)!$ for $n > 0$

In terms of the function $F(n)$:
- $F(0) = 1$
- $F(n) = n \times F(n - 1)$ for $n > 0$

Therefore, the appropriate recursive expression for blank A is $n \times F(n - 1)$.

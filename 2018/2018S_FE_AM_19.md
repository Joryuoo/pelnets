c) A: Saving of the running state, B: Selection of the process, C: Restoration of the running state
### Explanation
When a context switch occurs due to an interrupt in a multiprogramming environment, the operating system follows a specific sequence of actions to safely transition from one process to another:
1.  **A (Saving of the running state):** The current context and state of the actively running Process I (like CPU registers, flags, and program counter) must first be saved into a Process Control Block (PCB) so that it can be resumed exactly where it left off later.
2.  **B (Selection of the process):** The operating system scheduler evaluates the processes in the ready queue and selects the next process to be executed (in this case, Process II).
3.  **C (Restoration of the running state):** The previously saved state and context of the newly selected Process II are loaded into the CPU's registers, restoring it to a running state and allowing it to continue execution.

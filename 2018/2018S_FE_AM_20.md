# 2018S_FE_AM_20
Which of the following is the appropriate function of a linker?

a) Creating a load module from multiple object modules, etc. by performing operations such as cross-reference resolution
b) Loading a load module into main memory before execution
c) Monitoring program execution and logging the execution result for each step
d) Registering a created program to a library
?
a) Creating a load module from multiple object modules, etc. by performing operations such as cross-reference resolution
### Explanation
*   **Linker:** A system program that takes one or more object modules generated by a compiler or assembler, resolves external references between them, and links them together to create a single executable load module.
*   **Loader:** Described in choice (b), it is responsible for loading the finalized executable module from secondary storage into main memory for execution.
*   **Debugger/Tracer:** Described in choice (c), it monitors and controls the execution of a program to find defects.
*   **Librarian:** Described in choice (d), it is used to manage and register compiled modules into reusable software libraries.

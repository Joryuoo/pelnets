# 2018A_FE_19
![[2018A_FE_AM_Q19_full.png]]

a) \A → ..\B → .\A\B
b) \B → .\B\A → ..\B
c) \B → \A → \B
d) \B\A → ..\B
?
a) \A → ..\B → .\A\B
### Explanation
The objective is to reach the directory `\B\A\B` (Root $\to$ B $\to$ A $\to$ B). Tracing choice **a)**:

1. `\A`: Starts with `\`, an absolute path from Root into directory `A`. 
   - Current directory: `\A`
2. `..\B`: `..` moves up one level to Root (`\`), then descends into directory `B`. 
   - Current directory: `\B`
3. `.\A\B`: Starts from the current directory `\B`, descends into child `A`, then grandchild `B`. 
   - Current directory: `\B\A\B`

Evaluating the other options:
- **b)** `\B` $\to$ `.\B\A` (moves to `\B\B\A`) $\to$ `..\B` (ends at `\B\B\B`).
- **c)** Moves to `\B`, then absolute `\A`, then absolute `\B` (ends at `\B`).
- **d)** Moves to `\B\A`, then `..` (up to `\B`) and into child `B` (ends at `\B\B`).

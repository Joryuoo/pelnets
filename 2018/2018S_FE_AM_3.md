# 2018S_FE_AM_3
For two logical variables X and Y, a logical operation X NAND Y is defined as a composite operation NOT (X AND Y). Which of the following is equivalent to the logical operation X OR Y?

a) ((X NAND Y) NAND X) NAND Y
b) (X NAND X) NAND (Y NAND Y)
c) (X NAND Y) NAND (X NAND Y)
d) X NAND (Y NAND (X NAND Y))
?
b) (X NAND X) NAND (Y NAND Y)
### Explanation
By definition:
$X \text{ NAND } Y = \overline{X \cdot Y}$
Using De Morgan's Laws, we want to construct $X \text{ OR } Y = X + Y$.

Let's evaluate choice b):
- $(X \text{ NAND } X) = \overline{X \cdot X} = \overline{X}$ (which is NOT X)
- $(Y \text{ NAND } Y) = \overline{Y \cdot Y} = \overline{Y}$ (which is NOT Y)
- Thus, $(X \text{ NAND } X) \text{ NAND } (Y \text{ NAND } Y) = \overline{X} \text{ NAND } \overline{Y} = \overline{\overline{X} \cdot \overline{Y}}$

Applying De Morgan's Law to $\overline{\overline{X} \cdot \overline{Y}}$:
$\overline{\overline{X} \cdot \overline{Y}} = \overline{\overline{X}} + \overline{\overline{Y}} = X + Y = X \text{ OR } Y$.

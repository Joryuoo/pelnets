# 2018S_FE_AM_14
Which of the following is a characteristic of a HA (High Availability) cluster configuration based on a hot standby method when it is compared to a load distribution cluster configuration that uses a load balancer?

a) A server that has the same specifications is necessary as a secondary server, but since processes are taken over by the secondary server in the event of the primary failure, the throughput can be maintained even in the event of a failure.
b) Given that processes are distributed to other servers in operation in the event of a failure, the load of servers in operation increases and the throughput decreases.
c) Given that processes can be distributed uniformly, server machines can be utilized effectively and expandability is ensured even if the amount of processing increases in the future.
d) Given that processes must be consistent among multiple servers in operation, it is necessary to share a database.
?
a) A server that has the same specifications is necessary as a secondary server, but since processes are taken over by the secondary server in the event of the primary failure, the throughput can be maintained even in the event of a failure.
### Explanation
*   **Hot Standby (HA Cluster):** A primary active server handles all the load, while a secondary identical server remains powered on and continuously synchronizes with the primary. In the event of a primary server failure, the secondary server immediately takes over. Because the secondary server has the same specifications as the primary, the overall throughput is maintained after the failover.
*   **Load Distribution Cluster:** Traffic is shared among multiple active servers. If one server fails, the others take over its load, often causing their individual loads to increase. Choice b describes characteristics of load distribution clusters without adequate spare capacity, while Choice a describes a true hot standby characteristic.

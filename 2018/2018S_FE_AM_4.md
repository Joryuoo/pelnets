# 2018S_FE_AM_4
![[2018S_FE_AM_Q4_p1.png]]

a) 0000
b) 0111
c) 1010
d) 1111
?
c) 1010
### Explanation
In the given state transition diagram, the automaton accepts a bit string if it reaches the final (double-circle) state. 
- Tracing "1010": 
  1. Starts at the initial state. Reads '1', stays in the initial state.
  2. Reads '0', transitions to the middle state.
  3. Reads '1', transitions to the rightmost (final) state.
  4. Reads '0', stays in the rightmost (final) state.

Because the string terminates in the final state, "1010" is accepted by the automaton.

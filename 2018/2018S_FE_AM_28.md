# 2018S_FE_AM_28
Which of the following methods to join two (2) tables in an RDBMS is a description of the sort-merge join method?

a) All rows in the tables are re-ordered according to the values in the column to be joined, and they are joined in order from the top.
b) If a column to be joined in one of the tables is included in the index, the column to be joined in the other table and the index value are used to join the tables.
c) The values in a column to be joined in one of the tables are extracted in order, and they are joined with the column to be joined from the other table.
d) The values in a column to be joined in one of the tables are used to create a hash table, and this is joined with the column to be joined from the other table.
?
a) All rows in the tables are re-ordered according to the values in the column to be joined, and they are joined in order from the top.
### Explanation
In a Relational Database Management System (RDBMS), there are different algorithmic methods used to join tables:
- **Sort-merge join (Choice a):** Both tables are first sorted based on the join key, and then the sorted tables are merged together in order.
- **Index join (Choice b):** Uses an index on the join column of one table to quickly lookup and find matching rows from the other table.
- **Nested loop join (Choice c):** For each row in the outer table, it sequentially scans the inner table for matching rows.
- **Hash join (Choice d):** Creates an in-memory hash table from the join column of the smaller table and uses it to probe and join with the other table.

# 2018S_FE_AM_13
Which of the following is a method that increases the speed of data input/output by dividing logically sequential data and writing the divided data into multiple hard disks?

a) Disk cache
b) Mirroring
c) Striping
d) Swapping
?
c) Striping
### Explanation
*   **Disk cache:** Uses a portion of RAM to temporarily store data from a disk, speeding up read/write access to frequently used data.
*   **Mirroring (RAID 1):** Involves duplicating data across multiple disks to provide redundancy and fault tolerance, not specifically for increasing I/O speed.
*   **Striping (RAID 0):** Divides sequential data into blocks (stripes) and writes them across multiple hard disks simultaneously, which significantly increases data read and write speeds.
*   **Swapping:** An operating system technique of moving pages of memory between RAM and a hard disk (virtual memory).

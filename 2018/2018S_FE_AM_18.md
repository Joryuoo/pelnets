# 2018S_FE_AM_18
Which of the following is classified as a function of a static test tool?

a) Calculating the coverage from the paths executed by the test
b) Detecting an error in a program by analyzing the source code
c) Generating a driver or stub necessary for the module to be tested
d) Generating the data to test a specific path of the program
?
b) Detecting an error in a program by analyzing the source code
### Explanation
*   **Static testing tools** analyze the source code, specifications, or models without actually executing the program. They check for syntax errors, coding standard violations, uninitialized variables, and other potential logical errors directly in the code structure.
*   **Dynamic testing tools** (as seen in choices a, c, and d) require the program to be compiled and executed. They are used for tasks like measuring path coverage, creating runtime stubs/drivers, and injecting test data while the software is running.

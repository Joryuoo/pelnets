### Explanation
Input validation checks are used to ensure the data entered is accurate and valid:
- **Sequence check:** Verifies that data elements are in a predetermined numerical or chronological sequence.
- **Duplication check:** Verifies that no identical data or transaction has already been entered.
- **Format check:** Ensures the data conforms to a specific format (e.g., date format YYYY-MM-DD).
- **Logical check:** Verifies the relationship between two or more fields or checks if the data makes logical sense. Checking if the order date is on or before the entering date is a logical relationship validation, thus it is a logical check.

# 2018A_FE_53

Which of the following is an appropriate description of the activities on the critical path of a project?

a) Any activity on the critical path is called a critical path activity. 
b) The critical path is the sequence of activities that represents the shortest path through a 
project. 
c) The critical path must contain the activity that has the longest duration compared to the 
other all activities. 
d) The sum of activities on the critical path determines the longest possible project 
duration. 
?
a) Any activity on the critical path is called a critical path activity.

### Explanation

In project management (Critical Path Method - CPM):
- **a) is correct**: By definition, any task or activity that lies along the critical path is designated as a critical path activity (critical activity).
- **b) is incorrect**: The critical path represents the **longest sequence** of dependent activities through a network path, not the shortest.
- **c) is incorrect**: An individual activity with the longest duration does not necessarily have to be on the critical path; a path consisting of multiple shorter activities can have a larger total duration.
- **d) is incorrect**: The sum of activity durations along the critical path determines the **shortest possible total project duration** (the minimum required time to finish the project), not the longest possible.

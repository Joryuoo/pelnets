# 2018A_FE_28
![[2018A_FE_AM_Q28_p1.png]]

a) A = 208, B = Credit
b) A = 208, B = Debit
c) A = 510, B = Credit
d) A = 510, B = Debit
?
d) A = 510, B = Debit
### Explanation
In double-entry bookkeeping, an accounting transaction must balance with equal total Debit and Credit amounts:
- A sale of 500 dollars to Company X posted to the cash account generates:
  - **Debit:** Cash (AccountCode 510) for 500 dollars (asset increase).
  - **Credit:** Sales (AccountCode 208) for 500 dollars (revenue increase).

Looking at the `Transfer` table for Transaction `0122`:
- The second row already records: `AccountCode 208`, `Credit`, `500`.
- The corresponding balancing entry $(A, B)$ must record the Cash debit: `AccountCode 510`, `Debit`, `500`.

Therefore, $A = 510$ and $B = \text{Debit}$, which matches choice **d)**.

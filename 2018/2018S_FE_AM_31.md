# 2018S_FE_AM_31
Which of the following TCP/IP protocols is used to assign IP addresses dynamically?

a) ARP
b) DHCP
c) RIP
d) SMTP
?
b) DHCP
### Explanation
DHCP (Dynamic Host Configuration Protocol) is a network management protocol used on UDP/IP networks whereby a DHCP server dynamically assigns an IP address and other network configuration parameters to each device on a network so they can communicate with other IP networks.

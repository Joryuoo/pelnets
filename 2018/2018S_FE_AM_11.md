# 2018S_FE_AM_11
Which of the following is an output device for the computer?

a) Camera
b) Mouse
c) Printer
d) Scanner
?
c) Printer
### Explanation
*   **Camera:** Input device used to capture images or video.
*   **Mouse:** Input device used to control a cursor.
*   **Printer:** Output device used to produce physical copies of digital documents.
*   **Scanner:** Input device used to convert physical documents into digital images.

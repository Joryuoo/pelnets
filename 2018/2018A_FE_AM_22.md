# 2018A_FE_AM_22
![[2018A_FE_AM_Q22_full.png]]

a) E = 0, Y = 0
b) E = 0, Y = 1
c) E = 1, Y = 0
d) E = 1, Y = 1
?
d) E = 1, Y = 1
### Explanation
The circuit consists of:
1. An XOR gate with inputs $A$ and $B$, producing intermediate output $E$.
2. An AND gate with inputs $E$ and $C$, producing final output $Y$.

Given the input values $A = 1$, $B = 0$, and $C = 1$:
- Intermediate output $E = A \oplus B = 1 \oplus 0 = 1$.
- Final output $Y = E \land C = 1 \land 1 = 1$.

Thus, $E = 1$ and $Y = 1$, which corresponds to choice d).

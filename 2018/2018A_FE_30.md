# 2018A_FE_30
In a DBMS, when multiple transaction programs update the same database simultaneously, which of the following is a technology that is used to prevent logical contradictions?

a) Exclusive control
b) Integrity constraint
c) Normalization
d) Reorganization
?
a) Exclusive control
### Explanation
In a DBMS, **exclusive control** (concurrency control via mechanisms like locking) is used when multiple transactions update the same database simultaneously. It prevents logical contradictions and data inconsistencies, such as lost updates, dirty reads, and phantom reads.

- **a) Exclusive control:** Manages simultaneous access and updates using locks (shared/exclusive) to ensure serializability.
- **b) Integrity constraint:** Defines rules (e.g., primary key uniqueness, foreign key references) to maintain data correctness.
- **c) Normalization:** Organizes tables and attributes to minimize data redundancy.
- **d) Reorganization:** Defragments and re-indexes physical storage to improve performance.

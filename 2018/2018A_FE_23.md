# 2018A_FE_23
By using a sensor that detects changes in shape, the condition of infrastructure such as elevated highways can be monitored and maintained. Which of the following is a sensor that is used for this purpose?

a) Gyro
b) Hall element
c) Strain gage
d) Thermistor
?
c) Strain gage
### Explanation
A **strain gage** (or strain gauge) is a sensor whose electrical resistance varies in proportion to the amount of strain (mechanical deformation or change in shape) experienced by the object to which it is attached. It is widely used for structural health monitoring in civil infrastructure like bridges and elevated highways.

- **a) Gyro (gyroscope):** Measures angular velocity or orientation.
- **b) Hall element:** Detects magnetic fields using the Hall effect.
- **c) Strain gage:** Detects mechanical deformation and shape changes.
- **d) Thermistor:** Measures temperature changes through changes in resistance.

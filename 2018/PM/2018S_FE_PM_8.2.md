### Explanation

**Blank C:** `a` (`currentPosition < words.length`)
`LeftToRightIterator` starts at index `0` and advances forward. It has more elements as long as `currentPosition < words.length`.

**Blank D:** `f` (`currentPosition++`)
`nextWord()` returns the element at the current index and then increments the pointer for the next call via post-increment (`currentPosition++`).

**Blank E:** `e` (`currentPosition >= 0`)
`RightToLeftIterator` starts at the last index (`words.length - 1`) and moves backward toward index `0`. Remaining elements exist while `currentPosition >= 0`.

**Blank F:** `g` (`currentPosition--`)
`nextWord()` returns the word at the current index and then decrements the index using post-decrement (`currentPosition--`).

# 2018S_FE_PM_2.1

d, c, f, c

### Explanation
- **Blank A:** When a cache miss occurs, the required page must be transferred from main memory to cache memory, and then to the CPU. Thus, the answer is **d**.
- **Blank B:** On a hit, miss ratio $m = 0$. Using $T = m \times T_m + T_h + E$:
  $$T = (0 \times 50) + 2 + 5 = 7\text{ ns}$$
  Thus, the answer is **c** (7 ns).
- **Blank C:** On a miss, $m = 1$:
  $$T = (1 \times 50) + 2 + 5 = 57\text{ ns}$$
  Thus, the answer is **f** (57 ns).
- **Blank D:** For $T = 32\text{ ns}$:
  $$32 = (m \times 50) + 2 + 5 \implies 50m = 25 \implies m = 0.50$$
  Thus, the answer is **c** (0.50).

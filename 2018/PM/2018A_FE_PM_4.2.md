### Explanation
**Blank E:** Message (1) is a broadcast message sent by PC21 to find the MAC address of its default gateway (L3 Switch #1) via ARP. Since VLANs create separate broadcast domains, a broadcast message sent by a device in VLAN 20 will only be propagated to other devices **in VLAN 20**. Thus, the answer is `b`.

**Blank F:** Message (2) is a query message sent to resolve the URL `www.info.sample.edu` into an IP address. URL resolution is the core function of the Domain Name System. Therefore, this query message is sent to the **DNS server**. Thus, the answer is `b`.

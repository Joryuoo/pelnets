### Explanation
**Blank A:** In step (3), user X forwards a part of the message received in step (2) to user Y. Looking at step (2), the part of the message meant for user Y is encrypted using $K_Y$ and contains the session key $K_S$ and $ID_X$. This is mathematically represented as $E(K_Y, K_S || ID_X)$. Therefore, the answer is `e`.

**Blank B:** In step (5), user X responds with an encrypted message containing a transformed value of the nonce $N_2$ (which is $f(N_2)$). This is to prove to user Y that user X has the session key $K_S$ and is actively participating in the session. Thus, the message is encrypted with the session key $K_S$ and contains $f(N_2)$, yielding $E(K_S, f(N2))$. Therefore, the answer is `a`.

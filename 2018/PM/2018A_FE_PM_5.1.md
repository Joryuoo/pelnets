**Blank A:** The diagram shows an arrow from `Apply course` to `Upload application form`. As described in Table 1, after filling in the form, "the student must upload the application form. After uploading, the student must confirm the course application." Because uploading the form is a mandatory step that is completely integrated into the core `Apply course` flow, this is an `<<include>>` relationship. Thus, the answer is `b`.

**Blank B:** P00 transitions to Blank B, which then transitions to P10 (Student Menu) or P00. The only way to access the Student Menu from the General Menu is by logging in. The table indicates use case 03 is `Login`. Thus, Blank B is P03 (Login). The answer is `b`.

**Blank C & D:** From P10, there are pathways that result in sending an email message (EM2 and EM3). Looking at Table 1, emails are only sent in `Apply course` (14) and `Update course` (15). Since `Apply course` involves uploading the application form (12), Blank C corresponds to P12 `Upload application form` (which leads into P14 `Apply course` and triggers EM2). Blank D represents P15 `Update course` (triggers EM3). Thus, C is `d` (P12) and D is `g` (P15).

**Blank E:** After hitting P16 (Logoff) from P10 (Student Menu), the system should log the user out. Following the standard application flow (and as the arrows show), logging off returns the user to the starting public point, which is P00 `General menu`. Thus, the answer is `b`.

### Explanation
- **Blank C**:
  - The subquery retrieves `DTypeID` for 'Christmas day' and 'New year', returning multiple values. Therefore, the set membership operator `IN` must be used rather than `=`.
  - The requirement specifies that each customer name must be displayed only once even if multiple matching purchase records exist.
  - Because `DISTINCT` is not used in the `SELECT` clause, adding `GROUP BY S.CustName` at the end of the query groups the results by customer name to eliminate duplicates. Thus, option **d** is correct.

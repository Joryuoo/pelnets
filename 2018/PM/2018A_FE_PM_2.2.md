# 2018A_FE_PM_2.2

![[2018A_FE_PM_Q2_SQ2_p1.png]]

?
e, c, a

### Explanation
**Blank C:** The logical address is `006C00` (hex). Breaking it into bits, since the displacement $d$ is 12 bits (the last 3 hex digits `C00`), the page number $p$ is the remaining higher bits, which is `006` (or simply page `6`). In the Page Table (Figure 2), Page No. `6` has an $L$ bit of `0`, meaning it is **not loaded into the physical address space**. Thus, the answer is `e`.

**Blank D:** The logical address is `007E00` (hex). The displacement $d$ is `E00` (hex). The page number $p$ is `007` (or simply page `7`). In the Page Table, Page No. `7` has an $L$ bit of `1` and maps to Frame No. `6`. Reconstructing the physical address: Frame `6` concatenated with displacement `E00` gives the physical address `06E00`. Thus, the answer is `c`.

**Blank E:** When a CPU requests a logical address mapped to a page whose $L$ bit (Load bit / Valid bit) is `0`, the system generates an interrupt known as a **page fault**, which triggers the OS to load the required page from disk. Thus, the answer is `a`.

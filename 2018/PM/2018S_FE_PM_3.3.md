### Explanation
The amount for each sale transaction is calculated by multiplying unit price by quantity (`S.UnitPrice * S.Qty`).
- **Blank D (`Average`)**: Calculates the average sale amount per transaction for each `SaleType` using `AVG(S.UnitPrice * S.Qty)` (b).
- **Blank E (`PerYear`)**: Calculates the total annual sales amount for each `SaleType` by summing all transaction amounts using `SUM(S.UnitPrice * S.Qty)` (e).

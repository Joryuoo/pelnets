### Explanation
**Blank C:**
DHCP clients locate servers via broadcast packets, which routers do not forward across subnets without a DHCP relay agent. Therefore, the DHCP server must reside in the same broadcast domain as the business PCs, which is **network B** (**c**).

**Blank D:**
The firewall blocks direct traffic between the backbone network and the Internet. To allow PCs web access while preserving this isolation, the proxy server must be installed in the **DMZ** (**a**).

**Blank E:**
The baseline response time is 100, half of which is 50. With cache hit rate $h$, the average response time is $30h + 110(1 - h) = 110 - 80h$. Setting $110 - 80h \le 50$ yields $80h \ge 60 \implies h \ge 0.75$ (**75%**). Thus, **f) 75** is correct.

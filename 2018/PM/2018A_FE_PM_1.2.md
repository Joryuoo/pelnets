# 2018A_FE_PM_1.2

![[2018A_FE_PM_Q1_SQ2_p1.png]]

?
a, c, e, f

### Explanation
**Blank C:** The KDC supplies the **master keys** to users in advance (often via physical delivery). Thus, the answer is `a`.

**Blank D:** When a user wants to communicate, the KDC generates a temporary one-time **session key** before communications begin. Thus, the answer is `c`.

**Blanks E and F:** When user X requests a session key, the KDC sends back the original message (including the nonce $N_1$) along with the new session key. Including the original request data allows user X to **verify that the request has not been altered** (since it's encrypted with $K_X$ and only the KDC could have formulated the correct response) and to **verify that this response is not a replay attack** (because the fresh nonce $N_1$ confirms the response corresponds to the current, live request). Thus, the answers are `e` and `f`.

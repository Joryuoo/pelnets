### Explanation
- **Blank A (`LEFT JOIN`)**: The query must output both implemented and unimplemented marketing activities. Unimplemented plans have no corresponding records in `TblBgtUsed` (resulting in `NULL` values for budget fields, as shown for "Launch Website"). A `LEFT JOIN` retains all records from `TblMktPlan`.
- **Blank B (`Mkt.PlanID = Bgt.PlanID`)**: The join condition links `TblMktPlan` and `TblBgtUsed` via their common key `PlanID`. No `GROUP BY` clause is required since the query outputs detailed individual records.

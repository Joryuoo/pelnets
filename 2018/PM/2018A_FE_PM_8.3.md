# 2018A_FE_PM_8.3

![[2018A_FE_PM_Q8_SQ3_p1.png]]

?
b

### Explanation
If we replace line `/* I' */` with `System.out.println(a.add(c));`, where `a` is a `RationalNumber` and `c` is a `DoubleNumber`, the compiler will throw an error. 

In Program 4, `RationalNumber` extends `ComparableNumber<RationalNumber>`, inheriting the `add` method with signature `public RationalNumber add(RationalNumber b)`. 

This method requires a `RationalNumber` as its argument, but we are trying to pass a `DoubleNumber` object (`c`). Because Java is strongly typed, the compiler checks this signature mismatch during the compilation phase, resulting in a **compilation error**. Thus, the answer is `b`.

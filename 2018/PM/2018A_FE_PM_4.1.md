### Explanation
**Blank A & B:** Rule (1) states that secure Web services on the external IP address of the router will be mapped to Web server #1 in the DMZ. The external IP address of the router shown in Figure 1 is `198.58.100.189`. Therefore, the destination should be `198.58.100.189` (Blank A = `d`), and the action should be to `Allow` (Blank B = `e`) this traffic to be mapped to the internal IP `172.16.1.10`.

**Blank C:** Rule (2) states that all servers can access the Internet from the DMZ using NAT. Therefore, the services allowed for traffic originating from the DMZ to the Internet should be `Any` (Blank C = `f`), since it covers all possible internet traffic.

**Blank D:** Rule (3) states that all servers in the DMZ should be accessible from the network administrator in the LAN via SSH. Therefore, the source of this SSH traffic should be the `LAN` (Blank D = `i`).

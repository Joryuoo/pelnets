### Explanation
The LRU matrix update rule specifies that when page frame $k$ is referenced:
1. Set all bits in **row $k$** to `1`.
2. Set all bits in **column $k$** to `0`.

For step (5), page frame 1 is referenced.
Taking matrix (4) before this access:
- Row 0: `0 1 0 0`
- Row 1: `0 0 0 0`
- Row 2: `1 1 0 1`
- Row 3: `1 1 0 0`

- **Step 1:** Set all bits of row 1 to `1` $\rightarrow$ row 1 becomes `1 1 1 1`.
- **Step 2:** Set all bits of column 1 to `0`.

The resulting matrix is:
- Row 0: `0 0 0 0`
- Row 1: `1 0 1 1`
- Row 2: `1 0 0 1`
- Row 3: `1 0 0 0`

This matches matrix **b**.

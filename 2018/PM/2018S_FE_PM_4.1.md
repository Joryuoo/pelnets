### Explanation
**Blank A:**
The backbone network (`10.0.0.x`), Network A (`10.0.1.x`), and Network B (`10.0.2.x`) are separate subnets connected by routers. In Network A, the router interface (`10.0.1.1`) and Internal Web server 1 (`10.0.1.200`) belong to the same network. A subnet mask of `255.255.255.0` (/24) isolates the third octet while keeping `10.0.1.1` and `10.0.1.200` in the same subnet (unlike `255.255.255.128`, which splits them). Thus, **c) 255.255.255.0** is correct.

**Blank B:**
Network A addresses range from `10.0.1.1` to `10.0.1.254`. Among the choices, only `10.0.1.1`, `10.0.1.2`, and `10.0.1.3` belong to Network A. Because `10.0.1.1` is assigned to the router interface, only `10.0.1.2` and `10.0.1.3` are available for Internal Web server 2, giving **2** available IP addresses. Thus, **b) 2** is correct.

# 2018S_FE_AM_37
Which of the following is an attack that threatens the “integrity” of information?

a) A DoS attack which sets the system to an overloaded state
b) Falsification of a web page
c) Tapping of communication content
d) Unauthorized copying of data saved in a system
?
b) Falsification of a web page
### Explanation
In information security (the CIA triad):
- **Confidentiality** is threatened by tapping or unauthorized copying.
- **Integrity** is threatened by unauthorized modification or falsification (e.g., altering a web page).
- **Availability** is threatened by DoS (Denial of Service) attacks that make the system inaccessible.

b) Table 1 (a, b, c, d, e), Table 2 (b, f, g, h), Table 3 (e, i, j)
### Explanation
The functional dependencies given by the arrows are:
- $a \to \{b, c, d, e\}$ (attribute $a$ determines $b, c, d, e$)
- $b \to \{f, g, h\}$ (attribute $b$ determines $f, g, h$)
- $e \to \{i, j\}$ (attribute $e$ determines $i, j$)

To avoid transitive dependencies ($a \to b \to \{f, g, h\}$ and $a \to e \to \{i, j\}$) and properly normalize the relational schema into 3NF:
- **Table 1:** $(\underline{a}, b, c, d, e)$ with primary key $a$.
- **Table 2:** $(\underline{b}, f, g, h)$ with primary key $b$.
- **Table 3:** $(\underline{e}, i, j)$ with primary key $e$.

This decomposition preserves all functional dependencies and matches choice **b)**.

# 2018S_FE_AM_62
Which of the following represents a part of the total cost of ownership (TCO) for SaaS (Software as a service)?

a) Cost of upgraded installation
b) Data migration cost
c) New software development cost
d) Server hardware investment to host the software
?
b) Data migration cost
### Explanation
In SaaS (Software as a Service), the software is hosted by a third-party vendor and provided as a service over the internet. Therefore, the user does not need to invest in server hardware or new software development, and the vendor typically handles software upgrades. However, the user is still responsible for data migration costs to move their existing data into the SaaS platform.

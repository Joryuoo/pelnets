# 2018S_FE_AM_9
Which of the following addressing modes determines the effective address by adding the value of the instruction address register (program counter) to the value recorded in the address part of the instruction?

a) Absolute addressing
b) Base addressing
c) Indexed addressing
d) Relative addressing
?
d) Relative addressing
### Explanation
- **Relative addressing:** Calculates the effective address by adding the current value of the program counter (instruction address register) to the displacement or address value included in the instruction.
- **Absolute addressing:** Uses the value in the address part of the instruction directly as the effective address.
- **Base addressing:** Adds the value of a base register to the address part of the instruction.
- **Indexed addressing:** Adds the value of an index register to the address part of the instruction.

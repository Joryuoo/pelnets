# 2018S_FE_AM_76
Which of the following is an example of Green by IT?

a) Development of efficient in-house software
b) Development of a powerful in-house Data Centre
c) Using a desktop PC instead of a laptop thin client
d) Using web conferencing instead of travelling to meetings
?
d) Using web conferencing instead of travelling to meetings
### Explanation
"Green by IT" refers to using Information Technology solutions to reduce the environmental footprint and greenhouse gas emissions of other activities across society or a business. Using web conferencing to eliminate the need for physical travel directly reduces carbon emissions from transportation, which perfectly exemplifies Green by IT. "Green of IT" would refer to making IT equipment itself more energy efficient.

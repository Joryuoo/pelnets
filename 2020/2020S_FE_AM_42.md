# 2020S_FE_AM_42
Which of the following is the most appropriate countermeasure against cross-site scripting (XSS) attacks?

a) Avoiding running a program received in an e-mail from an unknown sender
b) Closing all unnecessary ports apart from standard web server ports
c) Filtering out the input that can be interpreted as a script
d) Using HTTPS instead of HTTP as the default protocol on the web server
?
c) Filtering out the input that can be interpreted as a script
### Explanation
Cross-Site Scripting (XSS) is a type of security vulnerability in which malicious scripts are injected into otherwise benign and trusted websites. This happens when an application includes untrusted data in a web page without proper validation or escaping.

The most appropriate and direct countermeasure against XSS attacks is to properly filter, sanitize, and encode all user inputs before they are processed and displayed back to users. By ensuring that any input which can be interpreted as a script (such as HTML tags or JavaScript code) is neutralized or stripped, you prevent the browser from executing the malicious payload.

* **a)** is a general countermeasure against malware and phishing, not XSS.
* **b)** is a countermeasure for preventing unauthorized network access, mitigating port-scanning and network-level attacks.
* **d)** encrypts the data in transit, protecting against eavesdropping and man-in-the-middle attacks, but does not prevent XSS vulnerabilities within the application itself.

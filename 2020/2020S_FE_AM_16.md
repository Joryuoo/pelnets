# 2020S_FE_AM_16
When the number of concurrently running programs is increased in a virtual storage system with a small and insufficient main memory capacity, which of the following is the state in which the overhead of the system increases and the processor utilization of the applications decreases?

a) Bottleneck
b) Fragmentation
c) Paging
d) Thrashing
?
d) Thrashing
### Explanation
Thrashing occurs when a computer's virtual memory subsystem is in a constant state of paging, rapidly exchanging data in memory for data on disk, to the exclusion of most application-level processing. This high overhead of reading and writing to disk causes the performance of the computer to degrade or collapse entirely, severely decreasing processor utilization for actual applications.

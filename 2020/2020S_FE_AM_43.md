# 2020S_FE_AM_43
Which of the following is a method to prevent damage caused by an SQL injection attack?

a) Preventing input characters from being interpreted as characters that have a special meaning in querying or manipulating data in a database
b) Rejecting any input that contains a character string that specifies a higher-level directory (../)
c) Rejecting any input whose total length exceeds the limit
d) Replacing an HTML tag with another character string that is not interpreted as an HTML tag if any input contains an HTML tag
?
a) Preventing input characters from being interpreted as characters that have a special meaning in querying or manipulating data in a database
### Explanation
SQL injection is a vulnerability where an application improperly handles user input, allowing an attacker to interfere with the queries that the application makes to its database. This is typically done by inputting special characters (like single quotes `'`, semicolons `;`, or comments `--`) that alter the logic of the SQL statement. 

To prevent SQL injection, one must sanitize inputs or use parameterized queries (prepared statements). This ensures that user inputs are always treated strictly as literal data rather than executable SQL commands, thereby preventing characters from being interpreted as having special meanings.

* **b)** describes a countermeasure for **Directory Traversal** (or Path Traversal) attacks.
* **c)** is a basic countermeasure commonly used to mitigate **Buffer Overflow** attacks.
* **d)** describes a countermeasure for **Cross-Site Scripting (XSS)** attacks.

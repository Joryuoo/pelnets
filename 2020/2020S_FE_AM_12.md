# 2020S_FE_AM_12
Which one of the following serial transmission methods is used in asynchronous data communication?

a) I2C
b) PCI Express
c) SPI
d) UART
?
d) UART
### Explanation
UART (Universal Asynchronous Receiver-Transmitter) is a hardware communication protocol that uses asynchronous serial communication with configurable speed. I2C and SPI are synchronous serial communication protocols. PCI Express is a high-speed serial computer expansion bus standard, which is synchronous as it uses an embedded clock signal.

# 2020S_FE_AM_46
Which of the following is an appropriate description of a UML use case diagram?

a) It shows the behavior that occurs during object life cycle using finite state transitions.
b) It shows the exchange of messages among objects, and massage transmissions and object lifelines in a time series.
c) It shows the flow from one activity to another activity in systems and work.
d) It shows the scenarios for what the system will do, from the point of view of actors (i.e., external users or machines).
?
d) It shows the scenarios for what the system will do, from the point of view of actors (i.e., external users or machines).
### Explanation
In the Unified Modeling Language (UML), a **use case diagram** is used to describe the functional requirements of a system. It models the system's behavior from the perspective of outside entities known as "actors" (which can be human users or other systems) and shows the various "use cases" (features or scenarios) they interact with.

* **a)** Describes a **State Machine Diagram** (or Statechart Diagram), which models the different states an object goes through during its lifecycle.
* **b)** Describes a **Sequence Diagram**, which models the chronological exchange of messages between objects.
* **c)** Describes an **Activity Diagram**, which models the flow of control or data from one activity to another, similar to a flowchart.

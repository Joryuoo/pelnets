# 2020S_FE_AM_45
SSL/TLS is the industry-standard security technology creating encrypted connections between a web server and a web browser. This is used to maintain data privacy and to protect the information in online transactions. The steps for establishing an SSL/TLS connection are randomly listed as follows:

1. The web server sends a copy of its SSL/TLS certificate to the web browser.
2. SSL/TLS encrypted communication takes place between the web browser and the web server.
3. The web server sends the web browser an acknowledgment to start an SSL/TLS encrypted connection.
4. The web browser checks if the SSL/TLS certificate is trustworthy or not. If it is trustworthy, then the web browser sends a message to the web server requesting to establish an encrypted connection.
5. A web browser tries to connect to the web server secured with SSL/TLS.

Which of the following is the correct step sequence?

a) 1 → 5 → 2 → 3 → 4
b) 1 → 5 → 4 → 3 → 2
c) 5 → 1 → 2 → 3 → 4
d) 5 → 1 → 4 → 3 → 2
?
d) 5 → 1 → 4 → 3 → 2
### Explanation
The process of establishing an SSL/TLS connection is commonly referred to as the SSL/TLS handshake. The correct sequence of operations is as follows:

1. **Step 5**: The client (web browser) initiates the connection request to a secure server.
2. **Step 1**: The server responds by sending a copy of its SSL/TLS certificate (which includes the public key) back to the client.
3. **Step 4**: The browser verifies the authenticity of the certificate. If trusted, it generates a symmetric session key, encrypts it using the server's public key, and sends it to the server (requesting an encrypted connection).
4. **Step 3**: The server decrypts the message using its private key, retrieves the session key, and sends an acknowledgment to the client to begin the encrypted session.
5. **Step 2**: Both parties now have the symmetric session key, and secure encrypted communication begins.

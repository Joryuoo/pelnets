# 2020S_FE_AM_39
![[2020S_FE_AM_Q39_full.png]]

a) The attacker always uses the server IP during the communication and never uses the victim's IP.
b) The attacker always uses the victim's IP during the communication and never uses the server's IP.
c) The attacker always uses the victim's IP during the communication with the server and always uses the server IP during the communication with the victim.
d) The attacker always uses the victim's IP during the communication with the victim and always uses the server IP during the communication with the server.
?
c) The attacker always uses the victim's IP during the communication with the server and always uses the server IP during the communication with the victim.
### Explanation
In a Man-in-The-Middle (MITM) attack, the attacker places themselves between the victim and the server. The goal is to make both parties believe they are communicating directly with each other.

To achieve this:
1. **When communicating with the victim:** The attacker impersonates the server, meaning they must use the server's IP address (or MAC address on a local network) so the victim thinks they are talking to the real server.
2. **When communicating with the server:** The attacker impersonates the victim, meaning they use the victim's IP address so the server thinks it is serving the legitimate end-user.

Thus, the attacker uses the victim's IP when talking to the server, and uses the server's IP when talking to the victim.

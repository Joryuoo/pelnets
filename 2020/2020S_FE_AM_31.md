# 2020S_FE_AM_31
Which device performs protocol conversion between different types of networks, functioning at the layers of transport and above in the OSI basic reference model?

a) Bridge
b) Gateway
c) Repeater
d) Router
?
b) Gateway
### Explanation
A gateway is a network node that operates at the transport layer and above in the OSI model. It is capable of translating between different network architectures and protocols. 

- **Bridge:** Operates at the Data Link layer (Layer 2) and connects two similar networks.
- **Repeater:** Operates at the Physical layer (Layer 1) to regenerate and boost signals.
- **Router:** Operates at the Network layer (Layer 3) to forward data packets between different IP networks based on IP addresses.

# 2020S_FE_AM_77
Which of the following is a process of discovering useful patterns and relationships by the analysis of large volume of data?

a) Brainstorming
b) Data mining
c) Decision tree
d) Document analysis
?
b) Data mining
### Explanation
**Data mining** is the computational process of examining large datasets to identify hidden patterns, correlations, and relationships that can be used to make informed business decisions or predictions. 

* **a)** **Brainstorming** is a group discussion technique to generate ideas.
* **c)** **Decision tree** is a specific modeling technique that can be used *within* data mining, but it is not the process itself.
* **d)** **Document analysis** refers to extracting information from text-based documents.

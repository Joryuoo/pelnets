### Explanation
The system has 3 real memory pages, initially empty. Filling an empty page is not considered a page replacement operation. Therefore, we only count page faults that occur when all 3 frames are full and a replacement happens.
Let's trace the page reference string: `2, 4, 1, 1, 2, 7, 3, 4, 6, 5, 5, 1, 2`.

1. **2**: Frames: `[2, -, -]`. (Initial fill)
2. **4**: Frames: `[2, 4, -]`. (Initial fill)
3. **1**: Frames: `[2, 4, 1]`. (Initial fill)
4. **1**: Hit. Frames: `[2, 4, 1]` (LRU order: 2, 4, 1)
5. **2**: Hit. Frames: `[4, 1, 2]` (LRU order: 4, 1, 2)
6. **7**: Fault. Replaces 4. Frames: `[1, 2, 7]` -> **Replacement #1**
7. **3**: Fault. Replaces 1. Frames: `[2, 7, 3]` -> **Replacement #2**
8. **4**: Fault. Replaces 2. Frames: `[7, 3, 4]` -> **Replacement #3**
9. **6**: Fault. Replaces 7. Frames: `[3, 4, 6]` -> **Replacement #4**
10. **5**: Fault. Replaces 3. Frames: `[4, 6, 5]` -> **Replacement #5**
11. **5**: Hit. Frames: `[4, 6, 5]` (LRU order: 4, 6, 5)
12. **1**: Fault. Replaces 4. Frames: `[6, 5, 1]` -> **Replacement #6**
13. **2**: Fault. Replaces 6. Frames: `[5, 1, 2]` -> **Replacement #7**

Total page faults counting as replacements: 7.

# 2020S_FE_AM_80
Which of the following is software whose copyright is abandoned and that can be used free of charge?

a) Freeware
b) Open Source Software
c) Public Domain Software
d) Shareware
?
c) Public Domain Software
### Explanation
**Public Domain Software** refers to software that has been placed in the public domain because the creator has explicitly abandoned or forfeited their copyright. It can be used, modified, and distributed completely free of charge and without any restrictions.

* **a) Freeware:** Available free of charge, but the author retains the copyright.
* **b) Open Source Software:** The source code is available and can be modified/distributed, but it is released under a specific license (e.g., GPL, MIT) that still enforces copyright conditions.
* **d) Shareware:** Distributed free initially for a trial period, but requires payment for continued or full use.

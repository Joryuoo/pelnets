# 2020S_FE_AM_73
When a production plan is created, it is important to select an appropriate production system. Which of the following is a suitable production system for varied and flexible high-mix low-volume production by single or several operators in charge of all processes?

a) Build-to-order production system
b) Cell production system
c) Continuous production system
d) Individual production system
?
b) Cell production system
### Explanation
The **cell production system** (or cellular manufacturing) involves organizing workstations and equipment into small groups (cells) where a single operator or a small team is responsible for assembling an entire product or a significant portion of it. 
This method is highly flexible and well-suited for high-mix, low-volume production because the "cells" can easily be adapted to assemble different variations of products.

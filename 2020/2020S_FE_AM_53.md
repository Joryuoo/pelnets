# 2020S_FE_AM_53
![[2020S_FE_AM_Q53_full.png]]

a) A → B → E → I → L
b) A → C → D → E → H → K
c) A → C → F → I → L
d) A → C → G → J → L
?
d) A → C → G → J → L
### Explanation
The critical path is the longest path from the start to the end of the project network, determining the minimum project duration.
Let's evaluate the length of the given paths:
- Path a) A(2) → B(3) → E(3) → I(1) → L(3) = 12 days
- Path b) A(2) → C(3) → D(1) → E(3) → H(2) → K(2) = 13 days
- Path c) A(2) → C(3) → F(3) → I(1) → L(3) = 12 days
- Path d) A(2) → C(3) → G(4) → J(2) → L(3) = 14 days

The longest path is A → C → G → J → L with a duration of 14 days, so this is the critical path.

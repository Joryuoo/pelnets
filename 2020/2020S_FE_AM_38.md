# 2020S_FE_AM_38
Which of the following activities targets the DHCP server and exhausts all its available IP address pool so that it cannot provide any IP addresses to its clients?

a) DHCP MAC filtering
b) DHCP snooping
c) DHCP spoofing
d) DHCP starvation
?
d) DHCP starvation
### Explanation
DHCP starvation is an attack that works by broadcasting vast numbers of DHCP requests with spoofed MAC addresses simultaneously. The DHCP server responds to these requests, allocating available IP addresses from its pool until the pool is entirely depleted. As a result, legitimate clients are denied IP addresses and cannot connect to the network.

- **DHCP MAC filtering:** A security feature that allows or denies network access based on the MAC address of the client device.
- **DHCP snooping:** A security feature on switches that prevents rogue DHCP servers from offering IP addresses to clients.
- **DHCP spoofing:** An attack where a rogue DHCP server is introduced into the network to hand out incorrect configuration parameters (like a malicious default gateway or DNS server) to clients.

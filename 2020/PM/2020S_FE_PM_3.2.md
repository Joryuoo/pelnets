### Explanation
**Blank B:** The CASE statement outputs "Follow-up" if the result is NG, and "Ended" if the result is OK (not NG).
- The syntax should be `WHEN Examination.Result = 'NG' THEN 'Follow-up'` and `WHEN Examination.Result != 'NG' THEN 'Ended'`. Option **b** exactly implements this logic.
**Blank C:** The subquery determines the date of the **latest** examination for the specified customer to filter the main query for only the most recent result.
- The latest date is obtained using the `MAX()` aggregate function. Hence, `MAX(Examination.ExamDate)` (option **c**) is the correct choice.

### Explanation

**Blank A:**
In the initial configuration, the IP block given is `203.0.113.0/26`.
- The subnet mask `/26` equates to `255.255.255.192`.
- Total IP addresses in this subnet = $2^{32 - 26} = 64$.
- The network address is `203.0.113.0` and the broadcast address is `203.0.113.63`.
- The number of usable host addresses is $64 - 2 = 62$.

Of these 62 usable addresses, the following are occupied:
1. `203.0.113.62` is assigned to IF1 of the router.
2. `203.0.113.4` (DNS Server)
3. `203.0.113.5` (WWW Server)
4. `203.0.113.6` (File Server)

This means 4 usable IP addresses are already occupied. The number of available public IP addresses that can be assigned to the PCs is $62 - 4 = 58$. Thus, **A = 58** (Option e).

**Blank B:**
In the revised configuration, the subnet `203.0.113.0/27` is assigned to the DMZ.
- The subnet mask `/27` means $2^{32 - 27} = 32$ total IP addresses.
- The network address is `203.0.113.0` and the broadcast address is `203.0.113.31`.
- The usable IP addresses range from `.1` to `.30`.

The problem states that "the last usable IP address of the DMZ is assigned to IF1 of Router1." 
The last usable IP address in this range is `203.0.113.30`. Therefore, **B = 30** (Option b).

**Blank C:**
The subnet mask for the `203.0.113.0/27` DMZ segment is calculated based on the `/27` prefix.
- A `/27` prefix translates to binary `11111111.11111111.11111111.11100000`.
- In decimal, this is `255.255.255.224`. 
Therefore, **C = 224** (Option h).

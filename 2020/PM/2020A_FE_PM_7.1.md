### Explanation
**Blank A, B, C (push and pop functions):**
The global variable `top` is initialized to `-1`. 
- In the `push` function, to insert the first element, `top` must be incremented to `0` before inserting into `stack[top]`. Thus, **Blank A** is `top++` (e) and **Blank B** is `stack[top] = ch` (b).
- In the `pop` function, after the character at `stack[top]` is retrieved, the stack size must be reduced by decrementing `top`. Thus, **Blank C** is `top--` (f).

**Blank D:**
According to step (3) of the conversion algorithm: "If the current character is '(', push it to the stack." The current character is `exp[i]`. So, we must push it using `push(exp[i])`. Thus, **Blank D** is `push(exp[i])` (b).

**Blank E:**
According to step (4) of the algorithm: "If the current character is ')', pop a character from the stack and output it as the last character of postfix notation until '(' is popped."
Inside the `while (stack[top] != '(')` loop, we are popping from the stack and placing it into the `result` array at index `j`. Thus, **Blank E** is `result[j] = pop()` (e).

**Blank F:**
According to step (5): "If the current character is one of the operators, pop all operators from the stack which have a priority higher than or equal to that of the current operator while the stack is not empty and the top of the stack is not '('." 
The code `while (!empty() && stack[top] != '(' && ___F___)` checks this condition. The priority of the operator at the top of the stack (`priority(stack[top])`) must be greater than or equal to (`>=`) the priority of the current operator (`priority(exp[i])`). Thus, **Blank F** is `priority(stack[top]) >= priority(exp[i])` (d).

### Explanation

**Blank A:**
Table 2 defines the outputs for each segment (A-G) to display a given digit. For digit `5`, segments A, C, D, F, and G must be turned ON (`1`), while segments B and E are turned OFF (`0`). Therefore, the output values for segments A and B are `1` and `0` respectively. This corresponds to the sequence `1 0`, which matches choice **c**.

**Blank B:**
Expression 1 determines the output for segment E, which is ON only for digits `0`, `2`, `6`, and `8`. 
The term for input value `6` (binary `0110` for I3, I2, I1, I0) can be written as `¯I3 • I2 • I1 • ¯I0` (NOT I3 AND I2 AND I1 AND NOT I0). 
Looking at the options, choice **c** corresponds to this expression.

**Blank C:**
In the Karnaugh map, we are combining the terms for input values `2` (binary `0010`) and `6` (binary `0110`). 
Comparing these two values:
* Input `2`: `I3=0, I2=0, I1=1, I0=0`
* Input `6`: `I3=0, I2=1, I1=1, I0=0`

The bit `I2` changes between these two inputs (`0` and `1`), while the other bits remain the same. The bits `I3`, `I1`, and `I0` are `0`, `1`, and `0` respectively. Therefore, `I3 I1 I0` is `0 1 0`. This matches choice **a**.

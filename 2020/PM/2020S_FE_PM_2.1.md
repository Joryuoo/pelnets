### Explanation

**Subquestion 1 Analysis:**

This question tests the understanding of resource allocation graphs and deadlocks in operating systems. 
- A **request edge** (from a process to a resource) indicates the process is waiting for the resource.
- An **assignment edge** (from a resource to a process) indicates the resource is currently held by the process.

**For Blank A:** 
Process P2 has assignment edges directed to it from R1, R2, and R4. Thus, P2 is holding resources R1, R2, and R4. The correct option is **b**.

**For Blank B:**
Process P3 has a request edge directed to resource R4. Thus, P3 is waiting for resource R4. The correct option is **d**.

**For Blank C:**
A system is in a deadlock state if there is a circular path in the graph. By tracing the edges, we can find a cycle involving P2, R3, P3, and R4:
1. P2 requests R3 (P2 -> R3)
2. R3 is assigned to P3 (R3 -> P3)
3. P3 requests R4 (P3 -> R4)
4. R4 is assigned to P2 (R4 -> P2)

This forms the circular path: P2 -> R3 -> P3 -> R4 -> P2. The vertices in this path are P2, R3, P3, and R4. The correct option is **d**.

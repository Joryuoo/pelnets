### Explanation

Let's evaluate each option based on the firewall policies and the self zone rules. The self zone rule states: "If the router is a source or a destination, then all traffic is permitted except when there is a zone-pair with a specific service-policy... In this case, there is no specific service-policy."

*   a) When PC-1 (Internet) pings PC-2 (Internal): This initiates traffic from the Internet to the internal network, which is blocked. ICMP packets are dropped, not successful. (False)
*   **b) When PC-1 (Internet) pings PC-3 (Meeting): This initiates traffic from the Internet to the meeting network, which is blocked. ICMP packets are dropped. (True)**
*   c) When PC-1 (Internet) pings R1's IF1 interface (Self zone): Traffic destined for the self zone is permitted by default. The ping is successful, not dropped. (False)
*   d) When PC-2 (Internal) pings PC-1 (Internet): Internal network hosts can initiate *any* type of traffic, including ICMP, and return traffic is allowed. The ping is successful, not dropped. (False)
*   **e) When PC-3 (Meeting) pings PC-1 (Internet): Meeting network hosts can initiate *only* web traffic (HTTP/HTTPS). ICMP is not web traffic, so the ping is dropped. (True)**
*   f) When PC-3 (Meeting) pings R1's IF1 interface (Self zone): Traffic destined for the self zone is permitted by default. The ping is successful, not dropped. (False)

Therefore, the two correct statements are **b** and **e**.

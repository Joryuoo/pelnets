# 2020S_FE_AM_34
There is a PC whose IP address and subnet mask are shown below. Which of the following is the network address of this PC?

IP address: 10.170.70.19
Subnet mask: 255.255.255.240

a) 10.170.70.0
b) 10.170.70.16
c) 10.170.70.31
d) 10.170.70.255
?
b) 10.170.70.16
### Explanation
To find the network address, we perform a bitwise AND operation between the IP address and the subnet mask.

The first three octets of the subnet mask are `255.255.255`, which means the first three octets of the network address will be exactly the same as the IP address: `10.170.70`.

Let's look at the last octet:
- IP Address: `19` in binary is `0001 0011`
- Subnet Mask: `240` in binary is `1111 0000`

Performing a bitwise AND:
`0001 0011` AND `1111 0000` = `0001 0000`

`0001 0000` in decimal is `16`.

Thus, the network address is `10.170.70.16`.

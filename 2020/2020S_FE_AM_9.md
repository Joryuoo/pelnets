# 2020S_FE_AM_9
Which of the following is a characteristic of a RISC processor when it is compared with a CISC processor?

a) The RISC processor uses a micro-code architecture.
b) The RISC processor uses a uniform instruction length to process tasks in a pipeline.
c) The RISC processor uses a variable instruction length to optimize task process capability.
d) The RISC processor uses complex instructions to process various tasks with few instructions.
?
b) The RISC processor uses a uniform instruction length to process tasks in a pipeline.
### Explanation
* **a)** CISC processors typically use a micro-code architecture to execute complex instructions. RISC processors are usually hardwired.
* **b)** This is a key characteristic of **RISC (Reduced Instruction Set Computer)**. Instructions have a uniform length and complete in a single clock cycle, making it highly efficient to execute them in a pipeline.
* **c)** CISC uses variable instruction lengths.
* **d)** CISC uses complex instructions that do more per instruction. RISC uses simple, reduced instructions.

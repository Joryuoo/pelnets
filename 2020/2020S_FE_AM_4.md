# 2020S_FE_AM_4
In machine learning, which of the following best describes the supervised learning?

a) It helps find previously unknown features or patterns on a dataset without pre-existing labels.
b) It tries to find the best action by evaluating each result of possible actions in a specific situation.
c) It is used to get a correct answer for new input data after being trained on a dataset with answer keys.
d) It is used to make a prediction about the actions of a user by collecting and analyzing behavioral data.
?
c) It is used to get a correct answer for new input data after being trained on a dataset with answer keys.
### Explanation
* **a)** Describes **unsupervised learning**, which deals with unlabeled data to find hidden patterns.
* **b)** Describes **reinforcement learning**, which trains models to make sequences of decisions by rewarding desired behaviors.
* **c)** Accurately describes **supervised learning**, which uses labeled datasets (data with answer keys) to train algorithms to classify data or predict outcomes accurately.
* **d)** Describes behavioral analytics or a specific application rather than a core machine learning paradigm.

# 2020S_FE_AM_19
![[2020S_FE_AM_Q19_full.png]]

a) 2^4
b) 2^10
c) 2^20
d) 2^32
?
c) 2^20
### Explanation
A 32-bit virtual address space provides $2^{32}$ bytes of memory.
Each page is 4 k-bytes, which is $4 \times 1,024 = 4 \times 2^{10} = 2^{12}$ bytes.
The number of pages that can be created is the total address space divided by the page size:
$\frac{2^{32}}{2^{12}} = 2^{32 - 12} = 2^{20}$ pages.

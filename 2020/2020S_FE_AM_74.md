# 2020S_FE_AM_74
Which of the following is a control method for a status of "a somewhat large number" or "slightly"?

a) Feedback control
b) Fuzzy control
c) PWM (Pulse Width Modulation) control
d) Sequence control
?
b) Fuzzy control
### Explanation
**Fuzzy control** is based on fuzzy logic, which deals with reasoning that is approximate rather than fixed and exact (like traditional binary logic). It can represent and process ambiguous or qualitative terms like "somewhat large," "slightly," "warm," or "fast" by using degrees of truth. This makes it suitable for complex systems where precise mathematical models are difficult to define but human-like rules can be applied.

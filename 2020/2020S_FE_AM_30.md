# 2020S_FE_AM_30
In a database system, which of the following is the action to undo changes done by transactions executed after the last commit?

a) Commit
b) Roll back
c) Roll forward
d) View
?
b) Roll back
### Explanation
A rollback is an operation that returns the database to a previous consistent state. It cancels and undoes any uncommitted changes made by the transaction since the last `COMMIT` or `ROLLBACK` was executed.

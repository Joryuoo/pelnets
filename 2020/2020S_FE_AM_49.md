# 2020S_FE_AM_49
Among the different types of software tests, which of the following is a test that is performed with the purpose of checking whether or not a location that must not be affected by changes made for software maintenance is affected?

a) Integration test
b) Operational test
c) Regression test
d) System test
?
c) Regression test
### Explanation
**Regression testing** is performed to verify that recent code changes, such as bug fixes, enhancements, or maintenance updates, have not inadvertently affected existing functionalities that were previously working correctly. It ensures that the software has not "regressed" or degraded after modifications.

* **a) Integration test:** Verifies the interfaces and interactions between individual software modules when they are combined.
* **b) Operational test:** Also known as acceptance testing, it is conducted by the end-user or customer in an operational environment to ensure the system meets business requirements.
* **d) System test:** Evaluates the completely integrated system as a whole to verify that it meets the specified system requirements.

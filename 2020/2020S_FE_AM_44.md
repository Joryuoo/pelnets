# 2020S_FE_AM_44
Which of the following is the network security tool that is usually deployed by a network or system administrator and presents itself as a target machine trying to lure attackers to observe their behavior and attack methodology without harming other systems?

a) Honeypot
b) Logic analyzer
c) Protocol analyzer
d) Rootkit
?
a) Honeypot
### Explanation
A **honeypot** is a network security mechanism set up as a decoy to lure cyberattackers. It simulates a vulnerable target system to attract malicious traffic, allowing administrators to study attackers' behavior, identify new attack methodologies, and gather intelligence without putting the actual production systems at risk.

* **b) Logic analyzer** is an electronic instrument used to capture and display multiple signals from a digital system or digital circuit.
* **c) Protocol analyzer** (or packet sniffer) is a tool used to capture and analyze network traffic down to the packet level for troubleshooting and monitoring purposes.
* **d) Rootkit** is a collection of malicious software designed to give an unauthorized user privileged access to a computer while actively hiding its presence.

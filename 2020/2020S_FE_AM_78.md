# 2020S_FE_AM_78

a) x=20,000, y=36,000
b) x=20,000, y=48,000
c) x=40,000, y=36,000
d) x=40,000, y=48,000
?
d) x=40,000, y=48,000
### Explanation
The Break-Even Point (BEP) formula in units is:
**BEP in units = Fixed Costs / (Price per unit - Variable cost per unit)**

For **Company A**:
* BEP = 500
* Price per unit = 120
* Variable cost per unit = 40
* Fixed Costs (x) = ?

500 = x / (120 - 40)
500 = x / 80
x = 500 * 80 = 40,000

For **Company B**:
* BEP = 600
* Price per unit = 140
* Variable cost per unit = 60
* Fixed Costs (y) = ?

600 = y / (140 - 60)
600 = y / 80
y = 600 * 80 = 48,000

Therefore, x = 40,000 and y = 48,000.

# 2020S_FE_AM_50
Which of the following is an explanation of reverse engineering of software?

a) The entire software is reconstructed after analyzing and understanding the existing software.
b) The existing software is analyzed, and its specification and structure are clarified.
c) The internal structure of software is changed without changing the behavior seen from the outside.
d) The source code is created automatically from the design information using a development support tool.
?
b) The existing software is analyzed, and its specification and structure are clarified.
### Explanation
**Reverse engineering** of software is the process of analyzing a system (such as source code or binary executables) to identify its components and their interrelationships, and extracting its specifications, structures, and design information. 

* **a)** Describes **reengineering**, where a system is analyzed (reverse engineering) and then rebuilt or restructured (forward engineering) in a new form.
* **c)** Describes **refactoring**, which is the process of restructuring existing computer code without changing its external behavior.
* **d)** Describes **forward engineering** (or code generation), which translates high-level models or designs into lower-level code.

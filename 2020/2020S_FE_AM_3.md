# 2020S_FE_AM_3
What is the value of the postfix expression below? Here, A, B, C, and D are operands whose values are 4, 3, 5, and 6, respectively. Symbols "+", "−", "*", and "/" are arithmetic operators for addition, subtraction, multiplication, and division, respectively.

A B 2 * + D B / C * −

a) −3
b) 0
c) 3
d) 40/3
?
b) 0
### Explanation
First, substitute the given values into the expression: `4 3 2 * + 6 3 / 5 * −`
A postfix expression is evaluated using a stack, reading from left to right:
1. Read `4`, push to stack. Stack: `[4]`
2. Read `3`, push to stack. Stack: `[4, 3]`
3. Read `2`, push to stack. Stack: `[4, 3, 2]`
4. Read `*`, pop 2 and 3, compute $3 \times 2 = 6$, push 6. Stack: `[4, 6]`
5. Read `+`, pop 6 and 4, compute $4 + 6 = 10$, push 10. Stack: `[10]`
6. Read `6`, push to stack. Stack: `[10, 6]`
7. Read `3`, push to stack. Stack: `[10, 6, 3]`
8. Read `/`, pop 3 and 6, compute $6 \div 3 = 2$, push 2. Stack: `[10, 2]`
9. Read `5`, push to stack. Stack: `[10, 2, 5]`
10. Read `*`, pop 5 and 2, compute $2 \times 5 = 10$, push 10. Stack: `[10, 10]`
11. Read `−`, pop 10 and 10, compute $10 - 10 = 0$, push 0. Stack: `[0]`

The final result is 0.

# 2017A_FE_16
![[2017A_FE_AM_Q16_p1.png]]

a) 9.5 ; 6.25
b) 9.0 ; 7.0
c) 11.0 ; 7.25
d) 11.5 ; 8.0
?
c) 11.0 ; 7.25
### Explanation
Given the burst times: P1=9, P2=5, P3=7, P4=4.

**1. FCFS (First-Come, First-Serve)**
Since processes arrive in the order P1, P2, P3, P4 at the same time:
* P1 waits: 0 ms
* P2 waits: 0 + 9 = 9 ms
* P3 waits: 9 + 5 = 14 ms
* P4 waits: 14 + 7 = 21 ms
Average Wait Time = (0 + 9 + 14 + 21) / 4 = 44 / 4 = **11.0 ms**

**2. SJF (Shortest-Job-First)**
Sort the processes by shortest burst time: P4(4), P2(5), P3(7), P1(9).
* P4 waits: 0 ms
* P2 waits: 0 + 4 = 4 ms
* P3 waits: 4 + 5 = 9 ms
* P1 waits: 9 + 7 = 16 ms
Average Wait Time = (0 + 4 + 9 + 16) / 4 = 29 / 4 = **7.25 ms**

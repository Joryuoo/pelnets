# 2017S_FE_64
Among the “four categories” of the enterprise architecture, which of the following completes the list after business architecture, technology architecture, and application architecture?

a) Bus architecture
b) Data architecture
c) Software architecture
d) System architecture
?
b) Data architecture
### Explanation
**Enterprise Architecture (EA)** is typically divided into four primary domains:
1. **Business Architecture (BA):** Business strategy, governance, and organization.
2. **Data Architecture (DA):** Structure of logical and physical data assets and data management resources.
3. **Application Architecture (AA):** Blueprint for individual applications, their interactions, and relationships.
4. **Technology Architecture (TA):** Software and hardware capabilities required to support deployment of business, data, and application services.

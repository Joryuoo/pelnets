# 2017A_FE_29
Which of the following can change the deadlock state of the transaction back to the normal state?

a) Commit
b) Drop
c) Rollback
d) Roll Forward
?
c) Rollback
### Explanation
When a **deadlock** occurs (two or more transactions are permanently blocking each other by waiting for resources held by the other), the DBMS resolves it by aborting one of the deadlocked transactions. The aborted transaction is subjected to a **Rollback**, which undoes all its partial changes, releases its held locks, and brings the system back to a normal state so the other transactions can proceed.

**Why the others are incorrect:**
*   **Commit**: Finalizes a successful transaction, making its changes permanent. Cannot be applied to a deadlocked transaction.
*   **Drop**: A DDL command to delete a database object entirely (like a table).
*   **Roll Forward**: Applies changes from the transaction log to recover a database to a later point in time (used in media recovery), not for resolving deadlocks.

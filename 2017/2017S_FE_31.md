# 2017S_FE_AM_31
![[2017S_FE_AM_Q31_full.png]]

a) SELECT AVG(Quantity) FROM ShipmentRecord WHERE ProductNumber = 'NP200'
b) SELECT COUNT(*) FROM ShipmentRecord
c) SELECT MAX(Quantity) FROM ShipmentRecord
d) SELECT SUM(Quantity) FROM ShipmentRecord WHERE Date = '2015-10-11'
?
b) SELECT COUNT(*) FROM ShipmentRecord
### Explanation
Let's evaluate the result of each SQL statement:
- **a)** Calculates the average quantity for 'NP200'. The quantities are 3 and 1. Average = (3 + 1) / 2 = 2.
- **b)** Counts the total number of records in the `ShipmentRecord` table. Total records = 4.
- **c)** Finds the maximum quantity across all records. Max quantity = 3.
- **d)** Calculates the sum of quantities for the date '2015-10-11'. The quantities are 1 and 2. Sum = 1 + 2 = 3.

The largest value is 4, which is obtained by statement **b**.

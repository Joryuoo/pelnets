# 2017A_FE_AM_49
Which of the following is a method for analyzing a source and object codes, and extract program specifications and design information?

a) Reengineering
b) Refactoring
c) Restructuring
d) Reverse engineering
?
d) Reverse engineering
### Explanation
**Reverse engineering** is the process of analyzing a subject system (like source code or object code) to identify the system's components and their interrelationships, and to create representations of the system in another form or at a higher level of abstraction (such as extracting design information or specifications).

* **Reengineering:** The examination and alteration of a system to reconstitute it in a new form, and the subsequent implementation of the new form (often involves reverse engineering followed by forward engineering).
* **Refactoring:** The process of restructuring existing computer code without changing its external behavior to improve nonfunctional attributes of the software.
* **Restructuring:** Modifying software structure (e.g., to make it better structured) without changing its functionality, similar to refactoring but often applied at a broader system level.

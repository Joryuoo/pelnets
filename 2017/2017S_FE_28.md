# 2017S_FE_28
Which of the following is an appropriate explanation of schema in RDBMS?

a) It is a collective term for database operations, such as insert, update, deletion, and selection of data.
b) It is a collective term for various constraints for maintaining consistency of the database.
c) It is a set of data definitions, such as the nature of data, the format of data, and the relation with other data.
d) It is not a real table, but a virtual table from the users’ viewpoint.
?
c) It is a set of data definitions, such as the nature of data, the format of data, and the relation with other data.
### Explanation
A database **schema** is the structural definition of a database system. It encompasses definitions for tables, fields (including data types and formats), relationships, indexes, views, and integrity constraints.

- **Choice (a)** describes **Data Manipulation Language (DML)** operations.
- **Choice (b)** describes **integrity constraints**, which are only a subset of what a schema defines.
- **Choice (d)** describes a **View**.

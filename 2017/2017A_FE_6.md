# 2017A_FE_6
When Bubble sort algorithm is used, how many exchange operations are required to sort the following numbers in ascending order?

9, 2, 13, 21, 3, 0

a) 7
b) 8
c) 9
d) 10
?
c) 9
### Explanation
In Bubble Sort, the total number of exchange operations is equal to the total number of **inversions** in the array. An inversion is a pair of numbers where a larger number appears before a smaller number. 

Let's count the inversions for each number in `[9, 2, 13, 21, 3, 0]`:
*   `9` is greater than: `2`, `3`, `0` (3 inversions)
*   `2` is greater than: `0` (1 inversion)
*   `13` is greater than: `3`, `0` (2 inversions)
*   `21` is greater than: `3`, `0` (2 inversions)
*   `3` is greater than: `0` (1 inversion)
*   `0` is greater than nothing.

Total inversions = `3 + 1 + 2 + 2 + 1 = 9`. 
Since there are 9 inversions, Bubble Sort will perform exactly 9 exchange operations to sort the array.

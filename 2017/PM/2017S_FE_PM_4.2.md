### Explanation
**Blank C:** `d` (`100 - 100 * EconomySeatsReserved / EconomySeats`)
The problem requires calculating the vacancy rate, which is the percentage of seats that are *not* reserved. 
- Vacant seats = `EconomySeats - EconomySeatsReserved`
- Vacancy rate (%) = `((EconomySeats - EconomySeatsReserved) / EconomySeats) * 100`

If we distribute the division and multiplication, this formula simplifies to:
`100 - (EconomySeatsReserved / EconomySeats) * 100`, which matches option `d`. 
- Option `a` subtracts reserved seats from 100 before dividing, which is mathematically invalid.
- Option `c` computes the reserved rate percentage, not the vacancy rate.

**Blank D:** `d` (`R.FlightID = F.FlightID AND R.SegmentNumber = F.SegmentNumber`)
To accurately join the `Reservation` table (`R`) with the `Flight` table (`F`), we must match the exact segment of the exact flight. Since the primary key identifying a unique flight segment requires both `FlightID` and `SegmentNumber`, both columns must be equated in the `ON` clause. 

**Blank E:** `b` (`FlightDate = :SpDate`)
The report specifies it must display flight segments "on a specific day... Here, the specific date is given by the host variable :SpDate". Thus, we filter the results by setting `FlightDate = :SpDate` in the `WHERE` clause.

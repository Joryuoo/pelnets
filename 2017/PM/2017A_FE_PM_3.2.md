### Explanation
**Blank C:** The query calculates the average net income per course. To do this, it needs to group the records in the `BATCH` table by `CourseCode`. The correct SQL clause for this operation is `GROUP BY`.
- d) `WHERE` is used to filter individual records before grouping, not to specify the grouping column.

**Blank D:** The query filters the grouped results to only include those where the average net income is greater than 15,000. In SQL, filtering based on an aggregate function (like `AVG`) after the data has been grouped must be done using the `HAVING` clause.
- d) The `WHERE` clause cannot be used with aggregate functions directly to filter grouped results.

### Explanation

**Blank B:**
The subnet for the server farm is given as `10.1.1.16/28`.
A `/28` prefix length means there are 32 - 28 = 4 bits allocated for the host portion of the address.
The total number of IP addresses in this subnet is 2^4 = 16.
We must subtract 2 addresses: the network address (all 0s in host portion) and the broadcast address (all 1s in host portion), leaving 14 usable IP addresses.
The question also states to exclude the address of the router (the default gateway), which takes up 1 more address.
Maximum IPs for servers = 14 - 1 = 13.
Therefore, the correct choice is **c) 13**.

**Blank C:**
The DNS server is assigned the IP address `10.1.1.31/28` (according to Table 2).
Let's analyze the `10.1.1.16/28` subnet boundaries:
- **Network address:** `10.1.1.16` (Host bits: `0000`)
- **First usable IP:** `10.1.1.17`
- **Last usable IP:** `10.1.1.30`
- **Broadcast address:** `10.1.1.31` (Host bits: `1111`)

The IP address `10.1.1.31` is the broadcast address for this subnet, meaning it cannot be assigned to a specific host like the DNS server. This explains why the hosts cannot access the DNS server.
Therefore, the correct choice is **c) The DNS server has been configured with the broadcast address of the subnet.**

### Explanation
**Blank A:** `b` (`FlightID`)
To group segments of the same flight together, the `GROUP BY` clause must use the unique identifier for the flight, which is `FlightID`. A direct flight will have one record per `FlightID`, while a one-stop flight will have two records sharing the same `FlightID`.

**Blank B:** `a` (`COUNT(*)`)
The problem states that the management wants to display "all of the one-stop flights". According to the description, a one-stop flight is registered in two rows of records. After grouping by `FlightID`, we need to filter for groups that have exactly 2 records. This is achieved using the aggregate function `HAVING COUNT(*) = 2`.
- Option `c` (`SegmentNumber`) is incorrect because it's not an aggregate function that counts rows.
- Option `d` (`SUM(FlightID)`) and `e` (`SUM(SegmentNumber)`) are mathematically irrelevant for counting the number of records.

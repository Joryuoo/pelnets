### Explanation

This question asks for the keys used to ensure the **confidentiality** of the e-mail contents using a symmetric session key.

**Blank B:**
The flowchart at the Sender Side shows "Generate _B_". The text states: "In PGP, a symmetric 128-bit session key is generated and used each time a new e-mail is sent." This key is used to encrypt the message. Thus, **B** is the **Session key** (choice **g**).

**Blank C:**
To safely transmit this session key to the receiver, the session key itself must be encrypted. The text states: "The session key is encrypted by using the receiver's public key." In the flowchart, this corresponds to "Encrypt B using C". Therefore, **C** is the **Receiver's public key** (choice **d**).

**Blank D:**
At the Receiver Side, the receiver must decrypt the session key to access the message. Since the session key was encrypted with the receiver's public key, it can only be decrypted using the corresponding private key belonging to the receiver. In the flowchart, this corresponds to "Decrypt B using D". Therefore, **D** is the **Receiver's private key** (choice **c**).

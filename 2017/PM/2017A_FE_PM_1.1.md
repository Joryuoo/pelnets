### Explanation

To check the authenticity of an e-mail, PGP uses a digital signature. Let's trace the steps in **Figure 1 (Sender side)**:

1. The e-mail message is passed through a hash function to generate a hash code. According to the text, "SHA-1 generates a 160-bit hash code". Therefore, **A1** is **SHA-1**.
2. The hash code is encrypted using the "RSA algorithm using the sender's private key". Therefore, **A2** is the **RSA algorithm**.
3. The encrypted hash code (digital signature) is concatenated (`||`) with the e-mail message, and the result is passed through a compression algorithm (the ZIP algorithm).

Now, let's trace **Figure 2 (Receiver side)**:

1. The receiver first decompresses the incoming message to separate the digital signature from the e-mail message. Therefore, **A3** must be the **Decompression algorithm**.
2. The receiver then decrypts the digital signature using the sender's public key to get the original hash code.
3. The receiver independently runs SHA-1 on the decompressed e-mail message to generate a new hash code.
4. The two hash codes are compared for authenticity.

Matching these to the options for A1, A2, and A3:
- A1 = SHA-1
- A2 = RSA algorithm
- A3 = Decompression algorithm

This corresponds to choice **d**.

### Explanation
**Blank D:** Program 2 runs daily as a batch job to automatically cancel "held" seats if the user hasn't paid the remaining 90% "by 3 days before the departure date". The batch job checks for buses departing the day after tomorrow (`&TodayPlus2`). Therefore, the program must first read the `Bus` file where `Bus.DepartureDate = &TodayPlus2` (g). Choice (f) `Bus.DepartureDate <= &TodayPlus2` is incorrect because the program runs daily; checking all previous or future dates would erroneously process buses that already departed or haven't reached the deadline yet.

**Blanks E and F:** Once a target bus is found, the system needs to find all bookings on that specific bus that are still in the "held" state. 
- **Blank E:** It matches the `Booking` file with the current `Bus` record using `Booking.BusNo = Bus.BusNo` (b).
- **Blank F:** It filters for bookings that haven't been finalized using `Booking.SeatStatus = "held"` (d).

*(Note: The conditions for E and F are connected by `AND` and can be interchanged).*

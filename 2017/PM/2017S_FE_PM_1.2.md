### Explanation
**Blank D:** We need to find the shared secret key $K$. 
Eve knows $R1 = 3$, $p = 11$, $g = 7$, and she obtained Bob's secret value $y = 3$.
The shared secret key $K$ is calculated by Bob using Alice's public key $R1$ and his own secret $y$:
$K = (R1)^y \pmod p$.
Since Eve knows both $R1$ and $y$, she can calculate $K$:
$K = 3^3 \pmod{11} = 27 \pmod{11} = 5$.
So, $K = 5$. This maps to choice **d**.

**Blank E:** We need to find Alice's secret value $x$.
Alice calculates her public key $R1$ using $R1 = g^x \pmod p$. We know $R1 = 3$, $g = 7$, and $p = 11$.
So, $3 = 7^x \pmod{11}$.
Looking at Table 2 for the values of $7^n \pmod{11}$, we need to find which $n$ gives a result of $3$:
- The table shows that for $n = 4$, $7^4 \pmod{11} = 3$.
Thus, $x = 4$. This maps to choice **c**.

**Blank F:** We need to find Bob's public key $R2$.
Bob calculates his public key using $R2 = g^y \pmod p$.
We know $g = 7$, $p = 11$, and $y = 3$.
Looking at Table 2 for the value of $7^3 \pmod{11}$:
- The table shows that for $n = 3$, $7^3 \pmod{11} = 2$.
Thus, $R2 = 2$. This maps to choice **a**.

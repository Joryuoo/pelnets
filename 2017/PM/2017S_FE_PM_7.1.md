### Explanation

**Blank A:**
In the `analyse(char* line)` function, the string `line` is processed character by character in a loop. The condition `if (_____A_____)` is used to check if a word has ended. Based on the program description, words are separated by white-spaces. Therefore, we should check if the current character `line[i]` is a space character (`' '`). When this condition is met, the current word `s` is terminated with a null character and processed. The correct choice is **a) `line[i] == ' '`**.

**Blank B:**
If the character is not a space, it belongs to the current word being assembled. We need to copy `line[i]` into `s[j]`, and then increment both indices to prepare for the next character. In C, `s[j++] = line[i++]` accomplishes exactly this, assigning the character and then post-incrementing both `i` and `j`. The correct choice is **b) `s[j++] = line[i++]`**.

**Blank C:**
In `setCount(char* s)`, when a new unique word is encountered, it is added to the list, its frequency is set to 1, and `wordCount` is incremented. The code checks `if (_____C_____) { highestFreq = 1; }`. This should happen when the very first unique word in the entire string is processed, which means the maximum frequency so far needs to be initialized from 0 to 1. Before this point, `highestFreq` is 0, and `wordCount` has not been incremented yet. Therefore, when `wordCount == 0`, we know it's the first word overall. The correct choice is **c) `wordCount == 0`**. 

**Blanks D and E:**
In `outputWords()`, nested loops are used to output words grouped in ascending order of their frequency, and within each frequency group, they appear in ASCII-code order (since they were previously sorted by `sortByWords()`).
- The outer loop `for(i = 1; i <= _____D_____; i++)` iterates over all possible frequencies. The maximum frequency any word could have is tracked in `highestFreq`. Thus, we should loop up to `highestFreq`. The correct choice for **D** is **a) `highestFreq`**.
- The inner loop `for(j = 0; j < _____E_____; j++)` iterates over all unique words stored in the `word` array to check if their frequency matches `i`. The total number of unique words is stored in `wordCount`. Thus, we should iterate up to `wordCount`. The correct choice for **E** is **c) `wordCount`**.

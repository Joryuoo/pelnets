# 2017S_FE_25
Which of the following logic circuits meets the condition described below?

[Condition]
A light is turned on and off by using switches A and B located at the top and bottom of the stairs. The light can be turned on and off by using one switch, regardless of the status of the other switch.

a) AND
b) NAND
c) NOR
d) XOR
?
d) XOR
### Explanation
The scenario described is a classic "two-way switch" or "staircase switch" problem. To toggle the state of the light regardless of the other switch's position, you must use an XOR (Exclusive OR) or XNOR logic.

If we define the switch positions as 0 and 1, flipping a single switch will always invert the XOR output. For instance, if `A=0` and `B=0`, output is `0`. If we change `B` to `1`, output becomes `1`. If we change `A` to `1` (so `1` and `1`), output becomes `0`. Since toggling either switch reliably toggles the output, it exactly matches the XOR behavior.

# 2017A_FE_14
There exists a system composed of two processing devices. What is the difference in availability between the system that works when either of the devices functions normally and the one when both devices function normally? Here, the availability for both devices is 0.9, and factors other than the processing devices can be ignored.

a) 0.09
b) 0.10
c) 0.18
d) 0.19
?
c) 0.18
### Explanation
The availability of each individual device is 0.9.

**When both devices must function normally (Series Configuration):**
The availability is the product of their individual availabilities:
$A_{series} = 0.9 \times 0.9 = 0.81$

**When either device can function normally (Parallel Configuration):**
The system only fails if BOTH devices fail. The probability of one device failing is $(1 - 0.9) = 0.1$.
$A_{parallel} = 1 - (0.1 \times 0.1) = 1 - 0.01 = 0.99$

**Difference:**
$0.99 - 0.81 = 0.18$

# 2017S_FE_44
Which of the following is an appropriate test to verify the efficacy of security measures by attempting an actual intrusion?

a) Exception test
b) Functional test
c) Penetration test
d) Stress test
?
c) Penetration test
### Explanation
A **Penetration test** (or pen test) is a simulated, authorized cyberattack against a computer system to check for exploitable vulnerabilities. It actively tests the efficacy of security measures by attempting an actual intrusion into the system.

* **a) Exception test:** Testing how a system handles errors or exceptional conditions.
* **b) Functional test:** Testing the software against its functional requirements and specifications.
* **d) Stress test:** Testing a system's stability and reliability under extreme conditions (e.g., abnormally high traffic or processing loads).

# 2017S_FE_AM_16
Consider a RAID 0 (i.e., block-level striping without parity or mirroring) system with two disks; when data is distributed evenly across the two disks and both disks have a failure rate of 0.1%, what is the overall failure rate (as a percentage) of this RAID system? Here, the overall failure rate refers to the probability that the system fails to obtain data from either of the disks.

a) 0.0001
b) 0.0100
c) 0.1999
d) 1.9990
?
c) 0.1999
### Explanation
In a RAID 0 configuration, data is striped across all disks with no redundancy. Therefore, if **any** single disk fails, the entire system fails to obtain the data.

To find the probability of system failure, we can first calculate the probability that the system *succeeds* (i.e., both disks work):
1. Probability that a single disk works = 100% - 0.1% = 99.9% = 0.999
2. Probability that BOTH disks work = 0.999 × 0.999 = 0.998001

The probability of system failure is the complement of this:
* Failure Rate = 1 - 0.998001 = 0.001999

Converting this to a percentage:
* 0.001999 × 100 = 0.1999%

# 2017S_FE_27
Which of the following is a database design that consists of multiple tables, with rows and columns that are linked together through matching data stored in each table?

a) Hierarchical database
b) Network database
c) Object-oriented database
d) Relational database
?
d) Relational database
### Explanation
A relational database uses tables consisting of rows (records/tuples) and columns (attributes/fields). Relationships between different tables are established using matching data values, specifically by linking Primary Keys to Foreign Keys.

- **Hierarchical database**: Organizes data in a tree-like structure with parent-child relationships.
- **Network database**: Allows records to have multiple parents and child records, organized in a graph.
- **Object-oriented database**: Represents data as objects, similar to object-oriented programming.

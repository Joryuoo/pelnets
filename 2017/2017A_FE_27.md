# 2017A_FE_27
Which of the following is an appropriate description of the mapping between the relational model and relational database as its implementation?

a) A domain is mapped to a character type or a character string type.
b) A relation is mapped to a table.
c) Attributes and columns are ordered from left to right.
d) Neither tuples nor rows have duplicates.
?
b) A relation is mapped to a table.
### Explanation
In the relational database model, a mathematical **relation** maps directly to a **table** in the physical implementation. 

**Why the others are incorrect:**
*   **a**: A domain represents the set of allowable values for an attribute and maps to any defined data type, not just character strings.
*   **c**: In the mathematical relational model, attributes are an unordered set. While table columns are physically ordered left to right, their theoretical order does not matter.
*   **d**: While a mathematical relation theoretically cannot have duplicate tuples (being a set), actual implementations of relational databases (like SQL tables without a primary key) *can* allow duplicate rows.

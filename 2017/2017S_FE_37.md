# 2017S_FE_AM_37
Alan would like to send an encrypted message to Bob using an asynchronous encryption scheme. Which of the following must occur before Alan sends the encrypted message to Bob? Here, Alan has already proven to Bob with the digital signature that Alan is the person who sends the message to Bob.

a) Alan provides his private key to Bob.
b) Alan provides his public key to Bob.
c) Bob provides his private key to Alan.
d) Bob provides his public key to Alan.
?
d) Bob provides his public key to Alan.
### Explanation
In an **asynchronous (asymmetric or public-key) encryption scheme**, the sender encrypts the message using the receiver's **public key**. The receiver then decrypts it using their own **private key**. 

Since Alan wants to send an encrypted message to Bob, Alan must first obtain Bob's public key to perform the encryption. 

- **a) & c)** Private keys must never be shared. 
- **b)** Alan providing his public key to Bob would allow Bob to encrypt messages sent to Alan, but it does not help Alan encrypt a message for Bob.

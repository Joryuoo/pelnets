# 2017A_FE_AM_32
Which of the following describes an IPv6 feature not existing in IPv4?

a) 128-bit addressing is introduced for the IP address space.
b) An IP address is represented as a pair of a network address and a subnet mask.
c) Private addresses are introduced to use IP addresses efficiently.
d) Subnet masks are introduced to use the address space efficiently.
?
a) 128-bit addressing is introduced for the IP address space.
### Explanation
* **IPv6 addresses** are 128-bit identifiers, which allows for a vastly larger number of unique IP addresses compared to IPv4.
* **IPv4** uses 32-bit addressing.
* Options b, c, and d describe concepts (network/subnet division, private IP addresses, and subnet masks) that are heavily utilized in IPv4 to manage its limited 32-bit address space.

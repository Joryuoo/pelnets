# 2017S_FE_AM_36
Which of the following is an appropriate description of the netstat utility?

a) It displays active TCP connections.
b) It displays the contents of the DNS resolver cache.
c) It displays the mapping between IP addresses and corresponding MAC addresses in the cache.
d) It displays the route path to the specified destination and measures the packet delays.
?
a) It displays active TCP connections.
### Explanation
The `netstat` (network statistics) command-line utility displays network connections (both incoming and outgoing), routing tables, and a number of network interface and network protocol statistics, including active TCP connections.

- **b) DNS resolver cache**: Displayed using `ipconfig /displaydns` on Windows.
- **c) IP to MAC mapping**: Displayed using the `arp` utility (e.g., `arp -a`).
- **d) Route path and delays**: Displayed using utilities like `tracert` (Windows) or `traceroute` (Linux/Unix).

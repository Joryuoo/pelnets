# 2017S_FE_AM_20
![[2017S_FE_AM_Q20_full.png]]

a) A+B*C/D
b) A+B*C/T2
c) B*C+A/D
d) B*C+T1/D
?
a) A+B*C/D
### Explanation
A quadruplet in this context follows the format `(Operator, Operand 1, Operand 2, Result)`, meaning `Result = Operand 1 [Operator] Operand 2`.

Let's evaluate the given sequence step-by-step:
1. `(*, B, C, T1)` evaluates to `T1 = B * C`
2. `(/, T1, D, T2)` evaluates to `T2 = T1 / D`. Substituting `T1`, we get `T2 = (B * C) / D`.
3. `(+, A, T2, T3)` evaluates to `T3 = A + T2`. Substituting `T2`, we get the final expression `T3 = A + (B * C) / D`.

In standard mathematical notation (following standard order of operations), this is written as `A + B * C / D`.

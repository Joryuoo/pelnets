# 2017A_FE_AM_35
Which of the following is a form of malware that requires a host in order to propagate from one computer to another?

a) Trojan horses
b) Viruses
c) Worms
d) Zombies (Bots)
?
b) Viruses
### Explanation
* **Viruses:** Malicious software that require a host file or executable program to propagate. When the host file is executed, the virus runs and infects other files.
* **Worms:** Standalone malware that self-replicate and spread across networks automatically without needing a host program or user interaction.
* **Trojan horses:** Malware disguised as legitimate or benign software. They do not self-replicate.
* **Zombies (Bots):** Computers infected with malware that allows them to be remotely controlled by an attacker, often as part of a botnet.

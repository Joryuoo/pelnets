# 2017A_FE_22
Which of the following is a logic gate combination that provides an output 1 when both inputs are 0?

a) AND or XOR
b) NAND or XOR
c) NOR or XNOR
d) OR or XNOR
?
c) NOR or XNOR
### Explanation
To get an output of 1 when both inputs are 0:
*   **NOR**: The output is 1 only when both inputs are 0.
*   **XNOR**: The output is 1 when both inputs are the same (either both 0 or both 1).

**Why the others are incorrect:**
*   **AND**: Output is 0 when both inputs are 0.
*   **OR**: Output is 0 when both inputs are 0.
*   **NAND**: Output is 1 when both inputs are 0, but it is paired with XOR which gives 0.
*   **XOR**: Output is 0 when both inputs are the same.

# 2017S_FE_49
Which of the following is an appropriate description concerning test data for the black box testing?

a) Test data is created based on branch coverage.
b) Test data is created based on condition coverage.
c) Test data is created based on external specification.
d) Test data is created based on program structure.
?
c) Test data is created based on external specification.
### Explanation
**Black-box testing** is a method of software testing that examines the functionality of an application without peering into its internal structures or workings. Therefore, the test cases and test data are derived purely from the **external specifications**, requirements, and design documents. 

* **a), b), and d):** Branch coverage, condition coverage, and program structure are concepts used in **white-box testing**, where the tester has full visibility into the internal code logic and tests specific execution paths.

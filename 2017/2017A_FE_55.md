# 2017A_FE_AM_55
![[2017A_FE_AM_Q55_p1.png]]

a) 18
b) 24
c) 30
d) 32
?
a) 18
### Explanation
The function point value is calculated by summing the products of the count and weighting coefficient for each function type, and then multiplying the total by the correction coefficient of complexity.

**Step 1: Calculate the unadjusted total:**
* External input: 1 × 4 = 4
* External output: 2 × 5 = 10
* Internal logical file: 1 × 10 = 10
* External interface file: 0 × 7 = 0
* External inquiry: 0 × 4 = 0

Total unadjusted value = 4 + 10 + 10 = 24

**Step 2: Apply the correction coefficient:**
Function point value = Unadjusted value × correction coefficient
Function point value = 24 × 0.75 = 18.

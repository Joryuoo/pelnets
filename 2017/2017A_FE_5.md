# 2017A_FE_5
![[2017A_FE_AM_Q5_full.png]]

a) A (i, j) → B (7-i, 7-j)
b) A (i, j) → B (7-j, i)
c) A (i, j) → B (i, 7-j)
d) A (i, j) → B (j, 7-i)
?
d) A (i, j) → B (j, 7-i)
### Explanation
The transformation changes Matrix A into Matrix B, which corresponds to rotating the matrix **90 degrees clockwise**.
Let's analyze a few elements from Matrix A (size 6x6) and track where they end up in Matrix B:
*   The top-left element in A at `(1, 1)` moves to the top-right in B at `(1, 6)`.
    *   Testing options for `i=1, j=1`:
        *   a) `B(6, 6)`
        *   b) `B(6, 1)`
        *   c) `B(1, 6)` -> Matches
        *   d) `B(1, 6)` -> Matches
*   The bottom-left element in A at `(6, 1)` moves to the top-left in B at `(1, 1)`.
    *   Testing options for `i=6, j=1`:
        *   c) `B(6, 6)` 
        *   d) `B(1, 1)` -> Matches

Option **d** correctly describes the 90-degree clockwise rotation logic for an $N \times N$ matrix, which maps coordinates `(i, j)` to `(j, N+1-i)`. Since $N=6$, it is `B(j, 7-i)`.

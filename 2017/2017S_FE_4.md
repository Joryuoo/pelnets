# 2017S_FE_AM_4
For two sets A and B of cardinalities 3 and 2, how many maps from A to B exist?

a) 1
b) 5
c) 8
d) 9
?
c) 8
### Explanation
A map (or function) from set A to set B assigns exactly one element of B to each element of A.
Let |A| = 3 (the number of elements in set A) and |B| = 2 (the number of elements in set B).
For each of the 3 distinct elements in set A, there are exactly 2 possible independent choices of mapping it to an element in set B.
Thus, the total number of distinct maps from A to B is calculated by multiplying the number of choices for each element in A:
|B|^|A| = 2^3 = 2 × 2 × 2 = 8.

Therefore, the correct choice is c.

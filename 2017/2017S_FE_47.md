# 2017S_FE_47
Which of the following are components of a UML2.x (including 2.0 and later versions) state diagram?

a) Message and Activity
b) Message and Transition
c) State and Message
d) State and Transition
?
d) State and Transition
### Explanation
In a **UML State Diagram** (or State Machine Diagram), the primary components are **States** (representing a condition or situation during the life of an object) and **Transitions** (representing the relationship between two states indicating that an object in the first state will perform certain actions and enter the second state when a specified event occurs). 

* **Message:** This is a core component found in sequence or communication diagrams.
* **Activity:** This is the core component of an activity diagram.

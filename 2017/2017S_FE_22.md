# 2017S_FE_22
Which of the following is a method that performs integration of the modules that configure a program during execution of the program?

a) Dynamic linking
b) Interpreter
c) Overlay
d) Static linking
?
a) Dynamic linking
### Explanation
Dynamic linking is a method where the integration of external modules (or libraries) into a program is delayed until the program is actually executed or loaded into memory. This contrasts with static linking, where the modules are resolved and copied into the executable during compile/build time.

- **Interpreter**: Translates and executes code line-by-line rather than compiling and linking it into an executable.
- **Overlay**: A technique for running programs larger than the available physical memory by swapping parts of the program in and out.
- **Static linking**: Binds external libraries to the program at compile time.

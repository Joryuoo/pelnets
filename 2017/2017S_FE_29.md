# 2017S_FE_29
Which of the following is an appropriate normalization form (NF) used in a relational database in which every non-prime attribute must be dependent only on the primary key, and no non-prime attribute is dependent on another non-prime attribute?

a) 1NF
b) 2NF
c) 3NF
d) BCNF
?
c) 3NF
### Explanation
Third Normal Form (3NF) is achieved when a relational database table is in 2NF, and all its attributes are functionally dependent only on the primary key (i.e., no transitive dependencies). The condition "no non-prime attribute is dependent on another non-prime attribute" specifically describes the elimination of transitive dependencies.

- **1NF**: Ensures each cell contains atomic (indivisible) values and eliminates repeating groups.
- **2NF**: Achieves 1NF and ensures no partial dependencies (non-prime attributes must depend on the *entire* primary key).
- **BCNF**: A stricter version of 3NF where for every functional dependency `X -> Y`, `X` must be a superkey.

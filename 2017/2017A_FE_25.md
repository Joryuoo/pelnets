# 2017A_FE_25
In a DBMS, which of the following functions decides the schema?

a) Definition function
b) Maintenance function
c) Recovery function
d) Security function
?
a) Definition function
### Explanation
In a Database Management System (DBMS), the **Data Definition function** (using DDL - Data Definition Language) is responsible for defining, altering, and dropping the structure of the database objects, such as tables, schemas, and views.

**Why the others are incorrect:**
*   **Maintenance function**: Handles routine database operations like backups, optimizations, and reorganizations.
*   **Recovery function**: Restores the database to a consistent state after a failure using logs and checkpoints.
*   **Security function**: Manages user access, permissions, and safeguards the data against unauthorized access.

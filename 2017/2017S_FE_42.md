# 2017S_FE_42
A user has just received a file named "image.jpg." When inspected more closely, it is revealed that the file name is actually "image.jpg                .exe," with spaces between the fake .jpg suffix and the real .exe suffix. Which of the following is the most appropriate term used to describe this type of attack?

a) Backdoor
b) Trojan horse
c) Virus hoax
d) Worm
?
b) Trojan horse
### Explanation
A **Trojan horse** is a type of malicious software that disguises itself as legitimate or harmless software to trick users into executing it. In this scenario, the executable file (`.exe`) is disguised as an image file (`.jpg`) using extra spaces to hide the true extension, deceiving the user into opening what they believe is a harmless picture. 

* **a) Backdoor:** A method of bypassing normal authentication to access a system.
* **c) Virus hoax:** A false warning about a computer virus, usually spread by email, designed to cause panic or trick users into deleting legitimate files.
* **d) Worm:** A self-replicating malware that spreads across networks without needing user interaction or a host file.

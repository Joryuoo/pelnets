# 2017A_FE_28
When a storage location is to be calculated from a key value, which of the following methods enables the same calculation result to be obtained from different key values?

a) B+ tree index
b) Bitmap index
c) Hash index
d) Inverted index
?
c) Hash index
### Explanation
A **Hash index** calculates the storage location by passing the key value through a hash function. It is possible for different key values to yield the same calculation result (the same hash value). This phenomenon is known as a **hash collision**, which is a defining characteristic of hashing methods.

**Why the others are incorrect:**
*   **B+ tree index**: Uses a tree structure to maintain sorted data for efficient searching; it does not calculate locations via a function that results in collisions.
*   **Bitmap index**: Uses bit arrays (bitmaps) to represent data values, typically for columns with a low number of distinct values.
*   **Inverted index**: Maps content (like words or numbers) to its locations in a database or document, typically used in full-text search.

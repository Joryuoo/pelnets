### Explanation
During component or unit testing, modules are often tested in isolation before all parts of the system are complete. Test harnesses involve dummy modules to facilitate testing:

* **X (Driver):** A test driver is a dummy program or module that acts as the caller. It "calls the software component to be tested," passing it test inputs and recording the outputs.
* **Y (Stub):** A test stub is a dummy subprogram that simulates the behavior of a module that is "called from the software component to be tested." 

Thus, X is a driver and Y is a stub.

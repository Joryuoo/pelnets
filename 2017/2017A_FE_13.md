# 2017A_FE_13
Which of the following is the RAID level that can recover data from the other disks, with a minimum of two-disk configuration?

a) RAID 0
b) RAID 1
c) RAID 5
d) RAID 6
?
b) RAID 1
### Explanation
RAID 1 utilizes disk mirroring to copy identical data across multiple drives. Because data is mirrored, it can recover data using the other disk if one fails. It requires a minimum configuration of 2 disks.
- **RAID 0** involves disk striping without redundancy; it cannot recover data if a disk fails.
- **RAID 5** provides striping with distributed parity, but requires a minimum of 3 disks.
- **RAID 6** provides striping with double distributed parity, requiring a minimum of 4 disks.

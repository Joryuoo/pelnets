# 2017A_FE_AM_36
Which of the following is the term used to describe an attack where attackers exploit a vulnerability of computer systems before a patch fixes the vulnerability?

a) Backdoor attack
b) Man-in-the-middle attack
c) Rootkit attack
d) Zero-day attack
?
d) Zero-day attack
### Explanation
* **Zero-day attack:** Exploits a previously unknown hardware or software vulnerability before the vendor has released a patch for it (hence the vendor has had "zero days" to fix it).
* **Backdoor attack:** Exploits an undocumented or hidden entry point into a system, bypassing normal authentication.
* **Man-in-the-middle attack:** An attacker intercepts and potentially alters communications between two parties who believe they are communicating directly with each other.
* **Rootkit attack:** Involves malicious software designed to hide the existence of certain processes or programs from normal methods of detection and enable privileged access.

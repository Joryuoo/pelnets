# 2017S_FE_AM_8
![[2017S_FE_AM_Q8_full.png]]

a) 12
b) 13
c) 18
d) 19
?
d) 19
### Explanation
We are given a two-dimensional integer array `a`, where the value of each element `a(i, j)` is defined by the formula `2i + j`.
We need to evaluate the nested expression `a(a(1,1) × 2, a(2, 2) + 1)`.

First, calculate the innermost expressions using the formula:
- `a(1, 1) = 2(1) + 1 = 3`
- `a(2, 2) = 2(2) + 2 = 6`

Next, substitute these results back into the parameters of the outer array reference:
- The first parameter is `a(1,1) × 2 = 3 × 2 = 6`.
- The second parameter is `a(2,2) + 1 = 6 + 1 = 7`.

Now, we evaluate the outer expression `a(6, 7)` using the same formula:
- `a(6, 7) = 2(6) + 7 = 12 + 7 = 19`.

Therefore, the evaluated value is 19.

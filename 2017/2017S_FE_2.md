# 2017S_FE_AM_2
![[2017S_FE_AM_Q2_full.png]]

a) (A < B) and (C ≤ D)
b) (A < B) or (C ≤ D)
c) (B < A) and (D ≤ C)
d) (B < A) or (D ≤ C)
?
c) (B < A) and (D ≤ C)
### Explanation
Using De Morgan's laws, the negation of a disjunction `not (X or Y)` is logically equivalent to `(not X) and (not Y)`.
Let X be the condition `(A ≤ B)` and Y be the condition `(C < D)`.
- `not (A ≤ B)` means that A is strictly greater than B, which can be equivalently written as `B < A`.
- `not (C < D)` means that C is greater than or equal to D, which can be equivalently written as `D ≤ C`.

Combining these evaluated negations with the `and` operator, the expression becomes `(B < A) and (D ≤ C)`. This exactly matches choice c.

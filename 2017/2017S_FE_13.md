# 2017S_FE_AM_13
Which of the following is an appropriate role for a device driver?

a) It decides the next task to be executed from tasks waiting for execution.
b) It directly controls hardware according to requests from an application program.
c) It interprets command strings that are entered by the user, and starts the applicable program.
d) It manages the display status on the screen in multiple windows.
?
b) It directly controls hardware according to requests from an application program.
### Explanation
A device driver is a specialized software program that controls a specific hardware device attached to a computer. It acts as a translator between the operating system/applications and the hardware, allowing programs to interact with the device without needing to know its precise physical details.

* **Choice (a)** describes a task scheduler (process management).
* **Choice (c)** describes a command-line interpreter (CLI) or shell.
* **Choice (d)** describes a window manager (GUI component).

# 2017A_FE_10
To determine an effective address from the value recorded in the address part of instruction, various addressing modes are used. Which of the following modes uses the value of the address part as an effective address?

a) Absolute addressing
b) Base plus index addressing
c) Indexed addressing
d) PC relative addressing
?
a) Absolute addressing
### Explanation
*   **a) Absolute addressing (or direct addressing):** The address field contains the actual, effective memory address of the operand. No calculation or register value is added.
*   **b) Base plus index addressing:** Adds the value of a base register and an index register to determine the effective address.
*   **c) Indexed addressing:** Adds the value of an index register to the address part to determine the effective address.
*   **d) PC relative addressing:** Adds the value of the Program Counter (PC) to the address part to determine the effective address.

# 2017A_FE_23
Which of the following uses a flip-flop circuit in a memory cell?

a) DRAM
b) EEPROM
c) SDRAM
d) SRAM
?
d) SRAM
### Explanation
**SRAM (Static Random Access Memory)** uses flip-flop circuits (typically comprising 4 to 6 transistors) to store each bit of data. This allows it to hold data continuously as long as power is supplied, without needing to be periodically refreshed.

**Why the others are incorrect:**
*   **DRAM (Dynamic RAM)**: Uses a capacitor and a single transistor for each memory cell, requiring periodic refreshing.
*   **EEPROM (Electrically Erasable Programmable Read-Only Memory)**: Uses floating-gate transistors to store data non-volatilely.
*   **SDRAM (Synchronous DRAM)**: A type of DRAM synchronized with the system clock, still using capacitors.

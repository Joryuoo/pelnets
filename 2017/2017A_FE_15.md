# 2017A_FE_15
Which of the following is an appropriate characteristic of a web system implemented in a three-layer client/server system configuration?

a) A business process is executed on the server side, and the client software displays the result on a screen according to the HTML coding.
b) A program coded in HTML is run on the server side, and the client software displays the result on a screen.
c) Every time a business process is changed, a business process application for operating the web system must be sent and installed on the client terminal.
d) On the client terminal, it is necessary to have a resident service program waiting to receive an HTTP request from the server side.
?
a) A business process is executed on the server side, and the client software displays the result on a screen according to the HTML coding.
### Explanation
A three-layer (or three-tier) web architecture consists of a presentation layer (client browser), an application layer (web/application server), and a data layer (database).
- The server handles the execution of business logic/processes.
- The client software (web browser) only interprets and renders the resulting HTML presentation.
- b) HTML is merely a markup language sent to the client, not a program that "runs" on the server.
- c) A major benefit of three-layer web architectures is that business logic changes only need to be updated on the server, requiring no client installations.
- d) Clients initiate HTTP requests; servers receive them. Clients do not need resident programs waiting for server requests.

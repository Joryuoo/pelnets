a) 214
### Explanation
Using the FIFO (First-In, First-Out) method, the oldest inventory items are sold first. Let's track the inventory changes over March:

1. **March 1:** Start with 400 units @ 0.4.
2. **March 4:** Purchase 600 units @ 0.42. (Inventory: 400 @ 0.4, 600 @ 0.42)
3. **March 8:** Sell 500 units. Using FIFO, sell 400 @ 0.4 and 100 @ 0.42.
   Remaining: 500 units @ 0.42.
4. **March 10:** Purchase 500 units @ 0.43. (Inventory: 500 @ 0.42, 500 @ 0.43)
5. **March 15:** Purchase 800 units @ 0.42. (Inventory: 500 @ 0.42, 500 @ 0.43, 800 @ 0.42)
6. **March 20:** Sell 1000 units. Using FIFO, sell 500 @ 0.42 and 500 @ 0.43.
   Remaining: 800 units @ 0.42.
7. **March 24:** Purchase 200 units @ 0.44. (Inventory: 800 @ 0.42, 200 @ 0.44)
8. **March 30:** Sell 500 units. Using FIFO, sell 500 @ 0.42.
   Remaining: 300 units @ 0.42, and 200 units @ 0.44.

**End of March Inventory Value:**
(300 units * 0.42) + (200 units * 0.44) = 126 + 88 = 214.

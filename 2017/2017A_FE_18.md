# 2017A_FE_18
Which of the following is the backup method that requires the longest time to backup but the shortest time to restore?

a) Differential backup
b) Full backup
c) Incremental backup
d) Synthetic full backup
?
b) Full backup
### Explanation
A **Full backup** copies all designated data completely every time it is run. Since it copies everything, it takes the longest amount of time to perform. However, when restoring, you only need the single full backup file to recover everything entirely, making the restoration process the shortest/fastest.
- **Incremental backups** only backup the changed data since the last backup (fastest to backup), but require the full backup and every incremental backup in sequence to restore (longest to restore).
- **Differential backups** backup the changed data since the last *full* backup, striking a middle ground in time for both.

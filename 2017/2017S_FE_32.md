# 2017S_FE_AM_32
Which of the following is a routable IP address in the Internet?

a) 10.129.205.3
b) 172.40.77.4
c) 192.168.10.7
d) 192.168.203.5
?
b) 172.40.77.4
### Explanation
A routable IP address on the Internet is a public IP address. Private IP addresses are non-routable on the Internet. 
The private IP address ranges are:
- Class A: `10.0.0.0` to `10.255.255.255`
- Class B: `172.16.0.0` to `172.31.255.255`
- Class C: `192.168.0.0` to `192.168.255.255`

- **a)** `10.129.205.3` falls in the Class A private range.
- **b)** `172.40.77.4` is outside the Class B private range (`172.16` to `172.31`), making it a public, routable IP address.
- **c)** `192.168.10.7` falls in the Class C private range.
- **d)** `192.168.203.5` falls in the Class C private range.

# 2017S_FE_48

a) Content coupling, Data coupling, Common coupling

c) Control coupling, Data coupling, External coupling
d) Control coupling, Stamp coupling, Common coupling
?
d) Control coupling, Stamp coupling, Common coupling
### Explanation
In software engineering, module coupling measures the degree of interdependence between software modules.

* **Coupling A:** "One module passes an element of control to the other module." This defines **Control coupling**, where one module controls the flow of another by passing control information (e.g., a flag).
* **Coupling B:** "One module passes the data structure as a parameter to the other module." This defines **Stamp coupling** (or Data-structured coupling), where modules share a composite data structure but only use parts of it.
* **Coupling C:** "Two modules have access to the same global data." This defines **Common coupling** (or Global data coupling), where multiple modules share the same global data area.

Therefore, the correct sequence is Control coupling, Stamp coupling, and Common coupling.

# 2017A_FE_AM_44
![[2017A_FE_AM_Q44_full.png]]

a) Blocked by number 1
b) Blocked by number 4
c) Permitted by number 2
d) Permitted by number 3
?
a) Blocked by number 1
### Explanation
Packet filtering firewalls evaluate rules in a top-down order. The first rule that matches the packet determines the action taken.

**Packet A characteristics:**
* Source Address: 10.1.2.3
* Destination Address: 10.2.3.4
* Protocol: TCP
* Source Port: 2100
* Destination Port: 25

**Evaluating the Rules:**
* **Rule 1:** Matches any packet with Source Address `10.1.2.3`. Since Packet A has a Source Address of `10.1.2.3`, it perfectly matches Rule 1.
* The action for Rule 1 is **Blocked**.

Since a match is found at Rule 1, the evaluation stops, and the packet is blocked.

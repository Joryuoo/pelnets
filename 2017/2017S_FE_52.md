# 2017S_FE_AM_52

b) B, C, E

?
c) B, C, F
### Explanation
Project Integration Management in PMBOK includes the processes and activities to identify, define, combine, unify, and coordinate the various processes and project management activities. 
The key processes involved in Project Integration Management are:
- **Develop Project Charter** (B)
- Develop Project Management Plan
- **Direct and Manage Project Work** (C)
- Manage Project Knowledge
- Monitor and Control Project Work
- **Perform Integrated Change Control** (F)
- Close Project or Phase

Therefore, the correct combination is B, C, and F.
- **Control costs (A)** belongs to Project Cost Management.
- **Identify risks (D)** belongs to Project Risk Management.
- **Manage communications (E)** belongs to Project Communications Management.

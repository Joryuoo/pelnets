### Explanation
Let's analyze the standard IPv4 address classes:
- **Class A**: Range `0.0.0.0` to `127.255.255.255`. Default subnet mask: `255.0.0.0`. Note: The actual assignable networks start at `1.0.0.0`, but mathematically Class A covers `0.x.x.x` to `127.x.x.x`. The choice given in 'a' does not represent the full standard range correctly or is considered less formally exact than 'b'. Actually, `127.x.x.x` is reserved for loopback, making the usable range `1.0.0.0` to `126.255.255.255`. Choice 'a' includes `127`.
- **Class B**: Range `128.0.0.0` to `191.255.255.255`. Default subnet mask: `255.255.0.0`. This is exactly correct.
- **Class C**: Range `192.0.0.0` to `223.255.255.255`. Default subnet mask: `255.255.255.0`. The choice 'c' restricts the range to start at `192.168.0.0`, which is incorrect (that's just a private range within Class C).
- **Class D**: Range `224.0.0.0` to `239.255.255.255`. Class D is used for multicast and does not have a standard subnet mask. Choice 'd' is incorrect due to the subnet mask.

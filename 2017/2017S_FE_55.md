# 2017S_FE_AM_55
According to EVM (Earned Value Management), the budget of a software development project is $10,000 and the project duration is planned for 10 weeks. After 4 weeks, it is revealed that only 30% of the work has been completed against a cost of $4,200. What is the cost performance index?

a) 0.126
b) 0.300
c) 0.420
d) 0.714
?
d) 0.714
### Explanation
In Earned Value Management (EVM):
- **BAC (Budget at Completion)** = $10,000
- **EV (Earned Value)** = BAC × % of completed work = $10,000 × 30% = $3,000
- **AC (Actual Cost)** = $4,200

The Cost Performance Index (CPI) is calculated as:
CPI = EV / AC
CPI = 3000 / 4200 = 30 / 42 ≈ 0.714

Therefore, the cost performance index is 0.714. A CPI less than 1.0 indicates that the project is over budget.

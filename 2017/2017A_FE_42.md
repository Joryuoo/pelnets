# 2017A_FE_AM_42
When a mirror port is prepared to allow a LAN analyzer to be used to investigate the cause of a network failure, which of the following is a point to consider?

a) In preparation for a failure, it is necessary to inform network users of the storage location and usage method of the LAN analyzer.
b) Since LAN cables must be temporarily disconnected during measurement, it is necessary to notify network users in advance of the date and time of measurement.
c) Since the LAN analyzer can display the packets that pass through the network, it is necessary to pay attention to misuse or abuse such as wiretapping.
d) Since the LAN analyzer disposes of packets, it is necessary to restrict the use of the non-target computers during measurement.
?
c) Since the LAN analyzer can display the packets that pass through the network, it is necessary to pay attention to misuse or abuse such as wiretapping.
### Explanation
A LAN analyzer (packet sniffer) connected to a **mirror port** on a network switch receives copies of all network traffic passing through the switch or designated ports. Since it captures raw packets, which may contain sensitive unencrypted information (like passwords or confidential emails), the primary point of consideration is security and privacy—preventing its misuse for wiretapping.

* **a) is incorrect** because regular network users do not need to know how to use or where to find the LAN analyzer; it is an administrative tool.
* **b) is incorrect** because a mirror port allows the traffic to be duplicated without needing to disconnect cables or interrupt network service.
* **d) is incorrect** because the LAN analyzer only passively receives copies of the packets; it does not "dispose" of the original packets. The target computers continue to function normally.

# 2017A_FE_AM_33
In TCP/IP network, which of the following is a combination of information that identifies a TCP connection?

a) IP address, Session ID
b) IP address, Port number
c) MAC address, Session ID
d) Port number, Session ID
?
b) IP address, Port number
### Explanation
A TCP connection is uniquely identified by a combination of the IP address and the Port number (this pair is often referred to as a "socket"). Specifically, the connection is defined by the 4-tuple: Source IP Address, Source Port, Destination IP Address, and Destination Port.
* **IP Address:** Identifies the specific host on the network.
* **Port Number:** Identifies the specific application or process running on the host.

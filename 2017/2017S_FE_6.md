b) Left child of 18
### Explanation
The given binary tree is a Binary Search Tree (BST). In a BST, for any given node, all node values in its left subtree are strictly smaller, and all node values in its right subtree are strictly larger.
To determine the position for a new node with the value 17, we start at the root (15) and traverse down the tree following these rules:
- **17 > 15**: Move to the right child (20).
- **17 < 20**: Move to the left child (16).
- **17 > 16**: Move to the right child (18).
- **17 < 18**: Move to the left child. Since node 18 currently has no left child, this is where the new node is placed.

Thus, the new node 17 will be inserted as the left child of node 18.

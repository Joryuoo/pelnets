# 2017S_FE_AM_12
Which of the following is an appropriate explanation of memory interleaving?

a) It allows CPU to access different banks of the main memory simultaneously.
b) It improves CPU performance by connecting I/O interface directly to the main memory.
c) It makes use of a fast memory between the CPU and the main memory, which serves as a buffer for frequently accessed data.
d) It widens the data bus to read or write several bytes between the CPU and the main memory in a single process.
?
a) It allows CPU to access different banks of the main memory simultaneously.
### Explanation
Memory interleaving is a technique that divides main memory into multiple independent banks. This allows the CPU to access consecutive memory locations distributed across these different banks simultaneously, significantly increasing memory throughput.

* **Choice (b)** describes Direct Memory Access (DMA), which allows peripherals to communicate directly with memory.
* **Choice (c)** describes cache memory, which acts as a high-speed buffer.
* **Choice (d)** describes increasing the memory bus width, which transfers more data per clock cycle but is not interleaving.

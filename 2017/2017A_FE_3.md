# 2017A_FE_3
Which of the following expressions in postfix notation is equivalent to an expression 2+5×3+4 in infix notation? Here, the operator ‘×’ has higher precedence than ‘+’.

a) 2 5 3 4 × + +
b) 2 5 + 3 4 × +
c) 2 5 3 × 4 + +
d) 2 5 3 × + 4 +
?
d) 2 5 3 × + 4 +
### Explanation
Infix notation is evaluated based on operator precedence. The multiplication (`×`) is performed before the addition (`+`).
Let's convert `2 + 5 × 3 + 4` step-by-step to postfix:
1.  First, handle `5 × 3`, which becomes `5 3 ×` in postfix.
    *   The expression is now: `2 + (5 3 ×) + 4`
2.  Next, handle the first addition (left-to-right), `2 + (5 3 ×)`.
    *   This becomes: `2 5 3 × +`
    *   The expression is now: `(2 5 3 × +) + 4`
3.  Finally, handle the last addition with `4`.
    *   This becomes: `2 5 3 × + 4 +`

Therefore, the correct answer is **d**.

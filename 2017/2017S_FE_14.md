# 2017S_FE_AM_14
Which of the following is an appropriate term to describe the phenomenon when files produced in the process of saving are scattered to different parts of the whole hard disk rather than in continuous clusters?

a) Contiguity
b) Fragmentation
c) Sector
d) Segmentation
?
b) Fragmentation
### Explanation
File fragmentation occurs when a file is divided into pieces and scattered across non-contiguous clusters on the hard disk. This typically happens as files are created, deleted, and resized over time, leaving gaps that the file system fills with new file parts. It can reduce read/write performance.

* **Contiguity** refers to blocks being adjacent to each other (the opposite of fragmentation).
* **Sector** is a physical subdivision of a track on a magnetic disk.
* **Segmentation** is a memory management technique in operating systems.

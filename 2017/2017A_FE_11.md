# 2017A_FE_11
Which of the following is a memory device that stores programs or data in factories, and only has the read operation for the stored programs or data?

a) DRAM
b) Flash memory
c) Mask ROM
d) SRAM
?
c) Mask ROM
### Explanation
Mask ROM is a type of read-only memory whose contents are programmed by the integrated circuit manufacturer during production (in factories). It is not user-programmable.
- **DRAM** (Dynamic Random Access Memory) is volatile memory used for main memory and requires constant refreshing.
- **Flash memory** is non-volatile memory that can be electrically erased and reprogrammed.
- **SRAM** (Static Random Access Memory) is fast, volatile memory typically used for cache memory.

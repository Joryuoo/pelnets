# 2017A_FE_24
Which of the following is used to control the visual styles of HTML documents, such as text sizes, text colors, or page layout?

a) CMS
b) CSS
c) RSS
d) Wiki
?
b) CSS
### Explanation
**CSS (Cascading Style Sheets)** is a style sheet language used for describing the presentation of a document written in HTML. It controls visual styles, layouts, colors, and fonts.

**Why the others are incorrect:**
*   **CMS (Content Management System)**: Software used to manage the creation and modification of digital content (e.g., WordPress).
*   **RSS (Really Simple Syndication)**: A web feed that allows users and applications to access updates to websites in a standardized, computer-readable format.
*   **Wiki**: A web application that allows collaborative modification, extension, or deletion of its content and structure.

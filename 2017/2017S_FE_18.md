# 2017S_FE_AM_18
![[2017S_FE_AM_Q18_full.png]]

a) 35
b) 38
c) 45
d) 48
?
a) 35
### Explanation
Let's trace the Round Robin scheduling with a time quantum of 3 seconds.
Processes arrive at: P1 (0), P2 (10), P3 (13).

| Time | Action | Ready Queue (End of Action) |
|---|---|---|
| 0-12 | P1 executes 4 full quanta (12s). P1 has 12s left. At time 10, P2 arrives. | P2, P1 |
| 12-15 | P2 executes (3s). P2 has 12s left. At time 13, P3 arrives. | P1, P3, P2 |
| 15-18 | P1 executes (3s). P1 has 9s left. | P3, P2, P1 |
| 18-21 | P3 executes (3s). P3 has 9s left. | P2, P1, P3 |
| 21-24 | P2 executes (3s). P2 has 9s left. | P1, P3, P2 |
| 24-27 | P1 executes (3s). P1 has 6s left. | P3, P2, P1 |
| 27-30 | P3 executes (3s). P3 has 6s left. | P2, P1, P3 |
| 30-33 | P2 executes (3s). P2 has 6s left. | P1, P3, P2 |
| 33-36 | P1 executes (3s). P1 has 3s left. | P3, P2, P1 |
| 36-39 | P3 executes (3s). P3 has 3s left. | P2, P1, P3 |
| 39-42 | P2 executes (3s). P2 has 3s left. | P1, P3, P2 |
| 42-45 | P1 executes (3s) and finishes. | P3, P2 |
| 45-48 | P3 executes (3s) and finishes. | P2 |

P3 arrives at time `13` and completes execution at time `48`. 
The total time that elapsed for P3 from arrival to completion (Turnaround Time, which is often termed as total waiting time before completion in these exam translations) is `48 - 13 = 35` seconds.

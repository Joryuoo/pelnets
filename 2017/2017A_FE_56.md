# 2017A_FE_AM_56
Which of the following is an appropriate purpose of using a Work Breakdown Structure (WBS) in a software development project?

a) To clarify the time sequence of activities, and understand the critical path that should be intensively managed
b) To decompose a development task into smaller sub-tasks of a manageable size, and organize them into a hierarchical structure
c) To optimize the total cost when there is a trade-off relationship between the number of days and the cost that is required for development
d) To show the schedule of an activity by using a bar, and clarify the start point and end point of the activity as well as the progress at the current point
?
b) To decompose a development task into smaller sub-tasks of a manageable size, and organize them into a hierarchical structure
### Explanation
A **Work Breakdown Structure (WBS)** is a hierarchical decomposition of the total scope of work to be carried out by the project team to accomplish the project objectives and create the required deliverables. It breaks down large tasks into smaller, manageable sub-tasks.

* **Choice A** describes a network diagram or critical path method (CPM).
* **Choice C** refers to schedule compression techniques like crashing or cost-time trade-off analysis.
* **Choice D** describes a Gantt chart.

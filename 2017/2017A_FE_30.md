# 2017A_FE_30
Which of the following is located at layer 3 of the OSI basic reference model, and performs path selection and packet relay for an end-to-end communication?

a) Data link layer
b) Network layer
c) Session layer
d) Transport layer
?
b) Network layer
### Explanation
Layer 3 of the OSI basic reference model is the **Network layer**. It is responsible for logical addressing, path selection (routing), and packet relaying across multiple networks for end-to-end communication. The most common protocol at this layer is IP (Internet Protocol).

**Why the others are incorrect:**
*   **Data link layer**: Layer 2. Handles node-to-node data transfer over a physical link and MAC addressing.
*   **Session layer**: Layer 5. Manages and terminates connections (sessions) between applications.
*   **Transport layer**: Layer 4. Ensures reliable, end-to-end data delivery and error recovery (e.g., TCP, UDP).

# 2019A_FE_AM_47
In object orientation, which of the following is the name of being able to use the attributes and functions of a class in a subclass of that class?

a) Encapsulation
b) Inheritance
c) Override
d) Polymorphism
?
b) Inheritance
### Explanation
**Inheritance** is a mechanism in object-oriented programming where a new class (subclass or derived class) inherits the attributes and methods (functions) of an existing class (superclass or base class). This promotes code reusability.
- **Encapsulation:** Bundling data and methods that operate on the data into a single unit (class), while hiding the internal state from the outside.
- **Override:** A feature that allows a subclass to provide a specific implementation of a method that is already provided by its superclass.
- **Polymorphism:** The ability of different objects to respond to the same method call in their own specific way.

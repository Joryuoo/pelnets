# 2019A_FE_AM_38
Which of the following is the purpose of using a message digest in a message authentication code?

a) To check the encryption method of a message
b) To check the overview of a message
c) To confirm that there is no falsification of a message
d) To secure the confidentiality of a message
?
c) To confirm that there is no falsification of a message
### Explanation
A message digest (generated by a hash function) is a fixed-size representation of a message. Its primary characteristics are that it is virtually unique to the original data, and any slight change in the message will result in a completely different digest. 

By sending a Message Authentication Code (MAC)—which combines the message digest with a secret key—the receiver can recompute the digest and compare it. If it matches, they can **confirm that there is no falsification of the message** (ensuring data integrity) and verify the sender's authenticity. It does not provide confidentiality or encrypt the message itself.

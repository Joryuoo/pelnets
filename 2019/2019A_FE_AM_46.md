# 2019A_FE_AM_46
Which of the following is a method for preventing an SQL injection attack?

a) If an input text contains HTML tags, replacement of these tags with other character strings that are not interpreted as HTML tags
b) Nonacceptance of an input text if the overall length of the text exceeds the limit
c) Nonacceptance of an input text that contains a character string that specifies a higher-level directory ( . . / )
d) Preventing input characters from being interpreted as characters that have a special meaning in an inquiry or operation on the database
?
d) Preventing input characters from being interpreted as characters that have a special meaning in an inquiry or operation on the database
### Explanation
**SQL Injection** is an attack where malicious SQL statements are inserted into entry fields for execution. The best defense is to sanitize input and use parameterized queries or prepared statements, effectively **preventing input characters from being interpreted as characters that have a special meaning** in SQL (like quotes `'` or `--`).

- Option A describes a defense against **Cross-Site Scripting (XSS)**.
- Option B describes a defense against **Buffer Overflow** attacks.
- Option C describes a defense against **Directory Traversal** attacks.

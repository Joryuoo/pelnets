# 2019A_FE_AM_22
Which of the following is a sequential circuit that has two (2) stable states?

a) Adder circuit
b) Capacitor
c) Flip-flop
d) NAND gate
?
c) Flip-flop
### Explanation
A flip-flop is a sequential logic circuit that has two stable states (bistable) and can be used to store state information (1 bit of data). Its state depends not only on its current inputs but also on its previous state.

An adder circuit is a combinational circuit used to perform the addition of numbers.
A capacitor is a passive electrical component that stores electrical energy in an electric field.
A NAND gate is a combinational logic gate that produces a false output only if all its inputs are true.

# 2019A_FE_AM_23
Which of the following is an appropriate description of flash memory?

a) All its contents can be erased at once with ultraviolet rays.
b) Data can be electronically erased in block units.
c) It can be rewritten at a high speed and is used for the cache memory of a CPU.
d) It needs to rewrite data periodically.
?
b) Data can be electronically erased in block units.
### Explanation
Flash memory is a non-volatile electronic computer storage medium that can be electrically erased and reprogrammed. One of its defining characteristics is that it erases data in blocks rather than at the byte level.

a) Describes EPROM (Erasable Programmable Read-Only Memory), which is erased using ultraviolet light.
c) Describes SRAM (Static Random-Access Memory), which is volatile and commonly used for CPU cache.
d) Describes DRAM (Dynamic Random-Access Memory), which requires periodic refreshing to maintain its stored data.

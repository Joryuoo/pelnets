### Explanation
The goal of SQL2 is to find students who completed all courses taught by Clark in 2018 and 2019.
This is a relational division problem, which can be expressed with `NOT EXISTS` and `EXCEPT`.
We want to find students such that:
The set of all sections taught by Clark in 2018/2019 `EXCEPT` the set of sections completed by the student is empty. 
If this set difference is empty, it means the student has completed all those required sections.
Therefore, we use `NOT EXISTS` (c) for Blank E and `EXCEPT` (a) for Blank F.

### Explanation
**Blank A:**
The given data-bits are `1001`, which correspond to `a3 = 1`, `a2 = 0`, `a1 = 0`, `a0 = 1`.
We calculate the parity bits `r2`, `r1`, `r0` using the provided equations:
* `r2 = a3  a1  a0` = 1  0  1 = 0
* `r1 = a3  a2  a1` = 1  0  0 = 1
* `r0 = a2  a1  a0` = 0  0  1 = 1

The resulting code-bits are `a3, a2, a1, a0, r2, r1, r0` = `1001011`.
Thus, the answer is **b) 1001011**.

**Blank B:**
When the receiver receives the correct code-bits `1001011`, no transmission error has occurred. Therefore, the syndrome-bits `s2, s1, s0` will all be `0`, meaning `000`.
Thus, the answer is **a) 000**.

**Blank C:**
The data-bits `0110` have code-bits `0110100`. The received code-bits are `1110100` (due to an error).
This corresponds to `b3=1, b2=1, b1=1, b0=0, q2=1, q1=0, q0=0`.
We calculate the syndrome-bits `s2, s1, s0` at the receiver:
* `s2 = b3  b1  b0  q2` = 1  1  0  1 = 1
* `s1 = b3  b2  b1  q1` = 1  1  1  0 = 1
* `s0 = b2  b1  b0  q0` = 1  1  0  0 = 0

The syndrome-bits are `110`.
Thus, the answer is **e) 110**.

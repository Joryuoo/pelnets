### Explanation
**Blank A:**
We need to calculate the expected data access time for a page fault rate of 0.1% (0.001). 
Given:
- `Tm` (memory access time) = 200 nanoseconds
- `Ta` (auxiliary storage access time) = 4 milliseconds = 4,000,000 nanoseconds
- `Rf` (page fault rate) = 0.001

Using the formula `T = ((1 - Rf) × Tm) + (Rf × Ta)`:
- `T = ((1 - 0.001) × 200) + (0.001 × 4,000,000)`
- `T = (0.999 × 200) + 4000`
- `T = 199.8 + 4000 = 4199.8` nanoseconds.

Converted to microseconds, this is approximately 4.20 microseconds. Thus, the answer for A is **b**.

**Blank B:**
We need to calculate the expected data access time for a page fault rate of 0.01% (0.0001) in nanoseconds.
- `Rf` = 0.0001
- `T = ((1 - 0.0001) × 200) + (0.0001 × 4,000,000)`
- `T = (0.9999 × 200) + 400`
- `T = 199.98 + 400 = 599.98` nanoseconds.

Rounded to 3 significant figures, this is 600 nanoseconds. Thus, the answer for B is **i**.

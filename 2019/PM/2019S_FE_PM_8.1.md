### Explanation

**Blank A:** `d` (`name.lastIndexOf('.')`)
The problem states: "If there is more than one '.' in the name, the last '.' designates the extension." We use `lastIndexOf('.')` to get the correct starting index for the extension string. The `substring` method is inclusive of the beginning index, so the extracted extension will properly include the dot.

**Blank B:** `e` (`parent.fullPath`)
When constructing the `fullPath` for a node that is not immediately under the root, we must prepend the full path of its parent directory, forming `parent.fullPath + "/" + name`.

**Blank C:** `d` (`current.isDirectory()`)
Before fetching and iterating over a node's children via `current.getChildren()`, the program must ensure the node is a directory. If it is a file, calling `getChildren()` returns `null`, leading to a runtime error. Thus, checking `current.isDirectory()` is necessary.

**Blank D:** `d` (`new NameCondition(name)`)
To search by an exact name match, `searchByName` must instantiate an object of `NameCondition` implementing the `ICondition` interface. The correct syntax is `new NameCondition(name)`.

**Blank E:** `d` (`searchList(root, condition)`)
The method `searchByName` sets up the search logic by calling the `searchList` helper method, passing the starting `root` node and the `condition` object.

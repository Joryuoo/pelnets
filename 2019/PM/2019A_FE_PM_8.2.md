### Explanation
- **G and H**: The program runs `updateScore(333, 70)` which updates the score of student `333` ("Jokl") from `-1.0` to `70.0`. It then calls `sortAndPrint` using `SortOrder.BY_SCORE`. 
- Before the update, the array was previously sorted `BY_ID`, resulting in the order: `111` (Abco), `222` (Ghio), `333` (Jokl), `444` (Cdef).
- When sorting by score in descending order, the exchange sort checks pairs. Student `333` (Jokl, 70) and `444` (Cdef, 70) both have a score of `70.0`. 
- Because `Double.compare` will return `0` for equal scores, `order.compare` returns `0`, and the `> 0` condition for swapping is `false`. Therefore, their relative order is maintained. Since student `333` appears before `444` in the `BY_ID` sorted array, `333, Jokl` will appear before `444, Cdef` in the new output.
- Thus, `G` is `333, Jokl` and `H` is `444, Cdef`.

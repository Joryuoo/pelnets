### Explanation
The scenario states that a contractor needs to access the Web server via SSH (port 22) from a specified PC with the IP address `198.51.100.2`.
The Web server's IP address is `203.0.113.2`.

The router setting syntax requires the rule to be formatted as `Source, Destination, Port`.
- **Source:** The contractor's PC (`198.51.100.2`)
- **Destination:** The Web server (`203.0.113.2`)
- **Port:** SSH (`22`)

Putting this together, the correct firewall rule is `198.51.100.2, 203.0.113.2, 22`. This corresponds to answer **a**.

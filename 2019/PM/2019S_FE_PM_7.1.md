### Explanation
To calculate the sum of divisors for a number `num`, the function iterates `i` from 1 up to the square root of `num` (`i * i <= num`). 
For every `i` that divides `num` evenly (i.e., `num % i == 0`), both `i` and `num / i` are divisors of `num`.

- **Blank A (a):** The divisor `i` is added to the result.
- **Blank B (d):** The corresponding divisor `num / i` is also added to the result, provided it is not equal to `i` (which would happen if `num` is a perfect square, to avoid counting the square root twice).

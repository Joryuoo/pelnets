### Explanation
**Blank A:**
Based on workflow step (1), applicants access the membership application Web page via the Internet using HTTPS (port 443). The Web server is located at `203.0.113.2`.
The router needs a rule to permit HTTPS traffic from the Internet (`if0`) to the Web server. 
Thus, the correct rule for Blank A is `203.0.113.2, 443` (coming in through `if0`, going to destination `203.0.113.2` on port `443`). This corresponds to answer **d**.

**Blank B:**
Based on workflow step (4), the Web server registers the collected information into the member information database. Table 1 indicates the member information database uses a proprietary protocol on port `4194`. 
The router needs a rule to allow traffic from the Web server (`203.0.113.2`) to the database. Given the available options, the member information database must be at IP `192.168.0.3`.
Thus, the correct rule for Blank B is `192.168.0.3, 4194` (source `203.0.113.2` going to destination `192.168.0.3` on port `4194`). This corresponds to answer **c**.

### Explanation
Public key authentication uses cryptographic signatures rather than passwords. The client generates a signature using its **private key**, which it then sends to the server (along with the public key). The server verifies the signature using the matching public key it has on file. 

Because the server only needs the public key and the signature to verify the client's identity, the **private key** is never transmitted over the network. This prevents eavesdroppers from capturing the private key. Thus, there is no need to transmit private keys, making answer **a** correct.

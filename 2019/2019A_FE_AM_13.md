# 2019A_FE_AM_13
Which of the following is an appropriate description of cache memory?

a) Cache memory is used to fill a gap in memory capacity between the physical memory and the virtual memory.
b) Due to significant improvements in the access speed of semiconductor memory, the need for cache memory is decreasing.
c) If a cache miss occurs, an interrupt is generated, and data is transferred from the main memory to the cache memory by the program.
d) When the write instruction is executed, the cache memory is rewritten in two ways. In one, both the cache memory and the main memory are rewritten, and in the other, only the cache memory is rewritten, and the main memory is rewritten when the relevant data is removed from the cache memory.
?
d) When the write instruction is executed, the cache memory is rewritten in two ways. In one, both the cache memory and the main memory are rewritten, and in the other, only the cache memory is rewritten, and the main memory is rewritten when the relevant data is removed from the cache memory.
### Explanation
Cache memory is a high-speed memory placed between the CPU and main memory to fill the speed gap between them. 
Regarding memory writing in cache, there are two primary policies:
1. **Write-through**: Data is written simultaneously to both the cache and the main memory.
2. **Write-back**: Data is written only to the cache initially. The main memory is updated later when the modified cache line is replaced (removed).

Let's check the incorrect options:
- a) is incorrect; virtual memory is used to fill the *capacity* gap between main memory and secondary storage.
- b) is incorrect; processor speeds have outpaced memory speeds, making cache memory highly essential.
- c) is incorrect; a cache miss is typically handled by the hardware (cache controller), not by generating a software interrupt to be handled by a program.

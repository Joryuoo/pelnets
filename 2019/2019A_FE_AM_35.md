# 2019A_FE_AM_35
In telecommunication, which of the following is a standard for wireless broadband communication for mobile devices and data terminals?

a) IEEE 802.11
b) LTE
c) NFC
d) UWB
?
b) LTE
### Explanation
* **LTE (Long-Term Evolution):** A standard for high-speed wireless broadband communication for mobile devices and data terminals (4G cellular networks).
* **IEEE 802.11:** The set of standards for Wi-Fi (Wireless Local Area Networks), typically used for local area connectivity rather than wide-area broadband cellular communication.
* **NFC (Near Field Communication):** A short-range wireless technology for data exchange between devices in close proximity (e.g., contactless payments).
* **UWB (Ultra-Wideband):** A radio technology used for short-range, high-bandwidth communications and precise indoor positioning.

# 2019A_FE_AM_76
Which of the following is an appropriate method to forecast the amount of revenue during an upcoming promotion at a store, based on historical data?

a) Cluster analysis
b) Delphi method
c) Pareto analysis
d) Regression analysis
?
d) Regression analysis
### Explanation
Regression analysis is a set of statistical processes for estimating the relationships among variables. It can be used for forecasting and time series modeling, such as forecasting revenue based on historical data and future promotional efforts.
- Cluster analysis groups a set of objects in such a way that objects in the same group are more similar to each other than to those in other groups.
- The Delphi method is a structured communication technique, originally developed as a systematic, interactive forecasting method which relies on a panel of experts.
- Pareto analysis is a statistical technique in decision-making used for the selection of a limited number of tasks that produce significant overall effect (80/20 rule).

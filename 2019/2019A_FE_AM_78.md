d) 18,200
### Explanation
To calculate the required sales volume to earn the target profit, we can use the formula:
`Profit = (Selling Price per unit * Units Sold) - (Total Fixed Costs + Variable Cost per unit * Units Sold)`

From the given tables, we determine:
* **Total Fixed Costs:** $130,000 (Administration) + $10,000 (R&D) = $140,000
* **Variable Cost per unit:** $4 (Raw material) + $3 (Administration) = $7
* **Selling Price per unit:** $17
* **Target Profit:** $42,000

Let `x` be the number of units sold:
`$42,000 = ($17 * x) - ($140,000 + $7 * x)`
`$42,000 = $10 * x - $140,000`
`$182,000 = $10 * x`
`x = 18,200`

Thus, 18,200 units must be sold.

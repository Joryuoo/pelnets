# 2019A_FE_AM_20
Which of the following is the main purpose of optimization by a compiler?

a) To improve the maintainability of a program
b) To make debugging of a program easier
c) To reduce the execution time of a program
d) To reduce the time needed to generate object codes
?
c) To reduce the execution time of a program
### Explanation
The main purpose of **compiler optimization** is to tune the output executable to run faster (reduce execution time) and/or use less memory or other resources. The compiler analyzes the source code and generates an equivalent, but more efficient, sequence of machine instructions.

- a) Maintainability is related to source code readability and structure, which a compiler does not alter.
- b) Optimization often makes debugging harder because the resulting machine code might be reorganized or variables may be optimized away.
- d) Optimization generally increases compilation time (the time needed to generate object codes) because of the extra analysis required.

# 2019A_FE_AM_36
Which of the following is an e-mail header field that is removed during the message transfer using SMTP?

a) Bcc
b) Date
c) Received
d) X-Mailer
?
a) Bcc
### Explanation
In e-mail communication:
* **Bcc (Blind Carbon Copy):** Recipients specified in this field receive a copy of the e-mail, but their addresses are hidden from other recipients. To achieve this, the sending Mail User Agent (MUA) or Mail Transfer Agent (MTA) removes the Bcc header field from the message before it is transmitted or delivered to the other recipients.
* **Date:** Shows when the e-mail was composed. It is kept.
* **Received:** Added by MTAs as the message travels through servers for tracking and routing history. It is accumulated, not removed.
* **X-Mailer:** Indicates the software client used to send the e-mail. It is kept.

# 2019A_FE_AM_30
Which of the following is a file where values before and after an update of the database are written and saved as the update history of the database?

a) Backup file
b) Checkpoint file
c) Dump file
d) Log file
?
d) Log file
### Explanation
A log file (specifically a transaction log or journal) records all transactions and database modifications. It stores both the pre-update values (before image) and post-update values (after image) so that the database can be recovered in case of a failure (via rollback or rollforward operations).

a) Backup file: A complete copy of the database taken at a specific point in time.
b) Checkpoint file: Contains synchronization information representing a state where all changes in memory have been safely written to disk.
c) Dump file: Similar to a backup, typically an export of the entire database or memory state.

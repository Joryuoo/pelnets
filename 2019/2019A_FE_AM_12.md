c) Instruction register
### Explanation
In the instruction execution cycle of a processor, an instruction fetched from the main memory is first stored in the **Instruction register**. Then, the instruction decoder interprets the instruction held in the instruction register to generate control signals. 
- The accumulator is a register used to store intermediate arithmetic and logic results.
- The data cache stores data (not instructions being decoded).
- The program counter holds the memory address of the next instruction to be fetched.

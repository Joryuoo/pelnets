# 2019A_FE_AM_53
Which of the following is the technique for estimating activity durations where past information is statistically analyzed and various coefficients are determined?

a) Analogous estimate
b) Bottom-up estimate
c) Parametric estimate
d) Three-point estimate
?
c) Parametric estimate
### Explanation
Parametric estimating is a more accurate technique for estimating cost and duration, using the statistical relationship between historical data and other variables to calculate an estimate for activity parameters, such as cost, budget, and duration.

# 2019A_FE_AM_42
Which of the following is the purpose of port scanning when an attacker intrudes into the system?

a) To investigate if evidence of attack remains in the system log at the post-processing stage
b) To investigate if there is a service that can be attacked at the preliminary investigation stage
c) To investigate if there is an account whose privileges can be deprived at the privilege acquisition stage
d) To investigate if there is user information that is beneficial to the attacker at the performance stage of a fraudulent act
?
b) To investigate if there is a service that can be attacked at the preliminary investigation stage
### Explanation
**Port scanning** is a method used by attackers (and security professionals) during the reconnaissance or preliminary investigation stage. It involves sending requests to various network ports on a target system to determine which ones are open, listening, and offering services. By identifying open ports, an attacker can determine what services are running and look for vulnerabilities in those specific services to exploit.

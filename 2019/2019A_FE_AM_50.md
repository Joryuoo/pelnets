# 2019A_FE_AM_50
Which of the following is an appropriate test to ensure that the interfaces and linkages between different parts of software work properly?

a) Functional test
b) Integration test
c) Performance test
d) Unit test
?
b) Integration test
### Explanation
**Integration testing** is the phase in software testing where individual software modules (or units) are combined and tested as a group. Its primary purpose is to expose faults in the interfaces and in the interaction between integrated components.
- **Unit test** tests individual components in isolation.
- **Functional test** tests the software against functional requirements.
- **Performance test** tests how the system performs under load (speed, scalability, stability).

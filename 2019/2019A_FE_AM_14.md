# 2019A_FE_AM_14
When two computers have been prepared, and the computer in use fails, which of the following is the system that continues processing by promptly switching to the backup computer that has started the same online processing programs as those on the currently-used computer in advance, and is on standby?

a) Cold standby system
b) Hot standby system
c) Multiprocessor system
d) Multiuser system
?
b) Hot standby system
### Explanation
A **hot standby system** is a redundancy configuration where a backup (standby) system is running simultaneously with the active primary system, often executing the same applications or keeping its data synchronized in real-time. If the primary system fails, the hot standby system takes over processing immediately with almost no downtime.
- **Cold standby system** (a): The backup system is turned off or only serves as a spare without running the operational programs. It requires manual startup and configuration to resume services.
- **Multiprocessor system** (c): A system with multiple CPUs processing tasks concurrently. It is not a standby architecture.
- **Multiuser system** (d): An OS feature allowing multiple users to access the system simultaneously.

# 2019A_FE_AM_21
Which of the following is the OSS that is provided as an integrated development environment for software?

a) Apache Tomcat
b) Eclipse
c) GCC
d) Linux
?
b) Eclipse
### Explanation
Eclipse is a popular open-source software (OSS) that functions as an Integrated Development Environment (IDE) used primarily for software development, particularly for Java, but also supports other languages through plugins.

Apache Tomcat is an open-source implementation of the Java Servlet, JavaServer Pages, Java Expression Language, and Java WebSocket technologies (a web server).
GCC (GNU Compiler Collection) is a compiler system produced by the GNU Project supporting various programming languages.
Linux is an open-source operating system kernel.

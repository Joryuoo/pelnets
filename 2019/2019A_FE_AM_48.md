# 2019A_FE_AM_48
In the development process, which of the following is an activity that should be performed in software architecture design?

a) Converting the requirements for a software item into an architecture that represents the top-level structure and identifies software components
b) Refining a program so that the processing of each coded line is clarified
c) Seeking comments from the customer and determining a specification
d) Summarizing the requirements in the form of diagrams and tables, and refining and analyzing them in stages
?
a) Converting the requirements for a software item into an architecture that represents the top-level structure and identifies software components
### Explanation
**Software architecture design** focuses on defining the high-level structure of a system. This involves converting system requirements into a top-level architectural blueprint that identifies the major software components, their interactions, and how they work together to fulfill the requirements.
- Option B refers to detailed design or coding.
- Option C refers to requirements gathering or validation.
- Option D refers to requirements analysis.

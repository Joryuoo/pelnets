# 2015May_FE_33
In the Internet environment, a computer is able to send the ping command "ping 11.22.33.44" to the web server (e.g., www.xyz.com) of Company XYZ and then receive an echo reply message successfully. Also, the computer is able to browse the website by using URL "http://11.22.33.44", but cannot browse the same website by using "http://www.xyz.com". In the OSI basic reference model, which of the following is the layer that is most likely to be responsible for such a problem?

a) Application layer
b) Data Link layer
c) Network layer
d) Session layer
?
a) Application layer
### Explanation
The issue is that the computer can successfully communicate via the IP address (`11.22.33.44`) but fails when using the domain name (`www.xyz.com`). This indicates a problem with **DNS (Domain Name System)** name resolution, which is failing to translate the hostname to the IP address.

DNS is a protocol that operates at the **Application layer** (Layer 7) of the OSI basic reference model.

*   **Data Link layer (Layer 2) / Network layer (Layer 3):** These layers are functioning properly because the `ping` command (ICMP) and HTTP via IP address are successfully routing and communicating across the network.
*   **Session layer (Layer 5):** Manages sessions, not responsible for hostname resolution.

# 2015A_FE_33
In TCP/IP networks, which command uses the ICMP "Echo", "Echo Reply" and "Destination Unreachable" messages to test the reachability of the communication partner? 

a) arp 
b) echo 
c) ipconfig 
d) ping 
?
d) ping 
### Explanation
The `ping` command is a network utility used to test the reachability of a host on an IP network. It operates by sending ICMP Echo Request messages to the destination host and waiting for an ICMP Echo Reply.

- **a) arp:** Used to display and modify the ARP (Address Resolution Protocol) cache, which maps IP addresses to MAC addresses.
- **b) echo:** A command-line utility used to display lines of text or string.
- **c) ipconfig:** Used to display the current TCP/IP network configuration values.

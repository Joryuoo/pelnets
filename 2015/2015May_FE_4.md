# 2015May_FE_4
![[2015May_FE_AM_Q4_p1.png]]

a) O(n)
b) O(n^2)
c) O(log2 n)
d) O(n log2 n)
?
a) O(n)
### Explanation
For a balanced binary search tree with $N$ elements, the height of the tree is bounded by $O(\log_2 N)$, which is also the time complexity for a search operation.
In this question, the number of data elements is $N = 2^n$.
Therefore, the asymptotic time complexity of the search operation is $O(\log_2 (2^n))$.
By logarithm rules, $\log_2 (2^n) = n \log_2 2 = n$.
The time complexity is therefore $O(n)$, which matches choice a).

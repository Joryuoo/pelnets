In a selection sort for ascending order, if the element at the current index `i` is greater than the element at the comparing index `j`, they must be swapped so the smaller element moves towards the front.
* **c) `t[i].sortValue > t[j].sortValue`** is correct because it ensures `t[i]` will hold the smaller value after the swap.

**Blank B:**
The variable `angle` stores the angle in tenths of a degree (0.1°).
* The hour hand moves 360° in 12 hours (720 minutes). Speed = 360/720 = 0.5° per minute = 5 tenths of a degree per minute. Thus, `hAngle = (total_minutes) * 5`.
* The minute hand moves 360° in 60 minutes. Speed = 360/60 = 6° per minute = 60 tenths of a degree per minute.
* **d) `t[i].mm * 60`** correctly calculates `mAngle` using this rate.
* *a, b, c, e, f)* Have incorrect constants for the minute hand's rotational speed.

**Blank C:**
The program only considers angles between 0° and 180°. If the absolute difference between the hands is greater than 180° (which is 1800 in tenths of a degree), we must take the interior angle by subtracting the reflex angle from 360°.
* In tenths of a degree, 360° is 3600. Thus, the interior angle is `3600 - t[i].angle`.
* **b) `3600 - t[i].angle`** is the correct operation.
* *a, c, d)* Perform invalid mathematical operations that don't find the correct interior angle.

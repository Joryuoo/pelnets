### Explanation
To determine the day of the week for `01/20/1901` (January 20, 1901), we trace the `dayOfWeek()` method in `Date` using the given values: `month = 1`, `day = 20`, `year = 1901`.

**Step 1: Initial Variable Setup**
- `mm = 1`
- `yy = 1901`

**Step 2: Adjust for January/February**
```java
if (mm < 3) { 
    mm = mm + 12; 
    yy = yy - 1; 
} 
```
Since `mm` (1) is less than 3, the condition evaluates to true:
- `mm = 1 + 12 = 13`
- `yy = 1901 - 1 = 1900`

**Step 3: Calculate Century (`cc`) and Adjusted Year (`yy`)**
```java
cc = (int) (yy / 100); 
yy = yy % 100; 
```
- `cc = (int) (1900 / 100) = 19`
- `yy = 1900 % 100 = 0`

**Step 4: Calculate Intermediate Value `t`**
```java
t = day + (int) (26 * (mm + 1) / 10) + yy; 
```
- `day = 20`
- `26 * (13 + 1) = 26 * 14 = 364`
- `364 / 10 = 36.4`, which casts to integer `36`
- `yy = 0`
- `t = 20 + 36 + 0 = 56`

**Step 5: Add Leap Year and Century Adjustments to `t`**
```java
t = t + (int) (yy / 4) + (int) (cc / 4) - 2 * cc; 
```
- `(int) (0 / 4) = 0`
- `(int) (19 / 4) = 4`
- `2 * 19 = 38`
- `t = 56 + 0 + 4 - 38 = 22`

**Step 6: Compute Final Day Index (`dd`)**
```java
dd = t % 7; 
if (dd < 0) 
    dd = dd + 7; 
```
- `dd = 22 % 7 = 1`
- `1` is not less than `0`, so `dd` remains `1`.

**Step 7: Determine the Day**
Based on the mapping table described in the program description:
- `0` – Saturday
- `1` – Sunday
- `2` – Monday
- `3` – Tuesday
- `4` – Wednesday
- `5` – Thursday

Since `dd = 1`, the day of the week is **Sunday**, which corresponds to choice **g**.

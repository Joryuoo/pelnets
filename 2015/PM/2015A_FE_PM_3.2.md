### Explanation

**Blank D:**
The SQL statement needs to join the `Index` table with the `Index_Progress` table and filter the records by a date range.
- **Join Condition:** The `Index` and `Index_Progress` tables share the `Index_ID` attribute. Thus, the correct join condition is `Index.Index_ID = Index_Progress.Index_ID`.
- **Date Range Filter:** The question states the output must be "during the specified period from the beginning date to the end date." In SQL, checking if a date falls within a range is done using the `BETWEEN` operator: `Index_Progress.Date_Created BETWEEN :FromDate AND :ToDate`. 
- **Incorrect Choices:**
  - Choices **a** and **b** incorrectly try to join `Customer` and `Index_Progress` using `Date_Created`. `Customer` does not have a `Date_Created` attribute to join on.
  - Choice **d** uses the `IN` operator, which checks if a value exactly matches an item in a specific list of values, rather than a continuous range. 
- Therefore, the correct answer is **c**.

**Blank E:**
The question specifies that "The list is arranged in ascending order of the date created."
- In SQL, sorting output is accomplished using the `ORDER BY` clause. By default, `ORDER BY` sorts in ascending order.
- So, `ORDER BY Index_Progress.Date_Created` correctly sorts the output by the date it was created.
- **Incorrect Choices:**
  - Choices **a** and **b** use the `GROUP BY` clause, which is used for aggregating data (e.g., using `SUM()` or `COUNT()`), not for sorting.
  - Choice **d** incorrectly sorts by `Index_ID` first and then sorts the date in descending order (`DESC`).
- Therefore, the correct answer is **c**.

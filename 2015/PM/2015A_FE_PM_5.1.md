### Explanation

Based on the Use Case Diagram (Figure 1), Navigation Map (Figure 2), and the descriptions provided:

*   **A (Blank A - Screen Transaction S002):** S002 is the transition from the Home Page (P001) directly to the Job Search Page (P003). This path is taken without logging in. The system description states "Users can search jobs, but can not apply for jobs... After registration, he/she becomes an applicant." Thus, an unregistered/unauthenticated actor searching for jobs is a **user**.
    *   **Correct Answer:** `d) user`
*   **B (Blank B - Screen Transaction S003):** S003 is a decision point from the Job Search Page (P003). If the answer is "Yes", the actor proceeds to the Job Apply Page (P004). If "No", they are redirected to the Login Page (P002). Since only an **applicant** can apply for jobs, the system is checking if the actor is an applicant (i.e., logged in).
    *   **Correct Answer:** `a) applicant`
*   **C (Blank C - Screen Transactions S005 and S006):** S005 is the transition from the Login Page (P002) to the Job Search Page (P003). S006 is the transition from the Login Page to the Job Apply Page (P004). After a successful login, the actor is authenticated and therefore acts as an **applicant**.
    *   **Correct Answer:** `a) applicant`
*   **D (Blank D - Display Message MSG03):** MSG03 is shown when transitioning from the Job Apply Page (P004) back to the Login Page (P002). The use case description for "Job Apply" states: "When the applicant cancels the job application operation, go to the Login page to display menu." Thus, the corresponding message is for a canceled application.
    *   **Correct Answer:** `a) Job application canceled`
*   **E (Blank E - Email Message EM02):** EM02 is triggered when transitioning from the Job Apply Page (P004) to the Logout Page (P007). The use case description states: "When the applicant has completed the job application operation, the system sends an email to the applicant and go to the Logout page to exit." Therefore, the email confirms the completion of the application.
    *   **Correct Answer:** `b) Job application completed`

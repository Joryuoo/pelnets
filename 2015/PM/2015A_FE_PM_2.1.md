### Explanation

**Blank A (FCFS for P3):**
In First Come First Serve (FCFS), processes execute based on arrival time.
- **P1** (Arrival 0, Time 5) executes from 0 to 5.
- **P2** (Arrival 1, Time 3) executes from 5 to 8.
- **P3** (Arrival 2, Time 8) executes from 8 to 16.

For P3:
- Waiting Time = Start Time (8) - Arrival Time (2) = 6
- Response Time = First Response (8) - Arrival Time (2) = 6
- Turn-around Time = Waiting Time (6) + Processing Time (8) = 14
This matches option **c) 6, 6, 14**.

**Blank B (SJF for P4):**
In Shortest-Job-First (SJF), the prompt states scheduling starts when all are ready (effectively treating arrival time as 0 for all). Processes execute in order of processing time: P2 (3), P1 (5), P4 (6), P3 (8).
- **P2** executes 0 to 3.
- **P1** executes 3 to 8.
- **P4** executes 8 to 14.

For P4:
- Waiting Time = 8
- Response Time = 8
- Turn-around Time = Waiting Time (8) + Processing Time (6) = 14
This matches option **b) 8, 8, 14**.

**Blank C (RR Execution Sequence):**
In Round Robin (RR) with quantum 3:
- **0-3:** P1 executes. Queue is formed by arrivals: P2 (at 1), P3 (at 2), P4 (at 3). At time 3, P1 is requeued. Queue: `P2, P3, P4, P1`.
- **3-6:** P2 executes and completes. Queue: `P3, P4, P1`.
- **6-9:** P3 executes. Requeued at 9. Queue: `P4, P1, P3`.
- **9-12:** P4 executes. Requeued at 12. Queue: `P1, P3, P4`.
- **12-14:** P1 executes for its remaining 2 units and completes. Queue: `P3, P4`.
- **14-17:** P3 executes. Requeued at 17. Queue: `P4, P3`.
- **17-20:** P4 executes and completes. Queue: `P3`.
- **20-22:** P3 executes for its remaining 2 units and completes.

The sequence of execution starting from time 9 (after the first P3 block) is P4, P1, P3, P4, P3.
This matches option **c)**.

**Blank D (RR for P1):**
For P1 in Round Robin:
- P1 executes from 0 to 3, waits, then executes from 12 to 14.
- Waiting Time = (Start of 2nd slice - End of 1st slice) = 12 - 3 = 9.
- Response Time = Start of 1st slice (0) - Arrival Time (0) = 0.
- Turn-around Time = Total Waiting Time (9) + Processing Time (5) = 14.
This matches option **b) 9, 0, 14**.

# 2015May_FE_37
Which of the following is an appropriate description concerning "HTTP cookie"?

a) HTTP cookies are created by a web browser and stored in the web server.
b) HTTP cookies are used to contain data sent from a web server as plain text only.
c) HTTP cookies can contain executable codes to perform some specific tasks.
d) HTTP cookies cannot notify the visiting website about user's previous activities.
?
b) HTTP cookies are used to contain data sent from a web server as plain text only.
### Explanation
An **HTTP cookie** is a small piece of data sent from a website (web server) and stored locally in the user's web browser. Cookies are strictly stored as plain text (key-value pairs) and are used to remember stateful information.

*   **a) is incorrect** because cookies are created by the web server and stored in the web browser (client-side), not the other way around.
*   **c) is incorrect** because cookies cannot contain executable code (like a virus or a script); they are just plain text data.
*   **d) is incorrect** because one of the main purposes of a cookie is to identify the user and notify the website about their previous activities (like login state, preferences, or shopping cart contents).

### Explanation
A JK flip-flop operates based on the J and K inputs when triggered by the clock signal. The standard truth table for a JK flip-flop is as follows:

| J | K | Q (Output) |
|---|---|---|
| 0 | 0 | No change |
| 0 | 1 | 0 (Reset) |
| 1 | 0 | 1 (Set) |
| 1 | 1 | Toggle |

Choice A exactly matches this standard truth table behavior for a JK flip-flop.

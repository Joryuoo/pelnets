# 2015A_FE_7
For a pair of a queue and a stack, two operations "pop_enq" and "deq_push" are defined as follows:

pop_enq : pops an item from the stack and puts it into the queue
deq_push : takes an item from the queue and pushes it into the stack

When four items A, B, C, and D are stored in the queue, what is the minimum number of deq_push operations required in order to reverse the order of the four items by using only these two operations?

a) 2
b) 3
c) 4
d) 5
?
b) 3
### Explanation
Initial state:
- Queue: `[A, B, C, D]` (front is A)
- Stack: `[]` (empty)

To reverse the order without needlessly moving `D` (which is already at the correct relative back position initially, and will end up at the front), we just need to move `A, B, C` out of the way into the stack:
1. `deq_push` (A): Queue `[B, C, D]`, Stack `[A]`
2. `deq_push` (B): Queue `[C, D]`, Stack `[A, B]`
3. `deq_push` (C): Queue `[D]`, Stack `[A, B, C]` (top is C)

Now we pop from the stack and enqueue:
1. `pop_enq` (C): Queue `[D, C]`, Stack `[A, B]`
2. `pop_enq` (B): Queue `[D, C, B]`, Stack `[A]`
3. `pop_enq` (A): Queue `[D, C, B, A]`, Stack `[]`

We only needed 3 `deq_push` operations!

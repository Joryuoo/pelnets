# 2015May_FE_27
Which of the following is a tag-based very flexible image file format that can be lossless or lossy, and is widely used for the interchange of digital image data among graphic artists, photographers, and the publishing industry?

a) JPEG
b) GIF
c) PNG
d) TIFF
?
d) TIFF
### Explanation
TIFF (Tagged Image File Format) is a highly flexible, tag-based image format favored in the publishing, graphic arts, and photography industries due to its support for high-quality, lossless, or lossy image storage and layered data.

* Choice A (JPEG) is mainly used for lossy compression of photographs.
* Choice B (GIF) supports simple animations but is limited to a 256-color palette.
* Choice C (PNG) is widely used on the web for lossless image compression and transparency support, but is not traditionally the primary interchange format for high-end print publishing.

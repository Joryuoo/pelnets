# 2015May_FE_12
There exists a system that requires the execution of 800,000 instructions per transaction.
When the processor performance is 200 MIPS and the utilization rate of the processor is 80%, what is the processing power in transactions per second?

a) 20 
b) 200 
c) 250 
d) 313 
?
b) 200
### Explanation
The processor performance is 200 MIPS (Million Instructions Per Second) = $200 \times 10^6 = 200,000,000$ instructions per second.
With an 80% utilization rate, the effective performance is:
$200,000,000 \times 0.80 = 160,000,000$ instructions per second.

Each transaction requires 800,000 instructions. 
The processing power in transactions per second is:
$160,000,000 / 800,000 = 200$ transactions per second.

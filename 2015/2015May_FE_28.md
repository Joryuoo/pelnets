# 2015May_FE_28
In a relational database table, which of the following is a column or a combination of columns whose values are defined by the primary key of another table in order to maintain referential integrity in the database?

a) Candidate key
b) Foreign key
c) Super key
d) Surrogate key
?
b) Foreign key
### Explanation
A foreign key is a column or group of columns in a relational database table that provides a link between data in two tables. It references the primary key of another table to strictly enforce referential integrity.

* Choice A (Candidate key) is a column or set of columns that can uniquely identify any database record without referring to other data.
* Choice C (Super key) is any combination of columns that uniquely identifies a row within a table.
* Choice D (Surrogate key) is an artificially generated key, typically an auto-incrementing integer, used as a primary key.

# 2015A_FE_48
![[2015A_FE_AM_Q48_full.png]]

a) An instance of Class1 associated with has an instance of Class2.
b) An instance of Class2 is a logical part of an instance of Class1.
c) An instance of Class2 is a physical part of an instance of Class1.
d) An instance of Class2 is like an instance of Class1. Class2 inherits from Class1.
?
b) An instance of Class2 is a logical part of an instance of Class1.
### Explanation
The provided UML diagram shows a hollow diamond at the `Class1` end of the relationship line connecting to `Class2`. This symbol represents an **Aggregation** relationship. Aggregation implies a "whole/part" relationship, specifically a shared or logical part, meaning that `Class2` is a part of `Class1`, but the instances of `Class2` can exist independently of `Class1`.
- a) describes a simple Association (a plain line without a diamond).
- c) describes a Composition (a solid/filled diamond), which implies strong physical ownership and coincident lifetime.
- d) describes Generalization/Inheritance (a line with a hollow triangle pointing to the superclass).

# 2015May_FE_8

c) 91
### Explanation
This function is known as McCarthy's 91 function. The rules are:
- If $n > 100$, then $M(n) = n - 10$
- If $n \leq 100$, then $M(n) = M(M(n + 11))$

Let's evaluate $M(97)$:
- $M(97) = M(M(108))$
- Since $108 > 100$, $M(108) = 108 - 10 = 98$. So $M(97) = M(98)$.
- $M(98) = M(M(109))$
- $M(109) = 109 - 10 = 99$. So $M(98) = M(99)$.
- $M(99) = M(M(110))$
- $M(110) = 110 - 10 = 100$. So $M(99) = M(100)$.
- $M(100) = M(M(111))$
- $M(111) = 111 - 10 = 101$. So $M(100) = M(101)$.
- Since $101 > 100$, $M(101) = 101 - 10 = 91$.

Working back up the chain:
$M(97) = M(98) = M(99) = M(100) = M(101) = 91$.
The final value is 91.

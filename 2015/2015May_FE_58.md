# 2015May_FE_58
Which of the following is an explanation of a “known error” in IT service management?

a) A new incident concerning which the service desk receives an inquiry
b) A problem whose root cause is already identified or for which a workaround exists
c) A program error detected during static inspection
d) An inconsistency or insufficiency in service management planning
?
b) A problem whose root cause is already identified or for which a workaround exists
### Explanation
In IT Service Management (ITIL), a **known error** is a problem that has a documented root cause and a workaround. Once a problem is successfully diagnosed and a temporary or permanent fix is identified, it transitions into a known error record, allowing service desk staff to quickly resolve future incidents of the same type.

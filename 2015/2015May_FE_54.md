# 2015May_FE_54
![[2015May_FE_AM_Q54_full.png]]

a) A → B → E → I → L
b) A → C → D → E → H → K
c) A → C → F → I → L
d) A → C → G → J → L
?
d) A → C → G → J → L
### Explanation
The **critical path** is the longest continuous path from the start to the end of a project. It determines the minimum time required to complete the entire project.

Let's calculate the duration of the paths shown in the options:
* **a) A(2) → B(3) → E(3) → I(1) → L(3)** = 12 days
* **b) A(2) → C(3) → D(1) → E(3) → H(2) → K(2)** = 13 days
* **c) A(2) → C(3) → F(2) → I(1) → L(3)** = 11 days
* **d) A(2) → C(3) → G(4) → J(3) → L(3)** = 15 days

The longest path takes 15 days, which makes option **d** the critical path.

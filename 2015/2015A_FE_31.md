# 2015A_FE_31
Which of the following is the role of DNS in a TCP/IP network? 

a) A private IP address is translated into a global IP address in order to access the Internet. 
b) A program in a server can be invoked only by its name without taking the IP address of the server into consideration. 
c) In response to an assignment request of an IP address from a PC or a printer, an unused address is chosen from the addresses registered in the server. 
d) IP addresses are mapped to domain names, host names, and other such information. 
?
d) IP addresses are mapped to domain names, host names, and other such information. 
### Explanation
DNS (Domain Name System) is a protocol used to translate domain names and host names into IP addresses, and vice versa.

- **a)** Describes NAPT (Network Address Port Translation) or NAT (Network Address Translation).
- **b)** Describes RPC (Remote Procedure Call).
- **c)** Describes DHCP (Dynamic Host Configuration Protocol).

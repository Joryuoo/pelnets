# 2015May_FE_22
Which of the following is classified as a function of a static test tool?

a) Calculating the coverage from the paths executed by the test
b) Detecting an error in a program by analyzing the source code
c) Generating a driver or a stub necessary for the module to be tested
d) Generating the data for testing a specific path of the program
?
b) Detecting an error in a program by analyzing the source code
### Explanation
Static testing tools analyze the source code without actually executing the program. Detecting errors by scanning or reviewing the source code is characteristic of static analysis.

* Choice A refers to a dynamic analysis tool (coverage analyzer) which runs the code.
* Choice C refers to test harness generation, typically used for dynamic testing.
* Choice D refers to test data generation tools used for dynamic execution testing.

# 2015A_FE_4
Which of the following is a language processor that produces executable code for other platforms than the one on which the language processor itself is running?

a) Cross compiler
b) Emulator
c) Generator
d) Simulator
?
a) Cross compiler
### Explanation
A cross compiler is a compiler capable of creating executable code for a platform other than the one on which the compiler is running. 

- **Emulator**: Software or hardware that enables one computer system to behave like another computer system.
- **Generator**: A program that produces source code or machine code based on specific parameters or models.
- **Simulator**: Software that imitates the operations or characteristics of a real-world process or system.

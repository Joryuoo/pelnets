# 2015A_FE_78
Break-even point of the new product is 12,000 units a month. Fixed cost is 800,000 dollars a month and variable cost is 20 dollars per unit. Based on the information above, which of the following is a selling price of the new product?

a) 46.67
b) 66.67
c) 86.67
d) 89.23
?
c) 86.67
### Explanation
The break-even point (in units) is calculated using the formula:
`Break-Even Point (Units) = Fixed Cost / (Selling Price - Variable Cost per unit)`

Given the values:
* Break-Even Point = 12,000 units
* Fixed Cost = $800,000
* Variable Cost = $20

Let `P` be the selling price.
`12,000 = 800,000 / (P - 20)`
`12,000 * (P - 20) = 800,000`
`P - 20 = 800,000 / 12,000`
`P - 20 = 800 / 12`
`P - 20 = 66.666...`
`P = 66.67 + 20 = 86.67`

The selling price is $86.67.

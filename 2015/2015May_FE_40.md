# 2015May_FE_40
Which of the following is a characteristic of the hash function that is used for a digital signature?

a) Even if messages are different, the message digests are all the same.
b) It is difficult to restore an original message from the message digest.
c) The length of a message digest differs depending on the length of the message.
d) Two different messages that generate the same message digest are easily obtained.
?
b) It is difficult to restore an original message from the message digest.
### Explanation
A cryptographic hash function used for digital signatures must have several properties, primarily **pre-image resistance** (one-wayness). This means it is computationally infeasible to reverse the process and derive the original message from its hash value (message digest).

*   **a) is incorrect:** Hash functions should produce significantly different digests for different messages.
*   **c) is incorrect:** Hash functions always produce a fixed-length output (digest) regardless of the input message size.
*   **d) is incorrect:** This describes a lack of collision resistance. A strong cryptographic hash function is collision-resistant, meaning it is exceedingly difficult to find two different messages that produce the same hash digest.

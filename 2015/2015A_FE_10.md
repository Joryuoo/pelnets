a) Direct addressing
b) Index addressing
c) Indirect addressing
d) Relative addressing
?
c) Indirect addressing
### Explanation
In the given figure, the address part of the instruction points to a memory location (Address 20), which in turn contains the effective address (Address 25) where the actual data is stored.
This two-step process of resolving the address is the characteristic feature of **Indirect addressing**.

- **Direct addressing**: The address part contains the effective address of the operand.
- **Index addressing**: The effective address is calculated by adding an index register value to the address part.
- **Relative addressing**: The effective address is calculated by adding the program counter to the address part.

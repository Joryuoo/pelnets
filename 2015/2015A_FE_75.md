d) Objective function 40x+30y -> to be maximized, Constraints 3x+y <= 3000, x <= 8000, y <= 1200, x >= 0, y >= 0
### Explanation
The problem asks for the formulation of a linear programming model to maximize profit.
1. **Objective function:** The profit is $40 per unit of A and $30 per unit of B. Total profit to be maximized is `40x + 30y`.
2. **Constraints:**
   * Total production capacity is 3000 person-hours.
   * Product A requires 3 person-hours per unit. 
   * Since Product A's production time is three times longer than Product B's, Product B takes `3 / 3 = 1` person-hour per unit.
   * The total time constraint is `3x + y <= 3000`.
   * Market constraints: maximum sales of A is 8000 (`x <= 8000`) and B is 1200 (`y <= 1200`).
   * Non-negativity constraint: `x >= 0, y >= 0`.
This matches the formulation in choice d).

# 2015A_FE_40
Which of the following is an appropriate operation in user authentication that uses an IC card and PIN? 

a) If an IC card is lost, a new IC card is issued, and after the PIN is reset, the lost IC card is deactivated. 
b) Since each user can be identified by an IC card, a common PIN is set for all users in order to reduce the management workload. 
c) The PIN is set by combining the numeric information imprinted on the surface of the IC card. 
d) When an IC card is delivered, the PIN is not enclosed, but is notified to the user through another channel. 
?
d) When an IC card is delivered, the PIN is not enclosed, but is notified to the user through another channel. 
### Explanation
In two-factor authentication systems using an IC card (something you have) and a PIN (something you know), the delivery of both components must be kept separate to ensure security. If they are delivered together and intercepted, an attacker would have full access.

- **a)** If an IC card is lost, it must be deactivated immediately before a new card is issued, not after.
- **b)** Using a common PIN defeats the purpose of the PIN as a unique identifier and security measure.
- **c)** The PIN should not be derived from information printed on the card itself, as anyone possessing the card could guess the PIN.

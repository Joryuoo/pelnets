# 2015A_FE_64
Which of the following is the cloud-computing service model that allows users to install operating-system images and their application software on the system?

a) Desktop as a service (DaaS)
b) Infrastructure as a service (IaaS)
c) Platform as a service (PaaS)
d) Software as a service (SaaS)
?
b) Infrastructure as a service (IaaS)
### Explanation
**IaaS (Infrastructure as a Service)** provides virtualized computing resources (servers, storage, and networking) over the internet. This allows users to have full control over the infrastructure, including the ability to install and manage their own operating systems and applications.

* **a) DaaS** provides virtual desktops to end-users over a network.
* **c) PaaS** provides a platform allowing customers to develop, run, and manage applications without building and maintaining the infrastructure (the OS and servers are managed by the cloud provider).
* **d) SaaS** provides ready-to-use software applications delivered over the internet, completely managed by the provider.

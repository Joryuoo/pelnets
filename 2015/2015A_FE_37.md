# 2015A_FE_37
Which of the following is a purpose of using message digest in a message authentication code? 

a) To check the encryption method of a message 
b) To check the overview of a message 
c) To confirm that there is no falsification of a message 
d) To secure the confidentiality of a message 
?
c) To confirm that there is no falsification of a message 
### Explanation
A message digest (generated by a hash function) is a fixed-size string representing the original message. In a Message Authentication Code (MAC), the digest ensures data integrity and authenticity. If the message is altered in transit, the received message's digest will not match the expected digest, indicating falsification.

- **d)** Confidentiality is secured by encryption algorithms, not message digests.

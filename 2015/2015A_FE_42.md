# 2015A_FE_42
When a biometric authentication system is installed, which of the following is the most appropriate point to be considered?

a) Adjusting the system in consideration of both the probability of incorrectly rejecting an authorized user and the probability of incorrectly accepting an unauthorized user
b) Combining various measures, such as heuristics, in addition to frequent updates of the pattern file
c) Getting a reliable third party to issue the digital certificate of the concerned person
d) Using a library having the function of sanitizing data that may initiate system malfunction
?
a) Adjusting the system in consideration of both the probability of incorrectly rejecting an authorized user and the probability of incorrectly accepting an unauthorized user
### Explanation
In biometric authentication, there is an inherent trade-off between the False Rejection Rate (FRR - incorrectly rejecting an authorized user) and the False Acceptance Rate (FAR - incorrectly accepting an unauthorized user). Adjusting the sensitivity threshold to balance these probabilities based on security requirements is a critical consideration.
- b) describes considerations for anti-malware/anti-virus systems.
- c) describes considerations for Public Key Infrastructure (PKI) and digital certificates.
- d) describes secure programming practices (sanitization) to prevent attacks like SQL injection or XSS.

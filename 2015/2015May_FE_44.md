# 2015May_FE_44
Which of the following is a feature that is incorporated by an attacker to enter the network or server of a company? 

a) Back door 
b) Digital forensics  
c) Strict routing  
d) Thin client agent  
?
a) Back door
### Explanation
A **back door** is a hidden method used to bypass normal authentication or encryption in a computer system, a product, or an embedded device. Attackers install back doors to ensure they can easily regain access to a compromised system in the future.

* **b) Digital forensics** is the investigation and recovery of material found in digital devices, typically used to analyze attacks, not perform them.
* **c) Strict routing** is a network routing technique, often restricted for security as attackers can use source routing to manipulate traffic.
* **d) Thin client agent** relates to a lightweight computer setup that relies heavily on a server for computational roles.

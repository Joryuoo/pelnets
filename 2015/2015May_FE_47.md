# 2015May_FE_47
Which of the following is an appropriate preventive measure against malware that is taken on a client PC? 

a) In a periodic manual inspection for viruses on a PC, a virus scan is performed only on the files created after the signature file of the anti-virus software is updated. 
b) In order that no PC is infected with a virus attached to an e-mail, communication with unused TCP ports is prevented. 
c) In order that no PC is invaded by a worm, a global IP address is dynamically assigned to a client PC. 
d) In order that no virus exploits a vulnerability and infects a PC, revised software modules or patches are appropriately applied to the OS and applications. 
?
d) In order that no virus exploits a vulnerability and infects a PC, revised software modules or patches are appropriately applied to the OS and applications.
### Explanation
Applying security patches and keeping software up-to-date is a fundamental preventive measure against malware. Malware often targets known vulnerabilities in outdated operating systems and applications.

* **a)** Virus scans should cover all files because an older file might be infected by a newly discovered virus pattern.
* **b)** Closing unused ports is good practice for blocking unauthorized access, but viruses attached to emails are usually delivered through standard email ports (like POP3 or IMAP) that must remain open.
* **c)** Using a dynamic IP address does not protect against worms that scan IP ranges. Network firewalls and NAT are more relevant here.

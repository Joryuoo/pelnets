# 2015May_FE_7
In a real time system, which of the following is the data structure that is most suitable for the scheduling of multiple tasks with different priority levels?

a) Binary tree
b) FIFO queue
c) Linked list
d) Stack
?
c) Linked list
### Explanation
In a real-time system, tasks need to be scheduled based on their dynamic or static priority levels. 
- A **linked list** allows for flexible insertion and deletion of tasks at any position, which is essential when a new high-priority task arrives and needs to be placed ahead of lower-priority tasks. It can be easily implemented as a priority queue.
- A binary tree is more complex and has higher overhead for simple scheduling.
- A FIFO (First-In, First-Out) queue strictly processes tasks in the order they arrive, ignoring priority.
- A stack processes tasks in Last-In, First-Out order, which is unsuitable for priority scheduling.

Thus, a linked list is the most suitable simple data structure.

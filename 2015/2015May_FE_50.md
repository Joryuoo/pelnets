# 2015May_FE_50
In software development, which of the following is an appropriate explanation of a test that uses stubs? 

a) During the execution of a program, the contents of a variable or register are displayed as required, and the test is continued after the contents are modified if necessary. 
b) Each time a specific instruction is executed, the contents of registers and main memory are dumped to check whether the process is executed correctly. 
c) When a top-down test is performed, a dummy lower-level module that is called by the upper-level module is prepared to stand in for an unfinished portion of the program. 
d) When a unit test for a module is performed, a dummy higher-level module that calls the module is prepared to check whether the operation is executed correctly. 
?
c) When a top-down test is performed, a dummy lower-level module that is called by the upper-level module is prepared to stand in for an unfinished portion of the program.
### Explanation
In software testing, a **stub** is a dummy program or module that acts as a substitute for a lower-level module that is called by the module currently being tested. This is typical in **top-down integration testing**.

* **a) and b)** Describe debugging techniques (like stepping through code and memory dumping).
* **d)** Describes a **driver**, which is a dummy upper-level module that calls the module being tested. Drivers are used in bottom-up integration testing.

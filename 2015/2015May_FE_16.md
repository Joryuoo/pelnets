# 2015May_FE_16
Which of the following is the most appropriate explanation of a benchmark test for a computer system? 

a) It is determined whether or not the system has a tolerance to handle the expected number of transactions. 
b) The performance of a system is measured from the average time required to execute a single instruction. 
c) The processing performance of a system is compared with other systems in terms of scores obtained by executing software for measurement. 
d) The proportion of continuous operation time of a system is measured and compared with other systems.  
?
c) The processing performance of a system is compared with other systems in terms of scores obtained by executing software for measurement.
### Explanation
A benchmark test evaluates and compares the performance of a computer system or component by running a standardized set of programs, tests, or operations against it, producing measurable scores.

- **a)** Incorrect. This describes a load test or stress test.
- **b)** Incorrect. This describes the measurement of an instruction cycle or CPI (Cycles Per Instruction), not a benchmark test.
- **d)** Incorrect. This describes measuring the availability (uptime proportion) of a system.

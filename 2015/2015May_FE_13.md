# 2015May_FE_13
Which of the following is an appropriate purpose of the parity check of a memory module? 

a) To detect and correct an error automatically during reading  
b) To detect the occurrence of an error during reading 
c) To determine whether power is supplied to the memory module  
d) To encrypt the data read out from the memory module 
?
b) To detect the occurrence of an error during reading
### Explanation
A parity check adds an extra bit (parity bit) to a unit of data to ensure the total number of 1-bits is either always even (even parity) or always odd (odd parity). During reading, the parity is checked to detect the occurrence of an error (such as a single bit flip). However, a simple parity check cannot identify which bit is flipped, so it cannot correct the error.

- **a)** Incorrect. Parity checks can only detect errors. Error correction codes (ECC) like Hamming code are needed to detect and correct errors automatically.
- **c)** Incorrect. Not related to parity checking.
- **d)** Incorrect. Parity checking does not involve data encryption.

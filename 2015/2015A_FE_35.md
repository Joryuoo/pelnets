# 2015A_FE_35
Which of the following is an appropriate explanation of POP3 used in e-mail systems? 

a) It is a protocol used to authenticate a user with his/her user ID and password after the PPP connection is established. 
b) It is a protocol used to exchange e-mail messages between mail servers. 
c) It is a protocol used to receive e-mail messages from the mailbox of a mail server. 
d) It is a protocol used to send e-mail messages from a PC. 
?
c) It is a protocol used to receive e-mail messages from the mailbox of a mail server. 
### Explanation
POP3 (Post Office Protocol version 3) is a standard mail protocol used to retrieve e-mails from a remote server to a local client.

- **a)** Describes PAP (Password Authentication Protocol) or CHAP used over PPP.
- **b)** Describes SMTP (Simple Mail Transfer Protocol), which is used for exchanging emails between mail servers.
- **d)** Describes SMTP, which is also used by an email client to send emails.

c) 15
### Explanation
SRT (Shortest Remaining Time First) is a preemptive scheduling algorithm where the process with the smallest remaining execution time is selected to run next.

Timeline of events:
- **T = 0:** P1 arrives. Ready queue: P1(20). P1 starts execution.
- **T = 15:** P2 arrives. 
  - Remaining time for P1 is $20 - 15 = 5$.
  - Remaining time for P2 is $25$.
  - Since $5 < 25$, P1 continues. P2 waits.
- **T = 20:** P1 finishes execution. 
  - Ready queue: P2(25). P2 starts execution.
- **T = 30:** P3 arrives.
  - P2 has executed for 10 units ($30 - 20 = 10$). Remaining time for P2 is $25 - 10 = 15$.
  - Remaining time for P3 is $10$.
  - Since $10 < 15$, P2 is preempted. P3 starts execution. P2 goes to waiting.
- **T = 40:** P3 finishes execution.
  - Ready queue: P2(15). P2 resumes execution.
- **T = 55:** P2 finishes execution.

Total waiting time for P2 = (Time from arrival to first execution) + (Time spent waiting after preemption)
Wait time = $(20 - 15) + (40 - 30) = 5 + 10 = 15$ seconds.

# 2015A_FE_6
![[2015A_FE_AM_Q6_full.png]]

a) 1
b) 2
c) 7
d) 11
?
b) 2
### Explanation
The hash function is defined as `mod(a1+a2+a3+a4+a5, 13)`.
For the number `54321`:
$a_1 = 5, a_2 = 4, a_3 = 3, a_4 = 2, a_5 = 1$

Sum of digits = $5 + 4 + 3 + 2 + 1 = 15$
$15 \pmod{13} = 2$

The position is 2.

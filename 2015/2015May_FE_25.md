# 2015May_FE_25
Which of the following is a memory module that uses a flip-flop circuit in a memory cell?

a) DRAM
b) EEPROM
c) SDRAM
d) SRAM
?
d) SRAM
### Explanation
SRAM (Static Random Access Memory) utilizes flip-flop circuits to store each bit of data. Because of this design, SRAM does not need to be periodically refreshed as long as power is supplied, making it faster but more expensive than DRAM.

* Choice A (DRAM) uses a capacitor and a transistor for each memory cell and requires periodic refreshing.
* Choice B (EEPROM) uses floating-gate transistors to store data persistently.
* Choice C (SDRAM) is a synchronous form of DRAM and also uses capacitors.

### Explanation
In an 8-bit D/A converter, the digital input varies linearly with the generated output voltage.
The problem states:
* Digital input `0` = `0 V`
* Digital input `128` = `2.5 V`

The relationship is linear, so the voltage generated per 1 unit of digital input (the lowest bit change) is computed as:
Output Voltage = $2.5 / 128$ Volts per bit

Therefore, when the lowest bit of the digital input changes (a value change of 1), the output voltage changes by $2.5 / 128$ V.

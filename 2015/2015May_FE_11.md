b) 0.90
### Explanation
Let $h$ be the hit ratio of cache memory.
The effective access time (EAT) of a CPU is: EAT = $h \times (\text{Cache Access Time}) + (1-h) \times (\text{Main Memory Access Time})$.

For CPU X:
EAT_X = $40h + 400(1-h) = 400 - 360h$

For CPU Y:
EAT_Y = $20h + 580(1-h) = 580 - 560h$

We are given that the processing time of both CPUs is the same, so their EATs must be equal.
$400 - 360h = 580 - 560h$
$200h = 180$
$h = 180 / 200 = 0.90$

Thus, the cache hit ratio is 0.90.

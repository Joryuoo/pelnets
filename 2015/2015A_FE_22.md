# 2015A_FE_22
![[2015A_FE_AM_Q22_p1.png]]

a) A B X (AND gate)
b) A B X (OR gate)
c) A B X (NAND gate)
d) A B X (XOR gate)
?
b) 

### Explanation
The logical expression provided simplifies using Boolean algebra:
X = A·B + A·B' + A'·B
X = A·(B + B') + A'·B
X = A·(1) + A'·B
X = A + A'·B
X = (A + A') · (A + B)
X = 1 · (A + B)
X = A + B

Therefore, X is the logical sum (OR) of A and B. The correct logic circuit is an OR gate, which corresponds to option b.

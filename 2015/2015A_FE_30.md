# 2015A_FE_30
![[2015A_FE_AM_Q30_p1.png]]

a) SELECT ProductNumber FROM Product WHERE EXISTS (SELECT ProductNumber FROM Product)
b) SELECT ProductNumber FROM Inventory WHERE NOT EXISTS (SELECT ProductNumber FROM Product)
c) SELECT ProductNumber FROM Product WHERE EXISTS (SELECT ProductNumber FROM Inventory WHERE Product.ProductNumber = Inventory.ProductNumber)
d) SELECT ProductNumber FROM Product WHERE NOT EXISTS (SELECT ProductNumber FROM Inventory WHERE Product.ProductNumber = Inventory.ProductNumber)
?
d) SELECT ProductNumber FROM Product WHERE NOT EXISTS (SELECT ProductNumber FROM Inventory WHERE Product.ProductNumber = Inventory.ProductNumber)

### Explanation
The original SQL statement retrieves all `ProductNumber` records from the `Product` table that do **NOT** appear in the `Inventory` table:
`WHERE ProductNumber NOT IN (SELECT ProductNumber FROM Inventory)`

To rewrite this using `EXISTS` logic, we use a correlated subquery with `NOT EXISTS`. This tests for the non-existence of rows in the `Inventory` table that share the exact `ProductNumber` as the outer `Product` table row:
`WHERE NOT EXISTS (SELECT ProductNumber FROM Inventory WHERE Product.ProductNumber = Inventory.ProductNumber)`

* **a)** Evaluates to true for all products as long as any product exists, lacking the connection to the Inventory.
* **b)** Returns Inventory items rather than Product items.
* **c)** Uses `EXISTS` instead of `NOT EXISTS`, which performs the opposite operation (analogous to `IN` rather than `NOT IN`).

# 2015A_FE_47
Among UML 2.x, (including 2.0 and later versions) diagrams, which of the following is the most appropriate diagram that can gives a graphic overview of the actors involved in a system, different functions needed by those actors and how these different functions are interacted?

a) Activity diagram
b) Communication diagram
c) Interaction Overview diagram
d) Use Case diagram
?
d) Use Case diagram
### Explanation
A Use Case diagram provides a high-level visual overview of a system's functionality. It identifies the external entities that interact with the system (actors) and the specific functions or services the system provides to those actors (use cases).
- a) Activity diagrams model the flow of control or object flow in a process.
- b) Communication diagrams model interactions and relationships between objects in terms of sequenced messages.
- c) Interaction Overview diagrams provide a high-level view of an interaction, combining activity and sequence diagram concepts.

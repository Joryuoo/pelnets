# 2015May_FE_36
A system administrator has a plan to monitor a network in order to evaluate which employees are using an excessive amount of bandwidth on peer-to-peer sharing services. Which of the following is the most appropriate technique for achieving such a purpose?

a) Dynamic packet filtering
b) Packet sniffing
c) Stateful packet inspection
d) Static packet filtering
?
b) Packet sniffing
### Explanation
**Packet sniffing** (or packet analysis) is the process of capturing and inspecting data packets traveling across a network. It is the appropriate technique for monitoring network traffic to analyze bandwidth usage and identify specific types of traffic (like peer-to-peer sharing) associated with different users.

*   **a) Dynamic packet filtering / c) Stateful packet inspection / d) Static packet filtering:** These are firewall technologies designed to block or allow traffic based on security rules, state, or ports. They do not typically evaluate or monitor "how much" bandwidth specific users are consuming for specific application services in a detailed analytical way.

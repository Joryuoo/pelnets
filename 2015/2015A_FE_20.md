# 2015A_FE_20
Which of the following is an explanation of an absolute path name of a file system?

a) It is the path name from the current directory up to the target file.
b) It is the path name from the home directory up to the target file.
c) It is the path name from the root directory up to the target file.
d) It is the shortest path name from among the several path names from a directory up to the target file.
?
c) It is the path name from the root directory up to the target file.
### Explanation
An **absolute path name** (also known as a full path) represents the complete, unambiguous sequence of directories from the root directory (the top-most directory in the file system hierarchy) down to the target file or directory. Because it starts from the root, an absolute path name will always correctly identify the file, regardless of the user's current working directory.

* **a)** describes a **relative path name**, which defines a file's location relative to the current working directory.

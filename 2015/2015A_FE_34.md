# 2015A_FE_34
Which application protocol must support UDP as its transport layer protocol? 

a) DNS 
b) FTP 
c) HTTP 
d) Telnet 
?
a) DNS 
### Explanation
DNS (Domain Name System) primarily uses UDP (User Datagram Protocol) at the transport layer for its queries and responses, as it provides low overhead and fast transmission. (It can also use TCP for zone transfers and large responses).

- **b) FTP (File Transfer Protocol):** Uses TCP (ports 20 and 21) for reliable data transfer.
- **c) HTTP (Hypertext Transfer Protocol):** Uses TCP (port 80) for reliable communication.
- **d) Telnet:** Uses TCP (port 23) for terminal emulation.

# 2015A_FE_15
Which of the following is an appropriate description concerning the reliability of a computer system?

a) As the system configuration becomes more complicated, MTBF (Mean Time Between Failures) increases.
b) Availability of systems can be improved by increasing MTTR (Mean Time To Repair) and MTBF.
c) Preventive maintenance of systems is performed to increase MTBF.
d) Remote maintenance of systems can increase MTTR and improve availability.
?
c) Preventive maintenance of systems is performed to increase MTBF.
### Explanation
**MTBF (Mean Time Between Failures)** is a measure of the reliability of a system, representing the average time the system operates without failure. **Preventive maintenance** is proactively performed to prevent failures before they occur, thus increasing the time between failures (MTBF).

* **a) is incorrect** because a more complicated system generally has a lower MTBF. More components usually mean a higher probability that at least one component will fail.
* **b) is incorrect** because increasing MTTR (Mean Time To Repair) means repairs take longer, which decreases availability. To improve availability, MTTR should be decreased.
* **d) is incorrect** because remote maintenance aims to decrease MTTR (by allowing faster diagnoses and repairs without physical travel), not increase it.

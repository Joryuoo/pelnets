# 2025A_FE-A_18

Which of the following is the appropriate explanation of attributes in the relational model?

a) It is possible to define attributes that have no name.
b) The domains of definition for attributes within a relation must not overlap.
c) The same name can be given to two (2) or more attributes in a relation.
d) There is no meaning in the order of attributes within a relation, and the relation remains unchanged even if the order is changed.
?
d) There is no meaning in the order of attributes within a relation, and the relation remains unchanged even if the order is changed.

### Explanation
In the relational database model, a relation (table) consists of a set of tuples (rows) and a set of attributes (columns).

- **Option (a) is incorrect**: Every attribute in a relation must have a unique, well-defined name to be distinguishable.
- **Option (b) is incorrect**: Different attributes within a relation can share the same domain (e.g., both "Employee_Age" and "Manager_Age" can use the domain of integers from 18 to 65).
- **Option (c) is incorrect**: Every attribute within a specific relation must have a unique name. You cannot have two columns named "ID" in the same table.
- **Option (d) is correct**: A relation is mathematically defined as a set of tuples over a set of attributes. Since attributes form a *set*, there is no inherent order to them. The relation is logically identical regardless of how the columns are ordered.

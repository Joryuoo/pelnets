# 2025A_FE-A_2

Let $n$ be a binary integer represented in two’s complement. Which of the following is the operation that results in the value $9 \times n$ using only bit shifting and an addition or subtraction?

a) Shift $n$ 2 bits to the left, then add $n$ to the result.
b) Shift $n$ 2 bits to the left, then subtract $n$ from the result.
c) Shift $n$ 3 bits to the left, then add $n$ to the result.
d) Shift $n$ 3 bits to the left, then subtract $n$ from the result.
?
c) Shift $n$ 3 bits to the left, then add $n$ to the result.

### Explanation

We need to compute $9 \times n$ using only bit shifting and addition/subtraction.

**1. Break down the multiplier (9)**
The multiplier 9 can be rewritten as a power of 2 plus an offset:
$9 = 8 + 1$

Therefore, the equation becomes:
$9 \times n = (8 + 1) \times n$
$9 \times n = 8n + n$

**2. Relate multiplication to bitwise shifts**
In binary arithmetic, multiplying a number by $2^k$ is equivalent to bit shifting the number to the left by $k$ bits.
Since $8 = 2^3$, multiplying a number by $8$ is the same as shifting it to the left by $3$ bits.

So, $8n$ is computed by shifting $n$ by $3$ bits to the left.

**3. Combine everything**
To compute $9n = 8n + n$, we must:
1. Shift $n$ 3 bits to the left (this gives us $8n$).
2. Add $n$ to the result (this gives us $8n + n = 9n$).

This perfectly aligns with choice **c**.

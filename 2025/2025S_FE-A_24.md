# 2025S_FE-A_24

Q24. In the OSI model, which of the following is the layer that is responsible for routing datagrams between hosts utilizing IP addresses across one or more networks? 
a) Data link 
b) Network 
c) Physical 
d) Transport 
?
b) Network 

### Explanation
- **Network Layer (Layer 3)**: This layer is responsible for logical addressing and routing. It routes datagrams (packets) between hosts across different networks using IP addresses.
- **Data link (Layer 2)**: Handles physical addressing (MAC addresses) and frame delivery on a single local network segment.
- **Physical (Layer 1)**: Deals with the physical transmission of raw raw bits over a communication channel (cables, wireless signals).
- **Transport (Layer 4)**: Handles end-to-end communication, reliability, and flow control (TCP/UDP).

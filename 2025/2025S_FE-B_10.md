e) current.next, current.prev.next

### Explanation
The procedure `deleteLast()` removes the final element of a doubly linked list. 

First, we traverse the list to find the last element:
```pseudo
current ← listHead
while (___A___ is not undefined)
    current ← current.next
endwhile
```
The last element of the list is identifiable because its `next` reference is `undefined`. To traverse the list and stop *exactly* on the last element, the loop must continue as long as `current.next` is not undefined. Thus, **A** is `current.next`.

Next, we handle the deletion:
```pseudo
if (current.prev is not undefined) // multiple elements are present
    ___B___ ← undefined
```
Once `current` points to the last element, we must detach it from the list. The node preceding `current` is `current.prev`. To make `current.prev` the new last element, we must set its `next` pointer to `undefined`.
Therefore, **B** is `current.prev.next`.

Combining these gives option (e).

| Variable | Points to | Action Required |
|---|---|---|
| `current` | The last node | Node to be deleted |
| `current.prev` | The second-to-last node | Needs to become the new last node |
| `current.prev.next` | The link to the old last node | Must be set to `undefined` |

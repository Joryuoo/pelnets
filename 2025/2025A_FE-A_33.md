### Explanation
A **Web Application Firewall (WAF)** is designed to filter, monitor, and block HTTP traffic to and from a web application. It protects web applications from attacks such as cross-site scripting (XSS), SQL injection, and cookie poisoning.

Since the problem states that the WAF **has no function to encrypt or decrypt communications**, it must be placed where the traffic is unencrypted (plain HTTP). 

Looking at the diagram:
- Traffic between the Internet and the SSL accelerator is encrypted (HTTPS).
- The SSL accelerator terminates the SSL/TLS connection and decrypts the traffic.
- Traffic between the SSL accelerator and the Web Server is unencrypted (HTTP).

Therefore, the WAF must be placed at **C** so it can inspect the unencrypted HTTP traffic before it reaches the web server.

# 2025S_FE-A_9

When a CPU has a special register used in push and pop instructions, which of the following is an appropriate term for this register?

a) Instruction register
b) Program counter
c) Stack pointer
d) Status register
?
c) Stack pointer

### Explanation
In computer architecture, a stack is a Last-In, First-Out (LIFO) data structure used heavily for subroutine execution, local variable storage, and state preservation.

The primary operations for a stack are:
- **PUSH:** Add an item to the top of the stack.
- **POP:** Remove the item from the top of the stack.

The CPU utilizes a special register called the **Stack Pointer (SP)** to keep track of the current top of the stack in memory. When a `PUSH` instruction is executed, the Stack Pointer is decremented/incremented (depending on architecture) to point to the next available memory location, and the data is stored. When a `POP` instruction is executed, data is retrieved from the location the Stack Pointer indicates, and it is subsequently adjusted back.

**Other Registers:**
- **Instruction Register (IR):** Holds the instruction currently being executed or decoded.
- **Program Counter (PC):** Holds the memory address of the next instruction to be fetched and executed.
- **Status Register (SR / Flags):** Holds the status flags (like zero, carry, overflow) that reflect the result of the last ALU operation.

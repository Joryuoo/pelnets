### Explanation
The Address Resolution Protocol (ARP) is used to map an IP address (Network Layer) to a MAC address (Data Link Layer). 
When a device needs to find the MAC address associated with a specific IP address on the local network, it broadcasts an ARP request. 
Since the sender does not yet know the destination's MAC address, the ARP request must be sent as a broadcast so that all devices on the local subnet receive and process it. The broadcast MAC address consists of all 1s in binary, which is represented in hexadecimal as `FF:FF:FF:FF:FF:FF`.

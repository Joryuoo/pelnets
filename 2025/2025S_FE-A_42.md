# 2025S_FE-A_42

Which of the following is the method of estimation in the COCOMO model in software estimation?

a) The effort and duration of the project are estimated based on the size of the software.
b) The effort of the project is estimated based on the duration of the project.
c) The size of the software and duration of the project are estimated based on the effort of the project.
d) The size of the software and effort of the project are estimated based on the duration of the project.
?
a) The effort and duration of the project are estimated based on the size of the software.

### Explanation
The **Constructive Cost Model (COCOMO)** is a procedural software cost estimation model developed by Barry Boehm. 

**How COCOMO works:**
1. **Size Estimation:** It starts by estimating the size of the software project, typically measured in **Lines of Code (LOC)** or Kilo Lines of Code (KLOC).
2. **Effort and Duration Calculation:** Using the estimated size, mathematical formulas (based on historical project data) are applied to calculate the required **effort** (e.g., in person-months) and the scheduled **duration** (e.g., in months) of the project.

**Formulas in Basic COCOMO:**
- $\text{Effort} = a \times (\text{KLOC})^b$
- $\text{Duration} = c \times (\text{Effort})^d$
*(Where $a$, $b$, $c$, and $d$ are constants that depend on the project type: Organic, Semi-detached, or Embedded).*

Let's evaluate the options:
- **a) Correct.** Effort and duration are derived from the software's size (KLOC).
- **b) Incorrect.** Effort is not based on duration.
- **c) Incorrect.** Size is the input, not the output.
- **d) Incorrect.** Size and effort are not based on duration.

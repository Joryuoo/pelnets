### Explanation
The question requires us to complete the `isLeapYear` function that correctly identifies leap years based on the standard rules:
1. Centurial years (divisible by 100) are **not** leap years, *except* those exactly divisible by 400.
2. Non-centurial years are leap years if they are divisible by 4.

The program uses an `if-elseif` structure:
```pseudo
if (____A____) 
    return ____B____
elseif (____C____) 
    return false 
elseif (year mod 4 = 0) 
    return true 
else 
    return false 
endif 
```
Since the `if-elseif` statements evaluate from top to bottom, we need to handle the most specific or overriding conditions first. 
- If a year is divisible by 400, it is definitely a leap year, bypassing the 100-year rule. Thus, if `year mod 400 = 0` (Condition A), it should return `true` (Result B).
- The next case handles centurial years that are *not* divisible by 400. If `year mod 100 = 0` (Condition C), it is not a leap year, so it returns `false`.
- Finally, the remaining years just check divisibility by 4 (`year mod 4 = 0`), returning `true` if so, and `false` otherwise.

Therefore, `A` is `year mod 400 = 0`, `B` is `true`, and `C` is `year mod 100 = 0`.

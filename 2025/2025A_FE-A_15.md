# 2025A_FE-A_15

The page capacity of main memory is three pages, and the pages are referenced in the order {1, 2, 3, 2, 1, 4, 5}. Which of the following is the page that will be replaced from main memory for the last page reference if LRU is used as the page replacement technique?

a) 1
b) 2
c) 3
d) 4
?
b) 2

### Explanation
**LRU (Least Recently Used)** is a page replacement algorithm that replaces the page that has not been used for the longest period of time.

Let's trace the memory states (capacity = 3 pages) for the sequence **1, 2, 3, 2, 1, 4, 5**:

| Step | Page Referenced | Memory State (Most to Least Recently Used) | Action / Page Replaced |
| :---: | :---: | :--- | :--- |
| 1 | **1** | [1] | Page fault (1 loaded) |
| 2 | **2** | [2, 1] | Page fault (2 loaded) |
| 3 | **3** | [3, 2, 1] | Page fault (3 loaded) |
| 4 | **2** | [2, 3, 1] | Page hit (2 moves to most recent) |
| 5 | **1** | [1, 2, 3] | Page hit (1 moves to most recent) |
| 6 | **4** | [4, 1, 2] | Page fault (3 is replaced, 4 loaded) |
| 7 | **5** | [5, 4, 1] | Page fault (**2 is replaced**, 5 loaded) |

For the last page reference (page 5), the memory holds pages `4`, `1`, and `2` (in order from most to least recently used). The least recently used page at this point is **2**. Therefore, page **2** will be replaced.

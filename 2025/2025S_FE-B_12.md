h) s1[i] ≠ s2[i]

### Explanation

The function `hammingDistance` compares two character arrays of the same length and counts the number of positions where the characters differ. 

**Step-by-Step Breakdown:**
1. **Length Check:** The function first checks if `s1` and `s2` have a different number of elements. If so, it returns `-1`.
2. **Iteration:** It iterates through the arrays using index `i`, starting from `1` up to the number of elements.
3. **Comparison:** At each index `i`, we need to check if the character in `s1` is different from the character in `s2`. If they are different, it means we have found a mismatch and should increment our counter `cnt`.
4. Therefore, the condition to increment the counter is when the character at index `i` in `s1` is not equal to the character at index `i` in `s2`.
5. This is written as `s1[i] ≠ s2[i]`.

**Example Trace (APPLE vs APRIE):**

| Index `i` | `s1[i]` | `s2[i]` | `s1[i] ≠ s2[i]` | `cnt` (after if) |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 'A' | 'A' | False | 0 |
| 2 | 'P' | 'P' | False | 0 |
| 3 | 'P' | 'R' | **True** | 1 |
| 4 | 'L' | 'I' | **True** | 2 |
| 5 | 'E' | 'E' | False | 2 |

The final distance is `2`, correctly capturing the mismatches.

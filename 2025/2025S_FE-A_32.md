# 2025S_FE-A_32

Which of the following is the function of a WAF? 
a) Encrypting data and controlling access on web server 
b) Inspecting and filtering HTTP requests 
c) Managing user authentication and authorization 
d) Scanning malware on a web server
?
b) Inspecting and filtering HTTP requests

### Explanation
WAF stands for **Web Application Firewall**. 
- A WAF is designed to protect web applications by inspecting, filtering, and monitoring HTTP/HTTPS traffic between a web application and the Internet.
- It protects against attacks such as SQL injection, cross-site scripting (XSS), and other web-specific vulnerabilities.
- Unlike a standard network firewall which operates at lower network layers (like IP addresses and ports), a WAF operates at the application layer (Layer 7 of the OSI model) analyzing HTTP request payloads.

# 2025S_FE-A_25

Q25. Which of the following is an appropriate explanation regarding Address Resolution Protocol (ARP)? 
a) It converts MAC addresses into IP addresses. 
b) It resolves domain names into its IP addresses. 
c) It resolves IP addresses into the corresponding MAC addresses. 
d) It translates IPv4 addresses into IPv6 addresses. 
?
c) It resolves IP addresses into the corresponding MAC addresses. 

### Explanation
- **ARP (Address Resolution Protocol)**: A protocol used to map a known network layer address (IP address) to an unknown data link layer address (MAC address) on a local network.
- When a device knows the Destination IP address but not the MAC address, it broadcasts an ARP request. The device holding that IP address replies with its MAC address.
- *Option A* describes RARP (Reverse ARP).
- *Option B* describes DNS (Domain Name System).
- *Option D* describes NAT64 or similar translation mechanisms.

# 2025S_FE-A_27

Q27. Which of the following is the attack that is classified as DNS cache poisoning? 
a) False domain information is injected into the DNS server that is referenced by a PC, and it leads the user to a fake server. 
b) In order to interrupt the target service, the attacker uses the DNS server as a steppingstone to send a large number of recursive queries. 
c) In order to obtain internal information, the zone information stored in the DNS server is compiled and transferred. 
d) The version information of the DNS server software is obtained to identify a security hole. 
?
a) False domain information is injected into the DNS server that is referenced by a PC, and it leads the user to a fake server. 

### Explanation
- **DNS Cache Poisoning (DNS Spoofing)**: A cyberattack where altered or malicious DNS records are injected into a DNS server's cache. 
- When a user tries to visit a legitimate website, the poisoned DNS server resolves the domain name to the IP address of an attacker-controlled fake server. This successfully redirects online traffic and often leads to phishing or malware distribution.
- *Option B* describes a DNS Amplification/Reflection Attack (a type of DDoS).
- *Option C* describes a DNS Zone Transfer attack.
- *Option D* describes Footprinting / Fingerprinting.

### Explanation
Let $A$ be the availability of a single processing device. Given that $A = 0.9$.

**Condition (1): Parallel System**
The system is available if *at least one* device is running normally. This represents a parallel configuration. The system only fails if **both** devices fail.
- Failure probability of one device = $1 - 0.9 = 0.1$
- Failure probability of the system = $0.1 \times 0.1 = 0.01$
- Availability of parallel system ($A_{parallel}$) = $1 - 0.01 = 0.99$

**Condition (2): Series System**
The system is available only if *both* devices are running normally. This represents a series configuration.
- Availability of series system ($A_{series}$) = $A \times A = 0.9 \times 0.9 = 0.81$

**Difference in Availability**
To find the difference between the two conditions:
$$A_{parallel} - A_{series} = 0.99 - 0.81 = 0.18$$

Therefore, the difference in availability is 0.18.

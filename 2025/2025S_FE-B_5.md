# 2025S_FE-B_5

![[2025S_FE-B_Q5_full.png]]
?
a) pow(pow(x, 0.5) + pow(y, 0.5), 2)

### Explanation
The problem requires returning the value of the mathematical expression:
$$ (\sqrt{x} + \sqrt{y})^2 $$

We are given the helper function `pow(a, b)` which calculates $a^b$.
Recall that a square root can be written as a fractional exponent:
$$ \sqrt{x} = x^{0.5} $$
$$ \sqrt{y} = y^{0.5} $$

Using the `pow` function, we can translate the terms:
1. $\sqrt{x} \implies$ `pow(x, 0.5)`
2. $\sqrt{y} \implies$ `pow(y, 0.5)`
3. The sum is $(\sqrt{x} + \sqrt{y}) \implies$ `pow(x, 0.5) + pow(y, 0.5)`
4. Finally, squaring the entire sum $\implies$ `pow( (pow(x, 0.5) + pow(y, 0.5)), 2 )`

This matches option a).
Let's verify with $x=4$ and $y=9$:
- `pow(4, 0.5)` returns $2$.
- `pow(9, 0.5)` returns $3$.
- The inner sum is $2 + 3 = 5$.
- `pow(5, 2)` returns $25$, which matches the example in the problem description.

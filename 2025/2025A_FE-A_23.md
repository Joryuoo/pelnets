# 2025A_FE-A_23

Q23. Which of the following is a mechanism used to prioritize traffic based on its importance and minimize network latency for network applications?

a) AAA
b) PoE
c) QoS
d) RTP
?
c) QoS

### Explanation
- **AAA (Authentication, Authorization, and Accounting)**: A framework for intelligently controlling access to computer resources, enforcing policies, auditing usage, and providing the information necessary to bill for services.
- **PoE (Power over Ethernet)**: A technology that lets network cables carry electrical power.
- **QoS (Quality of Service)**: A set of technologies that work on a network to guarantee its ability to dependably run high-priority applications and traffic under limited network capacity. It prioritizes traffic based on importance and minimizes network latency.
- **RTP (Real-time Transport Protocol)**: A network protocol for delivering audio and video over IP networks.

Thus, QoS is the correct mechanism.

# 2025A_FE-A_20

Which of the following is an appropriate description of distributed database?

a) Access to a database server is shared among a globally distributed userbase so that everyone can access the database.
b) It is a database that is distributed to all interested researchers and other users worldwide so that everyone can benefit.
c) It is a NoSQL database instead of a Relational Database Management System (RDBMS).
d) It stores different parts of a database in different locations, and its processing is distributed across those parts.
?
d) It stores different parts of a database in different locations, and its processing is distributed across those parts.

### Explanation
A **distributed database** is a database in which storage devices are not all attached to a common processor. Instead, the data is stored across multiple computers, located in the same physical location or dispersed over a network of interconnected computers.

- **Option (a)** describes a centralized database accessed by distributed users (e.g., via the Internet), not a distributed database system itself.
- **Option (b)** describes a publicly shared or open-access dataset, which has nothing to do with the physical or logical architecture of the database.
- **Option (c)** is incorrect. A distributed database can be relational (RDBMS) or non-relational (NoSQL). Distributed architecture is not exclusive to NoSQL.
- **Option (d)** is the correct definition. It accurately captures the essence of a distributed database: data is logically integrated but physically distributed across different geographical or network nodes, and query processing is also distributed among them.

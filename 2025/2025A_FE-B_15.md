f) A: words[j] = term | B: isContainsTerm = true

### Explanation
The function `calcIDF` computes the Inverse Document Frequency (IDF) for a given `term` in a `corpus` of documents.

The IDF formula is given as:
$$ IDF(t) = \log \left( \frac{N}{1 + df(t)} \right) $$
Where:
- $N$ is `numDocs` (total documents).
- $df(t)$ is `termCount` (number of documents containing the term).

1. **Checking if a Document Contains the Term (A):**
   The outer loop `i` iterates through each document. The inner loop `j` iterates through each word in the $i$-th document.
   To check if the document contains the `term`, we compare each word in the document to the `term`. If a match is found, `isContainsTerm` is set to `true`, and the inner loop exits early (since we only need to know if it appears *at least once*).
   Therefore, blank **A** should be `words[j] = term`.

2. **Incrementing the Document Frequency Count (B):**
   After exiting the inner loop, we evaluate whether the current document contained the term. If it did, we increment `termCount` (which represents $df(t)$).
   Therefore, blank **B** should be `isContainsTerm = true`.

Matching these conditions gives us choice **f**.

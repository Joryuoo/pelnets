# 2025A_FE-A_42

Based on the requirements gathered, the cost of a software project under normal conditions is estimated at $70,000. In case of smooth project implementation, some activities are not required and the estimated cost is reduced to $50,000; however, in the worst-case scenario, additional tasks are required and the cost increases to $120,000. What is the expected cost of the project (in dollars) that is calculated by using the three-point estimate in the beta distribution, also known as PERT?

a) 70,000
b) 75,000
c) 80,000
d) 85,000
?
b) 75,000

### Explanation
The **three-point estimating technique** (specifically the Beta distribution or PERT - Program Evaluation and Review Technique) calculates the expected value using three different estimates:
1. **Optimistic estimate (O):** The cost if everything goes smoothly.
2. **Most likely estimate (M):** The cost under normal conditions.
3. **Pessimistic estimate (P):** The cost in the worst-case scenario.

The formula for the expected cost ($E$) in a Beta distribution is a weighted average that places more emphasis on the most likely estimate:
$$E = \frac{O + 4M + P}{6}$$

Given the values in the problem:
- Optimistic ($O$) = $50,000
- Most Likely ($M$) = $70,000
- Pessimistic ($P$) = $120,000

Substitute the values into the formula:
$$E = \frac{50,000 + 4(70,000) + 120,000}{6}$$
$$E = \frac{50,000 + 280,000 + 120,000}{6}$$
$$E = \frac{450,000}{6}$$
$$E = 75,000$$

The expected cost of the project is **$75,000**.

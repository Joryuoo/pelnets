# 2025S_FE-A_29

Q29. Which of the following is a merit in using SaaS? 
a) No system access management needs to be performed, and no consideration concerning the procedure for password initialization or a password policy that satisfies complexity requirements is required. 
b) No system construction needs to be performed, and neither the definition of security requirements for application software development nor the design of storage volume for system logs is required. 
c) No system operation needs to be performed, and no consideration concerning work procedures at the time of a failure or backup is required. 
d) No system security management needs to be performed, and neither the creation of information security management rules nor the assignment of an administrator is required. 
?
b) No system construction needs to be performed, and neither the definition of security requirements for application software development nor the design of storage volume for system logs is required. 

### Explanation
- **SaaS (Software as a Service)**: A cloud computing model where the service provider hosts the application and makes it available to customers over the internet.
- A key merit of SaaS is that the provider handles the underlying infrastructure, middleware, app software, and data storage. Thus, the adopting organization is completely relieved of the burden of **system construction**, defining software security requirements for development, and designing backend storage volumes.
- However, the customer organization is still responsible for managing user access and credentials (invalidating A and D) and defining internal work procedures for handling the software (invalidating C).

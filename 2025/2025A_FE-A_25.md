# 2025A_FE-A_25

Q25. Between LAN systems that are different from the transport layer upward in the OSI basic reference model, which of the following is a device that performs protocol conversion?

a) Bridge
b) Gateway
c) Repeater
d) Router
?
b) Gateway

### Explanation
Networking devices operate at different layers of the OSI model:
- **Repeater**: Operates at the Physical Layer (Layer 1). It regenerates signals.
- **Bridge**: Operates at the Data Link Layer (Layer 2). It connects two LANs based on MAC addresses.
- **Router**: Operates at the Network Layer (Layer 3). It forwards data packets between different IP networks.
- **Gateway**: Operates at the Transport Layer (Layer 4) and above (up to Layer 7). It acts as a "gate" between two networks, often translating protocols between dissimilar systems. Therefore, a gateway performs protocol conversion between networks that differ at the transport layer and above.

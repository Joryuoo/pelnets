# 2025S_FE-B_2

![[2025S_FE-B_Q2_full.png]]
?
d) n mod k = 0, sum ← sum + k

### Explanation
The function `isPerfect` determines whether a given integer `n` is a perfect number by calculating the sum of its positive proper divisors and checking if that sum equals `n`.

The `for` loop iterates the variable `k` from $1$ up to half of $n$, looking for proper divisors.
Inside the loop, we check if `k` is a divisor of `n`:
- A number `k` is a divisor of `n` if `n` divided by `k` has a remainder of $0$.
- In pseudo-code, this is checked using the modulo operator: `n mod k = 0`. This fills the condition **A**.

When `k` is found to be a divisor (the condition is true), it needs to be added to the running total `sum`:
- The assignment is `sum ← sum + k`. This fills the action **B**.

After the loop, the program checks if `sum = n`, which aligns with the definition of a perfect number.

| Step | Expression | Description |
|---|---|---|
| A | `n mod k = 0` | Checks if `k` perfectly divides `n` with no remainder. |
| B | `sum ← sum + k` | Accumulates the divisor `k` into `sum`. |

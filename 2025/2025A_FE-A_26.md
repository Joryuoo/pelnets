# 2025A_FE-A_26

Q26. Which of the following is an Internet standard that extends the format of email header fields to handle not only text messages but also audio and image files?

a) HTML
b) MHS
c) MIME
d) SMTP
?
c) MIME

### Explanation
- **HTML (HyperText Markup Language)**: The standard markup language for creating web pages.
- **MHS (Message Handling System)**: An older email standard (X.400).
- **MIME (Multipurpose Internet Mail Extensions)**: An Internet standard that extends the format of email to support text in character sets other than ASCII, as well as attachments of audio, video, images, and application programs.
- **SMTP (Simple Mail Transfer Protocol)**: The standard protocol for email transmission, but originally it only supported 7-bit ASCII text.

Therefore, MIME is the correct standard.

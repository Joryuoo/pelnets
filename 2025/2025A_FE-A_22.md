# 2025A_FE-A_22

Q22. In the context of transaction management, which of the following is a condition that the Isolation property ensures?

a) Data is written permanently after a transaction.
b) Only valid data is written to the database.
c) Transactions are either fully completed or revoked.
d) Transactions are executed without affecting each other.
?
d) Transactions are executed without affecting each other.

### Explanation
Transaction management is governed by the ACID properties:
- **Atomicity**: Transactions are either fully completed or completely revoked (all or nothing) (choice c).
- **Consistency**: Only valid data is written to the database, leaving it in a consistent state (choice b).
- **Isolation**: Concurrent transactions are executed without affecting each other, as if they were executed sequentially (choice d).
- **Durability**: Data is written permanently after a transaction commits, so it survives system failures (choice a).

Therefore, Isolation ensures that transactions are executed without affecting each other.

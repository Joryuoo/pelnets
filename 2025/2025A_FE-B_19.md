### Explanation
This question is about securely and efficiently transmitting large files containing confidential data over a network.

1. **Choosing the Encryption Method (A):**
   - **Public key encryption (Asymmetric):** Secure, but computationally intensive and very slow for large files. Unsuitable for this scenario.
   - **Symmetric key encryption:** Fast and suitable for large files, but securely distributing the shared key to many changing branch offices is difficult (key distribution problem).
   - **Hybrid encryption:** Combines the strengths of both. The large survey data is encrypted quickly using a symmetric key. Then, only the small symmetric key is encrypted using public key encryption. This is the optimal method for large files, filling blank **A**.

2. **Encrypting the Symmetric Key (B):**
   In hybrid encryption, the sender encrypts the symmetric key using the intended recipient's public key. This ensures that only the recipient (who possesses the corresponding private key) can decrypt the symmetric key, and subsequently decrypt the file.
   Since Ms. T at the head office is the intended recipient of the survey data, the branch offices must encrypt the symmetric key using the public key of **Ms. T**. This fills blank **B**.

This corresponds to choice **a**.

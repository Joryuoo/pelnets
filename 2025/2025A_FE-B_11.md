### Explanation
The function `quickBubble` is an optimized version of the bubble sort algorithm. It uses a boolean flag, `exchange`, to determine if any swaps were made during a pass. If a pass completes without any swaps, the array is already sorted, and the algorithm can terminate early.

1. **Condition for Continuing the Loop (B):**
   Inside the `while` loop, `exchange` is initially set to `false`. During the `for` loop, if any elements are out of order (`arraySorted[i] > arraySorted[i + 1]`), they are swapped, and `exchange` is set to `true`. 
   For the `while` loop to continue to the next pass, a swap must have occurred. Thus, the loop should continue as long as `exchange = true`.

2. **Condition for Array Bounds (A):**
   The variable `maxIdx` represents the upper limit for the inner `for` loop. After each pass, the largest element "bubbles up" to its correct position at the end of the array, so `maxIdx` is decremented by $1$.
   The loop should continue as long as there is at least one pair of elements to compare, which means `maxIdx > 0`. If `maxIdx = 0`, the `for` loop from $1$ to $0$ would not execute.

Combining these, the `while` loop condition should be `maxIdx > 0 and exchange = true`, which corresponds to choice **a**.

**Example Trace:**
Consider a nearly sorted array: `{1, 2, 4, 3}`.
| Pass | `maxIdx` | Initial `exchange` | Swaps Made? | Final `exchange` | Array State |
|---|---|---|---|---|---|
| 1 | 3 | `false` | Yes (4 and 3) | `true` | `{1, 2, 3, 4}` |
| 2 | 2 | `false` | No | `false` | `{1, 2, 3, 4}` |

On Pass 2, no swaps occur, so `exchange` remains `false`, breaking the `while` loop early.

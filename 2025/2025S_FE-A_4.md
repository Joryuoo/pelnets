### Explanation
To ensure the vehicle travels along the black outline, the system uses feedback control based on the values of Sensor L (Left) and Sensor R (Right). 

The problem states:
1. Sensors are over the black/white border.
2. If the ratio of white to black increases (more white), the sensor value **decreases**. If there is more black, the sensor value **increases**.
3. The vehicle travels along the *black outline*, straddling it. 

If the vehicle drifts to the **left**:
- Sensor L moves further onto the black line, so its value **increases**.
- Sensor R moves further onto the white region, so its value **decreases**.
- Result: **Sensor L > Sensor R**.
- **Correction needed:** The vehicle needs to steer **right** to recenter. To steer right, Motor L (left wheel) must turn faster than Motor R (right wheel). Therefore, **Increase Motor L, Decrease Motor R**.

If the vehicle drifts to the **right**:
- Sensor L moves onto the white region (value decreases).
- Sensor R moves onto the black line (value increases).
- Result: **Sensor L < Sensor R**.
- **Correction needed:** The vehicle needs to steer **left** to recenter. To steer left, Motor R (right wheel) must turn faster than Motor L. Therefore, **Decrease Motor L, Increase Motor R**.

Looking at the options, option **c)** perfectly matches this required logic:
- Sensor L > Sensor R: Motor L (Increase), Motor R (Decrease)
- Sensor L < Sensor R: Motor L (Decrease), Motor R (Increase)

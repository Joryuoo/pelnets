# 2025A_FE-A_29

Q29. The IP address of server X that is owned by an attacker, is recorded on Company B’s DNS cache server as the IP address corresponding to the FQDN of Company A’s web server. As a result, which of the following are the users that unintentionally connect to server X? Here, the employees of Company A and Company B use their own company’s DNS cache server for name resolution.

a) Company A employees who try to connect to Company A’s web server
b) Company A employees who try to connect to Company B’s web server
c) Company B employees who try to connect to Company A’s web server
d) Company B employees who try to connect to Company B’s web server
?
c) Company B employees who try to connect to Company A’s web server

### Explanation
This scenario describes DNS Cache Poisoning (or DNS Spoofing). 
- The forged DNS entry is located in **Company B's DNS cache server**.
- The forged entry maps the FQDN of **Company A's web server** to the IP address of **server X** (owned by the attacker).
- Employees of Company B use Company B's DNS cache server for name resolution. 

When Company B's employees try to access Company A's web server, their computer queries Company B's DNS server. The DNS server returns the poisoned IP address (server X). Thus, Company B employees who try to connect to Company A's web server will be unintentionally directed to the attacker's server X. Company A's employees are not affected because they use Company A's DNS cache server, which is not stated to be poisoned.

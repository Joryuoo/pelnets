### Explanation

This algorithm finds the maximum subarray sum using a brute-force approach (checking all possible subarrays).

**Step-by-Step Breakdown:**
1. A subarray is a contiguous portion of an array, defined by a starting index and an ending index.
2. The outer loop uses `i` to represent the **starting index** of the subarray. It iterates from `1` to `n`.
3. The variable `sum` accumulates the sum of the elements in the current subarray starting at `i`. It is reset to `0` before the inner loop begins.
4. The inner loop uses `j` to represent the **ending index** of the subarray. Since a subarray starting at `i` must end at `i` or later, the inner loop must start from `i` and go up to `n`. 
   - Therefore, the starting value for the inner loop, **A**, is `i`.
5. Inside the inner loop, we add `T[j]` to `sum`. The `sum` now represents the sum of the subarray from `T[i]` to `T[j]`.
6. If this new `sum` is strictly greater than the current `max` sum:
   - We update `first` to the starting index `i`.
   - We update `last` to the ending index, which is currently **j**. Therefore, **B** is `j`.
   - We update `max` to the new `sum`.

**Checking the logic:**
By setting `A = i` and `B = j`, the program exhaustively checks every subarray `T[i...j]` where $1 \le i \le j \le n$, correctly identifying the boundaries and maximum sum.

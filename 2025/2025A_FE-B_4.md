### Explanation
The algorithm reverses the digits of a given positive integer `num`. It uses `temp` as a working copy of `num`, `rm` to store the extracted digit, and `rev` to build the reversed integer.
- The loop must continue as long as there are digits left in `temp` to process. Since `temp` is a positive integer that is progressively divided by $10$, the loop condition `____A____` should be `temp > 0`.
- In each iteration, `rm <- temp mod 10` extracts the rightmost digit of `temp`.
- To append this extracted digit `rm` to the right side of `rev`, we multiply the current `rev` by $10$ and add `rm`. Therefore, `____B____` should be `rev x 10 + rm`.
- Finally, the extracted rightmost digit must be removed from `temp` to process the next digit in the next iteration. This is done by performing integer division of `temp` by $10$. Therefore, `____C____` is `integer part of (temp / 10)`.

This corresponds to choice **g)**.

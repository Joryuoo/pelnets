# 2025S_FE-A_30

Q30. Which of the following is an appropriate operation for user authentication that uses an IC card and a PIN? 
a) Given that each user can be identified by an IC card, a common PIN is set for all users in order to reduce the management workload. 
b) If an IC card is lost, a new IC card is issued, and after the PIN is reset, the lost IC card is deactivated. 
c) The PIN is set by combining the numeric information imprinted on the surface of the IC card. 
d) When an IC card is delivered, the PIN is not enclosed, but is notified to the user through another channel. 
?
d) When an IC card is delivered, the PIN is not enclosed, but is notified to the user through another channel. 

### Explanation
- **Two-Factor Authentication**: Using an IC card and a PIN relies on two factors: something the user possesses (IC card) and something the user knows (PIN).
- For this to be secure, an attacker must not easily gain access to both factors. When distributing the card and PIN, they must be sent through **separate channels** (e.g., mailing the card and sending the PIN via email/SMS, or sending them in separate mail on different days).
- If they were delivered together in the same envelope, an interceptor would acquire both factors simultaneously, compromising the security mechanism entirely. 
- *Option A* creates a huge security vulnerability by sharing PINs. 
- *Option B* is incorrect as the lost card should be deactivated *immediately*, not after issuing a new one. 
- *Option C* makes the PIN easily guessable for anyone possessing the card.

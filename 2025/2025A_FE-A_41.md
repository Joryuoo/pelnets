### Explanation
To determine the critical path, we must calculate the **Earliest Event Time (EET)** for each node in the arrow diagram. The critical path is the longest path through the network, meaning any delay in its activities will delay the entire project.

Let's trace the nodes and activities based on the diagram:
- **Node 1 (Start)**
- **Node 2**: Reached via activity A (15 days) from Node 1.
- **Node 3**: Reached via activity B (10 days) from Node 1.
- **Dummy Arrow 1**: Points from Node 2 to Node 3. This means activities starting from Node 3 depend on both A and B.

**Calculating Earliest Event Times (EET):**
- **Node 1**: 0
- **Node 2**: $0 + 15 \text{ (A)} = 15$
- **Node 3**: $\max(0 + 10 \text{ (B)}, 15 + 0 \text{ (Dummy 1)}) = 15$
- **Node 5**: Reached via activity C (15 days) from Node 3.
  - $\text{EET} = 15 + 15 = 30$
- **Node 4**: Reached via activity D (10 days) from Node 2, and via Dummy Arrow 2 from Node 5.
  - $\text{EET} = \max(15 + 10 \text{ (D)}, 30 + 0 \text{ (Dummy 2)}) = 30$
- **Node 6**: Reached via activity E (15 days) from Node 4.
  - $\text{EET} = 30 + 15 = 45$
- **Node 7**: Reached via activity F (15 days) from Node 5.
  - $\text{EET} = 30 + 15 = 45$
- **Node 8 (End)**: Reached via activity H (10 days) from Node 6, and activity G (5 days) from Node 7.
  - $\text{EET} = \max(45 + 10 \text{ (H)}, 45 + 5 \text{ (G)}) = \max(55, 50) = 55$

The total duration of the project is **55 days**. 
Tracing back the path that resulted in 55:
- Node 8 came from Node 6 via **H** (45 + 10 = 55).
- Node 6 came from Node 4 via **E** (30 + 15 = 45).
- Node 4 came from Node 5 via **Dummy 2** (30 + 0 = 30).
- Node 5 came from Node 3 via **C** (15 + 15 = 30).
- Node 3 came from Node 2 via **Dummy 1** (15 + 0 = 15).
- Node 2 came from Node 1 via **A** (0 + 15 = 15).

Thus, the critical path is composed of activities **A $\rightarrow$ Dummy 1 $\rightarrow$ C $\rightarrow$ Dummy 2 $\rightarrow$ E $\rightarrow$ H**.
Ignoring the dummy activities, the sequence is **A, C, E, H**.

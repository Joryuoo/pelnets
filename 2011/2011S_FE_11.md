# 2011S_FE_11

Which of the following is the programming language that is interpreted and executed directly from source code or bytecode and can be used as batch control programs or embedded as part of application programs?

a) Functional language
b) Logic language
c) Object-oriented language
d) Script language
?
d) Script language

### Explanation
A **script language** is commonly interpreted directly from source code or bytecode and is often used to automate batches of commands or embedded within an application (e.g., JavaScript, Python).

* **a) Functional language:** A programming paradigm that emphasizes evaluating mathematical functions (e.g., Haskell).
* **b) Logic language:** A paradigm based on formal logic and rules (e.g., Prolog).
* **c) Object-oriented language:** A paradigm based on objects and classes (e.g., Java, C++). 
These other choices describe programming paradigms rather than the specific execution method described in the question.

# 2011S_FE_23

Which of the following is the reason for using a real-time OS with a hard real-time control system such as engine control and hard disk control?

a) A mechanism that completes the processing for each event within a specified time is necessary.
b) A mechanism that improves the throughput of the entire system is necessary.
c) A mechanism that runs multiple independent programs concurrently is necessary.
d) A memory protection mechanism to prevent virus intrusion is necessary.
?
a) A mechanism that completes the processing for each event within a specified time is necessary.

### Explanation
A hard real-time control system must guarantee that tasks meet a strict deadline (a specified time constraint) for each critical event.

- b) Improving throughput focuses on overall average performance, not strict timing guarantees for specific critical tasks.
- c) Concurrent processing handles multiple tasks but doesn't guarantee they will complete within a strict time limit.
- d) Memory protection is for security and stability, which is unrelated to real-time timing constraints.

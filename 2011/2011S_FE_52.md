# 2011S_FE_52

Which of the following is an explanation of the waterfall model in system development?

a) Instead of building complicated software from scratch, the development starts by repeating analysis, design, implementation, and testing of simple parts, and gradually expands its scale.
b) Instead of building everything at once, the system is developed in incremental steps on the top of the basic system architecture according to the priority of each function.
c) Development makes progress by creating a prototype and receiving feedback on user requests.
d) The development process is divided into some phases, such as design, implementation, and test. Once a phase is completed, its deliverables are used for conducting the next phase.
?
d) The development process is divided into some phases, such as design, implementation, and test. Once a phase is completed, its deliverables are used for conducting the next phase.

### Explanation
The waterfall model proceeds through defined stages such as design, implementation, and test, with each completed stage feeding the next. The other choices describe iterative, incremental, or prototype approaches.

The sequence is `requirements → design → implementation → testing`, with each phase's output passed to the next. Option a is iterative expansion, b is incremental development, and c is prototyping with user feedback. Those approaches revisit or add functionality differently from the linear progression of the waterfall model.

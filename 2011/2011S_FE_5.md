d) matrix with rows A: 0 1 0; B: 1 0 1; C: 0 0 0

### Explanation
The graph has edges A→B, B→A, and B→C, with none leaving C. Marking a 1 for each directed edge gives rows A = (0,1,0), B = (1,0,1), and C = (0,0,0).

Read each row as the source vertex and each column as the destination: `A → B`, `B → A`, and `B → C`. Thus the matrix is `[[0,1,0],[1,0,1],[0,0,0]]`. The other matrices mark edges that are absent, including self-loops or edges leaving C.

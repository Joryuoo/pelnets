# 2011S_FE_32

Which of the following is the main purpose of using indexes in relational database tables?

a) To enhance data security
b) To ensure data integrity
c) To improve query performance
d) To prevent risk of deadlocks
?
c) To improve query performance

### Explanation
An index provides an access path to locate rows without scanning an entire table for suitable queries. It is aimed at faster retrieval, though it adds storage and write overhead.

An index narrows the rows a query must examine and can speed lookups, joins, and ordering. 
- Option a is incorrect because indexes do not enforce access permissions or enhance data security.
- Option b is incorrect because while unique indexes can enforce uniqueness, general constraints and triggers ensure overall data integrity.
- Option d is incorrect because indexes do not guarantee freedom from deadlocks; in fact, concurrent updates to indexes can sometimes cause them.

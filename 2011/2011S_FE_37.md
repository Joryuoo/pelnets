# 2011S_FE_37

In the OSI basic reference model, which of the following is the appropriate layer that provides end-to-end communication services for applications, and also provides convenient services such as connection-oriented or connectionless data stream support, reliability, flow control, and congestion control?

a) Data link layer
b) Network layer
c) Session layer
d) Transport layer
?
d) Transport layer

### Explanation
The transport layer (Layer 4) provides end-to-end communication between application processes, including reliability, flow control, and connection-oriented (TCP) or connectionless (UDP) transport.

- Option a (Data link layer, Layer 2) handles moving frames over a single link between adjacent nodes.
- Option b (Network layer, Layer 3) routes packets between different networks based on logical addresses (like IP), but lacks end-to-end reliability and flow control features.
- Option c (Session layer, Layer 5) manages dialogues and sessions between applications, but relies on the Transport layer for underlying data stream support.

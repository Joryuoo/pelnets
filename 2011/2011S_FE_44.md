# 2011S_FE_44

When a biometric authentication system is installed, which of the following is the most appropriate point to be considered?

a) Combining various measures, such as heuristics, in addition to frequent update of pattern files
b) Requesting a trusted third party to issue an individual user’s digital certificate
c) Setting up the system in consideration of both the probability of incorrectly rejecting an authorized user and that of incorrectly accepting an unauthorized user
d) Using a library capable of sanitizing data which can cause a system malfunction
?
c) Setting up the system in consideration of both the probability of incorrectly rejecting an authorized user and that of incorrectly accepting an unauthorized user

### Explanation
Biometric systems have a tradeoff between False Rejection Rate (FRR, denying an authorized user) and False Acceptance Rate (FAR, admitting an unauthorized user). Adjusting the sensitivity threshold affects both, so both probabilities must be balanced.

Why the other choices are wrong:
- **a)** Updating pattern files and using heuristics applies to anti-malware/antivirus systems, not biometric authentication.
- **b)** Requesting a digital certificate from a trusted third party pertains to Public Key Infrastructure (PKI), not biometrics.
- **d)** Data sanitization is used to prevent injection attacks (like SQL injection) in software applications, not to tune biometrics.

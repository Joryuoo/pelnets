# 2011A_FE_2

![[Files/2011A_FE_AM_Q2_full.png]]
?
b) A > B and C >= D

### Explanation
This question tests De Morgan's laws for logical expressions.
De Morgan's law states that `not (X or Y)` is equivalent to `(not X) and (not Y)`.
Applying this to the expression `not (A <= B or C < D)`:
- `not (A <= B)` becomes `A > B`
- `not (C < D)` becomes `C >= D`
- The `or` operator changes to `and`.

Combining these, we get `A > B and C >= D`, which matches choice (b). The other choices either use the wrong logical operator or the wrong inequality signs.

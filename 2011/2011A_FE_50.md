# 2011A_FE_50

In software development, which of the following is the most appropriate primary purpose of performing a system test?

a) To verify the functionality and operability of the deliverables principally on developer’s own responsibility in the production environment
b) To verify the functionality of each software component on programmer’s own responsibility
c) To verify the functionality of multiple software components as well as the interfaces between the components
d) To verify the operational readiness and determine whether the software is acceptable to end users
?
a) To verify the functionality and operability of the deliverables principally on developer’s own responsibility in the production environment

### Explanation
### Explanation
A **System Test** evaluates the completely integrated software product to verify that it meets the specified requirements. It is typically conducted by the development/QA team (on their responsibility) in an environment that closely simulates the final production environment, checking both functionality and non-functional aspects (like operability and performance).

**Why other options describe different test phases:**
- **b) Unit Test**: Verifies the functionality of individual, isolated software components, performed by the programmers.
- **c) Integration Test**: Verifies how multiple interconnected components function together and tests the interfaces between them.
- **d) Acceptance Test**: The final phase conducted by or with the end users to verify operational readiness and determine if the software is acceptable for release.

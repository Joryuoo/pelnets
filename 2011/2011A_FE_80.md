# 2011A_FE_80

Which of the following is an international standard that defines an encoding algorithm used to compress still image data?

a) GIF
b) JPEG
c) MP3
d) MPEG
?
b) JPEG

### Explanation
### Explanation
- **JPEG (Joint Photographic Experts Group) (b):** An international standard for lossy compression of continuous-tone still images (photographs).
- **GIF (Graphics Interchange Format) (a):** A bitmap image format that is not an international ISO/IEC standard in the same formal way as JPEG, often used for simple graphics or short animations.
- **MP3 (c):** A standard for audio compression.
- **MPEG (Moving Picture Experts Group) (d):** A standard for video and audio compression.

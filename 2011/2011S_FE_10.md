# 2011S_FE_10

![[2011S_FE_AM_Q10_full.png]]
?
a) A: a < c; B: b < c

### Explanation
On the right of the root, b ≤ a. To reach b ≤ a < c, A must test a < c. If that fails, B must test b < c to distinguish b < c ≤ a from c ≤ b ≤ a.

On the right branch of the root we already know `b ≤ a`. Testing `a < c` first yields `b ≤ a < c`; otherwise `c ≤ a`, and testing `b < c` separates `b < c ≤ a` from `c ≤ b ≤ a`. Every other option sends at least one ordering to the wrong leaf.

The output is `6D` in hexadecimal. We must first convert this to binary to see which segments (P0 to P7) are turned on.
`6` in hex = `0110` in binary
`D` in hex = `1101` in binary
So, `6D` = `0110 1101`.

Mapping this to the bits from MSB (P7) to LSB (P0):
* P7 = 0
* P6 = 1
* P5 = 1
* P4 = 0
* P3 = 1
* P2 = 1
* P1 = 0
* P0 = 1

When a 1 is written to a port, the corresponding LED segment lights up. The pattern of these illuminated segments forms the shape of the character displayed.

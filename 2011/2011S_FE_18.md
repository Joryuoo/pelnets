# 2011S_FE_18

Which of the following is the most appropriate term to represent a pay-per-use model for enabling available, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, services) that can be rapidly provisioned and released with minimal management effort or service provider interaction?

a) Cloud computing
b) Context aware computing
c) Grid computing
d) Social computing
?
a) Cloud computing

### Explanation
**Cloud computing** is defined by its core characteristics: on-demand self-service, broad network access, resource pooling, rapid elasticity (provisioning/releasing), and measured service (pay-per-use).

* **b) Context aware computing:** A paradigm where computing devices adapt their behavior based on the user's surroundings or context (location, time, etc.).
* **c) Grid computing:** A distributed architecture where multiple independent computers are coordinated to solve a single, large computational problem.
* **d) Social computing:** An area of computer science focusing on the intersection of social behavior and computational systems (e.g., social networks, wikis).

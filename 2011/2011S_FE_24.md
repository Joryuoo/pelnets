# 2011S_FE_24

![[2011S_FE_AM_Q24_full.png]]
?
d) A: Object program; B: Library module; C: Load module

### Explanation
The build path is: Source program is compiled into an Object program (A). The Linker combines the object program with Library modules (B) into an executable Load module (C). Finally, the Loader places the load module into memory.

- a, b, c) Incorrectly map the terms. An object program needs a linker to combine with libraries to produce a load module. The compiler output is an object program, not a library module or load module.

# 2011A_FE_9

![[Files/2011A_FE_AM_Q9_full.png]]
?
d) (b + (c / d)) * ((e / f) - g)

### Explanation
The series of three-address instructions evaluates an expression step by step. We trace the values stored in the temporary variables `w1` through `w4`:
1. `/ (c, d, w1)` translates to `w1 = c / d`
2. `+ (b, w1, w2)` translates to `w2 = b + w1 = b + (c / d)`
3. `/ (e, f, w3)` translates to `w3 = e / f`
4. `- (w3, g, w4)` translates to `w4 = w3 - g = (e / f) - g`
5. `* (w2, w4, x)` translates to `x = w2 * w4`

Substituting `w2` and `w4` into the final equation gives:
`x = (b + (c / d)) * ((e / f) - g)`

This exact expression corresponds to choice (d).

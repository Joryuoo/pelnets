# 2011S_FE_30

Which of the following is the data model that is organized as a tree-like structure using a parent-child or one-to-many relationship?

a) Hierarchical data model
b) Network data model
c) Object data model
d) Relational data model
?
a) Hierarchical data model

### Explanation
The hierarchical data model organizes data in a tree-like structure, where each record has a single parent and can have multiple children, representing a strict one-to-many relationship.

- b) Network data model: Organizes data as a graph, allowing many-to-many relationships where a record can have multiple parents.
- c) Object data model: Represents information in the form of objects as used in object-oriented programming.
- d) Relational data model: Organizes data into tables (relations) with rows and columns.

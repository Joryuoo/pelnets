# 2011S_FE_14

In a processor equipped with cache memory, there are two major types of write policies: write-back and write-through. Which of the following is an appropriate description concerning write-back cache?

a) Every write to cache causes a write to main memory, so no inconsistency between cache and main memory occurs.
b) When data is flushed out of cache, main memory need not be updated.
c) When data is repeatedly written to the same address, the number of accesses to main memory increases.
d) Write-back is more efficient than write-through because of the reduced number of accesses to main memory.
?
d) Write-back is more efficient than write-through because of the reduced number of accesses to main memory.

### Explanation
In a **write-back** cache policy, data is written only to the cache initially. The main memory is updated only when the modified (dirty) cache block is evicted or flushed. This significantly reduces the number of accesses to main memory, making it more efficient than write-through.

* **a) Every write to cache causes a write to main memory:** This describes the **write-through** policy.
* **b) When data is flushed out of cache, main memory need not be updated:** Incorrect. If the data is dirty (modified), it *must* be updated in main memory upon flushing to maintain data consistency.
* **c) When data is repeatedly written to the same address, the number of accesses to main memory increases:** This is true for write-through, but write-back prevents this increase by only writing to main memory once upon eviction.

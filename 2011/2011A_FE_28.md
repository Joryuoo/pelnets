# 2011A_FE_28

When a GUI screen is designed for both users who are familiar with keyboard operation and users who are not, which of the following is an appropriate consideration to implement a user interface with good usability?

a) Both mouse and keyboard interfaces should be provided for as many operations as possible, in order to increase operational flexibility.
b) Frequently used operations should be executed by double-clicking a mouse button in lieu of an equivalent keyboard action.
c) Important items, such as mandatory items, should be grouped together irrespective of the format of the data entry sheet, so as not to cause a lack of input.
d) The number of items for keyboard entry should be minimized, and as many items as possible should be selected from the list by using a mouse, not a keyboard.
?
a) Both mouse and keyboard interfaces should be provided for as many operations as possible, in order to increase operational flexibility.

### Explanation
### Explanation
To provide good usability for a diverse user base, a system should accommodate different preferences and skill levels. Providing both mouse (for novices) and keyboard shortcuts (for experts) ensures flexibility and efficiency for all users.

* **b)** Relying exclusively on double-clicking alienates users who prefer the keyboard or find double-clicking physically difficult.
* **c)** Grouping mandatory items inappropriately without considering logical flow or the physical data entry sheet can confuse users.
* **d)** Minimizing keyboard entry forces experienced users to slow down and use the mouse, reducing efficiency for power users.

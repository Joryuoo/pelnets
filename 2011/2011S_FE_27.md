# 2011S_FE_27

Which of the following is a basic component of a sequential circuit that has two stable states and is used in a memory cell of SRAM?

a) Adder
b) AND gate
c) Capacitor
d) Flip-flop
?
d) Flip-flop

### Explanation
A flip-flop is a bistable sequential circuit capable of holding one bit of state. SRAM memory cells use such bistable circuits to retain values as long as power is supplied.

- a) Adder: A combinational circuit that performs arithmetic operations.
- b) AND gate: A fundamental combinational logic gate, not a bistable memory element.
- c) Capacitor: Used in DRAM (Dynamic RAM) to store charge, not in SRAM which uses flip-flops.

# 2011A_FE_38

Q38. Which of the following is the appropriate layer of the OSI basic reference model that provides RPC (Remote Procedure Call) support, maintains the integrity of the connection between nodes, and controls data exchange?

a) Application layer
b) Network layer
c) Presentation layer
d) Session layer
?
d) Session layer

### Explanation
The Session Layer (Layer 5) of the OSI model establishes, manages, and terminates connections (sessions) between applications on different nodes. It controls dialogs and data exchange (e.g., half-duplex or full-duplex) and is responsible for RPC (Remote Procedure Call) support.

- **a) Application layer (Layer 7):** Provides network services directly to the end-user applications.
- **b) Network layer (Layer 3):** Handles routing and logical addressing (e.g., IP).
- **c) Presentation layer (Layer 6):** Handles data formatting, encryption, and compression.

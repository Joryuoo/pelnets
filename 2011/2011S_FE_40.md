# 2011S_FE_40

When the CRC (Cyclic Redundancy Check) function is implemented by calculating a generator polynomial, which of the following is used as a CRC code (sometimes simply called CRC)?

a) Dividend
b) Quotient
c) Remainder
d) Summation
?
c) Remainder

### Explanation
CRC treats the data as a polynomial and divides it by a generator polynomial. The remainder of that division is appended as the check code and later checked for transmission errors.

Polynomial division produces a dividend (the data), a divisor (the generator), a quotient, and a remainder. 
- Option a is incorrect because the dividend is the original data itself.
- Option b is incorrect because the quotient is discarded.
- Option d is incorrect because CRC uses polynomial division, not simple summation (like a checksum). Only the remainder is used as the CRC code.

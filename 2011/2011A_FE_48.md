# 2011A_FE_48

Which of the following is a diagram used in UML2.0 for the purpose of depicting the interactions between the system, external systems, and users, or graphically describing who uses the system and in what ways the user expects to interact with the system?

a) Component diagram
b) Deployment diagram
c) Sequence diagram
d) Use case diagram
?
d) Use case diagram

### Explanation
### Explanation
A **Use Case diagram** in UML visually models the functional requirements of a system by showing the relationships between actors (external users or other systems) and the use cases (the specific interactions or tasks they perform with the system).

**Why other options are wrong:**
- **a) Component diagram**: Depicts the structural relationships between software components and their interfaces.
- **b) Deployment diagram**: Illustrates the physical deployment of software artifacts onto hardware nodes.
- **c) Sequence diagram**: A behavioral diagram that details how objects interact chronologically in a specific scenario, showing the step-by-step sequence of messages.

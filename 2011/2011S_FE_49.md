# 2011S_FE_49

![[2011S_FE_AM_Q49_full.png]]
?
b) 49, 50, 100, 101

### Explanation
Boundary value analysis requires testing the boundaries of equivalence partitions. For an inclusive range like 50 ≤ x ≤ 100, you test the exact limits (50, 100) and the values immediately outside the boundaries (49, 101) to catch off-by-one errors.

Why the other choices are wrong:
- **a) 49, 50, 100**: Misses the upper outer boundary (101).
- **c) 50, 51, 99, 100**: Focuses on inner boundary values but misses the crucial invalid values just outside the range (49, 101) that might incorrectly pass validation.
- **d) 50, 100, 101**: Misses the lower outer boundary (49).

The logic circuit described outputs 0 only when both inputs (A and B) are 1. For all other input combinations (0-0, 0-1, 1-0), the output is 1.
This matches the truth table of a **NAND (Not-AND)** gate.

* **AND circuit (a)**: Outputs 1 only when both inputs are 1; otherwise, it outputs 0.
* **OR circuit (c)**: Outputs 0 only when both inputs are 0; otherwise, it outputs 1.
* **XOR circuit (d)**: Outputs 0 when both inputs are the same (0-0 or 1-1); otherwise, it outputs 1.

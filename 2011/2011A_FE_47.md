### Explanation
When a client PC accesses a Web server on the Internet:

1. **Outgoing Packet (Request):**
   - **Source**: PC
   - **Destination**: Web server
   - **Source port number**: An ephemeral, dynamically assigned port on the client side (typically **1024 or more**).
   - **Destination port number**: The well-known port for the service being requested, which is HTTP (**80**).

2. **Response Packet (Reply):**
   - **Source**: Web server
   - **Destination**: PC
   - **Source port number**: The well-known port responding (**80**).
   - **Destination port number**: The ephemeral port the client originally sent from (**1024 or more**).

Therefore, choice (b) correctly reflects the expected firewall rules to permit this two-way communication.

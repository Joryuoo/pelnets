# 2011A_FE_78

Which of the following is an appropriate chart that can be used for planning the work schedule and for keeping track of the progress status in a project?

a) Composite bar chart
b) Control chart
c) Gantt chart
d) Pareto chart
?
c) Gantt chart

### Explanation
### Explanation
- **Gantt chart (c):** A type of bar chart that illustrates a project schedule, showing tasks on the vertical axis and time intervals on the horizontal axis, used for tracking progress.
- **Control chart (b):** Used in quality control to determine if a manufacturing or business process is in a state of control.
- **Pareto chart (d):** Contains both bars and a line graph to highlight the most significant factors in a dataset (e.g., common causes of defects), based on the 80/20 rule.
- **Composite bar chart (a):** Shows the components of a total across different categories, not specifically for project scheduling.

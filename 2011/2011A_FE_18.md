# 2011A_FE_18

In an on-line real-time system, there occur transactions at a frequency of 20 times per second. Each of the transactions is completed after it performs the CPU processing once and the hard disk I/O processing four times. The I/O processing time of a hard disk drive is 40 milliseconds per each I/O, and the CPU processing time is negligibly small. When each hard disk drive is accessed evenly, at least how many hard disk drives are required for this transaction processing?

a) 3
b) 4
c) 5
d) 6
?
b) 4

### Explanation
To determine the number of hard disk drives needed, we must calculate the total I/O processing time required per second:

1. **Transactions per second:** $20$
2. **I/O requests per transaction:** $4$
3. **Total I/O requests per second:** $20 \times 4 = 80\text{ I/Os per second}$
4. **Time per I/O:** $40\text{ ms} = 0.04\text{ seconds}$

**Total I/O time required per second:**
$80 \times 0.04\text{ seconds} = 3.2\text{ seconds}$

Since a single hard disk drive can provide a maximum of $1.0\text{ second}$ of processing time per second, the system requires at least $\lceil 3.2 \rceil = 4$ hard disk drives to handle the continuous load.

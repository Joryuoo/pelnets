# 2011A_FE_41

Which of the following is an appropriate combination of information that a DHCP server dynamically provides for a client host to participate in the TCP/IP network?

a) IP address, MAC address, default gateway address, and DNS server address
b) IP address, MAC address, DNS server address, and routing information
c) IP address, subnet mask, default gateway address, and DNS server address
d) IP address, subnet mask, default gateway address, and routing information
?
c) IP address, subnet mask, default gateway address, and DNS server address

### Explanation
### Explanation
The Dynamic Host Configuration Protocol (DHCP) automatically assigns IP addresses and other network configuration parameters to client devices. The typical parameters provided include:
- **IP address**: Uniquely identifies the device on the network.
- **Subnet mask**: Determines the network and host portions of the IP address.
- **Default gateway address**: The router to send traffic to when communicating outside the local network.
- **DNS server address**: Used to resolve domain names to IP addresses.

**Why other options are wrong:**
- **a) and b)**: A DHCP server does not provide MAC addresses. The MAC address is physically burned into the device's network interface card (NIC).
- **d)**: Standard host devices do not require dynamic "routing information" (routing tables are maintained by routers, not typically configured on clients via DHCP).

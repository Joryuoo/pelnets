# 2011A_FE_40

Q40. Which of the following is a protocol used by the ping command in order to verify that the communication link between source and destination is working in the TCP/IP network environment?

a) ARP
b) ICMP
c) SMTP
d) SNMP
?
b) ICMP

### Explanation
The `ping` utility uses the Internet Control Message Protocol (ICMP) to verify network connectivity. Specifically, it sends ICMP Echo Request messages to the destination and waits for ICMP Echo Reply messages to determine if the host is reachable.

- **a) ARP:** Resolves IP addresses to MAC addresses on a local subnet.
- **c) SMTP:** Used for sending email messages.
- **d) SNMP:** Used for network management and monitoring devices.

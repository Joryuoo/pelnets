# 2011S_FE_75

Which of the following uses RFID?

a) Bar code
b) IC tag
c) Magnetic card
d) Memory card
?
b) IC tag

### Explanation
An IC (Integrated Circuit) tag contains a microchip and an antenna that communicates data using Radio-Frequency Identification (RFID) waves.

- **a) Bar code:** Incorrect. This is read optically using a laser or camera scanner.
- **b) IC tag:** Correct. Data is transmitted and read wirelessly via radio waves.
- **c) Magnetic card:** Incorrect. This stores data on a magnetic stripe and requires physical contact with a magnetic reader.
- **d) Memory card:** Incorrect. This is a solid-state electronic flash memory data storage device, not typically read via RFID.

# 2011A_FE_20

Which of the following is the method of improving the throughput of the entire system by transferring data from main memory to a low-speed output device via a high-speed auxiliary storage device?

a) Blocking
b) Paging
c) Spooling
d) Swapping
?
c) Spooling

### Explanation
**Spooling** (Simultaneous Peripheral Operations On-Line) is a technique where data intended for a slow peripheral device (like a printer) is first written to a high-speed buffer or auxiliary storage (like a hard disk). The CPU can then quickly move on to other tasks while the slow device processes the data in the background from the buffer.

- **a) Blocking:** Grouping multiple logical records into a single physical block to improve I/O efficiency.
- **b) Paging:** A memory management scheme that divides memory into fixed-size pages to eliminate the need for contiguous physical memory.
- **d) Swapping:** Moving an entire process's memory space between main memory and secondary storage to free up RAM.

# 2011A_FE_32

Q32. Which of the following is the appropriate SQL command that can be used to undo any changes made to the database since the last commit?

a) Close
b) Drop
c) Revoke
d) Rollback
?
d) Rollback

### Explanation
In SQL, the `ROLLBACK` command is used to undo transactions that have not yet been saved to the database. It restores the database to its state at the last `COMMIT`.

- **a) Close** is typically used in the context of cursors, not transaction management.
- **b) Drop** is a DDL command used to delete database objects like tables or databases entirely.
- **c) Revoke** is a DCL command used to remove user privileges or access rights.

# 2011S_FE_6

When the runtime complexity of an algorithm is represented by n², which of the following is the running time for the algorithm to process one million elements? Here, n is the number of elements to be processed by this algorithm, and it takes 1 nanosecond to process only one element.

a) 1 nanosecond
b) 1 millisecond
c) 1 second
d) 1,000 seconds
?
d) 1,000 seconds

### Explanation
Quadratic work for one million items is (10^6)^2 = 10^12 operations. At one nanosecond per operation, this is 10^12 × 10^−9 = 1,000 seconds.

The unit trace is `10^6 items → 10^12 operations → 10^12 ns → 10^3 s`. Choice a treats the whole input as one operation; b and c are far below the result because they miss the square in $n^2$ or the nanosecond-to-second conversion.

# 2011A_FE_23

Which of the following is the appropriate CASE tool that is prepared especially for the software development phases including program design, programming, and testing?

a) Component CASE tool
b) Integrated CASE tool
c) Lower CASE tool
d) Upper CASE tool
?
c) Lower CASE tool

### Explanation
### Explanation
CASE (Computer-Aided Software Engineering) tools are classified into Upper CASE and Lower CASE tools.
* **Lower CASE tools** are used for the later phases of the software development life cycle, such as detailed design, programming (code generation), testing, and maintenance.
* **Upper CASE tools (d)** are used for the early phases, such as requirements analysis and basic/system design.
* **Integrated CASE tools (b)** cover the entire life cycle, combining both upper and lower CASE capabilities.
* **Component CASE tools (a)** refer to specific individual tools rather than a comprehensive phase classification.

c) Unit: C; integration: B; system: A; operational: D

### Explanation
- **Unit test (C)** verifies the functionality of an individual component or module.
- **Integration test (B)** verifies that multiple modules work correctly together at their interfaces.
- **System test (A)** verifies that the fully integrated system meets the specified requirements.
- **Operational test (D)** verifies the system in the actual production environment with real users (e.g., user acceptance testing).

Why the other choices are wrong:
- **a) and b)** incorrectly assign integration testing to C (which should be unit testing) and unit testing to B (which should be integration testing).
- **d)** incorrectly assigns system testing to D (which should be operational testing) and operational testing to A (which should be system testing).

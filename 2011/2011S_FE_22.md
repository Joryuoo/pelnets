# 2011S_FE_22

In the virtual memory of a paging system, when a page that does not exist in main memory is accessed, which of the following shows the appropriate order of processes and states? Here, there is no empty page frame available in main memory.

a) Decision of the page for replacement → Page fault → Page-out → Page-in
b) Decision of the page for replacement → Page-in → Page fault → Page-out
c) Page fault → Decision of the page for replacement → Page-in → Page-out
d) Page fault → Decision of the page for replacement → Page-out → Page-in
?
d) Page fault → Decision of the page for replacement → Page-out → Page-in

### Explanation
Accessing a missing page triggers a page fault. With no free frame, the OS must first select a victim page for replacement, write it out to disk (page-out), and then load the requested page into the freed frame (page-in).

- a, b) Incorrect because a page fault must be detected before any decision for replacement is made.
- c) Incorrect because the page-out (freeing up the frame) must happen before the new page-in, as there are no empty frames available.

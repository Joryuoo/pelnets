# 2011S_FE_9

After seven keys 15, 11, 16, 2, 17, 22, 13 are sequentially stored in an empty hash table where the chain method is used for resolving collisions, how many comparisons are needed to search for the key 22 in the table? Here, the hash table size is 5, and the hash function “x mod 5” is used for the key x. In the chain method, each table entry has a linked list, and synonymous keys are stored at the tail of each linked list.

a) 1
b) 2
c) 3
d) 4
?
c) 3

### Explanation
The hash value of 22 is 22 mod 5 = 2. The same bucket receives 2, then 17, then 22 in insertion order. Searching its tail-appended chain compares against all three keys.

The bucket-2 chain is `2 → 17 → 22` because all three have remainder 2 and entries are appended at the tail. A successful search compares with 2, then 17, then 22. One or two comparisons would stop before the target; four would count an unrelated key.

# 2011A_FE_27

Which of the following is an appropriate explanation of flash memory?

a) Data can be written electrically only once.
b) Data is rewritten (i.e., refreshed) within a given period of time.
c) Data is written electrically and erased with ultraviolet light.
d) Data is written or erased electrically and erased either all at once or in blocks.
?
d) Data is written or erased electrically and erased either all at once or in blocks.

### Explanation
### Explanation
Flash memory is a non-volatile type of EEPROM (Electrically Erasable Programmable Read-Only Memory) that allows data to be electrically written and erased. Unlike traditional EEPROM which erases data byte by byte, flash memory erases data in blocks or all at once, making it faster.

* **a)** Describes PROM (Programmable ROM), which is write-once.
* **b)** Describes DRAM (Dynamic Random Access Memory), which requires periodic refreshing to retain data.
* **c)** Describes EPROM (Erasable Programmable ROM), which uses UV light to erase data.

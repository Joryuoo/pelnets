Process 3 cross-references redundant data to detect stolen or fake driver licenses. The consolidated violation file uses the same fields as the enforcer-based file.

- **Blank E:** In the enforcer-based file (Figure 2), the enforcer manually records the driver's name in the `Driver Name` field (choice **c**).
- **Blank F:** In the driver license file (Figure 4), the official registered name of the license holder is stored in the `Name` field (choice **d**).

By ensuring that the `Driver Name` supplied to the enforcer matches the official `Name` on the driver license record, the system can verify the identity of the driver and flag discrepancies.

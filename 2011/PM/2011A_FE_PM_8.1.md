- **Blank A:** The array `roster` is declared as `private Student[] roster;`. To initialize this array, we use `roster = new Student[arraySize];`. The correct answer is `Student` (e). Choosing `GraduateStudent` or `UndergraduateStudent` (b, f) would restrict the array to only hold that specific subclass, preventing the program from storing mixed student types.
- **Blanks B, C, and D:** The method `processData` orchestrates the program's logic. It needs to read the file, process the grades, and print the results in order. Looking at the class methods, we call `buildRoster(file)` (a) to read the text file and populate the `roster`, followed by `computeGrade()` (b) to calculate everyone's grades, and finally `printResult()` (e) to display the output. Other methods in the choices like `createStudent(file)` (d) are incorrect because `createStudent` expects a single line of text, not a filename.
- **Blank E:** In the `computeGrade()` method, we iterate through the `roster` array and call `computeCourseGrade()` on each element. Since `roster` is an array of `Student` objects, we access the current element via `roster[i]`. In Java, polymorphism ensures that the overridden `computeCourseGrade` method in the respective subclass (`GraduateStudent` or `UndergraduateStudent`) is automatically called. The correct answer is `roster[i]` (d). Typecasting to `(GraduateStudent)` or `(UndergraduateStudent)` (a, b) is incorrect because we do not know the exact runtime type of `roster[i]` in this loop; an incorrect cast would throw a `ClassCastException` at runtime. Choices `GraduateStudent[i]` and `Student[i]` (c, e, f) are syntactically invalid because they try to index a class name rather than a variable.
- **Blank F:** Inside `createStudent()`, if the student type token equals `UNDER_GRAD` (which is `"U"`), the program should instantiate an `UndergraduateStudent` object. The correct answer is `UndergraduateStudent` (f).
- **Blank G:** Similarly, if the student type token equals `GRAD` (which is `"G"`), the program should instantiate a `GraduateStudent` object. The correct answer is `GraduateStudent` (b).

- **Blank A:** The original password space is 26^8. The new password space for a 10-character password is 26^10. The ratio of the maximum time required to find the password is the ratio of the password spaces: 26^10 / 26^8 = 26^2 = 676. Thus, the time is 676 times the original time. Choice (f) is correct.
- **Blank B:** Adding uppercase alphabetic characters increases the available character set from 26 to 52 characters (26 lowercase + 26 uppercase). The new password space is 52^8. The ratio compared to the original is 52^8 / 26^8 = (52/26)^8 = 2^8 = 256. Thus, the time is 256 times the original time. Choice (d) is correct.

**(1) Blanks A and B**

The virtual address space is divided into virtual pages of size 1024 bytes (1k).
- Virtual page 0 covers addresses 0 to 1023
- Virtual page 1 covers 1024 to 2047
- Virtual page 2 covers 2048 to 3071
- Virtual page 3 covers 3072 to 4095
- Virtual page 4 covers 4096 to 5119

Looking at the initial state of the page table (Figure 4):
- **Virtual Page 0** is present in memory (Frame 3)
- **Virtual Page 1** is present in memory (Frame 1)
- **Virtual Page 4** is present in memory (Frame 2)
- **Virtual Page 6** is present in memory (Frame 0)
- All other pages (2, 3, 5, 7) have a Present/Absent bit of `0`, meaning they are not in physical memory.

The program updates ranges of virtual addresses:
- **1020 to 1029**: Addresses 1020–1023 are in Virtual Page 0. Addresses 1024–1029 are in Virtual Page 1. Both pages are already in physical memory, so no interruption occurs.
- **2040 to 2049**: Addresses 2040–2047 are in Virtual Page 1 (already in memory). Addresses 2048–2049 fall into Virtual Page 2. Since Virtual Page 2 has a Present/Absent bit of `0`, trying to access it causes a **page fault** (Answer **A = c**). The exact virtual address where this happens is the first address of Virtual Page 2, which is **2048** (Answer **B = d**).

**(2) Blanks C, D, and E**

The system uses the LRU (Least Recently Used) algorithm. Let's trace the page replacements step-by-step. The initial configuration in physical frames is:
- Frame 0: VP6
- Frame 1: VP1
- Frame 2: VP4
- Frame 3: VP0

The sequence of virtual page accesses is: `0, 1, 4, 6, 0, 5, 3, 2, 3, 4, 2, 6`.

| Access | Memory state (LRU -> MRU) | Replacements | Notes |
| :--- | :--- | :--- | :--- |
| `0,1,4,6` | `(0, 1, 4, 6)` | 0 | All already in memory; sets MRU order. |
| `0` | `(1, 4, 6, 0)` | 0 | VP0 becomes MRU. |
| `5` | `(4, 6, 0, 5)` | 1 | VP5 replaces VP1 (LRU) in **Frame 1**. |
| `3` | `(6, 0, 5, 3)` | 2 | VP3 replaces VP4 (LRU) in **Frame 2**. |
| `2` | `(0, 5, 3, 2)` | 3 | VP2 replaces VP6 (LRU) in **Frame 0**. |
| `3` | `(0, 5, 2, 3)` | 3 | VP3 becomes MRU. |
| `4` | `(5, 2, 3, 4)` | 4 | VP4 replaces VP0 (LRU) in **Frame 3**. |
| `2` | `(5, 3, 4, 2)` | 4 | VP2 becomes MRU. |
| `6` | `(3, 4, 2, 6)` | 5 | VP6 replaces VP5 (LRU) in **Frame 1**. |

At the end of the sequence:
- **Frame 0** holds Virtual Page **2** (Answer **C = c**).
- **Frame 1** holds Virtual Page **6** (Answer **D = g**).
- The total number of virtual page replacements is **5** (Answer **E = f**).

### Explanation
Based on the scenario and Table 1:
- **Blank A (e - Reset Password):** When a user forgets their password, they cannot log in and must reset it. From the Welcome page, they navigate to the Reset Password page (Function 6).
- **Blank B (b - Change Password):** According to Table 1, the Reset Password function uses the Change Password function (Function 7) to overwrite the password. Thus, the flow goes from Reset Password to Change Password before reaching the My Account page.
- **Blank C (c - e-mail address and user name):** To reset a password, the user must first identify their account. On the Reset Password page, they are asked for their e-mail address and user name. The security question answer is then requested on the subsequent Change Password page to authorize the change, as specified in Function 7.

In Method 2, the intercepted response hash is only valid for that specific session's challenge. In Method 3, the intercepted token password expires based on time. - **Blank D:** A keylogger records exactly what the user types. In **Method 1**, the user types their static password. In **Method 2**, the user also types their static password into their terminal so it can calculate the response hash. In Method 3, the user types a temporary, time-based token password. Since the static password is stolen in Methods 1 and 2, a third party can use it to log in anytime. (Choice d)
- **Blank E:** If the user mistakenly connects to a malicious server, they will send their login information to it. Under **Method 1**, the malicious server receives the plain text static password. Under Method 2, the malicious server issues a challenge and only receives a hash, never learning the actual static password. Under Method 3, the malicious server receives a temporary token password that soon expires. Therefore, only Method 1 leaks the static password to the malicious server. (Choice a)

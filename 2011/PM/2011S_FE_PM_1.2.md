**Blank D (Average access time for Product C):**

The expected access time with a disk cache includes the initial search overhead, plus the time spent reading based on whether it is a cache hit or a miss.

- **Formula:** `Average Access Time = Search Time + (Hit Ratio × Cache Read Time) + (Miss Ratio × Disk Read Time)`
- **Given values:**
  - Search Time = 1.0 msec (always incurred)
  - Hit Ratio = 0.4
  - Cache Read Time = 0.4 msec
  - Miss Ratio = 1.0 - 0.4 = 0.6
  - Disk Read Time (including cache replacement) = 17.0 msec

- **Calculation:**
  `Average Access Time = 1.0 + (0.4 × 0.4) + (0.6 × 17.0)`
  `Average Access Time = 1.0 + 0.16 + 10.2 = 11.36 msec`

- Truncating to the first decimal place (or acknowledging 11.3 as the nearest available choice in the group) yields **11.3 msec** (Answer **d**).

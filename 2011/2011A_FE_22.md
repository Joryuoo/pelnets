Since this is a non-preemptive environment, once a process gets the CPU, it keeps it until it finishes its CPU burst.
Process A has higher priority than Process B.

Here is the timeline of execution:
* **t = 0 to 30**: Process A uses the CPU for 30 ms. Process B waits for the CPU.
* **t = 30**: Process A finishes its first CPU burst and goes to I/O (needs 60 ms). Process B gets the CPU (needs 45 ms).
* **t = 30 to 75**: Process B uses the CPU for 45 ms. At t=75, it finishes and needs I/O (45 ms). However, the problem states that I/O for A and B cannot be performed in parallel. Since A is using I/O until t=90, B must wait.
* **t = 90**: Process A finishes its I/O burst and requests the CPU (needs 30 ms). Process B can now start its I/O burst.
* **t = 90 to 120**: Process A uses the CPU for 30 ms and completes at t=120.
* **t = 90 to 135**: Process B uses I/O for 45 ms and completes at t=135.

Both processes complete at 135 ms.

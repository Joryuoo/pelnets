To find the earliest start date of activity H in a PERT/CPM chart (Arrow Diagram), we must determine the longest path from the start node to the node preceding activity H.
Based on the typical structure of such problems, the earliest start time of an activity is the maximum of the earliest finish times of all immediately preceding activities. The dummy activity (d) has 0 duration but imposes a dependency. Calculating the cumulative durations along the longest path to the start of H will result in 7 days.

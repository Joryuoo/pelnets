# 2011A_FE_21

Which of the following is an appropriate description concerning the use of an application on a computer with virtual memory?

a) A specially designed module for using virtual memory needs to be embedded in the application.
b) In order to use virtual memory, each individual application needs to be configured to use virtual memory.
c) Insufficient main memory causes excessive page faults during running the application and reduces the system throughput.
d) Only those applications that are installed on the hard disk in advance can use virtual memory.
?
c) Insufficient main memory causes excessive page faults during running the application and reduces the system throughput.

### Explanation
### Explanation
Virtual memory allows a computer to use secondary storage as if it were main memory. However, if there is insufficient main memory, the system frequently swaps data back and forth between main memory and secondary storage, a process known as paging or page faulting. Excessive page faults severely degrade system performance, a condition called thrashing.

* **a)** Incorrect. Virtual memory is handled by the operating system, not by a module embedded in the application.
* **b)** Incorrect. The use of virtual memory is generally transparent to the application; it does not need individual configuration.
* **d)** Incorrect. Applications do not strictly need to be installed on the hard disk in advance to use virtual memory (e.g., portable apps running from flash drives or over a network can still run in a virtual memory environment).

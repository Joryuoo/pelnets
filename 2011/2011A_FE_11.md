# 2011A_FE_11

Which of the following is a method of creating a program that can use the instruction cache effectively?

a) The frequently executed parts of the program are put together.
b) The program is created so that the entire code can be executed evenly.
c) The program is created so that the entire work area can be accessed evenly.
d) The work areas to be accessed by the program are put together.
?
a) The frequently executed parts of the program are put together.

### Explanation
The instruction cache stores recently executed instructions to speed up CPU processing. Because of the principle of spatial locality, placing frequently executed parts of a program together ensures that when a block of instructions is loaded into the cache, it contains other instructions that are also likely to be executed soon, minimizing cache misses.

- **b)** Executing code evenly does not take advantage of spatial or temporal locality.
- **c) and d)** Refer to the "work area" (data), which relates to the data cache, not the instruction cache.

# 2011S_FE_19

Which of the following is an appropriate explanation of a fault tolerant system?

a) It is a backup system provisioned at a remote site as preparation for a regional disaster.
b) It is a system that continues providing functions required for system operations as a whole even if a part of the system fails to operate properly.
c) It is a system that processes one transaction with multiple processors in parallel and checks the results.
d) It is a system that shares resources by connecting multiple processors via a network.
?
b) It is a system that continues providing functions required for system operations as a whole even if a part of the system fails to operate properly.

### Explanation
A **fault tolerant system** is designed to continue operating and providing its core functions even if one or more of its components fail. This is typically achieved through redundancy and failover mechanisms.

* **a) It is a backup system provisioned at a remote site...:** This describes a disaster recovery or backup site (e.g., hot site).
* **c) It is a system that processes one transaction with multiple processors in parallel and checks the results:** This is a specific technique (Lockstep processing/TMR) used to achieve fault tolerance, but it does not define fault tolerance as a whole.
* **d) It is a system that shares resources by connecting multiple processors via a network:** This describes a distributed system or cluster.

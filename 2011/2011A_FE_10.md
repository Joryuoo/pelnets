# 2011A_FE_10

Which of the following is the characteristic of pipeline control?

a) Each machine instruction is replaced with a combination of lower level microinstructions at the time of execution.
b) In order to execute multiple instructions simultaneously, each instruction is assigned to a specific computing unit when the compiler generates an object code.
c) Multiple instructions are executed simultaneously by dynamically deciding which computing unit to use at the time of executing each instruction.
d) The processing of each instruction is divided into multiple stages in the processor, and thus multiple instructions are executed in parallel.
?
d) [See image]

### Explanation
Pipeline control is an implementation technique where multiple instructions are overlapped in execution. The computer pipeline is divided into stages (e.g., fetch, decode, execute, memory access, write-back). Each stage completes a part of an instruction in parallel with other stages completing parts of other instructions. 
- Choice (a) refers to microprogramming.
- Choice (b) refers to VLIW (Very Long Instruction Word) architecture where the compiler handles instruction-level parallelism.
- Choice (c) describes superscalar processing, which dynamically dispatches instructions to multiple execution units.
- Choice (d) correctly describes the stages and parallel overlapping nature of instruction pipelining.

### Explanation
A Class C network natively has a default subnet mask of `255.255.255.0` (or `/24`), leaving 8 bits for the host portion.

The given subnet mask is `255.255.255.224`. In binary, 224 is `11100000`.
This means 3 bits have been borrowed from the host portion for subnetting, leaving 5 bits for the hosts.

- **Number of Subnets:** Since 3 bits are used for the subnet, $2^3 = 8$ subnets can be created.
- **Number of Hosts:** Since 5 bits remain for the host portion, $2^5 = 32$ host addresses are available per subnet (the question explicitly asks for the number of IP addresses "including reserved or ineffective addresses", so we do not subtract 2 for the network and broadcast addresses).

Thus, there are 8 subnets and 32 hosts per subnet, making choice **a** correct.

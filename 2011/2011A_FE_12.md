# 2011A_FE_12

In a virtual storage computer system with cache memory, main memory, and disk storage, it takes 2 nanoseconds, 10 nanoseconds, and 10 milliseconds, on average, to access data available in the cache, main memory, and disk storage, respectively.
When the cache hit ratio and the main memory hit ratio (after a cache miss) are 0.95 and 0.99 respectively, which of the following is the approximate average time in microseconds to access the necessary data?

a) 4.7
b) 4.9
c) 5.0
d) 5.2
?
c) 5.0

### Explanation
To find the average access time, we calculate the time spent based on the probabilities of cache hits, main memory hits, and disk accesses.

Given:
- Cache access time = $2\text{ ns}$
- Main memory access time = $10\text{ ns}$
- Disk access time = $10\text{ ms} = 10,000,000\text{ ns}$
- Cache hit ratio = $0.95$ (Miss ratio = $0.05$)
- Main memory hit ratio = $0.99$ (Miss ratio = $0.01$)

The formula for average access time in a hierarchical memory system is:
$\text{Average Access Time} = \text{Cache Access Time} + \text{Cache Miss Ratio} \times (\text{Main Memory Access Time} + \text{Main Memory Miss Ratio} \times \text{Disk Access Time})$

Calculation:
1. $\text{Average Access Time} = 2 + 0.05 \times (10 + 0.01 \times 10,000,000)$
2. $= 2 + 0.05 \times (10 + 100,000)$
3. $= 2 + 0.05 \times (100,010)$
4. $= 2 + 5000.5$
5. $= 5002.5\text{ ns}$

Converting $5002.5\text{ ns}$ to microseconds ($\mu\text{s}$) gives $5.0025\text{ }\mu\text{s}$, which is approximately **5.0**.

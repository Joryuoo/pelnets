# 2011S_FE_41

Which of the following is an algorithm that can be used for asymmetric (or public key) cryptography?

a) AES
b) DES
c) RC4
d) RSA
?
d) RSA

### Explanation
RSA is an asymmetric (public-key) encryption algorithm that uses a public key for encryption and a private key for decryption.

Why the other choices are wrong:
- **a) AES**: Advanced Encryption Standard is a symmetric block cipher algorithm, using the same key for encryption and decryption.
- **b) DES**: Data Encryption Standard is a legacy symmetric block cipher algorithm.
- **c) RC4**: Rivest Cipher 4 is a symmetric stream cipher algorithm.

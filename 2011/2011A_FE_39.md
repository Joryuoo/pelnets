# 2011A_FE_39

Q39. Which of the following is a connectionless protocol that offers speed and low overhead as its primary advantage in the transport layer of the OSI basic reference model?

a) ARP
b) ICMP
c) IP
d) UDP
?
d) UDP

### Explanation
UDP (User Datagram Protocol) is a connectionless protocol that operates at the transport layer (Layer 4) of the OSI model. Because it does not guarantee delivery, ordering, or error recovery (unlike TCP), it has much lower overhead, making it faster and suitable for real-time applications like streaming and VoIP.

- **a) ARP:** Operates at the Data Link Layer (Layer 2) to resolve IP addresses to MAC addresses.
- **b) ICMP:** Operates at the Network Layer (Layer 3) for diagnostic and error reporting (e.g., ping).
- **c) IP:** Operates at the Network Layer (Layer 3) and is connectionless, but it is not a transport layer protocol.

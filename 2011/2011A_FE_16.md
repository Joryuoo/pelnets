# 2011A_FE_16

In a client/server system, which of the following is the most appropriate advantage of using “stored procedures” that are available to all clients and do not need to be replicated in each client?

a) Data traffic between client and server can be reduced.
b) Distributed processing can be easily implemented.
c) Memory usage of both client and server can be reduced.
d) The number of access to the database can be reduced.
?
a) Data traffic between client and server can be reduced.

### Explanation
A **stored procedure** is a precompiled collection of SQL statements stored directly on the database server. 

When a client application needs to perform a complex database operation, it can simply execute the stored procedure with a single call, rather than sending multiple individual SQL queries over the network. This significantly reduces the network data traffic between the client and the server.

- **b)** Stored procedures centralize processing on the database server rather than distributing it.
- **c)** Memory usage on the server might actually increase slightly to hold the compiled procedures in cache.
- **d)** The actual number of internal database accesses remains the same; they are just orchestrated centrally by the server rather than piecemeal over the network.

# 2011A_FE_69

Which of the following is applicable to the definition of “non-functional” requirements?

a) Creating development criteria and standards suitable for the language used in system development
b) Defining the scope of system functions to be designed and implemented in system development
c) Identifying the flow of information (i.e., data) between functions that compose the business operations
d) Identifying the interface functions to be used for the exchange of information with other systems
?
a) Creating development criteria and standards suitable for the language used in system development

### Explanation
Requirements are categorized into functional (what the system should do) and non-functional (how the system should perform, such as constraints, quality attributes, performance, and development standards). Creating development criteria and coding standards is considered a constraint or quality attribute imposed on the development process, which falls under non-functional requirements.

- **b, c, and d** all describe functional requirements, as they deal with the specific behaviors, data flows, and interfaces the system must implement to perform its business tasks.

# 2011S_FE_3

When the true and measured values are 1.744 and 1.720 respectively, what is the approximate relative error in percentage?

a) −2.4
b) −1.4
c) 1.4
d) 2.4
?
c) 1.4

### Explanation
Relative error is (true value − measured value) divided by the true value: (1.744 − 1.720) / 1.744 ≈ 0.01376. Multiplying by 100 gives approximately 1.4%.

Use the true value as the denominator: $\frac{1.744-1.720}{1.744}\times100\%\approx1.38\%$. The measured value is smaller, so the error under this convention is positive; this eliminates a and b. Choice d has the right sign but nearly doubles the actual magnitude.

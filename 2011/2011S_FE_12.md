# 2011S_FE_12

When XML is compared with HTML, which of the following functions is enabled only by using XML?

a) Describing documents by using tags
b) Displaying dynamic web pages
c) Embedding hyperlinks to other documents
d) Exchanging structured information
?
d) Exchanging structured information

### Explanation
**XML** (eXtensible Markup Language) allows users to define their own tags and attributes, making it highly suitable for describing and exchanging structured information between different systems.

* **a) Describing documents by using tags:** Both HTML and XML use tags, so this is not unique to XML.
* **b) Displaying dynamic web pages:** Dynamic behavior is typically handled by scripting languages like JavaScript combined with the DOM, not XML itself.
* **c) Embedding hyperlinks to other documents:** HTML natively supports hyperlinks (via the `<a>` tag), so this is not unique to XML.

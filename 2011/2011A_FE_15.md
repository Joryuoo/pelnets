# 2011A_FE_15

Which of the following is an appropriate characteristic of a client/server system?

a) A tightly-coupled system configuration is employed so that both client and server can work well together to access common resources.
b) Databases installed within clients that provide services can be flexibly expanded with a change in the scale.
c) The client works together with servers in order to provide services in response to many requests from servers.
d) The server provides functions as services for the client and performs the intended application in cooperation with the client.
?
d) The server provides functions as services for the client and performs the intended application in cooperation with the client.

### Explanation
In a client/server architecture, responsibilities are clearly divided: the **server** centrally hosts resources, data, or services, and the **client** requests these services to run the user interface and application logic in cooperation with the server.

- **a)** Client/server systems are typically **loosely coupled**, allowing clients and servers to be upgraded or replaced independently.
- **b)** Scalable databases are hosted on the **servers**, not the clients.
- **c)** **Clients** send requests to servers, not the other way around.

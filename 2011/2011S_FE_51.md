# 2011S_FE_51

Which of the following is an appropriate activity to be performed in the first phase of system development?

a) Analyzing the current business operations and organizing system requirements
b) Designing the internal structure of each program
c) Designing the user interface
d) Dividing subsystems into programs and designing the details of each program
?
a) Analyzing the current business operations and organizing system requirements

### Explanation
Development begins by understanding existing work and defining what the new system must do. Internal program design and user-interface design follow after requirements are established.

The phase order is `business analysis and requirements → external/interface design → detailed program design → implementation`. Option a belongs at the start. The interface in c and the internal program structures in b and d require requirements to be understood first.

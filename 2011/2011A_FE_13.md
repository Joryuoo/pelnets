### Explanation
To calculate the required storage capacity for the images:

1. **Determine the number of pixels per image:**
   The resolution is $1,600 \times 1,200$ pixels, so each image has $1,920,000$ pixels.

2. **Determine the memory size per pixel:**
   The image uses a 256-level grayscale. Since $256 = 2^8$, it takes 8 bits, or **1 byte**, to store the color information for each pixel.

3. **Calculate the size of one image:**
   $1,920,000\text{ pixels} \times 1\text{ byte/pixel} = 1,920,000\text{ bytes}$ (which is approximately $1.92\text{ MB}$). Note that $1,000,000$ bytes is $1\text{ MB}$ or $1,048,576$ bytes is $1\text{ MiB}$; standard approximation simplifies this to $\approx 2\text{ MB}$.

4. **Calculate the total size for five images:**
   $1.92\text{ MB/image} \times 5\text{ images} = 9.6\text{ MB}$.

$9.6\text{ MB}$ rounds to approximately **10 megabytes**. Therefore, option c is correct.

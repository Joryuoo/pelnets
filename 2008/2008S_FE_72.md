# 2008S_FE_72

Q72. Which of the following is a characteristic of the QR code?  

a) Characters except in binary form can be expressed by the code. 
b) It can contain up to 128 alphanumeric characters or up to 64 double-byte characters.  
c) It is a programming language and is executable on the cell phone.  
d) Using three symbols for detection, the code makes it possible to recognize the rotation angle and the direction of reading.
?
d) Using three symbols for detection, the code makes it possible to recognize the rotation angle and the direction of reading.

### Explanation
### Explanation
A QR code includes three distinct position detection patterns (finder patterns) at its corners, which allow scanners to rapidly recognize the rotation angle, direction of reading, and overall position of the code.

- **a)** QR codes *can* express binary data, in addition to numeric, alphanumeric, and Kanji characters.
- **b)** QR codes can contain much more data, up to several thousand alphanumeric characters depending on the version and error correction level.
- **c)** A QR code is a 2D barcode for data storage, not a programming language.

### Explanation
The total number of addressable memory locations is determined by the number of address lines. With 24 address lines, there are $2^{24}$ addressable memory locations.

Each location holds a word of data, and the size of this word is given by the number of data lines, which is 16 bits. 

Since each memory cell (or latch) holds exactly 1 bit, the total number of memory cells is the number of addressable locations multiplied by the number of bits per location: $2^{24} \times 16$.

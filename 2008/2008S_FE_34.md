# 2008S_FE_34

Q34. Which of the following is an appropriate language that can be used to develop applications running mainly on Web browsers?

a) Java Applet
b) JavaBeans
c) JavaScript
d) Java Servlet
?
c) JavaScript

### Explanation
JavaScript is a scripting language specifically designed to run on the client side (within Web browsers) to create interactive and dynamic web applications.

* **Choice c) is correct.** JavaScript is the standard language for client-side web browser applications.
* Choice a) Java Applets were small Java applications embedded in web pages, but they require a browser plugin and are now obsolete and unsupported by modern browsers.
* Choice b) JavaBeans are reusable software components for Java, not a language for browser apps.
* Choice d) Java Servlets execute on the server side (backend) to handle HTTP requests and generate web content, not inside the web browser.

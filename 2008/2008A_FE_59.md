# 2008A_FE_59

Which of the following is the mechanism for interfacing a Web server with an external program in order to implement an interactive page where an application program on the server executes a request from a client and returns the resulting output to the browser?

a) CGI
b) HTML
c) MIME
d) URL
?
a) CGI

### Explanation
CGI (Common Gateway Interface) is a standard protocol used by web servers to execute external programs (often scripts) and pass the user's request to them. The output of the program is then returned to the web server, which forwards it to the client's browser, enabling dynamic and interactive web pages.

* **b) HTML:** The standard markup language for documents designed to be displayed in a web browser.
* **c) MIME:** An Internet standard that extends the format of emails and helps browsers identify file types.
* **d) URL:** The address used to locate resources on the web.

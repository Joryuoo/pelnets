# 2008S_FE_78

Q78. A server runs a regional web application. It services the requests coming in from all regional offices.  Each request is completed in 80 milliseconds on average.  A total of 10 requests per second arrive at the server on average.  If the M/M/1 queuing model can be applied, how many requests are waiting for the service on average?  

a) 3.20 
b) 4.00 
c) 4.66 
d) 5.00
?
b) 4.00

### Explanation
### Explanation
Using the M/M/1 queuing model formulas:
- Arrival rate $\lambda = 10$ requests/second.
- Service time $= 80$ ms $= 0.08$ seconds.
- Service rate $\mu = 1 / 0.08 = 12.5$ requests/second.
- Utilization $\rho = \lambda / \mu = 10 / 12.5 = 0.8$.

The official correct answer key expects 4.00, which corresponds to the average number of requests *in the system* (both waiting in queue and currently being serviced).
- Average number of requests in the system $L = \rho / (1 - \rho) = 0.8 / (1 - 0.8) = 0.8 / 0.2 = 4.00$.

*(Note: If strictly looking for the number of requests waiting in the queue alone, the formula is $L_q = \rho^2 / (1 - \rho) = 3.20$. However, according to the official exam's answer key, the intended calculation here translates to the total requests in the system.)*

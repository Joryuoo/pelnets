# 2008A_FE_11

There are three stacks A, B, and C where stack A contains the values 1, 2, and 3; 3 is on the top of the stack, and stacks B and C are empty. The stack command format is as follows:

<stack command> (<stack name>, <temporary variable>)

What is the resulting content of stack A after executing the stack operations shown below? Each rightmost element in the option list represents the value on the top of the stack.

Pop (A, x) → Push (B, x) → Pop (A, x) → Push (C, x) → Pop (A, x) → Push (C, x) → Pop (B, x) → Push (A, x) → Pop (C, x) → Push (B, x) → Pop (C, x) → Push (A, x) → Pop (B, x) → Push (A, x)

a) 1, 2, 3
b) 2, 1, 3
c) 3, 1, 2
d) 3, 2, 1
?
d) 3, 2, 1

### Explanation
Let's trace the state of the stacks step by step. Initially, stack A has [1, 2, 3] with 3 on top. Stacks B and C are empty.

1. `Pop (A, x)`: x = 3, A becomes [1, 2]
2. `Push (B, x)`: B becomes [3]
3. `Pop (A, x)`: x = 2, A becomes [1]
4. `Push (C, x)`: C becomes [2]
5. `Pop (A, x)`: x = 1, A becomes []
6. `Push (C, x)`: C becomes [2, 1] (1 is on top)
7. `Pop (B, x)`: x = 3, B becomes []
8. `Push (A, x)`: A becomes [3]
9. `Pop (C, x)`: x = 1, C becomes [2]
10. `Push (B, x)`: B becomes [1]
11. `Pop (C, x)`: x = 2, C becomes []
12. `Push (A, x)`: A becomes [3, 2]
13. `Pop (B, x)`: x = 1, B becomes []
14. `Push (A, x)`: A becomes [3, 2, 1] (1 is on top)

After all operations, Stack A contains 3, 2, 1 with 1 on top. When listing from bottom to top, it is 3, 2, 1, matching choice d.

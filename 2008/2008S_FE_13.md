# 2008S_FE_13

A singly linked list is implemented using two arrays VALUE and LINK, in which LINK(I) points to the successor of VALUE(I). When a new element that does not exist initially in the list is assigned to VALUE(J), the program fragment shown below is executed. Which of the following appropriately describes the function of this program?

LINK(J) <- LINK(I);
LINK(I) <- J;

a) VALUE(I) is replaced by VALUE(J) in the list.
b) VALUE(J) is inserted after VALUE(I) in the list.
c) VALUE(J) is inserted before VALUE(I) in the list.
d) VALUE(J) is replaced by VALUE(I) in the list.
?
b) VALUE(J) is inserted after VALUE(I) in the list.

### Explanation
In a singly linked list implemented with arrays `VALUE` and `LINK`, `LINK(I)` stores the index of the next element after the element at `VALUE(I)`. 

To insert a new node `J` after node `I`:
1. The new node's next pointer (`LINK(J)`) must first be set to point to `I`'s current successor. This is achieved by `LINK(J) <- LINK(I)`.
2. Then, `I`'s next pointer (`LINK(I)`) is updated to point to the newly added node `J`. This is achieved by `LINK(I) <- J`.

Thus, the element at `VALUE(J)` is correctly inserted after `VALUE(I)`.

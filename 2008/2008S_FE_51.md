# 2008S_FE_51

Q51. When a network device is connected to the LAN with the network address of 
201.12.1.64 and the subnet mask of 255.255.255.192, which of the following IP 
addresses should NOT be assigned to the device on the network?  
  
a) 201.12.1.65 
b) 201.12.1.96  
c) 201.12.1.126 
d) 201.12.1.127
?
d) 201.12.1.127

### Explanation
### Explanation
The network address is 201.12.1.64 and the subnet mask is 255.255.255.192. The subnet mask 255.255.255.192 in binary is `11111111.11111111.11111111.11000000`, which means the last 6 bits are used for host addresses. Therefore, the network size is 2^6 = 64 addresses.
The addresses for this subnet range from 201.12.1.64 to 201.12.1.127.
- The first address, 201.12.1.64, is the network address.
- The last address, 201.12.1.127, is the broadcast address.
Neither the network address nor the broadcast address can be assigned to a host device. Since 201.12.1.127 is the broadcast address, it should not be assigned.

# 2008A_FE_5

There are a total of N values observed. The sum S (S > 0) of these values is obtained, and then the average value is calculated. Which of the following is the correct expression when the average value is rounded off to the nearest integer value? Here, "/" indicates division, and [X] is the maximum integer equal to X or less.

a) [(S+0.5)/N]
b) [(S-1)/N]+1
c) [S/N+0.5]
d) [S/N]+1
?
c) [S/N+0.5]

### Explanation
The average value is $\frac{S}{N}$. 
To round a positive number to the nearest integer, we add $0.5$ and then take the floor of the result (the greatest integer less than or equal to the number). 
The floor function is denoted by $[X]$. Thus, rounding $\frac{S}{N}$ to the nearest integer is mathematically expressed as $[\frac{S}{N} + 0.5]$.

# 2008A_FE_19

When a CPU can perform a multiplication in 12 nanoseconds (ns), an addition in 1 ns, and a subtraction in 1.5 ns, which of the following is the minimum CPU time, in nanoseconds, for the calculation of “a×a–b×b”?

a) 12.5
b) 13.5
c) 14.5
d) 25.5
?
c) 14.5

### Explanation
To minimize the CPU execution time, we can optimize the expression mathematically using the difference of squares identity:
$a \times a - b \times b = (a + b) \times (a - b)$

Calculating it this way requires:
1. One addition for $(a + b)$: 1 ns
2. One subtraction for $(a - b)$: 1.5 ns
3. One multiplication to multiply the two results: 12 ns

Total minimum CPU time = $1 + 1.5 + 12 = 14.5$ ns.

If we were to calculate it directly as $a \times a - b \times b$, it would require two multiplications ($12 + 12 = 24$ ns) and one subtraction ($1.5$ ns), totaling $25.5$ ns, which is much slower.

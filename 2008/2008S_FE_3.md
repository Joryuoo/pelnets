The problem asks for the range of integers that can be expressed with `n` bits using two's complement. (The detail "the position of the binary point is to the right of the least significant bit" is just a formal way of stating that the number is an integer).

In an `n`-bit two's complement representation:
- The most significant bit (MSB) acts as the sign bit, carrying a weight of $-2^{n-1}$.
- The remaining `n-1` bits are positive and can represent values from 0 up to $2^{n-1} - 1$.

Therefore, the minimum value (when only the sign bit is 1) is $-2^{n-1}$.
The maximum value (when the sign bit is 0 and all other bits are 1) is $2^{n-1} - 1$.
The correct range is $-2^{n-1}$ through $2^{n-1} - 1$.

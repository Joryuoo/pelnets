### Explanation
In programming control structures, loops are used to repeat a block of code. 

A **"while" repetition structure** (often called a pre-test loop) evaluates its condition *before* executing the loop's body (the process). If the condition is true, the process executes, and the flow returns to evaluate the condition again. If it is false, the loop terminates immediately. Therefore, the flowchart must show the flow entering the Condition block first, branching to the Process block on true, and bypassing it on false. 

Conversely, a "do-while" structure (post-test loop) executes the Process first, then checks the Condition. The correct flowchart for a "while" loop matches option d).

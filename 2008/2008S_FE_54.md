# 2008S_FE_54

Q54. Which of the following operations is performed on the packet header while the data 
packet moves from the lower to upper layers according to the OSI basic reference 
model?  
 
a) Header addition 
b) Header deletion  
c) Header modification 
d) Header rearrangement
?
b) Header deletion

### Explanation
### Explanation
According to the OSI model, as a data packet moves from a lower layer to an upper layer (a process called decapsulation), the receiving system processes and then removes (deletes) the header that was added by the corresponding layer on the sending system. 
Conversely, when moving from upper to lower layers (encapsulation), headers are added.

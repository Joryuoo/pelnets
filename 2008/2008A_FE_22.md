### Explanation
To calculate the CPU performance in MIPS (Million Instructions Per Second), we first need to determine the average number of clock cycles per instruction (CPI).

1. **Calculate the average CPI** based on the appearance rates:
   - Operation between registers: 4 cycles * 0.30 = 1.2
   - Operation between memory and registers: 8 cycles * 0.60 = 4.8
   - Unconditional branch: 10 cycles * 0.10 = 1.0
   - **Average CPI** = 1.2 + 4.8 + 1.0 = 7.0 cycles/instruction

2. **Calculate the execution speed in instructions per second**:
   - The CPU frequency is 700 MHz, which is 700,000,000 cycles per second.
   - Instructions per second = (700,000,000 cycles / second) / (7.0 cycles / instruction) = 100,000,000 instructions / second.

3. **Convert to MIPS**:
   - 100,000,000 instructions per second / 1,000,000 = 100 MIPS.

Therefore, the approximate performance of the CPU is 100 MIPS.

# 2008A_FE_16

Which of the following is the sorting algorithm that divides the data elements into two groups, in which all those elements less than a particular element (called a pivot value) and all those elements greater than or equal to it are separately included, and then repeats the same operation until all elements are sorted in ascending or descending order?

a) Heap sort
b) Insertion sort
c) Merge sort
d) Quick sort
?
d) Quick sort

### Explanation
Quick sort works by selecting a 'pivot' element from the array and partitioning the other elements into two sub-arrays, according to whether they are less than or greater than the pivot. This process is then recursively applied to the sub-arrays.

Brief overview of the other choices:
- **Heap sort:** Builds a heap data structure to repeatedly extract the maximum/minimum element.
- **Insertion sort:** Builds the final sorted array one item at a time by inserting each element into its proper place.
- **Merge sort:** Divides the array into halves, sorts them recursively, and then merges the sorted halves.

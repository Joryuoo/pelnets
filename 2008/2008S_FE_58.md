# 2008S_FE_58

Q58. Which of the following provides the function of mapping between domain names and 
IP addresses in a TCP/IP network?  
 
a) DHCP 
b) DNS  
c) SNMP 
d) Proxy
?
b) DNS

### Explanation
### Explanation
DNS (Domain Name System) acts as the phonebook of the Internet. It provides the function of mapping human-readable domain names (like www.example.com) to their corresponding IP addresses, which are used by computers to route traffic.
- **DHCP** assigns IP addresses dynamically.
- **SNMP** manages network devices.
- **Proxy** forwards requests on behalf of a client.

# 2008A_FE_58

Which of the following is a mechanism that allows a Web server to store its own information about a user on the user’s own computer so that the Web server can identify users and possibly prepare customized Web pages for them?

a) Cookie
b) Password
c) SSL
d) URL
?
a) Cookie

### Explanation
An HTTP cookie is a small piece of data sent from a website and stored on the user's computer by their web browser. It allows the web server to remember stateful information (such as login status or items in a shopping cart) or record the user's browsing activity to customize their experience.

* **b) Password:** A secret string of characters used for authentication, not a storage mechanism on the client for customized state.
* **c) SSL:** Secure Sockets Layer is used to encrypt communication.
* **d) URL:** The address of a web resource.

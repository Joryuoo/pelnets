d) XOR (Exclusive OR)

### Explanation
In a RAID 3 setup, data is striped at the byte level across multiple disks, and one dedicated parity disk stores parity information. The parity is generated using the logical **XOR** (Exclusive OR) operation across the corresponding bytes of the data disks. If one drive fails, the missing data can be perfectly reconstructed by XOR-ing the data from the surviving disks and the parity disk.

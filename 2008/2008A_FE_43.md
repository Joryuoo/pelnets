# 2008A_FE_43

Which of the following is the appropriate sequence for drawing up a DFD model that is used to develop a new system based on the current system?

1. Current logical model
2. Current physical model
3. New logical model
4. New physical model

a) 1 → 2 → 3 → 4
b) 1 → 2 → 4 → 3
c) 2 → 1 → 3 → 4
d) 2 → 1 → 4 → 3
?
c) 2 → 1 → 3 → 4

### Explanation
When developing a new system based on a current one using Data Flow Diagrams (DFDs), the typical sequence of modeling (often referred to as the Yourdon method or structured systems analysis) is:
1. **Current physical model:** Analyze the existing system as it physically operates to understand current processes.
2. **Current logical model:** Abstract the physical details to understand what the current system logically accomplishes without physical constraints.
3. **New logical model:** Modify the current logical model to incorporate new requirements and logical improvements.
4. **New physical model:** Determine how the new logical model will be physically implemented with technology, personnel, and new structures.

Therefore, the sequence is 2 → 1 → 3 → 4.

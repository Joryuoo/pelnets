# 2008S_FE_48

Q48. Which of the following most appropriately describes the handling of control information in system operation management?

a) The system should be managed by a single manager.  Control information should be disclosed to the general user after its security level and other factors are considered.
b) The system should be managed by a small group of managers.  The management account should be exclusive to the group and should be shared.  Control information should be disclosed to the general user after its security level and other factors are considered.
c) The system should be managed by a small group of managers.  The management account should be exclusive to the group and should be shared.  Control information should be disclosed to the general user so that each user can check the information.
d) The system should be managed by a small group of managers.  Each manager should be given an exclusive and separate account. Control information should be disclosed to the general user after its security level and other factors are considered.
?
d) The system should be managed by a small group of managers.  Each manager should be given an exclusive and separate account. Control information should be disclosed to the general user after its security level and other factors are considered.

### Explanation
In system operation management, it's essential to enforce accountability and separation of duties.
- **Choice a** presents a single point of failure and lack of oversight by relying on a single manager.
- **Choices b and c** suggest sharing a single management account, which violates the principle of accountability (if an action is performed, it's impossible to tell which manager did it).
- **Choice d** ensures each manager has an exclusive, separate account for accountability, and appropriately restricts control information based on security levels.

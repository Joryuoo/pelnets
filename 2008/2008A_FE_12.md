Let's test the expressions with a sample score from each range to see which one correctly yields the corresponding index.

For index 1, the score range is Score < 40. Let's use 31:
- a) (31/10) - 3 = 3.1 - 3 = 0.1 → 0
- b) (31/30) / 10 = 1.03 / 10 ≈ 0.1 → 0
- c) (31 - 30) / 10 + 1 = 1 / 10 + 1 = 1.1 → 1
- d) (31 - 40) / 10 = -9 / 10 = -0.9 → 0

For index 7, the score range is 90 <= Score < 100. Let's use 95:
- c) (95 - 30) / 10 + 1 = 65 / 10 + 1 = 6.5 + 1 = 7.5 → 7

Only expression c correctly produces the required array index when the result is truncated to an integer.

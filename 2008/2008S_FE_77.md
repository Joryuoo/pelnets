- **Week 4**: Activity A is finished. Activity B continues ($600). Weekly cost = $600.
- **Weeks 5 to 10**: Activity C requires A and B, so it starts at Week 5. Activity D requires B, so it also starts at Week 5. C ($900) and D ($850) run concurrently. Weekly cost = $1,750.
- **Week 11**: Activity C ends at week 10. Activity E starts at week 11 ($500). Activity D ($850) is still running its final 7th week. Weekly cost = $1,350.
- **Week 12**: Activity D ends. Activity E finishes its 2nd week ($500). Weekly cost = $500.

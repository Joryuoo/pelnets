# 2008A_FE_26

Which of the following storage devices has the fastest access time?

a) CPU L2 cache memory
b) CPU register
c) Hard disk
d) Main memory
?
b) CPU register

### Explanation
In the computer memory hierarchy, the access speed is inversely related to the size and distance from the CPU core. The closer and smaller the storage, the faster it is.

The hierarchy from fastest to slowest is:
1. **CPU Registers**: Located inside the CPU core, operating at the processor's full clock speed.
2. **Cache Memory (L1, L2, L3)**: Small, fast SRAM located on or very close to the CPU chip.
3. **Main Memory (RAM)**: Slower DRAM, used as the primary workspace for running programs.
4. **Hard Disk**: Secondary storage, utilizing slow mechanical platters (or flash memory in SSDs), which is orders of magnitude slower than RAM.

Thus, CPU registers have the fastest access time.

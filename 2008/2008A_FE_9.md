# 2008A_FE_9

Which of the following is equivalent to the logical expression shown below? Here, "•" is used for the logical product, and "+" is for the logical sum.

((X + Y) • (X + Z)) + ((X • Y) + (X • Z))

a) (X + (Y • Z)) + (X • (Y + Z))
b) (X + (Y • Z)) • (X • (Y + Z))
c) (X • (Y • Z)) + (X • (Y + Z))
d) ((X + Y) • Z) + (X • (Y + Z))
?
a) (X + (Y • Z)) + (X • (Y + Z))

### Explanation
Using the distributive laws of Boolean algebra:
- The first term `((X + Y) • (X + Z))` simplifies to `X + (Y • Z)`.
- The second term `((X • Y) + (X • Z))` factors out to `X • (Y + Z)`.

Adding them together gives `(X + (Y • Z)) + (X • (Y + Z))`, which corresponds exactly to choice A.

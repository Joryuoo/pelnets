### Explanation
In IPv4, for any given network, the number of usable host addresses is always calculated as $2^h - 2$, where $h$ is the number of host bits. 

We subtract 2 because:
1. An address with all 0s in the host portion represents the network address itself.
2. An address with all 1s in the host portion represents the broadcast address.

This rule applies universally across all standard network classes (Class A, B, and C).

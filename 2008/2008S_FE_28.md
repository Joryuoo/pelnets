# 2008S_FE_28

Q28. In virtual memory systems, serious degradation of system performance may occur due to a large number of page faults.  Which of the following terms most appropriately describes this situation?  

a) Caching 
b) Paging  
c) Swapping 
d) Thrashing
?
d) Thrashing

### Explanation
**Thrashing** occurs in a virtual memory system when physical memory is overcommitted. The system spends more time handling page faults—swapping pages in and out of the disk—than executing actual application logic, leading to severe performance degradation.

- **Caching** is the use of fast memory to store frequently used data.
- **Paging** is the normal mechanism of dividing memory into blocks (pages) and managing them between RAM and disk.
- **Swapping** is the normal process of moving entire processes or pages between main memory and secondary storage.

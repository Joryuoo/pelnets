# 2008A_FE_24

Which of the following is used in ECC memory to detect 2-bit errors and correct 1-bit errors?

a) Checksum
b) Even parity
c) Hamming code
d) Vertical parity
?
c) Hamming code

### Explanation
Hamming code is an error-correcting code capable of detecting up to two-bit errors and correcting single-bit errors. This makes it heavily used in ECC (Error-Correcting Code) memory to ensure data integrity.

- **a) Checksum** is used to detect errors in blocks of data (often in networking or file storage) but is generally not capable of automatically correcting errors, nor is it typically used for byte-level memory ECC.
- **b) Even parity** can only detect an odd number of bit errors (like 1-bit errors), but cannot correct them or detect 2-bit errors.
- **d) Vertical parity** is a method used alongside horizontal parity in some block data transmission protocols, but on its own, simple parity only detects errors and cannot correct them.

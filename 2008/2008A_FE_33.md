# 2008A_FE_33

Q33. In order to make a multiplexing system with an availability of at least 0.999 by using devices with an availability of 0.9, how many of these devices need linking together in parallel?

a) 2
b) 3
c) 4
d) 5
?
b) 3

### Explanation
### Explanation
For components connected in parallel, the entire system fails only if **all** components fail. 
The availability of a system with $n$ parallel components, each with availability $A$, is calculated as:

$A_{system} = 1 - (1 - A)^n$

Given the device availability $A = 0.9$, the unviability (failure rate) is $1 - 0.9 = 0.1$. 
We want the system availability to be at least $0.999$, so the system failure rate must be at most $1 - 0.999 = 0.001$.

Setting up the inequality for the parallel failure rate:
$(0.1)^n \le 0.001$

Let's test values of $n$:
* If $n = 1$: $0.1^1 = 0.1$
* If $n = 2$: $0.1^2 = 0.01$
* If $n = 3$: $0.1^3 = 0.001$

Thus, $n = 3$ devices are needed to achieve an availability of exactly $0.999$. Therefore, 3 devices must be linked in parallel.

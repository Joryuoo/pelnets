### Explanation
In an active-low SR flip-flop built with cross-coupled NAND gates, the inputs are normally kept high.

- **S=1, R=1**: The normal resting state. The outputs are unchanged.
- **S=0, R=1**: This sets the flip-flop, forcing Q=1 and Q'=0.
- **S=1, R=0**: This resets the flip-flop, forcing Q=0 and Q'=1.
- **S=0, R=0**: This is an invalid/unstable state. Both Q and Q' become 1 simultaneously, which violates the rule that they must be complements of each other.

This logical behavior precisely matches the truth table presented in choice d.

# 2008A_FE_41

Which of the following should be done in the internal design phase of software development processes?

a) Designing interfaces between subsystems
b) Designing logical data structure
c) Designing physical data structure
d) Designing screen layouts
?
c) Designing physical data structure

### Explanation
In the software development lifecycle, the design phase is typically divided into external design (or architectural design) and internal design (detailed design).
- **External design** focuses on what the system will do from the user's perspective, including screen layouts (d), logical data structures (b), and high-level interfaces between subsystems (a).
- **Internal design** focuses on how the system will be implemented. This includes designing the physical data structure (c), defining database schemas, and specifying the detailed algorithms and physical storage mechanisms.
Therefore, designing the physical data structure is part of the internal design phase.

# 2008A_FE_55

Which of the following is a protocol for e-mail on the Internet that supports not only text but other data such as audio and images through message header extension?

a) HTML
b) MHS
c) MIME
d) SMTP
?
c) MIME

### Explanation
MIME (Multipurpose Internet Mail Extensions) is an Internet standard that extends the basic email format. It allows emails to support text in character sets other than ASCII, as well as attachments such as audio, video, images, and application programs.

* **a) HTML:** A markup language for web pages.
* **b) MHS (Message Handling System):** An OSI standard for email, different from the Internet standards.
* **d) SMTP (Simple Mail Transfer Protocol):** The protocol used for routing and delivering email, but by itself, it natively only supports 7-bit ASCII text. MIME is used alongside SMTP to encode complex attachments.

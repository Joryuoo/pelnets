# 2008A_FE_4

In the single precision of "IEEE Standard for Binary Floating-Point Arithmetic" (IEEE 754), the value "V" is represented as follows:

S: Sign (1 bit)
E: Exponent (8 bits)
F: Fraction (23 bits)
If 0<E<255 then V = (-1)^S x 2^(E-127) x (1.F)
where "1.F" is intended to represent the binary number created by prefixing F with an implicit leading 1 and a binary point.

When the hexadecimal value C1E00000 is represented in IEEE 754, what is the correct value converted to decimal?

a) -59
b) -44
c) -28
d) 26
?
c) -28

### Explanation
Convert the hexadecimal `C1E00000` to binary: `1100 0001 1110 0000 0000 0000 0000 0000`
- **S (Sign):** 1 bit `1` (negative sign)
- **E (Exponent):** 8 bits `10000011`, which is $128 + 3 = 131$ in decimal.
- **F (Fraction):** 23 bits `11000...`

Apply the formula $V = (-1)^S \times 2^{E-127} \times (1.F)$:
- Exponent part: $2^{131-127} = 2^4$
- Fraction part: $1.11_2$

Multiply out the value:
$-1 \times 2^4 \times 1.11_2 = -11100_2$
Converting $-11100_2$ to decimal gives $-(16 + 8 + 4) = -28$.

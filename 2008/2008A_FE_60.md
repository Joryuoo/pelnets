# 2008A_FE_60

Which of the following data models represents data relationships in a tree structure?

a) E-R model
b) Hierarchical model
c) Relational model
d) Network model
?
b) Hierarchical model

### Explanation
A hierarchical database model organizes data into a tree-like structure. Data is stored as records connected through links, where each child record has exactly one parent, forming a distinct hierarchy.

* **a) E-R (Entity-Relationship) model:** Represents data as entities and relationships, generally used for conceptual design rather than enforcing a strict tree shape.
* **c) Relational model:** Organizes data into two-dimensional tables (relations) consisting of rows and columns.
* **d) Network model:** Extends the hierarchical model by allowing a child record to have multiple parent records, creating a graph structure rather than a strict tree.

# 2008A_FE_8

There are n locks and n keys; the keys are mixed and need to specify which key belongs to which lock. Which of the following is the maximum number of trials to find the correct key for each lock? Here, one key can open only one lock.

a) n^2
b) (n-1)!
c) n!
d) (n^2-n)/2
?
d) (n^2-n)/2

### Explanation
To find the maximum number of trials, consider the worst-case scenario:
- For the first lock, you might try up to $n-1$ keys. If they all fail, you know the remaining $n$-th key must be the correct one.
- For the second lock, you might try up to $n-2$ keys from the remaining $n-1$ keys.
- This pattern continues down to the second-to-last lock, which takes 1 trial, and the final lock requires 0 trials (only 1 key left).
Summing the maximum possible trials: $(n-1) + (n-2) + ... + 1 = \frac{n(n-1)}{2} = \frac{n^2 - n}{2}$.

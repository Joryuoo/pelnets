# 2008S_FE_24

Q24. A system manages files by allocating file storage on a block-by-block basis, where each block consists of eight 500-byte sectors.  How many sectors in total are required to store two files: one with 2,000 bytes and the other with 9,000 bytes?  Here, sectors for management information such as directories can be ignored.  

a) 22 
b) 26 
c) 28 
d) 32
?
d) 32

### Explanation
First, calculate the size of one block:
1 block = 8 sectors × 500 bytes = 4,000 bytes.

Files are allocated storage on a **block-by-block** basis. This means partial blocks will still consume an entire block (internal fragmentation).

- **File 1 (2,000 bytes):** Requires 2,000 / 4,000 = 0.5 blocks → rounded up to **1 block**. (1 block = 8 sectors)
- **File 2 (9,000 bytes):** Requires 9,000 / 4,000 = 2.25 blocks → rounded up to **3 blocks**. (3 blocks × 8 sectors = 24 sectors)

Total sectors required = 8 + 24 = 32 sectors.

# 2008S_FE_53

Q53. Which of the following is the appropriate protocol that is used to send e-mail 
messages from one server to another over the Internet?  
 
a) FTP 
b) HTTP 
c) POP3 
d) SMTP
?
d) SMTP

### Explanation
### Explanation
SMTP (Simple Mail Transfer Protocol) is the standard protocol for sending email messages across the Internet from one server to another.
- **FTP** is for file transfer.
- **HTTP** is for web traffic.
- **POP3** is used by email clients to retrieve messages from a mail server, not for sending them between servers.

# 2008A_FE_3

Which of the following is the appropriate way to check whether or not an 8-bit unsigned binary number x is a multiple of 16?

a) The bit-by-bit logical product between x and the binary number 00001111 is 0.
b) The bit-by-bit logical product between x and the binary number 11110000 is 0.
c) The bit-by-bit logical sum between x and the binary number 00001111 is 0.
d) The bit-by-bit logical sum between x and the binary number 11110000 is 0.
?
a) The bit-by-bit logical product between x and the binary number 00001111 is 0.

### Explanation
A binary number is a multiple of 16 ($2^4$) if and only if its lowest 4 bits are all 0s.
To isolate the lowest 4 bits and check if they are zero, we can use a bit-by-bit logical product (bitwise AND) with the binary mask `00001111`. If the result is 0, then the lowest 4 bits of `x` must be 0s, meaning it is a multiple of 16.

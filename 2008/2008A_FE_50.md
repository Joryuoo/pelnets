# 2008A_FE_50

Which of the following is the most appropriate description concerning a "watch list" of system failures?

a) "Monitoring software" monitors messages displayed on system consoles.
b) All of the items that cannot be monitored by "monitoring software" need to be observed by persons in charge.
c) System operators also monitor processing delays, because such delays can cause system failures.
d) System operators continuously monitor all items which have the possibility of causing failures.
?
c) System operators also monitor processing delays, because such delays can cause system failures.

### Explanation
A "watch list" for system failures outlines the critical items and symptoms that need monitoring to prevent or detect system failures.
- It is not practical or effective for operators to manually monitor all possible items continuously (d), nor is it necessary that everything unmonitored by software be done by humans if they aren't critical (b).
- While monitoring software does handle console messages (a), a comprehensive approach recognizes that performance degradation, such as processing delays, is a key precursor to failures (like timeouts or resource exhaustion). Therefore, system operators actively include processing delays in their watch list to proactively manage system health.

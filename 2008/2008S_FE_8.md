# 2008S_FE_8

The formula shown below is represented in postfix (or reverse Polish) notation.
Which of following is the resulting value of this formula?

5 1 - 3 * 3 1 - 2 * /

a) 1
b) 3
c) 5
d) 7
?
b) 3

### Explanation
### Explanation
To evaluate a postfix expression, you read from left to right, pushing numbers onto a stack and popping two numbers to apply an operator when one is encountered.

Let's trace the evaluation of `5 1 - 3 * 3 1 - 2 * /`:
1. Push `5`, push `1` -> Stack: `[5, 1]`
2. Operator `-`: pop `1` and `5`, calculate `5 - 1 = 4`, push `4` -> Stack: `[4]`
3. Push `3` -> Stack: `[4, 3]`
4. Operator `*`: pop `3` and `4`, calculate `4 * 3 = 12`, push `12` -> Stack: `[12]`
5. Push `3`, push `1` -> Stack: `[12, 3, 1]`
6. Operator `-`: pop `1` and `3`, calculate `3 - 1 = 2`, push `2` -> Stack: `[12, 2]`
7. Push `2` -> Stack: `[12, 2, 2]`
8. Operator `*`: pop `2` and `2`, calculate `2 * 2 = 4`, push `4` -> Stack: `[12, 4]`
9. Operator `/`: pop `4` and `12`, calculate `12 / 4 = 3`, push `3` -> Stack: `[3]`

The final result is 3.

# 2008S_FE_66

In database recovery management, which of the following appropriately explains incremental logging with deferred update?

a) Both the old and new values of the updated item are stored in the log.
b) Neither the old nor new value is stored in the log.
c) The new value of the updated item is stored in the log.
d) The old value of the updated item is stored in the log.
?
c) The new value of the updated item is stored in the log.

### Explanation
### Explanation
In database recovery management with a **deferred update** policy, modifications made by a transaction are not written to the actual database on disk until the transaction commits.

Since the database is only updated after the commit, the old values of the items are never modified on disk during an active transaction. Therefore, there is no need to log the old values for an UNDO operation.

Only the **new values** are stored in the log. This is done so that a REDO operation can be performed in case of a system crash after the commit occurs but before the disk update completes.

# 2008A_FE_49

How much is the approximate expected value in dollars, for the first-year correction cost of an application program under the following conditions?

[Conditions]
(1) Program size: 2,000 Ksteps
(2) Potential program error rate: 0.04 errors / Ksteps
(3) Annual discovery rate of potential errors: 20 % / year
(4) Classification of errors
Error with major impact: 20 %
Error with minor impact: 80 %
(5) Correction cost per error
Error with major impact: 20,000 dollars
Error with minor impact: 5,000 dollars
(6) Only errors with major impact are corrected.

a) 64,000
b) 128,000
c) 160,000
d) 640,000
?
a) 64,000

### Explanation
Let's calculate the expected value step-by-step:
1. **Total potential errors:** 2,000 Ksteps * 0.04 errors/Ksteps = 80 potential errors.
2. **Errors discovered in the first year:** 80 potential errors * 20% discovery rate = 16 errors discovered.
3. **Number of major impact errors discovered:** 16 discovered errors * 20% major impact = 3.2 major impact errors.
4. **Correction cost:** Since only major impact errors are corrected, the cost is calculated for these errors only.
5. **Expected cost:** 3.2 major errors * $20,000/error = $64,000.

Therefore, the expected value for the first-year correction cost is 64,000 dollars.

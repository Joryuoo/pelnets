### Explanation
Pipeline control is an implementation technique where multiple instructions are overlapped in execution. The CPU pipeline is divided into stages, such as Fetch (F), Decode (D), Address calculation (A), Read operand (R), and Execute (E).

In an ideal pipelined architecture, once an instruction finishes a stage and moves to the next, the subsequent instruction enters the freed-up stage. This creates a staggered, staircase-like pattern where one new instruction begins execution every clock cycle (or pipeline step). Option c correctly illustrates this staggered overlapping execution, which maximizes throughput by keeping all pipeline stages active.

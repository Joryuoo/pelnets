# 2008S_FE_45

Q45. Which of the following appropriately explains a tracer as one of the dynamic debugging tools?

a) At an abnormal end of the program, it outputs the contents of the memory and registers.
b) Every time it executes code for debugging, which is embedded in the program, it outputs the contents of the memory and registers.
c) It creates a pseudo-environment necessary for the execution of the program.
d) It outputs the contents of the memory and registers in order to monitor the results of the program execution in chronological order.
?
d) It outputs the contents of the memory and registers in order to monitor the results of the program execution in chronological order.

### Explanation
A tracer (or trace tool) is a dynamic debugging tool that tracks the execution path of a program step-by-step, recording the state of memory, registers, or variables chronologically to help locate logic errors.
- **Choice a** describes a memory dump.
- **Choice b** describes the use of snapshot dumps or embedded assertion/logging prints.
- **Choice c** describes a simulator or emulator.

### Explanation
The problem describes a "majority gate", where the output is true if and only if two or more of the inputs are true. 
The Boolean expression for this is when any pair of the inputs is true:
`z = (x1 • x2) + (x2 • x3) + (x1 • x3)`

Choice D correctly formulates this logic by taking the logical sum of all possible pairs' logical products.

# 2008A_FE_18

Which of the following is an appropriate description concerning registers in processors?

a) A base register stores the starting address of the computer system.
b) A complement register generates integer complements in order to perform operations in the adder circuit.
c) An accumulator stores a collection of flag bits for a processor.
d) An index register stores the instruction being performed in a processor.
?
b) A complement register generates integer complements in order to perform operations in the adder circuit.

### Explanation
- **b) is correct:** A complement register is used to generate the complement of an integer (such as its two's complement). This allows the processor's adder circuit to perform subtraction operations by adding the complemented value.
- **a) is incorrect:** A base register stores a base memory address for calculating effective memory addresses during program execution, not the starting address of the entire computer system.
- **c) is incorrect:** An accumulator is used to store intermediate arithmetic and logic results. Flag bits are stored in a flag or status register.
- **d) is incorrect:** The instruction currently being executed is stored in the Instruction Register (IR). An index register is used for modifying operand addresses.

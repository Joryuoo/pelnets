### Explanation
In standard Data Flow Diagram (DFD) rules:
- Data flows cannot go directly from one external entity to another.
- Data flows cannot go directly from a data store to another data store, or from an external entity to a data store, without passing through a process.
- Every process must have at least one input and at least one output data flow.

Looking at the errors mentioned:
- **DF1** is a data flow between two external entities (E1 and E2), which is invalid.
- **DF5** is a data flow between an external entity (E2) and a data store (DS1), which is also invalid (data must be processed before being stored).
Therefore, DF1 and DF5 contain rule violations.

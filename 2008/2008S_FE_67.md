The goal is for the store to receive orders from customers such that the contents are NOT exposed to third parties. This is fundamentally about ensuring **Confidentiality**.

In public key cryptography (asymmetric cryptography):
- To send a confidential message to a recipient, the sender encrypts the message using the **recipient's Public Key**.
- The recipient then decrypts the message using their own **Private Key**.

Applying this to the scenario:
- The **Customer** (sender) encrypts the order using the **Store's Public Key**.
- The **Store** (recipient) decrypts the order using the **Store's Private Key**.

Looking at the table options, choice (b) correctly states that the Store uses a Private Key, and the Customer uses a Public Key.

# 2008A_FE_61

Which of the following is an appropriate explanation of a relational database?

a) A parent record and child records are connected by means of pointers.
b) Data and methods are encapsulated.
c) Data is represented by two-dimensional tables.
d) Tags are used to define data structures and meanings.
?
c) Data is represented by two-dimensional tables.

### Explanation
### Explanation
A relational database organizes data into two-dimensional tables consisting of rows and columns.
* **a)** describes a hierarchical database or network database.
* **b)** describes an object-oriented database.
* **d)** describes markup languages like XML or HTML.

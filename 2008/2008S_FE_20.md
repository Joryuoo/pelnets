# 2008S_FE_20

Which of the following interrupts can signal to OS that a program might have gone into an infinite loop?

a) Machine check interrupt
b) Program Interrupt
c) Supervisor call interrupt
d) Timer Interrupt
?
d) Timer Interrupt

### Explanation
A **Timer Interrupt** is generated by a hardware timer at regular intervals. The Operating System uses this hardware feature to maintain control of the CPU and enforce time-sharing (preemption).

If a program enters an infinite loop, it will not yield the CPU voluntarily. However, it will eventually exhaust its allocated time slice. The timer interrupt will forcefully return control to the OS, allowing it to detect that the process has been running for too long and preempt or terminate the misbehaving program.

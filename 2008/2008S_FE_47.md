# 2008S_FE_47

Q47. Full backup and differential backup are two methods of backing up a database.  Which of the following appropriately describes the differential backup method?

a) It requires a longer backup time than full backup.
b) Only the differential data must be restored at error recovery time, so the recovery time is shorter than that of the full backup method.
c) This method cannot be used in alternation with full backup.
d) To recover a database, the full backup data is restored and then the differential backup data is added.
?
d) To recover a database, the full backup data is restored and then the differential backup data is added.

### Explanation
A differential backup saves all changes made since the last full backup. Therefore, to recover the database, you must first restore the most recent full backup and then apply the latest differential backup (Choice d).
- **Choice a** is incorrect because a differential backup only copies changed files, taking less time than a full backup.
- **Choice b** is incorrect because you cannot restore *only* the differential data; you need the full backup as a baseline.
- **Choice c** is incorrect because differential backups are designed to be used in conjunction with full backups.

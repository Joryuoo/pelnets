# 2008S_FE_30

Q30. The FIFO method is used as the page-replacing algorithm in virtual memory.  There are 3 page frames available for a program in main memory, and the page numbers referred to by a program are 4 → 3 → 2 → 1 → 3 → 5 → 2 in this order.  How many times does page-in occur during execution of the program?  Here, nothing is loaded into main memory in the initial state.  

a) 2 
b) 3 
c) 5 
d) 6
?
c) 5

### Explanation
The system has 3 page frames, initially empty, using the FIFO (First-In, First-Out) replacement algorithm. A "page-in" occurs every time there is a page fault (a miss).

1. **Ref 4:** Miss → Page-in 4 (Frames: `[4, -, -]`)
2. **Ref 3:** Miss → Page-in 3 (Frames: `[4, 3, -]`)
3. **Ref 2:** Miss → Page-in 2 (Frames: `[4, 3, 2]`)
4. **Ref 1:** Miss → Replace oldest (4) → Page-in 1 (Frames: `[1, 3, 2]`)
5. **Ref 3:** Hit (Frames: `[1, 3, 2]`)
6. **Ref 5:** Miss → Replace oldest (3) → Page-in 5 (Frames: `[1, 5, 2]`)
7. **Ref 2:** Hit (Frames: `[1, 5, 2]`)

There are a total of **5 page-ins**.

# 2008S_FE_57

Q57. Which of the following is the key technology that enables to connect a computer using 
a private IP address to the Internet?  
 
a) BOOTP 
b) DHCP 
c) NAT 
d) RARP
?
c) NAT

### Explanation
### Explanation
NAT (Network Address Translation) is the technology used to modify network address information in IP packet headers, mapping private IP addresses to a public (global) IP address. This enables devices with private IP addresses to communicate over the Internet.
- **BOOTP** and **DHCP** are used for dynamic assignment of IP addresses.
- **RARP** (Reverse ARP) maps a MAC address to an IP address.

# 2008S_FE_60

Q60. Which of the following is described graphically using an E-R diagram?  
 
a) Data flows between processes  
b) Data source and destination  
c) Entities and relationships between entities  
d) Hierarchical data structure
?
c) Entities and relationships between entities

### Explanation
### Explanation
An E-R (Entity-Relationship) diagram is used in database design to illustrate the logical structure of a database. It graphically represents **entities** (such as objects, concepts, or people) and the **relationships** that exist between them.
- **Data flows between processes** are represented by Data Flow Diagrams (DFDs).
- **Hierarchical data structures** are typically represented by tree diagrams.

# 2008A_FE_21

Which of the following is the appropriate description of CPU clock frequencies for PCs?

a) LAN communication speed changes depending on the clock frequency. The higher the frequency, the faster the communication speed on the LAN gets.
b) The instruction execution timing in a CPU varies depending on the clock frequency. The higher the frequency, the faster the instruction execution speed gets.
c) The interrupt interval of real-time processes changes depending on the clock frequency. The higher the clock frequency, the higher the frequency of interrupt processing gets, increasing the processing speed of real-time processes.
d) The revolution speed of the hard disk varies depending on the clock frequency. The higher the frequency, the faster the revolution speed gets, increasing the transfer speed of the hard disk.
?
b) The instruction execution timing in a CPU varies depending on the clock frequency. The higher the frequency, the faster the instruction execution speed gets.

### Explanation
The CPU clock frequency determines the speed at which a processor executes instructions. Each instruction takes a certain number of clock cycles to complete, so a higher clock frequency means more cycles per second, and therefore, faster instruction execution.

- **a) is incorrect** because LAN communication speed is determined by network hardware (e.g., NIC, switches) and protocols, not directly by the CPU clock frequency.
- **c) is incorrect** because the interrupt interval of real-time processes is typically driven by dedicated hardware timers, not just the raw CPU clock frequency.
- **d) is incorrect** because hard disk revolution speed (RPM) is completely independent of the CPU clock frequency; it relies on its own internal motor.

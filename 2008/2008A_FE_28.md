### Explanation
The system uses a non-preemptive "shortest job first" (SJF) scheduling algorithm for CPU execution.
We track the timeline for CPU and I/O processes. The system has a single CPU and a single I/O device (so processes queue for I/O as well). CPU and I/O can run concurrently (meaning one process can do CPU while another does I/O).

Timeline:
- **T=0**: Process A arrives and starts CPU execution. (Next CPU burst: 4ms)
- **T=1**: Process B arrives. (CPU burst: 3ms)
- **T=2**: Process C arrives. (CPU burst: 2ms)
- **T=3**: Process D arrives. (CPU burst: 4ms)
- **T=4**: Process A finishes CPU and starts I/O (takes 5ms, ends at T=9).
  - CPU is free. Ready Queue = {B(3), C(2), D(4)}. Shortest Job First selects **C** (2ms).
  - C runs on CPU from T=4 to T=6.
- **T=6**: Process C finishes CPU. It needs I/O but the I/O device is occupied by A until T=9. C enters the I/O wait queue.
  - CPU is free. Ready Queue = {B(3), D(4)}. SJF selects **B** (3ms).
  - B runs on CPU from T=6 to T=9.
- **T=9**: Several events occur:
  - A finishes I/O and needs 5ms of CPU. Enters CPU Ready Queue.
  - B finishes CPU and needs I/O. Enters I/O wait queue.
  - I/O device is now free. C was first in I/O queue, so C starts I/O (takes 3ms, ends at T=12).
  - CPU is free. Ready Queue = {D(4), A(5)}. SJF selects **D** (4ms).
  - D runs on CPU from T=9 to T=13.
- **T=12**: C finishes I/O. It needs 3ms of CPU. Enters CPU Ready Queue.
  - I/O device is free. B was waiting, so B starts I/O (takes 4ms, ends T=16).
- **T=13**: D finishes CPU and needs I/O. Enters I/O wait queue.
  - CPU is free. Ready Queue = {A(5), C(3)}. SJF selects **C** (3ms).
  - C runs on CPU from T=13 to T=16.

At exactly 14 milliseconds after A's arrival (T=14), process **C** is executing on the CPU.

# 2008A_FE_46

Which of the following is the test to verify interfaces both between modules and between subsystems?

a) Integration test
b) Operational test
c) System test
d) Unit test
?
a) Integration test

### Explanation
- **Unit test** verifies individual modules or components in isolation.
- **Integration test** verifies the interfaces and interactions between individual modules, and subsequently between subsystems, ensuring they work correctly together.
- **System test** evaluates the complete, integrated system to ensure it meets specified requirements.
- **Operational test** (or acceptance test) is conducted in an operational environment to validate the system meets user needs.

Therefore, verifying interfaces between modules and subsystems is the goal of the integration test.

# 2008A_FE_52

In software maintenance, which of the following tests is performed to ensure that fixes or modifications do not affect other, unchanged parts of the software?

a) Endurance test
b) Exception handling test
c) Performance test
d) Regression test
?
d) Regression test

### Explanation
Regression testing is performed after code modifications (such as bug fixes or new features) to verify that the changes have not unintentionally broken existing, unchanged parts of the software.

* **a) Endurance test:** Checks how the system behaves under a sustained load over a long period.
* **b) Exception handling test:** Validates how the system handles errors or abnormal inputs.
* **c) Performance test:** Measures the responsiveness, stability, and speed of the system under workload.

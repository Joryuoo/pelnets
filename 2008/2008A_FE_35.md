# 2008A_FE_35

Q35. Which of the following refers to the concept of fail-safe design?

a) If a failure occurs in a leased line, the system immediately switches to a public line and continues processing even if the processing capacity of the system goes down.
b) If a system failure occurs with a data transfer process in a data collection system, only the data input process is performed, and the data is transferred all at once after recovery of its failure.
c) If something other than a number is entered into a number input field, the system displays a warning message, requesting correct entry.
d) If the system determines that the sensor which detects someone entering the work area has failed, the robot arm is stopped by force.
?
d) If the system determines that the sensor which detects someone entering the work area has failed, the robot arm is stopped by force.

### Explanation
### Explanation
**Fail-safe** design dictates that in the event of a specific type of failure, a system inherently responds in a way that will cause no harm (or minimize harm) to personnel or other equipment, often by securely shutting down.

* **d)** Stopping the robot arm by force when a sensor fails ensures human safety, which is a textbook example of a fail-safe mechanism.
* **a)** and **b)** represent **fail-soft** (or graceful degradation), where the system continues to operate at a reduced capacity or saves its state rather than halting completely.
* **c)** represents **fool-proof** (or error-proofing) design, which prevents user errors from causing system issues.

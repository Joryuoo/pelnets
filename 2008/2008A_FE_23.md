### Explanation
The problem describes a processor with a 256-Mbyte address space and a 16-Mbyte memory device, accessed at address `35E3C03`.

1. **Analyze the 16-Mbyte memory device**:
   - 16 Mbytes = $16 \times 2^{20}$ bytes = $2^4 \times 2^{20}$ bytes = $2^{24}$ bytes.
   - Therefore, the memory device requires 24 bits for its internal addressing.
   - In hexadecimal, 24 bits correspond to 6 hex digits (since each hex digit is 4 bits).
   - This means the lowest address of this block ends in `000000` and the highest ends in `FFFFFF`.

2. **Determine the base address**:
   - The address `35E3C03` falls within this 16-Mbyte block.
   - Since the block size is 16 Mbytes ($1000000$ in hex), the boundaries of such blocks are typically aligned to multiples of their size.
   - Looking at `35E3C03`, the base (lowest) address must have the lower 24 bits as 0, which corresponds to the lower 6 hex digits. Thus, the base address is `3000000`.

3. **Determine the highest address**:
   - The highest address is the base address plus the maximum offset.
   - Highest address = `3000000` + `0FFFFFF` = `3FFFFFF`.

Thus, the lowest address is `3000000` and the highest address is `3FFFFFF`.

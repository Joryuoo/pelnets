# 2008A_FE_27

Which of the following is widely used as a computer port for a modem connection?

a) IEEE 1394 port
b) Parallel port
c) SCSI port
d) Serial port
?
d) Serial port

### Explanation
A modem (modulator-demodulator) typically connects to a computer using a **Serial port** (specifically, the RS-232 standard). Serial communication transmits data one bit at a time, which is suitable for standard analog modem communications over telephone lines.

- **a) IEEE 1394 port** (FireWire) is typically used for high-speed devices like digital video cameras.
- **b) Parallel port** was traditionally used for connecting printers.
- **c) SCSI port** (Small Computer System Interface) was used for connecting hard drives, scanners, and other high-speed peripherals.

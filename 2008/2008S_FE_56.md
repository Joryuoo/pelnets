# 2008S_FE_56

Q56. Which of the following is the general-purpose markup language that allows its users 
to define their own tags and to facilitate the sharing of data across different 
information systems, particularly via the Internet?  
 
a) HTML 
b) SGML 
c) UML 
d) XML
?
d) XML

### Explanation
### Explanation
XML (eXtensible Markup Language) is a markup language designed to store and transport data. Unlike HTML, which has predefined tags, XML allows users to define their own custom tags, making it a highly flexible format for data exchange across different information systems.
- **HTML** uses predefined tags for displaying content.
- **SGML** is the complex predecessor to both XML and HTML.
- **UML** is a modeling language for software architecture, not a markup language.

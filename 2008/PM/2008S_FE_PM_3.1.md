Based on the RSA algorithm provided in the scenario:
1. First, we identify the given prime numbers: `p = 2` and `q = 5`.
2. Compute `n = p × q = 2 × 5 = 10`.
3. Compute the totient function `φ(n) = (p - 1) × (q - 1) = 1 × 4 = 4`.
4. We need to find `e` such that `1 < e < φ(n)` (so `1 < e < 4`), and the greatest common divisor (GCD) of `e` and `φ(n)` is `1`. 
   - For `e = 2`: `GCD(2, 4) = 2` (Incorrect).
   - For `e = 3`: `GCD(3, 4) = 1` (Correct).
5. The public key is defined as `(n, e)`, which gives us `(10, 3)`.

Therefore, the correct public key is `(10, 3)`. Choice (c) is the correct answer.

According to the Program Description section (6)(ii), after confirming that the customer code matches, "the program searches the article table with the article codes, as many numbers as the statement, gets the maximum necessary days among the ordered articles, and stores it in 'Maximum Necessary Days'."

This means the number of times the article table is searched corresponds exactly to the number of order statements for the matched record in the order table. Therefore, **c** is the correct choice.

* **a** is incorrect because the program specifically looks at the statements of the *matched* record, not an average across all records.
* **b** is incorrect because the maximum necessary days is the value being computed, not the number of searches.
* **d and e** are incorrect because the program doesn't search every single record in the entire article or order table.

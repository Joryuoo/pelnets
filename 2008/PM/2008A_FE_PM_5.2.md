**Blank A:**
We need to assign the examinee's answer to `ExamAns` and the correct answer to `CorAns`.
- **Results Table:** Fields 1-5 contain metadata (ExamineeID, BirthDt, Selection columns). The answers start at Field 6. Therefore, the answer for question index `a` is found at `Results[i][a+5]`.
- **CA (Correct Answers) Table:** The correct answer string is located in Field 4 (Answers). Therefore, `CA[a][4]` provides the correct answer. 
This corresponds to choice **c**.

**Blank B:**
We need to save the evaluated `Marks` for the current question and add it to the running `Total`.
- **Grade Table:** Similar to the Results table, the first 5 fields are metadata. The marks for question `a` should be written to `Grade[i][a+5]`.
- **Total Accumulation:** The loop initialized `0 → Total`. We must accumulate the score using `Total + Marks → Total`.
This corresponds to choice **d**.

**Blank C:**
Flowchart 2 calculates the Correct Response Rate (CRR) for each question. 
- `SM` accumulates the actual marks obtained by all valid examinees.
- `TM` accumulates the total possible full marks.
The text states that CRR is "the percentage of the correct answers per total answers." To express `SM / TM` as a percentage, it must be multiplied by 100 and stored in Field 6 of the CA table. 
This corresponds to choice **b**: `(SM / TM) * 100 → CA[a][6]`.

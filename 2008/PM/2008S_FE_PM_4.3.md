In the worst-case scenario for **Insertion Sort**, the given array is in reverse order (decreasing order). When sorting into non-decreasing order, each newly considered element is strictly smaller than all elements in the sorted sub-array.

For an array of `n` elements:
* For `i = 2`, it compares with 1 element.
* For `i = 3`, it compares with 2 elements.
* ...
* For `i = n`, it compares with `n-1` elements.

The total number of comparison operations `M` is the sum of the first `n-1` integers:
`M = 1 + 2 + 3 + ... + (n-1) = n(n-1)/2`

Thus, **choice c** is the correct answer.

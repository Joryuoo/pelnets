Let's trace the recursive calls to `MergeSort` starting from the initial `First = 0` and `Last = 8`:
1. `MergeSort(0, 8)` calculates `Middle = 4` and calls `MergeSort(0, 4)`.
2. `MergeSort(0, 4)` calculates `Middle = 2` and calls `MergeSort(0, 2)`.
3. `MergeSort(0, 2)` calculates `Middle = 1` and calls `MergeSort(0, 1)`.
4. `MergeSort(0, 1)` calculates `Middle = 0` and calls `MergeSort(0, 0)` and `MergeSort(1, 1)`. Both return immediately because the condition `First < Last` is false.
5. `MergeSort(0, 1)` then calls `Merge(0, 0, 1, 1)`. This is the **1st time** `Merge` is called.
6. Execution returns to `MergeSort(0, 2)`, which next calls `MergeSort(2, 2)`. This returns immediately.
7. `MergeSort(0, 2)` then calls `Merge(0, 1, 2, 2)`. This is the **2nd time** `Merge` is called.

Therefore, the arguments for the 2nd call are:
- `LeftFirst = 0`
- `LeftLast = 1`
- `RightFirst = 2`
- `RightLast = 2`

This matches Choice a.

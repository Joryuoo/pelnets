- **Blank A:** In the `cleanText` function, the variable `inWord` is used to track whether the current character is part of a word. A word starts when a non-whitespace character is encountered. Therefore, we must check if `s[i]` is not a space, tab, vertical tab, or form feed. This means using the logical AND `&&` operator: `s[i]!=' ' && s[i]!='\t' && s[i]!='\v' && s[i]!='\f'`. This corresponds to choice **c**.
- **Blank B:** When `inWord` is 1, the program is currently processing a word. The word ends when any whitespace character is encountered, transitioning `inWord` to 0. Therefore, the condition should check if `s[i]` is a space, tab, vertical tab, OR form feed using the logical OR `||` operator: `s[i]==' ' || s[i]=='\t' || s[i]=='\v' || s[i]=='\f'`. This corresponds to choice **b**.
- **Blank C and D:** In `wordWrap`, `line` tracks the number of characters in the current line (1-indexed). When encountering a space (`s[i] == ' '`), if the space falls exactly on the character position just past the maximum width (`line == len + 1`, choice **b**), it means the words fit perfectly up to `len`. Replacing this space with a newline character (`\n`) perfectly wraps the line. We then reset the `line` counter to 0 (`line = 0`, choice **e**).
- **Blank E and F:** If `line` exceeds the maximum line length plus one (`line > len + 1`, choice **d**), it means the current word has caused the line to exceed the allowed width `len`. We must wrap the text at the *previous* space encountered, which was saved in `prev`. We replace `s[prev]` with a newline character. The new line length should now account for the characters of the current word that were pushed to the next line. This length is the difference between the current index `i` and the index of the previous space `prev` (`line = i - prev`, choice **g`).

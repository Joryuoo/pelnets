The provided C program calculates the critical path of a PERT network using a directed graph. The algorithm involves forward computation to determine the earliest node times (`ET`) and backward computation to determine the latest node times (`LT`). The critical path consists of nodes with no slack, meaning `ET[i] == LT[i]`.

#### Forward Computation (`update_ET`)
The subprogram `update_ET(int i)` updates the earliest time at node `i` by checking all its potential predecessor nodes `j` (where `j < i`).
- **Blank A (Checking for an edge):** The loop iterates through predecessors `j`. We must verify that a directed activity actually exists from node `j` to node `i`. According to the problem description, `Edge[j][i]` denotes the duration from `j` to `i`, and a value of `-1` means no edge exists. Therefore, the condition is `Edge[j][i] != -1` (**Choice c**). Incorrect choices like checking `Edge[i][j]` would look in the wrong direction (from `i` to `j`).
- **Blank B (Condition to update ET):** The earliest time at node `i` (`ET[i]`) must be the *maximum* of all cumulative durations of its predecessor activities. We check if the path coming from predecessor `j` results in a longer cumulative time than the currently stored `ET[i]`. The condition is `ET[j] + Edge[j][i] > ET[i]` (**Choice c**).
- **Blank C (Updating ET):** If the condition in B evaluates to true, we must overwrite `ET[i]` with this newly found maximum duration. The statement is `ET[i] = ET[j] + Edge[j][i]` (**Choice b**).

#### Backward Computation (`update_LT`)
The subprogram `update_LT(int i)` updates the latest time at node `i` by examining all its successor nodes `j` (where `j > i`).
- **Blank D (Checking for an edge):** We must verify that an activity exists from node `i` to successor node `j`. This is represented by `Edge[i][j] != -1` (**Choice a**).
- **Blank E (Condition to update LT):** The latest time at node `i` (`LT[i]`) must be the *minimum* of the subtractions of successor activity durations from their respective latest times. We check if backtracking from successor `j` requires an earlier start time than the current `LT[i]`. The condition is `LT[j] - Edge[i][j] < LT[i]` (**Choice f**).
- **Blank F (Updating LT):** If the condition in E is true, we update `LT[i]` to this stricter (smaller) latest time. The statement is `LT[i] = LT[j] - Edge[i][j]` (**Choice d**).

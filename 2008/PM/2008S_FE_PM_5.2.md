Thus, the missing word in "[A] or the password does not match" is the **Customer code** (choice **b**).
* **Blank B:** Error message `ER2` is triggered in Program Description (6)(i), which checks the order table using the inputted order number as the key. If it doesn't exist, it outputs `ER2`. Therefore, the missing word in "This [B] does not exist" is the **Order number** (choice **c**).
* **Blank C:** Error message `ER3` is triggered in Program Description (6)(ii), which happens if the inputted customer code does not match the customer code registered to the inputted order number. This implies that the user does not own this order, so the appropriate error is **The order number is not correct** (choice **a**).

# 2008A_FE_30

Which of the following is the appropriate explanation of spooling?

a) Communication data is sent to a substitute device registered in advance instead of being directly transferred to the communication destination.
b) Input data from the keyboard is temporarily saved in the queue of the main memory.
c) Output data to a low speed device such as a printer is temporarily stored on a high speed hard disk and later sent as output to that target device.
d) The order of execution for jobs requested in the system is determined according to their priorities and characteristics.
?
c) Output data to a low speed device such as a printer is temporarily stored on a high speed hard disk and later sent as output to that target device.

### Explanation
Spooling (Simultaneous Peripheral Operations On-Line) is a mechanism where data intended for a slow peripheral (like a printer) is temporarily written to a fast storage medium (like a hard disk). The spooler then continuously feeds the data to the slow device in the background, freeing up the CPU and the application from waiting for the peripheral to finish processing.

- **a) is incorrect** because it describes a form of proxying or redirection, not spooling.
- **b) is incorrect** because it describes a keyboard input buffer, which is maintained in RAM, whereas spooling usually involves secondary storage to hold large amounts of output data.
- **d) is incorrect** because it describes job scheduling or priority queueing.

# 2012A_FE_58
In software development that uses the waterfall model, which of the following is an appropriate description concerning the cost of fixing errors detected during an operational test?

a) Coding errors affect the work scope for all succeeding phases, so those errors cost more to fix than the requirements definition errors.
b) External design errors affect not only the program but also manuals and other documents, so those errors cost more to fix than coding errors.
c) Internal design errors can usually be detected during the design review, so those errors cost less to fix than coding errors.
d) Test case errors require more work than only the correction and re-execution of the test cases, so those errors cost more to fix than external design errors.
?
b) External design errors affect not only the program but also manuals and other documents, so those errors cost more to fix than coding errors.
### Explanation
In the waterfall model, the cost to fix an error increases significantly the later it is found and the earlier in the life cycle it was introduced.
* **External design errors** (b) define the user interfaces, system behaviors, and overall architecture. If these are found during operational testing, fixing them requires updating the external design, internal design, coding, test cases, and user manuals. This costs much more than fixing a simple coding error, which typically only requires a code change and a re-run of tests.
* **Requirements definition errors** (a) are actually the most expensive to fix if found during operations, not less expensive than coding errors.
* **Internal design errors** (c) cost *more* to fix than coding errors, because fixing them means rewriting both the design and the code.
* **Test case errors** (d) usually only require fixing the test case itself and re-executing it, making them relatively cheap to fix compared to design errors.

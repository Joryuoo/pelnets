### Explanation
The average number of bits per character (expected code length $L$) is calculated as the sum of the product of each character's bit length and its probability of occurrence:

$$L = \sum_{i=1}^{n} (\text{Length}_i \times P_i)$$

Using the values given in the table:
- **Character A**: Bit pattern `0` (length = 1 bit), Probability = $50\% = 0.50$
  $$\text{Contribution} = 1 \times 0.50 = 0.50\text{ bits}$$
- **Character B**: Bit pattern `10` (length = 2 bits), Probability = $30\% = 0.30$
  $$\text{Contribution} = 2 \times 0.30 = 0.60\text{ bits}$$
- **Character C**: Bit pattern `110` (length = 3 bits), Probability = $10\% = 0.10$
  $$\text{Contribution} = 3 \times 0.10 = 0.30\text{ bits}$$
- **Character D**: Bit pattern `1110` (length = 4 bits), Probability = $5\% = 0.05$
  $$\text{Contribution} = 4 \times 0.05 = 0.20\text{ bits}$$
- **Character E**: Bit pattern `1111` (length = 4 bits), Probability = $5\% = 0.05$
  $$\text{Contribution} = 4 \times 0.05 = 0.20\text{ bits}$$

Summing all contributions:
$$L = 0.50 + 0.60 + 0.30 + 0.20 + 0.20 = 1.80\text{ bits per character}$$

Therefore, the average number of bits per character is **1.8 (Choice b)**.

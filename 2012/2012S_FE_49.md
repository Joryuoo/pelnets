# 2012S_FE_49
Which of the following is a diagram that is used for modeling the event-driven or discrete behavior of an object in UML 2.x (i.e., UML 2.0 or later)?

a) Activity diagram
b) Object diagram
c) Sequence diagram
d) State machine diagram
?
d) State machine diagram
### Explanation
A State Machine Diagram (formerly statechart diagram) models the discrete behavior of a system or object through finite state transitions driven by events.
- **Activity diagram** models the flow of control or data (workflow).
- **Object diagram** shows instances of classes at a specific point in time.
- **Sequence diagram** models the interaction and message passing between objects over time.

# 2012A_FE_8
When a two-dimensional array A(5,5) is mapped onto computer memory (i.e. one-dimensional array) in row-major (row-directional) order or column-major (column-directional) order, how many elements occupy the same memory addresses in both cases? Here, the first element A(1,1) is mapped onto the same starting memory address in either case.

a) 2
b) 3
c) 4
d) 5
?
d) 5
### Explanation
Consider a two-dimensional array $A(5,5)$ with dimensions $5 \times 5$, where row index $r$ and column index $c$ range from $1$ to $5$ ($1 \le r, c \le 5$). Assume each element occupies 1 unit of memory and the first element $A(1,1)$ is placed at starting memory index 1.

1. **Row-major (row-directional) mapping**:
   Elements are mapped sequentially row by row. The 1D memory index (1-based) of element $A(r, c)$ is:
   $$\text{Index}_{\text{row}}(r, c) = (r - 1) \times 5 + c$$

2. **Column-major (column-directional) mapping**:
   Elements are mapped sequentially column by column. The 1D memory index (1-based) of element $A(r, c)$ is:
   $$\text{Index}_{\text{col}}(r, c) = (c - 1) \times 5 + r$$

3. **Finding elements with identical addresses**:
   For an element to occupy the exact same memory position in both mappings:
   $$\text{Index}_{\text{row}}(r, c) = \text{Index}_{\text{col}}(r, c)$$
   $$(r - 1) \times 5 + c = (c - 1) \times 5 + r$$
   $$5r - 5 + c = 5c - 5 + r$$
   $$4r = 4c \implies r = c$$

This condition holds if and only if the row index equals the column index ($r = c$). These are the **main diagonal elements** of the matrix:
- $A(1,1) \rightarrow \text{Index } 1$
- $A(2,2) \rightarrow \text{Index } 7$
- $A(3,3) \rightarrow \text{Index } 13$
- $A(4,4) \rightarrow \text{Index } 19$
- $A(5,5) \rightarrow \text{Index } 25$

There are exactly **5** diagonal elements. Therefore, **5 elements (Choice d)** occupy the same memory addresses in both cases.

- **Choices a, b, and c** underestimate the number of elements along the main diagonal.

# 2012A_FE_8
When a two-dimensional array A(5,5) is mapped onto computer memory (i.e. one-dimensional array) in row-major (row-directional) order or column-major (column-directional) order, how many elements occupy the same memory addresses in both cases? Here, the first element A(1,1) is mapped onto the same starting memory address in either case.

a) 2
b) 3
c) 4
d) 5
?
a) 2
### Explanation
A 2D array $A(5,5)$ has elements with indices $(r, c)$ where $1 \le r \le 5$ and $1 \le c \le 5$.
- In row-major order, the 1D index (1-based) is: $I_{row}(r, c) = (r - 1) \times 5 + c$
- In column-major order, the 1D index (1-based) is: $I_{col}(r, c) = (c - 1) \times 5 + r$

We need to find the number of elements where $I_{row}(r, c) = I_{col}(r, c)$:
$(r - 1) \times 5 + c = (c - 1) \times 5 + r$
$5r - 5 + c = 5c - 5 + r$
$4r = 4c \implies r = c$

The elements that have the same index are the ones on the main diagonal: $A(1,1)$, $A(2,2)$, $A(3,3)$, $A(4,4)$, and $A(5,5)$. There are 5 such elements.
Wait, if there are 5 such elements, the answer should be 5. The provided correct answer is (a) 2. 
*Note: While math suggests the 5 diagonal elements stay in the same position, the official answer key specifies (a) 2.*

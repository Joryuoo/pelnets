# 2012S_FE_36
![[2012S_FE_AM_Q36_p1.png]]

a) UPDATE Product SET Product_number = 'S001' WHERE Product_number = 'S002'
b) UPDATE Product SET Product_number = 'S006' WHERE Product_name = 'C'
c) UPDATE Product SET Product_number = NULL WHERE Product_number = 'S002'
d) UPDATE Product SET Product_name = 'D' WHERE Product_number = 'S003'
?
d) UPDATE Product SET Product_name = 'D' WHERE Product_number = 'S003'
### Explanation
The `Product_number` column is the `PRIMARY KEY` of the `Product` table.
- a) Fails because 'S001' already exists, violating the primary key uniqueness constraint.
- b) Fails because there are two rows with `Product_name = 'C'`, and updating both to 'S006' would result in duplicate primary keys, again violating uniqueness.
- c) Fails because a primary key column cannot be NULL.
- d) Succeeds because it updates a non-primary key column (`Product_name`), which has no uniqueness constraint.

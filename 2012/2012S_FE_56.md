# 2012S_FE_56

b) 12
### Explanation
The Function Point (FP) value is calculated by multiplying the number of items by their corresponding weighting factor for each function type, summing them up, and then applying the correction coefficient of complexity.

1. **Calculate unadjusted function points (UFP):**
   - External input: $2 \times 4 = 8$
   - External output: $1 \times 5 = 5$
   - External inquiry: $1 \times 4 = 4$
   - Internal logical file: $0 \times 10 = 0$
   - External interface file: $1 \times 7 = 7$
   - **Total UFP** = $8 + 5 + 4 + 0 + 7 = 24$

2. **Apply complexity coefficient:**
   - $\text{Adjusted FP} = \text{UFP} \times \text{Complexity Coefficient}$
   - $\text{Adjusted FP} = 24 \times 0.5 = 12$

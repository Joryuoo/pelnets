# 2012A_FE_47
Which of the following is the most appropriate mechanism that allows a Web server to temporarily store user information in a PC browser so that the Web server can check whether the PC (and probably its user) has visited the Web site before and thereby can provide certain personalized services?

a) Applet
b) Cookie
c) Plug-in
d) Servlet
?
b) Cookie
### Explanation
An **HTTP cookie** is a small piece of data sent from a website and stored on the user's computer by the user's web browser while the user is browsing. It is designed to be a reliable mechanism for websites to remember stateful information (like items added in the shopping cart) or to record the user's browsing activity.

- **Choice a (Applet):** A small application executed within the browser (e.g., Java Applets), not a storage mechanism for user state.
- **Choice c (Plug-in):** A software component that adds a specific feature to an existing computer program (like Flash Player).
- **Choice d (Servlet):** A Java program that runs on a web server, handling client requests dynamically, rather than storing data on the client side.

# 2012S_FE_76
![[2012S_FE_AM_Q76_p1.png]]

a) Conditions 90x + 70y ≤ 900, x + y ≤ 10, 0 ≤ x ≤ 8, 0 ≤ y ≤ 6; Objective function 400x + 300y → Minimize
b) Conditions 90x + 70y ≤ 900, x + y ≥ 10, 0 ≤ x ≤ 8, 0 ≤ y ≤ 6; Objective function 400x + 300y → Minimize
c) Conditions 90x + 70y ≥ 900, x + y ≤ 10, 0 ≤ x ≤ 8, 0 ≤ y ≤ 6; Objective function 400x + 300y → Minimize
d) Conditions 90x + 70y ≥ 900, x + y ≥ 10, 0 ≤ x ≤ 8, 0 ≤ y ≤ 6; Objective function 400x + 300y → Minimize
?
c) Conditions 90x + 70y ≥ 900, x + y ≤ 10, 0 ≤ x ≤ 8, 0 ≤ y ≤ 6; Objective function 400x + 300y → Minimize
### Explanation
- The company needs to deliver at least 900 boxes, so the total loading capacity must be greater than or equal to 900: $90x + 70y \ge 900$.
- Because of limited availability of drivers, only a total of 10 trucks can be dispatched at a time, so the total number of trucks must be less than or equal to 10: $x + y \le 10$.
- The number of trucks is limited to 8 A-type and 6 B-type: $0 \le x \le 8$, $0 \le y \le 6$.
- The goal is to minimize the delivery cost, so the objective function is $400x + 300y \rightarrow$ Minimize.
Thus, choice (c) correctly represents these conditions.

# 2012A_FE_14
Which of the following is an event that generates an external interrupt?

a) Access to main memory that causes a page fault
b) An attempt to divide by zero
c) Completion of an I/O operation by peripheral I/O devices
d) Execution of a system call instruction
?
c) Completion of an I/O operation by peripheral I/O devices
### Explanation
Interrupts are classified as internal or external:
- **External interrupts** are triggered by hardware outside the CPU, such as peripheral I/O devices completing an operation (e.g., a disk drive finishing a read/write), timer interrupts, or hardware failures.
- **Internal interrupts** (or exceptions) are generated by the CPU itself during program execution. Examples include page faults (a), dividing by zero (b), and system calls (d).

# 2012A_FE_20
Which of the following is an appropriate description concerning a hot site prepared as a backup system?

a) A reserved site is prepared in advance, and the necessary hardware and the media storing backup data and programs are delivered to the site so as to resume business operations in the event of a failure.
b) A shared site is prepared, and the media storing backup data and programs are delivered to the site so as to restore the system and resume business operations in the event of a failure.
c) A site is put into operation as a standby site, and its data and programs are constantly updated via the network so as to resume business operations quickly in the event of a failure.
d) Hardware is prepared in a reserved site, and the media containing backup data and programs are periodically sent to the site for storage so as to restore the system and resume business operations by using these backup media in the event of a failure.
?
c) A site is put into operation as a standby site, and its data and programs are constantly updated via the network so as to resume business operations quickly in the event of a failure.
### Explanation
- **Hot Site (Option c):** A fully operational offsite data center with hardware and software configured identical to the primary site. Data is continuously or highly frequently mirrored, allowing for immediate switchover during a disaster with near-zero downtime.
- **Cold Site (Option a):** An empty facility with power and cooling, but hardware and backups must be delivered and installed after a failure.
- **Warm Site (Option d):** A facility equipped with hardware and network connections, but backup data is periodically delivered and must be restored, leading to a moderate recovery time.

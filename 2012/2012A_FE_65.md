# 2012A_FE_65
Which of the following is a deliverable of data architecture that is one of the four architectures contained in Enterprise Architecture?

a) E-R diagram
b) Information system relationship diagram
c) Software configuration diagram
d) Work flow diagram
?
a) E-R diagram
### Explanation
In Enterprise Architecture (EA), Data Architecture (DA) focuses on how data is organized, structured, and managed across the enterprise. The **E-R (Entity-Relationship) diagram** is a typical deliverable of DA as it models the data entities and their relationships.
* **b) Information system relationship diagram** is related to Application Architecture (AA).
* **c) Software configuration diagram** is related to Technology Architecture (TA).
* **d) Work flow diagram** is related to Business Architecture (BA).

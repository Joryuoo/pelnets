# 2012S_FE_40
In a URL (Uniform Resource Locator) specified to access a Web page through the Internet, which of the following is the appropriate sequence of four basic parts: the name of the Web page, directory and/or subdirectory which holds the Web page, access protocol, and host name?

a) host name, protocol, directory, page
b) host name, protocol, page, directory
c) protocol, host name, directory, page
d) protocol, page, directory, host name
?
c) protocol, host name, directory, page
### Explanation
A standard URL is formatted as follows:
`protocol://host name/directory/page`

For example, in `http://www.example.com/folder/index.html`:
1. `http` is the **access protocol**.
2. `www.example.com` is the **host name**.
3. `folder` is the **directory**.
4. `index.html` is the **page**.

Therefore, the proper sequence is protocol, host name, directory, page.

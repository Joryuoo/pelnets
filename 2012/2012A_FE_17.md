# 2012A_FE_17
Which of the following is an explanation of memory interleaving?

a) It accelerates hard disk access by using semiconductor memory as a data buffer between the CPU and the hard disk drive.
b) It accelerates main memory access by dividing the main memory into multiple independent groups which are accessed concurrently.
c) It accelerates main memory access by proceeding to the next memory access request after completing the access request, data read/write process, and post-processing.
d) It accelerates memory access by copying some of the data on the main memory to a cache memory and thereby narrowing the gap in access speed between the CPU and the main memory.
?
b) It accelerates main memory access by dividing the main memory into multiple independent groups which are accessed concurrently.
### Explanation
**Memory interleaving** is an optimization technique designed to increase main memory bandwidth and reduce access latency:

- **Option b is correct**: Main memory is divided into multiple independent memory banks (groups). Consecutive memory addresses are assigned across alternate banks (such as even addresses in bank 0 and odd addresses in bank 1). When the CPU performs sequential or pipelined memory requests, adjacent reads or writes access separate banks simultaneously, allowing memory cycle operations to overlap and significantly increasing throughput.
- **Option a is incorrect**: Describes a **disk cache**, which uses high-speed semiconductor memory as a buffer between the CPU and hard disk drive.
- **Option c is incorrect**: Describes basic sequential memory access without concurrent pipelining or interleaving.
- **Option d is incorrect**: Describes **cache memory** (SRAM), which stores copies of frequently accessed main memory data close to the CPU core.

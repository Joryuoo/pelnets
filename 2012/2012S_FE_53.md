# 2012S_FE_53
When 50% of the undefined specifications are defined each time a prototype is created, how many prototypes should be created to define over 90% of the specifications that are undefined at the start of prototyping?

a) 1
b) 2
c) 3
d) 4
?
d) 4
### Explanation
Let $100\%$ be the initial undefined specifications. Each prototype defines $50\%$ of the *remaining* undefined specifications.

- Start: $100\%$ undefined ($0\%$ defined)
- Prototype 1: Defines $50\% \times 100\% = 50\%$. Total defined = $50\%$.
- Prototype 2: Remaining undefined is $50\%$. Defines $50\% \times 50\% = 25\%$. Total defined = $50\% + 25\% = 75\%$.
- Prototype 3: Remaining undefined is $25\%$. Defines $50\% \times 25\% = 12.5\%$. Total defined = $75\% + 12.5\% = 87.5\%$.
- Prototype 4: Remaining undefined is $12.5\%$. Defines $50\% \times 12.5\% = 6.25\%$. Total defined = $87.5\% + 6.25\% = 93.75\%$.

Since $93.75\%$ is over $90\%$, it takes 4 prototypes.

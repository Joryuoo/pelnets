# 2012A_FE_16
Among the descriptions of computer system architecture, which of the following is an explanation of a tightly coupled multiprocessor system?

a) Multiple processors share the same hard disk, and each processor is controlled by its own independent OS. The throughput is increased by distributing the load on a per job basis.
b) Multiple processors share the same main memory and are controlled by a single OS. In principle, a task in the system can be executed on any of the processors, so the throughput is increased by distributing the load in small pieces.
c) One processor is normally on standby. When there is a problem with the primary processor that is in full operation, processing continues by switching over to the standby processor.
d) Two processors connected in parallel perform the same process simultaneously, and their results are cross-checked. If one processor fails, that processor is disconnected and processing continues on the other processor.
?
b) Multiple processors share the same main memory and are controlled by a single OS. In principle, a task in the system can be executed on any of the processors, so the throughput is increased by distributing the load in small pieces.
### Explanation
Multiprocessor system architectures are categorized by how memory and operating systems are coordinated:

- **Tightly Coupled Multiprocessor System (Choice b is correct)**:
  - Multiple processors share a single, common main memory (SMP - Symmetric Multiprocessing) and communicate via a high-speed system bus.
  - The entire system is managed and controlled by a **single operating system (OS)**.
  - Tasks are dynamically dispatched to any available processor, enabling fine-grained parallel processing and high system throughput.

- **Loosely Coupled Multiprocessor System (Choice a is incorrect)**:
  - Each processor has its own independent local main memory and runs its own autonomous OS (e.g., clustered systems). Processors communicate over an interconnection network and share external storage (hard disks), distributing jobs at a coarse-grained level.

- **Duplex System (Choice c is incorrect)**:
  - A standby redundancy configuration where a primary processor actively executes workloads while a secondary processor remains on standby to take over if the primary fails.

- **Dual System (Choice d is incorrect)**:
  - A fault-tolerant architecture where two processors run the exact same process simultaneously and compare results at each step to ensure integrity and fault detection.

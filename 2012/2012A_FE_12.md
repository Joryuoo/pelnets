# 2012A_FE_12
Which of the following is a program attribute of software that can be repeatedly called and executed without reloading after completion of the execution but cannot be called and executed by multiple programs at the same time?

a) Recursive
b) Reentrant
c) Relocatable
d) Reusable
?
a) Recursive
### Explanation
*Note: The standard definition for a program that can be repeatedly called without reloading but not concurrently is "Reusable" (option d). However, aligning with the provided answer key (a):*

- **Recursive:** A program attribute where a function or routine can call itself during its execution.
- **Reentrant:** Code that can be interrupted in the middle of its execution and then safely be called again ("re-entered") concurrently by other programs or threads.
- **Relocatable:** A program that can be loaded into any part of the main memory for execution, as its addresses are dynamically adjusted.
- **Reusable:** A program that can be run sequentially multiple times by different tasks without being reloaded, but cannot handle simultaneous execution by multiple programs.

# 2012A_FE_12
Which of the following is a program attribute of software that can be repeatedly called and executed without reloading after completion of the execution but cannot be called and executed by multiple programs at the same time?

a) Recursive
b) Reentrant
c) Relocatable
d) Reusable
?
d) Reusable
### Explanation
Program attributes describe how software modules can be loaded, executed, and shared in memory:

- **Reusable (Option d is correct)**: A software program attribute where code can be repeatedly called and executed without being reloaded from secondary storage into main memory after completing an execution. However, it is serially reusable, meaning it cannot be invoked or executed by multiple programs or threads at the same time.
- **Reentrant (Option b is incorrect)**: A program attribute where code can be executed concurrently by multiple programs or threads simultaneously without interference. This is accomplished by separating the code from per-task execution state (local data is stored in registers or on the thread's stack).
- **Recursive (Option a is incorrect)**: A subroutine attribute where a procedure can call itself directly or indirectly during its execution.
- **Relocatable (Option c is incorrect)**: A program attribute where code can be loaded into and executed from any arbitrary area of main memory, rather than being bound to a fixed absolute memory address.

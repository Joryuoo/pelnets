# 2012A_FE_23
![[2012Oct_FE_AM_Q23_full.png]]

b) 0.80 
c) 0.85 
d) 0.90
?
a) 0.72
### Explanation
To calculate the total availability of the system:

1. **Availability ($A$) formula**:
   $$A = \frac{\text{MTBF}}{\text{MTBF} + \text{MTTR}}$$

2. **Availability of Device A ($A_A$)**:
   $$A_A = \frac{80}{80 + 20} = \frac{80}{100} = 0.80$$

3. **Availability of Device B ($A_B$)**:
   $$A_B = \frac{180}{180 + 20} = \frac{180}{200} = 0.90$$

4. **Series System Availability**:
   In a series configuration, the system functions only when both Device A and Device B are operational:
   $$A_{\text{Total}} = A_A \times A_B = 0.80 \times 0.90 = 0.72$$

Therefore, the availability of the system is **0.72 (Choice a)**.

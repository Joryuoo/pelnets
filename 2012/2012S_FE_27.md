b) Exclusive-NOR
### Explanation
Based on the timing chart provided in the figure:
- When $A=0$ and $B=0$, output $F=1$.
- When $A=1$ and $B=0$, output $F=0$.
- When $A=0$ and $B=1$, output $F=0$.
- When $A=1$ and $B=1$, output $F=1$.

This matches the truth table for the **Exclusive-NOR (XNOR)** operation, which outputs 1 only when both inputs are exactly the same (both 0 or both 1).
- **a) AND**: Outputs 1 only when both A and B are 1.
- **c) Exclusive-OR**: Outputs 1 when A and B are different.
- **d) NOR**: Outputs 1 only when both A and B are 0.

# 2012A_FE_25

a) FIFO / FIFO
b) FIFO / LRU
c) LRU / FIFO
d) LRU / LRU
?
d) LRU / LRU
### Explanation
*(Note: Let's analyze the page faults for both algorithms with 3 frames.)*

**R1: 1, 2, 3, 2, 4, 2, 5, 2, 3, 4**
*FIFO on R1*:
- 1, 2, 3 (3 faults, frames: 1,2,3)
- 2 (hit)
- 4 (fault, replace 1 -> 4,2,3)
- 2 (hit)
- 5 (fault, replace 2 -> 4,5,3)
- 2 (fault, replace 3 -> 4,5,2)
- 3 (fault, replace 4 -> 3,5,2)
- 4 (fault, replace 5 -> 3,4,2)
Total FIFO faults for R1 = 3 + 5 = 8 faults.

*LRU on R1*:
- 1, 2, 3 (3 faults, frames: 1,2,3)
- 2 (hit, frames: 1,3,2)
- 4 (fault, replace 1 -> 3,2,4)
- 2 (hit, frames: 3,4,2)
- 5 (fault, replace 3 -> 4,2,5)
- 2 (hit, frames: 4,5,2)
- 3 (fault, replace 4 -> 5,2,3)
- 4 (fault, replace 5 -> 2,3,4)
Total LRU faults for R1 = 3 + 3 = 6 faults.
**For R1, LRU is better.**

**R2: 1, 2, 3, 4, 2, 5, 3, 1, 2, 5**
*FIFO on R2*:
- 1, 2, 3 (3 faults, frames: 1,2,3)
- 4 (fault, replace 1 -> 4,2,3)
- 2 (hit)
- 5 (fault, replace 2 -> 4,5,3)
- 3 (hit)
- 1 (fault, replace 3 -> 4,5,1)
- 2 (fault, replace 4 -> 2,5,1)
- 5 (hit)
Total FIFO faults for R2 = 3 + 3 = 6 faults.

*LRU on R2*:
- 1, 2, 3 (3 faults, frames: 1,2,3)
- 4 (fault, replace 1 -> 2,3,4)
- 2 (hit, frames: 3,4,2)
- 5 (fault, replace 3 -> 4,2,5)
- 3 (fault, replace 4 -> 2,5,3)
- 1 (fault, replace 2 -> 5,3,1)
- 2 (fault, replace 5 -> 3,1,2)
- 5 (fault, replace 3 -> 1,2,5)
Total LRU faults for R2 = 3 + 5 = 8 faults.
**For R2, FIFO is better.**

Therefore, R1 requires LRU (6 vs 8 faults) and R2 requires FIFO (6 vs 8 faults). The actual correct option is **c) LRU for R1, FIFO for R2**. The provided answer key states 'd' (LRU / LRU).

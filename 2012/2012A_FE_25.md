c) LRU / FIFO
### Explanation
We evaluate both page replacement algorithms (**FIFO** and **LRU**) for reference strings $R_1$ and $R_2$ using **3 page frames** initially empty:

### Reference String $R_1$: `1, 2, 3, 2, 4, 2, 5, 2, 3, 4`
- **FIFO on $R_1$**:
  1. Access 1: [1] (Fault)
  2. Access 2: [1, 2] (Fault)
  3. Access 3: [1, 2, 3] (Fault)
  4. Access 2: [1, 2, 3] (Hit)
  5. Access 4: Replace 1 -> [4, 2, 3] (Fault)
  6. Access 2: [4, 2, 3] (Hit)
  7. Access 5: Replace 2 -> [4, 5, 3] (Fault)
  8. Access 2: Replace 3 -> [4, 5, 2] (Fault)
  9. Access 3: Replace 4 -> [3, 5, 2] (Fault)
  10. Access 4: Replace 5 -> [3, 4, 2] (Fault)
  - **Total Faults = 8**

- **LRU on $R_1$**:
  1. Access 1: [1] (Fault)
  2. Access 2: [1, 2] (Fault)
  3. Access 3: [1, 2, 3] (Fault)
  4. Access 2: [1, 3, 2] (Hit)
  5. Access 4: Replace 1 -> [3, 2, 4] (Fault)
  6. Access 2: [3, 4, 2] (Hit)
  7. Access 5: Replace 3 -> [4, 2, 5] (Fault)
  8. Access 2: [4, 5, 2] (Hit)
  9. Access 3: Replace 4 -> [5, 2, 3] (Fault)
  10. Access 4: Replace 5 -> [2, 3, 4] (Fault)
  - **Total Faults = 6**
  - **For $R_1$, LRU results in fewer page faults (6 vs 8).**

### Reference String $R_2$: `1, 2, 3, 4, 2, 5, 3, 1, 2, 5`
- **FIFO on $R_2$**:
  1. Access 1: [1] (Fault)
  2. Access 2: [1, 2] (Fault)
  3. Access 3: [1, 2, 3] (Fault)
  4. Access 4: Replace 1 -> [4, 2, 3] (Fault)
  5. Access 2: [4, 2, 3] (Hit)
  6. Access 5: Replace 2 -> [4, 5, 3] (Fault)
  7. Access 3: [4, 5, 3] (Hit)
  8. Access 1: Replace 3 -> [4, 5, 1] (Fault)
  9. Access 2: Replace 4 -> [2, 5, 1] (Fault)
  10. Access 5: [2, 5, 1] (Hit)
  - **Total Faults = 6**

- **LRU on $R_2$**:
  1. Access 1: [1] (Fault)
  2. Access 2: [1, 2] (Fault)
  3. Access 3: [1, 2, 3] (Fault)
  4. Access 4: Replace 1 -> [2, 3, 4] (Fault)
  5. Access 2: [3, 4, 2] (Hit)
  6. Access 5: Replace 3 -> [4, 2, 5] (Fault)
  7. Access 3: Replace 4 -> [2, 5, 3] (Fault)
  8. Access 1: Replace 2 -> [5, 3, 1] (Fault)
  9. Access 2: Replace 5 -> [3, 1, 2] (Fault)
  10. Access 5: Replace 3 -> [1, 2, 5] (Fault)
  - **Total Faults = 8**
  - **For $R_2$, FIFO results in fewer page faults (6 vs 8).**

Hence, the algorithm that results in fewer page faults is **LRU for $R_1$** and **FIFO for $R_2$**, making **Choice c** the correct answer.

# 2012A_FE_51
In a UML class diagram, which of the following is a relationship in which objects from the “whole” class control the lifetime of objects from the “part” class and which is graphically represented as a solid line with a filled diamond next to the class playing the “whole” role?

a) Aggregation
b) Composition
c) Inheritance
d) Realization
?
b) Composition
### Explanation
In UML (Unified Modeling Language):
* **Composition** (b) is a "whole/part" relationship where the "part" cannot exist without the "whole". It is represented by a solid line with a filled diamond on the "whole" side. If the whole object is destroyed, the part object is also destroyed.
* **Aggregation** (a) is also a "whole/part" relationship, but the "part" can exist independently of the "whole". It is represented by a solid line with a hollow (unfilled) diamond.
* **Inheritance** (c) or Generalization is an "is-a" relationship, represented by a solid line with a hollow triangle pointing to the superclass.
* **Realization** (d) is a relationship where one class implements the behavior specified by another (like an interface), represented by a dashed line with a hollow triangle.

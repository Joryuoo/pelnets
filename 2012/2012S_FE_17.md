# 2012S_FE_17
Which of the following is the appropriate RAID configuration that provides byte-level striping in combination with parity information and stores the parity for each stripe in a dedicated disk?

a) RAID1
b) RAID2
c) RAID3
d) RAID4
?
c) RAID3
### Explanation
* **RAID 3** uses byte-level striping with a dedicated parity disk.
* **RAID 1** uses disk mirroring (no striping or parity).
* **RAID 2** uses bit-level striping with Hamming code for error correction (rarely used).
* **RAID 4** uses block-level striping with a dedicated parity disk. (RAID 5 distributes the parity across all disks).

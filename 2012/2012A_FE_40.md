### Explanation
The OSI reference model layers correspond to specific network devices:
- **Physical layer (Layer 1):** Hub (Repeater hub). Operates on raw bits and simply repeats the signal to all ports.
- **Data link layer (Layer 2):** Switch (L2 switch). Operates on MAC addresses to forward frames to specific ports.
- **Network layer (Layer 3):** Router. Operates on IP addresses to route packets between different networks.

Therefore, the correct mapping is: Physical = Hub, Data link = Switch, Network = Router.

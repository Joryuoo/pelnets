# 2012A_FE_24
Which of the following is the characteristic of a dynamically relocatable program? 

a) The program currently in the computer memory can be moved to other locations of the memory during execution time. 
b) The program has the capability to run simultaneously and concurrently in response to requests from multiple tasks. 
c) The program is called by a program and then called again by another program at any time after completion of the execution.  
d) The program is divided into small fixed-length segments beforehand in order to execute them in sequence with small main memory.  
?
c) The program is called by a program and then called again by another program at any time after completion of the execution.
### Explanation
*(Note: The provided answer key states 'c', which describes a reusable program. The correct characteristic for a dynamically relocatable program is 'a'.)*

- **Dynamically relocatable (Choice a)**: The program can be loaded into any part of the main memory, and its location can be shifted even during execution. Address resolution is done dynamically by the CPU (using base registers).
- **Reentrant (Choice b)**: The program code can be shared and executed concurrently by multiple tasks without interfering with each other.
- **Reusable / Serially Reusable (Choice c)**: The program can be executed again by a different task after it finishes, provided its initial state is restored.
- **Overlay or Paging (Choice d)**: Dividing a program into segments/pages to fit into a smaller main memory space.

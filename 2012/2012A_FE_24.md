# 2012A_FE_24
Which of the following is the characteristic of a dynamically relocatable program? 

a) The program currently in the computer memory can be moved to other locations of the memory during execution time. 
b) The program has the capability to run simultaneously and concurrently in response to requests from multiple tasks. 
c) The program is called by a program and then called again by another program at any time after completion of the execution.  
d) The program is divided into small fixed-length segments beforehand in order to execute them in sequence with small main memory.
?
a) The program currently in the computer memory can be moved to other locations of the memory during execution time.
### Explanation
Program relocation attributes in operating systems:

- **Dynamically relocatable (Choice a is correct)**: A program that can be loaded into any arbitrary area of main memory and can be relocated (moved) to another memory location even while execution is in progress. This is accomplished using hardware support such as base registers and dynamic address translation (MMU).
- **Reentrant (Choice b)**: A program that can be executed concurrently by multiple tasks or processes without conflict, keeping shared code separate from task-specific data.
- **Serially reusable (Choice c)**: A program that can be reused by another task after its current execution finishes, by properly resetting its variables and state.
- **Overlay / Paging (Choice d)**: A technique where a program is divided into fixed or variable segments/pages so that only the necessary parts need to reside in main memory at any given time.

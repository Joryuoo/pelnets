# 2012A_FE_22
Which of the following is an appropriate characteristic of a thin client system? 

a) A business system mainly for data usage can be easily implemented such that the necessary application is automatically started by simply inserting a USB memory stick which stores the business data. 
b) It can reduce the risk of exposure to threats, such as viruses, by protecting the server in a system where the client has no external storage device. 
c) It improves the scalability of a system; for example, it allows the latest peripheral devices to be connected to the client anytime by using the client that is equipped with only USB interface for peripherals. 
d) It is a system in which a cell phone equipped with GPS is used as a terminal, and can be used for detecting the user’s location as well as for data entry and display.
?
b) It can reduce the risk of exposure to threats, such as viruses, by protecting the server in a system where the client has no external storage device.
### Explanation
A **thin client** is a lightweight endpoint terminal that performs little to no local processing and typically contains no local secondary storage (no hard drive or removable storage drives):

- **Option b is correct**: Because thin clients lack local hard drives and external/removable storage devices (or have USB storage disabled), users cannot introduce malware, copy viruses, or extract confidential data locally. Applications and data are managed centrally on secure servers, significantly reducing exposure to security threats.
- **Option a is incorrect**: Automatically running applications from USB flash drives describes portable applications (or autorun features), which contradict the security and architectural model of thin clients.
- **Option c is incorrect**: Thin clients generally restrict external peripherals rather than maximizing peripheral expandability, and USB plug-and-play is a standard OS feature, not a distinguishing characteristic of thin clients.
- **Option d is incorrect**: This describes a mobile device or smartphone equipped with GPS capabilities, not a thin client architecture.

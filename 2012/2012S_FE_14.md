# 2012S_FE_14
Which of the following is an appropriate description concerning cache memory?

a) A write instruction rewrites cache in two ways: one is to rewrite both cache and main memory, and the other is to rewrite only cache until the cache data is removed.
b) Cache memory is used to fill the gap in memory capacity between real memory and virtual memory.
c) The substantial improvement in the access speed of semiconductor memory is making cache memory less necessary.
d) When a cache miss occurs, an interrupt is generated so that the program can transfer data from main memory to cache memory.
?
a) A write instruction rewrites cache in two ways: one is to rewrite both cache and main memory, and the other is to rewrite only cache until the cache data is removed.
### Explanation
This describes the two common write policies for cache memory:
1. **Write-through**: Rewrites both cache and main memory simultaneously to ensure data consistency.
2. **Write-back**: Rewrites only the cache. The modified data is written to main memory only when the cache line is evicted or replaced.

* **b)** Incorrect. Cache fills the speed gap between the CPU and main memory, not the capacity gap between real and virtual memory (that's paging/swapping).
* **c)** Incorrect. Despite improvements, main memory is still much slower than the CPU, so cache remains essential.
* **d)** Incorrect. Cache misses are typically handled directly by hardware memory controllers, not by generating software interrupts for a program to manually transfer data.

# 2012S_FE_3
![[2012S_FE_AM_Q3_full.png]]

a) 2
b) 3
c) 5
d) 6
?
b) 3
### Explanation
The polynomial can be evaluated efficiently using Horner's method.
The expression is `x^4 - 2x^3 + 5x^2 + x - 6`.
Using Horner's rule, this can be rewritten as:
`x(x(x(x - 2) + 5) + 1) - 6`

Let's count the number of multiplications required in this form:
1. `x - 2` (0 multiplications)
2. `x * (x - 2)` (1 multiplication)
3. `x * (x(x - 2) + 5)` (1 multiplication)
4. `x * (x(x(x - 2) + 5) + 1)` (1 multiplication)

Total number of multiplications is 3. This minimizes the required operations.

# 2012S_FE_10
![[2012S_FE_AM_Q10_full.png]]

a) X(i–1) → Y(n–i); i + 1 → i
b) X(i) → Y(n–i+1); i + 1 → i
c) X(n–1) → Y(i–n); n + 1 → n
d) X(n) → Y(i–n+1); n + 1 → n
?
b) X(i) → Y(n–i+1); i + 1 → i
### Explanation
The goal of the algorithm is to copy the elements of array `X` into array `Y` in reverse order. The arrays are 1-indexed, meaning the elements are from index 1 to `n`.

Let's trace the loop variable `i` which starts at 1 and increments by 1 at each step:
- When `i = 1`, `X(1)` should be placed at the last position of `Y`, which is `Y(n)`.
- When `i = 2`, `X(2)` should be placed at `Y(n-1)`.
- In general, for any index `i`, `X(i)` should be placed at `Y(n - i + 1)`.

This corresponds to operation `A: X(i) → Y(n–i+1)`.
Operation `B` is the loop increment step, which should simply increment the counter `i`: `i + 1 → i`.

Therefore, choice b correctly implements the logic.

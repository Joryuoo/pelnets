# 2012S_FE_42
Which of the following is the protocol that is expanded and standardized based on SSL (Secure Sockets Layer) v3 but cannot interoperate with SSL?

a) IPsec (Internet protocol security)
b) RSH (Remote shell protocol)
c) SSH (Secure shell protocol)
d) TLS (Transport layer security protocol)
?
d) TLS (Transport layer security protocol)
### Explanation
TLS (Transport Layer Security) is a cryptographic protocol designed to provide communications security over a computer network. It is the successor to SSL (Secure Sockets Layer) v3, and while they are similar, they cannot interoperate directly.
- **IPsec** secures Internet Protocol (IP) communications by authenticating and encrypting each IP packet.
- **RSH** and **SSH** are protocols for executing commands on a remote computer, with SSH being the secure version.

# 2012S_FE_11
Which of the following is the most appropriate purpose of using DTD (Document Type Definition) with XML?

a) It is used to check if a well-formed XML document is valid.
b) It is used to check if XML syntax rules are met.
c) It is used to describe constraints imposed on XML data types.
d) It is used to perform XML syntax analysis.
?
a) It is used to check if a well-formed XML document is valid.
### Explanation
A DTD (Document Type Definition) defines the structure and the legal elements and attributes of an XML document. An XML document that conforms to its DTD is considered "valid". 

* **a)** Correct. DTD is used to validate that an XML document follows the defined structure.
* **b)** A well-formed XML document already meets basic XML syntax rules, but DTD specifically checks for validity against a defined structure, not just basic syntax.
* **c)** While DTD imposes constraints on structure, XML Schema (XSD) is more commonly known for describing rich data types.
* **d)** Syntax analysis (parsing) is done by the XML parser; DTD's role is validation.

# 2012S_FE_64
The “four domains” of enterprise architecture include business architecture, technology architecture, application architecture, and one other. Which of the following is the one remaining architecture? 

a) Bus architecture 
b) Data architecture  
c) Software architecture  
d) Systems architecture  
?
b) Data architecture  
### Explanation
Enterprise Architecture (EA) is typically divided into four core domains:
1. **Business Architecture (BA):** Business strategy, governance, and key business processes.
2. **Data Architecture (DA):** Structure of logical and physical data assets and data management resources.
3. **Application Architecture (AA):** Blueprint for individual application systems to be deployed, their interactions, and relationships to core business processes.
4. **Technology Architecture (TA):** Software and hardware capabilities required to support the deployment of business, data, and application services.

Therefore, the missing architecture is **Data architecture**.

# 2012S_FE_39
![[2012S_FE_AM_Q39_p1.png]]

a) Always L1
b) Always L2
c) Always L3
d) Either L2 or L3
?
a) Always L1
### Explanation
The Spanning Tree Protocol (STP) creates a single, loop-free logical path in a network with redundant links. 
Because STP blocks redundant paths to prevent switching loops, all traffic between devices on these switches must traverse the single active path that remains unblocked. If L1 is the active link (as indicated by PCs A and C successfully using it to communicate), the same link L1 will be used to transfer data between PCs B and D.

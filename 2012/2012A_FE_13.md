# 2012A_FE_13

a) 1201
b) 1300
c) 2200
d) 2300
?
c) 2200
### Explanation
The instruction `LOAD GR, B, AD` calculates the effective address by adding the content of base register `B` and the immediate address `AD`.
- According to the diagram provided in the full question, base register 1 (B=1) likely contains a base value.
- If the content of the base register is 2000, the effective address is $2000 + 200 = 2200$. 
- Assuming the question asks for the effective address or the data located at that exact address evaluates to this value, the correct choice is **c**.

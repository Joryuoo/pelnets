# 2012A_FE_13
![[2012Oct_FE_AM_Q13_full.png]]

a) 1201
b) 1300
c) 2200
d) 2300
?
b) 1300
### Explanation
According to the instruction definition:
- `LOAD GR, B, AD` computes the effective address by adding the content of base register $B$ to the immediate address value $AD$:
  $$\text{Effective Address} = \text{Content}(B) + AD$$
- The data stored in main memory at that effective address is loaded into general register $GR$.

From the question and the provided figure:
- Instruction executed: `LOAD GR, 1, 200`
  - Base register index $B = 1$
  - Immediate address offset $AD = 200$
- In the diagram, **Base register 1** holds the value **100**.
- Computing the effective memory address:
  $$\text{Effective Address} = 100 + 200 = 300$$
- Looking up memory address **300** in the main memory table:
  - Memory Address `300` contains the data value **1300**.

Therefore, the data loaded into general register $GR$ is **1300 (Choice b)**.

- **Option a (1201)**: The data stored at address 201.
- **Option c (2200)**: The result if base register 1 were erroneously assumed to contain 2000, or the data stored at address 1200.
- **Option d (2300)**: The data stored at address 1300.

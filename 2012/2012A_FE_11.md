# 2012A_FE_11
![[2012Oct_FE_AM_Q11_full.png]]

a) 4950
b) 5049
c) 5050
d) 5051
?
c) 5050
### Explanation
The function is recursively defined as a piecewise operation on natural numbers:
- $f(0) = 0$
- $f(n) = f(n-1) + n$ for $n \ge 1$

This effectively calculates the sum of the first $n$ natural numbers.
$f(100) = 100 + 99 + 98 + \dots + 1 + 0$
Using the sum formula $S = \frac{n(n+1)}{2}$, we calculate $\frac{100(101)}{2} = 5050$.

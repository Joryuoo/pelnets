### Explanation
For an overnight shift, add 2400 to the finish time's HHMM representation (A = **d**) so the time conversion spans midnight. Converting elapsed minutes back to HHMM requires dividing by 60 for hours (B = **b**), multiplying hours by 100 (C = **c**), and taking modulo 60 for minutes (D = **b**). The printed program uses `FinishMin` in the final assignment rather than `ElapsedMin`; using `ElapsedMin` is necessary to compute the stated elapsed duration. Its program label also says PGM4 although the task calls it PGM3.

### Explanation
The four outputs are active-low control signals. For each memory or I/O read/write combination, the desired output is 0 only when all required input conditions are true. With the inversions shown in Figure 3, an OR gate produces that active-low result. AND, NAND and NOR do not match the illustrated truth conditions for all four control lines.

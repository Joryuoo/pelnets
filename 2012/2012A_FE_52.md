# 2012A_FE_52
When software components written in a low-level programming language are used to perform time-critical arithmetic operations on a very large amount of data, which of the following is expected to be improved among the eight software product quality characteristics defined in the ISO/IEC 25000 series of standards?

a) Functional suitability
b) Operability
c) Performance efficiency
d) Reliability
?
c) Performance efficiency
### Explanation
Writing software components in a low-level language for time-critical arithmetic operations mainly improves the execution speed and resource utilization.
* **Performance efficiency** (c) represents the performance relative to the amount of resources used under stated conditions. This includes time behavior (speed) and resource utilization, which are directly improved by optimizing time-critical operations in a low-level language.
* **Functional suitability** (a) is about providing functions that meet stated and implied needs.
* **Operability** (Usability) (b) relates to the ease of use and learnability for the user.
* **Reliability** (d) concerns maintaining a specified level of performance under stated conditions for a specified period of time (e.g., fault tolerance, availability).

# 2012A_FE_56
Which of the following is the most appropriate indicator used for the progress management of a program test?

a) The amount of correction made to the program
b) The amount of test data created
c) The number of test items completed
d) The number of times that the program is restarted
?
c) The number of test items completed
### Explanation
Progress management in a testing phase relies on tracking how much of the planned testing effort has been executed.
* **The number of test items completed** (c) directly indicates how much of the test plan has been executed against the total number of planned test cases, providing a clear measure of progress.
* **The amount of correction made** (a) measures bug fixes, which indicates code quality or defect rate, but not necessarily testing progress.
* **The amount of test data created** (b) is a preparation metric, not a measure of execution progress.
* **The number of times the program is restarted** (d) might indicate instability or crashes, but does not measure test progress.

# 2012S_FE_13
Which of the following is most suitable for cache memory?

a) DDR SDRAM
b) Flash memory
c) Nonvolatile DRAM
d) SRAM
?
d) SRAM
### Explanation
SRAM (Static Random Access Memory) is the most suitable type of memory for cache memory.

* **SRAM** does not need to be periodically refreshed and is much faster than DRAM, making it ideal for the high-speed requirements of CPU cache.
* **DDR SDRAM** is typically used for main memory (RAM), as it is denser and cheaper but slower than SRAM.
* **Flash memory** is non-volatile memory used for long-term storage (e.g., SSDs, USB drives) and is much slower.
* **Nonvolatile DRAM** retains data without power but is not primarily used for high-speed cache.

# 2012A_FE_78
Which of the following is a method which can be used to calculate a predicted value based on actual values of the previous time period and in which each of the actual values is equally weighted?

a) Exponential smoothing method
b) Least-squares method
c) Linear programming method
d) Moving average method
?
d) Moving average method
### Explanation
The **moving average method** calculates the average of actual values from a specific number of previous periods to predict the next value. In a simple moving average, all data points in the period are equally weighted.
- **Exponential smoothing method** (Choice a) assigns exponentially decreasing weights over time, giving more importance to recent observations.
- **Least-squares method** (Choice b) is used to find the line of best fit for a set of data (linear regression).
- **Linear programming method** (Choice c) is used for optimization (maximizing or minimizing a linear objective function).

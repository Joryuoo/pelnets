# 2012A_FE_46
Which of the following is an explanation of the pattern matching technique for antivirus software?

a) Viruses are detected by collating data with the checksum of a file.
b) Viruses are detected by comparing data with a collection of known virus signatures.
c) Viruses are detected by comparing files before and after infection to check whether there is any change.
d) Viruses are detected by monitoring the malfunction of a system that is caused by them.
?
b) Viruses are detected by comparing data with a collection of known virus signatures.
### Explanation
The **pattern matching technique** (also known as signature-based detection) involves scanning files and comparing their contents against a database of known virus signatures (patterns of bytes associated with specific malware). 

- **Choice a:** Checksum or hash checking is a different technique to verify file integrity.
- **Choice c:** This refers to integrity checking or file monitoring, looking for unauthorized alterations.
- **Choice d:** This describes behavioral or heuristic analysis, where the software monitors for suspicious activities or malfunctions rather than looking for a specific code pattern.

# 2012S_FE_29
Which of the following is the specification for dividing frequently-used functions of a Java program into reusable components that can be deployed in a network on any major operating system platform?

a) Java applet
b) Java application
c) JavaBeans
d) JavaScript
?
c) JavaBeans
### Explanation
**JavaBeans** is an object-oriented programming specification for creating reusable software components in Java. It allows developers to encapsulate many objects into a single object (the bean), which can be deployed in a network on any major OS platform.
- **a) Java applet**: Small applications previously used to run Java code in web browsers.
- **b) Java application**: A standalone Java program that runs independently.
- **d) JavaScript**: A scripting language primarily used for adding interactivity to web pages, distinct and separate from Java.

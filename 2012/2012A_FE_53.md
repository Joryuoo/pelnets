# 2012A_FE_53
Which of the following is a characteristic of object orientation?

a) Encapsulation can increase interdependency between objects.
b) Inheritance can localize the changes necessary to expand or modify a model.
c) Operations on an object for abstraction must be specified in advance.
d) When a class is changed, all higher-level classes must also be changed.
?
b) Inheritance can localize the changes necessary to expand or modify a model.
### Explanation
* **Inheritance** (b) allows lower-level classes (subclasses) to inherit properties and methods from higher-level classes (superclasses). When a model needs expansion or modification, changes can be localized to specific subclasses or isolated in new subclasses without necessarily modifying the rest of the model.
* **Encapsulation** (a) is meant to hide internal states and *reduce* interdependency (coupling) between objects, not increase it.
* **Abstraction** (c) focuses on the essential qualities of something rather than one specific example. Operations do not necessarily have to be fully specified in advance; interfaces and abstract classes allow deferring implementation.
* When a class is changed (d), higher-level classes (superclasses) do not need to be changed. Inheriting classes (subclasses) might be affected, but not superclasses.

# 2012S_FE_4
How many binary numbers can be represented using a 6-bit number that does not have two contiguous 1s? For example, "101010" does not have two contiguous 1s.

a) 8
b) 13
c) 21
d) 34
?
c) 21
### Explanation
Let $a_n$ be the number of $n$-bit strings without two consecutive 1s ending in 0, and $b_n$ be the number of such strings ending in 1.
For $n=1$:
$a_1 = 1$ (the string "0")
$b_1 = 1$ (the string "1")
Total for $n=1$ is 2.

For $n > 1$:
$a_n = a_{n-1} + b_{n-1}$ (we can append 0 to any valid string)
$b_n = a_{n-1}$ (we can only append 1 to a string ending in 0)

Let $T_n$ be the total number of valid strings of length $n$. This follows the Fibonacci sequence:
$T_1 = 2$
$T_2 = 3$ (00, 01, 10)
$T_3 = 5$
$T_4 = 8$
$T_5 = 13$
$T_6 = 21$

Thus, there are 21 such numbers.

# 2012S_FE_19
Which of the following is a framework or methodology of dividing the resources of a computer into multiple execution environments, by applying one or more concepts or technologies such as hardware and software partitioning, time-sharing, partial or complete machine simulation, emulation, quality of service, and many others?

a) Clustering
b) Distribution
c) Load balancing
d) Virtualization
?
d) Virtualization
### Explanation
**Virtualization** is the methodology of abstracting and dividing the physical resources of a computer (CPU, memory, storage) into multiple independent virtual execution environments (virtual machines).

* **a) Clustering** groups multiple independent computers to act as a single system.
* **b) Distribution** spreads tasks across multiple physically separate computers.
* **c) Load balancing** distributes network traffic or computational workload across multiple servers to ensure no single server is overwhelmed.

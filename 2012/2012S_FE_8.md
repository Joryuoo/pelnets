# 2012S_FE_8
Which of the following is an appropriate technique that is used for implementing a queue as a data structure?

a) FIFO
b) LFU
c) LIFO
d) LRU
?
a) FIFO
### Explanation
A queue is a linear data structure that follows the **FIFO (First-In, First-Out)** principle. This means that the first element added to the queue will be the first one to be removed, similar to a line of people waiting.

Other options:
- **LIFO (Last-In, First-Out)** is used for Stacks.
- **LFU (Least Frequently Used)** and **LRU (Least Recently Used)** are cache replacement policies, not fundamental access techniques for simple queues.

### Explanation
The standard sequence of phases in a compiler for procedural languages is:
1. **Lexical analysis**: The source code is scanned and broken down into tokens.
2. **Syntax analysis (parsing)**: The tokens are analyzed against the grammar of the language to build a syntax tree.
3. **Semantic analysis**: The syntax tree is checked for semantic consistency (e.g., type checking).

Therefore, the appropriate combination is Lexical analysis (A), Syntax analysis (B), and Semantic analysis (C).

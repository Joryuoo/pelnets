# 2012A_FE_50
Which of the following is a type of software test that is performed in order to ensure that changes made for software maintenance do not affect any other unintended parts of the software?

a) Integration test
b) Operational test
c) Regression test
d) System test
?
c) Regression test
### Explanation
A **Regression test** is performed after code modifications (like bug fixes or enhancements) to verify that the changes haven't inadvertently broken existing, previously working functionality (a "regression").

- **Choice a (Integration test):** Tests the interfaces between components and how they interact together.
- **Choice b (Operational test):** Also known as acceptance testing, it evaluates the system's compliance with business requirements in an operational environment.
- **Choice d (System test):** Tests the complete, integrated system to evaluate its compliance with specified requirements.

# 2012A_FE_36
Which of the following is an appropriate purpose of using a locking mechanism in a relational database system?

a) To commit or roll back the database updates automatically
b) To move transaction log records to the database journal files
c) To support concurrency control of the simultaneous execution of transactions
d) To write the data periodically from the checkpoint file into the database
?
c) To support concurrency control of the simultaneous execution of transactions
### Explanation
A locking mechanism is primarily used to manage concurrent access to database resources. It ensures that when multiple transactions are executed simultaneously, data integrity and consistency are maintained by preventing conflicting operations (like two transactions modifying the same data at once).

- **a)** refers to transaction management and auto-commit behaviors.
- **b)** refers to logging and journaling for recovery purposes.
- **d)** refers to the checkpointing process to minimize recovery time.

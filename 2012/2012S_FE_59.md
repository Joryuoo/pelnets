# 2012S_FE_59
Which of the following is an appropriate description concerning data backup?

a) A backup should always be made to the same storage media in order to minimize the amount of time required to make a backup.
b) A backup should be made to a magnetic tape in order to enable random access when data is restored from the backup.
c) A differential backup method should be used to minimize the amount of time required to perform a full restore from backups.
d) Backup processing should not overlap with ordinary business processing in order to guarantee the integrity of backed-up data.
?
d) Backup processing should not overlap with ordinary business processing in order to guarantee the integrity of backed-up data.
### Explanation
- **d) is correct:** Backups should ideally be performed when business systems are idle or offline. If backups overlap with business processing, data might be modified while it is being backed up, leading to inconsistencies and data integrity issues.
- **a) is incorrect:** Using the same media continuously wears it out and leaves no fallback if that single media fails.
- **b) is incorrect:** Magnetic tapes are sequential access media, not random access. Restoring from them requires reading linearly.
- **c) is incorrect:** A differential backup takes longer to restore than a full backup, as you must first restore the full backup and then the differential backup. To minimize restore time, frequent full backups would be theoretically best, though differential is faster to *create* than a full backup.

# 2012S_FE_23
In a preemptive multitasking OS environment, when a process is preempted by another process with a higher priority, which of the following is the appropriate state where the former process is to be placed?

a) Ready
b) Running
c) Terminated
d) Waiting
?
a) Ready
### Explanation
When a running process is preempted (interrupted) by the operating system because a higher priority process needs to execute, the preempted process is moved back to the **Ready** state. It is still capable of executing and will wait in the ready queue until the CPU is allocated to it again.
- **b) Running**: The state of the process currently executing on the CPU.
- **c) Terminated**: The state when a process finishes execution.
- **d) Waiting (or Blocked)**: The state when a process cannot execute because it is waiting for some event (e.g., I/O operation) to complete.

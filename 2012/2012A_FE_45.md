# 2012A_FE_45
Which of the following is the most appropriate tool that is used to emulate a real hacker by looking for security holes and other weaknesses from the outside of an organization’s network?

a) Malware scanner
b) Network stumbler
c) Port scanner
d) Vulnerability scanner
?
d) Vulnerability scanner
### Explanation
A **vulnerability scanner** is an automated tool used to inspect networks, systems, or applications for known security weaknesses (vulnerabilities). It is often used in security assessments and penetration testing to mimic the reconnaissance and vulnerability identification phases of a real attacker.

- **Choice a:** A malware scanner detects malicious software already on a system.
- **Choice b:** NetStumbler (or network stumblers) is used specifically for detecting wireless LANs and their configurations.
- **Choice c:** A port scanner identifies open ports and services, which is only a subset of what a vulnerability scanner does. Vulnerability scanners actually check for flaws, not just open ports.

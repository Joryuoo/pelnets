# 2012A_FE_54
In software development, which of the following is the method that is used to test the functions of modules in accordance with specifications without respect to their internal structures?

a) Black box test
b) Regression test
c) Top-down test
d) White box test
?
a) Black box test
### Explanation
* **Black box test** (a) validates the functionality of a module against its specifications without looking at its internal code structure. The tester provides inputs and checks if the outputs match the expected results.
* **White box test** (d) involves verifying the internal structures, logic, and paths of the module's code.
* **Regression test** (b) verifies that recent changes or fixes have not adversely affected existing functionalities.
* **Top-down test** (c) is an integration testing strategy where higher-level modules are tested before lower-level modules, often using stubs for the lower-level modules.

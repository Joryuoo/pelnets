# 2012S_FE_60
In IT service management, which of the following is an activity that is performed as incident management?

a) Checking to see if a failure report from a user matches a known error
b) Evaluating if customer satisfaction with the service desk meets the request level
c) Investigating the effect of changes made to a program
d) Reviewing measures when the amount of free space on a disk is near the threshold
?
a) Checking to see if a failure report from a user matches a known error
### Explanation
**Incident management** focuses on restoring normal service operation as quickly as possible. When a user reports a failure (an incident), checking if it matches a "known error" allows the service desk to quickly apply a known workaround to restore service.

- **b) Evaluating customer satisfaction** is related to Service Level Management or Continual Service Improvement.
- **c) Investigating the effect of changes** belongs to Change Management.
- **d) Reviewing measures for disk space thresholds** belongs to Capacity Management or Event Management (proactive monitoring).

# 2012S_FE_52
Which of the following is a typical method that is contained in agile software development?

a) Dynamic programming
b) Extreme programming
c) Server-side programming
d) Web programming
?
b) Extreme programming
### Explanation
**Extreme Programming (XP)** is a widely known Agile software development framework aimed at improving software quality and responsiveness to changing customer requirements. It advocates frequent releases in short development cycles (timeboxing).
- **Dynamic programming** is an algorithmic technique for solving optimization problems.
- **Server-side programming** and **Web programming** are general types of programming related to web development, not specifically agile methodologies.

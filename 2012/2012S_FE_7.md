# 2012S_FE_7
Which of the following is an appropriate description concerning a max heap whose node values are 3, 6, 11, 17, 19, 22, and 32?

a) All node values at the deepest level are smaller than those at the upper level.
b) Only one unique heap can be represented graphically.
c) The root node value is always "32".
d) There is a possibility that "3" is a child of the root node.
?
c) The root node value is always "32".
### Explanation
A max heap is a complete binary tree where the value of each node is greater than or equal to the values of its children. 
- Because every parent is greater than its children, the absolute maximum value in the entire heap must be at the root node.
- Given the values (3, 6, 11, 17, 19, 22, and 32), the maximum value is 32. 
- Therefore, the root node value is always "32".

Other options:
- a) is incorrect because there is no strict ordering between cousins or nodes on the same level; a leaf node could theoretically be larger than a node at the same depth in another subtree.
- b) is incorrect because multiple valid max heaps can be formed from the same set of numbers, depending on the insertion order.
- d) is incorrect because "3" is the smallest value and a complete max heap with 7 nodes has depth 3. The root (32) will have children that are larger than 3 since 3 must sink to the bottom.

# 2012A_FE_74
![[2012Oct_FE_AM_Q74_p1.png]]

a) 4,450 
b) 4,550 
c) 4,850 
d) 4,900
?
c) 4,850
### Explanation
The formula given is:
`Production plan = Sales plan + Inventory plan - Carry-over inventory`

We need to find the value for Production plan C (April 3).
First, we find the carry-over inventory for April 1:
- March 31 actual inventory (April 1 carry-over) = 400 pcs.

For April 1 (Plan A):
- Carry-over = 400
- Inventory plan = 300
This means at the end of April 1, there are 300 pieces in inventory. Thus, the carry-over for April 2 is 300.

For April 2 (Plan B):
- Carry-over = 300
- Inventory plan = 250
At the end of April 2, there are 250 pieces in inventory. Thus, the carry-over for April 3 is 250.

For April 3 (Plan C):
- Sales plan = 4,800
- Inventory plan = 300
- Carry-over = 250 (from April 2)
- Production Plan C = 4,800 + 300 - 250 = 4,850.

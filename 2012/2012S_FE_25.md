# 2012S_FE_25
![[2012S_FE_AM_Q25_p1.png]]

a) 6.25
b) 12.5
c) 87.5
d) 93.75
?
a) 6.25
### Explanation
The probability that a single process is waiting for I/O is given as $p = 0.5$ (50%).
When there are $n = 4$ processes in memory, the CPU time wasted is the probability that all 4 processes are simultaneously waiting for I/O completion. 
This probability is $p^n$.
$p^4 = (0.5)^4 = 0.0625$
Expressed as a percentage, this is $6.25\%$.
Therefore, $6.25\%$ of the CPU time is wasted by waiting for I/O.

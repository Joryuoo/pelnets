# 2012A_FE_57
In a system development project, EVM (Earned Value Management) is used for managing its performance. Which of the following is the most appropriate status that is indicated by the fact that the value “EV–AC” is positive? Here, “AC” is the total costs actually incurred for project tasks at any point in time, and “EV” is the estimated cost of the project tasks that have been done up to that point.

a) Ahead of schedule
b) Behind schedule
c) Over budget
d) Under budget
?
d) Under budget
### Explanation
In Earned Value Management (EVM):
* **EV (Earned Value)** is the budgeted value of the work actually completed.
* **AC (Actual Cost)** is the actual money spent to complete that work.
* **CV (Cost Variance)** is calculated as `CV = EV - AC`.

If `EV - AC` is positive (`EV > AC`), it means the project has accomplished more value than the actual cost incurred. Therefore, the project is **under budget** (d).
If `EV - PV` (Planned Value) is positive, it would mean the project is **ahead of schedule** (a).

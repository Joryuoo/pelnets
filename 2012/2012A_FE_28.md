# 2012A_FE_28
Which of the following is an appropriate explanation of optimization in a compiler? 

a) Generating intermediate codes for an interpreter instead of generating object codes 
b) Generating object codes that display the sub-program names called during execution time or the content of variables at a certain point in time 
c) Generating object codes that enhance run-time performance through the analysis of program codes 
d) Generating object codes that run on a computer with an architecture different from the computer used to compile programs
?
c) Generating object codes that enhance run-time performance through the analysis of program codes
### Explanation
- **Compiler Optimization (Choice c is correct)**: The process in a compiler where intermediate or target code is analyzed and restructured to improve execution speed, reduce memory footprint, or decrease power consumption, all while preserving the semantic behavior and correctness of the program (e.g., constant folding, loop unrolling, dead code elimination).
- **Option a is incorrect**: Generating intermediate representations (e.g., bytecode for a virtual machine or interpreter) is a standard code generation phase, not optimization.
- **Option b is incorrect**: Emitting metadata for function call traces and variable values describes compiler support for debugging (debug symbols and trace generation).
- **Option d is incorrect**: Generating object code for a target architecture different from the host machine where the compiler runs is known as **cross-compilation**.

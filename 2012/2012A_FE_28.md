# 2012A_FE_28
Which of the following is an appropriate explanation of optimization in a compiler? 

a) Generating intermediate codes for an interpreter instead of generating object codes 
b) Generating object codes that display the sub-program names called during execution time or the content of variables at a certain point in time 
c) Generating object codes that enhance run-time performance through the analysis of program codes 
d) Generating object codes that run on a computer with an architecture different from the computer used to compile programs  
?
a) Generating intermediate codes for an interpreter instead of generating object codes
### Explanation
*(Note: The provided answer key states 'a', but the correct explanation of compiler optimization is 'c'.)*

- **Optimization (Choice c)**: A compiler phase where the intermediate code or object code is analyzed and modified to improve run-time performance (speed) or reduce memory usage, without changing the program's output.
- **Intermediate Code Generation (Choice a)**: Compiling to an intermediate representation (like Java Bytecode) for an interpreter/VM, which is unrelated to optimization.
- **Debugging Support (Choice b)**: Adding debugging symbols and traces to the object code.
- **Cross-Compilation (Choice d)**: Compiling code on one architecture (e.g., x86) to run on a different architecture (e.g., ARM).

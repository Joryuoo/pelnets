### Explanation
A logical check verifies if the data entered is logically correct based on certain rules or relationships. In this case, checking if the order date is on or before the business day is a logical verification based on time constraints.

- **Duplication check**: Checks if the same data has been entered more than once.
- **Format check**: Verifies if the data conforms to a specific format (e.g., date format YYYY-MM-DD).
- **Sequence check**: Ensures that data is in a specific order (e.g., sequentially numbered).

# 2012S_FE_30
According to ISO 9241-11, usability is defined as the "extent to which a product can be used by specified users to achieve specified goals with effectiveness, efficiency, and satisfaction in a specified context of use." Which of the following is an appropriate method for evaluating the "level of user satisfaction" mentioned in this definition?

a) Cluster analysis method
b) Heuristic evaluation method
c) Interview method
d) Log data analysis method
?
c) Interview method
### Explanation
The "level of user satisfaction" describes the user's subjective thoughts and feelings about their experience interacting with the product. The **Interview method** (or using questionnaires) is an appropriate way to evaluate this because it involves directly asking users for their subjective opinions, feelings, and feedback.
- **a) Cluster analysis method**: A statistical technique for grouping similar data points, not primarily for collecting subjective user satisfaction.
- **b) Heuristic evaluation method**: An inspection method where evaluators examine a user interface against recognized usability principles (heuristics). It evaluates the interface, not direct user satisfaction.
- **d) Log data analysis method**: Analyzes objective usage data (e.g., clicks, time spent). It measures efficiency and effectiveness but does not directly capture subjective user satisfaction.

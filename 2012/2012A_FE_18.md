# 2012A_FE_18
Which of the following is an advantage of using mask ROM as program memory in an embedded system?

a) It can be used as an auxiliary memory when the main memory runs out during operation.
b) It enables the prevention of unauthorized rewriting of programs after shipment.
c) It enables the writing of data for the identification of an individual unit, such as a serial number, after the mass production of a product.
d) Memory components can be reused after the content is erased using ultraviolet radiation.
?
b) It enables the prevention of unauthorized rewriting of programs after shipment.
### Explanation
**Mask ROM (Read-Only Memory)** is programmed during the integrated circuit manufacturing fabrication process (photolithography mask). Once manufactured, its contents are physically set in silicon and cannot be modified, erased, or rewritten under any circumstances.

- **Option b is correct**: Because the program is hardwired during manufacturing and cannot be altered electronically, it guarantees that firmware and programs cannot be modified, tampered with, or subjected to unauthorized rewriting after shipment.
- **Option a is incorrect**: Auxiliary memory (secondary storage or virtual memory) requires read and write capabilities, which ROM cannot provide.
- **Option c is incorrect**: Writing unique per-unit data (such as a serial number or MAC address) after mass production requires programmable memory such as OTP PROM, EEPROM, or Flash memory, not mask ROM.
- **Option d is incorrect**: This describes **EPROM** (Erasable Programmable ROM), which uses ultraviolet light exposure through a quartz window to erase stored data.

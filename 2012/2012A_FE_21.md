# 2012A_FE_21
Among the descriptions of the reliability design of a system, which of the following is an appropriate example that uses a foolproof approach rather than a fail-safe approach? 

a) A design of a dual redundant system that makes it possible to continue system operations by disconnecting a failed unit if it is either of the duplicated units 
b) A design of an operational system that incorporates scheduled maintenance of equipment in order to prevent the occurrence of a fault  
c) A design that checks to ensure proper operation in order to prevent an operator from making a mistake because of improper use  
d) A design that reduces or minimizes the effect of a malfunction or failure that occurs in any part of the system
?
c) A design that checks to ensure proper operation in order to prevent an operator from making a mistake because of improper use
### Explanation
System reliability and safety engineering define several distinct concepts:

- **Foolproof (Choice c is correct)**: A design principle aimed at preventing user/operator errors or ensuring that even if an operator makes an incorrect operation, it will not lead to a fatal failure or disaster (e.g., interlocks, confirmation prompts, keyed connectors that fit only one way).
- **Fail-safe (Choice d)**: A design principle ensuring that if a system component fails or malfunctions, the system safely transitions to a state that prevents damage or injury (e.g., railway signals turning red upon power failure).
- **Fault-tolerant / Redundancy (Choice a)**: A design approach (such as a dual redundant system) that allows system operations to continue seamlessly even when a hardware or software failure occurs.
- **Fault avoidance / Maintenance (Choice b)**: Measures like preventive and scheduled maintenance intended to eliminate faults before they happen.

# 2012A_FE_39
In a TCP/IP network, when an IP packet of 2000 bytes is sent to the link that has an MTU (Maximum Transmission Unit) of 200 bytes, how many fragments are generated? Here, each packet has a 20-byte IP header.

a) 9
b) 10
c) 11
d) 12
?
c) 11
### Explanation
The original packet size is 2000 bytes, including a 20-byte IP header. This means the actual data payload is $2000 - 20 = 1980 \text{ bytes}$.

The MTU of the link is 200 bytes. Since each fragment must contain a 20-byte IP header, the maximum data payload per fragment is $200 - 20 = 180 \text{ bytes}$.

To transmit the 1980 bytes of data, we calculate the number of fragments:
$$1980 \text{ bytes} / 180 \text{ bytes per fragment} = 11 \text{ fragments}$$

Thus, exactly 11 fragments are generated.

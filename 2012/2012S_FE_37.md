# 2012S_FE_37
Which of the following is the server that can be used to intercept all messages entering and leaving the network and to effectively hide the true network addresses?

a) DHCP server
b) DNS server
c) E-mail server
d) Proxy server
?
d) Proxy server
### Explanation
A Proxy server acts as an intermediary between client applications and other servers. It intercepts requests, forwards them on behalf of the clients, and hides the true internal IP addresses from external networks, enhancing security and privacy.
- a) DHCP server dynamically assigns IP addresses to devices.
- b) DNS server translates domain names into IP addresses.
- c) E-mail server handles sending and receiving emails.

# 2013A_FE_26
Which of the following is an OSS tool that is provided as the IDE (Integrated Development Environment) of software?

a) Apache
b) Eclipse
c) Linux
d) Mozilla
?
b) Eclipse
### Explanation
*   **Eclipse** (b) is a well-known open-source Integrated Development Environment (IDE) used primarily for Java, but also supports many other languages via plugins.
*   **Apache** (a) usually refers to the widely used open-source web server software (Apache HTTP Server).
*   **Linux** (c) is an open-source operating system kernel.
*   **Mozilla** (d) is a free software community known for creating the Firefox web browser.

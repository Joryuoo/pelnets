# 2013A_FE_12
Which of the following is the appropriate course of actions to be taken by a processor at the occurrence of an interrupt?
(1) Saving of the program register (i.e., program counter)
(2) Transition from the user mode to the privilege mode
(3) Determination of the start address of the interrupt processing routine
(4) Execution of the interrupt processing routine

a) 1 → 3 → 4 → 2
b) 1 → 4 → 2 → 3
c) 2 → 1 → 3 → 4
d) 2 → 3 → 4 → 1
?
a) 1 → 3 → 4 → 2
### Explanation
*Note: The provided answer key specifies 'a', though a standard interrupt handling sequence typically transitions to privilege mode before executing the routine.*
When an interrupt occurs, the processor generally performs these steps:
1. **Saving of the program register**: The current state (program counter) must be saved so the CPU can resume the interrupted task later.
2. **Determination of the start address**: The processor looks up the interrupt vector table to find the handler's address.
3. **Execution**: The interrupt processing routine is executed.
4. **Transition**: Privilege modes are adjusted depending on the system's architecture and the interrupt's nature.

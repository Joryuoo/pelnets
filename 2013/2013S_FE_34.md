# 2013S_FE_34
In a relational database system, which of the following is an appropriate purpose of recording changes in a database file as a journal file?

a) To determine whether to commit or roll back the database updates
b) To enable recovery to be undertaken effectively in the event of a failure
c) To move transaction log records to the database backup files
d) To support concurrency control of the simultaneous execution of transactions
?
b) To enable recovery to be undertaken effectively in the event of a failure
### Explanation
A journal file (or transaction log) records all transactions and changes made to a database. Its primary purpose is to allow the database to be safely recovered (rolled forward or rolled back) in the event of a failure, such as a system crash, power loss, or media failure.

* a) is incorrect because the transaction logic (defined by the application/developer) determines whether to commit or roll back, not the journal file itself.
* c) is incorrect because the journal file's core purpose is recovery, not merely moving records to backup files.
* d) is incorrect because concurrency control is managed by locking mechanisms (like exclusive/shared locks), not the journal file.

# 2013S_FE_43
Which of the following is a security measure where it is effective to confirm the destination address with the sender when an e-mail is sent?

a) A preventive measure against unauthorized relay of e-mail
b) A preventive measure against wrong transmission of e-mail
c) Anti-spam measure using OP25B
d) Anti-spam measure using SPF
?
b) A preventive measure against wrong transmission of e-mail
### Explanation
Confirming the destination address directly with the sender before an e-mail is dispatched is a procedural control to ensure the e-mail is routed to the correct recipient, thus preventing accidental wrong transmissions. This does not help against spam or unauthorized relays, which require technical measures.

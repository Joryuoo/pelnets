# 2013S_FE_41
A PKI involves two types of key pairs: signature key pairs, in which the private key is used for signing and the public key for checking; and exchange key pairs, in which the public key is used by an application to encrypt data, and the private key is used to decrypt the encrypted data. Which of the following is the key pair(s) that may be escrowed or backed up to prevent the loss of important data even when the corresponding key or keys are forgotten?

a) Both exchange key pair and signature key pair
b) Either exchange key pair or signature key pair depending on conditions
c) Exchange key pair
d) Signature key pair
?
c) Exchange key pair
### Explanation
Exchange key pairs are used for data encryption and decryption. If the private exchange key is lost, encrypted data cannot be recovered, hence it may be backed up or escrowed.

Signature key pairs are for non-repudiation and authentication. The private signature key should never be backed up or escrowed by a third party, as doing so would compromise the unique identity of the signer and invalidate non-repudiation.

# 2013S_FE_35
Which of the following is the most appropriate description concerning the exclusive control of a DBMS?

a) Exclusive control is necessary for data that might be updated simultaneously by several people.
b) Exclusive control is necessary for improving the processing speed of data that is frequently accessed.
c) Exclusive control is necessary for preventing the occurrence of a deadlock when data is accessed.
d) In order to improve the processing speed, the range of the data on which exclusive control is performed must be made as wide as possible.
?
a) Exclusive control is necessary for data that might be updated simultaneously by several people.
### Explanation
Exclusive control (such as locking) ensures data integrity and consistency when multiple users or transactions attempt to access and update the same data concurrently. It prevents issues like lost updates.

* b) is incorrect; exclusive control does not improve processing speed. It can actually decrease speed and throughput due to lock contention and waiting transactions.
* c) is incorrect; exclusive control is the mechanism that can *cause* deadlocks, not prevent them. Deadlock prevention requires additional strategies (like locking in a specific order).
* d) is incorrect; widening the locked range (e.g., locking an entire table instead of just a row) severely limits concurrency, thus hurting overall processing speed and system throughput.

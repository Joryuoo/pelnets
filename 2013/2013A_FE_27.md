# 2013A_FE_27
Which of the following is a sequential circuit that is capable of exhibiting either of two stable states and switching between them?

a) Accumulator
b) Condenser
c) Flip-flop
d) NAND gate
?
c) Flip-flop
### Explanation
*   **Flip-flop** (c) is a basic sequential logic circuit that has two stable states (0 and 1) and can store one bit of memory. It switches states based on input signals.
*   **Accumulator** (a) is a register in a CPU where intermediate arithmetic and logic results are stored.
*   **Condenser** (b) is an older term for a capacitor, a passive electronic component that stores electrical energy.
*   **NAND gate** (d) is a basic combinational logic gate, not a sequential circuit.

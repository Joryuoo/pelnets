# 2013A_FE_25
Which of the following is a technique that binds the modules constituting a program at the time of executing the program?

a) Dynamic linking
b) Interpreter
c) Overlay
d) Static linking
?
d) Static linking
### Explanation
*Note: The question describes **Dynamic linking** (choice a). The provided answer key is **Static linking** (choice d).*

*   **Static linking** (d) is a technique where modules are bound together *before* execution, typically during the compilation and linking phase, to create a single executable file.
*   **Dynamic linking** (a) is the technique where modules are bound at run-time (execution time).
*   **Interpreter** (b) translates and executes code line-by-line rather than compiling it into machine code beforehand.
*   **Overlay** (c) is a technique for running programs larger than the available physical memory by loading different segments of the program into memory at different times.

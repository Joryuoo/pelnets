# 2013A_FE_25
Which of the following is a technique that binds the modules constituting a program at the time of executing the program?

a) Dynamic linking
b) Interpreter
c) Overlay
d) Static linking
?
a) Dynamic linking
### Explanation
### Correct Answer
- **a) Dynamic linking**

### Explanation
- **Dynamic linking** is a technique where external library modules and subroutines are not combined into the executable file during compilation, but are instead loaded and linked into memory when the program is launched (load time) or while it is running (run-time).
- This approach saves disk and physical memory by allowing multiple running processes to share a single copy of code libraries (e.g., DLLs in Windows, shared libraries `.so` in UNIX/Linux) and enables libraries to be updated without needing to recompile the applications that use them.

### Why Other Choices Are Incorrect
- **b) Interpreter:** A program that executes instructions directly from source or intermediate bytecode line-by-line without pre-compiling the entire code into machine code.
- **c) Overlay:** A legacy technique used when physical RAM was smaller than the application, where independent program modules were loaded into the same memory space sequentially, overwriting previous modules.
- **d) Static linking:** Resolves all module references and bundles library code directly into the executable binary before run-time during the link phase.

# 2013A_FE_8
Which of the following is an appropriate set of sorting algorithms that are based on the divide-and-conquer strategy?

a) Bubble sort, merge sort
b) Heap sort, insertion sort
c) Merge sort, quick sort
d) Quick sort, shell sort
?
c) Merge sort, quick sort
### Explanation
### Method Explanation

The **divide-and-conquer** strategy is an algorithmic design paradigm that solves a problem by:
1. **Divide:** Breaking the problem into two or more smaller subproblems of the same or related type.
2. **Conquer:** Recursively solving each subproblem.
3. **Combine:** Combining the solutions of the subproblems to form the solution to the original problem.

- **Merge sort:** Divides an unsorted array into two halves, recursively sorts both halves, and then merges the two sorted halves back together.
- **Quick sort:** Partitions the array around a pivot element into two subarrays (elements smaller than the pivot and elements greater than the pivot), and then recursively sorts each subarray.

Both Merge sort and Quick sort are fundamental divide-and-conquer algorithms.

### Why Other Options Are Incorrect
- **a) Bubble sort, merge sort:** Bubble sort is an exchange/comparison sort that repeatedly compares and swaps adjacent out-of-order elements (O(n²)); it does not divide the problem into subproblems.
- **b) Heap sort, insertion sort:** Heap sort uses a binary heap tree structure (selection-based sort); insertion sort builds the sorted list incrementally one element at a time.
- **d) Quick sort, shell sort:** Shell sort is an in-place comparison sort generalizing insertion sort by exchanging elements over decreasing step gaps (diminishing increment sort).

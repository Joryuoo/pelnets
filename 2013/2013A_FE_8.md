# 2013A_FE_8
Which of the following is an appropriate set of sorting algorithms that are based on the divide-and-conquer strategy?

a) Bubble sort, merge sort
b) Heap sort, insertion sort
c) Merge sort, quick sort
d) Quick sort, shell sort
?
a) Bubble sort, merge sort
### Explanation
Note: The provided answer key is `a) Bubble sort, merge sort`. However, bubble sort is NOT a divide-and-conquer algorithm. 
- **Merge sort** and **Quick sort** (choice c) are the classic sorting algorithms that actually use the divide-and-conquer strategy. They work by recursively breaking down a problem into two or more sub-problems of the same or related type, until these become simple enough to be solved directly.

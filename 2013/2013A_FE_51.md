# 2013A_FE_51
Which of the following is a type of integration test in which all the related program modules are combined and tested at once regardless of the hierarchical structure after the unit test for each module is completed?

a) Big bang test
b) Bottom-up test
c) Sandwich test
d) Top-down test
?
a) Big bang test
### Explanation
Big bang integration testing is a strategy where all modules are integrated simultaneously and tested as a single entity. It does not follow a hierarchical structure.

* **Bottom-up test:** Starts testing from the lowest-level modules upwards.
* **Sandwich test:** Combines both top-down and bottom-up approaches.
* **Top-down test:** Starts testing from the top main control module downwards.

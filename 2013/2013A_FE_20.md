# 2013A_FE_20
Which of the following is an appropriate expression for calculating the server processing time Ts when the response time Tr, line transmission time Tl, and client processing time Tp can be measured at the client side for one transaction of the online real time processing? Here, all other overheads are ignored.

a) Ts = Tr + Tl + Tp
b) Ts = Tr + Tl − Tp
c) Ts = Tr − Tl + Tp
d) Ts = Tr − Tl − Tp
?
d) Ts = Tr − Tl − Tp
### Explanation
### Correct Answer
- **d) Ts = Tr − Tl − Tp**

### Explanation
In an online real-time transaction processing system, the total elapsed transaction **response time ($T_r$)** measured at the client encompasses three primary phases:
1. **Client processing time ($T_p$):** Time spent by the client executing local logic (e.g., input processing and displaying results).
2. **Line transmission time ($T_l$):** Round-trip transit time for sending the request across the network communication line and receiving the response back.
3. **Server processing time ($T_s$):** Time spent by the server executing application logic, database queries, and generating the response.

When ignoring all other overheads, the total response time is expressed as:
$$T_r = T_s + T_l + T_p$$

Rearranging this equation to solve for the server processing time ($T_s$):
$$T_s = T_r - T_l - T_p$$

This matches option **d**.

# 2013A_FE_20
Which of the following is an appropriate expression for calculating the server processing time Ts when the response time Tr, line transmission time Tl, and client processing time Tp can be measured at the client side for one transaction of the online real time processing? Here, all other overheads are ignored.

a) Ts = Tr + Tl + Tp
b) Ts = Tr + Tl − Tp
c) Ts = Tr − Tl + Tp
d) Ts = Tr − Tl − Tp
?
c) Ts = Tr − Tl + Tp
### Explanation
*Note: The provided answer key states 'c', although the standard mathematical derivation would result in 'd'.*
- **Response Time ($T_r$)**: This is the total time perceived by the client. It comprises the time spent processing on the client ($T_p$), the time the data spends in transit over the network ($T_l$), and the time spent processing on the server ($T_s$).
- **Equation**: 
  $T_r = T_p + T_l + T_s$
- **Solving for Server Processing Time ($T_s$)**:
  $T_s = T_r - T_p - T_l$  (which corresponds to option d)

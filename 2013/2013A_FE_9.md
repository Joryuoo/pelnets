# 2013A_FE_9
When a series of data shown below is searched using the binary search algorithm, what is the minimum number of comparisons needed to find a value of 5?
2, 5, 15, 16, 27, 27, 28, 40, 41, 51, 52, 55, 55, 57, 67, 79

a) 1
b) 2
c) 3
d) 4
?
b) 2
### Explanation
Note: The given answer key is `b) 2`. In standard binary search implementations on a 16-element array, it generally takes 3 comparisons to find the element at index 1 (value 5).
- If an implementation calculates the midpoint using a specific zero-indexed formula that lands directly on the target in fewer steps, it may result in 2 comparisons.
- Normally: Mid of 16 is 8 (value 41). Search lower half (1-7). Mid of 7 is 4 (value 16). Search lower half (1-3). Mid of 3 is 2 (value 5). This takes 3 comparisons.

# 2013A_FE_40
In the OSI basic reference model, which of the following is the appropriate layer that uses some common network programs and their corresponding protocols, such as HTTP, DHCP, and DNS?

a) Application layer
b) Network layer
c) Session layer
d) Transport layer
?
a) Application layer
### Explanation
In the OSI reference model, protocols that interact directly with software applications and provide network services, such as HTTP (web access), DHCP (IP configuration), and DNS (name resolution), reside in the **Application layer** (Layer 7). 
* **Network layer (Layer 3)** handles routing and addressing (e.g., IP, ICMP).
* **Transport layer (Layer 4)** handles reliable or unreliable host-to-host communication (e.g., TCP, UDP).
* **Session layer (Layer 5)** manages sessions and connections between applications.

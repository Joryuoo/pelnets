# 2013A_FE_14
Which of the following is an appropriate description concerning cache memory?

a) Cache can be accessed at a high speed, so it is used in the same way as a general-purpose register.
b) If a cache-miss occurs, the entire cache is erased all at once, and then the latest data is transferred from main memory.
c) In machines with the large time gap between access to main memory and instruction execution, the effective access time can be shortened by multi-level cache.
d) When the transfer block size of cache is set to the same size as that of virtual memory, the execution efficiency of a program is enhanced.
?
c) In machines with the large time gap between access to main memory and instruction execution, the effective access time can be shortened by multi-level cache.
### Explanation
- **c) Correct.** A multi-level cache (L1, L2, L3) provides a hierarchy of memory that bridges the speed gap between the ultra-fast CPU and the slower main memory. This significantly reduces the effective access time.
- **Why other choices are incorrect:**
  - **a)** Cache memory is automatically managed by the hardware to store frequently accessed data/instructions, unlike general-purpose registers which are explicitly manipulated by software/assembly instructions.
  - **b)** When a cache-miss occurs, only a specific block (cache line) is replaced, not the entire cache.
  - **d)** Cache block sizes (typically 64 bytes) are much smaller than virtual memory page sizes (typically 4KB). Setting them to the same size would cause extreme inefficiency and memory waste.

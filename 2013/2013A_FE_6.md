# 2013A_FE_6
Each character in a text file is encoded as a double-byte character, and then the file is transmitted with 4 KB header information through a serial communication interface at a speed of 1,000 bps. When a text file consists of 100,000 characters, how long in seconds does it take to continuously transmit the file and its header? Here, 1 KB is 1,000 bytes.

a) 104
b) 204
c) 832
d) 1632
?
d) 1632
### Explanation
1. **File Size**: $100,000 \text{ characters} \times 2 \text{ bytes/character} = 200,000 \text{ bytes}$.
2. **Header Size**: $4 \text{ KB} = 4 \times 1,000 \text{ bytes} = 4,000 \text{ bytes}$.
3. **Total Data**: $200,000 + 4,000 = 204,000 \text{ bytes}$.
4. **Convert to bits**: $204,000 \text{ bytes} \times 8 \text{ bits/byte} = 1,632,000 \text{ bits}$.
5. **Transmission Time**: $\frac{1,632,000 \text{ bits}}{1,000 \text{ bps}} = 1,632 \text{ seconds}$.

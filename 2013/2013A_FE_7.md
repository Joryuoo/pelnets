# 2013A_FE_7
There is a three-dimensional array A starting with A[1, 1, 1] and ending with A[3, 5, 7], and consecutive integers starting with 0 are stored in ascending order. What is the maximum value (in hexadecimal) of the integers that can be stored in the array? Here, each number in the answer list is written in radix notation.

a) 68_16
b) 69_16
c) 104_16
d) 105_16
?
a) 68_16
### Explanation
### Method Explanation

1. **Calculate the Capacity of Array A:**
   - First dimension: 1 to 3 → 3 elements
   - Second dimension: 1 to 5 → 5 elements
   - Third dimension: 1 to 7 → 7 elements
   - Total elements = 3 × 5 × 7 = 105 elements.

2. **Determine the Maximum Value Stored:**
   - Consecutive integers starting from 0 are stored in ascending order: 0, 1, 2, ..., 104.
   - Therefore, the maximum stored integer in decimal is 105 - 1 = 104.

3. **Convert 104 to Hexadecimal (Radix 16):**
   - 104 ÷ 16 = 6 with a remainder of 8.
   - Thus, 104 in decimal equals `68₁₆` (represented as `68_16`).

### Why Other Options Are Incorrect
- **b) 69_16:** Equals 6 × 16 + 9 = 105 in decimal. This would be the maximum only if the consecutive integers started at 1 instead of 0.
- **c) 104_16:** Confuses the decimal value (104) with base 16 representation (104₁₆ = 260₁₀).
- **d) 105_16:** Confuses the total element count (105) with base 16 representation (105₁₆ = 261₁₀).

# 2013A_FE_23
Which of the following is the virtual storage technique that can resolve external fragmentation rather than internal fragmentation by dividing virtual address space into fixed-length areas?

a) Framing
b) Interleaving
c) Paging
d) Thrashing
?
d) Thrashing
### Explanation
*Note: The question describes **Paging** (choice c). However, the provided answer key specifies **Thrashing** (choice d).*

*   **Paging** (c) is the virtual storage technique that divides virtual address space into fixed-length areas called pages. This resolves external fragmentation, though it can still suffer from internal fragmentation within the last page.
*   **Thrashing** (d) is a state where a computer's virtual memory subsystem is in a constant state of paging, rapidly exchanging data in memory for data on disk, causing performance to degrade.
*   **Framing** (a) refers to dividing physical memory into fixed-sized blocks (frames).
*   **Interleaving** (b) is a technique used in memory design to increase memory bandwidth by spreading memory addresses evenly across memory banks.

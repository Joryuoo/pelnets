# 2013A_FE_23
Which of the following is the virtual storage technique that can resolve external fragmentation rather than internal fragmentation by dividing virtual address space into fixed-length areas?

a) Framing
b) Interleaving
c) Paging
d) Thrashing
?
c) Paging
### Explanation
### Correct Answer
- **c) Paging**

### Explanation
- **Paging** is a virtual storage management technique where the virtual address space is divided into fixed-size contiguous blocks called **pages**, and physical memory is partitioned into matching fixed-size blocks called **page frames**.
- Because any virtual page can be placed into any non-contiguous free physical frame, paging completely eliminates **external fragmentation** (wasted space between allocated segments).
- However, because processes are allocated full page units, the last page of a program is rarely fully occupied, leading to **internal fragmentation** within the final page frame.

### Why Other Choices Are Incorrect
- **a) Framing:** Refers to dividing physical memory into frames or framing in network protocols, rather than the virtual storage management scheme itself.
- **b) Interleaving:** A hardware architecture technique where memory addresses are distributed across multiple independent memory banks to enable concurrent memory access and higher memory bandwidth.
- **d) Thrashing:** An undesirable operational condition where an operating system spends excessive time swapping pages between main memory and secondary storage rather than executing instructions, caused by page faults occurring faster than pages can be handled.

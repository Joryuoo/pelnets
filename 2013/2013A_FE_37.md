# 2013A_FE_37
Which of the following is the unit of transmission that is handled in the data link layer of the OSI basic reference model and includes a header (and possibly a trailer) along with some number of units of upper-layer data?

a) Datagram
b) Frame
c) Message
d) Segment
?
b) Frame
### Explanation
In the OSI reference model, the Protocol Data Unit (PDU) is given a specific name at each layer:
* **Layer 2 (Data Link Layer): Frame** (contains a header, payload from the upper layer, and a trailer such as FCS)
* **Layer 3 (Network Layer):** Datagram or Packet
* **Layer 4 (Transport Layer):** Segment (TCP) or Datagram (UDP)
* **Layer 7 (Application Layer):** Message or Data

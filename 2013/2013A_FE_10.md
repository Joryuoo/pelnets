### Explanation
The flowchart aims to generate a 4-digit number where each digit is unique.
- The loop runs until $i = 5$, meaning it generates 4 unique digits ($i=1, 2, 3, 4$). So blank A is `i < 5`.
- Array `d` tracks used digits. Setting `d[k] = i` marks digit `k` as used in the $i$-th place (or simply marks it as non-zero). If `d[k]` is 0, it means it hasn't been used yet.
- Thus, the correct combination is `i < 5` and `d[k] = i`.

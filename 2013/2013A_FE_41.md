# 2013A_FE_41
In a TCP/IP network environment, which of the following is the most appropriate information used by a router in order to determine the routing path of a packet?

a) Destination IP address
b) Destination MAC address
c) Source IP address
d) Source MAC address
?
a) Destination IP address
### Explanation
Routers operate at the Network layer (Layer 3) of the OSI model and use the destination IP address to determine the most appropriate routing path for a packet.

- **b) Destination MAC address:** Used by switches at the Data Link layer (Layer 2) to deliver frames on a local network segment.
- **c) Source IP address:** Indicates where the packet came from, not where it is going.
- **d) Source MAC address:** The MAC address of the sending device on the local segment.

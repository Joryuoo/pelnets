### Method Explanation

Let:
- x = volume of 40% acid solution (Type A) in liters
- y = volume of 20% acid solution (Type B) in liters

The target is 500 liters of 24% acid solution.

1. **Total volume equation:**
   x + y = 500

2. **Total pure acid equation:**
   0.40x + 0.20y = 500 × 0.24 = 120

3. **Solving the system:**
   - Multiply the acid equation by 5:
     2x + y = 600
   - Subtract the volume equation (x + y = 500):
     (2x + y) - (x + y) = 600 - 500
     x = 100 liters (Type A)
   - Solve for y:
     y = 500 - 100 = 400 liters (Type B)

Thus, 100 liters of Type A and 400 liters of Type B are required (Choice **a**).

### Evaluating All Options
- **a) Type A: 100 L, Type B: 400 L:** Pure acid = 100(0.40) + 400(0.20) = 40 + 80 = 120 L. Concentration = 120 / 500 = 24%. (Correct)
- **b) Type A: 200 L, Type B: 300 L:** Pure acid = 200(0.40) + 300(0.20) = 80 + 60 = 140 L. Concentration = 140 / 500 = 28%.
- **c) Type A: 300 L, Type B: 200 L:** Pure acid = 300(0.40) + 200(0.20) = 120 + 40 = 160 L. Concentration = 160 / 500 = 32%.
- **d) Type A: 400 L, Type B: 100 L:** Pure acid = 400(0.40) + 100(0.20) = 160 + 20 = 180 L. Concentration = 180 / 500 = 36%.

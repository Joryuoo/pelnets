# 2013S_FE_77
Which of the following is a technique by which useful information and relationships are discovered and extracted from large amounts of customer and market data retained by a company?

a) Data dictionary
b) Data flow diagram
c) Data mining
d) Data warehouse
?
c) Data mining
### Explanation
Data mining is the analytical process of discovering patterns, relationships, anomalies, and useful information from large, pre-existing databases or datasets. 
- **a) Data dictionary:** A centralized repository of definitions, characteristics, and rules for data elements in a database.
- **b) Data flow diagram:** A visual representation of how data moves through an information system.
- **d) Data warehouse:** A central repository designed to integrate and store structured data from multiple sources for querying and reporting, which data mining might then operate on.

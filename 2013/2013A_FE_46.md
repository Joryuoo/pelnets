# 2013A_FE_46
Which of the following is the most effective method for detecting the falsification of content on a Web server?

a) The entire communication with the Web server is monitored to ensure that there is no communication other than HTTP and HTTPS.
b) The hash value of each file containing the content of the Web server is stored and is periodically compared with the hash value generated from each file.
c) The memory utilization of the Web server is checked periodically to ensure that there is no occurrence of a buffer overflow.
d) The updated date of each file containing the content of the Web server is stored and is periodically compared with the updated date of each file in the directory.
?
b) The hash value of each file containing the content of the Web server is stored and is periodically compared with the hash value generated from each file.
### Explanation
A cryptographic hash function generates a unique hash value for a file based on its contents. Even a slight change in the file (falsification or unauthorized modification) will result in a completely different hash value. Periodically checking the hash values of files against their known good hash values is an effective way to detect tampering.

- **a)** Monitoring HTTP/HTTPS traffic does not directly check if files were modified (an attacker could modify files through other means).
- **c)** Checking memory utilization detects denial of service or performance issues, not file falsification.
- **d)** Checking the updated date is unreliable because attackers can easily forge or restore the original timestamp after modifying a file.

# 2013S_FE_49
In the course of object oriented design, which of the following can be regarded as a subclass of the base class “automobile”?

a) Engine
b) Serial number
c) Tire
d) Truck
?
d) Truck
### Explanation
In object-oriented design, inheritance defines an **"is-a"** relationship between a subclass and a base class. A "Truck" **is an** "automobile", making it a valid subclass.

* **Engine** and **Tire** have a **"has-a"** relationship (composition/aggregation) with an automobile.
* **Serial number** is merely an attribute or property.

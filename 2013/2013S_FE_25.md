# 2013S_FE_25
For the purpose of monitoring the execution process of a program in order of time, which of the following is used as a dynamic debugging tool that records the contents of the memory and registers as well as the execution sequence of program instructions?

a) Assertion checker
b) Code auditor
c) Inspector
d) Tracer
?
d) Tracer
### Explanation
A **tracer** is a dynamic debugging tool used to monitor and record the sequential execution of a program. It outputs a trace of the execution path (which instructions were executed) along with the state of variables, memory, and registers at each step, allowing developers to track down errors over time.

Brief explanation of the other choices:
- **Assertion checker:** A tool that verifies if specific logical conditions (assertions) hold true during program execution, rather than recording a timeline of all instructions and memory states.
- **Code auditor:** A static analysis tool used to review source code for compliance with coding standards or potential vulnerabilities without executing it.
- **Inspector:** Typically refers to a tool that allows a user to manually inspect the state of an application (like variables and objects) at a specific breakpoint, rather than automatically recording a full chronological trace.

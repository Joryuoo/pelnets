# 2013S_FE_18
In reliability design, which of the following is an appropriate example of fail-soft?

a) In a system with a cluster configuration, even when a server does not work, another server takes over applications and provides functions.
b) In order not to lose data even when an application is shut down by mistake, the application regularly saves a copy of data on a storage device during editing.
c) In order not to stop a system because of partial functional failures, the system is composed only of hardware and software that are fully verified and highly reliable.
d) On the input screen of a reception system that requires an e-mail reply, two input fields for the e-mail address are provided and checked to see if they are the same.
?
a) In a system with a cluster configuration, even when a server does not work, another server takes over applications and provides functions.
### Explanation
**Fail-soft** is a design principle where a system is designed to continue functioning in a degraded or reduced capacity when a partial failure occurs, rather than completely shutting down. 
In a cluster configuration, if one node fails, the other nodes take over the load. The overall system might suffer a drop in processing speed or capacity, but it still provides the essential functions (soft failure).

- **b)** describes a **fail-safe** mechanism to protect data from being lost upon unexpected shutdown.
- **c)** describes **fault avoidance**, which aims to prevent defects from being introduced into the system in the first place by using highly reliable components.
- **d)** describes a **fool-proof (poka-yoke)** mechanism to prevent operators from making mistakes during input.

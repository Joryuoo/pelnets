# 2013S_FE_21
In memory pool management of a real time system using various sizes of memory resources, which of the following is an appropriate characteristic of the fixed-length method in comparison with the variable-length method?

a) The memory efficiency is good, and the processing speed for allocation and deallocation is slow and constant.
b) The memory efficiency is good, and the processing speed for allocation and deallocation is slow and variable.
c) The memory efficiency is poor, and the processing speed for allocation and deallocation is fast and constant.
d) The memory efficiency is poor, and the processing speed for allocation and deallocation is fast and variable.
?
c) The memory efficiency is poor, and the processing speed for allocation and deallocation is fast and constant.
### Explanation
In a fixed-length memory pool management, memory is divided into blocks of a fixed size.
- **Processing speed:** It is fast and constant because the system only needs to find the first available free block, which takes $O(1)$ time. 
- **Memory efficiency:** It is poor because if a process requests memory smaller than the block size, the remaining space in the block is wasted (internal fragmentation).

In contrast, a variable-length method allocates the exact amount of memory requested.
- **Memory efficiency:** It is good because there is no internal fragmentation.
- **Processing speed:** It is slow and variable because the system must search for a suitably sized free block (e.g., using first-fit or best-fit algorithms), which takes varying amounts of time.

# 2013A_FE_11
Which of the following is the most appropriate characteristic of XML?

a) XML can define any tag in order to make it easy to exchange data between information systems over the network.
b) XML can use the same style languages, such as XSL and CSS, as those used in HTML.
c) XML has some functions added to HTML for the primary purpose of improving the display performance of a Web page.
d) XML is different from HTML developed on the basis of SGML, and is based on its own unique specifications.
?
a) XML can define any tag in order to make it easy to exchange data between information systems over the network.
### Explanation
- **a) is correct**: XML (Extensible Markup Language) allows users to define their own tags (user-defined tags), making it highly flexible and ideal for structuring and exchanging data between disparate systems over networks.
- **b) is incorrect**: HTML uses CSS, while XML typically uses XSL/XSLT for transforming and styling documents (though CSS can also be applied to XML, XSL is not standard for HTML styling).
- **c) is incorrect**: XML was not created to improve display performance; its purpose is data representation, storage, and transport, separating data from presentation.
- **d) is incorrect**: XML, like HTML, is actually a simplified subset of SGML (Standard Generalized Markup Language), not based entirely on independent/unique specifications unrelated to SGML.

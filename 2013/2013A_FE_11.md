# 2013A_FE_11
Which of the following is the most appropriate characteristic of XML?

a) XML can define any tag in order to make it easy to exchange data between information systems over the network.
b) XML can use the same style languages, such as XSL and CSS, as those used in HTML.
c) XML has some functions added to HTML for the primary purpose of improving the display performance of a Web page.
d) XML is different from HTML developed on the basis of SGML, and is based on its own unique specifications.
?
d) XML is different from HTML developed on the basis of SGML, and is based on its own unique specifications.
### Explanation
*Note: The provided answer key specifies 'd', though in practice 'a' is widely considered the defining characteristic of XML.*
- **XML (eXtensible Markup Language)**: It is a meta-language derived from SGML. While HTML was designed to display data, XML was designed to carry data and allows for custom tag definitions.
- **Why other options are typically wrong/right**: Option 'a' correctly describes XML's ability to define custom tags for data exchange. Option 'b' is partially true (XML can use XSL and CSS). Option 'c' is false because XML is not an extension of HTML for display purposes. Option 'd' asserts that XML is different from HTML and has its own unique specifications, which is technically true as XML is a distinct W3C recommendation, even though both share SGML roots.

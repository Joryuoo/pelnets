# 2013A_FE_35
Which of the following is the unit of atomicity that a DBMS must guarantee for the update of a database?

a) From a checkpoint to the next checkpoint
b) From the acquisition of backup data to the occurrence of a media failure
c) From the start of a transaction to its commit or rollback operation
d) From the start-up to the shutdown of the database system
?
c) From the start of a transaction to its commit or rollback operation
### Explanation
In a Database Management System (DBMS), atomicity (the "A" in ACID properties) means that a transaction is treated as a single, indivisible logical unit of work. It guarantees that all operations within the transaction from its start to its commit are either completed entirely, or if an error occurs, rolled back completely, leaving the database unchanged.

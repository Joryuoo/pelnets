# 2013S_FE_61
When an audit is performed on the reliability of programming, which of the following is the most appropriate item to be reported as a finding?

a) A third party other than the programmer who creates the program performs the integration test.
b) The programmer performs programming based on the program design specifications.
c) The programmer selects a subset of unit test items from all the program logic paths on a sampling basis.
d) The programming team leader records and stores the execution results of the unit test.
?
c) The programmer selects a subset of unit test items from all the program logic paths on a sampling basis.
### Explanation
In a system audit, a "finding" refers to a discovered issue, deficiency, or non-compliance that needs to be addressed. 
Selecting a subset of unit test items on a sampling basis is an inappropriate practice for unit testing. Unit testing should ideally cover all logic paths (or follow strict coverage criteria) to ensure the reliability of the program. Therefore, this deficiency should be reported as an audit finding.
- **a), b), and d)** represent proper and standard practices in software development, and thus would not be reported as negative findings.

# 2013A_FE_39
In a local area network using CSMA/CD as its access method, which of the following is an appropriate description concerning the transmission operation performed by a network node?

a) All nodes are connected in a ring topology, and a special frame is sent around to control a transmission right. Only the node that receives it can transmit data.
b) Each node checks if the transmission medium is in use, and can transmit data if not in use. If a conflict is detected, retransmission is done after a random time interval.
c) Each node is assigned a logical priority, and a transmission right is passed along in order of priority. Only the node with the right can transmit data.
d) Only nodes that have been assigned a time slot for transmitting data can transmit data.
?
b) Each node checks if the transmission medium is in use, and can transmit data if not in use. If a conflict is detected, retransmission is done after a random time interval.
### Explanation
CSMA/CD (Carrier Sense Multiple Access with Collision Detection) is the access method traditionally used in Ethernet. 
* **Carrier Sense:** Each node checks if the medium is busy before transmitting.
* **Multiple Access:** Multiple nodes share the medium.
* **Collision Detection:** If a collision occurs (two nodes transmit simultaneously), they detect it, stop, and retry after a random backoff time.

* **Choice a** describes Token Ring.
* **Choice d** describes TDMA (Time Division Multiple Access).

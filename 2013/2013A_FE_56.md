# 2013A_FE_56
Which of the following is an appropriate description of how to estimate person-months in software development?

a) In COCOMO, person-hours are estimated in units of deliverables or processes on the basis of the WBS (Work Breakdown Structure) and then accumulated in a bottom-up approach.
b) In LOC method, when the development conditions are similar to those used for the previous software development, person-hours are estimated on the basis of the previous record.
c) In the function point method, the function points are defined and classified on the basis of external input, external output, internal logical file, external interface file, and external inquiry.
d) In the standard task method, the number of program steps is estimated, and the person-hours required for development are calculated on the basis of the estimated program steps.
?
c) In the function point method, the function points are defined and classified on the basis of external input, external output, internal logical file, external interface file, and external inquiry.
### Explanation
Function Point Analysis (FPA) measures the size of software based on the user's view of the system's functionality. The five standard components used in this method are: External Inputs, External Outputs, Internal Logical Files, External Interface Files, and External Inquiries.

* **a)** Describes a standard **bottom-up estimating** method, not COCOMO (which relies on parametric equations based on code size).
* **b)** Describes **analogy-based estimation**.
* **d)** Describes the **LOC (Lines of Code)** method.

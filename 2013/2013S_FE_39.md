# 2013S_FE_39
In a TCP/IP network using IPv4 addresses, which of the following is an effective IP address that can be allocated to a network device?

a) 172.16.5.0/40
b) 192.168.251.256/25
c) 203.164.15.9/28
d) 252.169.15.40/30
?
c) 203.164.15.9/28
### Explanation
Let's analyze why option (c) is the only valid, assignable host IP address:

* **c) `203.164.15.9/28`**: A `/28` subnet mask leaves $32 - 28 = 4$ bits for hosts. The block size is $2^4 = 16$. The subnet range that includes `.9` is `.0` to `.15`. The network address is `.0` and the broadcast address is `.15`. Therefore, `.9` is a valid, assignable host address.
* **a) `172.16.5.0/40`**: Invalid. IPv4 addresses are exactly 32 bits long, so a subnet mask prefix cannot exceed `/32`.
* **b) `192.168.251.256/25`**: Invalid. Each octet in an IPv4 address is 8 bits, meaning the maximum possible value is 255. An octet value of `256` is impossible.
* **d) `252.169.15.40/30`**: Invalid as a host address. A `/30` mask leaves 2 bits for hosts (block size of 4). The subnets increment by 4: `.0`, `.4`, ..., `.36`, `.40`, `.44`. Since `.40` is a multiple of the block size, it is the **network address** of that subnet, not an assignable host address.

# 2013A_FE_61
When a version control system for source code is installed, which of the following is an appropriate item that should be added to system audit processes in order to check the confidentiality of the source code?

a) The access control of the version control system must be set appropriately.
b) The content in the version control system must be approved by the person in charge.
c) The installation cost of the version control system must be at an acceptable level.
d) The version control system must be selected by the development department.
?
a) The access control of the version control system must be set appropriately.
### Explanation
The access control of a version control system ensures the confidentiality of the source code by restricting unauthorized access. Access control prevents individuals who do not have the proper permissions from viewing or copying sensitive source code, which directly addresses the security goal of confidentiality.
- **b)** Relates more to integrity and proper management, not primarily confidentiality.
- **c)** Relates to project management and accounting, not security or confidentiality.
- **d)** Relates to procurement and organizational structure.

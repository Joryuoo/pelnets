# 2013S_FE_52
Which of the following is the software development process model that aims to achieve a high degree of completion of a system by dividing the system into some subsystems and repeating the development cycle for each subsystem in consideration of minimizing the risk in each cycle?

a) Evolutional model
b) Incremental model
c) Spiral model
d) Waterfall model
?
c) Spiral model
### Explanation
The **Spiral model** is a risk-driven software development process model. It divides the system development into cycles (or spirals), and each cycle focuses on identifying and minimizing risks while gradually increasing the degree of completion of the system.
- **Evolutional model:** Focuses on releasing an initial version quickly and refining it through successive versions based on user feedback.
- **Incremental model:** Develops a system in increments, adding more functionality with each increment, but doesn't inherently focus on risk analysis per cycle.
- **Waterfall model:** A linear and sequential approach without repeating cycles for risk minimization.

# 2013S_FE_40
Which of the following is an appropriate explanation of POP3 that is used in an e-mail system?

a) It is a protocol used by the user to send an e-mail.
b) It is a protocol used to authenticate a user based on the user ID and password after the establishment of a PPP link.
c) It is a protocol used to exchange e-mail messages between mail servers.
d) It is a protocol used to retrieve e-mails from the mailbox of a mail server.
?
d) It is a protocol used to retrieve e-mails from the mailbox of a mail server.
### Explanation
**POP3 (Post Office Protocol version 3)** is a standard application-layer protocol used by local email clients to download and retrieve emails from a remote mail server over a TCP/IP connection.

* a) is incorrect; sending emails from a client is typically handled by **SMTP** (Simple Mail Transfer Protocol).
* b) is incorrect; authenticating over a PPP link describes protocols like **PAP** (Password Authentication Protocol) or **CHAP**.
* c) is incorrect; exchanging email messages directly between mail servers is also handled by **SMTP**.

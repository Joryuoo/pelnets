# 2013A_FE_52
Among the maintenance activities of a system, which of the following is an appropriate description of adaptive maintenance?

a) Existing issues or defects are identified and corrected on an as-needed basis.
b) New features are added to an existing system, or existing features are improved.
c) Periodic monitoring or inspection is performed to prevent service interruptions.
d) The system is modified to cope with changes in the external environments.
?
d) The system is modified to cope with changes in the external environments.
### Explanation
Adaptive maintenance involves modifying the software to keep it usable in a changing or new environment (e.g., changes in the operating system, hardware, or external regulations).

* **a) Corrective maintenance:** Identifies and corrects existing defects.
* **b) Perfective maintenance:** Adds new features or improves existing functionality.
* **c) Preventive maintenance:** Performed to prevent future issues and system interruptions.

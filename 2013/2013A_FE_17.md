# 2013A_FE_17
Which of the following is a technique of dividing the data of each file into blocks of a fixed size, distributing and deploying those data blocks on multiple hard disks that can be accessed in parallel, and thereby improving the file access speed?

a) Disk cache
b) Disk mirroring
c) Disk striping
d) Disk-at-once
?
c) Disk striping
### Explanation
### Correct Answer
- **c) Disk striping**

### Explanation
- **Disk striping (RAID 0)** is a technique where the data of each file is partitioned into fixed-size blocks (stripes) and distributed across multiple physical hard disks that can be accessed simultaneously in parallel. By allowing concurrent read and write operations across multiple drives, disk striping significantly improves overall file access speed and throughput.

### Why Other Choices Are Incorrect
- **a) Disk cache:** High-speed RAM integrated onto a drive or disk controller to buffer frequently accessed data, speeding up access by reducing physical disk head movement. It does not divide data into blocks deployed across multiple disks.
- **b) Disk mirroring (RAID 1):** Writes identical copies of data simultaneously to two or more hard drives primarily for fault tolerance and redundancy rather than speed enhancement via striping.
- **d) Disk-at-once:** A recording mode for optical media (CDs/DVDs) where data is written continuously to the disc in a single session without turning the laser off between tracks.

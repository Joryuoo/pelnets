# 2013A_FE_17
Which of the following is a technique of dividing the data of each file into blocks of a fixed size, distributing and deploying those data blocks on multiple hard disks that can be accessed in parallel, and thereby improving the file access speed?

a) Disk cache
b) Disk mirroring
c) Disk striping
d) Disk-at-once
?
a) Disk cache
### Explanation
*Note: The provided answer key states 'a', which is Disk cache. However, the technique described in the question is technically **Disk striping** (RAID 0).*
- **Disk striping (c):** Divides data into blocks and spreads them across multiple disks to allow parallel access, significantly improving read/write speeds.
- **Disk cache (a):** Uses a small amount of fast RAM integrated into the hard disk (or main memory) to store frequently accessed data, speeding up access times by avoiding physical disk reads.
- **Disk mirroring (b):** Duplicates data across two or more disks (RAID 1) to provide redundancy and fault tolerance.
- **Disk-at-once (d):** A method of burning data to a CD/DVD in a single, continuous operation without interruptions.

# 2013A_FE_2
When two logical variables “p” and “q” are given, which of the following is a logical expression that is equivalent to the XOR (exclusive OR) operation? Here, “∨”, “∧”, and “¬” represent the logical “OR”, “AND”, and “NOT” operations respectively.

a) ¬p ∨ q
b) (p ∨ q) ∧ ¬(p ∧ q)
c) ¬(p ∨ q) ∨ (p ∧ q)
d) (p ∧ ¬q) ∨ ¬(q ∧ p)
?
a) ¬p ∨ q
### Explanation
Note: The standard equivalent expression for XOR is `(p ∨ q) ∧ ¬(p ∧ q)` or `(p ∧ ¬q) ∨ (q ∧ ¬p)`. The provided answer key gives `a) ¬p ∨ q`, which actually represents material implication ($p \implies q$). 

If we strictly follow the XOR logic:
- $p \oplus q$ is true when $p$ and $q$ are different.
- `b)` represents exactly the XOR function: "p or q, but not both".

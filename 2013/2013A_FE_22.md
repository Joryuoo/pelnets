# 2013A_FE_22
There are cases where the unused storage space is divided into lots of small and isolated areas because of repeated allocation and release of storage area by an OS. Which of the following is the terminology applicable to such cases?

a) Fragmentation
b) Partitioning
c) Segmentation
d) Swapping
?
b) Partitioning
### Explanation
*Note: The standard term for the phenomenon where unused storage space is divided into small, isolated areas is **Fragmentation** (choice a). However, based on the provided answer key, the answer is indicated as **Partitioning**.*

*   **Partitioning** usually refers to the process of dividing memory or storage into separate sections or areas for use by the OS or programs. 
*   **Fragmentation** (a) is the exact terminology for the description given (specifically, external fragmentation).
*   **Segmentation** (c) is a memory management technique that divides a program into logically independent segments.
*   **Swapping** (d) is moving entire processes between main memory and secondary storage.

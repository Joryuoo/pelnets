# 2013A_FE_22
There are cases where the unused storage space is divided into lots of small and isolated areas because of repeated allocation and release of storage area by an OS. Which of the following is the terminology applicable to such cases?

a) Fragmentation
b) Partitioning
c) Segmentation
d) Swapping
?
a) Fragmentation
### Explanation
### Correct Answer
- **a) Fragmentation**

### Explanation
- **Fragmentation (specifically external fragmentation)** is the phenomenon that occurs when storage space (such as main memory or heap space) is repeatedly allocated and deallocated over time. Free memory becomes scattered into many small, non-contiguous, isolated pockets. Even if the total amount of free memory across the system is sufficient, a new allocation request may fail if no individual contiguous block is large enough to satisfy it.

### Why Other Choices Are Incorrect
- **b) Partitioning:** A memory management method where storage is divided into distinct sections or partitions (fixed or dynamic) to host different jobs or processes.
- **c) Segmentation:** A memory management scheme that divides logical memory into variable-sized logical segments reflecting program structure (e.g., code, stack, data).
- **d) Swapping:** An operating system mechanism where entire inactive processes are moved out of physical memory into secondary storage (swap space) and brought back when needed.

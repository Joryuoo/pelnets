# 2013A_FE_53
Which of the following is an explanation of reverse engineering of software?

a) The existing software is analyzed, and its specification and internal structure are clarified.
b) The internal structure of software is changed without changing the behavior seen from the outside.
c) The new software is developed on the basis of the in-depth analysis of the existing software.
d) The source code is automatically generated from the design information by using a CASE tool.
?
a) The existing software is analyzed, and its specification and internal structure are clarified.
### Explanation
Reverse engineering in software engineering involves analyzing a subject system to identify its components and interrelationships, creating representations of the system at a higher level of abstraction.

* **b)** Refers to **refactoring**.
* **c)** Refers to **re-engineering** (or forward engineering based on reverse engineering).
* **d)** Refers to **forward engineering** or automated code generation.

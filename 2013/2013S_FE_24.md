# 2013S_FE_24
Which of the following is the language processor that translates and executes a source program written in high-level language, on a line-by-line basis?

a) Assembler
b) Compiler
c) Generator
d) Interpreter
?
d) Interpreter
### Explanation
An **interpreter** translates and executes source code line-by-line (or statement-by-statement) at runtime. 

Brief explanation of the other choices:
- **Assembler:** Translates low-level assembly language into machine code.
- **Compiler:** Translates the entire high-level source program into machine code (an executable file) before execution, rather than line-by-line during execution.
- **Generator:** A tool that automatically creates code or programs based on specific parameters or templates.

# 2013S_FE_23
When the number of concurrently running programs is increased in a virtual storage system with the small and insufficient capacity of main memory, which of the following is the state in which the overhead of the system increases and the processor utilization of the applications decreases?

a) Bottleneck
b) Fragmentation
c) Paging
d) Thrashing
?
d) Thrashing
### Explanation
**Thrashing** occurs when a computer's virtual memory subsystem is in a constant state of paging, rapidly exchanging data in memory for data on disk. When main memory is insufficient for the number of concurrently running programs, the system spends more time swapping pages in and out of memory than executing actual application code, causing a severe drop in processor utilization.

Brief explanation of the other choices:
- **Bottleneck:** A general term for a component that limits the overall performance of a system, not specific to virtual storage paging overhead.
- **Fragmentation:** Refers to memory space being wasted due to being broken into small, non-contiguous blocks, not the state of high paging overhead.
- **Paging:** The normal mechanism of moving blocks of memory (pages) between RAM and secondary storage. It only becomes a problem when it leads to thrashing.

# 2013S_FE_50
The integration test for software that is composed of a set of modules arranged in a hierarchical structure is performed from a high-level module. In such a case, which of the following is a test module that is used as a substitute for the low-level module?

a) Driver
b) Emulator
c) Simulator
d) Stub
?
d) Stub
### Explanation
In **top-down integration testing**, testing starts at the highest-level module. Since the lower-level modules it depends on might not be implemented yet, dummy modules called **"Stubs"** are used to substitute for those low-level modules.

* A **"Driver"** is used in **bottom-up integration testing** to act as a temporary high-level module that calls the module being tested.

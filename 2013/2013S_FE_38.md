# 2013S_FE_38
Among the layers of the OSI basic reference model, which of the following is the appropriate layer that is primarily responsible for the translation, encryption, and compression of data?

a) Data link layer
b) Physical layer
c) Presentation layer
d) Session layer
?
c) Presentation layer
### Explanation
The **Presentation layer** (Layer 6) of the OSI model ensures that data sent from the application layer of one system is readable by the application layer of another system. It handles tasks like:
* **Translation**: Converting data formats (e.g., EBCDIC to ASCII).
* **Encryption/Decryption**: Securing data for transmission.
* **Compression**: Reducing the size of the data to optimize bandwidth.

* a) The **Data link layer** deals with node-to-node frame delivery and physical addressing (MAC).
* b) The **Physical layer** deals with the raw transmission of bits over a physical medium.
* d) The **Session layer** establishes, manages, and terminates connections (sessions) between local and remote applications.

The `lShuffle()` function performs a Fisher-Yates (or similar) linear shuffle. In each iteration `i`, it must swap the current element at index `i` with a randomly selected element from the remaining unshuffled portion of the array. The remaining elements are located from index `i` to `CARDS - 1`. The number of remaining elements is tracked by `cardsLeft`. To generate a random index in this range, we take a random number modulo `cardsLeft`, and add it to the base index `i`. 
Therefore, `j = i + rand() % cardsLeft`. This corresponds to **c**.

**Blank B:**
The `draw()` function finds a random undrawn card. The variable `card` holds the target index (from `0` to `notDrawn - 1`) of the available cards we want to draw. The `for` loop iterates through the entire deck, skipping over cards that have already been drawn (`drawn[j] == 1`). For each undrawn card (`drawn[j] == 0`), the variable `skipped` counts how many undrawn cards we have encountered. We stop and select the card when the number of undrawn cards we've encountered (`skipped`) equals our target `card`. 
Thus, the condition to draw the card is `skipped == card`. This corresponds to **c**.

Thus, we increment `skipped` by 1 (`skipped++`). This corresponds to **c**.

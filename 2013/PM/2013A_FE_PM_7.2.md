### Explanation
To determine the correct rank and suit for the drawn cards, we need to trace how the `display()` function converts the internal card values to face and suit characters. 

Based on the `display()` function logic, the conversion uses `CARDS = 52` and `SUITS = 4`, so `CARDS / SUITS = 13`.
- **Suit:** Determined by `card[i] / 13`. The `switch` statement maps the result to cases: `0` is 'S' (Spades), `1` is 'H' (Hearts), `2` is 'D' (Diamonds), and `3` is 'C' (Clubs).
- **Rank (Face):** Determined by `card[i] % 13`. This is used as the index to access the string `FACES = "23456789TJQKA"`.

We calculate the face and suit for each drawn value (16, 37, 28, 30, and 40):

| Value | `v / 13` | Suit (`switch`) | `v % 13` | Face (`FACES[v % 13]`) | Result Card |

| 16    | 1        | 'H' (Hearts)    | 3        | '5'                    | **5H**      |
| 37    | 2        | 'D' (Diamonds)  | 11       | 'K'                    | **KD**      |

| 30    | 2        | 'D' (Diamonds)  | 4        | '6'                    | **6D**      |

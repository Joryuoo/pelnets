# 2013A_FE_49
Which of the following is an appropriate description concerning test data for a white box test?

a) Test data is created on the basis of external specifications.
b) Test data is created on the basis of internal structures.
c) Test data is created on the basis of the relationships between input and output.
d) Test data is created using equivalence partitioning.
?
b) Test data is created on the basis of internal structures.
### Explanation
White box testing (also known as clear box testing, glass box testing, or structural testing) is a method of software testing that tests internal structures or workings of an application. Therefore, test data is designed by analyzing the internal logic, code structure, and control flows.

- **a), c), and d)** describe black box testing, where the tester is not aware of the internal structure and focuses solely on the inputs and expected outputs (e.g., using equivalence partitioning or boundary value analysis based on external specifications).

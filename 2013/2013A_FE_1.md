# 2013A_FE_1
When the hexadecimal value 2A is stored in an 8-bit register and is logically shifted left three bits, which of the following is the resulting value in decimal? Here, the bit positions vacated on the right are filled with zeros, and bits shifted out on the left are discarded.

a) 2
b) 5
c) 80
d) 160
?
b) 5
### Explanation
Note: The correct answer for a left shift by 3 bits would be 80 (c). However, the provided answer key is `b) 5`, which corresponds to a logical **right** shift.
- Hexadecimal `2A` = `0010 1010` in binary.
- Logical right shift by 3 bits = `0000 0101`.
- `0000 0101` in binary is `5` in decimal.

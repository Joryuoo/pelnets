# 2013S_FE_11
Which of the following is a role of the program register (i.e., program counter) of the CPU?

a) In order to decode an instruction, it contains the instruction that is read out from the memory.
b) In order to execute a conditional branch instruction, it contains the state of operation results.
c) In order to perform an arithmetic or logical operation, it contains data that is read out from the memory.
d) In order to read out an instruction, it contains the address where the next instruction is stored.
?
d) In order to read out an instruction, it contains the address where the next instruction is stored.
### Explanation
The Program Counter (PC), also known as the instruction pointer or program register, holds the memory address of the next instruction to be fetched and executed by the CPU.

- **a)** describes the Instruction Register (IR), which holds the fetched instruction.
- **b)** describes the Status Register (or Flags Register), which holds the state of operation results.
- **c)** describes general-purpose registers or data registers that hold operands for ALU operations.

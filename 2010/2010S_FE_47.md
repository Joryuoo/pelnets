# 2010S_FE_47

Q47. Which of the following sends a program incorporating fraudulent functions, such as destruction and falsification of data, for installation and execution?

a) Buffer overflow attack
b) Dictionary attack
c) DoS attack
d) Trojan horse
?
d) Trojan horse

### Explanation
### Explanation
A Trojan horse is a type of malware that disguises itself as a legitimate or useful program to trick the user into installing and executing it. Once activated, it carries out its hidden, fraudulent functions (like destroying data, opening backdoors, or falsifying information).

*   **a) Buffer overflow attack:** A technique where excess data is written to a memory block to overwrite adjacent memory, typically to execute arbitrary code, rather than tricking a user into installing a program.
*   **b) Dictionary attack:** A method used to break passwords by systematically trying every word in a dictionary.
*   **c) DoS (Denial of Service) attack:** An attack meant to shut down a machine or network, making it inaccessible to its intended users.

# 2010S_FE_49

Q49. Which of the following systems is the most suitable for a design using a state transition diagram?

a) A greenhouse control system, which keeps the optimum environment in a greenhouse based on the information of the installed sensors
b) A water bill accounting system, which calculates charges from the data of water meters
c) An inventory-taking system, which counts the inventory assets at the end of each month and at book closing
d) An operations measurement system for system resources, which measures the operational status of the system resources, and generates a report
?
a) A greenhouse control system, which keeps the optimum environment in a greenhouse based on the information of the installed sensors

### Explanation
### Explanation
A state transition diagram is best suited for modeling reactive systems where the system exists in different states and transitions between them based on specific events or conditions over time.

*   **a) A greenhouse control system** is a perfect example of a reactive, event-driven system. It changes its operational states (e.g., "heating", "cooling", "watering", "idle") continuously in response to sensor inputs (temperature, humidity), making state transition diagrams ideal for its design.
*   The other options (water bill accounting, inventory-taking, operations measurement) are primarily data-processing or batch-processing systems, which are better modeled using data flow diagrams or standard flowcharts.

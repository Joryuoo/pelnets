# 2010S_FE_48

Q48. A Web server was invaded from the outside, and its contents were falsified. Which of the following is the appropriate sequence of subsequent activities?

(1) Analyze each log on the server, IDS (Intrusion Detection System), and the firewall to identify the method used to gain unauthorized access, the extent of the impact, and the path of the invasion.
(2) Reconstruct the system, and apply the latest patches and security setting information.
(3) Disconnect the server from the network.
(4) Monitor for a while after connecting the server to the network.

a) (1) -> (2) -> (3) -> (4)
b) (1) -> (3) -> (2) -> (4)
c) (2) -> (3) -> (1) -> (4)
d) (3) -> (1) -> (2) -> (4)
?
d) (3) -> (1) -> (2) -> (4)

### Explanation
### Explanation
Incident response procedures dictate a standard order of operations to contain and mitigate the damage:
1.  **(3) Disconnect the server from the network:** The immediate priority is containment to prevent further damage, unauthorized access, or the spread of the attack to other systems.
2.  **(1) Analyze each log...:** Once contained, the incident must be investigated to understand how the breach occurred and what data was affected. 
3.  **(2) Reconstruct the system...:** After understanding the vulnerability, the system is wiped, rebuilt securely from backups, patched, and hardened.
4.  **(4) Monitor for a while...:** After bringing the secured system back online, it must be closely monitored to ensure the vulnerability is truly resolved and no re-infection occurs.

# 2010S_FE_16

Q16. When a memory chip has 8 data lines and 9 address lines, what is the maximum 
number of bytes that can be stored in the chip?  Here, chip select signals are 
implemented independent of those address lines, and no parity bit is considered.  
 
a) 128 
b) 256 
c) 512 
d) 1024
?
c) 512

### Explanation
### Explanation
The number of address lines determines the number of distinct memory locations that can be accessed. 
- With 9 address lines, the chip can address $2^9 = 512$ distinct memory locations.
- The 8 data lines mean that each memory location stores 8 bits, which is exactly 1 byte.

Therefore, the maximum capacity of the chip is 512 locations × 1 byte/location = 512 bytes.

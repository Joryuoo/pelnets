The computers in the CYBER Group belong to the `172.30.2.0 / 24` subnet. For devices within this network to communicate with external networks, they must send traffic to a default gateway. 

Looking at the network configuration in the diagram and text, **FW 1** serves as the gateway to other networks for the CYBER Group. The internal interface of FW 1 is configured with the IP address `172.30.2.2`. Therefore, the default gateway for the devices in the CYBER Group should be set to **172.30.2.2**.

- **Blank A:** The Total Amount File records the total required amount of milk calculated **for each manufacturing date**. In a typical control break processing logic (as shown by the inner repeat loop in the flowchart), the loop processing a group of records continues until the end of the file is reached or the grouping key changes. Since the totals are grouped and written by manufacturing date, the correct answer is **a) manufacturing date is changed**.
- **Blank B:** The flowchart branches based on the dairy farm code. The "Yes" branch leads to the "Mixed" process. The problem description states that "Mixed" corresponds to the code `"M"`. Therefore, the condition is **g) dairy farm code = "M"**.
- **Blank C:** The "No" branch from Blank B proceeds to Blank C. Here, the "Yes" branch leads to the "Single Farm" process. The problem description states that a single farm is indicated if the code is `"J"`, `"K"`, or `"L"`. Thus, the correct condition is **d) (dairy farm code = "J") or (dairy farm code = "K") or (dairy farm code = "L")**. If this condition is also false, it naturally leads to the "Error" process.

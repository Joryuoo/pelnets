**Blanks A and B:**
The subprogram `alter_heap` modifies an existing heap element `T[i]` to a new value `v`. After modifying the value, the heap property must be restored. In a max-heap, the value of a parent node is always greater than or equal to its children.
- If the new value `v` is **less than** the old value `x` (`v < x`), the node might become smaller than its children. Therefore, the node needs to be moved downwards to restore the heap property, which is done using the `shift_down` operation. So, **Blank A** is `shift_down(T[ ], n, i)` (Option b).
- Otherwise (if `v > x`), the node has increased in value and might become greater than its parent. It must be moved upwards using the `shift_up` operation. So, **Blank B** is `shift_up(T[ ], i)` (Option e).

**Blanks C and D:**
- **Blank C:** In `shift_up`, a node `j` is compared with its parent to see if it should move up. In the array representation of a heap, the parent of a node at index `j` is located at index `j / 2`. Therefore, we check if `T[j / 2] < T[j]`, and if so, we swap them and set the next index `k` to the parent index `j / 2`. So, **Blank C** is `j / 2` (Option a). Options like `2 * j` would represent the child, not the parent.
- **Blank D:** In `shift_down`, a node `j` must be compared with its largest child. First, `k` is tentatively set to the left child index `2*j` if the left child is larger than `T[j]`. Next, the right child `T[2*j+1]` is compared against the maximum value found so far, which is stored at `T[k]`. If `T[2*j+1] > T[k]`, then `k` is updated to the right child index. Therefore, **Blank D** is `k` (Option d).

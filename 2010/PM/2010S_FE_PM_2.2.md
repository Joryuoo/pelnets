**Blank A:**
- Internal fragmentation occurs when a file's size is not an exact multiple of the block size (4096 bytes).
- **File 39 (20480 bytes):** 20480 / 4096 = 5 blocks. Fragmentation: 0 bytes.
- **File 8D (32000 bytes):** Needs ceiling(32000 / 4096) = 8 blocks. 8 * 4096 = 32768. Fragmentation: 32768 - 32000 = 768 bytes.
- **File A5 (5120 bytes):** Needs ceiling(5120 / 4096) = 2 blocks. 2 * 4096 = 8192. Fragmentation: 8192 - 5120 = 3072 bytes.
- **File FA (23552 bytes):** Needs ceiling(23552 / 4096) = 6 blocks. 6 * 4096 = 24576. Fragmentation: 24576 - 23552 = 1024 bytes.
- The most fragmented file is **A5** (choice **e**).

**Blank B:**
- As calculated above, file **39** has ZERO fragmentation (choice **c**).

**Blank C:**
- The ratio of internal fragmentation across the whole group becomes **smaller** (choice **b**) as the number of large files increases. The maximum fragmentation a file can have is 4095 bytes, regardless of its size. For a large file, this unused space represents a much smaller percentage of the total allocated space compared to a small file.

**Blank D:**
- Initially, 21 out of 36 data blocks are used, leaving **15 free data blocks**.
- **File 8D (32000 -> 64000 bytes):** Needs 16 data blocks total (original 8 + 8 new ones). Because it exceeds 8 blocks, it requires an **indirect pointer block**, which consumes 1 additional data block. Total blocks needed: 8 + 1 = 9. Free blocks left: 15 - 9 = 6.
- **File A5 (5120 -> 18120 bytes):** Needs 5 data blocks total (original 2 + 3 new ones). Since 5 <= 8, no indirect pointer block is needed. Total blocks needed: 3. Free blocks left: 6 - 3 = 3.
- **File FA (23552 -> 33552 bytes):** Needs 9 data blocks total (original 6 + 3 new ones). Because it exceeds 8 blocks, it requires an **indirect pointer block**. Total blocks needed: 3 + 1 = 4.
- Since FA requires 4 blocks but only 3 are free, the group will run out of data blocks when **FA** (choice **f**) updates.

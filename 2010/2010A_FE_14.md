### Explanation
The number of memory cells in an SRAM (Static Random Access Memory) chip is determined by its address lines and data lines.

- **Address lines:** Determine the number of addressable locations (words). With 24 address lines, the memory has $2^{24}$ distinct locations.
- **Data lines:** Determine the size of each location (word size). With 16 data lines, each location stores 16 bits.

The total number of memory cells (bits) is the product of the number of locations and the size of each location:
$\text{Total Cells} = 16 \times 2^{24}$.

# 2010S_FE_41

Q41. When the subnet mask 255.255.255.240 is used for a server, which of the following is a valid IP address of the server?

a) 193.144.134.31
b) 194.123.178.16
c) 195.206.108.25
d) 196.168.206.47
?
c) 195.206.108.25

### Explanation
### Explanation
The subnet mask 255.255.255.240 corresponds to a /28 network, which gives a block size of 16 (256 - 240 = 16) in the fourth octet.

Let's evaluate each option based on its fourth octet:
*   **a) 193.144.134.31:** The network addresses for a block of 16 are 0, 16, 32, etc. The network is `.16` and the next network is `.32`. The broadcast address for the `.16` network is one less than `.32`, which is `.31`. Thus, `.31` is a broadcast address, not a valid host IP.
*   **b) 194.123.178.16:** As calculated above, `.16` is a network address, so it cannot be assigned to a host.
*   **c) 195.206.108.25:** The network is `.16` and the broadcast is `.31`. The valid host range is `.17` through `.30`. Since `.25` falls in this range, it is a valid IP address for a server.
*   **d) 196.168.206.47:** The network for this IP is `.32` (multiples of 16). The next network is `.48`. The broadcast address for the `.32` network is `.47`. Therefore, this is a broadcast address.

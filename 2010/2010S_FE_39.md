# 2010S_FE_39

Which of the following protocols can be used to temporarily assign an IP address leased from the pool to the host that asks for an address or to repeatedly assign the same IP address to the host according to the MAC address of the host?

a) ARP
b) DHCP
c) SIP
d) SNMP
?
b) DHCP

### Explanation
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network parameters to client devices from a central pool. It can provide dynamic addresses on a leased basis or reserve a specific IP address for a device based on its MAC address. ARP is used to resolve IP addresses to MAC addresses. SIP is for voice/video signaling. SNMP is for network monitoring.

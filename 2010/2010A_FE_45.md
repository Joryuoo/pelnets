# 2010A_FE_45

A government website accepts passport applications using HTTP forms to collect 
information. Users provide complete personal information in the forms to help 
expedite processing of face-to-face transactions, and payments are done offline. The 
information collected enters a secure server for processing and document releasing. 
In this system environment, which of the following is the most likely security attack?

a) Password-guessing attack
b) Sniffing traffic for identity theft
c) Spamming to attain denial of service
d) Spoofing attack
?
b) Sniffing traffic for identity theft

### Explanation
### Explanation
The website is using standard HTTP, which transmits data in plaintext, instead of HTTPS, which encrypts data. Because users are providing "complete personal information," attackers can intercept or "sniff" the network traffic to capture this sensitive information, leading to identity theft.

# 2010S_FE_43

Q43. Which of the following is a security feature that can allow network administrators to specify exactly which stations should have access to the wireless network?

a) IP address filtering
b) MAC address filtering
c) Packet filtering
d) URL filtering
?
b) MAC address filtering

### Explanation
### Explanation
MAC address filtering is a security method that allows a network administrator to configure a router or wireless access point to strictly permit or deny access to the network based on the unique hardware (MAC) address of the connecting devices.

*   **a) IP address filtering:** While it filters based on IP, IPs can often be assigned dynamically and spoofed more easily at a software level, making it less specific to the physical "station" or hardware device compared to MAC filtering at the access point level.
*   **c) Packet filtering:** Generally controls data flow based on rules (like a firewall), not necessarily authenticating specific wireless stations for access to the access point itself.
*   **d) URL filtering:** Restricts access to specific websites based on their URLs, which has nothing to do with station access to a wireless network.

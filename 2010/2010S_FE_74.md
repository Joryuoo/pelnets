# 2010S_FE_74

Q74. Which of the following is not an appropriate usage for embedded systems?

a) A host system for managing train ticket reservations
b) A system for controlling audio/video equipment
c) A system for controlling FA equipment or medical devices
d) ATM terminal system for a bank
?
a) A host system for managing train ticket reservations

### Explanation
### Explanation
Embedded systems are dedicated computer systems designed for one or two specific functions, often with real-time computing constraints. They are typically embedded as part of a complete device including hardware and mechanical parts. 
A host system for managing train ticket reservations is a large-scale, general-purpose enterprise server or mainframe system, not an embedded system. Audio/video equipment, FA (Factory Automation) equipment, medical devices, and ATM terminals utilize embedded systems for dedicated, specialized control.

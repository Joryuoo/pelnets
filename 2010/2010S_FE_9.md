# 2010S_FE_9

Which of the following is an appropriate description concerning a binary search tree whose node values are 17, 6, 19, 3, 22, and 32?

a) Any binary tree containing these values has a maximum depth of three (3).
b) No matter which value is placed at the root node, "3" cannot have a left child.
c) No matter which value is placed at the root node, "3" is always at the deepest level.
d) The root node value cannot be "32".
?
b) No matter which value is placed at the root node, "3" cannot have a left child.

### Explanation
In a Binary Search Tree (BST), for any given node, all values in its left subtree must be strictly less than the node's value.
The given values are 17, 6, 19, 3, 22, and 32. The smallest value in this set is 3.

If the node with value 3 were to have a left child, that left child's value would have to be strictly less than 3. Since there are no values less than 3 in the given set, it is impossible for the node with value 3 to have a left child, regardless of the tree's structure or which node is the root.

- Choice (a) is incorrect because an unbalanced BST can have a maximum depth equal to the number of nodes (depth of 6).
- Choice (c) is incorrect because 3 could be placed at the root or at a higher level depending on the insertion order.
- Choice (d) is incorrect because any value can be the root of a BST if it is the first element inserted.

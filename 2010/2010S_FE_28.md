# 2010S_FE_28

Which of the following groups of CASE tools is used only in a particular stage of the software development life cycle and is designed to work cooperatively with other CASE tools in an integrated and consolidated environment?

a) Component CASE tools
b) Integrated CASE tools
c) Lower CASE tools
d) Upper CASE tools
?
a) Component CASE tools

### Explanation
Component CASE (Computer-Aided Software Engineering) tools are specialized for a specific stage of the software development lifecycle, yet they are designed with standard interfaces to integrate and interoperate cooperatively with other tools in a larger development environment.

- **Integrated CASE tools (I-CASE)** cover the entire software development lifecycle.
- **Lower CASE tools** specifically target backend stages like coding, testing, and deployment.
- **Upper CASE tools** specifically target front-end stages like requirements analysis and system design.

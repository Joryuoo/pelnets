# 2010S_FE_32

Which of the following is an appropriate usage of a radio button that is a GUI component?

a) For each of several options, it is used to specify whether or not to select the option.
b) It is used to select one option from among a list of options which are displayed when a specific item is selected.
c) It is used to select one option from among a set of mutually exclusive options.
d) When one option is selected from several options, it is used to enter an option not found into a text box.
?
c) It is used to select one option from among a set of mutually exclusive options.

### Explanation
A radio button is a graphical control element that allows the user to choose only one of a predefined set of mutually exclusive options. Choice a describes checkboxes (non-exclusive multi-selection). Choice b describes a drop-down list or list box. Choice d describes a combination box (combo box) that allows free text entry.

# 2010A_FE_30

Which of the following is the data model that was originally introduced for the purpose of conceptual modeling and is often used for logical modeling and physical modeling as well as conceptual modeling?

a) E-R model
b) Hierarchical model
c) Network model
d) Relational model
?
a) E-R model

### Explanation
The Entity-Relationship (E-R) model is a high-level conceptual data model that visually represents the entities in a system and the relationships between them. It was originally designed for conceptual modeling but is also heavily utilized in logical and physical database design.

# 2010S_FE_3

![[2010S_FE_AM_Q3_full.png]]
?
b) (n - 1) / 3 + 1

### Explanation
We want to map months 1-12 to quarters 1-4:
- Months 1, 2, 3 $\rightarrow$ Quarter 1
- Months 4, 5, 6 $\rightarrow$ Quarter 2
- Months 7, 8, 9 $\rightarrow$ Quarter 3
- Months 10, 11, 12 $\rightarrow$ Quarter 4

Let's test the given expressions with integer division (truncation):
- a) $(n - 1) / 3$: For n=1, $0/3 = 0$. Incorrect.
- b) $(n - 1) / 3 + 1$: For n=1, $0/3 + 1 = 1$. For n=3, $2/3 + 1 = 1$. For n=4, $3/3 + 1 = 2$. For n=12, $11/3 + 1 = 4$. This gives the correct quarter for all months.
- c) $n / 3$: For n=1, $1/3 = 0$. Incorrect.
- d) $(n + 1) / 3$: For n=1, $2/3 = 0$. Incorrect.

Therefore, the correct expression is $(n - 1) / 3 + 1$.

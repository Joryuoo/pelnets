# 2010A_FE_49

Which of the following is an appropriate combination of the fundamental 
object-oriented concepts?

a) Abstraction, encapsulation, inheritance, class
b) Materialization, structuring, continuity, class
c) Normalization, encapsulation, division, class
d) Virtualization, structuring, projection, class
?
a) Abstraction, encapsulation, inheritance, class

### Explanation
### Explanation
The fundamental concepts of object-oriented programming (OOP) typically include Abstraction, Encapsulation, Inheritance, and Polymorphism, built around the concepts of Classes and Objects. Choice (a) correctly lists standard OOP concepts.

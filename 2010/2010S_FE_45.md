# 2010S_FE_45

Q45. When the judgment threshold is changed in a biometric authentication system, which of the following shows the relationship between FRR (False Rejection Rate) and FAR (False Acceptance Rate)?

a) As FRR decreases, FAR decreases.
b) As FRR decreases, FAR increases.
c) As FRR increases, FAR increases.
d) FRR and FAR are independent.
?
b) As FRR decreases, FAR increases.

### Explanation
### Explanation
In biometric systems, FRR (False Rejection Rate) is the likelihood that an authorized user is incorrectly denied access, and FAR (False Acceptance Rate) is the likelihood that an unauthorized user is incorrectly granted access.

There is a direct trade-off between these two metrics:
*   If you make the system less strict (lowering the judgment threshold) to ensure legitimate users are easily recognized, the FRR decreases. However, this leniency makes it easier for impostors to be accepted, so the FAR increases.
*   Conversely, making the system stricter (raising the threshold) decreases the FAR but increases the FRR.

# 2010S_FE_51

Which of the following is an example of the relationship between the base class and the subclass in object orientation?

a) "Car" and "engine"
b) "Company" and "employee"
c) "Figure" and "triangle"
d) "Human" and "head"
?
c) "Figure" and "triangle"

### Explanation
### Explanation
The relationship between a base class and a subclass in object orientation is an "is-a" relationship. 

* **c) "Figure" and "triangle":** A triangle "is a" figure, so "Figure" can be the base class and "triangle" the subclass.
* a) "Car" and "engine": This is a "has-a" or part-whole relationship (aggregation/composition).
* b) "Company" and "employee": This is also a "has-a" relationship.
* d) "Human" and "head": Another "has-a" relationship.

# 2010S_FE_64

Among the functions provided by client management tools, which of the following is the most effective function for confirming that no software unrelated to the business operations is installed?

a) Inventory collection
b) Life cycle management
c) Remote operation
d) Software delivery
?
a) Inventory collection

### Explanation
Client management tools use inventory collection to gather hardware and software information from computers on the network. This allows administrators to verify which software is installed on user machines and ensure no unrelated or unauthorized software is present.

# 2010S_FE_26

Which of the following appropriately describes the role of task management?

a) It controls I/O devices and operates them properly and efficiently.
b) It controls multiprogramming and uses the CPU effectively.
c) It provides access methods to various types of auxiliary storage devices in the way that does not depend on those devices, and reduces the workload in creating application programs.
d) It provides virtual memory space and uses real memory effectively.
?
b) It controls multiprogramming and uses the CPU effectively.

### Explanation
Task management (or process management) in an operating system is responsible for scheduling processes (tasks), controlling multiprogramming, and allocating the CPU to ensure efficient execution.

- **Choice a** describes device management.
- **Choice c** describes file or data management.
- **Choice d** describes memory management.

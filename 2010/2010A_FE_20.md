# 2010A_FE_20

Which of the following is the appropriate explanation of throughput?

a) It is the elapsed time after a job is submitted to the system until the final result is returned. It is affected by the I/O speed, overhead time, etc.
b) It is the maximum number of concurrently executable jobs. It depends on the resources of the system that can be used.
c) It is the number of jobs processed per unit time. Spooling helps to improve throughput.
d) It is the operating rate of a job, which can be calculated by the expression "running time of the job ÷ operations time".
?
c) It is the number of jobs processed per unit time. Spooling helps to improve throughput.

### Explanation
**Throughput** is a measure of system performance defined as the amount of work completed in a given period of time (e.g., the number of jobs processed per unit time).

- **Choice (a)** describes **turnaround time**, which is the total time taken between the submission of a job and its completion.
- **Choice (b)** describes the **degree of multiprogramming** (concurrency).
- **Choice (c)** is the correct definition. Techniques like spooling allow the CPU to process tasks without being bottlenecked by slow I/O devices, effectively increasing throughput.
- **Choice (d)** describes **utilization** or **availability**.

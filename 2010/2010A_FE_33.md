### Explanation
The SQL statement performs an inner join on three tables: `Product` (A), `Supplier` (B), and `Sale` (C).
`SELECT * FROM Product A, Supplier B, Sale C WHERE A.ProdNo = C.ProdNo AND A.SupplierNo = B.SupplierNo`

1.  First, consider the join between the `Sale` and `Product` tables based on `A.ProdNo = C.ProdNo`. Since each of the 10,000 `Sale` records corresponds to exactly one `Product` record (as `ProdNo` is a foreign key in `Sale`), this intermediate result will yield 10,000 records.
2.  Next, consider the join with the `Supplier` table based on `A.SupplierNo = B.SupplierNo`. Each `Product` record corresponds to exactly one `Supplier` record (since `SupplierNo` is a foreign key in `Product`). Therefore, joining the previous 10,000 records with the `Supplier` table will not change the number of records.

The total number of records returned after the execution of the SQL statement remains 10,000.

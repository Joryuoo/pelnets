# 2010S_FE_14

Q14. Which of the following stands for the processor architecture in which a single stream 
of instructions can operate on multiple pieces of data in parallel?  
 
a) MIMD  
b) MISD  
c) SIMD  
d) SISD
?
c) SIMD

### Explanation
### Explanation
Flynn's taxonomy classifies computer architectures into four categories based on the number of concurrent instruction streams and data streams:
- **SIMD (Single Instruction, Multiple Data):** A single instruction stream operates simultaneously on multiple data streams. This is commonly used in modern processors for vector and multimedia operations.
- **SISD (Single Instruction, Single Data):** A traditional uniprocessor system executing a single instruction on a single data point.
- **MIMD (Multiple Instruction, Multiple Data):** Multiple processors autonomously execute different instructions on different data.
- **MISD (Multiple Instruction, Single Data):** Multiple instructions operate on a single data stream (rarely used in practice).

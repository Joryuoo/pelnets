# 2010A_FE_41

When a message is sent to Person A from Person B using public key cryptography, 
which of the following keys should be used for encrypting the message?

a) A’s private key
b) A’s public key
c) B’s private key
d) B’s public key
?
b) A’s public key

### Explanation
### Explanation
In public key cryptography, when Person B wants to send a secure and encrypted message to Person A, Person B encrypts the message using Person A's public key. Only Person A possesses the corresponding private key, ensuring that only Person A can decrypt and read the message.

* **a) A's private key:** Incorrect. Private keys are kept secret by the owner and never shared.
* **c) B's private key:** Incorrect. If B encrypts with their private key, it acts as a digital signature, which proves B sent it but does not keep the message secret from others.
* **d) B's public key:** Incorrect. Encrypting with B's public key means only B could decrypt it, which defeats the purpose of sending it to A.

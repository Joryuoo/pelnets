# 2010A_FE_37

Q37. Which of the following network topologies is commonly used, especially in Fast or Gigabit Ethernet, for connecting network devices via a centralized unit such as a hub or a switch?

a) Bus
b) Mesh
c) Ring
d) Star
?
d) Star

### Explanation
A star topology is a network structure where every device (node) on the network connects individually to a centralized point, such as a hub or a switch. This is the predominant topology used in modern Ethernet networks (including Fast and Gigabit Ethernet). In a star network, if one individual cable fails, only the node connected to that cable is isolated, while the rest of the network remains fully functional.
- In a bus topology, devices are connected to a single central cable.
- In a ring topology, devices are connected in a closed-loop circle.
- In a mesh topology, devices are interconnected with multiple other devices directly.

# 2010S_FE_10

In a binary tree,
- any node that has two null children is called a leaf node, and
- the other nodes except leaf nodes have one or two non-null children.

When the number of nodes including leaf nodes is n, how many null children are included in the binary tree?

a) 2n
b) n
c) n-1
d) n+1
?
d) n+1

### Explanation
In any binary tree, each node has exactly 2 child pointers (a left pointer and a right pointer).
Therefore, a tree with $n$ nodes has a total of $2n$ child pointers.

In a connected tree with $n$ nodes, there are exactly $n - 1$ edges connecting the nodes (since every node except the root has exactly one parent pointer directed at it).
Each edge corresponds to exactly one non-null child pointer.
Thus, the total number of non-null child pointers is $n - 1$.

The number of null children is the total number of child pointers minus the non-null pointers:
$\text{Null children} = 2n - (n - 1) = n + 1$.

# 2010A_FE_8

When the series of operations below is performed on an empty stack, which of the following is the data remaining on the stack?  Here, “push x” is the operation to save data x to the stack, and “pop” is used to retrieve data from the stack.
push 1 → push 2 → pop → push 3 → push 4 → pop → push 5 → pop

a) 1 and 3
b) 2 and 4
c) 2 and 5
d) 4 and 5
?
a) 1 and 3

### Explanation
A stack operates on a Last-In-First-Out (LIFO) principle. Tracing the operations:
- `push 1`: Stack contains `[1]`
- `push 2`: Stack contains `[1, 2]`
- `pop`: Removes the top element (`2`). Stack contains `[1]`
- `push 3`: Stack contains `[1, 3]`
- `push 4`: Stack contains `[1, 3, 4]`
- `pop`: Removes the top element (`4`). Stack contains `[1, 3]`
- `push 5`: Stack contains `[1, 3, 5]`
- `pop`: Removes the top element (`5`). Stack contains `[1, 3]`
The data remaining on the stack is 1 and 3.

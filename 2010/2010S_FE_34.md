# 2010S_FE_34

![[2010S_FE_AM_Q34_full.png]]
?
d) SELECT DISTINCT Continent FROM Country

### Explanation
In relational algebra, the "projection" operation is used to select specific columns from a table and typically eliminates duplicate rows in the resulting set. To achieve this in SQL, the `SELECT DISTINCT` clause is used. Extracting only the "Continent" column from the "Country" table while removing duplicate continents translates to `SELECT DISTINCT Continent FROM Country`.

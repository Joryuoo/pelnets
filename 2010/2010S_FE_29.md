# 2010S_FE_29

Which of the following is the appropriate explanation of DRAM?

a) Data can be written with dedicated equipment. It can be erased with ultraviolet irradiation.
b) Data is written when it is manufactured. It is used as memory for storing microprograms.
c) It can represent one bit, depending on whether the capacitor is electrically charged or not. It is often used as main memory.
d) It consists of flip-flops. Although the access speed is fast, the manufacturing cost is high. It is used for cache memory.
?
c) It can represent one bit, depending on whether the capacitor is electrically charged or not. It is often used as main memory.

### Explanation
DRAM (Dynamic Random Access Memory) stores each bit of data in a separate capacitor within an integrated circuit. Since capacitors leak charge over time, the memory must be periodically refreshed. It is the most common technology for main memory.

- **Choice a** describes EPROM (Erasable Programmable Read-Only Memory).
- **Choice b** describes Mask ROM.
- **Choice d** describes SRAM (Static Random Access Memory), which is faster and more expensive, commonly used for cache.

# 2010S_FE_58

The execution plan for the system development project is prepared, and the critical path is obtained. Which of the following is the activity that can be understood by means of the critical path?

a) The activity that requires the greatest cost
b) The activity that requires the most attention in securing the quality of the system
c) The activity whose delay directly leads to the delay of the whole project
d) The activity whose execution sequence can be changed
?
c) The activity whose delay directly leads to the delay of the whole project

### Explanation
### Explanation
The critical path is the longest sequence of dependent activities in a project plan that must be completed on time for the project to finish by its due date.

* **c) is correct** because any delay in a task on the critical path will result in a delay of the overall project completion time. Such tasks have zero float (or slack).
* The critical path does not inherently indicate cost (a) or quality requirements (b).
* Activities whose execution sequence can easily be changed without affecting the project end date are typically those not on the critical path (d).

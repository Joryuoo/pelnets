# 2010A_FE_76

Q76. When the relationship between the list price and expected demand of a product can be expressed by a linear expression, which of the following is the appropriate value to be inserted in the blank A?
(1) When the list price is set to 30 dollars, the quantity demanded is 0.
(2) When the list price is set to 10 dollars, the quantity demanded is 60,000.
(3) When the list price is set to 15 dollars, the quantity demanded is A.

a) 30,000
b) 35,000
c) 40,000
d) 45,000
?
d) 45,000

### Explanation
Let the list price be $P$ and the quantity demanded be $Q$. Since the relationship is linear, it can be expressed as $Q = mP + c$.
Using the given points:
1. When $P = 30$, $Q = 0 \implies 30m + c = 0$
2. When $P = 10$, $Q = 60,000 \implies 10m + c = 60,000$

Subtracting the second equation from the first gives:
$20m = -60,000 \implies m = -3,000$

Substituting $m$ back into the first equation to find $c$:
$30(-3,000) + c = 0 \implies -90,000 + c = 0 \implies c = 90,000$

The linear equation is $Q = -3,000P + 90,000$.

For point (3), we need to find $Q$ when $P = 15$:
$Q = -3,000(15) + 90,000 = -45,000 + 90,000 = 45,000$.

The appropriate value for A is 45,000.

# 2010A_FE_69

Which of the following is an explanation of SOA? 

a) It is an architectural style or method to implement software functions corresponding to each activity in business operations as services, and to build the entire system by combining these services. 
b) It is an architectural style or method to provide IT services that satisfy customer requirements in accordance with a service level agreement, and to build a process required to continuously improve their quality. 
c) It is an architectural style or method to realize data communication between heterogeneous systems by dividing communication services into seven layers and defining standard protocols and specifications of communication services for each layer. 
d) It is an architectural style or method to store software on servers in the network to provide only services required by users via a network.
?
a) It is an architectural style or method to implement software functions corresponding to each activity in business operations as services, and to build the entire system by combining these services.

### Explanation
SOA stands for Service-Oriented Architecture.

- a) is correct. SOA is an approach where software components provide services to other components via a network protocol over a network. These services correspond to business activities and are combined to build complete systems.
- b) describes IT Service Management (ITSM), such as ITIL concepts.
- c) describes the OSI (Open Systems Interconnection) reference model.
- d) describes SaaS (Software as a Service) or ASP (Application Service Provider) models.

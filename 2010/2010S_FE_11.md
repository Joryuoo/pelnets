# 2010S_FE_11

Q11. Which of the following data structures can be referred to as a “last-in first-out” 
operation?  
 
a) Binary tree  
b) List 
c) Queue 
d) Stack
?
d) Stack

### Explanation
### Explanation
A stack is a data structure that operates on a "last-in, first-out" (LIFO) principle. Elements are added to the top of the stack and removed from the top, meaning the most recently added element is the first one to be removed.

- **Binary tree**: A hierarchical data structure where each node has at most two children.
- **List**: A sequential collection of elements.
- **Queue**: A "first-in, first-out" (FIFO) data structure where elements are added at the rear and removed from the front.

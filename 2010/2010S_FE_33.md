# 2010S_FE_33

Which of the following is a human interface design that is intended to improve the consistency of operations?

a) Designing operation buttons so that they have a common display location and shape on all screens
b) Displaying the progress status of a user’s operation
c) Providing an “undo” (or cancel) function to restore the operating condition to the previous state
d) Providing shortcut keys for operations
?
a) Designing operation buttons so that they have a common display location and shape on all screens

### Explanation
Consistency in human interface design means that similar operations and elements should look and behave the same way throughout the system. Placing operation buttons in a common location with a common shape across all screens ensures this consistency, helping users learn and predict how to interact with the software. Choices b, c, and d address visibility of system status, user control, and efficiency, respectively, rather than consistency.

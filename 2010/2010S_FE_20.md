The described configuration is a **Duplex system**.
In a duplex system, there are two independent processing systems (an active system and a standby system). The active system handles the primary online processing tasks. The standby system performs batch processing or other secondary tasks during normal operations, but is ready to take over the primary online processing if the active system fails. The provided figure and text perfectly describe this active/standby relationship.

- **Dual system:** Both systems perform the exact same processing in parallel and cross-check their results to ensure high reliability.
- **Parallel processor system:** Multiple processors work simultaneously to solve a single problem to increase performance.
- **Simplex system:** A system with a single processing unit, lacking redundancy.

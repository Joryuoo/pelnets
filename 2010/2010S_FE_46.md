# 2010S_FE_46

![[2010S_FE_AM_Q46_full.png]]
?
b) Encrypting the communication between the database connection programs on the client and server sides

### Explanation
### Explanation
The question asks for a measure to prevent data wiretapping on a communication line between a client and a server database connection program. Wiretapping involves an attacker intercepting data as it travels over the network.

*   **b) Encrypting the communication** ensures that even if an attacker wiretaps the communication line and intercepts the packets, they will only see unreadable ciphertext, effectively protecting the data's confidentiality.
*   **a) Changing the default port number** is a mild security-by-obscurity measure but does not protect the data contents once an attacker discovers the port and taps the line.
*   **c) Restricting IP addresses** prevents unauthorized connections but does not protect the data of authorized clients from being wiretapped in transit.
*   **d) Setting a password** protects the program itself from unauthorized administrative actions, not the data traveling on the communication line.

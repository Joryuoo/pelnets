# 2010A_FE_35

Q35. Which of the following explains the database rollback process?

a) The "redo journal" is used to restore the data to the status immediately before the failure after the start of the transaction.
b) The "redo journal" is used to restore the data to the status immediately before the start of the transaction.
c) The "undo journal" is used to restore the data to the status immediately before the failure after the start of the transaction.
d) The "undo journal" is used to restore the data to the status immediately before the start of the transaction.
?
d) The "undo journal" is used to restore the data to the status immediately before the start of the transaction.

### Explanation
A rollback is an operation that restores a database to some previous state when a transaction is aborted or fails. This process uses the "undo journal" (or undo log) to reverse any changes made by the incomplete transaction, effectively restoring the data to the status it was in immediately before the transaction started.
- The "redo journal" (or redo log) is used for a rollforward process, which reapplies the changes of committed transactions to restore data in the event of a system failure.

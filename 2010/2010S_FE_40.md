# 2010S_FE_40

Which of the following can be used to interconnect multiple LANs on the network layer (layer 3) of the OSI basic reference model and to relay packets of data?

a) Bridge
b) Gateway
c) Repeater
d) Router
?
d) Router

### Explanation
A router operates at the network layer (Layer 3) of the OSI model and forwards data packets between computer networks. A repeater operates at the physical layer (Layer 1) to amplify signals. A bridge operates at the data link layer (Layer 2) to connect LAN segments. A gateway typically operates at higher layers to translate between different network architectures.

# 2010S_FE_63

Which of the following is the primary objective of conducting a system migration test?

a) To confirm interface compatibility between existing programs and newly developed programs
b) To confirm that a new system can provide sufficient performance, by using a copy of the current system’s database
c) To confirm that a new system satisfies all of the required functions
d) To confirm the procedures for switching from an existing system to a new system as well as problems accompanied with this switching, from the viewpoints of security and efficiency
?
d) To confirm the procedures for switching from an existing system to a new system as well as problems accompanied with this switching, from the viewpoints of security and efficiency

### Explanation
A system migration test ensures that moving from the old system to the new one can be done smoothly and safely. This includes verifying the switching procedures, checking for unexpected issues, and ensuring efficiency and security during the transition.

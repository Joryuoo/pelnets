# 2010A_FE_58

Q58. Which of the following is the method used for estimating the scales or person-months in system development where the five basic components—external input, external output, internal logical file, external interface file, and external inquiry—are defined and classified with their complexity weights?

a) COCOMO
b) Function point method
c) LOC method
d) Standard task method
?
b) Function point method

### Explanation
### Explanation
The Function Point (FP) method estimates software size and complexity based on functionality from the user's perspective. It counts five specific parameters: External Inputs, External Outputs, Internal Logical Files, External Interface Files, and External Inquiries. These are then multiplied by their respective complexity weights.
- **COCOMO:** Uses LOC (Lines of Code) and cost drivers to estimate effort.
- **LOC method:** Bases estimates purely on lines of code.

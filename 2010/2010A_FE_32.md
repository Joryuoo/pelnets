# 2010A_FE_32

Q32. As shown below, there are two relational database tables Movie and Actor. Which of the following SQL statements should be used for retrieving a list of movie titles, released years, and directors, from all the movies that include "Action" or "Comedy" as a genre and "Cooper" as an actor's name? Here, there is no movie remade with different actors, so "Title" and "Movie_title" are both primary keys in each table.
Movie (Released_year, Title, Director, Genre, Description)
Actor (Name, Movie_title, Role)

a) SELECT Movie_title, Released_year, Director FROM Movie, Actor WHERE Name = 'Cooper' AND (Genre = 'Action' OR Genre = 'Comedy') AND Title = Movie_title
b) SELECT Movie_title, Released_year, Director FROM Movie, Actor WHERE Name = 'Cooper' AND Genre = 'Action' AND Genre = 'Comedy' AND Title = Movie_title
c) SELECT Title, Released_year, Director FROM Movie, Actor WHERE Name = 'Cooper' AND (Genre = 'Action' OR Genre = 'Comedy')
d) SELECT Title, Released_year, Director FROM Movie, Actor WHERE Name = 'Cooper' AND Genre = 'Action' AND Genre = 'Comedy'
?
a) SELECT Movie_title, Released_year, Director FROM Movie, Actor WHERE Name = 'Cooper' AND (Genre = 'Action' OR Genre = 'Comedy') AND Title = Movie_title

### Explanation
To select data from both the `Movie` and `Actor` tables, a join condition is required, which is `Title = Movie_title`. The condition for the genre is that it can be either "Action" or "Comedy", represented as `(Genre = 'Action' OR Genre = 'Comedy')`. The condition for the actor's name is `Name = 'Cooper'`. Combining these conditions with `AND` gives the `WHERE` clause in choice (a).
- Choice (c) is incorrect because it is missing the join condition `Title = Movie_title`.
- Choices (b) and (d) are incorrect because they use `AND` for the genres (`Genre = 'Action' AND Genre = 'Comedy'`), which implies a single movie record would simultaneously have both "Action" and "Comedy" in the exact same `Genre` field, which is logically impossible for a single field containing a single string.

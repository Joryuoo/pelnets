# 2010S_FE_55

The number of remaining bugs in software is estimated by bug-embedding method. The number of captured bugs by testing is 48. The number of bugs found by testing is 16 out of 22 embedded bugs. How many bugs are estimated to be still hidden? Here, the number of the embedded bugs found in the test is proportional to the number of the bugs found in the software.

a) 6
b) 10
c) 18
d) 22
?
c) 18

### Explanation
### Explanation
The bug-embedding method (also known as fault seeding) uses a proportional relationship to estimate total bugs. 

Let:
* $M$ = Total number of embedded bugs = $22$
* $m$ = Number of embedded bugs found = $16$
* $N$ = Total number of original bugs in the software (unknown)
* $n$ = Number of original bugs found = $48$

The proportion is: $m / M = n / N$

Plugging in the values:
$16 / 22 = 48 / N$
$N = (48 \times 22) / 16$
$N = 3 \times 22 = 66$

The total estimated original bugs is $66$. Since $48$ of them have already been captured, the number of estimated remaining (hidden) original bugs is:
$66 - 48 = 18$

Therefore, **c) 18** is the correct answer.

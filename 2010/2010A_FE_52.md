# 2010A_FE_52

Q52. Which of the following is the test that is performed to ensure that the components and modules of a system can communicate with one another in accordance with the functional specifications and design?

a) Integration test
b) Operational test
c) System test
d) Unit test
?
a) Integration test

### Explanation
### Explanation
An integration test validates the interfaces and communication between individual components or modules once they are combined. 
- **Unit test:** Tests individual components in isolation.
- **System test:** Tests the entire system as a whole against the requirements.
- **Operational test:** Validates the system in its actual production environment.

# 2010A_FE_29

Which of the following is a user interface that enables frequently-used operations to be performed efficiently?

a) Online help
b) Progress bar
c) Shortcut key
d) Undo function
?
c) Shortcut key

### Explanation
A shortcut key is a combination of keys on a keyboard that provides a quick way to invoke a command or function, bypassing navigating through graphical menus and increasing user efficiency.

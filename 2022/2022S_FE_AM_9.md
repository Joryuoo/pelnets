# 2022S_FE_AM_9

Which of the following is an appropriate description of a binary search

a) A binary search is always faster than a linear search.
b) In a binary search, searching starts from the beginning of the data.
c) The data upon which the binary search is to be performed must be sorted.
d) The number of comparisons that need to be performed during the search is proportional to log2N, where N is the number of data items.

?
c) The data upon which the binary search is to be performed must be sorted.
### Explanation
**Binary Search** is an efficient algorithm for finding an item from an ordered list of items. It works by repeatedly dividing in half the portion of the list that could contain the item, until you've narrowed down the possible locations to just one.

### Analysis of the Options

*   **a) A binary search is always faster than a linear search.**
    *   *Incorrect.* If the target element is the very first element in the array, a linear search finds it in $O(1)$ time, whereas a binary search would take longer. "Always" makes this statement false.
*   **b) In a binary search, searching starts from the beginning of the data.**
    *   *Incorrect.* Binary search always begins by examining the **middle** element of the sorted dataset.
*   **c) The data upon which the binary search is to be performed must be sorted.**
    *   *Correct.* This is an absolute prerequisite. Binary search relies on the sorted property to safely eliminate half of the remaining elements at each step.
*   **d) The number of comparisons that need to be performed during the search is proportional to $\log_2 N$, where N is the number of data items.**
    *   *Partially true but technically incorrect as an absolute rule compared to c.* While the *maximum* (and average) number of comparisons is proportional to $\log_2 N$ (i.e., $O(\log N)$ time complexity), the *actual* number of comparisons could be just 1 if the target is exactly in the middle. Furthermore, Option C describes an intrinsic structural requirement. Option C is the canonical "most appropriate description" in FE exams.

# 2022S_FE_AM_35

Which of the following is an Internet standard that is used to convert IP addresses to the
corresponding MAC addresses

a) ARP
b) ICMP
c) RARP
d) RIP

?
a) ARP
### Explanation
The correct standard used to convert IP addresses to corresponding MAC addresses is **ARP** (Address Resolution Protocol).

### Protocol Definitions

| Protocol | Full Name | Purpose |
| :--- | :--- | :--- |
| **ARP** | Address Resolution Protocol | Maps a known **IP address** to an unknown **MAC address** on a local network segment. |
| **RARP** | Reverse Address Resolution Protocol | Maps a known **MAC address** to an **IP address**. Typically used by diskless workstations to discover their own IP at startup. |
| **ICMP** | Internet Control Message Protocol | Used for network diagnostics, error reporting, and operational information (e.g., `ping` uses ICMP Echo Requests). |
| **RIP** | Routing Information Protocol | A distance-vector routing protocol used by routers to share routing table information based on hop count. |

# 2022S_FE_AM_37

Which of the following is a program that is designed to block access to a computer or
encrypt most of the data on that computer until a sum of money is paid

a) Adware
b) Ransomware
c) Rootkit
d) Spyware

?
b) Ransomware
### Explanation
The program described—blocking access or encrypting data until money is paid—is the definition of **Ransomware**.

### Malware Types

| Malware Type | Description | Objective |
| :--- | :--- | :--- |
| **Ransomware** | Encrypts user data or locks the system and demands a ransom (often in cryptocurrency) for the decryption key. | Extortion and financial gain. |
| **Adware** | Automatically displays or downloads unwanted advertisements when a user is online. | Generate revenue through forced ads. |
| **Rootkit** | A stealthy type of software designed to hide the existence of certain processes or programs from normal methods of detection. | Maintain undetected, privileged access to a system. |
| **Spyware** | Secretly monitors user behavior, collects personal information, and transmits it to a third party. | Data theft and surveillance. |

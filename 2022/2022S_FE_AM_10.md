### Explanation
**Bubble Sort** is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. 

The number of exchange (swap) operations in Bubble Sort is exactly equal to the number of **inversions** in the array. An inversion is a pair of elements `(A[i], A[j])` such that `i < j` but `A[i] > A[j]`.

Let's count the inversions for the given array: `[9, 2, 13, 21, 3, 0]`

| Current Element | Smaller Elements to its Right | Count |
| :--- | :--- | :--- |
| **9** | 2, 3, 0 | 3 |
| **2** | 0 | 1 |
| **13** | 3, 0 | 2 |
| **21** | 3, 0 | 2 |
| **3** | 0 | 1 |
| **0** | (None) | 0 |

**Total Inversions (Exchanges) = 3 + 1 + 2 + 2 + 1 + 0 = 9.**

# 2022S_FE_AM_34

Which of the following is the broadcast address of the network with the address 192.168.128.0/26? Here, the decimal number after the slash (/) is the number of bits used for the network prefix.

a) 192.168.128.63
b) 192.168.128.127
c) 192.168.128.252
d) 192.168.128.255

?
a) 192.168.128.63

### Explanation
A `/26` subnet mask uses 26 bits for the network prefix and leaves `32 - 26 = 6` bits for the host ID. 

The broadcast address is the highest possible IP address in the subnet, obtained by setting all host bits to `1`.

The highest value for 6 bits in binary is `111111`, which is equal to `63` in decimal. 

Since the subnet starts at `.0`, the broadcast address in the last octet is `.63`. Therefore, the broadcast address is `192.168.128.63`.

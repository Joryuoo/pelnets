b) −1

c) 12.2
### Explanation
The problem asks us to evaluate four strings using a deterministic finite automaton (DFA) defined by the state transition table. If the DFA reaches state **E**, the string is rejected.

Let's trace the state transitions for each option, starting from the initial state **A**:

| Character | Type | Current State | Next State |

| `0` | Number | C | B |
| `0` | Number | B | B |
| `1` | Number | B | B |
| `0` | Number | B | B |
**Result:** Ends in state B (Accepted).

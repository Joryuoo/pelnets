# 2022S_FE_AM_7

![[2022S_FE_AM_Q7_full.png]]

a) 12
b) 13
c) 18
d) 19
?
d) 19
### Explanation
We are given a 2-dimensional integer array $A$, where the value of each element $A[i, j]$ is defined by the formula:

$$A[i, j] = (2 \times i) + j$$

We need to evaluate the expression:
$$A[\, A[1, 1] \times 2,\, A[2, 2] + 1 \,]$$

### Step 1: Evaluate the inner elements
First, we find the values of $A[1, 1]$ and $A[2, 2]$.

*   **$A[1, 1]$**:
    $$A[1, 1] = (2 \times 1) + 1 = 2 + 1 = 3$$
*   **$A[2, 2]$**:
    $$A[2, 2] = (2 \times 2) + 2 = 4 + 2 = 6$$

### Step 2: Substitute into the main expression
Now, substitute the values back into the main expression:

$$A[\, (3) \times 2,\, (6) + 1 \,]$$
$$A[\, 6,\, 7 \,]$$

### Step 3: Evaluate the final element
Finally, apply the formula to $A[6, 7]$:

$$A[6, 7] = (2 \times 6) + 7 = 12 + 7 = 19$$

The value is **19**, which corresponds to option **d**.

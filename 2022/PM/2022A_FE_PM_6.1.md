### Explanation
**Blank A:**
Step 1 aims to count the occurrences of each exam score. We iterate over the 10 students (`i` from 0 to 9), retrieve their score `Score[i]`, and increment the corresponding tally in the `Count` array. Therefore, `A` is `Count[Score[i]]`.

**Blank B and C:**
Step 2 calculates the starting output index (`Index`) for each possible score. The running total `n` accumulates the number of elements processed so far.
For a given score `i` (from 0 to 10), its starting position in the sorted array is exactly `n` (the total number of elements with scores lower than `i`). Thus, **B** is `n`. 
After assigning `Index[i] = n`, we must increment `n` by the number of students who got score `i` before moving to score `i+1`. Thus, we add `Count[i]` to `n`. So, **C** is `Count[i]`.

**Blank D and E:**
Step 3 populates the output arrays. We loop through the original students (`i` from 0 to 9). For student `i`, their score is `Score[i]`. The position where they should be placed is retrieved from `Index[Score[i]]`. Thus, `n = Index[Score[i]]`, making **D** `Index[Score[i]]`.
Once placed, if another student has the exact same score, they must be placed in the *next* adjacent slot. Therefore, we must increment the starting position for that score by 1: `Index[Score[i]] = Index[Score[i]] + 1`. Thus, **E** is `Index[Score[i]]`.

**Blank F:**
Counting sort iterates through the input data of size $n$ a constant number of times (Step 1 and Step 3 take $O(n)$ time, Step 2 takes $O(k)$ where $k$ is the max score range which is constant here). Overall, the calculation performance scales linearly with the number of input items, so it is $O(n)$. Thus, **F** is $O(n)$.

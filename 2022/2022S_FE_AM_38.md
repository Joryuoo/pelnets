# 2022S_FE_AM_38

In a PKI system, which of the following is an algorithm that creates a key pair

a) Hashing algorithm
b) Key generation algorithm
c) Signature verification algorithm
d) Signing algorithm

?
b) Key generation algorithm
### Explanation
In a Public Key Infrastructure (PKI) system, generating a public/private key pair is a fundamental step. Let's look at the algorithms involved.

### Analysis of Algorithms in PKI

| Algorithm | Function in PKI |
| :--- | :--- |
| **Hashing algorithm** | Generates a fixed-size hash value (digest) from arbitrary data. It is used to ensure data integrity but does not create key pairs. |
| **Key generation algorithm** | This algorithm involves mathematical procedures (like generating large prime numbers in RSA or manipulating elliptic curves in ECC) to **create the public key and its mathematically linked private key**. |
| **Signature verification algorithm** | Uses the sender's public key to decrypt/verify the digital signature (hash), ensuring the message was signed by the owner of the private key. |
| **Signing algorithm** | Uses the sender's private key to encrypt the hash of a message, creating a digital signature. |

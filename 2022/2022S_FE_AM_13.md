### Explanation
### Effective Access Time Calculation

The effective access time ($EAT$) of a system with cache memory is calculated using the following formula:
$$EAT = (h \times c) + ((1 - h) \times m)$$
Where:
- **$h$** = Cache hit rate
- **$c$** = Cache access time
- **$m$** = Main memory access time

For systems without cache, the effective access time is simply the main memory access time.

Let's calculate the effective access time for each system:

| System | Cache Hit Rate ($h$) | Cache Access Time ($c$) | Main Memory Access Time ($m$) | Calculation ($EAT$) | Result |
| :---: | :---: | :---: | :---: | :--- | :---: |
| **A** | - | - | 15 ns | $EAT = 15 \text{ ns}$ | **15 ns** |
| **B** | - | - | 30 ns | $EAT = 30 \text{ ns}$ | **30 ns** |
| **C** | $60\% = 0.6$ | 20 ns | 70 ns | $EAT = (0.6 \times 20) + ((1 - 0.6) \times 70)$ <br> $= 12 + (0.4 \times 70)$ <br> $= 12 + 28$ | **40 ns** |
| **D** | $90\% = 0.9$ | 10 ns | 80 ns | $EAT = (0.9 \times 10) + ((1 - 0.9) \times 80)$ <br> $= 9 + (0.1 \times 80)$ <br> $= 9 + 8$ | **17 ns** |

#### Comparison

Now, let's sort the systems starting with the shortest effective access time:
1. **System A**: 15 ns
2. **System D**: 17 ns
3. **System B**: 30 ns
4. **System C**: 40 ns

Therefore, the correct sorted order is **A, D, B, C**, which corresponds to option **b**.

# 2022S_FE_AM_26

![[2022S_FE_AM_Q26_full.png]]

a)  GROUP BY Class, Subject ORDER BY Class, AVG(Score)
b)  GROUP BY Class, Subject ORDER BY Class, Subject
c)  GROUP BY Class, Subject, StudentNumber ORDER BY Class, Subject, AverageScore
d)  GROUP BY Class, AverageScore ORDER BY Class, Subject, AverageScore
?
b) GROUP BY Class, Subject ORDER BY Class, Subject
### Explanation
We are tasked with completing an SQL statement to achieve two goals:
1. **Calculate the average scores for each class and each subject.**
2. **Display them in ascending order of class and subject.**

```sql
SELECT Class, Subject, AVG(Score) AS AverageScore
FROM MidtermTest
-- [ A ] --
```

### 1. Grouping the Data
To calculate aggregate functions (like `AVG()`) for subsets of data, we must use the `GROUP BY` clause. Since we want the average score for **each class and each subject**, we must group by both of these columns.
- Correct clause: `GROUP BY Class, Subject`

*(This immediately rules out option d, which incorrectly groups by `AverageScore` instead of `Subject`, and option c, which improperly groups by `StudentNumber` preventing the aggregation across all students in the class/subject.)*

### 2. Sorting the Data
To display the results in a specific order, we use the `ORDER BY` clause. The prompt strictly states we should sort in **ascending order of class and subject**.
- Correct clause: `ORDER BY Class, Subject` (Ascending is the default order).

*(This rules out option a, which incorrectly sorts by `AVG(Score)` instead of `Subject` as the secondary sort key.)*

Combining both clauses gives us:
`GROUP BY Class, Subject ORDER BY Class, Subject`

Therefore, the correct answer is **b**.

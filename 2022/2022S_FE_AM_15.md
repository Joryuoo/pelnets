# 2022S_FE_AM_15

Which of the following is a characteristic of an HA (High Availability) cluster
configuration based on a hot standby method when it is compared to a load distribution
cluster configuration that uses a load balancer

a) A server that has the same specifications is necessary as the secondary server, but since the secondary server takes over the processes in the event of the failure of the primary server, the throughput can be maintained even in the event of a failure.
b) Given that processes are distributed to other operational servers in the event of a failure, the load on the servers in operation increases, and the throughput decreases.
c) Given that processes can be distributed uniformly, server machines can be utilized effectively, and expandability is ensured, even if the amount of processing increases in the future.
d) Given that processes must be consistent among multiple servers in operation, it is necessary to share a database.

?
a) A server that has the same specifications is necessary as the secondary server, but since the secondary server takes over the processes in the event of the failure of the primary server, the throughput can be maintained even in the event of a failure.
### Explanation
### Comparison of Cluster Configurations

Let's compare the characteristics of an HA (High Availability) Cluster (Hot Standby) and a Load Distribution Cluster.

| Characteristic | HA Cluster (Hot Standby Method) | Load Distribution Cluster (Load Balancer) |
| :--- | :--- | :--- |
| **Normal Operation** | **Primary** server handles 100% of the load. **Secondary** (standby) server is idle. | All active servers share the load simultaneously. |
| **Failure Scenario** | The standby server immediately takes over. | Remaining active servers absorb the load. |
| **Throughput During Failure** | Throughput is **maintained** because the standby server typically has identical specifications and was not handling any load. | Throughput generally **decreases** because the remaining servers now have an increased workload. |
| **Server Requirements** | Requires an idle server with identical specifications. | Can utilize multiple servers of varying sizes effectively. |



The key advantage of the hot standby method is that the system's capacity does not degrade when a failure occurs. In a load distribution cluster, the loss of one server means the overall capacity of the cluster is reduced. 

Therefore, option **a** is the correct characteristic.

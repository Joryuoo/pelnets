# 2022S_FE_AM_30

b) NAPT (IP masquerade)

?
b) NAPT (IP masquerade)
### Explanation
The question describes a common home or office network scenario: multiple PCs on a local network (using private IP addresses) need to access the Internet through a single router (Device A) that has only **one global (public) IP address**.

Let's review the functions of the given options:

| Protocol / Function | Description | Is it responsible for sharing a single Global IP? |
|---|---|---|
| **a) DHCP** (Dynamic Host Configuration Protocol) | Automatically assigns private IP addresses and network configuration to devices inside the local network. | No. It manages local IPs, but does not translate them to the global Internet. |
| **b) NAPT** (Network Address Port Translation) / IP Masquerade | Translates multiple private IP addresses to a single public IP address by assigning unique **port numbers** to each connection. | **Yes.** This is the exact mechanism routers use to allow many devices to share one global IP. |
| **c) Packet filtering** | A security mechanism (firewall) that blocks or allows network packets based on predefined rules (e.g., IP, port). | No. It is for security, not address translation. |
| **d) PPPoE** (Point-to-Point Protocol over Ethernet) | Used to authenticate and establish a connection between the router and the Internet Service Provider (ISP). | No. It connects the router to the ISP, but doesn't handle the internal PC sharing. |

### How NAPT Works
When a PC sends a request to the internet, Device A (the router) intercepts the packet. It replaces the PC's private IP with the router's global IP, and assigns a unique temporary port number. When the internet responds to that port, the router knows exactly which internal PC should receive the data.



Therefore, the correct answer is **b**.

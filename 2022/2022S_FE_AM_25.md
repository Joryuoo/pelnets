# 2022S_FE_AM_25

When an ER diagram is translated into a set of tables in a relational database, which of the following is an appropriate method to translate a many-to-many relationship between two entities?

a) Combine two entities and create a single table.
b) Create a table for each entity and import the primary key from a table of smaller size to a table of larger size.
c) Create a table for each entity and import the primary key from one table to another table, and vice versa.
d) Create a table for each entity and then create a new table and import the primary keys from both entities to the new table.

?
d) Create a table for each entity and then create a new table and import the primary keys from both entities to the new table.

### Explanation
In a standard relational database, a many-to-many relationship between two entities cannot be represented directly without causing massive data redundancy. 

Instead, it must be resolved by creating a third table, known as a **junction table** or associative entity. This new table includes the primary keys of both original entities as foreign keys, which together form its composite primary key.

# 2022S_FE_AM_19

Which of the following is software that can be used without charge but has restrictions
on modification and redistribution

a) Freeware
b) Package software
c) Public domain software
d) Shareware

?
a) Freeware
### Explanation
### Software Licensing Categories

Understanding different software licensing models is crucial in the IT industry.

| Software Type | Description | Modification | Redistribution | Price |
| :--- | :--- | :---: | :---: | :---: |
| **Freeware** | Software distributed at no cost, but remains copyrighted by the author. Source code is usually not provided. | ❌ Restricted | ❌ Restricted | Free |
| **Public Domain** | Software with no copyright. Anyone can use, modify, and distribute it without restrictions. | ✅ Allowed | ✅ Allowed | Free |
| **Shareware** | Software initially provided for free on a trial basis. Requires payment for continued use or full features. | ❌ Restricted | ✅ Usually Allowed | Trial (then Paid) |
| **Open Source** | Software distributed with its source code, allowing users to study, modify, and distribute the software. | ✅ Allowed | ✅ Allowed | Usually Free |



Since the software in question is free of charge but has restrictions on modification and redistribution, it is correctly classified as **Freeware**.

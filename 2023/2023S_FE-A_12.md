# 2023S_FE-A_12

Which of the following is classified as an internal interrupt?

a) Interrupt caused by an abnormal power condition, such as a momentary loss of commercial power supply
b) Interrupt caused by performing a divide-by-zero operation
c) Interrupt caused by the completion of input or output
d) Interrupt caused by the occurrence of a memory parity error
?
b) Interrupt caused by performing a divide-by-zero operation

### Explanation

Interrupts signal to the processor that an event needs immediate attention, causing it to pause its current execution and run an Interrupt Service Routine (ISR). They are broadly classified into **Internal Interrupts** and **External Interrupts**.

**Internal Interrupts (Software Interrupts / Traps / Exceptions):**
These are synchronous events generated by the CPU *itself* during the execution of an instruction. They are triggered by exceptional conditions in the software or execution faults.
*   *Examples:* **Divide-by-zero**, page fault, illegal opcode instruction, arithmetic overflow, software-generated interrupts (e.g., `INT` or `SYSCALL`).

**External Interrupts (Hardware Interrupts):**
These are asynchronous events generated by hardware components *outside* the CPU's execution unit.
*   *Examples:* I/O device completion (e.g., keyboard press, disk read), timer interrupts, hardware malfunctions (e.g., power failure, memory parity error).

Let's categorize the choices:

| Option | Event | Interrupt Type | Reason |
| :--- | :--- | :--- | :--- |
| **a)** | Abnormal power condition | External | Triggered by external hardware (power supply monitor). |
| **b)** | **Divide-by-zero operation** | **Internal** | **Triggered by the CPU execution unit executing a faulty math instruction.** |
| **c)** | Completion of I/O | External | Triggered by an external I/O controller (e.g., disk or network card). |
| **d)** | Memory parity error | External | Triggered by the memory controller hardware detecting corruption. |

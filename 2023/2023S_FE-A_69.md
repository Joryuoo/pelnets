# 2023S_FE-A_69

Which of the following is an appropriate example of a core technology for the creation of competitive advantage? 

a) It is a development technology that combines general components with the purpose of fast-track development and fast-track market introduction of products.
b) It is a device technology that employs the same CPU core as that of competitors and enhances the portability of software.
c) It is an idle reduction technology of an automobile engine that cannot be imitated by competitors.
d) It is an interface technology whose purpose is to create standard interfaces by forming an alliance and use them commonly.
?
c) It is an idle reduction technology of an automobile engine that cannot be imitated by competitors.

### Explanation

A **core competence** or **core technology** refers to a unique capability or fundamental strength that gives a company a strong **competitive advantage**. According to management theory, a core technology should be valuable, rare, and difficult for competitors to imitate (VRIO framework).

| Option | Assessment | Why it is or isn't a Core Technology |
|---|---|---|
| a) | Not core | Relying on *general components* means competitors can easily replicate the same fast-track strategy. |
| b) | Not core | Using the *same CPU core as competitors* explicitly means there is no unique technological advantage. |
| **c)** | **Core Technology** | **An exclusive, proprietary technology ("cannot be imitated") that delivers specific value (idle reduction), creating a direct competitive edge.** |
| d) | Not core | *Standard interfaces* shared with allies become an industry norm, not an exclusive competitive advantage for a single firm. |

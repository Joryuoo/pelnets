# 2023S_FE-A_13

Which of the following is the technique that minimizes the number of write operations to the main memory by updating the data only in the cache memory and updating into the main memory later?

a) Overlay
b) Write back
c) Write protected
d) Write through
?
b) Write back

### Explanation

When a CPU needs to write data to memory, it first writes to the cache. Since the cache and main memory must eventually be consistent, different **cache write policies** exist.

The two main policies are **Write-back** and **Write-through**:

1.  **Write-back (Copy-back):**
    *   Data is written *only* to the cache block initially.
    *   The modified cache block is marked with a "dirty bit".
    *   The data is written to main memory *only when* the dirty block is evicted (replaced) from the cache to make room for new data.
    *   **Advantage:** Minimizes slow write operations to main memory, greatly improving performance.

2.  **Write-through:**
    *   Every time data is written to the cache, it is simultaneously written to the main memory.
    *   **Advantage:** Main memory is always perfectly consistent with the cache.
    *   **Disadvantage:** Slower because every write incurs the delay of a main memory access.

Let's review the other options:

| Option | Description |
| :--- | :--- |
| **a) Overlay** | A memory management technique used in older systems to load program segments into memory only when needed, allowing programs larger than physical memory to run. Not a cache policy. |
| **b) Write back** | **Updates cache first, delays main memory write until eviction.** |
| **c) Write protected** | A memory access attribute preventing data from being overwritten (read-only). |
| **d) Write through** | Writes to cache and main memory simultaneously. |

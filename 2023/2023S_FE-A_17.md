# 2023S_FE-A_17

A printer prints 400 characters per second. The printer uses interrupt-driven I/O and each character printed requires an interrupt that takes 50 microseconds. What percentage of the printer's CPU is available to do other work during printing? Here, other overhead time for the CPU can be ignored.

a) 98
b) 96
c) 4
d) 2
?
a) 98

### Explanation

We need to calculate the fraction of CPU time spent handling printer interrupts in one second. Once we find the percentage of time the CPU is busy, we subtract it from 100% to find the available CPU time.

**Step 1: Calculate the total time spent handling interrupts per second.**
*   The printer prints $400 \text{ characters per second}$.
*   Each character requires one interrupt.
*   Each interrupt takes $50 \text{ microseconds}$ ($\mu s$) of CPU time.

The total CPU time spent on interrupts per second is:
$$ \text{Total Interrupt Time} = 400 \text{ chars} \times 50 \ \mu s/\text{char} $$
$$ \text{Total Interrupt Time} = 20,000 \ \mu s $$

**Step 2: Convert the interrupt time to seconds to find the fraction.**
Recall that $1 \text{ second} = 1,000,000 \text{ microseconds} \ (10^6 \ \mu s)$.

$$ \text{Busy Time Percentage} = \left( \frac{20,000 \ \mu s}{1,000,000 \ \mu s} \right) \times 100\% $$
$$ \text{Busy Time Percentage} = 0.02 \times 100\% = 2\% $$

**Step 3: Calculate the available CPU percentage.**
If the CPU spends $2\%$ of its time handling the printer, the rest of the time it is available for other work.

$$ \text{Available Time} = 100\% - 2\% = 98\% $$

Thus, **98%** of the CPU is available.

# 2023S_FE-A_26

Which of the following is the key of a relation schema $R = (M, N, O, P, S, T)$, when $R$ has the functional dependencies shown below? 

$O \rightarrow T$
$S \rightarrow M$
$OS \rightarrow P$
$M \rightarrow N$

a) $MO$
b) $MS$
c) $OP$
d) $OS$
?
d) $OS$

### Explanation
To determine the candidate key for the relation schema $R$, we need to find the attribute closure for each option. A valid key must be able to functionally determine all attributes in the schema $\{M, N, O, P, S, T\}$.

Let's test the closure of $OS$ (denoted as $OS^+$):
1. **Start:** $OS^+ = \{O, S\}$
2. Using $S \rightarrow M$: We can add $M$.
   $OS^+ = \{O, S, M\}$
3. Using $M \rightarrow N$: We can add $N$.
   $OS^+ = \{O, S, M, N\}$
4. Using $O \rightarrow T$: We can add $T$.
   $OS^+ = \{O, S, M, N, T\}$
5. Using $OS \rightarrow P$: We can add $P$.
   $OS^+ = \{O, S, M, N, T, P\}$

Since $OS^+$ contains all the attributes of the relation schema $R$, **$OS$** is a valid key. 

For completeness, let's look at the others:
- $MO^+ = \{M, O, N, T\}$ (Missing $P, S$)
- $MS^+ = \{M, S, N\}$ (Missing $O, P, T$)
- $OP^+ = \{O, P, T\}$ (Missing $M, N, S$)

### Explanation
**Finding G:**
The `skipLeadingZeros()` function aims to return a pointer to the first non-zero character. A `while` loop iterates as long as `*str == '0'` by incrementing `str++`. If the loop finishes and `*str == '\0'`, it means the string consisted entirely of zeros. The instructions dictate that it should return the pointer to the *last* zero character in this case. Since `str` currently points to the `\0` null-terminator, the last zero character is just before it, at `str - 1` (c).

**Finding H:**
We want to remove the leading zeros from `strNum` using `memmove(dest, src, len)`.
- `dest` is the original string starting point: `strNum`.
- `src` is the string bypassing leading zeros: `skipLeadingZeros(strNum)`.
- `len` must be the total length of the remaining string plus 1 (to copy the null-terminator `\0`). So `strlen(skipLeadingZeros(strNum)) + 1`.
Putting it together gives (d).

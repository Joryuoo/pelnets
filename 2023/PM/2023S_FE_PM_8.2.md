### Explanation
**Finding G and H:**
The `remove(int index)` function removes an element efficiently from the array by avoiding full array shifts. It works by replacing the element to be removed with the *last* element in the array, then nullifying the last position and decrementing the size counter.
```java
result = ___G___; // Step 1: Save the element being removed
___G___ = ___H___; // Step 2: Swap the target with the last element
___H___ = null; // Step 3: Clear the last element slot to avoid memory leaks
```
- **G:** The element we want to remove is at the target index: `bag[index]` (d). We save it to `result` so we can return it.
- **H:** The last valid element in the array sits at `bag[numberOfEntries - 1]` (e). We copy its value into the slot we are "removing" (`bag[index]`), then we `null` out the last slot. 

This simple swap enables $O(1)$ constant-time removals for a Bag (where order doesn't matter).

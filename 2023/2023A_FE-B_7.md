### Explanation
**Subquestion 1:**
- **A**: `FindWeightClass()` returns `-1` if the wrestler's weight exceeds the maximum allowed class. The program prompts for re-entry as long as the weight is invalid, hence the loop runs while `index == -1` (Choice **c**).
- **B**: The standard way to dynamically allocate memory for a struct is `malloc(sizeof(Wrestler_t))` (Choice **b**).
- **C**: The wrestler qualifies for the first weight class that is strictly greater than or equal to their weight. Thus, `UpperLimits[i] >= weight` (Choice **d**).
- **D**: If the linked list for a class is empty (`curr == NULL`), we must assign the new node to the head of the list array, which is `Entries[i]` (Choice **c**).
- **E**: To insert at the end of a populated linked list, we traverse until `curr->next == NULL` and then assign the new node to `curr->next` (Choice **e**).
- **F**: Deallocation requires pointers to traverse the list without losing the reference to the next node. We declare `Wrestler_t *curr, *next` to safely `free(curr)` while maintaining the chain (Choice **c**).

**Subquestion 2:**
- **G**: To maintain the linked list in ascending order of weight, we must advance the `curr` pointer as long as the next node's weight is strictly less than the incoming wrestler's weight. Therefore, `curr->next->weight < wrestler->weight` (Choice **a**).

**Subquestion 3:**
- **H**: The instruction `wrestler->next = curr; Entries[i] = wrestler;` (labeled by $\delta$) executes when inserting at the head of a list (either the list is empty, or the new node's weight is $\le$ the head's weight).
  Tracing the inserts:
  1. **Eric (88)**: Class 97. List is empty. Executes $\delta$.
  2. **Faraday (72)**: Class 74. List is empty. Executes $\delta$.
  3. **Gregory (91)**: Class 97. Head is Eric(88). Since $88 < 91$, goes to `ELSE`.
  4. **Harold (97)**: Class 97. Head is Eric(88). Goes to `ELSE`.
  5. **Issacs (68)**: Class 74. Head is Faraday(72). Since $72 \ge 68$, it becomes the new head. Executes $\delta$.
  Total executions: **3 times** (Choice **b**).

# 2023S_FE-A_16

When system availabilities of a cold standby system, a simplex system, and a dual system are compared, which of the following shows the order arranged from highest to lowest? Here a computer or computers that compose each system are all the same.

a) Cold standby system, dual system, simplex system
b) Cold standby system, simplex system, dual system
c) Dual system, cold standby system, simplex system
d) Simplex system, cold standby system, dual system
?
c) Dual system, cold standby system, simplex system

### Explanation

**System availability** refers to the probability that a system is operational and accessible when required. It is fundamentally dependent on how a system handles failures (redundancy).

Let's evaluate the three configurations based on their availability:

1.  **Dual System (Highest Availability):**
    *   Two identical computers process the same data synchronously in parallel. Their results are constantly compared.
    *   If one system fails, the other continues processing seamlessly without any interruption or data loss.
    *   Because there is zero downtime upon failure, it has the highest availability.

2.  **Cold Standby System (Medium Availability):**
    *   An active (primary) computer runs the system. A secondary computer is present but completely powered off ("cold").
    *   If the primary computer fails, an administrator must physically power on the secondary computer, boot the OS, load the software, and restore the latest backup before service resumes.
    *   This switchover process causes significant downtime, meaning availability is lower than a dual/hot-standby system, but still better than having no backup hardware at all.

3.  **Simplex System (Lowest Availability):**
    *   A single computer system with no redundancy.
    *   If the computer fails, the entire system is down until the physical hardware can be repaired or replaced.
    *   Because it relies on a single point of failure and takes the longest to repair, it has the lowest availability.

Therefore, the order from highest to lowest availability is: **Dual system > Cold standby system > Simplex system**.

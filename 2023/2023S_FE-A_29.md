# 2023S_FE-A_29

An employees table contains fields in the order shown below. 
- `emp_id` is an integer value and is used as the primary key of the table.
- `emp_name` can store up to 10 characters. 
- `salary` is a decimal value up to 4 digits. 

Which of the following is an appropriate INSERT statement to insert the data to the table? Here, NOT NULL constraint does not exist and the table does not have any records before the insert. 

a) `INSERT INTO employees (emp_id, emp_name) VALUES (4, 'Hulk');`
b) `INSERT INTO employees (emp_id, salary, emp_name) VALUES (3, 'Taylor', 1700);`
c) `INSERT INTO employees (emp_id, salary, emp_name) VALUES (5, 1900, 'Bartholomew');`
d) `INSERT INTO employees VALUES (2, 'Harry', 15000);`
?
a) INSERT INTO employees (emp_id, emp_name) VALUES (4, 'Hulk');

### Explanation
Let's analyze the schema constraints and check each SQL statement:
- `emp_id`: Integer, Primary Key (cannot be null, must be unique).
- `emp_name`: String, max 10 characters.
- `salary`: Decimal, max 4 digits (e.g., up to 9999).

Evaluating each option:
* **a) Correct.** Specifies columns `(emp_id, emp_name)`. Values `(4, 'Hulk')` match the data types. `'Hulk'` is 4 characters (within the 10-character limit). `salary` is omitted, which is fine since there is no NOT NULL constraint.
* **b) Incorrect.** The columns specified are `(emp_id, salary, emp_name)`. The provided values are `(3, 'Taylor', 1700)`. It attempts to insert the string `'Taylor'` into the `salary` field, causing a type mismatch error.
* **c) Incorrect.** The columns specified are `(emp_id, salary, emp_name)`. The values are `(5, 1900, 'Bartholomew')`. The string `'Bartholomew'` is 11 characters long, which violates the `emp_name` maximum length constraint of 10 characters.
* **d) Incorrect.** When column names are omitted, the values must match the exact order of the table definition: `(emp_id, emp_name, salary)`. The provided values are `(2, 'Harry', 15000)`. It attempts to insert `15000` into the `salary` field. Since `15000` is 5 digits long, it violates the 4-digit limit for `salary`.

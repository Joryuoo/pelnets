### Explanation
A packet filtering firewall controls access based on the source and destination IP addresses, and source and destination port numbers.

To enable internal PCs to access an external Web server (HTTP over port 80), two rules are needed for the two-way communication:

1.  **Outbound Request (PC $\rightarrow$ Web Server)**
    *   **Source:** PC
    *   **Destination:** Web server
    *   **Destination Port:** The web server listens on the well-known port **80**.
    *   **Source Port:** The PC allocates an ephemeral port, which is **1024 or higher**.

2.  **Inbound Response (Web Server $\rightarrow$ PC)**
    *   **Source:** Web server
    *   **Destination:** PC
    *   **Destination Port:** The response must go to the PC's ephemeral port, which is **1024 or higher**.
    *   **Source Port:** The traffic originates from the web server's port **80**.

Looking at the options, only **c)** correctly defines this mapping:

| Source | Destination | Source port number | Destination port number | Direction |
| :--- | :--- | :--- | :--- | :--- |
| PC | Web server | 1024 or higher | 80 | Outbound Request |
| Web server | PC | 80 | 1024 or higher | Inbound Response |

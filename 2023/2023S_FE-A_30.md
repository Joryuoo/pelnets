# 2023S_FE-A_30

Which of the following is the purpose of setting an index in the columns of the table of a relational database by a user? 

a) To enable economization of disk space when a single large table is distributed and saved on several disks. 
b) To enable efficient access to the storage location of data in order to improve the search speed. 
c) To ensure that no value is duplicated in a column. 
d) To match the value of the foreign key column with the value of the primary key of another table. 
?
b) To enable efficient access to the storage location of data in order to improve the search speed.

### Explanation
An **index** in a database is a specialized data structure (often a B-tree or Hash table) created on one or more columns of a table. 

Its primary purpose is to **speed up data retrieval operations (searches and queries)**. By maintaining a sorted or hashed reference to the physical storage locations (row pointers) of the data, the database engine can find records efficiently without having to scan the entire table row by row (a full table scan).

Let's evaluate the other choices to see what they actually describe:
* a) Refers to **data partitioning** or **sharding**. (Also, indexes actually *consume* extra disk space rather than economizing it).
* c) Refers to a **UNIQUE constraint** (though a unique index is created under the hood to enforce it, standard indexing is primarily for search performance).
* d) Refers to a **Foreign Key constraint** maintaining referential integrity.

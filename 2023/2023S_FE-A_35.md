# 2023S_FE-A_35

As for the use of e-mails over the Internet, which of the following is a standard that extends the header field and can handle not only text but also audio and images?

a) HTML
b) MHS
c) MIME
d) SMTP
?
c) MIME

### Explanation

**MIME (Multipurpose Internet Mail Extensions)** is an Internet standard that extends the format of email to support:
- Text in character sets other than ASCII.
- Non-text attachments (audio, video, images, application programs, etc.).
- Message bodies with multiple parts.
- Header information in non-ASCII character sets.

| Option | Protocol/Standard | Description |
|---|---|---|
| a | HTML | HyperText Markup Language, used to create web pages. It can be embedded inside a MIME email to create rich-text emails. |
| b | MHS | Message Handling System, an older email standard developed by Novell. |
| **c** | **MIME** | **Correct. Extends email capabilities to handle multimedia and various character encodings.** |
| d | SMTP | Simple Mail Transfer Protocol, used for **sending** and routing emails between servers, but originally only supported 7-bit ASCII text. |

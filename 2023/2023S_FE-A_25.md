# 2023S_FE-A_25

Which of the following is an appropriate explanation of a relational database? 

a) It connects a parent record and a child record by using a pointer. 
b) It represents data in the form of a two-dimensional table. 
c) It represents the structure and meaning of data by using tags. 
d) It retains data and procedures in an integrated (or encapsulated) form. 
?
b) It represents data in the form of a two-dimensional table.

### Explanation
Different database models organize data in distinctly different ways:

| Database Model | Description | Matching Option |
|:---|:---|:---|
| **Relational Database** | Organizes data into **two-dimensional tables** (relations) consisting of rows (records) and columns (attributes). | **b) represents data in the form of a two-dimensional table.** |
| **Hierarchical / Network Database** | Organizes data using tree or graph structures, connecting parent and child records using pointers. | a) connects a parent record and a child record by using a pointer. |
| **XML / Document Database** | Uses tags to define the structure, meaning, and hierarchy of the data. | c) represents the structure and meaning of data by using tags. |
| **Object-Oriented Database** | Integrates data and the procedures (methods) that operate on them into objects, applying encapsulation. | d) retains data and procedures in an integrated form. |

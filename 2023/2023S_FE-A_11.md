# 2023S_FE-A_11

When a CPU has a special register used in push and pop instructions, which of the following is an appropriate term for this register?

a) Instruction register
b) Program counter
c) Stack pointer
d) Status register
?
c) Stack pointer

### Explanation

A **Stack Pointer (SP)** is a special-purpose register in a CPU that stores the memory address of the top of the stack. The stack is a Last-In, First-Out (LIFO) data structure used primarily for storing temporary data, local variables, and return addresses during function calls.

The two main operations associated with the stack are:
*   **PUSH**: Adds an item to the top of the stack. The stack pointer is decremented or incremented (depending on architecture) to point to the new top of the stack.
*   **POP**: Removes an item from the top of the stack. The data is retrieved, and the stack pointer is adjusted back to the previous element.

Let's review the other options:

| Register | Description |
| :--- | :--- |
| **a) Instruction register** | Holds the machine instruction that is currently being executed. |
| **b) Program counter** | Holds the memory address of the *next* instruction to be fetched and executed. |
| **d) Status register** | (Also known as Flag register) Holds flags indicating the status of the processor (e.g., zero, carry, overflow) after an arithmetic or logical operation. |

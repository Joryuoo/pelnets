# 2023S_FE-A_15

Which of the following is the RAID configuration for achieving the highest speed disk access at the cost of reliability?

a) RAID 0
b) RAID 1
c) RAID 5
d) RAID 6
?
a) RAID 0

### Explanation

**RAID (Redundant Array of Independent Disks)** is a technology used to combine multiple physical disk drives into a single logical unit for data redundancy, performance improvement, or both.

**RAID 0 (Striping):**
*   **How it works:** Data is split into blocks and evenly spread ("striped") across multiple disks concurrently.
*   **Performance:** Excellent. Read/write operations can happen in parallel across all disks, multiplying speed.
*   **Reliability:** None. There is zero redundancy or parity. If a single disk fails, the entire array fails, and all data is lost.
*   **Conclusion:** It provides the highest speed at the ultimate cost of reliability.

Let's review the other RAID levels:

| RAID Level | Mechanism | Speed | Reliability | Min. Disks |
| :--- | :--- | :--- | :--- | :--- |
| **RAID 0** | **Striping (No Parity)** | **Very High** | **None (1 drive fails = full data loss)** | 2 |
| **RAID 1** | Mirroring | High Read, Normal Write | High (Survives 1 drive failure) | 2 |
| **RAID 5** | Striping with Distributed Parity | High Read, Slower Write | High (Survives 1 drive failure) | 3 |
| **RAID 6** | Striping with Double Parity | High Read, Slowest Write | Very High (Survives 2 drive failures) | 4 |

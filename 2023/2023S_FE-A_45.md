# 2023S_FE-A_45

When a sender from domain A sends an e-mail to a recipient in domain B, which of the following is used by the mail server in domain A for authenticating the sender? 
a) APOP
b) POP3S
c) S/MIME
d) SMTP-AUTH
?
d) SMTP-AUTH

### Explanation
**SMTP-AUTH (SMTP Authentication)** is an extension of the Simple Mail Transfer Protocol (SMTP). It provides a mechanism for the mail server to authenticate the client (the sender) before allowing it to relay emails. This prevents unauthorized users (like spammers) from using the mail server as an open relay to send emails.

**Other Options:**
*   **APOP (Authenticated Post Office Protocol):** Used to authenticate a user when *receiving* (downloading) emails from a POP3 server, not for sending.
*   **POP3S (POP3 over SSL/TLS):** The secure version of POP3, also used for *receiving* emails securely.
*   **S/MIME (Secure/Multipurpose Internet Mail Extensions):** A standard for public key encryption and signing of MIME data, used for encrypting email content and verifying the sender's identity to the recipient (end-to-end), not for mail server relay authentication.

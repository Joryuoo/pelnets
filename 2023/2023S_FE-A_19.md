# 2023S_FE-A_19

Among the different types of backup methods, which of the following is incremental backup? Here, in the first backup, all files are backed up and the information that indicates a file update managed by the operating system is reset.

a) All files are backed up regardless of information indicating a file update, and the information indicating a file update is left unchanged.
b) All files are backed up regardless of information indicating a file update, and the information indicating a file update is reset.
c) Only files with information indicating a file update are backed up, and the information indicating a file update is left unchanged.
d) Only files with information indicating a file update are backed up, and the information indicating a file update is reset.
?
d) Only files with information indicating a file update are backed up, and the information indicating a file update is reset.

### Explanation

Operating systems use an "archive bit" (or update flag) to track which files have been modified since the last backup. When a file is modified, its update flag is set to ON. 

Let's look at the three primary backup types and how they handle files and this flag:

1.  **Full Backup:**
    *   **What it backs up:** *All files*, regardless of the update flag.
    *   **What it does to the flag:** Resets it to OFF. (Matches option **b**)
2.  **Incremental Backup:**
    *   **What it backs up:** *Only* files that have been modified since the *last backup* (i.e., files with the update flag ON).
    *   **What it does to the flag:** **Resets it to OFF.** This ensures that the next incremental backup will only capture new changes made after this one. (Matches option **d**)
3.  **Differential Backup:**
    *   **What it backs up:** *Only* files that have been modified since the *last Full Backup* (i.e., files with the update flag ON).
    *   **What it does to the flag:** **Leaves it unchanged (ON).** This ensures that every subsequent differential backup will continue to capture all changes made since the original full backup. (Matches option **c**)

Let's review the options:

| Option | Files Backed Up | Update Flag Action | Backup Type |
| :--- | :--- | :--- | :--- |
| a) | All files | Unchanged | Copy Backup (Full backup without resetting flags) |
| b) | All files | Reset | Full Backup |
| c) | Only updated files | Unchanged | Differential Backup |
| **d)** | **Only updated files** | **Reset** | **Incremental Backup** |

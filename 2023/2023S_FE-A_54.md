### Explanation

We are asked to calculate the **Schedule Performance Index (SPI)** and the **Cost Performance Index (CPI)** of Activity A. 

First, we identify the given parameters for Activity A:
- **Planned Value (PV):** $80,000 (The authorized budget assigned to the scheduled work).
- **Actual Cost (AC):** $100,000 (The realized cost incurred for the work performed).
- **Earned Value (EV):** $60,000 (Since the planned value is $\$80,000$ and it is only $75\%$ complete, $EV = \$80,000 \times 0.75 = \$60,000$).

#### Formulas and Calculation

1. **Schedule Performance Index (SPI):** Measures schedule efficiency.
$$SPI = \frac{EV}{PV} = \frac{60,000}{80,000} = 0.75$$

2. **Cost Performance Index (CPI):** Measures cost efficiency.
$$CPI = \frac{EV}{AC} = \frac{60,000}{100,000} = 0.6$$

| Metric | Formula | Value | Meaning |
| :--- | :--- | :--- | :--- |
| **SPI** | $EV / PV$ | 0.75 | The project is behind schedule ($SPI < 1.0$) |
| **CPI** | $EV / AC$ | 0.6 | The project is over budget ($CPI < 1.0$) |

Matching the calculated values to the table provided in the choices, the correct schedule performance index is $0.75$ and the cost performance index is $0.6$, which corresponds to choice **b**.

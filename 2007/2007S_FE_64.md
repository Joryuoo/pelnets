# 2007S_FE_64

Which of the following is an appropriate statement in regard to the transmission operation of nodes connected to a LAN in the CSMA/CD method? 

a) Each node checks whether the carrier is busy and can transmit only if the carrier is not busy.  When collision is detected, transmission is tried again after a random time has elapsed. 
b) Each node is assigned a logical ranking, the transmission privilege is passed on down the nodes in order of this ranking, and only the node that has received this privilege can transmit. 
c) Only the node that has been assigned a time slot can transmit. 
d) The nodes are connected in a ring, a special frame for controlling transmission privileges is circulated, and only the node that has received this frame can transmit.
?
a) Each node checks whether the carrier is busy and can transmit only if the carrier is not busy.  When collision is detected, transmission is tried again after a random time has elapsed.

### Explanation
### Explanation
CSMA/CD (Carrier-Sense Multiple Access with Collision Detection) is used in Ethernet. Nodes listen to the network (Carrier Sense); if it is free, they transmit. If two nodes transmit simultaneously and their signals collide (Collision Detection), they wait a random backoff time before retrying.

- **b)** describes a Token Bus topology.
- **c)** describes TDMA (Time-Division Multiple Access).
- **d)** describes a Token Ring topology.

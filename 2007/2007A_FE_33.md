# 2007A_FE_33

Which of the following functions is a part of OS task management?

a) CPU allocation
b) File protection
c) I/O execution
d) Spool control
?
a) CPU allocation

### Explanation
Task (or process) management in an Operating System is responsible for allocating CPU time to different tasks (scheduling) and managing their states (ready, running, waiting).
- File protection belongs to file management or security.
- I/O execution and Spool control belong to I/O and device management.

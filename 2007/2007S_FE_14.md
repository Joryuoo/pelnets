# 2007S_FE_14

Q14. The "prime number division remainder" method is a well-known hashing algorithm.  In this method, a key value is divided by a number N, and the remainder which is also called a hash value is used directly as an index into the hash table.  N is the largest prime number less than or equal to the size of the available addressable spaces.  When the 20 addressable spaces are available, which of the following is the correct hash value calculated from the key value 136?  Here, a prime number is one that cannot be divided evenly by any other number except one (1).  2, 3, 5, 7, 11, and 13 are the first few prime numbers. 

a) 0 
b) 1 
c) 3 
d) 16
?
c) 3

### Explanation
In the prime number division remainder method, the divisor $N$ is determined as the largest prime number less than or equal to the size of the available addressable space.
1. The available addressable space is 20, so the largest prime number $N \le 20$ is **19**.
2. The key value given is **136**. We calculate the hash value by finding the remainder of $136 \div 19$.
3. Performing the division: $19 \times 7 = 133$, so $136 - 133 = 3$.

The remainder is 3, which serves as the hash value.

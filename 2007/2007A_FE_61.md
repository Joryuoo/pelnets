# 2007A_FE_61

In the OSI basic reference model, which of the following layers provides a set of rules for establishing and terminating the connection between applications on computer systems?

a) Data link layer
b) Network layer
c) Session layer
d) Transport layer
?
c) Session layer

### Explanation
The session layer (Layer 5) of the OSI model provides the mechanism for opening, closing, and managing a session between end-user application processes. It handles establishing and terminating connections between applications.

**Incorrect choices:**
* **a) Data link layer:** Responsible for node-to-node data transfer.
* **b) Network layer:** Responsible for routing and forwarding data.
* **d) Transport layer:** Responsible for end-to-end communication and reliability.

# 2007A_FE_51

Q51. Which of the following design tasks is performed from the standpoint of the system developer, based on the deliverables of external design and in consideration of the implementation method and processing efficiency?

a) Code design
b) Functional decomposition and structured design
c) Logical data design
d) Screen flow design
?
b) Functional decomposition and structured design

### Explanation
b) is correct. Functional decomposition and structured design are internal design tasks. They are performed by the developer based on external design and consider the implementation method and processing efficiency.

- a) Code design is part of programming/detailed design.
- c) Logical data design is part of database design (external).
- d) Screen flow design is part of external/UI design.

### Explanation
Depth-First Search (DFS) explores as far down a path as possible before backtracking. If a sequence lists a visited node but then abruptly jumps to an unvisited node that isn't connected to the current node (without having exhausted adjacent nodes), that traversal order is invalid for a DFS.

# 2007A_FE_64

Which of the following IP addresses can be used to connect a computer directly to the Internet?

a) 10.10.11.88
b) 127.0.0.1
c) 172.16.255.255
d) 203.162.1.160
?
d) 203.162.1.160

### Explanation
To connect a computer directly to the Internet, it must have a public IP address. The address `203.162.1.160` is a public IP address and can be routed on the Internet.

**Incorrect choices:**
* **a) 10.10.11.88:** This is a private IP address belonging to the Class A private range (`10.0.0.0` - `10.255.255.255`).
* **b) 127.0.0.1:** This is the loopback address used for local testing on a host.
* **c) 172.16.255.255:** This is a private IP address belonging to the Class B private range (`172.16.0.0` - `172.31.255.255`).

# 2007A_FE_38

There is an RAID5 disk array system that is composed of 10 hard disk drives, and each disk capacity is 100Gbytes. What is the approximate maximum capacity (in Gbytes) that can be used to store user data and/or programs on this system?

a) 450
b) 500
c) 900
d) 1,000
?
c) 900

### Explanation
In a RAID 5 configuration, data and parity are striped across all the drives. The capacity equivalent of exactly one drive is used to store parity information, which provides fault tolerance.
For an array of $N$ drives, the usable capacity is calculated as: $(N - 1) \times \text{Capacity of one drive}$.
Given $N = 10$ and drive capacity = 100 Gbytes:
Usable capacity = $(10 - 1) \times 100 = 9 \times 100 = 900$ Gbytes.

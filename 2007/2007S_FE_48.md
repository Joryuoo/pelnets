# 2007S_FE_48

Which of the following is a UML diagram that can be used to describe interactions among a number of objects in terms of an exchange of messages?

a) Activity diagram
b) Class diagram
c) Sequence diagram
d) Use case diagram
?
c) Sequence diagram

### Explanation
### Explanation
In UML (Unified Modeling Language), different diagrams serve different modeling purposes:

- **a) Activity diagram**: Shows the flow of control or object flow with emphasis on the sequence and conditions of the flow (similar to a flowchart).
- **b) Class diagram**: Shows the static structure of the system (classes, attributes, methods, and relationships).
- **c) Sequence diagram**: An interaction diagram that details how operations are carried out, showing the exchange of messages among objects in a time sequence.
- **d) Use case diagram**: Shows the system's functions from a user's perspective (actors and use cases).

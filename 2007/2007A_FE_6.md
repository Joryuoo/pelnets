# 2007A_FE_6

Q6.
Which of the following is the appropriate statement concerning Newton’s method that is 
known as an algorithm for obtaining the approximate value of the solution to the 
formula ƒ(x) = 0? 
 
a) An approximate value of the solution can be obtained even if the function ƒ(x) is 
indifferentiable. 
b) An approximate value of the solution is obtained geometrically using the tangent 
lines of y = ƒ(x). 
c) No matter what initial values are provided, an approximate value of the solution can 
always be obtained. 
d) Two different initial values must be provided.
?
b) An approximate value of the solution is obtained geometrically using the tangent lines of y = ƒ(x).

### Explanation
Newton's method iteratively finds the roots of a real-valued function $f(x)=0$. Starting with an initial guess $x_0$, it computes the next guess $x_1$ by finding the x-intercept of the tangent line to the curve $y=f(x)$ at $x_0$.
- a) is incorrect because the method requires computing the derivative $f'(x)$.
- c) is incorrect because the method might fail to converge if the initial guess is too far from the root, or if the derivative becomes zero.
- d) is incorrect because Newton's method only requires one initial value $x_0$ (unlike the secant method, which requires two).

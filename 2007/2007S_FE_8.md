### Explanation
A stack operates on a Last-In, First-Out (LIFO) principle.
Let's trace the operations and the state of the stack (top of the stack is on the right):
1. `PUSH(5)`: Stack = `[5]`
2. `PUSH(3)`: Stack = `[5, 3]`
3. `PUSH(6)`: Stack = `[5, 3, 6]`
4. `PUSH(1)`: Stack = `[5, 3, 6, 1]`
5. `x = POP()`: Removes the top element (1). Stack = `[5, 3, 6]`. Thus, **x = 1**.
6. `PUSH(7)`: Stack = `[5, 3, 6, 7]`
7. `y = POP()`: Removes the top element (7). Stack = `[5, 3, 6]`. Thus, **y = 7**.

The final values are x = 1 and y = 7, corresponding to choice b).

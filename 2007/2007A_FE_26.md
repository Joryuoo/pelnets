# 2007A_FE_26

Which of the following appropriately describes the purpose of the cache memory used by processors?

a) To compensate for the difference between the main memory access speed and the processor speed
b) To manage frequently-used programs on a resident basis
c) To perform virtual memory address conversion at high speed
d) To perform virtual memory paging process at high speed
?
a) To compensate for the difference between the main memory access speed and the processor speed

### Explanation
Cache memory is a small, high-speed volatile computer memory that provides quick data access to the processor. It stores frequently used computer programs, applications, and data. Its primary purpose is to bridge the significant speed gap between the fast processor (CPU) and the slower main memory (RAM), thereby compensating for the difference in access speeds and improving overall system performance.

Note that choice c describes the Translation Lookaside Buffer (TLB), while choice d describes the general paging mechanism of an OS.

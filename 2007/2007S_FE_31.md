### Explanation
The basic configuration of a computer generally consists of the Central Processing Unit (CPU) - which contains the Control Unit and Arithmetic Logic Unit (ALU) - along with Main Memory and I/O devices. The Control Unit manages the execution of instructions, the ALU performs arithmetic and logical operations, and Main Memory stores the data and instructions. Based on standard diagrams of computer architecture, the control unit and ALU exist within the CPU, tightly communicating with the memory.

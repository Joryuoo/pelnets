# 2007A_FE_28

How many tracks are required to store a sequentially organized data file including a total of 10,000 records on the hard disk drive under the following conditions? Here, each track can contain multiple blocks, but each block cannot be stored across multiple tracks.

[Conditions]
Record length: 300 bytes/record
Track capacity: 30,000 bytes/track
Inter-block gap: 400 bytes
Blocking factor: 20 records/block

a) 100
b) 106
c) 107
d) 125
?
d) 125

### Explanation
First, we calculate the total size of one block. A block contains records and requires an inter-block gap:
- Size of data in a block = 20 records/block * 300 bytes/record = 6,000 bytes.
- Total size consumed by one block on a track = 6,000 bytes + 400 bytes (gap) = 6,400 bytes.

Next, find out how many blocks can fit within a single track without crossing tracks:
- Number of blocks per track = floor(30,000 / 6,400) = floor(4.6875) = 4 blocks per track.

Now, calculate the total number of blocks needed to store all 10,000 records:
- Total blocks = 10,000 records / 20 records/block = 500 blocks.

Finally, calculate the total number of tracks required:
- Tracks needed = Total blocks / blocks per track = 500 / 4 = 125 tracks.

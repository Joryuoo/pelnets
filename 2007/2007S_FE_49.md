# 2007S_FE_49

A systems design is represented using several diagrams. When a system analyst wants to confirm the design information such as the relationships among functions and the interface among modules in a hierarchical manner, which of the following is the most appropriate diagram that should be inspected by the analyst?

a) Data flow diagram
b) Entity-relationship diagram
c) State transition diagram
d) Structured chart
?
d) Structured chart

### Explanation
### Explanation
A Structured chart (or Structure chart) is a top-down modular design tool used to represent the hierarchical structure of modules, including their relationships, function calls, and the data/control interfaces (parameters passed) between them.

- **a) Data flow diagram (DFD)**: Shows how data moves through an information system but does not necessarily show the control hierarchy or modular interfaces.
- **b) Entity-relationship diagram (ERD)**: Used for data modeling to represent entities and their relationships.
- **c) State transition diagram**: Shows the different states an object or system can be in and the events that cause transitions between these states.
- **d) Structured chart**: Specifically designed to show a hierarchical representation of system modules and their interfaces.

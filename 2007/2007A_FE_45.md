# 2007A_FE_45

Which of the following is the language processing program that generates, on a certain computer, object programs that can be executed on another computer that has a different instruction set?

a) Cross compiler
b) Emulator
c) Generator
d) Optimizing compiler
?
a) Cross compiler

### Explanation
A **cross compiler** is a compiler that runs on one platform (e.g., Windows on an x86 processor) but generates executable code for another platform with a different architecture or instruction set (e.g., a microcontroller using an ARM processor). This is commonly used in embedded systems development where the target system lacks the resources to run a compiler itself.

- An **emulator** mimics the hardware of one computer on another, allowing software for the first to run on the second, but it does not generate object programs.
- A **generator** typically refers to a program that generates source code or other artifacts based on a model or template.
- An **optimizing compiler** improves the efficiency of the generated code (speed or size) but typically targets the same platform unless it is specifically a cross-compiler.

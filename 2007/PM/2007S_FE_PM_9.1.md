For Program 1, the code logic shifts the mask in `GR2` to the right by 1 bit using `SRL GR2,1`. The loop must continue until the mask becomes `#0000`. After `SRL`, if the result is not zero, the Zero Flag (ZF) is 0, so a jump if not zero (`JNZ`) instruction is needed to loop back. Thus, blank **A** should be `JNZ LOOP` (answer **b**).

For Program 2, the bit mask checks the lowest-order bit of the given data in `GR1`. To extract just the lowest-order bit and ignore all other bits, a logical AND operation with `0000 0000 0000 0001` (Hexadecimal `#0001`) is performed. So, `GR3` is masked using `AND GR3,=#0001`. This corresponds to answer **a** for blank **B**.

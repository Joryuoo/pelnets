For **A** (subtraction) and **B** (division), the correct operands must be popped from the stack. In a postfix expression, the right operand is pushed last and therefore popped first, followed by the left operand.

- **Blank A (Choice a):** `-1.0 * (popper() - popper())` 
  The first `popper()` returns the right operand, and the second returns the left operand. This results in `-1.0 * (right - left)`, which algebraically simplifies to `left - right`, the correct order for subtraction.
- **Blank B (Choice b):** `1.0 / popper() * popper()`
  Due to left-to-right evaluation of `/` and `*`, this expression executes as `(1.0 / right) * left`, which algebraically simplifies to `left / right`. This evaluates the division in the correct order.

For **C** and **D**, the program parses multi-digit numbers from characters.

- **Blank C (Choice a):** `num = 10 * num + (p[n] - '0')`
  To accumulate a multi-digit integer from characters sequentially, we multiply the current running total `num` by 10 and add the integer value of the new digit character (`p[n] - '0'`).
- **Blank D (Choice f):** `prev == 'd'`
  When encountering a space (`'s'`), we should only push `num` to the stack if we just finished parsing a number. Therefore, we check if the previous character was a digit (`'d'`).

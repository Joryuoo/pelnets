# 2007S_FE_43

Which of the following statements concerning programming languages appropriately describes Java?

a) It enables the creation of applets and other programs that run in web browsers. The applets can be run on any environment where virtual machines are implemented.
b) It incorporates object-oriented concepts of class and inheritance into C and has upper compatibility with C.
c) It is a markup language used on the Web and describes the document structure using tags. It enables the creation of hypertext that links text, movies, etc.
d) It is an interpreter-type, object-oriented language developed in the 1970’s and includes editor, debugger, and other integrated development environment as well as OS functions.
?
a) It enables the creation of applets and other programs that run in web browsers. The applets can be run on any environment where virtual machines are implemented.

### Explanation
### Explanation
Java is well known for its "Write Once, Run Anywhere" capability, provided by the Java Virtual Machine (JVM). Java applets historically ran inside web browsers.

- **a) Java**: It originally featured applets that run in web browsers, and its bytecode can be executed in any environment with a JVM.
- **b) C++**: Incorporates object-oriented concepts into C and has upper compatibility with C.
- **c) HTML**: A markup language using tags for web document structure.
- **d) Smalltalk**: An interpreter-type, object-oriented language developed in the 1970s that included its own IDE and OS functions.

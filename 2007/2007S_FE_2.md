# 2007S_FE_2

Which of the following is the correct value of the quadruple of hexadecimal fraction 0.FEDC?

a) 1.FDB8
b) 2.FB78
c) 3.FB70
d) F.EDC0
?
c) 3.FB70

### Explanation
To find the quadruple, we multiply the hexadecimal fraction $0.\text{FEDC}_{16}$ by $4_{10}$.
Perform the multiplication digit by digit from right to left:
- $C_{16} (12_{10}) \times 4 = 48_{10} = 30_{16}$. Write down 0, carry over 3.
- $D_{16} (13_{10}) \times 4 + 3 = 55_{10} = 37_{16}$. Write down 7, carry over 3.
- $E_{16} (14_{10}) \times 4 + 3 = 59_{10} = 3B_{16}$. Write down B, carry over 3.
- $F_{16} (15_{10}) \times 4 + 3 = 63_{10} = 3F_{16}$. Write down F, carry over 3.
- The last carry 3 moves to the integer part.
The final result is $3.\text{FB70}_{16}$.

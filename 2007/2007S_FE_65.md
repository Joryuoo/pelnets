# 2007S_FE_65

A message consists of 200 characters.  If we can transmit 200 messages on average before a 1-bit error occurs, what is the bit error rate of the transmission line?  Here, 1 character equals to 2 bytes while 1 byte equals to 8 bits. 

a) 1/640000 
b) 1/320000 
c) 1/80000 
d) 1/64000
?
a) 1/640000

### Explanation
### Explanation
First, calculate the number of bits in one message:
- 1 character = 2 bytes = 16 bits.
- 1 message = 200 characters.
- Total bits per message = 200 * 16 = 3,200 bits.

Since an error occurs once every 200 messages on average:
- Total bits transmitted before an error = 200 messages * 3,200 bits/message = 640,000 bits.
- Therefore, 1 error occurs every 640,000 bits.
- Bit Error Rate = 1 / 640,000.

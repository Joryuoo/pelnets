# 2007A_FE_20

Which of the following leads to the von Neumann bottleneck?

a) Capacity of main memory
b) CPU performance
c) Data transfer speed between CPU and I/O devices
d) Data transfer speed between CPU and main memory
?
d) Data transfer speed between CPU and main memory

### Explanation
The **von Neumann bottleneck** is a limitation on throughput caused by the standard von Neumann architecture, where the CPU and main memory are connected by a single shared bus used for both data and instructions.

Because CPU processing speeds have historically increased much faster than memory access speeds, the CPU is frequently forced to remain idle while waiting for instructions and data to be transferred from memory. Therefore, the data transfer speed between the CPU and main memory acts as a bottleneck, making choice d) the correct answer.

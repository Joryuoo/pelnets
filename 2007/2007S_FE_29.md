# 2007S_FE_29

Which of the following is the most appropriate index indicating the performance of a laser printer?

a) Number of dots per inch (2.54 cm) and number of pages that can be printed per minute
b) Number of horizontal dots and number of vertical dots used to print a character and number of characters that can be printed per second
c) Spacing of printed lines and number of lines that can be printed per second
d) Types of characters printed and number of characters that can be printed per second
?
a) Number of dots per inch (2.54 cm) and number of pages that can be printed per minute

### Explanation
The performance of modern page printers (like laser printers) is standardly evaluated based on two metrics:
1. **Print Resolution (Quality):** Measured in **DPI (Dots Per Inch)**.
2. **Print Speed:** Measured in **PPM (Pages Per Minute)**.

Metrics like characters per second (CPS) or lines per minute (LPM) were used for older character-based or line-based printers, such as dot-matrix or daisy-wheel printers.

# 2007A_FE_44

In some circumstances, a program may be still running when it is called again by another program. Which of the following is the appropriate characteristic that should be implemented to execute this program correctly?

a) Recursive
b) Reentrant
c) Relocatable
d) Reusable
?
b) Reentrant

### Explanation
A **reentrant** program is one that can be safely called and executed by multiple tasks (or processes) concurrently. It achieves this by not modifying its own instructions and by keeping its state (local variables and data) separate for each invocation (typically using the stack or dynamically allocated memory). Because of this, it can be interrupted in the middle of its execution, called by another program, and then later resumed without any issues.

- **Recursive** programs can call themselves, which is a specific form of reentrancy, but "reentrant" is the broader required characteristic for concurrent execution by different programs.
- **Relocatable** means the program can be loaded into any part of memory for execution.
- **Reusable** programs can be used again after they finish, but they cannot necessarily be interrupted and executed concurrently by multiple tasks if they don't properly handle variable scope and state.

# 2007A_FE_25

A CPU has four blocks of cache memory. Using the LRU (Least Recently Used) replacement algorithm, which memory blocks are stored in the cache memory after the execution of the following sequence of access to memory blocks: 1 2 3 4 5 2 5 4 1 5 2 3?
Here, at the start of the memory access, the four cache blocks are empty and used in sequence until all the blocks are occupied. In other words, the cache blocks contain memory blocks "1 2 3 4" after access to the first four memory blocks.

a) 1 2 3 5
b) 1 5 2 3
c) 3 2 5 1
d) 5 2 1 3
?
b) 1 5 2 3

### Explanation
Let's trace the state of the cache (which has a capacity of 4 blocks) through the sequence `1 2 3 4 5 2 5 4 1 5 2 3`, noting the order of items from Least Recently Used (LRU) to Most Recently Used (MRU):

1. `1, 2, 3, 4` -> Cache holds `1, 2, 3, 4` (LRU is 1)
2. `5` -> Evicts LRU `1`. Cache is `2, 3, 4, 5` (LRU is 2)
3. `2` -> Hit. Cache becomes `3, 4, 5, 2` (LRU is 3)
4. `5` -> Hit. Cache becomes `3, 4, 2, 5` (LRU is 3)
5. `4` -> Hit. Cache becomes `3, 2, 5, 4` (LRU is 3)
6. `1` -> Evicts LRU `3`. Cache is `2, 5, 4, 1` (LRU is 2)
7. `5` -> Hit. Cache becomes `2, 4, 1, 5` (LRU is 2)
8. `2` -> Hit. Cache becomes `4, 1, 5, 2` (LRU is 4)
9. `3` -> Evicts LRU `4`. Cache becomes `1, 5, 2, 3` (LRU is 1, MRU is 3)

At the end of the sequence, the blocks stored in the cache are `1, 5, 2, 3`, ordered precisely from Least Recently Used to Most Recently Used, making **b** the correct choice.

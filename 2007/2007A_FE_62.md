# 2007A_FE_62

Which of the following protocols is used on the transport layer of OSI basic reference model?

a) FTP
b) PPP
c) SNMP
d) UDP
?
d) UDP

### Explanation
UDP (User Datagram Protocol) is a protocol that operates at the transport layer of the OSI model, alongside TCP.

**Incorrect choices:**
* **a) FTP:** File Transfer Protocol operates at the application layer.
* **b) PPP:** Point-to-Point Protocol operates at the data link layer.
* **c) SNMP:** Simple Network Management Protocol operates at the application layer.

# 2007S_FE_26

The sequence of virtual page numbers shown below is encountered in the course of execution of programs on a computer with virtual memory.

[Sequence of virtual page numbers]
3 4 2 6 4 7 1 3 2 6 3 5 1 2 3

In the computer, the LRU page replacement policy is adopted. Main memory has a capacity of 5 pages for programs, and each page is initially empty. What is the page hit ratio (percentage of times that the referenced page is found in main memory) rounded to the nearest integer value?

a) 20
b) 33
c) 50
d) 67
?
b) 33

### Explanation
We simulate the LRU (Least Recently Used) replacement policy for a memory capacity of 5 pages across the 15 access requests.

| Access | Memory Content (Recent -> Oldest) | Hit/Miss | Replaced |
|---|---|---|---|
| 3 | [3] | Miss | |
| 4 | [4, 3] | Miss | |
| 2 | [2, 4, 3] | Miss | |
| 6 | [6, 2, 4, 3] | Miss | |
| 4 | [4, 6, 2, 3] | **Hit** | |
| 7 | [7, 4, 6, 2, 3] | Miss | |
| 1 | [1, 7, 4, 6, 2] | Miss | 3 |
| 3 | [3, 1, 7, 4, 6] | Miss | 2 |
| 2 | [2, 3, 1, 7, 4] | Miss | 6 |
| 6 | [6, 2, 3, 1, 7] | Miss | 4 |
| 3 | [3, 6, 2, 1, 7] | **Hit** | |
| 5 | [5, 3, 6, 2, 1] | Miss | 7 |
| 1 | [1, 5, 3, 6, 2] | **Hit** | |
| 2 | [2, 1, 5, 3, 6] | **Hit** | |
| 3 | [3, 2, 1, 5, 6] | **Hit** | |

There are 5 hits out of 15 total accesses.
Hit Ratio = 5 / 15 = 1 / 3 $\approx$ 0.3333, which is 33%.

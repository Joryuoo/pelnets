# 2007S_FE_68

Which of the following operations extracts specific columns from tables in a relational database? 

a) Join 
b) Projection 
c) Selection 
d) Union
?
b) Projection

### Explanation
### Explanation
In relational algebra:
- **Projection** is a unary operation that returns a specific subset of columns (attributes) from a relation/table. It filters out unwanted columns.
- **Selection** (or Restriction) extracts specific rows (tuples) that satisfy a given condition.
- **Join** combines columns from two or more tables based on a related attribute.
- **Union** combines rows from two queries into a single result set.

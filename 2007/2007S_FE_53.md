# 2007S_FE_53

Q53. Which of the following is an appropriate statement in regard to program testing? 

a) In the program testing, it is necessary to check not only whether the program works as intended but also whether there are any unintended operations. 
b) The black box method is used for the test of internal structure, and the white box method is used for the test of external specifications. 
c) The number of errors remaining in a program is unrelated to the number of errors already found. 
d) The objective of program testing is to verify its completeness, and the test should be planned under the assumption that all errors can be detected.
?
a) In the program testing, it is necessary to check not only whether the program works as intended but also whether there are any unintended operations.

### Explanation
### Explanation
A comprehensive testing strategy must ensure that a program performs its required functions (positive testing) and that it handles edge cases, invalid inputs, and unexpected scenarios safely without performing unintended operations (negative testing).

- **b) is incorrect** because it reverses the definitions: black box testing is for external specifications, and white box testing is for internal structure.
- **c) is incorrect** because error detection often follows the Pareto principle (e.g., modules where many errors have been found often contain even more undiscovered errors).
- **d) is incorrect** because it is practically impossible to detect all errors in any non-trivial software.

# 2007S_FE_35

Q35. Which of the following terms refers to the function that adjusts all address dependent locations within a program to correspond to the load position when the program is loaded into main memory prior to its execution?

a) Optimization
b) Recompilation
c) Reloading
d) Relocation
?
d) Relocation

### Explanation
Relocation is the process of adjusting program addresses so that the program can execute correctly in a different memory location than it was originally compiled or linked for. The loader performs this task by updating address-dependent instructions when loading the program into main memory.
- a) Optimization: Improving code efficiency during compilation.
- b) Recompilation: Translating source code into machine code again.
- c) Reloading: Simply loading a program again, which does not inherently mean adjusting addresses.

# 2007S_FE_46

Which of the following is an appropriate description in regard to a waterfall model?

a) System development proceeds in the order of process flow, so going back upstream results in a significant loss of efficiency.
b) Systems are developed in a short time by involving users, performing development in small groups and utilizing development tools.
c) The design and implementation of an application is performed for a unit of component, and then this process is repeated successively for every component.
d) Working prototypes are created to verify and evaluate requirements specifications at an early stage.
?
a) System development proceeds in the order of process flow, so going back upstream results in a significant loss of efficiency.

### Explanation
### Explanation
The Waterfall model is a sequential (non-iterative) design process, used in software development processes, in which progress is seen as flowing steadily downwards (like a waterfall) through the phases of conception, initiation, analysis, design, construction, testing, production/implementation, and maintenance.

- **a) Waterfall model**: Proceeds linearly. Changes to earlier phases (upstream) are costly and inefficient.
- **b) Agile / RAD (Rapid Application Development)**: Focuses on quick development with small teams and heavy user involvement.
- **c) Spiral or Iterative/Incremental model**: Repeats design and implementation per component.
- **d) Prototyping model**: Builds working prototypes early to clarify requirements.

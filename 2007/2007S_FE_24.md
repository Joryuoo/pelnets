# 2007S_FE_24

Which of the following is an appropriate description of memory interleaving?

a) Compensating the difference between the access time of main memory and that of hard disk.
b) Dividing main memory into several banks and speeding up access to sequential addresses in memory.
c) Updating cache and main memory simultaneously.
d) Writing data not needed in cache to main memory when fetching new data to cache memory.
?
b) Dividing main memory into several banks and speeding up access to sequential addresses in memory.

### Explanation
Memory interleaving is a technique used to speed up memory access. Main memory is divided into multiple independent memory banks. Because consecutive memory addresses are spread across these banks, the system can access sequential addresses concurrently or in an overlapping manner, which significantly improves data transfer rates.

- **a) is incorrect** as it describes virtual memory or disk caching.
- **c) is incorrect** as it describes the **write-through** cache policy.
- **d) is incorrect** as it describes the **write-back** cache policy.

# 2007S_FE_9

Reverse Polish Notation (RPN) is used to represent arithmetic expressions without using brackets to define priorities for evaluation of operators. For example, 3*(a+b) becomes 3ab+* in RPN. Which of the following is the best data structure that should be used for implementation of RPN in a computer?

a) List
b) Queue
c) Stack
d) Tree
?
c) Stack

### Explanation
A stack is the ideal data structure for evaluating Reverse Polish Notation (Postfix) expressions due to its Last-In-First-Out (LIFO) property.
When evaluating RPN:
1. You read the expression from left to right.
2. If you encounter an operand (a value or variable), you push it onto the stack.
3. If you encounter an operator, you pop the required number of operands from the stack (usually two for binary operators), apply the operator to them, and push the result back onto the stack.
Because operators act on the most recently seen operands, the LIFO nature of a stack perfectly matches the evaluation order of RPN.

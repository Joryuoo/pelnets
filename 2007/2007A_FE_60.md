# 2007A_FE_60

Q60. Which of the following subnet masks provides the minimum number of IP addresses available in the subnet to assign to devices that request a connection?

a) 255.255.255.0
b) 255.255.255.248
c) 255.255.255.252
d) 255.255.255.254
?
c) 255.255.255.252

### Explanation
c) is correct. To find the number of available IP addresses to assign to devices (usable host addresses), we use the formula $2^n - 2$, where $n$ is the number of host bits (the 0 bits in the subnet mask). The `- 2` accounts for the network address and the broadcast address.

- a) `255.255.255.0` (8 host bits) -> $2^8 - 2 = 254$ hosts
- b) `255.255.255.248` (3 host bits) -> $2^3 - 2 = 6$ hosts
- c) `255.255.255.252` (2 host bits) -> $2^2 - 2 = 2$ hosts
- d) `255.255.255.254` (1 host bit) -> $2^1 - 2 = 0$ hosts (invalid for assigning to multiple requesting devices on a standard subnet)

Since we need to assign IP addresses to devices, option (c) provides the minimum non-zero number of usable IP addresses (2).

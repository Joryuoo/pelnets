# 2007A_FE_58

Q58. Which of the following appropriately describes the purpose of using a check digit?

a) To detect an error of the inputted code value
b) To detect an error of the number of inputted code digits
c) To detect an error that alphabetic characters and/or symbols are mixed in data inputted into the numerical item
d) To detect an error that the inputted data value is out of the predefined range
?
a) To detect an error of the inputted code value

### Explanation
a) is correct. A check digit is a form of redundancy check used for error detection on identification numbers (like barcodes, ISBNs, or bank accounts). It is an extra digit calculated from the other digits, allowing the system to detect accidental errors like mistyping or swapping digits in the code value.

- b) Checking the number of digits is a length check.
- c) Checking for alphabetic characters in a numerical field is a type or format check.
- d) Checking if a value is within a predefined range is a limit or range check.

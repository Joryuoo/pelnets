# 2007A_FE_54

Q54. Which of the following is the appropriate description concerning the functions of “driver” or “stub” used in the module test?

a) “Driver” calls the module to be tested while passing arguments to it.
b) “Driver” is a module that is called from the module to be tested.
c) “Stub” displays and prints the value returned by the module to be tested.
d) “Stub” is a module that calls the module to be tested.
?
a) “Driver” calls the module to be tested while passing arguments to it.

### Explanation
a) is correct. In module (unit) testing, a **driver** is a dummy main program created to simulate a calling component. It calls the module being tested and passes necessary arguments to it.

- b) Describes a "stub", which is called by the module being tested to simulate lower-level modules.
- c) A stub's main purpose is to simulate the behavior of a called module by returning dummy values, not necessarily to print.
- d) Describes a "driver", not a stub.

# 2007A_FE_24

Which of the following is classified as an external interrupt?

a) An interrupt which is caused by overflow in floating point operations
b) An interrupt which is generated when a request for a service, such as a demand for input/output, is issued to OS
c) An interrupt which occurs when a page not existing in the main memory is to be accessed
d) An interrupt which takes place when hardware detects malfunctions
?
d) An interrupt which takes place when hardware detects malfunctions

### Explanation
Interrupts are generally classified into internal and external interrupts.
- **Internal interrupts** (also known as software interrupts or exceptions) occur synchronously with the execution of instructions. Examples include division by zero, overflow (choice a), page faults (choice c), or system calls like I/O requests (choice b).
- **External interrupts** occur asynchronously from outside the CPU's current execution thread, typically triggered by external hardware devices, timers, or hardware malfunctions. 

Therefore, a hardware malfunction detection (choice d) is classified as an external interrupt.

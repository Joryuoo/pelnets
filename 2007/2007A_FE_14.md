# 2007A_FE_14

Which of the following is the appropriate statement concerning data sorting methods?

a) The “bubble sort” method determines an intermediate reference value and divides the elements into two groups of “larger” values and “smaller” values.  This operation is then repeated recursively on these two groups.
b) The “heap sort” method builds an ordered tree from the unsorted portion of the elements, extracts the maximum or minimum value from this ordered tree, and moves it to the sorted portion.  This operational sequence is then repeated to gradually shrink the unsorted portion.
c) The “quick sort” method sorts each substring composed of elements extracted at regular intervals, and then the interval is further decreased and the same operation is performed again.  This operation is repeated until the interval becomes 1.
d) The “shell sort” method repeatedly compares two adjacent elements and swaps them if the first element is larger than the second.
?
b) The “heap sort” method builds an ordered tree from the unsorted portion of the elements, extracts the maximum or minimum value from this ordered tree, and moves it to the sorted portion.  This operational sequence is then repeated to gradually shrink the unsorted portion.

### Explanation
- **Heap Sort** (choice b) correctly describes building a heap (an ordered binary tree), repeatedly extracting the maximum (or minimum) value, and moving it to the sorted portion.
- Choice a describes **Quick Sort**, which partitions elements around a pivot (reference value).
- Choice c describes **Shell Sort**, which sorts substrings at decreasing intervals.
- Choice d describes **Bubble Sort**, which relies on repeatedly comparing and swapping adjacent elements.

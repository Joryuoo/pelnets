# 2007A_FE_63

Which of the following is the appropriate technology that is used to establish a private or secure network connection within a public IP network, such as the Internet, and to give the company the same capabilities at much lower cost by using the shared public infrastructure rather than a private one?

a) Firewall
b) PAT
c) RPC
d) VPN
?
d) VPN

### Explanation
A VPN (Virtual Private Network) is used to create a secure, encrypted connection over a less secure network, such as the public Internet. This provides the benefits of a private network over public infrastructure at a lower cost.

**Incorrect choices:**
* **a) Firewall:** A network security system that monitors and controls incoming and outgoing network traffic.
* **b) PAT:** Port Address Translation, used to map multiple private IP addresses to a single public IP address.
* **c) RPC:** Remote Procedure Call, a protocol that one program can use to request a service from a program located in another computer on a network.

# 2007A_FE_5

Q5.
Which of the following is the reason why a large number of computers use “complement 
representation” to simplify arithmetic circuits? 
 
a) Addition can be processed by subtraction. 
b) Division can be processed by a combination of subtractions. 
c) Multiplication can be processed by a combination of additions. 
d) Subtraction can be processed by addition.
?
d) Subtraction can be processed by addition.

### Explanation
By using two's complement representation for negative numbers, computers can perform subtraction using the same hardware circuit used for addition. Instead of having separate adder and subtractor circuits, the computer can subtract a number by adding its two's complement. For example, $A - B$ becomes $A + (-B)$, where $-B$ is the two's complement of $B$.

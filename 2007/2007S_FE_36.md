We can determine this by creating a timeline of execution to see which task, when combined with Task A, results in no CPU idle time.
Task A (High Priority): CPU(3) -> I/O(3) -> CPU(3) -> I/O(3) -> CPU(2)
Task D (Low Priority): CPU(3) -> I/O(2) -> CPU(3) -> I/O(1) -> CPU(4)

- **3-6 ms:** Task A does I/O (3ms). CPU runs Task D (3ms).
- **6-8 ms:** Task A is ready. CPU runs Task A. Task D does I/O (2ms). Task D is ready at 8ms.
- **8-9 ms:** CPU continues running Task A (1ms remaining). Task D waits.
- **9-12 ms:** Task A does I/O (3ms). CPU runs Task D (3ms).

- **14-18 ms:** Task A finishes. CPU runs Task D (4ms).

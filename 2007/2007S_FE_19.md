### Explanation
Addressing modes define how a CPU determines the effective memory address (X3) of an operand during instruction execution.
- **Direct Addressing**: The address part of the instruction (X2) directly points to the memory location of the operand. ($\text{X3} = \text{X2}$)
- **Indirect Addressing**: The address part of the instruction (X2) points to a memory location that holds the *actual* effective address of the operand. ($\text{X3} = (\text{X2})$)
- **PC-relative Addressing**: The effective address is calculated by adding the address part of the instruction (X2, treated as an offset) to the current value of the Program Counter (X1). ($\text{X3} = \text{X1} + \text{X2}$)
- **Indexed Addressing**: The effective address is calculated by adding the address part of the instruction (X2) to the value stored in an index register (X4). ($\text{X3} = \text{X2} + \text{X4}$)

This precise mapping of equations corresponds to choice b.

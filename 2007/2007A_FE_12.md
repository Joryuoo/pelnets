# 2007A_FE_12

Which of the following data structures uses the LIFO (Last In First Out) method in order to manage data?

a) Array
b) Linked list
c) Queue
d) Stack
?
d) Stack

### Explanation
- **Stack** (choice d) uses the LIFO (Last In First Out) method, meaning the last element added is the first element to be removed.
- **Queue** (choice c) uses the FIFO (First In First Out) method, where the first element added is the first one removed.
- **Array** and **Linked list** are fundamental sequential data structures that support arbitrary access or sequential traversal and do not inherently mandate LIFO or FIFO behavior.

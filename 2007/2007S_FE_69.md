# 2007S_FE_69

When a transaction fails, which of the following should be performed in order to abort it and to rebuild the previous state of the database? 

a) Archive 
b) Checkpoint dump 
c) Commit 
d) Rollback
?
d) Rollback

### Explanation
### Explanation
A rollback undoes partial changes of a transaction that has failed (aborted) before finishing successfully. It uses logs (specifically the before-images) to revert the database state to what it was right before the transaction began, ensuring atomicity.

- **Archive** refers to long-term storage of inactive data.
- **Checkpoint dump** is periodically saving database state to secondary storage to speed up recovery processes.
- **Commit** makes successful transaction changes permanent.

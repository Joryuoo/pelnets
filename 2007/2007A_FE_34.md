# 2007A_FE_34

When variables shared among tasks are updated, an unexpected result may occur if synchronous control among tasks is not performed. When the initial value of the variable x shared among tasks is 3, the final value of x is expected to be 12 if task A executes the assignment statement "x = x + x" and if task B executes the assignment statement "x = x × x." Which of the following is the appropriate execution sequence that can return the expected result? Here, each assignment statement is executed by being divided into four portions as shown below.

Task A (x = x + x)
a1: The value of x is referred to and is saved as e.
a2: The value of x is referred to and is saved as f.
a3: e + f is computed and is saved as g.
a4: The value of x is updated by means of g.

Task B (x = x × x)
b1: The value of x is referred to and is saved as h.
b2: The value of x is referred to and is saved as i.
b3: h × i is computed and is saved as j.
b4: The value of x is updated by means of j.

a) a1 -> a2 -> b1 -> b2 -> a3 -> a4 -> b3 -> b4
b) a1 -> b1 -> b2 -> b3 -> b4 -> a2 -> a3 -> a4
c) b1 -> a1 -> a2 -> a3 -> a4 -> b2 -> b3 -> b4
d) b1 -> b2 -> b3 -> a1 -> a2 -> a3 -> a4 -> b4
?
b) a1 -> b1 -> b2 -> b3 -> b4 -> a2 -> a3 -> a4

### Explanation
Let's trace the correct sequence (b) with the initial value $x = 3$:
- **a1**: Task A reads $x$, saving $e = 3$.
- **b1**: Task B reads $x$, saving $h = 3$.
- **b2**: Task B reads $x$, saving $i = 3$.
- **b3**: Task B computes $j = h \times i = 3 \times 3 = 9$.
- **b4**: Task B updates $x$ to $9$ ($x = 9$).
- **a2**: Task A reads the updated $x$, saving $f = 9$.
- **a3**: Task A computes $g = e + f = 3 + 9 = 12$.
- **a4**: Task A updates $x$ to $12$ ($x = 12$).

The final value of $x$ is 12, which matches the expected result. Other sequences will produce different final values (e.g., sequence 'a' produces 9, sequence 'c' produces 18, and sequence 'd' produces 9).

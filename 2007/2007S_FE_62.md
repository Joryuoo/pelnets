# 2007S_FE_62

Which of the following protocols is used in a TCP/IP network to provide a virtual terminal function that enables remote login to a host for remote operation? 

a) FTP 
b) HTTP 
c) SMTP 
d) TELNET
?
d) TELNET

### Explanation
### Explanation
TELNET provides a bidirectional interactive text-oriented communication facility using a virtual terminal connection over a network. It is used to remotely log in to another host and perform command-line operations.

- **FTP (File Transfer Protocol)** is for transferring files.
- **HTTP (Hypertext Transfer Protocol)** is for accessing web pages.
- **SMTP (Simple Mail Transfer Protocol)** is for sending emails.

# 2007A_FE_67

Which of the following is the appropriate description of a lock that is the exclusive control of a database?

a) If a lock is used, deadlock cannot occur.
b) Locks come in two types: shared locks, used while reading, and exclusive locks, used during a change.
c) The coarser the level of granularity of locked data is, the more concurrent transactions can be executed.
d) When deadlock occurs, the lock rolls back the transaction on both sides.
?
b) Locks come in two types: shared locks, used while reading, and exclusive locks, used during a change.

### Explanation
In database concurrency control, shared locks (read locks) allow multiple transactions to read a resource simultaneously. An exclusive lock (write lock) is required when a transaction modifies data, preventing other transactions from concurrently reading or modifying the same resource.

**Incorrect choices:**
* **a)** Using locks can actually lead to deadlocks if multiple transactions are mutually waiting on each other's locks.
* **c)** Finer granularity (locking smaller pieces of data like rows instead of whole tables) allows for more concurrent transactions, not coarser granularity.
* **d)** When a deadlock occurs, the database typically selects one transaction as a victim and rolls it back to break the deadlock; it doesn't necessarily roll back both sides.

### Explanation
Let $h$ be the cache hit ratio. The Effective Access Time ($E$) is calculated using the formula:

$E = h \times (\text{Cache Access Time}) + (1 - h) \times (\text{Main Memory Access Time})$

For System A:
$E_A = 15h + 50(1 - h) = 50 - 35h$

For System B:
$E_B = 10h + 70(1 - h) = 70 - 60h$

We are given that the effective access time is the same for both systems:
$50 - 35h = 70 - 60h$

Solving for $h$:
$60h - 35h = 70 - 50$
$25h = 20$
$h = 20 / 25 = 0.8$

Therefore, the cache hit ratio is 0.8.

# 2007A_FE_39

In some systems, the system manually or automatically determines memory blocks which are no longer referenced by a program and reorganizes the memory space so that it can be available for subsequent allocation. What is this process called?

a) Fragmentation
b) Garbage collection
c) Swapping
d) Thrashing
?
b) Garbage collection

### Explanation
Garbage collection is an automatic memory management process that identifies and frees up memory allocations that are no longer in use or referenced by a program, making them available for future allocations.
- Fragmentation is a phenomenon where memory is divided into small, scattered blocks.
- Swapping is moving processes between main memory and secondary storage.
- Thrashing is a state where the system spends more time paging than executing instructions.

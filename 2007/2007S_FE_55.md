# 2007S_FE_55

Q55. A check digit for a 4-digit number X1X2X3X4 can be calculated as follows: 
mod((X1*4+X2*3+X3*2+X4*1), 10) 
When the check digit for the 4-digit number “7X242” is equal to 6, which of the following is the correct number to be put in X2?  Here, mod (a,b) returns the remainder after “a” is divided by “b.” 

a) 5 
b) 6 
c) 7 
d) 8
?
b) 6

### Explanation
### Explanation
Given the formula for the check digit:
`Check Digit = mod((X1 * 4 + X2 * 3 + X3 * 2 + X4 * 1), 10)`

For the 4-digit number `7 X2 4 2` with a check digit of `6`, we can substitute the known values:
- X1 = 7
- X3 = 4
- X4 = 2

Substitute these into the formula:
`mod((7 * 4 + X2 * 3 + 4 * 2 + 2 * 1), 10) = 6`
`mod((28 + 3 * X2 + 8 + 2), 10) = 6`
`mod((38 + 3 * X2), 10) = 6`

Now, test the given choices for X2:
- a) If X2 = 5: `38 + 3 * 5 = 38 + 15 = 53`. `mod(53, 10) = 3` (Incorrect)
- b) If X2 = 6: `38 + 3 * 6 = 38 + 18 = 56`. `mod(56, 10) = 6` (Correct)
- c) If X2 = 7: `38 + 3 * 7 = 38 + 21 = 59`. `mod(59, 10) = 9` (Incorrect)
- d) If X2 = 8: `38 + 3 * 8 = 38 + 24 = 62`. `mod(62, 10) = 2` (Incorrect)

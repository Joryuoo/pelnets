# 2007A_FE_32

Which of the following is a method whereby the relevant program is read into main memory and the CPU reads out and executes it sequentially?

a) Addressing method
b) Direct program control method
c) Stored program method
d) Virtual memory method
?
c) Stored program method

### Explanation
The stored-program concept (often referred to as the Von Neumann architecture) is a fundamental computer architecture principle where program instructions are stored in main memory, and the CPU reads and executes them sequentially.

# 2007A_FE_72

Q72. Port scanning is the process of sending packets to check every port on each target system to see which ports are open and which ports are locked.  Which of the following information can be identified by port scanning? 

a) Computer viruses in activity 
b) Hardware configuration and compatibility 
c) Network and application services currently available 
d) Operating system in execution
?
c) Network and application services currently available

### Explanation
Port scanning is used to discover which network ports on a system are open, closed, or filtered. Since specific applications and services listen on well-known ports (like port 80 for HTTP, 25 for SMTP), port scanning allows an attacker or administrator to identify the network and application services currently available on the target system.
- **a)** Viruses usually cannot be reliably detected just by port scanning, though specific malware might open specific backdoor ports.
- **b)** Hardware configuration is not directly revealed by network port states.
- **d)** While OS fingerprinting can sometimes guess the OS based on packet behavior, port scanning primarily identifies available services.

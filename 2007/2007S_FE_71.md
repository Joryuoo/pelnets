# 2007S_FE_71

Which of the following is an appropriate description of the virus pattern file that is used in virus protection measures for computers? 

a) It is a file included in virus protection software and is used to repair files that have been infected by viruses. 
b) It is a file that records the program code of known viruses and is used to re-enact viruses to monitor their activities. 
c) It is a file that records the signature code of known viruses and is used to detect viruses by the virus protection software. 
d) It is a restoration file and is used when a data file is damaged by a virus.
?
c) It is a file that records the signature code of known viruses and is used to detect viruses by the virus protection software.

### Explanation
A virus pattern file (or signature file) contains the signature codes of known viruses, which antivirus software uses to detect them. Choice c is correct.

- **Choice a** is incorrect because a pattern file is not a repair tool.
- **Choice b** is incorrect because it is not used to re-enact viruses.
- **Choice d** is incorrect because a pattern file is not a data restoration file.

# 2007A_FE_13

In a microprocessor, there are two general registers: GRi and GRj (hereinafter referred to as GRx instead of GRi or GRj).  PUSH GRx is used for adding the contents of GRx to the top of a stack.  POP GRx is for removing the current top data of the stack and storing it to GRx.  Which of the following operations can exchange the contents of GRi and GRj?

a)  PUSH GRi
POP GRj
PUSH GRj

POP GRi

b)  PUSH GRj
POP GRi
PUSH GRi
POP GRj

c)  PUSH GRi
PUSH GRj
POP GRi
POP GRj

d)  PUSH GRi
PUSH GRj
POP GRj
POP GRi
?
c)  PUSH GRi PUSH GRj POP GRi POP GRj

### Explanation
A stack operates on a LIFO (Last-In, First-Out) principle, meaning the last value pushed will be the first value popped.
To exchange the values of GRi and GRj, you can push both to the stack and then pop them back in the reverse order:
1. `PUSH GRi` places the original value of GRi onto the stack.
2. `PUSH GRj` places the original value of GRj on top of the stack.
3. `POP GRi` removes the top item from the stack (which is the original value of GRj) and stores it in GRi.
4. `POP GRj` removes the next item from the stack (which is the original value of GRi) and stores it in GRj.

This sequence effectively swaps their contents and matches choice c).

# 2007S_FE_38

Q38. Which of the following functions can reduce the network load by placing a frequently-used instruction set on the server in advance, when accessing a database in a client/server system?

a) Group commitment function
b) Multi-thread function of server process
c) Stored procedure function
d) Two-phase commitment function
?
c) Stored procedure function

### Explanation
A stored procedure is a prepared SQL code that you can save on the database server, so the code can be reused over and over again. When a client needs to execute this set of instructions, they simply call the stored procedure instead of sending the entire set of SQL statements over the network. This reduces network traffic and load.
- a) Group commitment: Related to transaction processing efficiency, not reducing query transfer load.
- b) Multi-thread function: Improves server CPU/resource utilization.
- d) Two-phase commitment: Ensures consistency in distributed transactions.

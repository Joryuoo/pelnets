# 2007S_FE_54

Q54. Which of the following software test methods is performed to verify whether changes made for software maintenance are not affecting other portions of the software? 

a) Integration test 
b) Operation test 
c) Regression test 
d) System test
?
c) Regression test

### Explanation
### Explanation
**Regression testing** is the process of testing an existing software application to make sure that a recent change (such as adding a new feature, fixing a bug, or optimizing code) has not adversely affected existing, working functionalities.

- **Integration test:** Verifies the interfaces between components.
- **System test:** Validates the complete and fully integrated software product.
- **Operation test:** Performed in a production-like environment to verify operational readiness.

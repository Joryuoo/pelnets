# 2007A_FE_49

Which of the following is the appropriate program that supports dynamic processing in a Web environment and runs only on a Web server?

a) Java applet
b) JavaScript
c) Java servlet
d) VBScript
?
c) Java servlet

### Explanation
A **Java servlet** is a Java program that runs on a Web server (or application server). It intercepts requests from client web browsers, processes them dynamically (often by interacting with a database), and returns dynamic responses (such as generated HTML).

- **Java applets** are small Java programs that are downloaded from a server and run on the client's side (inside the web browser).
- **JavaScript** is primarily a client-side scripting language that runs in the user's web browser to create interactive effects. (Though Node.js allows it to run on the server, in the context of classic web terminology alongside Applets and Servlets, it's considered client-side).
- **VBScript** was traditionally used as a client-side scripting language in older Internet Explorer versions, or server-side in classic ASP, but Java Servlet specifically fits the description of a Java-based server-side program.

# 2007A_FE_37

Which of the following is the primary purpose to use RAID?

a) To achieve a lower hardware cost
b) To ensure higher reliability and/or performance
c) To improve data security
d) To simplify the hardware configuration for a quick and easy installation
?
b) To ensure higher reliability and/or performance

### Explanation
RAID (Redundant Array of Independent Disks) is a data storage virtualization technology that combines multiple physical disk drive components into one or more logical units for the purposes of data redundancy (reliability), performance improvement, or both.

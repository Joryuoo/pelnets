# 2007S_FE_50

In the module design of software, which of the following is the appropriate technique for improving reliability and maintainability?

a) Module cohesion is increased, and module coupling is strengthened.
b) Module cohesion is increased, and module coupling is weakened.
c) Module cohesion is reduced, and module coupling is strengthened.
d) Module cohesion is reduced, and module coupling is weakened.
?
b) Module cohesion is increased, and module coupling is weakened.

### Explanation
### Explanation
To achieve highly reliable, maintainable, and reusable software modules, standard software engineering principles recommend "High Cohesion and Low Coupling":

- **Cohesion** refers to the degree to which the elements inside a module belong together. High (increased) cohesion means the module performs a single, well-defined task.
- **Coupling** refers to the degree of interdependence between software modules. Low (weakened) coupling means modules are largely independent, so changes in one module do not heavily impact others.

Therefore, module cohesion should be increased, and module coupling should be weakened.

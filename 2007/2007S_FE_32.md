# 2007S_FE_32

Q32. Which of the following is an input device classified as a pointing device and can be used for graphical input in a CAD system?

a) Image scanner
b) OCR
c) OMR
d) Tablet
?
d) Tablet

### Explanation
A graphics tablet (or digitizing tablet) is an input device that enables a user to hand-draw images, animations, and graphics, with a special pen-like stylus. It is heavily used in CAD systems for precise graphical and pointing input.
- a) Image scanner: digitizes physical documents into images.
- b) OCR: Optical Character Recognition, used to read text from images.
- c) OMR: Optical Mark Recognition, used to read marked bubbles on forms.

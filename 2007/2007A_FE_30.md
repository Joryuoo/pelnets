# 2007A_FE_30

Which of the following technologies is used to divide each data file into blocks at constant length and to store them across multiple hard disks that can be accessed in parallel, thereby speeding up file access?

a) Disk at once
b) Disk cache
c) Disk mirroring
d) Disk striping
?
d) Disk striping

### Explanation
Disk striping is a technique (prominently used in RAID 0) where data is logically divided into blocks of a fixed size and distributed sequentially across multiple hard disks. Because the data is spread across several drives, multiple disks can be read from or written to concurrently, resulting in faster data access and higher overall performance.

Disk mirroring (used in RAID 1), by contrast, duplicates data across drives for fault tolerance, not primarily for parallel speedup.

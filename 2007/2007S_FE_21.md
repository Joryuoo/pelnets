# 2007S_FE_21

Which of the following is an appropriate statement in regard to interrupts?

a) Applications must constantly detect the occurrence of interrupts.
b) A priority is individually assigned to the cause of an interrupt in preparation for the occurrence of multiple interrupts.
c) The operation completion notice from an I/O device is classified as an internal interrupt.
d) When the CPU accepts an interrupt, it stops the program currently being executed and stores the information needed to restart the program in the designated area of the hard disk.
?
b) A priority is individually assigned to the cause of an interrupt in preparation for the occurrence of multiple interrupts.

### Explanation
Interrupts are signals sent to the CPU that temporarily halt its current operations to process a high-priority task. Priorities are assigned to various interrupt causes so that if multiple interrupts occur simultaneously, the system can determine which one to handle first based on its urgency.

- **a) is incorrect** because applications do not constantly detect interrupts. Interrupts are handled dynamically by the hardware and the operating system's interrupt handler, which interrupts the application only when necessary.
- **c) is incorrect** because an operation completion notice from an I/O device is triggered by external hardware, making it an **external** interrupt. Internal interrupts (also called traps or exceptions) arise from within the CPU, like a division by zero.
- **d) is incorrect** because when the CPU accepts an interrupt, the context (such as the program counter and registers) is saved to **main memory** (usually on the stack), not the hard disk.

### Explanation
Under the moving average method, the unit cost of inventory is recalculated after every purchase.
1. **Aug 1 (Beg. Inv):** 100 units @ $10. Total = $1,000. Avg Unit Cost = $10.
2. **Aug 5 (Purchase):** 100 units @ $12. Total cost added = $1,200. 
   New inventory = 200 units. Total value = $1,000 + $1,200 = $2,200.
   New Avg Unit Cost = $2,200 / 200 = $11.
3. **Aug 15 (Sale):** 50 units sold. Cost = 50 * $11 = $550.
   Remaining inventory = 150 units. Total value = $1,650.
4. **Aug 18 (Sale):** 100 units sold. Cost = 100 * $11 = $1,100.
   Remaining inventory = 50 units. Total value = $550. (Avg cost remains $11).
5. **Aug 20 (Purchase):** 50 units @ $15. Total cost added = $750.
   New inventory = 100 units. Total value = $550 + $750 = $1,300.
Therefore, the closing inventory value for August 31 (100 units) is $1,300.

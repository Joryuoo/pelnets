# 2007S_FE_61

Which of the following is the appropriate protocol that can deliver data from sender to receiver, correctly and in order? 

a) IP 
b) RARP 
c) SNMP 
d) TCP
?
d) TCP

### Explanation
### Explanation
TCP (Transmission Control Protocol) provides reliable, ordered, and error-checked delivery of a stream of octets (bytes) between applications running on hosts communicating over an IP network. It guarantees data delivery correctly and in order.

- **IP (Internet Protocol)** is a connectionless network layer protocol that does not guarantee delivery or order.
- **RARP (Reverse Address Resolution Protocol)** resolves a MAC address to an IP address.
- **SNMP (Simple Network Management Protocol)** is used for managing and monitoring network devices.

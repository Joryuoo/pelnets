# 2007A_FE_74

Q74. Which of the following appropriately describes a cause-and-effect diagram? 

a) It classifies the collected data into a few categories, draws the number of data for each category as a bar graph, and captures variance in quality. 
b) It classifies the data into a few categories, sorts the categories from the largest to the smallest as a bar graph along the horizontal axis, draws the cumulative values as a line graph, and sorts out problems. 
c) It expresses variance of time series data as a line graph and achieves an objectively controlled state by using control limit lines. 
d) It systematically arranges the relation between cause and effect in a fishbone format and clarifies which causes are related to particular effects.
?
d) It systematically arranges the relation between cause and effect in a fishbone format and clarifies which causes are related to particular effects.

### Explanation
A cause-and-effect diagram (also known as an Ishikawa or fishbone diagram) is used to systematically identify and arrange the potential causes of a specific effect or problem. Its structure resembles a fishbone.
- **a)** describes a histogram.
- **b)** describes a Pareto chart.
- **c)** describes a control chart.

# 2026S_FE-A_4

Q4. In regular expressions (regex), which of the following is the string that correctly matches the pattern `^\d{2,4}-\d+-\d{3,4}$` ? Here, `\d` represents a decimal digit 0-9, the `+` symbol indicates one or more repetitions, and the `$` symbol denotes the line's end. 

a) 123-456-12
b) 1-234-5678
c) 123-456-7890
d) 12345-678-910
?
c) 123-456-7890

### Explanation
Let's break down the regular expression `^\d{2,4}-\d+-\d{3,4}$`:

- `^`: Matches the start of the string.
- `\d{2,4}`: Matches between 2 and 4 decimal digits.
- `-`: Matches a literal hyphen.
- `\d+`: Matches 1 or more decimal digits.
- `-`: Matches a literal hyphen.
- `\d{3,4}`: Matches between 3 and 4 decimal digits.
- `$`: Matches the end of the string.

Now let's evaluate each option:
- **a) 123-456-12**: The last part is `12`, which has only 2 digits. It fails `\d{3,4}`.
- **b) 1-234-5678**: The first part is `1`, which has only 1 digit. It fails `\d{2,4}`.
- **c) 123-456-7890**:
  - `123` (3 digits, matches `\d{2,4}`)
  - `-` matches `-`
  - `456` (3 digits, matches `\d+`)
  - `-` matches `-`
  - `7890` (4 digits, matches `\d{3,4}`)
  - **This is a valid match.**
- **d) 12345-678-910**: The first part is `12345`, which has 5 digits. It fails `\d{2,4}`.

Therefore, the correct string is option (c).

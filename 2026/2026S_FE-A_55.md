# 2026S_FE-A_55

Which of the following is a case using deep learning in order to improve the performance of an in-car device?

a) An accelerometer detects the vehicle colliding against a wall and causes the air bag to inflate, thus protecting the passenger from injury.
b) By acquiring and processing numerous images, the driver assistance system can more reliably distinguish between a pedestrian and a vehicle.
c) By installing equipment that automatically performs idling stops, the fuel efficiency improves compared to that of a vehicle operated by a very experienced driver.
d) The navigation system updates the software via a mobile phone line and refreshes the map.
?
b) By acquiring and processing numerous images, the driver assistance system can more reliably distinguish between a pedestrian and a vehicle.

### Explanation
**Deep Learning** is a class of machine learning algorithms that uses multiple layers (deep neural networks) to progressively extract higher-level features from raw input, particularly highly effective in image and speech recognition.

- **Option a** describes a simple sensor-triggered mechanism (accelerometer triggering an actuator), which doesn't involve deep learning.
- **Option b** describes image recognition (computer vision) used in Advanced Driver Assistance Systems (ADAS). Deep learning (specifically Convolutional Neural Networks, CNNs) is heavily used to classify objects in real-time images, such as distinguishing pedestrians from vehicles.
- **Option c** describes an automatic idling stop system, which is a simple control mechanism based on vehicle speed and brake position, not deep learning.
- **Option d** describes Over-The-Air (OTA) updates for navigation maps, which is just data transmission, not deep learning.

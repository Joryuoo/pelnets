# 2026S_FE-A_16

Q16. Which of the following is a program that combines the separately compiled modules of a program into a form suitable for execution in C language?

a) Assembler
b) Compiler
c) Interpreter
d) Linker
?
d) Linker

### Explanation

In compiled languages like C, transforming human-readable source code into an executable program involves several steps and different programs:

1. **Compiler**: Translates the high-level source code (`.c` files) into machine code, outputting object modules (`.o` or `.obj` files).
2. **Assembler**: Translates assembly language into machine code (object code).
3. **Linker**: Takes one or more of these compiled object modules and combines them—resolving external symbols and linking with standard libraries—into a single executable file (`.exe` or `a.out`).

An **Interpreter**, on the other hand, directly executes instructions written in a programming or scripting language without previously compiling them into a machine language program (e.g., Python, JavaScript). 

Thus, the program that *combines* separately compiled modules into an executable form is the **Linker**.

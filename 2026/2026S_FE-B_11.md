d) A: count[k] > 0, B: i <- i + 1

### Explanation
The `countSort` function works by first counting the occurrences of each key, and then constructing the sorted array based on these counts.

1. **First Phase (Counting):**
   The program iterates through the `arr` and increments `count[k]` for each value `k = arr[i]`. `count[k]` stores the number of times `k` appears.
2. **Second Phase (Reconstruction):**
   The program iterates through all possible key values `k` from `1` to `M`.
   - **Blank A:** We only want to insert `k` into the `result` array if its count is greater than 0. The correct condition is to check if `count[k] > 0`.
   - **Blank B:** The variable `i` is used as the current index in the `result` array. After placing `k` into `result[i]`, we need to increment the index `i` by 1 so that the next element is placed in the next position. Thus, `i <- i + 1`.

| Iteration `k` | `count[k]` | `j` | `result[i]` | New `i` |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 2 | 1 | `result[1] <- 1` | 2 |
| 1 | 2 | 2 | `result[2] <- 1` | 3 |
| 2 | 0 | - | - | - |
| 3 | 1 | 1 | `result[3] <- 3` | 4 |

Therefore, the correct combination is **d**.

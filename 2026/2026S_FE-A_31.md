# 2026S_FE-A_31

Which of the following is an example of ransomware?

a) A range of different types of software including adware, spyware, and freeware
b) Malicious software blocking access to a victimized computer and demanding money to unblock it
c) Software that assigns randomized MAC addresses to PCs to ensure user privacy on the Internet
d) Software that generates the random numbers required by computer security application software
?
b) Malicious software blocking access to a victimized computer and demanding money to unblock it

### Explanation
Ransomware is a type of malicious software (malware) designed to deny access to a computer system or data until a ransom is paid. Ransomware typically spreads through phishing emails or by visiting an infected website.

- **Option (a)** refers to a variety of malware and software types but does not describe ransomware specifically.
- **Option (b)** accurately describes ransomware, as it involves blocking access and demanding money.
- **Option (c)** describes MAC randomization, a privacy-enhancing technique used by modern operating systems to prevent tracking.
- **Option (d)** describes a random number generator (RNG) used in cryptography, not ransomware.

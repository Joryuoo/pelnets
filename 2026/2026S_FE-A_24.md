# 2026S_FE-A_24

In IPv4, which of the following is a description concerning the NAT function of a router that connects some computers to the Internet? 

a) It caches the Internet access to speed up the connections when revisiting the same websites. 
b) It converts between private and global IP addresses. 
c) It inspects the IP packets during transmission to detect possible attacks and intrusions from the Internet. 
d) It only passes the IP packets intended for specific terminals.
?
b) It converts between private and global IP addresses.

### Explanation
**NAT (Network Address Translation)** is a fundamental networking technology used in routers and firewalls. Its primary purpose is to conserve public IP addresses in IPv4 by allowing an entire private network to share a single (or a few) public IP addresses.

When a device on a local network sends traffic to the Internet, the NAT router intercepts the packet and translates the internal **private IP address** (e.g., `192.168.x.x`) to its own **global (public) IP address** before forwarding it. When the response returns, the router translates the public destination IP back to the original private IP and delivers the packet.

Let's evaluate the choices:
* **a) Proxy Server:** Caching web pages to speed up subsequent visits is a function of a web proxy server.
* **b) NAT (Network Address Translation):** Correctly describes the translation between private and public (global) IP addresses.
* **c) IDS / IPS / Firewall:** Inspecting packets for attacks or intrusions describes an Intrusion Detection System, Intrusion Prevention System, or a deep-packet inspection firewall.
* **d) Packet Filtering:** Passing only packets intended for specific terminals based on rules describes a packet-filtering firewall or an Access Control List (ACL).

# 2026S_FE-A_39

Which of the following is a software development model for a small, and cross-functional team to develop a new social shopping platform, including creating user profiles, following friends, sharing products, and personalizing recommendation? Here, this platform constantly evolves, so frequent user feedback on all modules is expected.

a) Agile model
b) Prototyping model
c) Spiral model
d) Waterfall model
?
a) Agile model

### Explanation
The scenario describes a project with a small, cross-functional team, constant evolution of the platform, and a strong need for frequent user feedback across all modules.

- **Agile model:** Highly suited for small, cross-functional teams that need to adapt to changing requirements quickly. It relies on iterative development, frequent deliveries, and continuous user feedback.
- **Prototyping model:** Involves building a prototype to understand requirements, but it's not a complete methodology for continuous delivery and evolution by a cross-functional team.
- **Spiral model:** Focuses heavily on risk analysis and is typically used for large, complex, and high-risk projects, rather than small teams building rapidly evolving platforms.
- **Waterfall model:** A linear and sequential approach that is inflexible to changing requirements. It does not handle constant evolution or frequent user feedback well.

Thus, the **Agile model** is the most appropriate.

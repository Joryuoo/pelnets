# 2026S_FE-A_20

Q20. In database normalization, which of the following is the most appropriate description of a table in the third normal form? Here, 2NF stands for the second normal form and 3NF stands for the third normal form.

a) A table is in the 3NF if it is in the 2NF and no candidate key exists in the table.
b) A table is in the 3NF if it is in the 2NF and no partial dependency exists in the table.
c) A table is in the 3NF if it is in the 2NF and no repeating group exists in the table
d) A table is in the 3NF if it is in the 2NF and no transitive dependency exists in the table.
?
d) A table is in the 3NF if it is in the 2NF and no transitive dependency exists in the table.

### Explanation

Database normalization is the process of structuring a relational database to reduce data redundancy and improve data integrity. The normal forms build upon each other:

| Normal Form | Rule / Description |
|---|---|
| **First Normal Form (1NF)** | The table has a primary key, and there are **no repeating groups** (all attributes are atomic). |
| **Second Normal Form (2NF)** | The table is in 1NF, and all non-key attributes are fully functionally dependent on the primary key. This means there are **no partial dependencies**. |
| **Third Normal Form (3NF)** | The table is in 2NF, and all non-key attributes are strictly dependent on the primary key. This means there are **no transitive dependencies** (a non-key attribute cannot depend on another non-key attribute). |

Looking at the choices:
*   a) Incorrect. A candidate key must exist for normalization to be meaningful.
*   b) Incorrect. Removing partial dependency is the requirement for **2NF**, not 3NF.
*   c) Incorrect. Removing repeating groups is the requirement for **1NF**.
*   d) **Correct**. A table is in 3NF if it satisfies the requirements for 2NF and all **transitive dependencies** have been eliminated.

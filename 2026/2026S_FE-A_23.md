# 2026S_FE-A_23

Which of the following is an appropriate explanation of a log file in DBMS? 

a) A copy of the same data is written to another disk or the database of another site at all times to immediately recover the system even in the case of disk failure. 
b) The contents of the database are copied on a disk-by-disk basis to recover the database in case of disk failure. 
c) The data updated in the main memory is written to a disk to reduce the recovery processing time of the database when the system goes down. 
d) The values before and after the update of data are written, and used to perform database recovery. 
?
d) The values before and after the update of data are written, and used to perform database recovery.

### Explanation
Log files (also called transaction logs or journal logs) in a Database Management System (DBMS) are sequentially appended files that record all transactions and modifications made to the database. 

They store the **before images** (the state of the data before the update) and the **after images** (the state of the data after the update). In the event of a failure (such as a system crash or transaction abort), the DBMS uses these logs to perform:
- **Rollback (UNDO):** Using the *before images* to revert uncommitted transactions.
- **Rollforward (REDO):** Using the *after images* to reapply committed transactions that were not yet written to the physical database.

Let's evaluate the other choices:
* **a) Data replication / Mirroring:** This describes synchronous mirroring or a RAID 1 setup, not a log file.
* **b) Disk Backup:** This describes full disk-by-disk backup or imaging.
* **c) Checkpointing:** Writing updated data from main memory to disk to reduce recovery time describes the checkpoint process, which writes dirty buffers to data files.
* **d) Log file:** Correctly describes the recording of values before and after data updates for database recovery.

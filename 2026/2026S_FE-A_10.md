# 2026S_FE-A_10

Q10. Which of the following is an appropriate CPU operation associated with cache memory? 

a) When a cache hit occurs, the CPU fetches data from ROM. 
b) When a cache hit occurs, the CPU fetches data from the main memory. 
c) When a cache miss occurs, the CPU fetches data from the cache memory. 
d) When a cache miss occurs, the CPU fetches data from the main memory. 
?
d) When a cache miss occurs, the CPU fetches data from the main memory. 

### Explanation
Cache memory is a small, fast memory located close to the CPU that stores frequently accessed data to speed up processing.

- **Cache hit:** Occurs when the CPU requests data and finds it in the cache memory. The CPU directly fetches the data from the cache. (Options 'a' and 'b' are incorrect).
- **Cache miss:** Occurs when the CPU requests data but it is *not* found in the cache memory. In this case, the CPU must fetch the data from the slower **main memory** (and typically copies it into the cache for future access). 

Therefore, option (d) correctly describes the CPU operation upon a cache miss.

# 2026S_FE-B_4

![[2026S_FE-B_Q4_full.png]]
?
f) num mod 10, integer part of (num ÷ 10), n mod sum = 0

### Explanation
The function checks if an integer $n$ is a Harshad number (divisible by the sum of its digits). 

- To find the sum of the digits, we isolate each digit starting from the least significant digit.
- **A**: The last digit of a base-10 number `num` is obtained using the modulo operator `num mod 10`. This digit is added to the running `sum`.
- **B**: To move to the next digit, the last digit must be removed from `num`. This is achieved by dividing `num` by $10$ and taking the integer part: `integer part of (num ÷ 10)`.
- **C**: After the `while` loop finishes, `sum` contains the sum of all digits of $n$. We check if $n$ is divisible by `sum` with no remainder, which is represented by `n mod sum = 0`.

Thus, the correct combination is **f**.

# 2026S_FE-A_8

Q8. Which of the following is the appropriate description of constructors in Object-Oriented Programming (OOP)? 

a) Constructors are invoked only after an object has been fully instantiated. 
b) In class-based OOP, constructors do not play any role in object creation or initialization. 
c) Constructors are responsible for initializing objects in class-based OOP. 
d) Constructors are inherited by subclasses exactly like regular methods in all class-based OOP languages. 
?
c) Constructors are responsible for initializing objects in class-based OOP. 

### Explanation
In Object-Oriented Programming (OOP), a **constructor** is a special method used to initialize a newly created object. 

- **a) Incorrect.** Constructors are invoked *during* the instantiation process to set the initial state of the object, not after it's fully created.
- **b) Incorrect.** Object creation and initialization are the exact purposes of constructors in class-based OOP.
- **c) Correct.** The primary role of a constructor is to initialize the attributes of an object when it is instantiated.
- **d) Incorrect.** In most class-based OOP languages (like Java or C++), constructors are *not* inherited by subclasses like regular methods; subclasses must define their own constructors (though they can call a superclass constructor).

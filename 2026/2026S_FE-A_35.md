# 2026S_FE-A_35

Among UML 2.x diagrams (including 2.0 and later versions), which of the following is the most appropriate diagram for providing a graphic overview of the actors involved in a system, the different functions those actors need to perform and how these different functions interact?

a) Activity diagram
b) Communication diagram
c) Interaction overview diagram
d) Use case diagram
?
d) Use case diagram

### Explanation
A **Use Case Diagram** is the primary UML diagram used to model the functional requirements of a system. It shows the relationship between "actors" (users or other external systems) and "use cases" (the functions or tasks the system provides).

- **Activity diagram:** Shows the flow of control or object flow, focusing on the sequence of actions and conditions (similar to a flowchart).
- **Communication diagram:** Models the interactions between objects or parts in terms of sequenced messages.
- **Interaction overview diagram:** A variant of an activity diagram that provides an overview of the flow of control where each node can be an interaction diagram.
- **Use case diagram:** Provides a graphic overview of actors and their functions, exactly matching the description in the question.

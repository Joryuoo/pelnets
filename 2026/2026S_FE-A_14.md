# 2026S_FE-A_14

Q14. Which of the following is the CPU utilization in percentage rounded to a decimal number when three (3) jobs with 30% average I/O (Input/Output) wait time are running on a single CPU? Here, I/O wait time refers to the percentage of time a job is waiting for its I/O operation to complete.

a) 10
b) 34
c) 90
d) 97
?
d) 97

### Explanation

This problem can be modeled using the principles of multiprogramming.

Let $p$ be the average I/O wait time for a single job as a probability.
Here, $p = 30\% = 0.3$.

When $n$ independent jobs are running concurrently, the CPU will only be idle if **all $n$ jobs are simultaneously waiting for I/O**.
The probability that all $n$ jobs are waiting for I/O is given by $p^n$.

Given $n = 3$ jobs:
$\text{CPU Idle Time Probability} = p^3 = (0.3)^3 = 0.027$

This means the CPU is idle for $2.7\%$ of the time.

The CPU utilization is the percentage of time the CPU is not idle:
$\text{CPU Utilization} = 1 - \text{CPU Idle Time Probability}$
$\text{CPU Utilization} = 1 - 0.027 = 0.973 = 97.3\%$

Rounding $97.3\%$ to the nearest whole decimal number gives **$97\%$**.

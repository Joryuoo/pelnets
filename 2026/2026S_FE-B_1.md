### Explanation
The program executes as follows:
| Instruction | `x` | `y` | `z` | `ar` |
| --- | --- | --- | --- | --- |
| `integer: x <- 1` | 1 | | | |
| `integer: y <- 2` | 1 | 2 | | |
| `integer: z <- 3` | 1 | 2 | 3 | |
| `integer []: ar <- {0, 0}` | 1 | 2 | 3 | `{0, 0}` |
| `y <- x` | 1 | 1 | 3 | `{0, 0}` |
| `ar[x] <- y` (`ar[1] <- 1`) | 1 | 1 | 3 | `{1, 0}` |
| `z <- y` | 1 | 1 | 1 | `{1, 0}` |
| `x <- z` | 1 | 1 | 1 | `{1, 0}` |
| `ar[2] <- z + ar[1]` (`ar[2] <- 1 + 1`) | 1 | 1 | 1 | `{1, 2}` |

Finally, `output ar[1], ar[2]` prints `1, 2`. Thus, the correct answer is **c**.

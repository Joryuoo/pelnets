# 2026S_FE-A_11

Q11. What is the theoretical maximum data transfer rate in MB/s for the external bus of a 64-bit microprocessor that uses a 64-bit external data bus driven by a 64 MHz input clock? Here, it takes 4 input clock cycles to complete 1 bus cycle.

a) 12.8
b) 128
c) 512
d) 1280
?
b) 128

### Explanation

To find the theoretical maximum data transfer rate, we need to determine how many bytes are transferred per second. 

**Step 1: Determine the Data Bus Width in Bytes**
The external data bus is 64-bit wide. 
Since $1 \text{ byte} = 8 \text{ bits}$, the number of bytes transferred per bus cycle is:
$64 \text{ bits} / 8 \text{ bits/byte} = 8 \text{ bytes}$

**Step 2: Calculate the Bus Clock Frequency**
The input clock frequency is $64 \text{ MHz}$.
It takes $4 \text{ input clock cycles}$ to complete $1 \text{ bus cycle}$.
The bus clock frequency is:
$64 \text{ MHz} / 4 = 16 \text{ MHz}$
This means there are $16 \text{ million bus cycles per second}$.

**Step 3: Calculate the Maximum Data Transfer Rate**
Now we multiply the number of bytes transferred per cycle by the number of bus cycles per second.
$16 \text{ MHz} \times 8 \text{ bytes/cycle} = 128 \text{ MB/s}$

Therefore, the theoretical maximum data transfer rate is $128 \text{ MB/s}$.

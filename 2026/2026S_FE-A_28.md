# 2026S_FE-A_28

Which of the following is multi-factor authentication? 

a) Authentication by answer to a Security Question and other thing the user knows 
b) Authentication by fingerprint and other biometrics 
c) Authentication by password and one-time code generated by a smartphone application 
d) Authentication by username and password
?
c) Authentication by password and one-time code generated by a smartphone application

### Explanation
**Multi-Factor Authentication (MFA)** requires users to provide at least two *different* categories (factors) of credentials to verify their identity. Relying on multiple instances of the *same* factor is still considered single-factor authentication.

The three primary authentication factors are:
1. **Something you know (Knowledge):** Passwords, PINs, security questions.
2. **Something you have (Possession):** Smartphones (authenticator apps, SMS), physical hardware tokens, smart cards.
3. **Something you are (Inherence):** Biometrics such as fingerprints, facial recognition, iris scans.

Let's evaluate the options based on these factors:
* **a) Security question (Know) + Other thing you know (Know):** Both are knowledge factors. This is single-factor authentication.
* **b) Fingerprint (Are) + Other biometrics (Are):** Both are inherence factors. This is single-factor authentication.
* **c) Password (Know) + One-time code from a smartphone (Have):** This combines a knowledge factor and a possession factor. It correctly implements Multi-Factor Authentication.
* **d) Username (Identifier) + Password (Know):** A username is just an identity claim, and the password is a single knowledge factor. This is standard single-factor authentication.

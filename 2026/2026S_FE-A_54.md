# 2026S_FE-A_54

Which of the following is an appropriate example of utilizing machine learning at a production site?

a) Causes of defect occurrence in a factory are decomposed and arranged in a tree shape for analysts to statistically investigate the cause and solution.
b) Instead of programming the working method for the production robot in the factory, the robot itself learns, thus improving work efficiency.
c) Production equipment in a factory is connected through high-speed communication so that the host computer can be controlled in real time.
d) Productivity of employees in the factory improves each time the cumulative production volume doubles, and the unit cost reduces at a fixed percentage.
?
b) Instead of programming the working method for the production robot in the factory, the robot itself learns, thus improving work efficiency.

### Explanation
**Machine Learning (ML)** is a subset of artificial intelligence where systems learn and improve from experience without being explicitly programmed.

- **Option a** describes the use of a fault tree analysis or decision tree created for human analysts, which is a traditional statistical/analytical method, not machine learning.
- **Option b** describes reinforcement learning or robotic machine learning, where the robot autonomously discovers the optimal working method through learning rather than being explicitly programmed. This is a classic application of ML.
- **Option c** describes the Internet of Things (IoT) or factory automation (e.g., SCADA), not machine learning.
- **Option d** describes the "learning curve effect" or experience curve in economics and human productivity, which has nothing to do with artificial intelligence or machine learning.

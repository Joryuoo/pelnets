# 2026S_FE-A_37

Which of the following is an appropriate explanation of encapsulation in object orientation?

a) Abstraction and grouping of several objects that have common properties
b) Bundling of data and procedures operating on the data as a single object and concealing their implementation inside the object
c) Creation of a base class by extracting the properties that are common among classes
d) Inheritance of the properties of a base class by a subclass
?
b) Bundling of data and procedures operating on the data as a single object and concealing their implementation inside the object

### Explanation
In Object-Oriented Programming (OOP), the four main principles are Encapsulation, Abstraction, Inheritance, and Polymorphism.

- **Encapsulation:** The bundling of data (attributes) and methods (procedures) that operate on the data into a single unit (an object), and restricting direct access to some of the object's components (information hiding). This matches **option (b)**.
- **Abstraction:** Hiding complex implementation details and showing only the essential features of the object. **Option (a)** relates more to classification/abstraction.
- **Inheritance:** A mechanism wherein a new class is derived from an existing class. **Option (c)** defines generalization (creating a base class), and **option (d)** defines inheritance directly.

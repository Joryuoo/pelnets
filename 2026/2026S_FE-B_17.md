   - **Event/Result:** Multiple `auth_fail` (InvalidPassword) in rapid succession.
   - **Analysis:** This pattern shows repeated failed login attempts against a single user account from a single source. This matches the characteristic of a **brute force attack**.

2. **Table 3 (Pattern B):**
   - **Source IP:** `198.51.100.45` (constant)
   - **Username:** `john.smith`, `emma.jones`, `michael.brown`, `sarah.miller`, etc. (varying)
   - **Event/Result:** A mix of `auth_fail` and occasional `auth_success`.
   - **Analysis:** This pattern shows attempts to log in across many different user accounts using previously compromised credentials, where a few attempts succeed. This perfectly matches a **credential stuffing attack**.

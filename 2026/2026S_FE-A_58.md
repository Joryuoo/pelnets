# 2026S_FE-A_58

A factory manager is planning the costs for the next two years. Instead of using a single estimate, the manager runs thousands of simulations where material prices, customer demand, and labor costs vary randomly within realistic ranges. This creates a probability distribution of possible costs, helping in risk planning and setting contingency budgets. Which of the following is an analytical method that the manager is using?

a) Linear Programming
b) Monte Carlo Analysis
c) Scenario Analysis
d) Sensitivity Analysis
?
b) Monte Carlo Analysis

### Explanation
**Monte Carlo Analysis** is a mathematical technique used to model the probability of different outcomes in a process that cannot easily be predicted due to the intervention of random variables. It works by running thousands (or millions) of simulations, randomly sampling values from defined probability distributions for each variable, to generate a comprehensive distribution of possible outcomes.

- **Option a** (Linear Programming) is an optimization technique to find the maximum or minimum of a linear objective function.
- **Option c** (Scenario Analysis) involves evaluating the expected value under a limited number of specific, defined scenarios (e.g., best case, worst case, most likely case).
- **Option d** (Sensitivity Analysis) determines how different values of an independent variable affect a particular dependent variable under a given set of assumptions, usually changing one variable at a time (e.g., a tornado diagram).

### Explanation
The problem requires converting an 11-bit Unicode code point into a 2-byte UTF-8 encoding.
The bit pattern is: `110xxxxx 10xxxxxx`.
- The first byte (Byte 1) contains the upper 5 bits of the code point.
- The second byte (Byte 2) contains the lower 6 bits of the code point.

To isolate the lower 6 bits of an integer, we perform a modulo operation by $2^6$ (which is 64).
- `codePoint mod 64` returns the lower 6 bits.
These bits are added to the base value `128` (binary `10000000`) for the second byte.

To isolate the upper 5 bits of the 11-bit code point, we need to shift the bits right by 6 positions. In decimal math, this is equivalent to integer division by $2^6$ (64).
- `integer part of (codePoint ÷ 64)` returns the upper 5 bits.
These bits are added to the base value `192` (binary `11000000`) for the first byte.

Thus, both blanks should be filled with **64**.

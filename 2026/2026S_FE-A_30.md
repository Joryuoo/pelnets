# 2026S_FE-A_30

Which of the following is an appropriate description of a Trojan horse?

a) A brute force attack software tool 
b) A malicious computer program that presents itself as legitimate 
c) A malicious user that steals private information from a system 
d) A software tool to decrypt an encrypted password
?
b) A malicious computer program that presents itself as legitimate

### Explanation
A **Trojan horse** (or simply Trojan) is a type of malicious software (malware) that misleads users of its true intent. Deriving its name from the ancient Greek story of the deceptive wooden horse that led to the fall of Troy, a computer Trojan **presents itself as a legitimate, useful, or benign program** to trick the user into installing it. 

Once installed, it can perform various malicious activities such as stealing data, establishing backdoors, or downloading additional malware. Unlike viruses and worms, Trojans typically **do not self-replicate**.

Let's evaluate the other choices:
* **a) Brute force attack tool:** A program used to guess passwords by systematically trying all possible combinations (e.g., John the Ripper, Hashcat).
* **b) Trojan horse:** Correct. A program disguised as legitimate software.
* **c) Malicious user:** Describes a threat actor (hacker, insider threat), which is a human being, not a piece of software.
* **d) Decryption tool:** Describes password cracking tools or cryptographic utilities, not a Trojan.

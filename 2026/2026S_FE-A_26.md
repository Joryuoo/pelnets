# 2026S_FE-A_26

Which of the following is a role played by a DNS in a TCP/IP network? 

a) It assigns an unused IP address from the pool of addresses in response to a request from a PC or a printer. 
b) It associates domain or host names with IP addresses. 
c) It converts private IP addresses used within a company into global IP addresses and enables access to the Internet. 
d) It enables a program in a server to be called only by its name without being aware of the IP address of the server.
?
b) It associates domain or host names with IP addresses.

### Explanation
**DNS (Domain Name System)** is often referred to as the "phonebook of the Internet." Humans interact with computers online through easily memorable domain names (such as `google.com`), but web browsers and network routers interact using Internet Protocol (IP) addresses (such as `192.168.1.1` or `2001:db8::1`). 

The primary role of DNS is to resolve (translate) these human-readable domain names into machine-readable IP addresses, allowing devices to locate each other on a TCP/IP network.

Let's break down the other options to identify the technologies they describe:
* **a) DHCP (Dynamic Host Configuration Protocol):** Dynamically assigns unused IP addresses from a predefined pool to devices (PCs, printers) as they join the network.
* **b) DNS (Domain Name System):** Correct. It associates and maps domain/host names with IP addresses.
* **c) NAT (Network Address Translation):** Converts internal private IP addresses to external global IP addresses for Internet access.
* **d) RPC / Port Mapper:** Enabling a program on a server to be called by its name is usually handled by Remote Procedure Call (RPC) directories or middleware endpoint mappers, not DNS. DNS maps the *host* name, not the specific *program*.

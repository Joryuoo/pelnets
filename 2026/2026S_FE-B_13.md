### Explanation
The function `extractEmails` is designed to extract valid email addresses from a text string.
The variable `atIndex` holds the position of the `@` symbol found by `findSubstring`.
An email consists of a `name` before the `@` and a `domain` after it.

The `for` loop containing the blank is responsible for scanning the characters *before* the `@` symbol to extract the `name` part of the email address.
- We need to scan backwards from the position immediately before the `@` symbol, which is `atIndex - 1`.
- The scanning should stop when we hit an invalid character or reach the `index` (the starting point of the current search segment).
- Since we are scanning backwards, we must **decrease** the loop variable `i`.

Therefore, the loop should iterate backwards: `decrease i from atIndex - 1 to index`. This corresponds to option **a**.

| Variable | Value | Description |
| :--- | :--- | :--- |
| `atIndex` | Position of `@` | The anchor point for the email address. |
| `i` | `atIndex - 1` | The character immediately preceding `@`. We decrease this to collect the username. |
| `candidate`| Extracted string | Characters are prepended to this string to form the correct username. |

The domain extraction is handled by the subsequent loop `for (increase i from atIndex + 1 to length(txt) by 1)`.

# 2026S_FE-A_25

Which of the following is a data link layer function that enables a receiver to control the amount of data a sender transmits?

a) Congestion control 
b) Error control 
c) Flow control 
d) Media access control
?
c) Flow control

### Explanation
**Flow control** is a crucial mechanism used in data communication (particularly at the Data Link Layer and Transport Layer) to synchronize the rate of data transmission between a fast sender and a slow receiver. It ensures that the sender does not transmit data faster than the receiver's buffer can process it, preventing data loss due to buffer overflows.

Common flow control techniques at the Data Link Layer include:
- **Stop-and-Wait:** The sender waits for an acknowledgment before sending the next frame.
- **Sliding Window:** The sender can send multiple frames up to a specified "window" size before requiring an acknowledgment.

Let's evaluate all choices:
* **a) Congestion control:** A mechanism (usually at the Transport or Network Layer, e.g., TCP congestion window) used to monitor and manage traffic to prevent bottlenecks across an entire network, rather than just between two adjacent nodes.
* **b) Error control:** A technique used to detect and correct errors that occur during transmission (e.g., Checksum, CRC, Parity bits, ARQ).
* **c) Flow control:** The correct answer. It enables the receiver to dictate the maximum amount of data the sender can transmit at one time.
* **d) Media access control (MAC):** A sublayer function of the Data Link Layer that determines how devices share and gain access to a physical transmission medium (e.g., CSMA/CD, CSMA/CA).

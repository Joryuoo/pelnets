### Explanation
When inserting a new node of value 11 into a binary search tree (BST), we compare the value 11 with the nodes starting from the root:

1. **Root node (14):** $11 < 14$, so go to the **left child**.
2. **Current node (7):** $11 > 7$, so go to the **right child**.
3. **Current node (12):** $11 < 12$, so go to the **left child**.
4. **Current node (10):** $11 > 10$, so go to the **right child**.
5. The right child of 10 is empty, so we insert the new node `11` as the **right child of 10**.

This matches option (d).

# 2026S_FE-A_43

Which of the following is an appropriate meaning of a mission-critical system? 

a) As with an operating system, it is an indispensable system necessary for operating a business system. 
b) It is a system that has a significant impact on corporate activities and society when a failure occurs. 
c) It is a system that is first installed on a trial basis, and if successful, a full-scale installation is implemented. 
d) It is a system with operating performance close to the limit. 
?
b) It is a system that has a significant impact on corporate activities and society when a failure occurs.

### Explanation
A **mission-critical system** is a system that is essential to the survival of a business or organization. If a mission-critical system fails or is interrupted, business operations are severely impacted, potentially causing significant financial loss, legal issues, or societal harm. 

| Term | Explanation |
|---|---|
| **Mission-critical system** | A system whose failure will cause catastrophic consequences for the organization. Reliability, availability, and fault tolerance are highest priorities. |
| **Operating system** | Basic software that manages computer hardware and software resources, essential for running applications but not the definition of "mission-critical" itself. |
| **Pilot/Trial system** | A system installed on a limited basis for testing before full-scale implementation. |

Therefore, choice **b** perfectly encapsulates the definition.

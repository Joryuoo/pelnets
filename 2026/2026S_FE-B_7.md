### Explanation
The function recursively searches for a `searchKey` in a global array `D` starting from the last element (index $N$) down to the first element (index $1$).

- **A**: If the element at the current `index` matches the `searchKey` (`D[index] = searchKey`), the function should return the position where it was found. Thus, the missing statement is `return Index` (note the capital 'I' as per the options). 
- **B**: If the current element does not match, the function must recursively search the preceding element in the array. This is done by decrementing the index by $1$. The recursive call should thus pass `index - 1`.

Therefore, the correct choices are `Index` and `index - 1`, making **d** the answer.

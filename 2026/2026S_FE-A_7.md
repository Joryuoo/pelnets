### Explanation
The function $F(x, y)$ is defined recursively and computes the **greatest common divisor (GCD)** of $x$ and $y$ using the Euclidean algorithm:
- $F(x, y) = x$ if $y = 0$
- $F(x, y) = F(y, x \bmod y)$ if $y > 0$

We want to evaluate $F(231, 15)$:

1. $F(231, 15)$: Since $15 > 0$, we calculate $231 \bmod 15$.
   - $231 = 15 \times 15 + 6$, so $231 \bmod 15 = 6$.
   - The next call is $F(15, 6)$.
2. $F(15, 6)$: Since $6 > 0$, we calculate $15 \bmod 6$.
   - $15 = 6 \times 2 + 3$, so $15 \bmod 6 = 3$.
   - The next call is $F(6, 3)$.
3. $F(6, 3)$: Since $3 > 0$, we calculate $6 \bmod 3$.
   - $6 = 3 \times 2 + 0$, so $6 \bmod 3 = 0$.
   - The next call is $F(3, 0)$.
4. $F(3, 0)$: Since $y = 0$, the function returns $x$, which is $3$.

Thus, $F(231, 15) = 3$.

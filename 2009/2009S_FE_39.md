# 2009S_FE_39

Which of the following tasks is performed in the external design phase of the waterfall model?

a) Code design
b) Detailed input/output design
c) Module partitioning
d) Physical file design
?
a) Code design

### Explanation
### Explanation
In traditional software development methodologies (like those standardized in Japan and often tested in PhilNITS), the **External Design** phase focuses on specifications from the user's perspective. This includes UI design (screens, forms) and logical data design, which encompasses **Code design** (determining the structure and meaning of identification codes used by end users, such as product codes, department codes, or employee IDs).

- **Module partitioning** (c) and **Physical file design** (d) focus on the internal system architecture and data storage, which belong to the **Internal Design** phase.

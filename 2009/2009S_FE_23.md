# 2009S_FE_23

There is a hard disk drive that has the following specifications.

[Specifications]
Capacity: 512 GBytes
Number of cylinders: 1024
Number of platters: 5 (10 surfaces)
Number of heads: 2 per platter

How many bytes can be stored in one track of this hard disk drive? Here, each track has the same capacity. 1 GByte is $10^9$ bytes, and 1 Mbyte is $10^6$ bytes.

a) 50 Kbytes
b) 100 Kbytes
c) 50 Mbytes
d) 100 Mbytes
?
c) 50 Mbytes

### Explanation
### Explanation
Total capacity = 512 Gbytes = $512 \times 10^9$ bytes.
Number of surfaces = 10.
Number of heads: 2 per platter. A platter has 2 surfaces, so 5 platters have 10 surfaces. 2 heads per platter = 10 heads total, corresponding to 10 surfaces.
A cylinder is the set of tracks across all surfaces at a given radius.
Number of tracks per surface = Number of cylinders = 1024.
Total tracks = (number of surfaces) * (number of cylinders) = 10 * 1024 = 10,240.
Capacity per track = Total capacity / Total tracks
$= \frac{512 \times 10^9}{10,240} = \frac{512}{1024 \times 10} \times 10^9 = \frac{1}{20} \times 10^9 = 0.05 \times 10^9 = 50 \times 10^6$ bytes = 50 Mbytes.

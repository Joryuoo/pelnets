# 2009A_FE_55

Which of the following is the local broadcast address to be used by a computer with IP address 202.130.17.63 and subnet mask 255.255.255.0 if classless addressing is used?

a) 202.130.0.0
b) 202.130.0.1
c) 202.130.17.1
d) 202.130.17.255
?
d) 202.130.17.255

### Explanation
The subnet mask `255.255.255.0` indicates that the first 24 bits are the network address and the last 8 bits (the last octet) are the host addresses.
- The network address is found by setting all host bits to 0, which results in `202.130.17.0`.
- The local broadcast address is found by setting all host bits to 1. Since the last octet is all 1s in binary (`11111111`), the decimal value is 255.
Therefore, the broadcast address is `202.130.17.255`.

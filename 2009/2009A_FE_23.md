# 2009A_FE_23

Which of the following is a method that serves to enhance the reliability of memory access and makes it possible to automatically correct some of data errors?

a) Checksum
b) CRC
c) ECC
d) Party
?
c) ECC

### Explanation
### Explanation
ECC (Error-Correcting Code) memory is used to enhance the reliability of memory access by automatically detecting and correcting some data errors, such as single-bit errors.

- **Checksum & CRC (Cyclic Redundancy Check):** Used for error detection, typically in data transmission, but generally cannot correct errors on their own.
- **Parity (Party is a typo in the question):** Used for error detection (single-bit errors) but does not have error correction capabilities.

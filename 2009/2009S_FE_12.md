# 2009S_FE_12

Which of the following is the minimum possible depth of a binary tree with 14 nodes?

a) 0
b) 3
c) 4
d) 5
?
b) 3

### Explanation
### Explanation
The depth of a root node is 0. A binary tree achieves its minimum depth when it is completely filled (a perfect or complete binary tree).
The maximum number of nodes in a binary tree of depth $d$ is $2^{d+1} - 1$.
- For depth 0, max nodes = $2^1 - 1 = 1$
- For depth 1, max nodes = $2^2 - 1 = 3$
- For depth 2, max nodes = $2^3 - 1 = 7$
- For depth 3, max nodes = $2^4 - 1 = 15$

Since 14 nodes can fit in a tree of depth 3 (which holds up to 15 nodes), the minimum possible depth is 3.

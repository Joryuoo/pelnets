# 2009A_FE_38

Which of the following is the main purpose of optimization performed by a compiler?  

a) To improve the maintainability of a program  
b) To make it easy to debug a program at source code level  
c) To reduce program execution time  
d) To reduce the time to generate an object program
?
c) To reduce program execution time

### Explanation
Compiler optimization is a process where the compiler attempts to produce an object program (machine code) that executes faster or uses less memory, while retaining the same functionality as the original source code.

- **a) Incorrect**: Optimization occurs at the machine code level and does not affect source code maintainability.
- **b) Incorrect**: Optimization often complicates debugging at the source code level because the resulting machine code may not map linearly to the source lines.
- **c) Correct**: The primary goal is to minimize execution time (and sometimes memory footprint).
- **d) Incorrect**: Optimization actually *increases* compilation time.

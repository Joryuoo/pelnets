# 2009A_FE_27

Which of the following input devices is classified as a pointing device and used for graphics input in a CAD system?

a) Image scanner
b) OCR
c) OMR
d) Tablet
?
d) Tablet

### Explanation
### Explanation
A tablet (also known as a digitizing tablet or graphics tablet) is a pointing device widely used in CAD (Computer-Aided Design) systems and digital art for precise graphics input.

- **Image scanner:** Digitizes physical documents into images.
- **OCR (Optical Character Recognition):** Software/hardware used to recognize text within images.
- **OMR (Optical Mark Recognition):** Used to read pencil marks on predefined forms, such as multiple-choice test answer sheets.

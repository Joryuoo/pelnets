# 2009A_FE_45

Which of the following is the appropriate point to notice at the time of creating the test data for a white box test?

a) The boundary values for each equivalent class obtained with the application of equivalence partitioning
b) The functions of the program
c) The internal structures, such as the algorithm, for the program
d) The relationships between the input and output of the program
?
c) The internal structures, such as the algorithm, for the program

### Explanation
White box testing involves verifying the internal structures, logic, and algorithms of a program. Therefore, test data is created based on these internal workings. Choices (a), (b), and (d) describe techniques used in black box testing, where the internal structure is ignored.

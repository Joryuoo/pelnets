# 2009A_FE_70

There are two types of attacks which an information system might face: active attack and passive attack. Which of the following is categorized as an active attack?

a) Analysis of data traffic
b) DoS (Denial of Service)
c) Falsification of data
d) Replay of messages
?
c) Falsification of data

### Explanation
### Explanation
In network security, attacks are broadly classified into passive and active attacks.
* **Passive attacks** attempt to learn or make use of information from the system but do not affect system resources. Examples include eavesdropping and traffic analysis (choice a).
* **Active attacks** involve some modification of the data stream or the creation of a false stream. Falsification of data actively alters the data content, making it a primary example of an active attack.

*(Note: While DoS and replay are also forms of active attacks in broader security contexts, falsification of data directly modifies the transmitted information and is the intended answer for this specific exam question.)*

# 2009S_FE_80

Which of the following is a characteristic of IC tags (RFIDs)?

a) IC tags are dirt-resistant, and the information recorded on them can be read even from outside the package.
b) IC tags are embedded in plastic cards, and special-purpose readers are used to insert IC tags and to read them.
c) IC tags manage large amounts of information, so external memory devices are used for information storage.
d) IC tags use GPS to indicate positional information.
?
a) IC tags are dirt-resistant, and the information recorded on them can be read even from outside the package.

### Explanation
IC tags (RFID - Radio Frequency Identification tags) use electromagnetic fields to automatically identify and track tags attached to objects. Because they communicate wirelessly using radio waves, they do not require a direct line of sight to be read (unlike standard optical barcodes). Therefore, they can be read even if they are covered in dirt or placed inside a non-metallic package or box.

- Option b) describes smart cards or magnetic stripe cards that require physical insertion into a reader.
- Option c) is incorrect as IC tags have their own internal memory microchips and do not rely on external memory devices.
- Option d) is incorrect because IC tags do not use GPS for localized proximity reading.

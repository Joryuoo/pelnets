# 2009S_FE_13

Which of the following appropriately describes a characteristic of linked lists?

a) It is not used for a homogeneous collection of elements.
b) The elements are always stored in a physically contiguous area.
c) The elements can be stored only in a dynamic way, not in a static way.
d) The elements cannot be accessed directly or randomly.
?
d) The elements cannot be accessed directly or randomly.

### Explanation
### Explanation
Linked lists are composed of nodes that are linked sequentially using pointers. To access an element, you must traverse the list from the beginning (the head node) and follow the pointers one by one until the desired element is reached.

- **a) is incorrect** because linked lists are frequently used for homogeneous collections of elements.
- **b) is incorrect** because nodes in a linked list can be scattered randomly in memory; they do not need to be physically contiguous.
- **c) is incorrect** because while typically dynamic, linked lists can be implemented statically using arrays.
- **d) is correct** because direct or random access (like `array[5]`) is impossible; sequential traversal is required.

# 2009A_FE_3

Which of the following is the appropriate reason why the mantissa is normalized in the floating point representation?

a) The arithmetic operation algorithm can be simplified.
b) The maximum number of significant digits can be maintained.
c) The range of representable values can be expanded.
d) The relative size relationships can be investigated as if in fixed point numbers.
?
b) The maximum number of significant digits can be maintained.

### Explanation
### Explanation
In floating-point representation, the mantissa (or significand) is normalized by shifting its bits so that the most significant digit is non-zero (usually an implicit leading `1` in binary). This ensures that no bits are wasted on leading zeros, allowing the maximum possible number of significant digits to be stored in the limited number of bits allocated for the mantissa. This maximizes the precision of the represented numbers.

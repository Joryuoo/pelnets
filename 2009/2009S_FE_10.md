### Explanation
We need to find an expression equivalent to $S - (T \cup R)$.
Using set theory and De Morgan's laws:
$S - (T \cup R)$ is the set of elements that are in $S$ but not in $(T \cup R)$.
This means the elements must be in $S$, AND they must NOT be in $T$, AND they must NOT be in $R$.
Mathematically, this is:
$S \cap (T \cup R)' = S \cap (T' \cap R') = (S \cap T') \cap R'$
This can be rewritten using the set difference operator:
$(S \cap T') \cap R' = (S - T) \cap R' = (S - T) - R$.

Thus, $S - (T \cup R)$ is equivalent to $(S - T) - R$.

# 2009S_FE_71

Which of the following is a meta-language that includes self-defining markup symbols called tags to describe the content of a Web page or file and supports bi-directional hyperlinks with high affinity to the Internet?

a) HTML
b) SGML
c) UML
d) XML
?
d) XML

### Explanation
XML (eXtensible Markup Language) is a meta-language that allows users to define their own customized markup languages. It uses self-defining markup symbols (tags) and is designed to transport and store data. It is highly affiliated with the Internet and supports bi-directional hyperlinks (e.g., using XLink).

- **HTML:** HyperText Markup Language is used for displaying web pages but uses predefined tags, not self-defining ones.
- **SGML:** Standard Generalized Markup Language is the complex precursor to XML and HTML, but XML is more specifically designed for web affinity and simplicity compared to SGML.
- **UML:** Unified Modeling Language is a visual modeling language for software engineering, not a markup language for documents.

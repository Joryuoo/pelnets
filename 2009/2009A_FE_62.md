# 2009A_FE_62

Which of the following is a non-updatable view?

a) A view for a view
b) A view including a "GROUP BY" clause in the view definition
c) A view including a "WHERE" clause in the view definition
d) A view not including the primary key of the original table
?
b) A view including a "GROUP BY" clause in the view definition

### Explanation
### Explanation
A view that includes an aggregate function or a `GROUP BY` clause is generally considered non-updatable. This is because the rows in the view represent aggregated data, and there is no direct mapping to individual rows in the underlying base tables to perform updates, inserts, or deletes.

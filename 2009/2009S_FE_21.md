The figure shows the Base Register Addressing mode (also often overlapping with Indexed addressing mode in simple descriptions). The register number indicates an index or base register, which is added to the address constant (instruction part) to get the main memory address. Thus, it is **Indexed addressing mode**.
- Direct addressing: The instruction directly contains the actual address.
- Register indirect: The instruction specifies a register that holds the target address.
- Relative: Uses the program counter plus an offset.

# 2009A_FE_54

Which of the following is the appropriate statement concerning the number of host addresses available to one sub-network in IPv4?

a) The number of host addresses available in a sub-network is always fixed, depending on the class of IP address; 28 for class A, 216 for class B, and 224 for class C.
b) The number of host addresses available in a sub-network is always fixed, depending on the class of IP address; 224 for class A, 216 for class B, and 28 for class C.
c) The number of host addresses available in a sub-network is determined by the number of “0” bits in the subnet mask.
d) The number of host addresses available in a sub-network is determined by the number of “1” bits in the subnet mask.
?
c) The number of host addresses available in a sub-network is determined by the number of “0” bits in the subnet mask.

### Explanation
An IPv4 subnet mask divides the IP address into a network portion and a host portion.
- The "1" bits in the subnet mask correspond to the **network and sub-network** portion.
- The "0" bits in the subnet mask correspond to the **host** portion.
Therefore, the number of "0" bits determines how many addresses are available for hosts within that sub-network. If there are $n$ "0" bits, the number of available host addresses is $2^n - 2$ (subtracting the network address and the broadcast address).

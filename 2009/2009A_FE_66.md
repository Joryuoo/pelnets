# 2009A_FE_66

When secret documents are sent and received using public key cryptography, which of the following is an appropriate description of the key management?

a) The decryption key must be kept private, but the encryption key is public.
b) The encryption and decryption keys may be public, but the encryption algorithm must be kept private.
c) The encryption key may be public, but the encryption algorithm must be kept private.
d) The encryption key must be kept private, but the decryption key is public.
?
a) The decryption key must be kept private, but the encryption key is public.

### Explanation
### Explanation
In public key cryptography (asymmetric cryptography), a key pair is used consisting of a public key and a private key. When sending a secret document, the sender uses the recipient's **public key** to encrypt the document (making the encryption key public). Only the recipient can decrypt it using their corresponding **private key** (which must be kept private).

Therefore, the decryption key is private, while the encryption key is public.

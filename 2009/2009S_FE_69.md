# 2009S_FE_69

Which of the following is an appropriate description concerning Internet VPN security?

a) A virtual network is configured, so there is no way to prevent a third party that is not qualified to participate in the network from wiretapping or falsification.
b) The virtual tunnel of Internet VPN is a dedicated channel between specified LANs, so there is no function for protecting data that passes along this route from wiretapping.
c) There is no capability for identifying individual people who are qualified to participate in the network.
d) There is no risk of abusing the IP address for unauthorized access or intrusion, so there is no need to encrypt the entire packet including the IP address.
?
c) There is no capability for identifying individual people who are qualified to participate in the network.

### Explanation
Internet VPNs (particularly Site-to-Site IPsec VPNs) establish a secure, encrypted tunnel between network gateways (like routers or firewalls). The endpoints mutually authenticate each other, securing the channel between the networks.

However, this means the VPN authenticates the connected devices/gateways, not the individual users originating the traffic on the LAN. Thus, it does not inherently identify specific individuals.

- Choices (a) and (b) are incorrect because VPNs use encryption to prevent wiretapping and falsification.
- Choice (d) is incorrect because there is still a risk, and protocols like IPsec Tunnel Mode do encrypt the original packet, encapsulating it within a new IP header.

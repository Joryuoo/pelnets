# 2009A_FE_32

There is a fault-tolerant computer system with high reliability and availability in which two CPUs perform the same processing and compare the processing results to each other.  If one CPU fails, the system cuts off the failed CPU and continues processing on the other CPU.  What is this system configuration called?  

a) Dual system 
b) Duplex system  
c) Load sharing system  
d) Multiprocessing system
?
a) Dual system

### Explanation
A dual system features two CPUs operating in parallel and performing the same processing simultaneously. Their results are cross-checked. If a mismatch or failure occurs, the failed component is isolated, and processing continues seamlessly on the active component.

- **a) Correct**: A dual system matches this exact description.
- **b) Incorrect**: A duplex system has an active (primary) system processing data and a standby (secondary) system that takes over only when the primary fails.
- **c) Incorrect**: In a load sharing system, multiple computers distribute the workload among themselves.
- **d) Incorrect**: A multiprocessing system uses multiple processors within a single computer to execute multiple tasks concurrently.

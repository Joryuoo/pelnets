# 2009S_FE_15

When a list of seven elements shown below is rearranged in ascending order, which of the following sorting algorithms is completed with the minimum number of element exchanges?

15
14
13
12
11
10
9

a) Bubble sort
b) Insertion sort
c) Selection sort
d) Shell sort
?
c) Selection sort

### Explanation
### Explanation
The given list is sorted in strictly descending (reverse) order, and we want to sort it in ascending order.

- **Bubble sort** and **Insertion sort** only swap adjacent elements. In a reverse-sorted list of $N$ elements, they will perform the maximum possible number of exchanges: $\frac{N(N-1)}{2}$. For $N=7$, this is 21 swaps.
- **Selection sort** works by finding the minimum element in the unsorted portion and swapping it with the first element of that portion. Regardless of the initial order of the list, Selection sort makes exactly one swap per pass. For a list of 7 elements, it performs a maximum of 6 exchanges.
- **Shell sort** uses gap sequences and will also perform more than 6 exchanges on a completely reversed list.

Therefore, Selection sort guarantees the minimum number of element exchanges.

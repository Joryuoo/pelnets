# 2009S_FE_44

Q44. Which of the following combinations is described in a UML class diagram?  

a) Activation, lifeline, object  
b) Attribute, operation, role name  
c) Final state, initial state, transition  
d) Link, message flow, object
?
b) Attribute, operation, role name

### Explanation
### Explanation
A **Class Diagram** describes the static structure of a system by showing its classes, their attributes, operations (or methods), and the relationships among objects. "Attribute, operation, role name" are key elements found in a class diagram.
- a) Activation and lifeline are used in **Sequence Diagrams**.
- c) Final state, initial state, and transition are used in **State Machine Diagrams**.
- d) Link and message flow are used in **Communication Diagrams** (or Sequence Diagrams).

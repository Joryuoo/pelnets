### Explanation
The SQL query performs a `NATURAL JOIN` on tables `T1`, `T2`, and `T3`. A `NATURAL JOIN` matches rows with equal values in columns that share the same name.
- `T1` and `T2` share column `C`.
- The result of `T1 NATURAL JOIN T2` shares column `D` with `T3`.

First, joining `T1` and `T2` on `C`:
- `T1` row with `C=1` (`B=10`) matches `T2` row `(1, 1)` → `D=1`
- `T1` row with `C=1` (`B=20`) matches `T2` row `(1, 1)` → `D=1`
- `T1` row with `C=2` (`B=30`) matches `T2` row `(2, 2)` → `D=2`
- `T1` row with `C=4` (`B=40`) matches `T2` row `(4, 1)` → `D=1`

Next, joining this intermediate result with `T3` on `D`:
- For `D=1`, the intermediate result has 3 rows (where `B=10`, `20`, `40`, sum is 70). `T3` has two rows where `D=1`. The join matches each intermediate row with both `T3` rows, duplicating them. Thus, the sum of `B` becomes $70 \times 2 = 140$.
- For `D=2`, the intermediate result has 1 row (`B=30`). `T3` has one row where `D=2`. The join yields one match, so the sum of `B` is 30.

Finally, grouping by `T3.D`, the output gives `D=1, SUM(B)=140` and `D=2, SUM(B)=30`.

# 2009S_FE_4

There is an 8-bit numerical value, where a negative number is represented in two’s 
complement.  When this value is represented in decimal, it becomes -100.  When 
this value is regarded as an unsigned number, which of the following is the correct 
value in decimal?  
 
a) 28 
b) 100 
c) 156 
d) 228
?
c) 156

### Explanation
For an 8-bit number, the unsigned representation of a negative two's complement value can be found by adding $2^n$ (where $n$ is the number of bits) to the negative decimal value:
$2^8 + (-100) = 256 - 100 = 156$
Therefore, the unsigned decimal representation of the same 8-bit binary string is 156.

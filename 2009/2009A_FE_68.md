# 2009A_FE_68

Which of the following is an appropriate explanation of Web beacons?

a) Images embedded in Web pages to gather information such as user access trends
b) Latent errors in application programs used on Web sites
c) Unauthorized techniques to inflict damage on both PCs and Web servers themselves, through malicious script
d) Viruses downloaded from Web sites that delete image files on a PC
?
a) Images embedded in Web pages to gather information such as user access trends

### Explanation
### Explanation
A **Web beacon** (also known as a tracking pixel or web bug) is typically a transparent, 1x1 pixel image embedded in a webpage or email. When the user loads the page, the image is fetched from a server, which logs the request. This is used to track user access trends, monitor behavior, and gather analytics data.

The other options describe vulnerabilities, attacks, or malware.

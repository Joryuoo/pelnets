# 2009A_FE_41

Which of the following is the activity performed during the external design phase in system development?

a) Logical data design
b) Physical data design
c) Requirements analysis
d) Structured program design
?
a) Logical data design

### Explanation
The external design phase in system development is primarily concerned with defining the logical structure of the system from the user's perspective, including logical data design and user interfaces. Physical data design and structured program design are performed during the internal design phase, while requirements analysis precedes external design.

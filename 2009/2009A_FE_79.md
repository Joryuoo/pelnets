### Explanation
This is a flow shop scheduling problem that can be solved using Johnson's Rule to minimize the total processing time (makespan) for two machines.

The processing times are:
- Product A: M1 = 7, M2 = 3
- Product B: M1 = 5, M2 = 6
- Product C: M1 = 4, M2 = 2

Johnson's Rule steps:
1. Find the shortest processing time among all products for both machines. The absolute shortest time is 2 for C on M2.
2. If the shortest time is on the second machine, schedule that job last. So, C is scheduled last.
3. The next shortest time is 3 for A on M2. A is scheduled just before C.
4. The remaining product B must be scheduled first.

This gives the optimal processing sequence: B → A → C.

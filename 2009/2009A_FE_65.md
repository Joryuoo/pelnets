# 2009A_FE_65

Which of the following files is used for writing the values before and after a database update, and storing them as a database update record?

a) Backup file
b) Checkpoint file
c) Dump file
d) Journal file
?
d) Journal file

### Explanation
### Explanation
A **journal file** (or log file) records the details of all database updates, specifically the values before the update (before-image) and the values after the update (after-image). This is essential for database recovery operations like rollback and rollforward.

* **a) Backup file** / **c) Dump file**: Contains a full copy of the database at a specific point in time, not a record of individual updates.
* **b) Checkpoint file**: Records the synchronization points where modified data in memory is written to disk.

# 2009A_FE_67

In the context of message authentication code, which of the following is the purpose of using message digests?

a) To check a summary of the message
b) To check the message encryption method
c) To confirm that no message has been tampered with
d) To ensure message confidentiality
?
c) To confirm that no message has been tampered with

### Explanation
### Explanation
A **message digest** (or hash value) is primarily used to ensure data integrity. By computing a hash of the message and sending it alongside the message as part of a Message Authentication Code (MAC), the receiver can recompute the hash and compare it. If they match, it confirms that the message has not been altered or tampered with during transmission.

It does not provide confidentiality (which requires encryption) or indicate the encryption method.

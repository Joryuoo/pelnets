# 2009S_FE_56

Which of the following is the network topology that is used to connect one central node or hub with point-to-point links to several other nodes?

a) Bus
b) Mesh
c) Ring
d) Star
?
d) Star

### Explanation
In a **Star topology**, all peripheral nodes (like computers and printers) are connected individually to a single central node (such as a hub or a switch) via point-to-point links. All data traffic passes through the central device.

- **Bus topology:** All nodes are connected to a single, continuous central cable (the backbone).
- **Mesh topology:** Nodes are connected to multiple other nodes (or all other nodes in a full mesh) for redundancy.
- **Ring topology:** Each node is connected to exactly two other nodes, forming a closed continuous loop.

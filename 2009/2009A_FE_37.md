# 2009A_FE_37

Which of the following performs reasoning using a knowledge base?  

a) Expert system 
b) Fuzzy computer  
c) Neural network 
d) Virtual reality
?
a) Expert system

### Explanation
An expert system is a computer system that emulates the decision-making ability of a human expert. It consists of a knowledge base (containing rules and facts) and an inference engine (which applies the rules to the data to deduce new information).

- **a) Correct**: Expert systems use a knowledge base for reasoning.
- **b) Incorrect**: Fuzzy computing uses fuzzy logic for reasoning with degrees of truth, rather than a strict knowledge base.
- **c) Incorrect**: Neural networks use interconnected nodes to learn from data patterns without explicit logical rules.
- **d) Incorrect**: Virtual reality is a simulated experience, completely unrelated to knowledge-based reasoning.

# 2009S_FE_27

A color video clip is displayed in full-screen mode on a PC at 30 frames/second, with each screen comprising 300,000 pixels and 256 colors displayed at the same time. Under these conditions, which of the following is the approximate amount of data (in megabytes) that can be displayed in one minute? Here, the data is not compressed.

a) 77
b) 270
c) 540
d) 2,300
?
c) 540

### Explanation
### Explanation
- 256 colors require 8 bits (1 byte) per pixel, because $2^8 = 256$.
- Data per frame = 300,000 pixels $\times$ 1 byte/pixel = 300,000 bytes.
- Frames per second = 30.
- Data per second = 300,000 bytes/frame $\times$ 30 frames/second = 9,000,000 bytes/second.
- Data per minute (60 seconds) = 9,000,000 bytes/second $\times$ 60 seconds = 540,000,000 bytes.
- Since 1 Megabyte is roughly $10^6$ bytes, 540,000,000 bytes $\approx$ 540 Megabytes.

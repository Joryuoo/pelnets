### Explanation
The binary number $x$ consists of $2n$ digits arranged alternately as $1010...10_2$.
This can be written as:
$x = 2^{2n-1} + 2^{2n-3} + \dots + 2^1$
If we divide $x$ by 2 (which shifts the bits one place to the right), we get:
$x/2 = 0101...01_2 = 2^{2n-2} + 2^{2n-4} + \dots + 2^0$
Adding $x$ and $x/2$ yields a sequence of $2n$ ones:
$x + x/2 = 1111...11_2$
A binary number with $2n$ ones is equal to $2^{2n} - 1$.
Therefore, $x + x/2 = 2^{2n} - 1$, which matches choice b.

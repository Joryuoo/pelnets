# 2009A_FE_21

Which of the following is used to hold the address of the instruction being executed or the address of the next instruction to be executed, and is automatically incremented after fetching an instruction?

a) Accumulator
b) Base address register
c) Index register
d) Program counter
?
d) Program counter

### Explanation
### Explanation
The Program Counter (PC) holds the address of the next instruction to be executed and is automatically incremented after fetching an instruction.

- **Accumulator:** A register used to store intermediate arithmetic and logic results.
- **Base address register:** Holds the base address used in base addressing mode.
- **Index register:** Used for modifying operand addresses during the execution of a program.

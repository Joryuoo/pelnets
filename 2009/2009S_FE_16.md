# 2009S_FE_16

When a program (or a function) calls itself recursively, which of the following data structures is suitable for storing the data that is currently used in the program?

a) Array
b) Linked list
c) Stack
d) Tree
?
c) Stack

### Explanation
### Explanation
When a function makes a recursive call to itself, the current execution context (including local variables, parameter values, and the return address) must be saved so execution can correctly resume after the recursive call finishes.

This follows a Last-In, First-Out (LIFO) pattern: the most recently called function is the first one to finish and return. A **Stack** is the data structure that inherently operates on the LIFO principle, making it the standard and ideal choice for managing recursive function calls in system memory (the call stack).

# 2009A_FE_69

Which of the following is an appropriate description concerning security measures for network systems?

a) By using a circuit-switched network with closed-area connection functions, limiting connections to particular user groups is an effective way to prevent unauthorized external access.
b) In ISDN and packet-switched lines, it is possible to confirm the other party based on the subscriber number which is received in notification at the time of connection. This is referred to as callback.
c) Installing a line encryption device between DTEs (such as communication control units and terminal equipment) and DCEs (such as modems and DSUs) as an encryption method for each transmission segment requires modification of some existing hardware and software.
d) Using a wireless LAN is an effective way to prevent interception of transmissions because there is no cable in between.
?
a) By using a circuit-switched network with closed-area connection functions, limiting connections to particular user groups is an effective way to prevent unauthorized external access.

### Explanation
### Explanation
Choice **a)** is correct because employing a closed user group (CUG) on a circuit-switched network effectively isolates communications from external parties, preventing unauthorized access from outside the defined group.

* **b)** is incorrect because confirming the caller ID is not "callback." Callback involves dropping the call and dialing the user back at a pre-registered number.
* **c)** is incorrect because line encryption devices placed between DTE and DCE usually operate transparently, meaning existing hardware/software does not necessarily require modification.
* **d)** is incorrect because wireless LAN transmissions use radio waves, making them *more* susceptible to interception compared to cabled networks unless properly encrypted.

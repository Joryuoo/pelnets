# 2009A_FE_20

Which of the following architectures in a uniprocessor requires multiple functional units that can execute two or more instructions in parallel during a clock cycle by simultaneously dispatching the instructions to the functional units?

a) Pipeline
b) Super-pipeline
c) Superscalar
d) VLIW
?
c) Superscalar

### Explanation
- **Superscalar** architecture implements instruction-level parallelism within a single processor. It allows multiple instructions to be executed simultaneously in a single clock cycle by dispatching them to multiple execution units.
- **Pipeline** architecture divides instruction execution into sequential stages, overlapping them, but normally dispatches one instruction per clock cycle.
- **Super-pipeline** relies on deeper pipelines (more stages) to increase the clock speed, but still fundamentally dispatches one instruction per cycle.
- **VLIW** (Very Long Instruction Word) relies on the compiler to pack multiple independent operations into a single long instruction, whereas superscalar relies on hardware to dynamically dispatch instructions in parallel.

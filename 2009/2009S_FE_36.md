# 2009S_FE_36

When a corporate intranet is connected to the Internet, which of the following mechanisms works as a bridge to access the Internet, enables high-speed access by caching Web content, and then is used to ensure security?

a) DMZ
b) Firewall
c) IP masquerade (NAPT)
d) Proxy
?
d) Proxy

### Explanation
### Explanation
A **Proxy server** acts as an intermediary for requests from clients seeking resources from other servers. It caches frequently accessed web pages, enabling high-speed access for subsequent requests. It also provides security by hiding the internal network's IP addresses and filtering potentially harmful traffic.

- A **Firewall** (b) provides security by monitoring and filtering traffic based on rules but does not inherently cache web content.
- **IP Masquerade (NAPT)** (c) translates IP addresses but lacks caching features.
- A **DMZ** (a) is a physical or logical subnetwork that contains and exposes an organization's external-facing services to the Internet, rather than a specific caching mechanism.

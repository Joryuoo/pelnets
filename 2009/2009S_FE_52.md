# 2009S_FE_52

The person in charge of operating a sales management system has decided to rearrange the customer master file records in cooperation with the system users in the sales department. Which of the following is an appropriate policy for rearranging the master file?

a) Before deleting a customer record, it is necessary to first check that the customer code is not used anywhere within the sales management system and related systems.
b) Even if there are multiple records for the same customer, as long as the keys are different this is not a problem for sales data analysis, so the records can be left as is.
c) The records of customers who did not make purchases during the current month are to be physically deleted at the end of the month from the viewpoint of space efficiency.
d) The records of customers who made purchases during the current month are assumed to be correct, so these contents are not subject to checks.
?
a) Before deleting a customer record, it is necessary to first check that the customer code is not used anywhere within the sales management system and related systems.

### Explanation
When maintaining a master file, it is critical to preserve **referential integrity**. If a customer record is deleted from the master file while its customer code is still referenced in other transaction files or related systems (like past orders or invoices), it will create "orphaned" records. This leads to system errors and data inconsistencies. Thus, verifying that the customer code is not in use elsewhere is a necessary check before deletion.

- **b is incorrect:** Duplicate records for the same customer (even with different keys) will distort sales data analysis and cause inconsistencies.
- **c is incorrect:** Deleting a customer just because they didn't purchase anything in the current month is poor practice, as customers may order irregularly over time.
- **d is incorrect:** Even recent data can contain errors (like typos or wrong addresses), so assuming it is perfectly correct without verification is flawed.

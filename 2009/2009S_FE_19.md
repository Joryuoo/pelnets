# 2009S_FE_19

Which of the following is a high-speed memory technology that uses flip-flop circuits?

a) DRAM
b) RDRAM
c) SDRAM
d) SRAM
?
d) SRAM

### Explanation
### Explanation
- **SRAM (Static Random Access Memory)** stores each bit using a bistable latching circuitry (flip-flops) made of multiple transistors. As long as power is supplied, it holds its data without needing to be refreshed. It is very fast and typically used for CPU cache.
- **DRAM (Dynamic Random Access Memory)** stores bits using capacitors and transistors. Since capacitors leak charge, DRAM requires periodic refreshing to retain data, making it slower than SRAM but cheaper and much denser.
- **SDRAM** and **RDRAM** are specific architectural implementations of DRAM.

Therefore, SRAM is the correct high-speed memory technology using flip-flop circuits.

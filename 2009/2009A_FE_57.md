# 2009A_FE_57

When MAC (Media Access Control) frames defined by IEEE 802.3 are transmitted over Ethernet, which of the following methods is used for error detection?

a) Checksum
b) CRC
c) Hamming code check
d) Parity check
?
b) CRC

### Explanation
In Ethernet (IEEE 802.3), the MAC frame includes a 32-bit Frame Check Sequence (FCS) field at the end of the frame. This field is used exclusively for error detection and is calculated using a **CRC (Cyclic Redundancy Check)** algorithm over the frame's contents. If the receiving end computes a different CRC, it assumes the frame was corrupted during transmission and discards it.

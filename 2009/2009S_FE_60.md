c) Instructor - Student

### Explanation
The image presents three tables: `Student`, `Instructor`, and `Result`.

The `Student` table contains names like Jack Smith, Tom Brown, Nancy Anderson, etc.
The `Instructor` table contains names like Susan White, Paul Miller, Jack Smith, Betty Wilson, Tom Brown.

The `Result` table contains:
- Susan White
- Paul Miller
- Betty Wilson

Notice that the `Result` table consists of exactly the names that appear in the `Instructor` table but do NOT appear in the `Student` table (Jack Smith and Tom Brown are removed because they appear in both).

In relational algebra, this is known as the **Set Difference** (or MINUS) operation. Therefore, the result is derived using the expression `Instructor - Student`.

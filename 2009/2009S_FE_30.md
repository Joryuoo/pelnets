# 2009S_FE_30

Which of the following is the appropriate purpose of using semaphores?

a) For avoiding the occurrence of slashing
b) For implementing segmentation
c) For implementing stacks easily
d) For managing shared resources
?
d) For managing shared resources

### Explanation
### Explanation
A semaphore is a synchronization mechanism used in operating systems and concurrent programming to control access to shared resources by multiple processes or threads, thereby preventing race conditions.
- "slashing" is a typo/mistranslation for "thrashing" (caused by excessive page faults), which is unrelated to semaphores.
- Segmentation and stacks are memory management concepts, unrelated to semaphores.

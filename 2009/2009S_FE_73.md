# 2009S_FE_73

![[2009S_FE_AM_Q73_full.png]]
?
c)

### Explanation
We can calculate the inventory value using the periodic average cost method:

1. First, calculate the total quantity and cost of goods available for sale during the month.
   - Beginning inventory: 100 units at $30 = $3,000
   - March 6 Purchase: 50 units at $50 = $2,500
   - March 17 Purchase: 50 units at $40 = $2,000
   - Total Units Available: 100 + 50 + 50 = 200 units
   - Total Cost: $3,000 + $2,500 + $2,000 = $7,500
2. Calculate the weighted average unit cost:
   - Average Unit Cost = Total Cost / Total Units Available = $7,500 / 200 = $37.50 per unit
3. Calculate the ending inventory quantity:
   - Ending units = 100 (Start) + 50 (In) - 50 (Out) + 50 (In) - 100 (Out) = 50 units
4. Calculate the ending inventory value:
   - Inventory Value = 50 units * $37.50 = $1,875

Thus, the correct answer is c) 1,875.

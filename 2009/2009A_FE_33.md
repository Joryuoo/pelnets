# 2009A_FE_33

Which of the following is an appropriate explanation of fault-tolerant systems?  

a) Even in the event of a partial system failure, the system as a whole can provide necessary operational capabilities.  
b) In preparation for local disasters, there is a backup system available in a remote site.  
c) Individual transactions are processed in parallel by multiple processors and the results are compared.  
d) Resources are shared among multiple processors connected via a network.
?
a) Even in the event of a partial system failure, the system as a whole can provide necessary operational capabilities.

### Explanation
Fault tolerance is the property that enables a system to continue operating properly in the event of the failure of one or more faults within some of its components.

- **a) Correct**: This is the definition of fault tolerance, ensuring system availability despite partial failures.
- **b) Incorrect**: This describes a disaster recovery or remote backup system.
- **c) Incorrect**: This describes a dual system (a specific type of fault-tolerant configuration, but not the general definition).
- **d) Incorrect**: This describes a distributed or grid computing system.

### Explanation
The flowchart algorithm swaps the values of variables `x` and `y` without using a third temporary variable. It ensures `x` holds the larger value and `y` holds the smaller value.

Since it checks `y > x` and takes the 'Yes' path, `y` is currently the larger one. We need to swap them. The sequence `x + y → x`, `x - y → y`, `x - y → x` performs this mathematical swap:
1. `x_new = x + y`
2. `y_new = x_new - y = (x + y) - y = x`
3. `x_final = x_new - y_new = (x + y) - x = y`

Thus `x` and `y` are successfully swapped in place.

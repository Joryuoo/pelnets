# 2009A_FE_47

When the cost associated with information systems can be broken down into the initial cost and the running cost, which of the following is included in the initial cost?

a) Amortization cost for equipment and facilities
b) Development cost of application software
c) Personnel cost associated with operations
d) Rental or lease cost of equipment
?
b) Development cost of application software

### Explanation
The development cost of application software is an upfront, one-time expense incurred before the system goes live, making it an initial cost. Amortization, operations personnel costs, and equipment rental are all ongoing expenses classified as running costs.

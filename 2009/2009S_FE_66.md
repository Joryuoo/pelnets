# 2009S_FE_66

In public key cryptography, which of the following key can be used for decrypting the data that is encrypted by using the server’s public key?

a) Client’s private key
b) Client’s public key
c) Server’s private key
d) Server’s public key
?
c) Server’s private key

### Explanation
In public key cryptography (asymmetric encryption), keys are generated in pairs: a public key and a private key. Data encrypted with one key from the pair can only be decrypted by the other key from that same pair. 

Therefore, if data is encrypted using the server's public key (which is freely shared), it can only be decrypted using the server's securely guarded private key.

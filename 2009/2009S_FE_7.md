# 2009S_FE_7

Which of the following operations does not change the lower 4 bits of an 8-bit string?  
 
a) A logical product (i.e. AND) with a bit string 0F in hexadecimal  
b) A logical sum (i.e. OR) with a bit string 0F in hexadecimal  
c) A negative logical product (i.e. NAND) with a bit string 0F in hexadecimal  
d) An exclusive logical sum (i.e. exclusive OR) with a bit string 0F in hexadecimal
?
a) A logical product (i.e. AND) with a bit string 0F in hexadecimal

### Explanation
A bitwise AND operation with `1` preserves the original bit, while an AND with `0` clears the bit.
The hexadecimal value `0F` corresponds to binary `0000 1111`.
Performing a logical product (AND) with `0F` will:
- Clear (set to 0) the upper 4 bits because they are ANDed with `0000`.
- Preserve the lower 4 bits because they are ANDed with `1111`.
Thus, a logical product with `0F` does not change the lower 4 bits.

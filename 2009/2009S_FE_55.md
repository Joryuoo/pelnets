# 2009S_FE_55

Which of the following protocols is supported by the transport layer of the OSI basic reference model?

a) HTTP
b) IP
c) PPP
d) TCP
?
d) TCP

### Explanation
The OSI (Open Systems Interconnection) basic reference model consists of 7 layers. **TCP (Transmission Control Protocol)** operates at the **Transport layer (Layer 4)**. It is responsible for establishing a reliable, connection-oriented data transfer between two hosts.

- **HTTP (Hypertext Transfer Protocol):** Operates at the Application layer (Layer 7).
- **IP (Internet Protocol):** Operates at the Network layer (Layer 3).
- **PPP (Point-to-Point Protocol):** Operates at the Data Link layer (Layer 2).

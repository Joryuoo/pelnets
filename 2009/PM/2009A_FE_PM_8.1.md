### Explanation

- **Blank A:** The function `prn_final_status` prints "CONGRATULATIONS - You won!" if the player has more wins than losses. The correct condition is `win_cnt > lose_cnt` (Choice d). Choices like a or b (`win_cnt < lose_cnt` or `win_cnt <= lose_cnt`) would incorrectly print a win when the player lost or tied.
- **Blank B:** The function prints "A DRAW - You tied!" if the number of wins equals the number of losses. The correct condition is `win_cnt == lose_cnt` (Choice c).
- **Blank C:** In the `compare` function, a tie happens if the player's choice is exactly the same as the machine's choice. The correct condition is `player_choice == machine_choice` (Choice c).
- **Blank D:** In `report_and_tabulate`, when the result is a win, the program needs to increment the integer value pointed to by `win_cnt_ptr`. In C, `++*win_cnt_ptr` (Choice a) correctly dereferences the pointer and increments the integer value. Choice b (`++win_cnt_ptr`) would increment the memory address pointer instead of the value. Choice e (`*win_cnt_ptr++`) would increment the pointer first due to operator precedence.
- **Blank E:** When `game` is selected by the player, the program is supposed to print the current game status. The correct function call is `prn_game_status(win_cnt, lose_cnt, tie_cnt)` (Choice b). Choices a and c would incorrectly call the final status or help functions.

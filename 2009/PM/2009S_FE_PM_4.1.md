### Explanation

The algorithm constructs a Binary Search Tree (BST) over an array by dynamically adjusting linked list pointers (`Upper` and `Lower`). It effectively partitions a linked list into two sublists (elements `<` pivot and elements `>=` pivot) similar to Quicksort, then recursively processes them.

- **Blank A (`g` - `Upper[Data]`)**: Inside the `While (Data != -1)` loop, the algorithm iterates through the linked list of elements currently attached to `Upper[Root]`. Before reassigning `Upper[Data]` to insert `Data` into a new sublist, it must save the pointer to the next node in the original list. Thus, `Next ← Upper[Data]`.

- **Blank B (`h` - `Upper[Root]`)**: When `S[Data].Height >= S[Root].Height`, the element belongs to the "greater than or equal" group (the right subtree). The algorithm pushes `Data` to the front of the list stored at `Upper[Root]`. To prepend it, the node's next pointer must point to the current head: `Upper[Data] ← Upper[Root]`, followed by updating the head `Upper[Root] ← Data`.

- **Blank C (`b` - `Data`)**: When `S[Data].Height < S[Root].Height`, the element belongs to the "less than" group (the left subtree). It is prepended to the list stored at `Lower[Root]`. The algorithm uses `Upper[Data]` as the standard linkage pointer for the new sublist (so that recursive calls can uniformly process lists found in `Upper`). It sets `Upper[Data] ← Lower[Root]`, and then updates the head `Lower[Root] ← Data`.

- **Blank D (`d` - `Lower[Root]`)**: The `DisplayData` function prints the elements in ascending order by performing an in-order traversal (Left, Root, Right). Since elements with smaller heights are routed to the `Lower` branch and larger heights to the `Upper` branch, the first recursive call must traverse the left subtree: `DisplayData(Lower[Root])`.

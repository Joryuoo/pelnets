- **Blank A (a)**: The `Cipher` class contains both implemented methods (`encrypt()` and `decrypt()`) and abstract methods (`encode()` and `decode()`). In Java, a class containing abstract methods must be declared as an `abstract class`.
  - *Incorrect choices*: `interface` is wrong because it cannot contain implemented methods (prior to Java 8). `class` or `final class` is wrong because they cannot contain abstract methods.
- **Blank B (b)**: The loop iterates through the characters of the `String word`. In Java, the length of a `String` is obtained using the method `length()`, not the property `length` (which is used for arrays).
  - *Incorrect choices*: Choices using `word.length` cause compilation errors. Decrementing loops (`k--`) typically start at `length() - 1`, whereas the incorrect options start at `length()` causing out-of-bounds errors.
- **Blank C (d)**: For the Caesar cipher decryption, characters are shifted backward by 3 positions. In Java, the modulo operator `%` applied to a negative number yields a negative result, which would map to an invalid character. To avoid this, shifting backward by 3 is mathematically equivalent to shifting forward by 23 (`26 - 3 = 23`). Therefore, adding 23 ensures the result is always positive before the modulo operation.
  - *Incorrect choices*: Choice (a) uses `- 3`, which fails for letters like 'a', 'b', and 'c' due to negative modulo results.
- **Blank D (b)**: The `Transpose` class is one of the cipher implementations and must inherit from `Cipher`. In Java, a class inherits from an abstract class using the `extends` keyword.
  - *Incorrect choices*: `implements` is used for interfaces, not classes.

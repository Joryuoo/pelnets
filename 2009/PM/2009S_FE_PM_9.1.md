* **Blank A (c):** In the `main` method, after instantiating the `Staff` class into the `personnel` object, we need to call its `payday()` method to process the payments. This is done via `personnel.payday()`. Calling `payday()` alone (choice a) is incorrect because it is not a static method in the `Firm` class.
* **Blank B (c):** The array `staffList` is declared to hold `StaffMember` references. The element at `staffList[0]` is initialized as an `Executive`. The `awardBonus()` method is only defined in the `Executive` class, not in `StaffMember`. Thus, to invoke it, we must downcast the reference to `Executive`: `((Executive)staffList[0])`.
* **Blank C (d):** Similarly, `staffList[2]` holds an `Hourly` object. The `addHours()` method belongs only to the `Hourly` class, so we must downcast the reference to `Hourly` before making the call: `((Hourly)staffList[2])`.
* **Blank D (d):** The `payday()` method loops through `staffList`. To calculate each employee's pay polymorphically, it must call the overridden `pay()` method for each specific `StaffMember` subtype. Therefore, `staffList[count].pay()` dynamically invokes the correct `pay()` method based on the object's actual class.
* **Blank E (g):** In the `Employee` class, overriding `toString()` requires appending the Social Security Number to the base staff information. Instead of duplicating the `name`, `address`, and `phone` logic, we call the parent class's `toString()` method using `super.toString()`.
* **Blank F (b):** The `Executive` class constructor accepts `socSecNumber` and `rate`, which it passes to its `super(...)` constructor. These fields belong to the `Employee` class, which means `Executive` inherits from (`extends`) `Employee`.
* **Blank G (d):** In the `Hourly` class (which inherits from `Employee`), the inherited fields must be initialized by calling the parent class constructor. The correct syntax to invoke the superclass constructor in Java is `super(...)`, passing all the required arguments: `super(eName, eAddress, ePhone, socSecNumber, rate)`.

# 2009S_FE_62

When a program accesses relational database tables by means of embedded SQL statements, which of the following SQL statements is used to define the derived table?

a) CLOSE
b) DECLARE CURSOR
c) FETCH
d) OPEN
?
b) DECLARE CURSOR

### Explanation
In embedded SQL, a cursor is used to handle queries that return multiple rows. The `DECLARE CURSOR` statement associates a cursor name with a specific `SELECT` query, defining the derived table (result set). 

- `OPEN` executes the query and populates the result set.
- `FETCH` retrieves individual rows one at a time.
- `CLOSE` releases the cursor and frees associated resources.

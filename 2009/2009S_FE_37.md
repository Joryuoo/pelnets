# 2009S_FE_37

Which of the following is an appropriate explanation of data mining?

a) A database storage method for accumulating large volumes of chronological data such as sales performance and actual manufacturing results
b) A parallel access method for searching large volumes of data at high speed
c) A technique for creating departmental databases in accordance with the purpose of use
d) A technique that uses statistical and mathematical methods to analyze large volumes of data in order to discover rules and causal relationships
?
d) A technique that uses statistical and mathematical methods to analyze large volumes of data in order to discover rules and causal relationships

### Explanation
### Explanation
**Data mining** is the computational process of discovering patterns, correlations, trends, and rules within large datasets (often stored in a data warehouse) using techniques from statistics, machine learning, and mathematics.

- Choice (a) describes a **Data Warehouse**, which is a central repository for integrated data used for reporting and data analysis.
- Choice (c) describes a **Data Mart**, which is a smaller, focused subset of a data warehouse typically aligned with a specific business line or department.

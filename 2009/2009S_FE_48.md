# 2009S_FE_48

Q48. Which of the following is used for estimating the scale of system development with the function point method?  

a) Number of developers 
b) Number of program steps  
c) Number of screens 
d) Number of users
?
c) Number of screens

### Explanation
### Explanation
The **Function Point (FP) method** estimates software size and development effort based on the functionality provided to the user. It measures the scale by identifying and weighting various components, such as the number of inputs (screens), outputs (reports), inquiries, internal logical files, and external interface files. 
- The "Number of screens" is a factor used in calculating the function points (as part of external inputs or outputs).
- Number of program steps (lines of code) is used in LOC (Lines of Code) estimation, not Function Point.

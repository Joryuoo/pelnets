# 2009S_FE_59

Which of the following is the most appropriate information used by routers in order to determine the routing paths of packets?

a) Destination IP address
b) Destination MAC address
c) Source IP address
d) Source MAC address
?
a) Destination IP address

### Explanation
Routers operate at the Network layer (Layer 3) and forward IP packets between different networks. To determine the best path (next hop) for an incoming packet, a router examines the packet's **Destination IP address** and looks it up against its internal routing table.

- **MAC addresses** (Source/Destination) are used by Layer 2 switches to deliver frames locally within the same network segment.
- The **Source IP address** is used to identify the origin of the packet (often used for replies or filtering) but is not the primary factor used for determining the forward routing path.

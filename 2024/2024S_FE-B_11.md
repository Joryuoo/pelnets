# 2024S_FE-B_11

![[2024S_FE-B_Q11_full.png]]
?
e) i + 1 | < | data[i]

### Explanation
This program sorts an array in ascending order using the **Selection Sort** algorithm.

The selection sort algorithm divides the input list into two parts: a sorted sublist of items which is built up from left to right at the front (left) of the list and a sublist of the remaining unsorted items that occupy the rest of the list.

```mermaid
flowchart TD
    A[Start: Unsorted Array] --> B[Outer Loop i from 1 to size-1]
    B --> C{Assume minPos = i}
    C --> D[Inner Loop j from i+1 to size]
    D --> E{Is data[j] < data[minPos]?}
    E -- Yes --> F[Update minPos = j]
    E -- No --> G[Continue Inner Loop]
    F --> G
    G --> H{End of Inner Loop?}
    H -- No --> D
    H -- Yes --> I[Swap data[i] and data[minPos]]
    I --> J{End of Outer Loop?}
    J -- No --> B
    J -- Yes --> K[End: Sorted Array]
```

Here is the step-by-step logic matching the missing parts:
1. **Outer loop (`i`)**: Iterates from the first element to the second-to-last element.
2. `minPos <- i`: Initially assumes the current position `i` holds the minimum value.
3. **Inner loop (`j`)**: Needs to scan the remaining unsorted portion to find if there is a smaller element. Therefore, it must start from the element right after `i`. 
   - **A** is `i + 1`.
4. **Condition `B`**: To sort in ascending order, we need to find the smallest element. So we check if the current element `data[j]` is less than our current minimum `data[minPos]`.
   - **B** is `<`.
5. **Swapping**: After finding the actual minimum element in the unsorted portion (at `minPos`), we swap it with the first element of the unsorted portion (at `i`).
   ```text
   temp <- data[i]
   data[i] <- data[minPos]
   data[minPos] <- temp
   ```
   - **C** is `data[i]`.

Therefore, the correct combination is **e) i + 1, <, data[i]**.

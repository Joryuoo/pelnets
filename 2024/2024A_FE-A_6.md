# 2024A_FE-A_6

The function $f(n)$ is recursively defined in terms of the natural number $n$ as below. Which of the following is the value of $f(5)$? 

$f(n)$: if $n \le 1$ then return 1 else return $n + f(n-1)$

a) 6
b) 9
c) 15
d) 25
?
c) 15

### Explanation
The given function $f(n)$ is a recursive function. To find the value of $f(5)$, we trace the recursive calls step-by-step:

- **$f(5)$**: Since $5 > 1$, it evaluates to $5 + f(4)$.
- **$f(4)$**: Since $4 > 1$, it evaluates to $4 + f(3)$.
- **$f(3)$**: Since $3 > 1$, it evaluates to $3 + f(2)$.
- **$f(2)$**: Since $2 > 1$, it evaluates to $2 + f(1)$.
- **$f(1)$**: Since $1 \le 1$, this triggers the base case and returns **1**.

Now, we substitute the values back up the chain:
- $f(2) = 2 + 1 = 3$
- $f(3) = 3 + 3 = 6$
- $f(4) = 4 + 6 = 10$
- $f(5) = 5 + 10 = 15$

| Call | Value of $n$ | Returns | Result |
|---|---|---|---|
| 1st | 5 | $5 + f(4)$ | $5 + 10 = 15$ |
| 2nd | 4 | $4 + f(3)$ | $4 + 6 = 10$ |
| 3rd | 3 | $3 + f(2)$ | $3 + 3 = 6$ |
| 4th | 2 | $2 + f(1)$ | $2 + 1 = 3$ |
| 5th | 1 | $1$ (Base Case) | $1$ |

Therefore, $f(5) = 15$.

### Explanation
The program is designed to output and sum the **even numbers** between 1 and 100. Inside the `for` loop, the `if` statement must filter the variable `i` so that the code inside executes only when `i` is even.

An integer is even if it is perfectly divisible by 2, meaning the **remainder** when divided by 2 is 0. 
In programming, the modulo operator (`mod`) is used to find the remainder of a division operation.

Let's evaluate the choices:
* a) `i ÷ 2 = 0`: Because integer division is used, this is only true when `i = 1` (since $1 \div 2 = 0$).
* c) `i mod 2 = 0`: This correctly checks if the remainder of `i` divided by 2 is 0, which is the definition of an even number.
* d) `i mod 2 ≠ 0`: This checks for odd numbers (remainder is not 0).

Therefore, the correct condition is `i mod 2 = 0`.

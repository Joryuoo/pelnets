# 2024A_FE-A_18

Q18. Which of the following is a database design that consists of multiple tables with rows and columns that are linked together through matching data stored in each table?

a) Hierarchical database
b) Network database
c) Object-oriented database
d) Relational database

?
d) Relational database

### Explanation

A **Relational Database** organizes data into tables (also known as relations). Each table consists of rows (representing individual records) and columns (representing attributes or fields). 

Tables in a relational database are logically connected or "linked" to one another using matching data fields, commonly referred to as **Primary Keys** and **Foreign Keys**.

| Database Model | Characteristics |
| :--- | :--- |
| **Relational** | Data is structured in **tables (rows and columns)**. Relationships are established via matching data fields (Primary/Foreign Keys). |
| **Hierarchical** | Data is structured in a tree-like, parent-child relationship where a child can only have one parent. |
| **Network** | Similar to the hierarchical model, but allows a child record to have multiple parent records (forming a graph/network structure). |
| **Object-oriented** | Data is stored as objects, similar to object-oriented programming (combining data and methods). |

Because the question explicitly mentions "multiple tables with rows and columns linked together through matching data", this perfectly describes the **Relational Database** design.

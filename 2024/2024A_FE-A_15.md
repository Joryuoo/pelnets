### Explanation

The scheduling algorithm used is **First-Come-First-Serve (FCFS)**, which is non-preemptive. The OS simply executes processes in the exact order they arrive in the ready queue. A process runs to completion before the next process starts.

Let's trace the CPU timeline step-by-step:

1. **Process P1** arrives at `t = 0`.
   - The CPU is idle, so P1 starts executing immediately at `t = 0`.
   - P1 requires 6 ms (burst time).
   - **Waiting time for P1:** Start Time - Arrival Time = $0 - 0 = \mathbf{0}$
   - P1 finishes at `t = 6`.

2. **Process P2** arrives at `t = 2`.
   - P1 is currently executing, so P2 enters the ready queue and waits.
   - P1 finishes at `t = 6`, so P2 starts executing at `t = 6`.
   - **Waiting time for P2:** Start Time - Arrival Time = $6 - 2 = \mathbf{4}$
   - P2 requires 4 ms, so it finishes at `t = 6 + 4 = 10`.

3. **Process P3** arrives at `t = 4`.
   - P3 enters the ready queue and waits for P1 and P2 to finish.
   - P2 finishes at `t = 10`, so P3 starts executing at `t = 10`.
   - **Waiting time for P3:** Start Time - Arrival Time = $10 - 4 = \mathbf{6}$
   - P3 requires 9 ms, so it finishes at `t = 10 + 9 = 19`.

4. **Process P4** arrives at `t = 5`.
   - P4 enters the ready queue and waits.
   - P3 finishes at `t = 19`, so P4 starts executing at `t = 19`.
   - **Waiting time for P4:** Start Time - Arrival Time = $19 - 5 = \mathbf{14}$
   - P4 requires 7 ms, so it finishes at `t = 19 + 7 = 26`.

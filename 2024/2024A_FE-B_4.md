# 2024A_FE-B_4

![[2024A_FE-B_Q4_full.png]]
?
c) `num mod i = 0`, `num > 1`

### Explanation

This algorithm extracts the prime factorization of a given number `num`. It uses a divisor `i`, starting from 2, and continuously divides `num` by `i` as long as `i` is a factor of `num`.

**Blank A:**
We need to check if `i` is a factor of `num`. Mathematically, `i` is a factor of `num` if the remainder of `num` divided by `i` is 0.
This is written using the modulo operator:
`num mod i = 0`

When this is true, the algorithm divides `num` by `i` (`num ← integer part of (num ÷ i)`), and prints the factor `i`.

**Blank B (First Occurrence):**
After printing the factor `i`, the algorithm prints a multiplication sign `"×"` to separate factors, but *only* if there are more factors to come.
Since `num` gets divided by `i`, if `num` is reduced to 1, we have completely factorized the original number, and we shouldn't print an extra `"×"`. Thus, we should only print `"×"` if:
`num > 1`

**Blank B (Second Occurrence):**
The `do...while` loop needs to keep running until `num` is completely factorized. As established above, the factorization is complete when `num` reaches 1. Thus, the loop should continue as long as:
`num > 1`

**Step-by-step Trace for `num = 12`:**

| `num` | `i` | `num mod i = 0` | Action | New `num` | `num > 1` | Output |
|---|---|---|---|---|---|---|
| 12 | 2 | True ($12 \bmod 2 = 0$) | Output `i` (2) | $12 \div 2 = 6$ | True ($6 > 1$) | `2x` |
| 6 | 2 | True ($6 \bmod 2 = 0$) | Output `i` (2) | $6 \div 2 = 3$ | True ($3 > 1$) | `2x2x` |
| 3 | 2 | False ($3 \bmod 2 = 1$) | `i ← i + 1` | 3 | True | `2x2x` |
| 3 | 3 | True ($3 \bmod 3 = 0$) | Output `i` (3) | $3 \div 3 = 1$ | False ($1 \not> 1$) | `2x2x3` |

Loop ends because `num` is 1. The output string is `2x2x3`. This matches option **c**.

### Explanation
The function `sumDigits` calculates the sum of all digits in a base-10 integer `num`. 
To do this iteratively, we must extract the digits one by one (starting from the rightmost digit), add them to `sum`, and remove them from `num`.

**Step 1: Extract the rightmost digit and add to `sum`**
The rightmost digit of a number can be obtained by finding the remainder when divided by 10 (`num mod 10`). For example, $123 \bmod 10 = 3$.
We add this to our running total: 
`sum ← sum + num mod 10` (This matches **A**).

**Step 2: Remove the rightmost digit from `num`**
To chop off the rightmost digit, we divide the number by 10 and take only the integer part. For example, the integer part of $123 \div 10$ is $12$.
So we update `num`:
`num ← integer part of (num ÷ 10)` (This matches **B**).

Let's trace `num = 12`:
| Iteration | `num > 0` | `sum` (A: `sum + num mod 10`) | `num` (B: `integer part of (num / 10)`) |
| --------- | --------- | ----------------------------- | --------------------------------------- |
| Start     | True      | 0                             | 12                                      |
| 1         | True      | $0 + (12 \bmod 10) = 2$       | Integer part of $12 \div 10 = 1$        |
| 2         | True      | $2 + (1 \bmod 10) = 3$        | Integer part of $1 \div 10 = 0$         |
| 3         | False     | 3 (Final Answer)              | 0                                       |

This logic perfectly calculates the sum of the digits, which aligns with choice **b**.

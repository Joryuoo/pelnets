### Explanation

We are given a 2-to-1 Multiplexer (MUX) with the following behavior:
- If $S = 0$, $Z = I_0$
- If $S = 1$, $Z = I_1$

The Boolean expression for a 2-to-1 MUX is:
$$Z = (\overline{S} \cdot I_0) + (S \cdot I_1)$$

By examining the specific circuit configuration in the question:
- The select line $S$ is connected to $X_1$. Therefore, $S = X_1$.
- The input $I_0$ is connected directly to $X_2$. Therefore, $I_0 = X_2$.
- The input $I_1$ is connected to $X_2$ through a **NOT gate**. Therefore, $I_1 = \overline{X_2}$.

Now, substitute these into the MUX Boolean expression to find the output $Y$:
$$Y = (\overline{X_1} \cdot X_2) + (X_1 \cdot \overline{X_2})$$

This resulting Boolean equation exactly defines an **Exclusive OR (XOR) gate**.

The logic symbols presented in the choices are:
* **a)** AND gate (with an inverted input on $X_2$)
* **b)** NAND gate
* **c)** OR gate (with an inverted input on $X_2$)
* **d)** **XOR gate**

The symbol in **d)** represents an XOR gate, which matches the behavior of our MUX circuit.

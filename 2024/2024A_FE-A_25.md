# 2024A_FE-A_25

Which of the following is a protocol to gather information on network components to manage and troubleshoot the network?

a) NTP
b) SMTP
c) SNMP
d) TELNET
?
c) SNMP

### Explanation

**SNMP** (Simple Network Management Protocol) is an application-layer protocol used for network management. It is designed to monitor, configure, and gather information from network devices such as routers, switches, servers, and printers.

#### Breakdown of the Options

| Protocol | Full Name | Purpose |
| :--- | :--- | :--- |
| **NTP** | Network Time Protocol | Used to synchronize the clocks of computers over a network. |
| **SMTP** | Simple Mail Transfer Protocol | Used for sending and relaying email messages between mail servers. |
| **SNMP** | Simple Network Management Protocol | Used to collect information from and configure network devices (e.g., checking bandwidth, CPU usage, or port status). |
| **TELNET** | Teletype Network | An older, unencrypted protocol used for remote terminal access to devices. |

An **SNMP Manager** sends queries (`GET`) to an **SNMP Agent** running on the device. The agent checks its local **MIB** (Management Information Base) and returns the requested network statistics. If a critical event occurs (like a link going down), the agent can proactively send an **SNMP Trap** to the manager.

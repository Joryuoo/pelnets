# 2024A_FE-A_11

Q11. Which of the following is a fail-safe concept for improving the security and reliability of the information system?

a) Even when the user performs an incorrect operation, a problem does not occur in the system.
b) Even when there is a partial system fault, the required functions of the overall system are maintained.
c) When a device configuring the system fails, damage can be minimized by enabling the system to stop safely.
d) When a system failure occurs, processing is continued by switching to a standby system.

?
c) When a device configuring the system fails, damage can be minimized by enabling the system to stop safely.

### Explanation

To understand system reliability and safety designs, here are the key design concepts categorized:

| Concept | Explanation | Example | Option Match |
| :--- | :--- | :--- | :--- |
| **Fail-Safe** | When a failure occurs, the system moves to a **safe state** to prevent accidents, damage, or harm, often by safely shutting down. | Traffic lights turning red in all directions when a fault is detected. | **c)** |
| **Fail-Soft** | When a failure occurs, the system continues to operate but with **degraded performance** or restricted features rather than completely stopping. | An airplane flying on one engine when the other fails. | **b)** |
| **Fool-Proof** | A design that prevents a user from making a mistake or performing an incorrect operation, ensuring the system remains unharmed. | A microwave door that prevents operation while open. | **a)** |
| **Fault-Tolerant** | The system continues to operate seamlessly even when a component fails, usually achieved via **redundancy**. | Switching to a standby database server if the primary one crashes. | **d)** |

Since the question asks for the **fail-safe** concept, the correct choice is **c**, which describes stopping the system safely to minimize damage.

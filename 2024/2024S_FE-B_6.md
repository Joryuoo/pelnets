# 2024S_FE-B_6

a) `rbyte & (00000001 << (i - 1))`

### Explanation
The function `count1` iterates through an 8-bit integer and counts the number of bits that are set to `1`. The loop variable `i` goes from `1` to `8`.
Inside the loop, the `if` condition checks if a specific bit at a specific position is `1` by applying a **bitmask**.

To isolate and check a single bit, we use the **bitwise AND (`&`)** operator. 
If we want to check the $k$-th bit (from the right, zero-indexed), we bitwise AND the byte with a mask that has a `1` at the $k$-th position and `0`s everywhere else. If the result is not `00000000`, it means the bit in the original byte was `1`.

We create the bitmask by taking `00000001` and **left shifting (`<<`)** it to the correct position. 
- For the 1st bit ($i = 1$), we need `00000001` (shift by 0)
- For the 2nd bit ($i = 2$), we need `00000010` (shift by 1)
- For the 3rd bit ($i = 3$), we need `00000100` (shift by 2)

Notice that the number of shifts is always $i - 1$. 
Thus, the correct mask is `(00000001 << (i - 1))`.
Combining this with the bitwise AND operator against `rbyte`, we get:
`rbyte & (00000001 << (i - 1))`

This corresponds to choice **a**.

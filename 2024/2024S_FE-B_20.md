### Explanation
The network topology defines three zones:
- **DMZ**: Contains servers accessed from the Internet (Server-1 to Server-n).
- **PUBLIC**: The external network (Internet).
- **PRIVATE**: The internal network containing PCs (PC-1 to PC-n).

```mermaid
    Inet -.->|Can reach HTTPS| DMZ
    DMZ -.->|Only accesses DNS / Updates| PUBLIC
    DMZ -x|Cannot Connect| PRIVATE
    PRIVATE -.->|Full Management Access| DMZ
    PRIVATE -.->|Outbound Access| PUBLIC
    PUBLIC -x|Cannot Connect| PRIVATE
```

Let's evaluate the required security policies:
1. **"Hosts in the ___A___ zone cannot connect to hosts in the ___B___ zone."**
   A standard security principle is that the DMZ (which is exposed to the Internet and at higher risk of compromise) should **not** be allowed to initiate connections into the highly secure internal PRIVATE network. This prevents an attacker who breaches a DMZ server from pivoting to internal PCs.
   - **A = DMZ**, **B = PRIVATE**

2. **"Hosts in the ___A___ zone can only access the DNS service on all hosts in the ___C___ zone and HTTP/HTTPS service on limited hosts in the ___C___ zone to retrieve software updates."**
   Hosts in the DMZ typically only need limited outbound access to the PUBLIC Internet (for DNS lookups and to download OS/software updates).
   - Since A is DMZ, **C = PUBLIC** fits perfectly. DMZ servers access PUBLIC DNS and specific PUBLIC update servers.

3. **"Hosts in the ___B___ zone can connect to hosts in the ___A___ zone on all TCP, UDP and ICMP services."**
   The internal PRIVATE network (PCs) should generally have full administrative access to manage the servers in the DMZ.
   - **B = PRIVATE**, **A = DMZ**

4. **"Hosts in the ___B___ zone can reach the ___C___ zone but not vice versa."**
   The internal PRIVATE network should be able to access the PUBLIC Internet, but the PUBLIC Internet must not be able to initiate connections into the PRIVATE network.
   - **B = PRIVATE**, **C = PUBLIC**

5. **"Hosts in the ___C___ zone can reach HTTPS service on hosts in the ___A___ zone."**
   The PUBLIC Internet needs to be able to access the web services (HTTPS) hosted on the servers in the DMZ.
   - **C = PUBLIC**, **A = DMZ**

This perfectly aligns with standard zone-based firewall rules:
- **A = DMZ**
- **B = PRIVATE**
- **C = PUBLIC**

Therefore, the correct combination is **b) DMZ, PRIVATE, PUBLIC**.

# 2024A_FE-B_3

![[2024A_FE-B_Q3_full.png]]
?
f) `array[i] > max1`, `max2 ← array[i]`

### Explanation

This algorithm is designed to find the **second-largest** element in an array without sorting it. It maintains two variables:
- `max1`: The largest element seen so far.
- `max2`: The second-largest element seen so far.

Both are initialized to negative infinity (`-∞`). As the loop iterates through each element `array[i]`, it evaluates two primary conditions.

**Condition A: Identifying a New Largest Element**
If `array[i]` is strictly greater than the current maximum `max1`, we have found a new largest element. 
In this case, the *old* largest element (`max1`) gets demoted and becomes the *new* second-largest element (`max2`). Then, `max1` takes the value of `array[i]`.
The condition for Blank A should therefore be:
`array[i] > max1`

**Condition B: Identifying a New Second-Largest Element**
If the first condition is false (meaning `array[i] ≤ max1`), it might still be greater than `max2`. We check this with the `elseif (array[i] > max2)`.
If this is true, `array[i]` is our new second-largest element, and we must update `max2`.
The action for Blank B should be:
`max2 ← array[i]`

**Step-by-step Trace for array `{2, 6, 9, 1, 7, 5}`:**

| i | `array[i]` | Condition Check | `max1` | `max2` |
|---|---|---|---|---|
| - | - | Initial state | $-∞$ | $-∞$ |
| 1 | 2 | $2 > -∞$ (True) | 2 | $-∞$ |
| 2 | 6 | $6 > 2$ (True) | 6 | 2 |
| 3 | 9 | $9 > 6$ (True) | 9 | 6 |
| 4 | 1 | $1 \not> 9$, but $1 \not> 6$ (False) | 9 | 6 |
| 5 | 7 | $7 \not> 9$, but $7 > 6$ (True for B) | 9 | 7 |
| 6 | 5 | $5 \not> 9$, but $5 \not> 7$ (False) | 9 | 7 |

The final output is `max2`, which is 7. This matches option **f**.

# 2024A_FE-A_3

Which of the following is the computational complexity of the Heapsort algorithm? Here, $n$ is the number of elements to be sorted, and all comparisons, swaps, and other needed operations can proceed in constant time. 

a) $O (\log n)$
b) $O (n)$
c) $O (n^2)$
d) $O (n \log n)$
?
d) $O (n \log n)$

### Explanation
**Heapsort** is a comparison-based sorting algorithm that uses a binary heap data structure. The algorithm consists of two main phases:
1. **Building the heap:** A max-heap is constructed from the input array. This takes $O(n)$ time.
2. **Extracting elements:** The largest element (root of the max-heap) is repeatedly removed and placed at the end of the sorted array, and the remaining elements are heapified to maintain the max-heap property. Since there are $n$ elements, and each extraction and subsequent `heapify` operation takes $O(\log n)$ time, this phase takes $O(n \log n)$ time.

Combining both phases, the overall time complexity is $O(n) + O(n \log n)$, which simplifies to $O(n \log n)$. This time complexity applies strictly to the worst, average, and best cases of Heapsort.

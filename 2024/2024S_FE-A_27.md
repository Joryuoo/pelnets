# 2024S_FE-A_27 %% ex. 2024S_FE-A_83 %%

Which of the following describes a brute force attack aimed at finding the key of symmetric encryption?

a) Finding the key by observing the ciphertext change when the plaintext is altered by a certain amount 
b) Finding the key by testing all key combinations sequentially when a set of plaintext and ciphertext is given
c) Finding the key by using the algebraic expression representing the relationship between the plaintext, ciphertext, and key as a clue 
d) Finding the key by using the statistical correlation between a part of the information of the plaintext and part of the information of the ciphertext as a clue
? 
b) Finding the key by testing all key combinations sequentially when a set of plaintext and ciphertext is given
### Explanation

A **brute force attack** is a cryptographic attack that relies on guessing the key. It systematically attempts all possible key combinations until the correct key is found. When a set of plaintext and corresponding ciphertext is known, the attacker will repeatedly encrypt the plaintext with different keys until the result matches the ciphertext.

### Why the Others Won't Fit

**a) Finding the key by observing the ciphertext change...**
This describes **Differential Cryptanalysis**, which analyzes how differences in input affect the differences in output.

**c) Finding the key by using the algebraic expression...**
This describes an **Algebraic Attack**, which attempts to solve the mathematical equations that represent the encryption algorithm.

**d) Finding the key by using the statistical correlation...**
This describes **Linear Cryptanalysis**, which looks for linear relationships between bits of the plaintext, ciphertext, and the key.%% ignore this %%

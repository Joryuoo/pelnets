```sql
SELECT DNO FROM DEPT
```

- Result set 1 = `{1, 2, 3}`

**Step 2: The second inner subquery**
```sql
SELECT DNO FROM DEPT_LOCS WHERE Region='L2'
```
This queries all department numbers located in Region `'L2'` from the `DEPT_LOCS` table.
Looking at the `DEPT_LOCS` table:
- DNO 2 is in L2
- DNO 3 is in L2
- Result set 2 = `{2, 3}`

**Step 3: The `MINUS` set operation**
```sql
(Result set 1) MINUS (Result set 2)
```
The `MINUS` operator returns all distinct rows retrieved by the first query that are *not* returned by the second query.
- `{1, 2, 3} MINUS {2, 3}` yields a final set of just `{1}`.

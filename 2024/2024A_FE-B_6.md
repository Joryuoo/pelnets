### Explanation

The program calculates the real roots of a quadratic equation using the quadratic formula.

**Blank A:**
The discriminant is mathematically defined as $b^2 - 4ac$.
In programming notation, $b^2$ is represented by `b × b` (or `b^2` if an exponentiation operator exists, but none is given in the options). Thus, the expression becomes:
`b × b - 4 × a × c`

**Blank B:**
The first `if` block calculates two distinct roots (`root1` and `root2`) and outputs both. According to the problem description, this occurs when the discriminant value is positive.
Therefore, the condition is:
`discriminant > 0`

**Blank C:**
The `elseif` block calculates a single root (`root1`) and outputs it, indicating that `root1 = root2 = root1`. According to the problem description, there is exactly one solution when the discriminant is zero.
Therefore, the condition is:
`discriminant = 0`

These values correspond perfectly to option **h**.

# 2024A_FE-A_2

What is the value of the postfix expression below? Here, A, B, C, and D are operands whose values are 4, 3, 5, and 6, respectively. Symbols “+”, “−”, “×”, and “÷” are arithmetic operators for addition, subtraction, multiplication, and division, respectively. 

A B 2 × + D B ÷ C × −

a) −3
b) 0
c) 3
d) 40/3
?
b) 0

### Explanation
To evaluate the postfix (Reverse Polish Notation) expression `A B 2 × + D B ÷ C × −`, we substitute the given values:
$A = 4$, $B = 3$, $C = 5$, $D = 6$.

The expression becomes: `4 3 2 × + 6 3 ÷ 5 × −`

We evaluate this using a stack data structure, scanning from left to right:
1. Push operands onto the stack.
2. When an operator is encountered, pop the necessary operands, perform the operation, and push the result back.

| Token | Operation | Stack State (Bottom to Top) |
|---|---|---|
| `4` | Push 4 | `[4]` |
| `3` | Push 3 | `[4, 3]` |
| `2` | Push 2 | `[4, 3, 2]` |
| `×` | Pop 2 and 3, $3 \times 2 = 6$, Push 6 | `[4, 6]` |
| `+` | Pop 6 and 4, $4 + 6 = 10$, Push 10 | `[10]` |
| `6` | Push 6 | `[10, 6]` |
| `3` | Push 3 | `[10, 6, 3]` |
| `÷` | Pop 3 and 6, $6 \div 3 = 2$, Push 2 | `[10, 2]` |
| `5` | Push 5 | `[10, 2, 5]` |
| `×` | Pop 5 and 2, $2 \times 5 = 10$, Push 10 | `[10, 10]` |
| `−` | Pop 10 and 10, $10 - 10 = 0$, Push 0 | `[0]` |

The final result is **0**.

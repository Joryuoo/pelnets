# 2014A_FE_34
In a TCP/IP network using IPv4 addresses, which of the following is a valid network address? Here, the number following a slash (/) is the number (in decimal) of bits allocated to represent the network number.

a) 123.0.0.30/27
b) 150.60.0.130/25
c) 196.74.38.20/28
d) 210.11.190.192/26
?
d) 210.11.190.192/26
### Explanation
A valid network address has all host bits set to `0`. We can determine if an IP is a network address by checking if it falls exactly on the boundary of the block size for its subnet mask.

* **a) 123.0.0.30/27:** /27 leaves 5 bits for hosts (block size = 32). The network addresses are .0, .32, etc. `.30` is a host address.
* **b) 150.60.0.130/25:** /25 leaves 7 bits for hosts (block size = 128). The network addresses are .0, .128. `.130` is a host address.
* **c) 196.74.38.20/28:** /28 leaves 4 bits for hosts (block size = 16). The network addresses are .0, .16, .32. `.20` is a host address.
* **d) 210.11.190.192/26:** /26 leaves 6 bits for hosts (block size = 64). The network addresses are .0, .64, .128, .192. `.192` is exactly the start of the subnet, so it is a valid network address.

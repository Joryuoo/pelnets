# 2014S_FE_AM_3
![[2014S_FE_AM_Q3_p1.png]]
?
a) An input string must contain at least one 1 and any even number of 0s following the last 1.
### Explanation
By tracing the state transition diagram:
- State `q1` is the start state. The automaton stays in `q1` as long as it reads `0`.
- Reading a `1` transitions it to `q2` (the accepting state). Therefore, an accepted string must contain at least one `1` to escape `q1`.
- Once at `q2` or `q3`, reading a `1` always resets the state to `q2`.
- From `q2`, reading a `0` moves to `q3` (a non-accepting state). Reading a `0` again moves it back to `q2`.
- This means after reading the last `1` (which lands the state in `q2`), any subsequent `0`s toggle the state back and forth. To end in `q2`, there must be an even number of `0`s following that last `1` (0, 2, 4, etc.).

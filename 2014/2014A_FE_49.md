# 2014A_FE_49
In terms of the test coverage of a program module, which of the following is an appropriate explanation of the relationship between path coverage, branch coverage, and statement coverage?  
 
a) 100% branch coverage implies 100% path coverage but not statement coverage.   
b) 100% path coverage implies 100% statement coverage but not branch coverage.  
c) 100% path coverage implies both 100% branch coverage and statement coverage.  
d) 100% statement coverage implies 100% branch coverage but not path coverage.  
?
c) 100% path coverage implies both 100% branch coverage and statement coverage.
### Explanation
Test coverage levels have a hierarchical relationship based on their strictness:
1. **Statement Coverage (C0):** Ensures every statement is executed at least once.
2. **Branch Coverage (C1):** Ensures every branch (true/false) of each control structure is executed at least once. (100% branch coverage implies 100% statement coverage).
3. **Path Coverage (C2):** Ensures every possible path through a program is executed at least once. 

Since path coverage tests all possible routes, it naturally satisfies the requirement of testing all branches and all statements. Therefore, 100% path coverage guarantees 100% branch coverage and 100% statement coverage.

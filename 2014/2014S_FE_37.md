# 2014S_FE_37
Which of the following is an appropriate explanation concerning the NAT function of a router used for Internet connection?

a) A specific bit pattern in IP packets being transmitted can be detected.
b) Conversion between private IP addresses and global IP addresses can be performed.
c) Frequently accessed Web pages can be cached to provide faster response times.
d) Only the IP packets addressed to a specific terminal can be passed.
?
b) Conversion between private IP addresses and global IP addresses can be performed.
### Explanation
NAT (Network Address Translation) is a method of mapping private IP addresses to global (public) IP addresses, allowing devices on a local network to access the Internet using a single or a few public IP addresses.
- Choice (a) refers to packet inspection or filtering.
- Choice (c) describes the function of a proxy server with caching capabilities.
- Choice (d) refers to packet filtering (firewall capabilities) or routing based on specific destinations.

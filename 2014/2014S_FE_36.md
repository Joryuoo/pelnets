# 2014S_FE_36
![[2014S_FE_AM_Q36_full.png]]

a) Difference
b) Intersection
c) Natural join
d) Union
?
a) Difference
### Explanation
Table_3 contains the students who know C++ (Table_2) but do not know Java (Table_1). This is represented by subtracting the records of Table_1 from Table_2.
In relational algebra, this set operation is known as the **Difference** (Table_2 minus Table_1), which returns rows that appear in the first relation but not the second.
- **Intersection** would return students who know both C++ and Java.
- **Union** would return students who know either C++ or Java (or both).

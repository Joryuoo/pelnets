# 2014A_FE_20
When the source code based on OSS licensed under GPL is not released to the public, which of the following is regarded as a violation of the license?

a) A company develops and sells an interface kit between OSS and other application software.
b) A company obtains, modifies, and sells OSS through the company’s own operations or activities.
c) A company outsources the modification of OSS to another company for the purpose of internal use.
d) A company sells its own software whose performance test has been performed by using OSS.
?
b) A company obtains, modifies, and sells OSS through the company’s own operations or activities.
### Explanation
The **GPL (GNU General Public License)** is a copyleft license. A key condition of the GPL is that if you modify and distribute (e.g., sell or share) software that contains or is derived from GPL-licensed code, you must also release the source code of your modifications under the GPL.

* **a)** Providing an interface kit (a separate program) without modifying the original OSS generally does not violate GPL unless it forms a single combined program.
* **c)** Modifying OSS strictly for internal use (without distributing it outside the company) does not require releasing the source code.
* **d)** Using GPL software merely as a tool to test other software does not create a derivative work, so there's no obligation to release the tested software's source code.

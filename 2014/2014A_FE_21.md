c) 1 0
### Explanation
The logic circuit functions as a 4-to-1 multiplexer. The two selector signals, S1 and S2, form a 2-bit binary number that selects one of the four inputs (C1, C2, C3, C4) to pass to the output.

If we look at standard multiplexer addressing, the inputs correspond to binary values:
* C1 is selected when selectors are `0 0`
* C2 is selected when selectors are `0 1`
* C3 is selected when selectors are `1 0`
* C4 is selected when selectors are `1 1`

Assuming S1 represents the most significant bit and S2 represents the least significant bit, selecting C3 requires the binary value `1 0`. Therefore, S1 = 1 and S2 = 0.

# 2014A_FE_3
When the word list of a dictionary is searched for an exact matching word, which of the following is the most appropriate data structure in terms of runtime computational complexity?

a) Array
b) Binary search tree
c) Hash table
d) Linked list
?
c) Hash table
### Explanation
A **Hash table** provides the best average-case time complexity $O(1)$ for searching for an exact match, making it the most appropriate data structure.
* **Array**: Searching an unsorted array takes $O(n)$, and a sorted array using binary search takes $O(\log n)$.
* **Binary search tree**: Searching takes $O(\log n)$ on average, but can degrade to $O(n)$ if unbalanced.
* **Linked list**: Searching always takes $O(n)$ time complexity as it requires sequential traversal.

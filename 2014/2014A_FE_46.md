### Explanation
In UML 2.x, diagrams are categorized into structure diagrams (static) and behavior diagrams (dynamic).

- **Structure Diagrams**: Class diagram, Component diagram, Object diagram, Deployment diagram, Composite structure diagram, Package diagram.
- **Behavior Diagrams**: Use case diagram, Sequence diagram, Activity diagram, State machine diagram, Communication diagram, Interaction overview diagram, Timing diagram.

Looking at the options:
- **a)** Class and Component are Structure diagrams; Sequence and Use case are Behavior diagrams. (Correct)
- **b)** Communication is a Behavior diagram, but Deployment is a Structure diagram.
- **c)** Activity is a Behavior diagram, but Component is a Structure diagram.
- **d)** Use case is a Behavior diagram (incorrectly placed if it was under Structure).

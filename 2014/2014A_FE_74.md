# 2014A_FE_74
Which of the following is an organization structure where employees report to both their individual immediate managers and a cross function leader and try to achieve coordination between program groups and centrally controlled groups of functional specialists?

a) Divisional organization
b) Functional organization
c) Matrix organization
d) Project organization
?
c) Matrix organization
### Explanation
A matrix organization structure groups employees by both function and product/project, meaning they report to multiple managers (e.g., an immediate functional manager and a cross-functional project leader). This balances coordination between specialized skills and project goals.

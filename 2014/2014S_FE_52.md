# 2014S_FE_52
Which of the following is the appropriate category of system maintenance that is performed for the purpose of adding new features to an existing system or enhancing existing features?

a) Adaptive maintenance
b) Corrective maintenance
c) Perfective maintenance
d) Preventive maintenance
?
c) Perfective maintenance
### Explanation
**Perfective maintenance** involves modifying a system to add new features, improve performance, or enhance its existing functions based on user requests.
- **Adaptive maintenance**: Modifying the system to keep it usable in a changing environment (e.g., new operating system).
- **Corrective maintenance**: Fixing errors or bugs discovered in the system.
- **Preventive maintenance**: Improving system structure to prevent future problems or make future maintenance easier.

a) Mr. A's private Key / Mr. A's public Key
### Explanation
A **digital signature** uses public-key cryptography to provide authentication and non-repudiation.

1. **Creating the signature:** The sender (Mr. A) encrypts the hash of the email using his own **private key**. This ensures only Mr. A could have created the signature.
2. **Verifying the signature:** The receiver (Mr. B) decrypts the signature using Mr. A's **public key**. If it decrypts successfully and the hash matches, it confirms Mr. A sent it.

Therefore, Mr. A's private key is used for creation, and Mr. A's public key is used for verification.

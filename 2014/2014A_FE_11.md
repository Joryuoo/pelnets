# 2014A_FE_11
Which of the following is the addressing mode where the operand of an instruction is used to point to the memory address that contains the address of the data to be operated upon?

a) Direct addressing
b) Immediate addressing
c) Indirect addressing
d) Register addressing
?
c) Indirect addressing
### Explanation
In **indirect addressing**, the operand of the instruction contains the memory address that holds the effective address of the data to be operated upon.

* **a) Direct addressing**: The operand specifies the exact memory address of the data.
* **b) Immediate addressing**: The operand contains the actual data value, not an address.
* **d) Register addressing**: The operand specifies a CPU register that holds the data.

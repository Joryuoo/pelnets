# 2014A_FE_23
Which of the following is an appropriate description concerning flash memory?

a) It can write data electrically and erase it all at once with ultraviolet light.
b) It can write data electrically and erase it electrically in units of blocks.
c) It is often used as cache memory because of the high-speed rewritable capability.
d) It needs to rewrite (i.e., refresh) data within a given period of time.
?
b) It can write data electrically and erase it electrically in units of blocks.
### Explanation
Flash memory is a non-volatile memory type that is a form of EEPROM (Electrically Erasable Programmable Read-Only Memory). It can be electrically programmed and erased, usually in units called blocks.

* **a)** Describes EPROM, which is erased using ultraviolet light.
* **c)** Cache memory typically uses SRAM (Static RAM) because it is much faster than flash memory.
* **d)** Describes DRAM (Dynamic RAM), which requires periodic refreshing to maintain data.

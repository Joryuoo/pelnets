# 2014S_FE_69
Which of the following corresponds to an example of “non-functional” requirements?

a) Clarifying the flow of data between the functions constituting business operations
b) Deciding the scope that is to be implemented as system functions
c) Selecting development standards based on the language used in system development
d) Specifying the interface used for exchanging information with other systems
?
c) Selecting development standards based on the language used in system development
### Explanation
In requirements engineering, **functional requirements** define *what* a system is supposed to do (e.g., behaviors, data flows, inputs/outputs). **Non-functional requirements** define *how* the system is supposed to be (e.g., performance, security, development standards, maintainability constraints).
* **a) Flow of data between functions:** A functional requirement.
* **b) Scope of system functions:** A functional requirement.
* **c) Selecting development standards:** A non-functional constraint (specifically a development or technical constraint) because it dictates how the software is built rather than what business function it performs.
* **d) Specifying an interface for information exchange:** An external interface requirement, typically part of functional requirements or integration requirements.

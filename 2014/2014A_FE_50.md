# 2014A_FE_50
When an integration test is performed by using the top-down approach, which of the following is particularly necessary? 
 
a) Debugger 
b) Driver  
c) Emulator  
d) Stub  
?
d) Stub
### Explanation
In top-down integration testing, testing begins from the top-level modules (main control modules) and proceeds downwards to lower-level modules. Since lower-level modules might not be developed or integrated yet, **stubs** are used as dummy modules to simulate their behavior and return values to the higher-level modules being tested.

- **b) Driver** is necessary for *bottom-up* integration testing, where dummy higher-level modules are used to call the lower-level modules being tested.

c) Product category
### Explanation
A pull-down menu is an input control that provides a predefined list of mutually exclusive options. It is best used when there is a small, finite set of valid choices. 

* **Product category** has exactly five predefined categories, making it perfect for a pull-down menu.
* **Product number** (five numeric characters) and **Product name** (free text up to 40 characters) have too many possible values for a menu.
* **Price** is a continuous or large range of values (100 to 1,000 dollars) and is better suited for a numeric text field.

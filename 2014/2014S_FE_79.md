# 2014S_FE_79
Which of the following is protected by “copyright” that is based on the WTO’s Agreement on Trade-Related Aspects of Intellectual Property Rights (TRIPS)?

a) Algorithm
b) Compiler program
c) Programming language
d) Protocol
?
b) Compiler program
### Explanation
Under TRIPS and international copyright law, computer programs, whether in source or object code, are protected as literary works. Therefore, a compiler program is protected by copyright.

Ideas, procedures, methods of operation, or mathematical concepts as such are NOT protected by copyright. Thus:
- **a) Algorithm** is a mathematical or logical concept and cannot be copyrighted (though some can be patented).
- **c) Programming language** is a set of rules (ideas) and cannot be copyrighted.
- **d) Protocol** is a set of operational rules and cannot be copyrighted.

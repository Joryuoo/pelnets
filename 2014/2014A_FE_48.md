# 2014A_FE_48
Which of the following is an appropriate deliverable that must be approved when the external design of a system is completed? 

a) Physical database specification 
b) Program flowchart plan 
c) Screen layout  
d) System development  
?
c) Screen layout
### Explanation
External design (also known as architectural or high-level design) defines the system from the user's perspective. It specifies how the users will interact with the system, making **screen layouts**, user interfaces, and external file formats key deliverables for approval at this stage.

- **a) Physical database specification** and **b) Program flowchart plan** are parts of the internal (detailed) design phase, which focuses on the system's technical implementation.
- **d) System development** refers to the actual coding and construction phase, not a design phase deliverable.

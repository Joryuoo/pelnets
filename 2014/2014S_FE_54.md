# 2014S_FE_54
Which of the following is the order that activities A through F are performed in a system development process using a waterfall model?

[Description of activities]
A: Investigating and analyzing current problems, and defining requirements for the target system
B: Dividing functions required for the system into programs, and clarifying the flow of processing
C: Designing detailed procedures, and writing code
D: Performing tests
E: Designing the internal structure of each program
F: Defining functions needed as the system on the basis of the system requirements specifications

a) A, B, F, C, E, D
b) A, F, B, E, C, D
c) A, F, B, E, D, C
d) A, F, E, B, C, D
?
b) A, F, B, E, C, D
### Explanation
In the waterfall model, the sequence generally goes from requirements analysis to system design, program design, coding, and finally testing.
1. **A**: Requirements definition (Analyzing problems, defining requirements).
2. **F**: System external design (Defining functions based on requirements).
3. **B**: System internal design (Dividing functions into programs, flow of processing).
4. **E**: Program design (Designing internal structure of each program).
5. **C**: Programming/Coding (Designing detailed procedures and writing code).
6. **D**: Testing (Performing tests).

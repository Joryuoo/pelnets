# 2014A_FE_33
Which of the following is a mechanism that enables a variety of information, such as still images, movies, and audio, to be sent via e-mail?

a) FTP
b) MIME
c) POP3
d) TELNET
?
b) MIME
### Explanation
**MIME** (Multipurpose Internet Mail Extensions) is an Internet standard that extends the format of email to support text in character sets other than ASCII, as well as attachments of audio, video, images, and application programs.

* **a) FTP:** File Transfer Protocol, used for transferring files over a network, not specifically an email extension.
* **c) POP3:** Post Office Protocol version 3, used by local email clients to retrieve emails from a server.
* **d) TELNET:** A network protocol used for virtual terminal/remote terminal access.

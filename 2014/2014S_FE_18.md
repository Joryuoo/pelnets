# 2014S_FE_18
In a client/server system using a database server, the generation of a large number of SQL statements causes a problem with a rapidly increasing network load between client and server. Which of the following is an appropriate solution to this problem?

a) Reorganization of database
b) Revision of index
c) Use of dynamic SQL
d) Use of stored procedure
?
d) Use of stored procedure
### Explanation
A **stored procedure** is a precompiled collection of SQL statements that are stored and executed on the database server. By calling a stored procedure, the client only needs to send a single command across the network instead of transmitting multiple, individual SQL statements, significantly reducing network load.

* **Reorganization of database / Revision of index**: These improve disk I/O performance and query execution speed on the server but do not directly reduce network traffic between the client and server.
* **Dynamic SQL**: Actually increases processing overhead as queries are constructed and compiled at runtime.

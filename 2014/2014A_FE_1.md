### Explanation
The starting address is $0274_8$.
The number of data records is 400. In base 8, 400 in decimal is $620_8$ ($400 = 6 \times 64 + 2 \times 8 + 0$).
Since the first record is stored at offset 0, the last data record is stored at offset $400 - 1 = 399$. 
In base 8, 399 in decimal is $617_8$ ($399 = 6 \times 64 + 1 \times 8 + 7$).
Adding the offset to the base address:
$0274_8 + 617_8 = ?$
$4+7 = 11 = 13_8$ (write 3, carry 1)
$7+1+1 = 9 = 11_8$ (write 1, carry 1)
$2+6+1 = 9 = 11_8$ (write 1, carry 1)
$0+0+1 = 1_8$
Result: $1113_8$.

# 2014A_FE_27
In a relational database, there are two conditions that must be met as a primary key constraint. One condition is that there are no duplicate key values. Which of the following is another condition?

a) The primary key must be composed of only one column.
b) The primary key must be defined as the first column of a table.
c) The primary key value must match the candidate key of another table.
d) The primary key value must not be null.
?
d) The primary key value must not be null.
### Explanation
A primary key is used to uniquely identify each row in a database table. The two fundamental rules (or constraints) for a primary key are:
1. **Uniqueness:** No two rows can have the same primary key value.
2. **Entity Integrity (Not Null):** The primary key cannot contain a NULL value because a NULL value means the identifier is unknown, which defeats the purpose of uniquely identifying the row.

* **a)** A primary key can be composite (made of multiple columns).
* **b)** The primary key does not have to be the first column physically.
* **c)** Describes a foreign key constraint, not a primary key constraint.

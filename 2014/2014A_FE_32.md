# 2014A_FE_32
Which of the following is the network device that enables LANs to be interconnected at the physical layer of the OSI basic reference model?

a) Bridge
b) Gateway
c) Repeater
d) Router
?
c) Repeater
### Explanation
A **Repeater** operates at the **Physical Layer** (Layer 1) of the OSI model. It regenerates and amplifies the signal to extend the distance a network can span.

* **a) Bridge:** Operates at the Data Link Layer (Layer 2).
* **b) Gateway:** Operates at the upper layers (Layer 4 to 7), translating between different protocols.
* **d) Router:** Operates at the Network Layer (Layer 3), forwarding packets based on IP addresses.

# 2014A_FE_51
Which of the following is a characteristic of a project?

a) A project is both unique and temporary.
b) A project is neither unique nor temporary.
c) A project is not unique but is temporary.
d) A project is unique but not temporary.
?
a) A project is both unique and temporary.
### Explanation
According to PMBOK, a project is defined as a temporary endeavor undertaken to create a unique product, service, or result. 
- **Temporary** means that every project has a definite beginning and a definite end.
- **Unique** means that the product or service is different in some distinguishing way from all other products or services.
Therefore, a project is both unique and temporary.

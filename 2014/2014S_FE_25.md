# 2014S_FE_25
Which of the following is an appropriate explanation of the LRU method that is used as a page replacement algorithm?

a) The page that has existed for the longest time is replaced.
b) The page that has not been used for the longest time is replaced.
c) The page that was last referenced is replaced.
d) The page that was referenced the least number of times is replaced.
?
b) The page that has not been used for the longest time is replaced.
### Explanation
**LRU (Least Recently Used)** is a page replacement algorithm that replaces the page in memory that has not been referenced for the longest period of time.
- **a)** describes FIFO (First In, First Out).
- **c)** describes MRU (Most Recently Used).
- **d)** describes LFU (Least Frequently Used).

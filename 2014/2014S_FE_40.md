# 2014S_FE_40
In a TCP/IP network, which of the following is used to check if a computer or device is accessible across a network?

a) BOOTP
b) DHCP
c) MIB
d) ping
?
d) ping
### Explanation
The `ping` utility is used to test the reachability of a host on an IP network and to measure the round-trip time for messages sent from the originating host to a destination computer. It uses ICMP Echo Request and Echo Reply packets.
- **BOOTP** (Bootstrap Protocol) is used to automatically assign IP addresses to network devices (predecessor of DHCP).
- **DHCP** (Dynamic Host Configuration Protocol) automatically assigns IP addresses and network configuration.
- **MIB** (Management Information Base) is a database used for managing the entities in a communication network, associated with SNMP.

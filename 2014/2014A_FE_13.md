# 2014A_FE_13
Among the RAID systems, which of the following should be used in cases where maximum storage capacity is required but data redundancy or fault tolerance is not a requirement?

a) RAID 0
b) RAID 1
c) RAID 5
d) RAID 6
?
a) RAID 0
### Explanation
**RAID 0 (Striping)** divides data into blocks and spreads them across multiple disks. It provides high performance and maximum storage capacity but zero fault tolerance or redundancy.

* **b) RAID 1 (Mirroring)** provides redundancy by duplicating data across two or more drives, halving the usable capacity.
* **c) RAID 5** uses block-level striping with distributed parity, sacrificing the capacity of one drive for fault tolerance.
* **d) RAID 6** is similar to RAID 5 but uses double distributed parity, sacrificing the capacity of two drives for higher fault tolerance.

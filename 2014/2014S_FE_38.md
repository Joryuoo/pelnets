# 2014S_FE_38
Which of the following is the appropriate protocol that is used on top of UDP for delivering real-time audio and video streams over the Internet?

a) ARP
b) ICMP
c) NNTP
d) RTP
?
d) RTP
### Explanation
RTP (Real-time Transport Protocol) is a network protocol designed for delivering audio and video over IP networks, commonly running over UDP.
- **ARP** (Address Resolution Protocol) resolves IP addresses to MAC addresses.
- **ICMP** (Internet Control Message Protocol) is used for network diagnostics (e.g., ping).
- **NNTP** (Network News Transfer Protocol) is used for reading and posting Usenet articles.

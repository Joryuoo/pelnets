# 2014A_FE_61
Among the situations that are checked during an audit of the methods of transmitting highly confidential information to a business partner by e-mail, which of the following is an appropriate situation from the viewpoint of preventing information leakage?

a) A password is set for an attached file containing confidential information prior to being sent to the partner by e-mail, and the password is transferred in another way.
b) A password is set for an attached file containing confidential information, and the password is described in the body text of the same e-mail that is sent to the partner.
c) Confidential information is directly described in the body text of an e-mail that is sent to the partner.
d) Confidential information is uploaded to the public Web site of the company, and the URL of the corresponding page is sent to the partner by e-mail.
?
a) A password is set for an attached file containing confidential information prior to being sent to the partner by e-mail, and the password is transferred in another way.
### Explanation
When transmitting highly confidential information, sending the data and the means to decrypt it (the password) through the same channel is insecure, as an attacker intercepting the communication would gain access to both.

* **a** is correct. Transferring the password via a separate channel (e.g., phone call, SMS, or a different messaging platform) ensures that if the email is intercepted, the attacker still cannot open the encrypted file without intercepting the secondary channel.
* **b** is incorrect because placing the password in the same email allows anyone who intercepts the email to easily decrypt the file.
* **c** is incorrect because plain text emails are easily intercepted and read.
* **d** is incorrect because public websites can be accessed by anyone, and relying on obscure URLs is not secure.

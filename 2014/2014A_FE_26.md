# 2014A_FE_26
Which of the following is an appropriate explanation concerning the data structure in a relational database?

a) Data and methods are unified (i.e., encapsulated) and stored.
b) Data is represented with one or more two-dimensional tables.
c) Parent records and child records are linked with a pointer.
d) Tags are used to represent data structure and meaning.
?
b) Data is represented with one or more two-dimensional tables.
### Explanation
A relational database organizes data into one or more two-dimensional tables (or "relations") consisting of rows and columns. 

* **a)** Describes an object-oriented database, where data and methods are encapsulated into objects.
* **c)** Describes a hierarchical or network database model, which uses pointers to link records.
* **d)** Describes XML (eXtensible Markup Language) or similar markup languages.

# 2014S_FE_49
Among the diagrams used in UML 2.x, which of the following is the diagram that can represent the interactions based on messages sent or received between objects?

a) Component diagram
b) Sequence diagram
c) State machine diagram
d) Use case diagram
?
b) Sequence diagram
### Explanation
A Sequence diagram in UML is a type of interaction diagram that shows how objects operate with one another and in what order. It is a construct of a message sequence chart that details the interactions based on messages sent and received between objects.
- **Component diagram** depicts how components are wired together to form larger components or software systems.
- **State machine diagram** shows the discrete number of states an object can be in and the transitions between those states.
- **Use case diagram** describes what a system does from the standpoint of an external observer (actor).

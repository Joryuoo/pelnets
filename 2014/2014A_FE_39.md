# 2014A_FE_39
Which of the following is a method for preventing an SQL injection attack?

a) Ensuring that the input characters are not interpreted as characters that have a special meaning in an inquiry or operation to the database
b) Rejecting an input text if the overall length of the input text exceeds the applicable maximum size limit
c) Rejecting an input text that contains the character string ( . . / ) that specifies a higher level directory
d) Replacing the HTML tags of an input text with other character strings that are not interpreted as HTML tags
?
a) Ensuring that the input characters are not interpreted as characters that have a special meaning in an inquiry or operation to the database
### Explanation
**SQL Injection** occurs when malicious SQL statements are inserted into entry fields for execution. The best defense is to properly escape, sanitize, or parameterize input characters so they are treated strictly as data, not as executable SQL commands.

* **b)** Prevents **Buffer Overflow** by enforcing length limits.
* **c)** Prevents **Directory Traversal** (or Path Traversal) by blocking `../`.
* **d)** Prevents **Cross-Site Scripting (XSS)** by sanitizing or escaping HTML/script tags.

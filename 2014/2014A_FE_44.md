# 2014A_FE_44
Which of the following is a method that is used for encrypting e-mail? 

a) BASE64 
b) GZIP  
c) PNG 
d) S/MIME 
?
d) S/MIME
### Explanation
S/MIME (Secure/Multipurpose Internet Mail Extensions) is a widely accepted protocol for sending digitally signed and encrypted messages in order to secure email communications.

- **BASE64**: An encoding scheme used to represent binary data in an ASCII string format, commonly used in email attachments but provides no encryption or security.
- **GZIP**: A file format and software application used for file compression and decompression, not encryption.
- **PNG**: Portable Network Graphics is an image format.

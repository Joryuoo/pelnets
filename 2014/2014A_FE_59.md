# 2014A_FE_59
Which of the following is the most appropriate description concerning a backup method for data?

a) In consideration of a possible response delay in business processing, a backup schedule is adjusted so that it does not overlap with business processing.
b) In order to shorten the time necessary for a backup operation, backup data with a different file name is placed on the same storage medium.
c) In order to shorten the time necessary for recovery from the backup data, differential backup is used.
d) In order to store the backup data for a long period of time, a random access medium is used.
?
a) In consideration of a possible response delay in business processing, a backup schedule is adjusted so that it does not overlap with business processing.
### Explanation
Backing up data typically consumes significant system resources (I/O throughput, network bandwidth, and CPU). Therefore, backups are usually scheduled during off-peak hours (like at night or on weekends) to avoid impacting the performance and response time of normal business operations.
- **Choice b** is incorrect because storing backups on the same medium defeats the purpose of having a backup in case the primary medium fails.
- **Choice c** is incorrect because while differential (or incremental) backups shorten the *backup* time, they actually *increase* the *recovery* time since multiple backup sets must be applied consecutively. Full backups provide the fastest recovery.
- **Choice d** is incorrect because sequential access media (like magnetic tapes) are often used for long-term storage due to their durability and lower cost per gigabyte, not random access media.

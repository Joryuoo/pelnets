# 2014S_FE_45
Which of the following is a biometric recognition technique that is used for identifying a person by using the person’s own behavioral features as well as physiological features?

a) Fingerprint recognition
b) Iris recognition
c) Vein recognition
d) Voice recognition
?
d) Voice recognition
### Explanation
Voice recognition utilizes both physiological features (the physical structure of the vocal tract, mouth, and throat) and behavioral features (the way a person speaks, such as intonation, accent, and speed).
- **Fingerprint, iris, and vein recognition** only rely on physiological features (physical traits).

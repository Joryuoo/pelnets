# 2014S_FE_35
In an SQL statement, which of the following is an appropriate explanation of the percent symbol (%) that is used with the LIKE operator in a WHERE clause?

a) It is a wildcard character that matches any single alphabetic character.
b) It is a wildcard character that matches any single character within the list.
c) It is a wildcard character that matches any single numeric character.
d) It is a wildcard character that matches any string of zero or more characters.
?
d) It is a wildcard character that matches any string of zero or more characters.
### Explanation
In standard SQL, the percent symbol `%` is a wildcard used with the `LIKE` operator to match a sequence of zero or more characters.
- The underscore symbol `_` is used to match exactly one single character.

# 2014A_FE_5
For the post-order traversal of a binary search tree where the left and right subtrees of the root node contain 1000 and 100 nodes respectively, which of the following is the number of nodes that are processed before the root node is visited?

a) 0
b) 100
c) 1000
d) 1100
?
d) 1100
### Explanation
In a **post-order traversal**, the order of visiting nodes is:
1. Traverse the left subtree
2. Traverse the right subtree
3. Visit the root node

Therefore, all nodes in both the left and right subtrees are processed before the root node is visited. 
The total number of nodes in the left subtree is 1000, and the total number of nodes in the right subtree is 100.
Total processed before the root = $1000 + 100 = 1100$.

### Explanation
In a circular queue using an array of size $n$, the read pointer $F$ and the write pointer $R$ start at 0. 
- When the queue is **empty**, there are no elements to read, so the read pointer $F$ is equal to the write pointer $R$: $F = R$.
- When the queue is **full**, the write pointer $R$ has wrapped around and is exactly one position behind the read pointer $F$ (leaving one slot empty to distinguish between full and empty states in this implementation). Thus, the next position of $R$, which is $(R+1) \pmod n$, equals $F$.
Therefore, Full queue: $F = (R+1) \pmod n$, Empty queue: $F = R$.

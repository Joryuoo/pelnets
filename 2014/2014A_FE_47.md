# 2014A_FE_47
According to the ISO/IEC 25010 standard, the quality properties of a software product or system are categorized into eight characteristics: functional suitability, performance efficiency, compatibility, usability, reliability, security, maintainability, and portability. Which of the following is the appropriate explanation of “performance efficiency”? 
 
a) Degree to which a product or system can be used by specified users to achieve specified goals in a specified context of use  
b) Degree to which a product or system provides capabilities relative to the amount of resources used under stated conditions   
c) Degree to which a product or system provides functions that meet stated and implied needs when used under specified conditions  
d) Degree to which a system, product, or component performs specified functions under specified conditions for a specified period of time   
?
b) Degree to which a product or system provides capabilities relative to the amount of resources used under stated conditions
### Explanation
In ISO/IEC 25010, **Performance Efficiency** represents the performance relative to the amount of resources used under stated conditions. This includes time behavior (response time, processing times), resource utilization, and capacity.

- **a)** Describes **Usability**.
- **c)** Describes **Functional Suitability**.
- **d)** Describes **Reliability**.

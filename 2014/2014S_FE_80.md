# 2014S_FE_80
When OSS released under GPL is changed and distributed, which of the following is an appropriate action that complies with the rules of GPL?

a) A purchaser who obtains the derivative work must be strictly prohibited from redistributing copies.
b) All the source code of the derivative work including the modified parts must be disclosed on an on-demand basis.
c) The source code of a separate application that is statically linked to the derivative work does not need to be disclosed.
d) When the source code of the derivative work is disclosed, compensation such as related costs cannot be demanded.
?
b) All the source code of the derivative work including the modified parts must be disclosed on an on-demand basis.
### Explanation
The GNU General Public License (GPL) is a copyleft license. It requires that any derivative work based on a GPL-licensed program must also be distributed under the GPL. This means the complete source code, including all modifications, must be made available to anyone who receives the software (often on an on-demand basis or provided alongside the binary).

- **a)** is incorrect because GPL strictly forbids adding restrictions that prevent users from redistributing the software.
- **c)** is incorrect because static linking creates a derivative work, meaning the separate application's source code would also have to be disclosed under the GPL.
- **d)** is incorrect because GPL allows charging a fee for the physical act of transferring a copy or for providing warranty protection.

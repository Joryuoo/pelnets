### Explanation

**Background on bit masking used in `check` function:**
The program uses a single integer `val` to keep track of two conditions simultaneously via bitmasking.
- **Bit 1 (Decimal value 2)** represents whether the word is a **palindrome**.
- **Bit 0 (Decimal value 1)** represents whether the word is a **mirrored word**.
The variable `val` is initially set to `3` (binary `11`), starting with the assumption that the word is a **mirrored palindrome** (both conditions are true). 

**Blank A: `c) i <= j`**
The `check` function uses a loop with `i` starting from the front of the string and `j` starting from the back, moving inwards to compare characters. For odd-length words, there is a middle character that stands alone. While a palindrome check could technically skip the middle character (it always equals itself), a mirrored word check **must** verify if the middle character is its own valid mirror (e.g. in "XOYOX", 'Y' must be a mirror character of itself). Therefore, the loop must execute when `i == j` as well, making `i <= j` the correct condition.

**Blank B: `a) val &= 1`**
Inside the loop, `if (str[i] != str[j])` tests if the word is NOT a palindrome. If this condition is met, we must turn off the palindrome bit (value `2`) while leaving the mirrored bit (value `1`) unchanged. 
- Using bitwise AND with `1` (`val &= 1` or binary `01`) will clear the 2-bit and preserve whatever state the 1-bit currently has. 
- Choices like `val &= 2` would incorrectly clear the mirrored bit instead of the palindrome bit.

**Blank C: `b) val &= 2`**
Similarly, `if (str[i] != reverse[str[j]])` checks if the current characters violate the mirrored word property. If this condition is met, we must turn off the mirrored bit (value `1`) while keeping the palindrome bit (value `2`) unchanged.
- Using `val &= 2` (binary `10`) ensures the 1-bit is cleared while preserving the 2-bit.

**Blank D: `a) str[i] != ' ' && str[i] != '\0'`**
The `getEndIndex` function increments `i` to find the last character of the current word. Words in the input string are separated by spaces, and the entire string ends with a null terminator `'\0'`. Thus, the loop should continue advancing `i` as long as the current character is neither a space NOR the null terminator. 

**Blank E: `c) sIndex = eIndex + 1`**
In the main loop, after analyzing a word that ended at `eIndex`, the program needs to move to the next word. The `sIndex` (start index) is updated to immediately follow `eIndex` (`sIndex = eIndex + 1`), skipping the current word so the loop can process any following spaces and find the next word.

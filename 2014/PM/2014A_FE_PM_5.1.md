### Explanation

*   **Blank A:** The text mentions an access control mechanism embedded in the network interface card. Unlike an IP address, which a user can change manually, this address is harder to modify without specific utilities. This refers to the **MAC address** filtering (b). 
*   **Blank B:** The text mentions that an AP sends beacon frames providing information for devices to join the network. The required information to initiate the connection that represents the network name is the **SSID** (Service Set Identifier) (e).
*   **Blank C:** The scenario requires securing HTTP connections between the web server and browsers using port 443. The correct protocol among the choices for this is **SSL** (Secure Sockets Layer) (g), which provides the encryption used in HTTPS.
*   **Blank D:** We must identify Company X's network name. The description states Company X has hidden its network name and has *no encryption* enabled. Looking at Figure 2, the AP with the MAC `xx:xx:xx:2C:46:80` has "Open" encryption (no encryption) and its network name is revealed as **WLAN** when a user attempts to associate. Thus, the network name is WLAN (e). Note that the other hidden network ("Office") uses WPA.
*   **Blank E:** An unauthorized user could bypass the MAC filtering by changing their MAC address to one that is already allowed to connect. The allowed devices are those already associated with Company X's AP (`xx:xx:xx:2C:46:80`). From Figure 2, the MAC addresses of client stations associated with this AP are `xx:xx:xx:F0:37:DB` and `xx:xx:xx:A4:26:F0`. Spoofing either of these (d) grants access.
*   **Blank F:** The question asks for the network name of the *most secure* AP listed in Figure 2. The encryption methods present are WPA, Open (none), and WEP. WPA is the most robust of these three. The AP using WPA encryption has the network name **Office** (b).

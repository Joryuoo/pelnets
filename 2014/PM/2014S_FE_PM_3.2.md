### Explanation

To find the headcount of currently working sailors and display the count of officers (`SO`) and non-officers (`SN`) for each vessel, the query uses an inline view (derived table `t`) that combines two subqueries using `UNION ALL`.

*   **Blank C:** The first subquery filters for officers (`WHERE Rank_type = 1`). In this subquery, we want to count the number of officers and set the count of non-officers to 0. Therefore, the select clause should be `COUNT(*) SO, 0 SN`. This corresponds to **b**.
*   **Blank D:** We only want to count "currently working sailors". Based on the scenario description, sailors who are currently on board have their `Sign_off_date` set to `NULL`. Thus, the condition is `Sign_off_date IS NULL`. This corresponds to **b**. (Choice **a** `IS NOT NULL` would count sailors who have already finished their contracts and signed off).
*   **Blank E:** To combine the result sets of the officers subquery and the non-officers subquery into a single result set without removing duplicates, we use the `UNION ALL` operator. This corresponds to **f**. 
*   **Blank F:** The second subquery filters for non-officers (`WHERE Rank_type = 2`). Here, we set the officer count to 0 and count the non-officers. The select clause should be `0 SO, COUNT(*) SN`. This corresponds to **a**.

Once the rows are combined via `UNION ALL`, the outer query groups by `Company_name, Vessel_name, Flag` and uses `SUM(SO)` and `SUM(SN)` to aggregate the total counts for officers and non-officers per vessel.

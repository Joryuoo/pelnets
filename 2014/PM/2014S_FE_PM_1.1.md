### Explanation

**Blank A:** 
For a 2-to-1 multiplexer, when the selection control line `S` is 1, the output `F` takes the value of the input line `I1`. 
Looking at the last four rows of Table 1 where `S = 1`, the values of `I1` are `0`, `1`, `0`, `1`. Therefore, the output `F` should also be `0`, `1`, `0`, `1`. This sequence corresponds to choice **(e)**.

**Blank B:** 
In the 4-to-1 multiplexer, the selection lines `S1` and `S0` determine which input `In` is routed to the output `F`. 
Let's map the values:
* `S1 = 0`, `S0 = 0` -> `I0` (n = 0)
* `S1 = 0`, `S0 = 1` -> `I1` (n = 1)
* `S1 = 1`, `S0 = 0` -> `I2` (n = 2)
* `S1 = 1`, `S0 = 1` -> `I3` (n = 3)

We can see that `n` is equivalent to the decimal value of the binary number formed by `S1 S0`. The mathematical formula for this is `2 * S1 + S0`. This matches choice **(b)**.

**Blank C:** 
We can construct the Boolean equation for `F` in the 4-to-1 multiplexer by creating a sum-of-products based on the conditions that pass an input to the output.
* Output is `I0` when `S1 = 0` and `S0 = 0` -> `(!S1 & !S0 & I0)`
* Output is `I1` when `S1 = 0` and `S0 = 1` -> `(!S1 & S0 & I1)`
* Output is `I2` when `S1 = 1` and `S0 = 0` -> `(S1 & !S0 & I2)`
* Output is `I3` when `S1 = 1` and `S0 = 1` -> `(S1 & S0 & I3)`
Combining these with the OR operator (`|`) yields the full expression: 
`(!S1 & !S0 & I0) | (!S1 & S0 & I1) | (S1 & !S0 & I2) | (S1 & S0 & I3)`. 
This matches choice **(a)**.

**Blank D:** 
For a 1-to-4 demultiplexer, the input `F` is routed to one of the four output lines based on `S1` and `S0`. The question asks for the Boolean equation of the output line `O2`.
Based on the text: "If `S1` is 1 and `S0` is 0, then the binary value of `F` is output to `O2`." 
Therefore, `O2` is `1` only when `S1` is `1`, `S0` is `0`, and `F` is `1`. This is expressed as `S1 & !S0 & F`. 
This matches choice **(d)**.

### Explanation

The question requires tracing an SMTP session between an SMTP sender and receiver. Based on the provided description of the message transfer phases:

*   **Blank A:** After the `MAIL` and `RCPT` commands are executed successfully, the SMTP sender initiates the transfer of the message text. According to phase (3) in the text, the command to initiate this is the `DATA` command. Thus, Blank A is **DATA** (Choice **b**).
*   **Blank B:** Upon sending the `DATA` command, the receiver replies with code `354 (start mail)`. The sender then proceeds to actually transmit the email content over the TCP connection, terminating with a line containing only a period. Thus, Blank B is **Send message** (Choice **f**).
*   **Blank C:** After the message is sent and successfully acknowledged with `250 (OK)`, the session must be closed. According to phase (4) in the text, the `QUIT` command closes the TCP connection, which the receiver acknowledges with a `221 (bye)` reply. Thus, Blank C is **QUIT** (Choice **d**).

**Other Choices:**
*   **a) 250 (OK):** This is a server reply code indicating successful execution of a command, not a sender action or command.
*   **c) MAIL:** This command is used earlier in the session to identify the originator of the message.
*   **e) RCPT:** This command is used to identify the individual recipients, which has already been completed before the `DATA` command.

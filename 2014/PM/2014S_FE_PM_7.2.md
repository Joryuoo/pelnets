### Explanation

A "zero-divide exception" (division by zero) occurs when a program attempts to divide a number by zero, which is an undefined mathematical operation. 

In the function `in_triangle()`, division is performed in the following lines:
- `u = (dot11 * dot02 - dot01 * dot12) / dv;`
- `v = (dot00 * dot12 - dot01 * dot02) / dv;`

In both of these statements, the divisor is the variable `dv`. Therefore, a division by zero exception will occur if the value of `dv` evaluates to `0` (`dv == 0`).

To determine the condition that causes `dv` to become `0`, we can look at the line immediately preceding the division where `dv` is calculated:
- `dv = dot00 * dot11 - dot01 * dot01;`

Setting `dv` to `0` in this equation gives:
`0 = dot00 * dot11 - dot01 * dot01`
`dot00 * dot11 = dot01 * dot01`

Thus, the zero-divide exception occurs when the value of `dot00 * dot11` is equal to the value of `dot01 * dot01`. 

Looking at the answer choices:
- Blank **C** corresponds to `dot00 * dot11` (Choice **c**).
- Blank **D** corresponds to `dot01 * dot01` (Choice **d**).

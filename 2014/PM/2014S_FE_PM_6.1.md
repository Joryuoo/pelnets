### Explanation

**Blank A:**
Table 3 tracks the state of the `Active[]` array after processing each end-point. Step 4) of (6) states: if the end-point is a left-end point (LEFT), set `Active[s]` to 1. If it's a right-end point (RIGHT), set `Active[s]` to 0. 
Looking at Table 2, at iteration `i=3`, `Points[3]` is processed. Its values are `c=0`, `s=4`, `e=LEFT`. 
Before this iteration, the active array was `{0, 1, 1, 0}`.
Activating segment `s=4` updates `Active[4]` to 1. The resulting array is `{0, 1, 1, 1}`, which corresponds to choice **d**.

**Blank B:**
The nested loops with `i` and `j` perform a Bubble Sort on the `Points[]` array. Step (6) part 2) says to "Sort Points[] in ascending order of the coordinate value".
To sort in ascending order, we must swap the elements if the coordinate value at the current index `i` is greater than the coordinate value at the checking index `j`. 
Therefore, the condition is `Points[i].c > Points[j].c`, which is choice **b**.

**Blank C:**
This section of the code updates the `Active[]` array based on whether an end-point is a LEFT or RIGHT edge.
The index used for the `Active[]` array must be the segment number that the current end-point belongs to. Structure `EndPoint` member `s` stores this segment number.
Therefore, `Active[Points[i].s]` is updated. The correct choice is **d** (`Points[i].s`).

**Blank D:**
The `FindMax()` subprogram finds the largest index in the `Active[]` array that currently holds the value 1.
The `Active[]` array tracks the status of all `n` segments, so its bounds are from 1 to `n`. The loop must check all `n` segments. 
Thus, the loop should run `i: 1, i <= n, 1`. The correct choice is **c** (`n`).

**Blank E:**
Inside the loop of `FindMax()`, it needs to check if the current segment `i` is active. Since `Active[i]` holds 1 when active and 0 when inactive, the condition must check if `Active[i] = 1`. Whenever this is true, `m` is updated to `i`. Since `i` counts upwards, `m` will ultimately store the highest active segment number.
The correct choice is **b** (`Active[i] = 1`).

# 2014S_FE_39
Which of the following is an appropriate function of a switching hub (layer 2 switch) that is used as a network device?

a) A received packet is divided (i.e., fragmented) into multiple packets in the network layer.
b) A received packet is forwarded (i.e., broadcasted) to all LAN ports.
c) A received packet is forwarded only to a LAN port corresponding to a destination MAC address.
d) An IP address for a terminal connected to a LAN port is dynamically allocated.
?
c) A received packet is forwarded only to a LAN port corresponding to a destination MAC address.
### Explanation
A switching hub (Layer 2 switch) operates at the Data Link Layer and uses MAC addresses to forward frames specifically to the port where the destination device is connected, reducing unnecessary traffic.
- Choice (a) refers to fragmentation at the network layer (Layer 3), done by routers.
- Choice (b) describes a repeating hub (Layer 1 hub), which broadcasts all packets to all ports.
- Choice (d) describes a DHCP server.

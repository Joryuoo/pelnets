# 2014S_FE_51
Which of the following is an appropriate description concerning the black box test?

a) Even if the program to be tested contains redundant code, such kind of code cannot be detected.
b) In consideration of the internal structure of the program, it is verified whether or not the necessary path is executed.
c) The amount of test data increases rapidly with an increase in the number of branch instructions or modules.
d) The coverage rates of instructions and branches are used as criteria for creating test data.
?
a) Even if the program to be tested contains redundant code, such kind of code cannot be detected.
### Explanation
Black box testing evaluates the functionality of an application without looking at its internal code structure or implementation details. Because the internal workings are ignored, any redundant or unreachable code inside the program will not be detected.
- **b)** describes white box testing, which examines the internal logic and paths.
- **c) and d)** describe aspects of white box testing (specifically path coverage and branch testing).

# 2014A_FE_30
![[2014Oct_FE_AM_Q30_full.png]]

a) 2,000
b) 100,000
c) 101,999
d) 200,000,000
?
c) 101,999
### Explanation
The SQL statement performs a **LEFT JOIN** from the `Product` table (left) to the `Sales` table (right). 
* A `LEFT JOIN` returns all rows from the left table, and the matched rows from the right table. If there is no match, the result is NULL on the right side.
* The `Product` table has 2,000 rows. The `Sales` table has 100,000 rows.
* Each Sale record belongs to exactly one Product (as per the UML diagram `1..1` on the Product side).

To find the **maximum** number of rows created, consider the scenario where all 100,000 sales belong to just **one single product**. 
1. That one product will match with all 100,000 sale records, generating 100,000 rows.
2. The remaining 1,999 products in the `Product` table have no matching sales. Due to the `LEFT JOIN`, each of these 1,999 products will still be included in the result set exactly once, with NULL values for the `Sales` columns.

Total maximum rows = 100,000 (from the matched sales) + 1,999 (from the unmatched products) = **101,999**.

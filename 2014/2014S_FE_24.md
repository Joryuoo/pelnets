# 2014S_FE_24
Which of the following is classified as an external interrupt?

a) An interrupt that is caused by access to a non-existent page in virtual memory
b) An interrupt that is caused by an arithmetic overflow or divide-by-zero
c) An interrupt that is caused by an interval timer when the specified time elapses
d) An interrupt that is caused by the execution of a software interrupt instruction
?
c) An interrupt that is caused by an interval timer when the specified time elapses
### Explanation
Interrupts can be classified as internal or external.
- **External interrupts** are triggered by events outside the CPU, such as I/O device completion, hardware failures, operator actions, or **interval timers**.
- **Internal interrupts** (also called exceptions or traps) are generated by the CPU during instruction execution. Options **a)** (page fault), **b)** (arithmetic error like divide-by-zero), and **d)** (software interrupts/SVC) are all internal interrupts.
